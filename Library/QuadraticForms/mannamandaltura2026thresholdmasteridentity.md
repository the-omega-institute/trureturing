# Master-identity criterion for threshold graph matrices

Conjecture 13.9, Section 13.4, printed p. 18, arXiv:2610.22838v1 states

> **Conjecture 13.9 (Master-identity criterion).** A graph matrix $M(G)$ is both always-integral and spectrally determining for threshold graphs if and only if $M(G)$ is an affine function of $L(G)$ and $J$ alone (i.e. $M(G)=\alpha L(G)+\beta J+\gamma I$ for scalars $\alpha,\beta,\gamma$, as is the case for $L$ itself and, via Proposition 7.3, for $D^L$).

Section 1, printed p. 1, defines finite threshold graphs by starting with one
vertex and repeatedly adding a vertex isolated from or adjacent to every
vertex already present. Section 2, printed p. 4, adopts connected threshold
graphs and writes $\operatorname{Deg}(G)$ for the diagonal degree matrix and
$L(G)=\operatorname{Deg}(G)-A(G)$ for the ordinary Laplacian. In the affine
form, $J$ is all ones and $I$ is the identity.

The specialization uses the source's own $\operatorname{Deg}(G)$, over the
reals. Spectral determination compares eigenvalue multisets with algebraic
multiplicity. The existential real coefficients are inside the graph
quantifier. The conjecture's wording is about a graph matrix $M(G)$.
Tables 1 and 3 organize examples surveyed in the paper.

The classical degree-sequence reconstruction is credited to Václav Chvátal
and Peter L. Hammer, *Aggregation of inequalities in integer programming*,
Annals of Discrete Mathematics **1** (1977), 145–162, reference [21] in
the survey. Their creation-sequence description applies also to the
disconnected intermediate graphs obtained by deleting the last addition.

Open Problem 15.6, Section 15, printed p. 21, asks for a structural criterion
predicting spectral determination. It is a separate question.
