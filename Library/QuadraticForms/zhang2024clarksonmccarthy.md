# Zhang, Clarkson–McCarthy type inequalities, part I

T. Zhang, arXiv:2410.21961v4 [math.FA] (28 March 2026; v1 29 October 2024). Quotations are from the v4 TeX source, with the macro `\tr` written as $\operatorname{tr}$. The same conjecture is restated in T. Zhang, arXiv:2602.01463v2.

The Schatten norm:

> For $1\le p<\infty$, let $S_p$ denote the Schatten–von Neumann class of compact operators $A:\ell_2\to\ell_2$ endowed with the norm $\|A\|_p=\bigl(\operatorname{tr} (A^*A)^\frac{p}{2}\bigr)^\frac{1}{p}=\Bigl(\sum_{j} s_j(A)^p\Bigr)^\frac{1}{p}$

The conjecture, introduced by "numerical evidence suggests the following sharp inequality":

> Let $A,B,C\in S_p$. Then for $2\le p<\infty$,
> $$\|A+B+C\|_p^p+\|A\|_p^p+\|B\|_p^p+\|C\|_p^p \le \frac{3^{p-1}+1}{2^p}\left(\|A+B\|_p^p+\|B+C\|_p^p+\|C+A\|_p^p\right).$$
> For $0<p\le2$, the inequality is reversed. Moreover, the constant $\frac{3^{p-1}+1}{2^p}$ is optimal: equality holds for all $p>0$ by taking $A=B=C\neq0$.
