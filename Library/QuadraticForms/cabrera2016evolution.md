# Simplicity of evolution algebras

Section 4, page 18 states: “We recall that an algebra A is simple if A² ≠ 0
and 0 is the only proper ideal.” The ideals are vector subspaces absorbing
multiplication on both sides; they are not restricted to spans of subsets
of a natural basis.
