# Reduction theory using semistability

## Locator

Daniel R. Grayson, *Reduction theory using semistability*, Commentarii Mathematici
Helvetici 59 (1984), 600–634. [DOI](https://doi.org/10.1007/BF02566369).

Earlier quadratic-form reduction theory appears in U. Stuhler,
*Eine Bemerkung zur Reduktionstheorie quadratischer Formen*, Archiv der Mathematik
27 (1976), 604–610. [DOI](https://doi.org/10.1007/BF01224726).

## Scope and abstract model

The classical setting is reduction theory for Euclidean lattices and quadratic forms,
using semistability and canonical slope filtrations. It supplies the mathematical
background for the repository's Harder–Narasimhan construction.

The repository model instead assumes an arbitrary lattice, a strictly increasing
natural-number rank satisfying the modular identity, and a supermodular real degree.
Its interval slopes use degree and rank differences. The three abstract existence,
uniqueness and extreme-slope statements are repository derivations under these explicit
hypotheses; this citation does not assert an identical theorem in either article.
An application to Euclidean lattices additionally requires saturated subobjects,
subspace covolumes and their supermodularity inequality. No such application or
operator-norm slope comparison is part of the abstract statements.
