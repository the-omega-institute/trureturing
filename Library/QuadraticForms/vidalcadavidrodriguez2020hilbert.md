# Hilbert evolution algebras

Definition 2.2 uses a real or complex separable Hilbert space, a bilinear
multiplication, and a complete orthonormal natural basis. For every fixed
vector v, left multiplication satisfies a bound
$\|v w\|\le M_v\|w\|$ for some $M_v>0$ and every w.
The preceding discussion uses convergent Hilbert expansions, not Hamel bases.
Corollary 2.4 supplies the Hilbert realization framework for a uniformly
bounded square table. These ingredients do not assert uniqueness of natural
orthonormal bases when the square is dense.
