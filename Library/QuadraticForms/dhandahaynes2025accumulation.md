# Quadratic norm values and normalized approximation

Theorem 4 treats a real quadratic irrational with arbitrary rational constant
and nonzero square-root coefficients, and a squarefree integer radicand at
least two. The approximation set uses all nonzero integer denominators and
all integer numerators, without a coprimality restriction.

Its accumulation set is the set of both signs of twice the square-root
coefficient times the square root of the radicand times the field norm of
each nonzero element of the trace dual of the lattice generated by one and
the irrational. Thus the right-hand side is a set of values of a binary
quadratic norm form on the actual trace-dual lattice.

Section 2.3 supplies the lattice and trace-pairing definitions. Section 7
proves the classification using a finite reduction and units. The
introduction also explicitly allows the possibility of elementary quadratic
proofs; the use of general algebraic number theory is motivated by higher
dimensional extensions.

The Lean statement `QuadraticAccumulation.signed_norm_values_accumulate` supplies the norm-value
inclusion, including injective sequences of genuine approximation values.
The Lean statement `QuadraticAccumulationClassification.derivedSet_eq_signed_norm_values` establishes the complete
classification. Its converse uses finite bounded-denominator sets, vanishing
unnormalized errors and eventual constancy of signed norm labels in a fixed
rational grid. This elementary argument is distinct from the source's
finite-reduction-and-units proof. An explicit algebra
equivalence identifies the coordinate presentation with the actual real
subfield generated by the irrational. Traces and norms are transported
through this equivalence, so the final theorem uses the actual trace-dual
lattice and field norm in that subfield.
