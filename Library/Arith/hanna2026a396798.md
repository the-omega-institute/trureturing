# OEIS A396798: the eighth compositional iterate

Paul D. Hanna's June 16, 2026 entry defines the ordinary integer series
`A(X)=Sum_{n>=1} a(n)X^n` by `A=X+I4(A)*I5(A)`, where `Ik` is the k-fold
compositional iterate and the product is ordinary multiplication. There is
no factorial scaling. Revision 12, dated June 17, states the eighth comment:

> Conjecture: [x^n] A^8(x) == 0 (mod 8) for n > 1.

`IterateProductFourFiveEighthModEight.generatingSeries` constructs this
zero-constant integer series by coefficient stabilization. Its sole `result`
proves the displayed divisibility for every n>1. The proof establishes the
source equation and uniqueness, identifies the source modulo four, then
uses an exact integer quotient and square-zero iteration modulo eight.

This resolves only the eighth comment, preregistered in issue #7943. The
original first comment's n>=1 period conflicts with its own a(3)=9; that
previously recorded non-kernel observation is not a new formal refutation.
Comments 2 through 7 and a proposed correction of the first comment remain
separate. The bounded source, cross-reference and exact-identifier searches
in #7943 found no earlier eighth-clause settlement; they do not establish
global priority or exclude all differently named general results.
