# Prime square perfect-power representation

Both OEIS entries state the same conjecture:

> Conjecture: There will always be an x,y,n such that x^2 + p = y^n for all primes p.

The exponent is read as at least two, which is the standard perfect-power
condition. Allowing exponent one would make the sentence immediate by taking
the power base to be the square plus the prime.
