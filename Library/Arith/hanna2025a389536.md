# OEIS A389536

Paul D. Hanna's entry, dated October 28, 2025, defines the generating function
by `A(x) = A(x^2 + 2*x^3) / x` and states the quoted coefficient conjecture.
The normalization is `a(1) = 1`; comparing the coefficient of `x^2` in
`x*A(x) = A(x^2 + 2*x^3)` gives the tautology `a(1) = a(1)`, so this
normalization is free. The Lean module constructs the integer series with
zero constant term, proves the normalized equation and uniqueness, and
proves the conjecture for every index greater than one.
