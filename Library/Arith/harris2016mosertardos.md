# Actual unions in the Moser–Tardos law

The inspected version is [v7](https://arxiv.org/html/1610.09653v7), dated
10 October 2019; first submission 30 October 2016. Checked 16 September 2026.
Proposition 3.4 bounds an ordered union using disjoint ambient pieces.
Section 1.1 defines adjacency by shared variables; Propositions 2.7 and 3.3
retain that dependency convention.

The bound can be applied to level sets of one complete test-layout load.
It does not justify replacing shared-variable edges by assignment-conflict
edges. The [Erdős #7 dossier](../../Problems/erdos-7-odd-covering-systems.md)
uses the separately verified commutative-resampling theorem of
[Iliopoulos](iliopoulos2017commutative.md) for that finer graph. Neither source
supplies an unconditional numerical head bound for the covering problem.
