# OEIS A393856

Paul D. Hanna's entry of March 11, 2026 defines the generating function by
`A( x - x*A(4*x)/4 ) = x` and conjectures `a(n) == 1 (mod 5)` for `n >= 1`.
The Lean module constructs the unique integer solution, proves the functional
equation, and proves the congruence as the case `q = 4` of a parametric theorem.
The entry's separate conjecture about odd coefficients is not addressed.
