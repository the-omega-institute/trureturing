# OEIS A322327

Schulte's conjecture concerns the function obtained by multiplying the
prime-factorization exponents and then multiplying by an integer parameter
raised to the number of distinct prime divisors. The formal scope is the two
assertions in the quoted conjecture sentence for every integer `k`:
multiplicativity on coprime positive arguments and the prime-power value
`k*e`. The trailing sequence correspondences are outside the claim. Lean's
natural-power convention supplies `0^0 = 1`.
