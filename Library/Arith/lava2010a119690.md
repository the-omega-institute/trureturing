# OEIS A119690

The NAME of A119690 states:

> n! mod n*(n+1)/2.

John W. Layman's target COMMENT states:

> It appears that f(n)=(n!)^(2k+1) modulo n(n+1)/2 is n if n is one less than an odd prime, else f(n) is 0, for any integer k. See A175567 for related results involving an even power of n!. - _John W. Layman_, Jul 12 2010

The FORMULA line states:

> a(n) = n if n+1 is an odd prime, a(n) = 0 otherwise.

The AUTHOR line states:

> _Paolo P. Lava_ and _Giorgio Balzarotti_, Jun 09 2006

Paolo P. Lava and Giorgio Balzarotti authored the sequence, while John W.
Layman authored the target conjectural comment. The bibliographic year 2010
records the conjecture date, not the 2006 sequence-author date.

The formal result settles only Layman's generalization to all odd powers.
The case `k = 0` is already the entry's own FORMULA, and no priority is
claimed for that case.
