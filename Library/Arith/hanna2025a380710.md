# OEIS A380710

Paul D. Hanna's entry of February 18, 2025 defines the generating function
by the displayed equation and states the parity conjecture. Here `abs`
takes the absolute value of each coefficient of the reciprocal-square
series. The Lean module constructs the unique integer solution with
constant coefficient one and proves the conjecture for every positive index.
