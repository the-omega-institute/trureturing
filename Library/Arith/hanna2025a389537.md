# OEIS A389537

Paul D. Hanna's entry defines the integer generating series by
`A(A(x) - x) = A(x)^2`, with zero constant coefficient and linear
coefficient one. It states the coefficient congruence conjecture quoted
above. The Lean module constructs this series by compositional reversion,
proves its defining equation and uniqueness, and proves both directions
of the mod-four classification for every index greater than two.
