# Linear Models

## Verified locator

John Wiley and Sons, New York, 1971 (Wiley Classics Library reprint 1997 carries the DOI), chapters on estimable functions in the non-full-rank linear model. Used for the classical mechanism behind the pair theorem: components of the parameter in the kernel of the design matrix cannot be recovered from training data. The fiber-law volume adds only the readout-fiber phrasing and an explicit hitting-time witness.
