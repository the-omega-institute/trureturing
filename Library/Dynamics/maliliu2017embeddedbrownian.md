# Calibrated linear memory and noise

Section II, arXiv:1606.03625v2, pages 4--6, equations (4)--(10), and page 12,
equations (28)--(29), keep the friction or memory operator and the Gaussian
forcing covariance as a paired contract, with equilibrium initialization in the
linear setting. The paper's broader generalized-Langevin framework is not
claimed for the finite graph below.

The source15 application solves its finite Ornstein--Uhlenbeck equation
directly. This note supplies background for the paired-memory requirement; it
does not turn a static precision matrix into a clock or a physical bath.
