# Permutative lifts and the general minimal branch

The source's Question 1.10 asks: given a minimal/strictly ergodic (Toeplitz)
subshift, does some permutative sliding block code of length at least two
have a minimal/strictly ergodic complete inverse image? Permutativity means
bijectivity in each endpoint with every other letter fixed. The same finite
alphabet is used for the source and image of the code. Theorem 1.3 describes
the entire lift as a finite permutation skew product with the actual prefix
fibre, of cardinality κ^(ℓ−1).

The linked formal construction addresses the general minimal branch without
the optional Toeplitz restriction. Its single infinite binary minimal base
has nonminimal entire lifts for all lengths and all such codes. It does not
claim the Toeplitz branch or a formal unique-ergodicity strengthening.

The coboundary mechanism is prior work, including Berthé, Goulet-Ouellet,
Nyberg-Brodda, Perrin and Petersen, arXiv:2403.17892v3, Definition 7.3,
Proposition 7.4 and Theorem 7.5. The candidate contribution is the explicit
recognizable factorial base simultaneously neutralizing all finite letter
actions. A bounded primary-source search on 2026-10-31 did not locate this
same uniform construction; it establishes neither worldwide absence nor
priority. Cited works announced as in preparation were unavailable.
