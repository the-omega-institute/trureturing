## Source statements

The loss channel: "E_τ(|α⟩⟨α|) := |√τ α⟩⟨√τ α|, (2) where 0 ≤ τ ≤ 1 is the transmissivity parameter … we can describe the action of a loss channel on state ρ as E_τ(ρ) = tr₂(U_BS ρ ⊗ |0⟩⟨0| U_BS†). The unitary operator U_BS describes the beam splitter, and its action on coherent and vacuum states U_BS|α⟩|0⟩ = |√τ α⟩|√(1−τ) α⟩ gives the definition (2)."

Result 2: "A loss channel with transmissivity τ ≤ 1/n breaks the incompatibility of any arbitrary set of n measurements … denoting E*_τ as the dual of the loss channel defined through tr(M^j_{a_j} E_τ(ρ)) =: tr(ρ E*_τ(M^j_{a_j})), the set of measurements {{E*_τ(M^j_{a_j})}_{a_j}}_{j=1}^n with n ≤ ⌊1/τ⌋ is jointly measurable."

Result 3: "There exist a set of n + 1 measurements that remain incompatible under τ = 1/n transmissivity. We prove this result numerically for 2 ≤ n ≤ 13, and conjuncture it to hold for arbitrary n."

Eq. (4): the two-outcome measurements M^k_1 = |μ_k⟩⟨μ_k| and M^k_2 = I − M^k_1 with coherent states |μ_k⟩ of equal modulus r, separated by the phase 2π/(n + 1) (Fig. 2).

Conclusions: "We explicitly show this for 2 ≤ n ≤ 13. However, we conjecture that the same is true for higher n."
