## Source statements

§2, Eq. (1): "Pr(s_i(t+1) = a) = w(a | s_{i−1}(t), s_i(t), s_{i+1}(t))."

§2, Eq. (2): "w(1|x₁x₂x₃) = (1−λ) f(x₁,x₂,x₃) + λ g(x₁,x₂,x₃)."

§2: "Suppose that we start with a symmetric Bernoulli distribution … d∞ = lim_{t→∞} d_t. Note that d_t and d∞ as defined above are theoretical expected values of s_i(t), for infinite lattice and assuming initial symmetric Bernoulli measure."

§3.2: "The diploid 10-245 has the following transition probabilities: w(1|x,y,z) = λ, 1−λ, λ, 1−λ, λ, λ, λ, λ" for xyz = 000, …, 111. The order-3 local structure approximation "yields the expression d = 1/4 + λ/2."

§5: "for rule 10-245, the expression for the asymptotic density, d = 1/4 + λ/2, appears to be exact. Could this be formally demonstrated?"
