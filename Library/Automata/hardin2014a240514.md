## Source statement

> Number of nX3 0..1 arrays with no element equal to exactly two horizontal and vertical neighbors, with new values 0..1 introduced in row major order.

> Empirical: a(n) = 4*a(n-1) -3*a(n-2) -2*a(n-3) +2*a(n-4) +2*a(n-5) -7*a(n-6) -8*a(n-7) +15*a(n-8) +4*a(n-9) -8*a(n-10) -4*a(n-11) +15*a(n-12) +8*a(n-13) -7*a(n-14) -2*a(n-15) +2*a(n-16) +2*a(n-17) -3*a(n-18) -4*a(n-19) -a(n-20)

The offset is `1,1`; the first six terms are `3,6,10,28,73,196`.
For a binary alphabet, introducing values in row-major order means that the
first entry is zero. The value one need not occur. Every in-board orthogonal
neighbor is counted once; boundaries do not wrap, and diagonals do not count.

## Mathematical mechanism

The formal definition filters every map `Fin n × Fin 3 → Bool` by the
first-entry condition and the literal local neighbor rule. It does not use
a recurrence to define the sequence. There are eight binary rows and
sixty-four ordered row-pair states. The transfer checks the middle row;
its terminal vector checks the final boundary. The initial weighted sum
checks the first boundary and fixes its first entry to false.

Finite-function decomposition and induction identify the weighted continuation
sum with the board count at every height at least two. An integer table for
continuation lengths zero through twenty satisfies the terminal condition
and each transition, as verified by Lean kernel reduction. The order-twenty
polynomial annihilates the entire initial continuation vector. Linearity
propagates this relation and the weighted sum to all heights at least twenty-two.
The same finite table, together with the literal count at height one,
establishes the remaining height-twenty-one case. All recurrence subtraction
is in the integers.
