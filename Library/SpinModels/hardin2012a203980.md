# OEIS A203980

## Verified locator

<https://oeis.org/A203980>; NAME and FORMULA are quoted in #31593.

## Source statement

> Number of (n+1) X 5 0..2 arrays with no 2 X 2 subblock having equal diagonal elements or equal antidiagonal elements, and new values 0..2 introduced in row major order.

> Empirical: a(n) = 15*a(n-1) - 270*a(n-3) + 324*a(n-4).

## Mathematical scope

The array has five columns and exactly 0 monochromatic diagonal or antidiagonal bonds.
There are no horizontal or vertical bonds. Colours follow literal row-major introduction.
The recurrence holds at every index at least 5; the number of rows is n+1.
These are finite three-state Potts antiferromagnet counts up to global colour relabelling.
