## Source statement

> Number of defective 3-colorings of an n X 5 0..2 array connected horizontally, diagonally and antidiagonally with exactly one mistake, and colors introduced in row-major 0..2 order.

> Empirical: a(n) = 28*a(n-1) - 286*a(n-2) + 1290*a(n-3) - 2373*a(n-4) + 304*a(n-5) + 3551*a(n-6) - 2846*a(n-7) - 546*a(n-8) + 1308*a(n-9) - 505*a(n-10) + 76*a(n-11) - 4*a(n-12) for n > 13.

## Mathematical scope

The reading index in #31121 is n at least 14, separately from the verbatim
source formula. The array has n rows and 5 columns and exactly 1
monochromatic horizontal, diagonal and antidiagonal bonds. Canonical colour
introduction follows literal row-major order. These are finite combinatorial counts.
