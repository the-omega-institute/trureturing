# OEIS A203981

## Verified locator

<https://oeis.org/A203981> records the NAME and FORMULA quoted in [#32721](https://github.com/the-omega-institute/trureturing/issues/32721).

## Source statement

> Number of (n+1) X 6 0..2 arrays with no 2 X 2 subblock having equal diagonal elements or equal antidiagonal elements, and new values 0..2 introduced in row major order.

> Empirical: a(n) = 25*a(n-1) - 45*a(n-2) - 963*a(n-3) + 2025*a(n-4) + 3645*a(n-5) - 6561*a(n-6).

> Empirical g.f.: 96*x*(16 - 76*x - 819*x^2 + 2124*x^3 + 3321*x^4 - 6561*x^5) / ((1 - 25*x + 90*x^2 - 81*x^3)*(1 - 45*x^2 - 81*x^3)). - _Colin Barker_, Jun 06 2018

## Mathematical scope

The array has six columns and exactly 0 monochromatic diagonal or antidiagonal bonds.
Colours follow literal row-major introduction.
The registered recurrence starts at index 7, which corresponds to 8 rows.
These are finite three-state Potts antiferromagnet counts up to global colour relabelling.
