# OEIS A229508

## Verified locator

<https://oeis.org/A229508> records the NAME and FORMULA quoted in [#32721](https://github.com/the-omega-institute/trureturing/issues/32721).

## Source statement

> Number of defective 3-colorings of an n X 6 0..2 array connected diagonally and antidiagonally with exactly one mistake, and colors introduced in row-major 0..2 order.

> Empirical: a(n) = 50*a(n-1) -715*a(n-2) +324*a(n-3) +50175*a(n-4) -180630*a(n-5) -940491*a(n-6) +4556250*a(n-7) +2329155*a(n-8) -27398736*a(n-9) +13286025*a(n-10) +47829690*a(n-11) -43046721*a(n-12) for n>13.

> Empirical g.f.: 192*x^2*(40 - 812*x + 2005*x^2 + 40851*x^3 - 164547*x^4 - 625725*x^5 + 3177063*x^6 + 1119015*x^7 - 16522785*x^8 + 8109396*x^9 + 26926344*x^10 - 23914845*x^11) / ((1 - 25*x + 90*x^2 - 81*x^3)^2*(1 - 45*x^2 - 81*x^3)^2). - _Colin Barker_, Jun 16 2017

## Mathematical scope

The array has six columns and exactly 1 monochromatic diagonal or antidiagonal bonds.
Colours follow literal row-major introduction.
The registered recurrence starts at index 14, which corresponds to 14 rows.
These are finite three-state Potts antiferromagnet counts up to global colour relabelling.
