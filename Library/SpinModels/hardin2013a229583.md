## Source statement

> Number of defective 3-colorings of an n X 5 0..2 array connected horizontally and
> antidiagonally with exactly one mistake, and colors introduced in row-major 0..2 order.

> Empirical: a(n) = 30*a(n-1) - 261*a(n-2) + 540*a(n-3) - 324*a(n-4).

The FORMULA line states no threshold. With offset 1, the recurrence is read for every $n\ge 5$, the first index at which $a(n-4)$ is defined.

The offset is 1. The literal counts at n=1 through seven are
16, 444, 9156, 167364, 2865780, 47091780, 752194836.

## Mathematical scope

A defect is a monochromatic bond. The in-row bonds join adjacent columns;
the between-row bonds join the upper-right cell to the lower-left cell.
Canonical colours first occur in increasing order. Every nonempty one-defect
array of this width uses at least two colours; each colour orbit has six members.
The continuation classes retain the equality pattern on the outgoing row tail
and the residual defect budget. There are 14 such classes.
The finite certificate verifies all class counts, budget preservation,
initial weights and an annihilating relation on forward weights.
The characteristic factor is (x² - 15x + 18)². The scalar relation at its
first registered index is checked separately from forward-vector propagation.
