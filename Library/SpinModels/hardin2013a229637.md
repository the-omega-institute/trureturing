## Source statement

> T(n,k) = number of defective 3-colorings of an n X k 0..2 array connected horizontally, diagonally and antidiagonally with exactly two mistakes, and colors introduced in row-major 0..2 order.

> Empirical for column k: k=1: a(n) = a(n-1)

> Empirical for row n: n=1: a(n) = 6*a(n-1) - 12*a(n-2) + 8*a(n-3) for n > 6.

> Row 1 is A052482(n-2).

## Mathematical scope

The array has n rows and k columns over {0,1,2}. A mistake is a monochromatic pair of
horizontally, diagonally or antidiagonally adjacent cells, and colours are introduced in
row-major order. The table starts 0, 0, 1, 3, 12, 40, 120, 336 in its first row, so
T(1,k) = C(k-1,2) 2^(k-4) for k >= 4, and its first column is 0. The width-5 column is
A229634, whose count uses the same defect and canonical predicates.
