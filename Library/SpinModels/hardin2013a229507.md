# OEIS A229507

## Verified locator

<https://oeis.org/A229507>; NAME and FORMULA are quoted in #31593.

## Source statement

> Number of defective 3-colorings of an n X 5 0..2 array connected diagonally and antidiagonally with exactly one mistake, and colors introduced in row-major 0..2 order.

> Empirical: a(n) = 30*a(n-1) - 225*a(n-2) - 540*a(n-3) + 8748*a(n-4) - 9720*a(n-5) - 72900*a(n-6) + 174960*a(n-7) - 104976*a(n-8) for n > 9.

## Mathematical scope

The array has five columns and exactly 1 monochromatic diagonal or antidiagonal bonds.
There are no horizontal or vertical bonds. Colours follow literal row-major introduction.
The recurrence holds at every index at least 10; the number of rows is n.
These are finite three-state Potts antiferromagnet counts up to global colour relabelling.
