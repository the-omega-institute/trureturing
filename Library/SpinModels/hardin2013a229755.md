## Source statement

> T(n,k) = number of defective 4-colorings of an n X k 0..3 array connected horizontally, vertically, diagonally and antidiagonally with exactly two mistakes, and colors introduced in row-major 0..3 order.

## Mathematical scope

The reading index n in the k=1 column is the number of rows. Every result count uses
row-major first occurrence of colour labels. Subtraction in a recurrence is interpreted
in the integers. The canonical introduction transfer records the number of colours
already introduced, so two-colour orbits are included without a uniform orbit divisor.
