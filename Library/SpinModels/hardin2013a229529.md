## Source statement

> Number of defective 3-colorings of an n X 3 0..2 array connected horizontally, diagonally and antidiagonally with exactly one mistake, and colors introduced in row-major 0..2 order.

> Empirical: a(n) = 10*a(n-1) - 29*a(n-2) + 20*a(n-3) - 4*a(n-4) for n>5.

## Mathematical scope

The reading index in #31121 is n at least 6, separately from the verbatim
source formula. The array has n rows and 3 columns and exactly 1
monochromatic horizontal, diagonal and antidiagonal bonds. Canonical colour
introduction follows literal row-major order. These are finite combinatorial counts.
