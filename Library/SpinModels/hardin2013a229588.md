## Source statement

> Number of defective 3-colorings of a 3 X n 0..2 array connected horizontally and antidiagonally with exactly one mistake, and colors introduced in row-major 0..2 order.

> Empirical: a(n) = 10*a(n-1) - 29*a(n-2) + 20*a(n-3) - 4*a(n-4) for n>6.

## Mathematical scope

The reading index in #30838 is n at least 7; this index is separate
from the verbatim source quotation. A monochromatic bond contributes one
mistake. The array has 3 rows and n columns; the canonical order is the
literal row-major order i*n+j. Transfer proceeds by columns, without
changing that order. There are 10 equality-and-budget classes.
The exact budget is 1. The certified forward relation starts at
power 2 and has degree 4. This is a finite combinatorial statement,
with no thermodynamic-limit assertion.
