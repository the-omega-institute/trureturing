# OEIS A229683

## Verified locator

<https://oeis.org/A229683> records the NAME and FORMULA quoted in [#32721](https://github.com/the-omega-institute/trureturing/issues/32721).

## Source statement

> Number of defective 3-colorings of an n X 6 0..2 array connected diagonally and antidiagonally with exactly two mistakes, and colors introduced in row-major 0..2 order.

> Empirical: a(n) = 75*a(n-1) - 2010*a(n-2) + 19486*a(n-3) + 60075*a(n-4) - 2206575*a(n-5) + 7404210*a(n-6) + 70536825*a(n-7) - 435322350*a(n-8) - 601275555*a(n-9) + 8082823950*a(n-10) - 6257717775*a(n-11) - 54520532190*a(n-12) + 92909172825*a(n-13) + 132368667075*a(n-14) - 366499782594*a(n-15) + 470715894135*a(n-17) - 282429536481*a(n-18) for n > 20.

## Mathematical scope

The array has six columns and exactly 2 monochromatic diagonal or antidiagonal bonds.
Colours follow literal row-major introduction.
The registered recurrence starts at index 21, which corresponds to 21 rows.
These are finite three-state Potts antiferromagnet counts up to global colour relabelling.
