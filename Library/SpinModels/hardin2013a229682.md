# OEIS A229682

## Verified locator

<https://oeis.org/A229682>; NAME and FORMULA are quoted in #31593.

## Source statement

> Number of defective 3-colorings of an n X 5 0..2 array connected diagonally and antidiagonally with exactly two mistakes, and colors introduced in row-major 0..2 order.

> Empirical: a(n) = 45*a(n-1) - 675*a(n-2) + 2565*a(n-3) + 25272*a(n-4) - 211410*a(n-5) + 3805380*a(n-7) - 8188128*a(n-8) - 14959080*a(n-9) + 70858800*a(n-10) - 85030560*a(n-11) + 34012224*a(n-12) for n > 13.

## Mathematical scope

The array has five columns and exactly two monochromatic diagonal or antidiagonal bonds.
There are no horizontal or vertical bonds. Colours follow literal row-major introduction.
The recurrence holds at every index at least 14; the number of rows is n.
These are finite three-state Potts antiferromagnet counts up to global colour relabelling.
