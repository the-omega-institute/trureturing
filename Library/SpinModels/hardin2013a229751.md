## Source statement

> Number of defective 4-colorings of an n X 4 0..3 array connected horizontally, vertically, diagonally and antidiagonally with exactly two mistakes, and colors introduced in row-major 0..3 order.
>
> Empirical: a(n) = 9*a(n-1) - 33*a(n-2) + 63*a(n-3) - 66*a(n-4) + 36*a(n-5) - 8*a(n-6) for n>11.
>
> Empirical g.f.: x*(3 + 395*x - 1352*x^2 - 825*x^3 + 7089*x^4 - 6731*x^5 + 132*x^6 + 863*x^7 - 58*x^8 - 60*x^9 + 8*x^10) / ((1 - x)^3*(1 - 2*x)^3). - _Colin Barker_, Sep 21 2018

## Mathematical scope

The reading index n counts rows at fixed width 4. The colours are introduced
in row-major order. Recurrence subtraction is interpreted in the integers.
