## Source statement

> T(n,k) = number of defective 4-colorings of an n X k 0..3 array connected horizontally, vertically, diagonally and antidiagonally with exactly one mistake, and colors introduced in row-major 0..3 order.

> Empirical for column k:
> k=1: a(n) = 8*a(n-1) - 22*a(n-2) + 24*a(n-3) - 9*a(n-4) for n > 6.
> k=2: a(n) = 4*a(n-1) - 4*a(n-2) for n > 3.
> k=3: a(n) = 6*a(n-1) - 13*a(n-2) + 12*a(n-3) - 4*a(n-4) for n > 5.
> k=4: a(n) = 6*a(n-1) - 13*a(n-2) + 12*a(n-3) - 4*a(n-4) for n > 7.
> k=5: a(n) = 6*a(n-1) - 13*a(n-2) + 12*a(n-3) - 4*a(n-4) for n > 7.
> k=6: a(n) = 6*a(n-1) - 13*a(n-2) + 12*a(n-3) - 4*a(n-4) for n > 7.
> k=7: a(n) = 6*a(n-1) - 13*a(n-2) + 12*a(n-3) - 4*a(n-4) for n > 7.

## Mathematical scope

A mistake is a monochromatic bond. The four bond orientations are horizontal, vertical, diagonal and antidiagonal. Colour labels first appear in increasing order along the row-major cell order. These are canonical counts, with no identification of different cell positions.

The displayed recurrence statements are empirical assertions in the source. The corresponding integer identities are derived here from the literal finite-array count. This note makes no claim about the source's generating functions or about literature priority.

The table definition also supplies the two-dimensional count T(n,k). Labelled arrays omit the first-appearance constraint. When both dimensions are at least two, each canonical colouring has twenty-four labelled colourings. The additive difference fields and the structural closed forms are repository constructions and deductions.
