# Ordowski's A369378 Fermat-number covering conjecture

T. Ordowski's OEIS A369378 entry was created 22 January 2024. Its COMMENTS line
states verbatim: "Conjecture: if n > 0, then 2^(2^n+1)-1 + 2^k is not prime for every k < 2^n."
The entry's NAME line states: "a(n) is the smallest k such that 2^(2^n+1)-1 + 2^k is prime, or -1 if no such k exists."

The Lean claim uses natural numbers n and k, the strict condition 0 < n, the bound
k < 2^n including k = 0, natural subtraction, and Nat.Prime. The settlement's
Fermat-number covering proof is newly derived in the repository from the odd part
of k and modular arithmetic in ZMod.

The source data include a(1) = 2 and a(2) = 4. The accompanying finite checker is
in the-omega-institute/trureturing-experiments at
