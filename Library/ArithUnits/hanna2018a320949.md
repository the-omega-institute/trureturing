# OEIS A320949

Paul D. Hanna's OEIS A320949 revision 12 (2018-11-25) states verbatim:

> `%N A320949 G.f. A(x) satisfies: Sum_{n>=0} (1+x)^(n^2) / (1 + A(x))^(n+1)  =  1.`
>
> `%F A320949 a(n) = 0 (mod 3) for n > 0 (conjecture).`

The entry's example gives `A(x) = 1 + 3*x + 21*x^2 + 360*x^3 + ...` and identifies `a(n)` with the ordinary coefficient `[x^n]A(x)`. The formalization interprets the displayed infinite sum coefficientwise through convergent rational sums in the usual topology; it does not use an X-adic sum.
