# Gardam's counterexample to the unit conjecture

Giles Gardam, *A counterexample to the unit conjecture for group rings*,
Annals of Mathematics 194 (3) (2021), arXiv:2102.11818v2,
DOI [10.4007/annals.2021.194.3.9](https://doi.org/10.4007/annals.2021.194.3.9).

Theorem A uses the group `P` generated by `a` and `b` with relations
`b⁻¹ a² b a² = 1` and `a⁻¹ b² a b² = 1`.  It defines `x=a²`, `y=b²`,
`z=(ab)²` and an element `u` in the group ring `F₂[P]`.  The formal module
`D5/S3/ArithUnits/Gardam` checks all three clauses: every nonzero natural
power equal to one forces the group element to be one, `u` is a unit, and
`u` is not a basis group element.
