# Hastings, Small Majorana fermion codes

M. B. Hastings, Quantum Inf. Comput. 17(13–14), 1191–1205 (2017); arXiv:1703.00612v1. Quotations are from the v1 TeX source.

A Majorana fermion code on $n_{\rm phys}$ modes corresponds to a self-orthogonal subspace of $\mathbb F_2^{n_{\rm phys}}$ (bit strings of the stabilizers), with $n_{\rm log}=n_{\rm phys}/2-n_{\rm stab}$ logical qubits; the distance is the minimum weight of a product of Majorana operators that commutes with every stabilizer but is not one. The paper restricts to codes whose stabilizer group contains the fermion parity. It proves that no such code with $n_{\rm phys}\le12$ has distance 4 and $n_{\rm log}>0$, constructs codes with $n_{\rm phys}=16$, and states:

> For $n_{\rm phys}=14$, we performed a numerical search (described in the next section) for a code with $n_{\rm stab}=6$ and did not succeed. Hence, we believe that no such code exists, i.e., we believe that $n_{\rm phys}=16$ is the minimum number of modes to have $d=4,n_{\rm log}>0$.
