# Kepler's fixed-graph question for the Bα matrix

Garrett Kepler, *Some Spectral Properties of the Bα Matrix of a Graph*,
arXiv:2607.25221v1 [math.CO], July 2026.

## Verified locator

DOI: 10.48550/arXiv.2607.25221

Source: https://arxiv.org/abs/2607.25221v1

Definition 1.5 (α-Matrices), printed p. 1, uses
$B_\alpha(G)=\alpha A(G)+(1-\alpha)L(G)$ for $\alpha\in[0,1]$.
Definitions 1.1–1.3 supply the adjacency matrix $A$, the degree matrix $D$
and $L=D-A$. The expression is equivalently
$B_\alpha=(1-\alpha)D+(2\alpha-1)A$.
[Definition 1.5 in the v1 PDF](https://arxiv.org/pdf/2607.25221v1#page=1)

Remark 4.3, printed p. 8, specifies an eigenvector with “a single 1 entry, a
single -1 entry, and n − 2 zero entries” and asks

> What Theorem 4.2 does not address is how many of these types of eigenvectors a given graph has. This may be an interesting place for exploration.
