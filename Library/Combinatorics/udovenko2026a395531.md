# Greedy-brick row births

OEIS A395531, revision 30, attributes the quoted conjecture to Aleksei
Udovenko, May 7, 2026. Bricks have integer widths 1,2,3,... and unit height.
Each brick is placed as close to the vertical axis as possible on the highest
fully supported row. The sequence records the width of the first brick in
each row, numbered from one.

The entry's Python generator stores rows from bottom to top. It creates a
new top row if the current width fits on the old top row; otherwise it
extends the highest row on which the whole brick fits. The independently
defined sourceRowStep stores these same rows in the reverse order. The
frozen row-transition and labelled-history results supply the capacity and
physical placement correspondence. No generator source is redistributed.
