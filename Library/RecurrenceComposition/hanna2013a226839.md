NAME, verbatim:

> E.g.f.: exp( Sum_{n>=1} x^(n*(n+1)/2) / n! ).

FORMULA, verbatim:

> a(n) == 1 (mod 3) (conjecture - valid up to n=1024; if true for n>=0, why?).

The formal interpretation uses rational formal power series:
$H(X)=\sum_{m\ge1}X^{m(m+1)/2}/m!$ and $A(X)=\exp(H(X))$.
The source's factorial coefficient expansion and PARI extraction program
identify $a(n)=n![X^n]A$. The natural domain includes zero.
The integer witness in the repository result proves integrality together
with the congruence; neither is assumed from the source's integer data.
