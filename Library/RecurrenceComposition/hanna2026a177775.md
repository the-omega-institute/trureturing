## Exact source correspondence

Let $G\in\mathbb Z[[X]]$ have constant coefficient zero and coefficients
$[X]G=[X^2]G=1$. Set $G^{[0]}=X$ and
$G^{[m+1]}=G^{[m]}(G(X))$. The defining condition is
$[X^n]G^{[n]}=[X^n]G^{[n-1]}$ for every $n>2$.
`DiagonalIterateEven.generating_equation` and `generating_unique` give the
integer construction and uniqueness with exactly these normalizations.
The source's original program gives zero below index one and one at indices
one and two; the revised program seeds its coefficient vector with `[0,1,1]`.
The NAME alone does not state these seeds. Formal verification of the PARI
programs is not asserted.

The conjecture concerns the ordinary coefficients $a(n)=[X^n]G$, for every
natural $n\ge1$: $a(n)$ is odd if and only if $n=2^k$ for some natural
$k$. This includes $n=1$ and $k=0$. Offset `1,3` supplies no additional
mathematical seed. `DiagonalIterateEven.a` instead denotes the diagonal
coefficient $[X^n]G^{[n]}$ of A395842.
