## Source statements

NAME, verbatim:

> Triangular matrix T, read by rows, that satisfies: T = D + SHIFT_LEFT(T^2) where SHIFT_LEFT shifts each row 1 place to the left and D is the diagonal matrix {1, 2, 3, ...}.

FORMULA, verbatim:

```text
Conjecture: T(n+m, m) = (n+m+1) * P(n+1, n+1, m) where P(n, k, m) = P(n-1, k, m) + (n+m) * P(n, k-1, m) for 1 < k < n with P(n, 1, m) = 1, P(n, n, m) = (n+m) * P(n, n-1, m). - _Mikhail Kurkov_, Jun 02 2026
```

OFFSET, verbatim: `0,2`.

The first displayed row is `1;`. Thus T is zero-indexed and T(a,a)=a+1.
Lower triangularity and the matrix square give
T(a,b)=sum over b+1 <= j <= a of T(a,j)T(j,b+1) when b<a.
Kurkov's three-argument P is distinct from the two-argument conjugating
matrix in the entry's earlier FORMULA. Its base rule includes P(1,1,m)=1;
its diagonal rule starts at row 2. Outside r>=k>=1, P is unrestricted.

## Mathematical scope

The formal statement quantifies over all natural-valued tables satisfying
these rules and all n,m in the natural numbers. The proof derives a
parameter-sensitive first-return convolution directly from the P recurrence
and then uses strong induction on the row-column difference in T.
It includes n=0 and m=0. A path-set bijection and an extension to arbitrary
weight sequences are not part of the formal result.
