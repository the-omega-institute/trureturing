# OEIS A377100

The unpaginated Name field states: "G.f. A(x) satisfies A(x) = A(x^3)/A(x^2) + A(x)^2."

The unpaginated Comments field states: "Conjecture: a(n) == 1 (mod 3) for n >= 1, which has been verified for the initial 2305 terms."

The example fixes the normalization A(0)=0, coefficient one at X, and offset one.
The rational power-series statement includes existence and asserts that every
positive coefficient is an integer congruent to one modulo three.
The quotient is interpreted in the field of Laurent series.
