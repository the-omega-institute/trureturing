# OEIS A000166, subfactorial or rencontres numbers

The entry identifies A000166 with the derangement numbers. A comment by
Zhi-Wei Sun dated January 9, 2025 states: "a(n) with n > 2 is a perfect power
only for n = 4 with a(4) = 3^2" and records verification through `n <= 1000`.

This finite-range comment is context for the formal exponent-divisibility
consequence. It is not treated as a proof of a universal perfect-power
classification, and the repository theorem does not assert that only `D_4`
is a perfect power.
