# OEIS A374911

Bryle Morga submitted the entry on July 23, 2024. Its definition is
`a(0) = 1`, and `a(n) = a(2^n mod n) + a(3^n mod n)` for positive n.
The comments explicitly ask: “Are 3 and 9 the only solutions to a(n) = 4?”
The entry also lists the indices for values one, two and three, and states
`a(2^n) = 3` for n > 0. These statements supply the problem and its context;
the entry does not supply the complete classification proof.

The Lean module defines the original recursion and proves the level sets
for values one through four over all natural indices. The zero branch is
tested before either recursive call, so the natural-number convention for
remainder modulo zero cannot cause self-reference.
