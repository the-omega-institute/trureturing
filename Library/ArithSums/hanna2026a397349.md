The claim field quotes the source; it does not certify both conjectures.
This lane proves only the modulo-three alternation. The power-of-two parity
clause remains open and is retained as the unproved `parity_conjecture : Prop`.

The integer construction uses a single well-founded recursion for `s`,
with `s 0 = s 1 = 0`, `a n = if n = 1 then 1 else (3n²−1)*s n`,
`b n = if n ≤ 1 then 1 else 3n*s n`, and, for `n ≥ 2`,
`s n = ∑_{k=1}^{n−1} a k * b (n−k)`.
Modulo three, the explicit factor in `b m` for `m ≥ 2` kills all summands
except `k=n−1`. The private escape witness `s_mod_three` gives the boundary
term; `a_mod_three_step` then gives alternation by induction from `a 1 = 1`.
