# Finite Fields

Lidl and Niederreiter's second edition is the classical reference for finite
fields and their character sums. This note records the literature anchor for
the shifted quadratic-character identity deposited in
`D5/S3/Arith/FiniteFieldQuadraticCharacterSum`.

The repository theorem is the explicit odd-characteristic identity
`∑ x, χ(x²-a) = -1` for `a ≠ 0`; its point-counting proof is checked in Lean
here. The note does not claim that the cited book contains this exact Lean
formulation or the repository's chosen bijection.
