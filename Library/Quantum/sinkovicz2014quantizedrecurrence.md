# Quantized recurrence time in iterated open quantum dynamics

Sections II and III, equations (11)--(20), concern the actual monitored
first-return process. For a unit vector v, P = |v><v| and Q = I - P, its
unnormalized survival state after n steps is F^n(P), where
F(X) = Q E(X) Q. Physical time starts at one, so
p_(n+1) = Tr(P E(F^n(P))). Relevant-space unitality is E(Pi_C) = Pi_C,
with C generated by the original Kraus words applied to v. Global
unitality and an ambient-dimension count are not required.

Appendix A, equation (A9), identifies the spaces generated by the
original Kraus operators K_a and the monitored operators Q K_a.
The invariant-hull argument also applies when the initial matrix P
is any Hermitian matrix: its range is its support, so the difference
P K_a x always belongs to the initial support. This extension is an
algebraic observation about reachable spaces; it does not make an
arbitrary Hermitian matrix a physical initial density matrix.

The steady-state argument in Section III uses equations (22)--(23):
on the relevant finite-dimensional bistochastic channel, a fixed
state is also fixed by the dual. This relationship must be derived
from the channel assumptions when applying the recurrence theorem.
The two-state unitary example alone does not establish the arbitrary
finite-Kraus result.
