# Orthogonal record entropy

## Verified locator

https://arxiv.org/html/1803.08936

The retrieved article's appendix explicitly uses mutually orthogonal supports, gives the
spectral mixture calculation in equations (19)–(28), and reduces the Holevo information
to the system entropy using the disjoint supports. The formalization uses natural
logarithms consistently for both Shannon and von Neumann entropy.

Only this forward entropy calculation is cited. The paper's converse involving strong
independence is outside scope; the later criticism of pairwise independence does not
supply any premise here. The module assumes the record states themselves have zero
pairwise products and proves the entropy equality from that hypothesis.

This is a conditional theorem about an explicitly supplied record/environment structure.
It does not derive the structure from the repository's observer assumptions and does
not assert that the physical input has been adopted. It does not formalize measurement
instruments or a multi-observer protocol; the terminal statement is the mutual
information equality for one fragment.
