# Transpose-channel recovery

The source constructs a reversal adapted to a reference state and noise channel, with near-optimal entanglement/classical fidelity bounds. The maximally mixed logical reference specializes to the inverse-square-root support construction used in the current finite recovery theorem. The current text gives its exact-error-correction proof directly and does not import an unproved diamond-norm approximation rate from this fidelity theorem.
