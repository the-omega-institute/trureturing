# Coherent control requires implementation data

The source proves a no-control statement for unknown quantum operations in the circuit setting. The current theory uses the elementary identity Ad(I)=Ad(-I) together with distinguishable controlled versions as a self-contained witness: an ordinary channel does not determine its coherent controlled implementation. This does not forbid control when the physical implementation, reference paths and phases are specified.

Source: https://arxiv.org/abs/1309.7976
