# Coherent information has a quantum carrier

The [primary preprint, version 1](https://arxiv.org/pdf/quant-ph/9604022v1),
Section 4, p. 9, equation (3), defines coherent information as
$S(\rho_{Q'})-S(\rho_{RQ'})$. Section 3, p. 8, specifies von Neumann
entropy with logarithms base two. The reference purifies the supplied
input and the channel acts on the input system.

[The five-state comparison](../../docs/develop/theory/AURIC_FIB_ATOM_STATIC_SEAMS_TRANSITION_CIRCULATION_AND_FIBONACCI_TOGGLE_CYCLES.md),
Definition 21.3, consumes this definition only to distinguish its type
from occupation covariance, a conditional table determinant and an
observable mixed coefficient. No quantum process, non-diagonal phase
or access to a quantum reference follows from a classical five-state law.
