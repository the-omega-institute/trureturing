# Polynomial Fock deformation conventions

Definition 3.2 fixes the pseudo-endomorphism identity with a translated
parameter in the first state of a vertex product. Proposition 3.6 relates
pseudo-derivations and pseudo-endomorphisms to derivations and endomorphisms
of the tensor product vertex algebra. Lemma 3.10 concerns exponentiation
under its completeness hypotheses; Proposition 3.11 constructs
pseudo-derivations from field modes. Proposition 3.15 deforms module fields
by a pseudo-endomorphism. The logarithmic extension is discussed on printed
page 16.

This is classical context for a concrete polynomial Fock substitution.
The unrestricted coefficient identity for the independently defined
substitution is a realization calculation in this repository, not a
literal published formula or a novelty claim. This reference supplies
conventions, not compiled Lean proof terms.
