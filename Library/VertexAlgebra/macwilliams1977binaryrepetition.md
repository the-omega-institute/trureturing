# Binary repetition-code short supports

Chapter 1 gives the standard binary support/complement viewpoint: for an odd repetition
length, complementary representatives have different sizes, so exactly one has size at most
half. The repository theorem uses this combinatorial input together with its independently
proved seven-section kernel relation. This citation does not supply a VOA or fusion
realization.
