# OEIS A181278

The NAME line defines A181278 as follows:

> Number of 2 X n binary matrices M with rows in strictly increasing order and rows of M*Mtranspose (mod 2) in strictly decreasing order.

The target FORMULA line, signed by Colin Barker on March 27, 2018, is:

> a(n) = 4*a(n-1) + 4*a(n-2) - 16*a(n-3) for n>3.

this recurrence. Its links contain only the sequence b-file, and its reference
