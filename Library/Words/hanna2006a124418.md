# OEIS A124418

Paul D. Hanna's entry defines a triangle by counting set partitions with a
specified number of blocks containing both odd and even entries. The formula
below was entered as a conjecture on November 8, 2006. The formal model uses
natural-number quotients for `[n/2]` and `[(n+1)/2]`.

The Lean definition `stirling2 r i` counts partitions of an `r`-element set
into `i` blocks, the Stirling numbers of the second kind named in the formula.
The alternating-sum closed form printed for `S2` is a standard identity for
that object and is not formalized here.

> Conjecture: T(n,k) = k!*A049020([n/2],k)*A049020([(n+1)/2],k) where A049020(n,k)=Sum_{i=0..n} S2(n,i)*C(i,k) and S2(n,k)=(1/k!)*Sum_{j=0..k} (-1)^(k-j)*C(k,j)*j^n (the Stirling numbers of 2nd kind).
