## Formal definitions and proof

HasConstantBlocks(m) quantifies over a finite set of pairs (v,c), each with
v>0 and c>0. Their weights v*c are injective on the whole set, and the
multiset sum of replicate(c,v) is exactly m. Distinct weights prohibit
duplicate identical pairs, so this set encoding faithfully represents
multiset block decompositions. Equal sums from either equal or different
values are excluded. Multiplicity one permits exactly the singleton block.

runSums(l) is `(l.splitBy (· == ·)).map List.sum`.
HasDistinctRunSums(m) requires a list l with `(l : Multiset Nat) = m` and
Nodup(runSums(l)). This is existence of a permutation, with maximal runs;
it does not count permutations or require all permutations to work.

The minimum is supplied by Nat.find on block count. In minimal_balanced,
assume k same-value blocks and o other blocks with k>o+1. Let a be a block
of maximum same-value weight. The k-1 candidates w(a)+w(b) are injective
because old weights are injective. Positivity puts every candidate above
every existing same-value weight. If all candidates occurred among the
old weights, the candidate image would inject into at most o other-value
weights, contradicting cardinality. A candidate outside that image supplies
a merge. The proof checks positivity, injectivity, preservation of the
multiset sum, and a decrease in cardinality. Thus 2k <= total+1.

order_colors uses strong induction on the finite set's cardinality. Its
invariant for forbidden first color p is 2k_c <= total+[c differs from p].
Choose a block whose eligible color has maximum cardinality. After erasing
it, its own count decreases; two disjoint color fibers bound the remaining
counts. The invariant therefore holds with the chosen color forbidden.
Starting with p=0 is valid because block values are positive. The returned
list is nodup, represents the same finite set, and has adjacent colors
different. splitBy_flatten then certifies its expanded blocks as the actual
maximal runs. The reverse direction encodes each actual run by head and
length and reconstructs its constant entries from its equality chain.

The public pointwise theorem takes an arbitrary Nat.Partition(n); positivity
comes from parts_pos. The count theorem identifies filters of the same
finite universe, so counts partitions, not block decompositions or orderings.
