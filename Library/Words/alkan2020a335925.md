# OEIS A335925

The entry defines the sequence from index one by
`a(n) = a(floor((n-1)/a(n-1))) + 1`, with `a(1) = 1`. The formal definition
uses the value one at index zero only to totalize this recurrence; no source
claim about index zero is asserted.

The entry records Alkan's conjecture that the least indices carrying successive
positive values form A000522. The formal threshold sequence starts with one and
satisfies `T(r+1) = (r+1)*T(r) + 1`, so its index `r` corresponds to A000522(r).
