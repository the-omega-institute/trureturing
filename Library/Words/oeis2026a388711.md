# OEIS A388711

The task is a first-tier recent OEIS comment conjecture, with source baseline
`d527e3081957dbd440ca634d821e98b868abf534`. The supplied source reads:

> Conjecture: Also the number of superdiagonal reversed partitions of n into k parts,
> where a sequence (y_1, ..., y_k) is superdiagonal iff y_i >= i for all i = 1..k.

> We say that a set or sequence of nonempty sets is choosable iff it is possible to choose a
> different element from each set. For example, ({1,2},{1},{1,3}) is choosable because we have
> the choice (2,1,3), but ({1},{1,2},{2}) is not.

The initial interval attached to a part x is {1,...,x}. Increasing order is
the reversed-partition convention. Indices in Lean start at zero, so the
superdiagonal bound must be i+1. Positive representatives are required even
when the list contains zero.
