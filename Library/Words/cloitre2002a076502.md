# OEIS A076502

The NAME line defines the nested recurrence:

> a(1)=1, a(n)=n-a(n-a(n-a(n-1)))

The 2002 comment states a conjunction of bounded error and three allowed
floor offsets. The theorem cited by this note refutes the floor-offset
conjunct at n = 1167. It makes no assertion about boundedness or asymptotic
growth.
