# The A261041 partition comparison

The entry counts partitions of arbitrary subsets of the first n positive integers.
Each block avoids pairs of consecutive integers. The comment compares that count
with full partitions of the first n+1 positive integers under a triple condition.

## Verified locator

- https://oeis.org/A261041/internal, revision #44, 10 September 2024. The NAME line
  defines the partial partition count. In COMMENTS, the 25 November 2019 comment
  says “Conjecture: Also the number of set partitions of {1, ..., n + 1} where, if
  x and x + 2 belong to the same block, then so does x + 1.” OFFSET is 0,2.
  The listed target partition at n=0 is the single block {1}.
