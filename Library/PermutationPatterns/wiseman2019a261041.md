# The A261041 partition comparison

The entry counts partitions of arbitrary subsets of the first n positive integers.
Each block avoids pairs of consecutive integers. The comment compares that count
with full partitions of the first n+1 positive integers under a triple condition.

## Verified locator

- https://oeis.org/A261041/internal, revision #44, 10 September 2024. The NAME line
  defines the partial partition count. In COMMENTS, the 25 November 2019 comment
  says “Conjecture: Also the number of set partitions of {1, ..., n + 1} where, if
  x and x + 2 belong to the same block, then so does x + 1.” OFFSET is 0,2.
  The listed target partition at n=0 is the single block {1}.

## Related readings

Max Alekseyev derives the generating function for the partial partition count
in NAME by inclusion–exclusion. The problem dossier derives the same function
directly for the full partitions. [Alekseyev's enumeration](https://mathoverflow.net/a/478471) · [Problem dossier](../../Problems/wiseman-a261041.md)

Mansour–Shattuck–Yan rank the distinct labels in each consecutive subword by
numeric order. Section 1, p. 2, specifies “replacing all letters corresponding
to the smallest element occurring in α with 1, replacing all letters
corresponding to the second smallest element of α with 2”. Thus an endpoint
label smaller than the different middle label gives `121`, and a larger one
gives `212`. The canonical word `12212` avoids `121` and violates the OEIS
condition at its final triple `212`. The full class jointly avoids both
patterns. Theorem 3.1 at $y=0$ and the specialization following Theorem 2.9
enumerate the two single-pattern avoidance classes separately.
[Counting Subwords in a Partition of a Set](https://doi.org/10.37236/291)
