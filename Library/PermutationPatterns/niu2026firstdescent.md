# The first descent in a rectangular tableau

Section 2 identifies the first descent with the entry in row two and column one minus one. Theorem 4 gives the limiting law and odd-entry constant for three rows. Question 15 asks for the law and constant with a fixed number of rows. The parity event uses the one-based entry, so it is equivalent to an even first descent.
