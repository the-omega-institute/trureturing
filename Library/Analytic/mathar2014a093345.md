# OEIS A093345

The entry defines the factorial nested reciprocal sum at offset zero, with
initial values `1, 2, 6, 23, 108, 605, 3956`. Mathar's formula of May 30,
2014 conjectures a third-order recurrence. The formal definition uses
rational division and the exact two summation ranges in the NAME.

The cited Mansour-West paper (2002) establishes the signed-permutation
enumeration by the nested sum; this is distinct from the recurrence claim.
For the prefix `b(m) = m! * Sum(j=0..m, 1/j!)`, the updates are
`b(m+1) = (m+1)*b(m) + 1` and `a(m+1) = (m+1)*a(m) + b(m)`.
Eliminating the prefix proves the displayed recurrence for every `n >= 3`.
Integrality and the exponential generating function are not asserted as
formal theorems here.
