# OEIS A398690

Chapoton's entry defines the simplified Verlinde numbers by
`A(r,q) = (2q+1)^(-1) sum_{j=0}^{2q} (-1)^(rj)
sin((2j+1)2pi/(8q+4))^(2-r)` for `r >= 3`. For each `n >= 0`, it calls the
numerator of `sum_{q>=0} A(n+3,q) z^q`, with denominator `(1-z)^(n+1)`,
the row polynomial. Its comment conjectures that these polynomials are
palindromic. The separate A107735 array changes `q` to `q/2` on even rows;
that normalization is not used here.
