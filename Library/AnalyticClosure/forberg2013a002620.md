## Mathematical statement

The entry defines the quarter-squares by
`a(m) = floor(m/2)*ceiling(m/2) = floor(m^2/4)`, with offset zero.
For every natural number n satisfying 1 <= n, the asserted identity is
`floor(n/(exp(4/n)-1)) = floor((n-1)^2/4)`.
All arithmetic inside the floors is real arithmetic, with n coerced before
division and subtraction; exp is the real exponential and both floors are
integer-valued. The endpoint n=1, both parities and unbounded n are included.

The analytic argument places the quotient, for real r >= 2, between
`(r-1)^2/4` and `r^2/4-r/2+1`, with a strict upper inequality. A logarithmic
series bound supplies the lower inequality and the quadratic exponential
bound supplies the upper inequality. Parity identifies the common integer
floor; the endpoint n=1 is handled separately.
