# Mathar's A386844 twin recurrence problem

Manyama defines the sequence by the inclusive natural binomial sum. The
official export, revision 16, contains both of Mathar's conjectures:

> Conjecture D-finite with recurrence 3*n*(2*n-1)*a(n) +(-353*n^2+1009*n-672)*a(n-1) +(3938*n^2-15029*n+13872)*a(n-2) -399*(3*n-4)*(3*n-5)*a(n-3)=0.

> Conjecture D-finite with recurrence n*(2*n-1)*(5*n-8)*a(n) +(-145*n^3+362*n^2-264*n+63)*a(n-1) +3*(3*n-1)*(5*n-3)*(3*n-2)*a(n-2)=0.

OEIS specifies offset 0,2 but neither recurrence onset. The full natural-lag
domains n >= 3 and n >= 2, including both endpoints, are the disclosed
interpretations in [issue #27973](https://github.com/the-omega-institute/trureturing/issues/27973).
D-finiteness means a finite nonzero homogeneous polynomial differential
operator annihilating the same complete ordinary rational formal series.
The export's editorial approval is not a proof.
