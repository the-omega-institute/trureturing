## Source statements

Proposition 0, page 1: "Let A(x) be a real analytic function on (a connected open domain U of) R^d. If A is not identically zero, then its zero set F(A) := {x ∈ U : A(x) = 0} has a zero measure, i.e., mes_d F(A) = 0."

The same page records that "Remark 5.23 in [Kuc15] and Lemma 1.2 in [Dan15] list possible approaches to the proof — from using Fubini's theorem to Hironaka's resolution of singularities."
