# Divided Differences

Newton interpolation expands the exact interpolant in successive nodal products. For a real function with n continuous derivatives on an interval, its divided difference at n+1 distinct nodes equals f^(n)(xi)/n! for a point xi in their convex hull.

The derivative-to-monomial coefficient budget in UniformCoefficientBudget combines this classical relation with bounds on nodal products. Its endpoint application couples the same polynomial to both atomic supports. The reference supplies the classical interpolation method; it is not a source for the uniform finite-atomic Laplace minimax upper bound.
