# Official complexity definitions and the common-witness boundary

The official Clay Millennium problem description was read for its definitions of P, NP, polynomial reduction and NP-completeness. The bibliographic key uses the Millennium problem announcement year; the PDF hosting path is not the publication date of Cook's original 1971 theorem. No resolution of P versus NP is asserted.

In the unified predictive theory, Section 16 distinguishes existence of a common optimum from computational cost of deciding or constructing one. An inconsistent parity cycle stays inconsistent even under the hypothesis P=NP. Conversely, some frustrated instances have efficient cycle tests or explicit semidefinite certificates.

The explicit binary-phase threshold problem in Section 16 maps to weighted MAX-CUT. A proposed binary phase vector is a short threshold witness. This does not supply a short certificate that every proposed optimum is globally optimal, or show that arbitrary continuous/quantum variants belong to NP. Exact real arithmetic, numerical tolerance and succinct quantum input sizes require separate models.

The existing complete-mediator Lean theorem uses finite maximization on a whole response-table carrier; it certifies an attained maximum without providing a polynomial algorithm. No new kernel-level complexity statement is attached to this reference.
