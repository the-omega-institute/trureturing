# A relaxation changes the set of common implementations

Journal of the ACM 42(6), 1115–1145 (1995). The author-hosted PDF was read at the MAX-CUT formulation, the SDP resource/accuracy discussion, and the random-hyperplane algorithm. PDF page 5 was visually checked. The well-known guarantee exceeding 0.87856 is cited as existing work, without claiming it is the latest optimum for every graph or strengthened relaxation.

The repository's actual complete-mediator response law already attains half a normalized weighted cut using one common Boolean table and its complement. Unified theory Section 16 maps that same assignment to a binary diagonal phase controller, with calibrated thermal reference and exact autonomous update. The resulting edge phase-flip score is twice the causal benefit.

Allowing all positive-semidefinite correlation matrices instead gives the larger vector/quantum-channel control class and the standard SDP objective. A triangle attains 3/4 in this larger class and at most 2/3 with binary controls. The former is not the solution of the original binary problem, and continuous scalar phases already realize its triangle score. This is not a quantum-computational speedup claim.

Hyperplane rounding maps a vector solution back to an allowed binary controller and, through the same complement law, to the existing causal mechanism. The approximation theorem, MAX-CUT hardness and rounding method are prior art. The present note adds scope and a concrete cross-module interpretation, not a new Lean theorem or a P/NP resolution.
