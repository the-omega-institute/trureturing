# Cheng--Chen Lorentz invariant range

The source is arXiv:2605.19530v2, Sections 2.4 and 3.3. Definition 12 says: “We say that ϵ = [[0, 1], [−1, 0]] is the two-dimensional Levi-Civita symbol. … We refer to ϵ_n = ϵ^{⊗n} as the tensor product of n ϵ's.” Eq. (54) defines “I_ρ := Tr(ρ^T ϵ_n ρ ϵ_n)”. Conjecture 24 states verbatim: “Suppose ρ is an arbitrary n-qubit state with odd n, then the range of Lorentz invariant Iρ is [−1/2, 0].”
