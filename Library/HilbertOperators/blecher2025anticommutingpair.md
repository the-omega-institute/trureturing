# Blecher, Commutativity of operator algebras, Example 5.5

Example 5.5 defines the anticommuting pairs at issue as elements $x,y$ with
$xy=-yx\ne0$ and asks, “It would be interesting to find an example with no
such anticommuting pair.” Thus any pair with $xy=-yx$ in the requested algebra
must have $xy=0$. The journal citation and the separate four-by-four uniqueness
conjecture are recorded in the [Example 5.2 reading note](blecher2025commutativity.md).
