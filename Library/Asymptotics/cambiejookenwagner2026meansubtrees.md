- Page 1, Introduction, defines a subtree as any tree subgraph of the host. Distinct tree edge sets on the same vertices are counted separately. [Version 2, p. 1](https://arxiv.org/pdf/2508.20593v2#page=1)
- Page 3, just before Question 1.9, defines a connected vertex set by connectedness of its induced graph. Question 1.9 asks “Is it true that μ(G) ≥ av(G) holds for every connected graph G?” [Version 2, p. 3](https://arxiv.org/pdf/2508.20593v2#page=3)
- Page 3, Section 2, defines the subtree mean using the counts and total orders over orders 1 through the host order. Singletons contribute to both means. [Version 2, p. 3](https://arxiv.org/pdf/2508.20593v2#page=3)
- Section 4.1 uses the complete-graph subtree count asymptotic and estimates for subtrees containing a fixed edge to compare mean subtree orders after adding edges in a family of finite graphs. Remark 4.2 gives the asymptotic size of the increase for an edge in Case 4. [Version 2, pp. 10–13](https://arxiv.org/pdf/2508.20593v2#page=10)
- Section 4.2 gives subtree counts and total order sums for a complete multipartite family and compares the mean orders before and after deleting one edge in specific examples. [Version 2, pp. 13–14](https://arxiv.org/pdf/2508.20593v2#page=13)
