# Yu, Quantum coherence via skew information and its polygamy

C.-s. Yu, Phys. Rev. A 95, 042337 (2017); arXiv:1704.04871v1. Quotations are from the v1 TeX source.

In a fixed reference basis $\{|k\rangle\}$ the coherence is $C(\rho)=1-\sum_k\langle k|\sqrt\rho|k\rangle^2$ (Lemma 1). For a bipartite pure state with reduced density matrices $\rho_A,\rho_B$, Theorem 2 gives $1-C(|\Psi\rangle_{AB})\le[1-C(\rho_A)][1-C(\rho_B)]$. The paper shows that the same relation fails for some two-qubit mixed states, tests random states on $2\otimes3$, $3\otimes3$, $3\otimes4$ and $4\otimes4$, and states:

> However, we would like to conjecture that it could hold for the bipartite mixed states with the dimension $N \geq 6$.
