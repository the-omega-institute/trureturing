# The A263160 first-zero path conjecture

A263160 is the diagonal of A263159. Coordinate labels and step order are
retained. Each step decrements a nonempty subset by one and the path stops
as soon as any coordinate is zero. The empty path is the sole path when
height or dimension is zero.

## Scope

The full all-index diagonal limit remains unproved here. Finite counting
lemmas do not assert a limit, and endpoint-alignment asymptotics in fixed
dimension do not identify this first-zero count. Prior-art completeness and
global priority are ASSUMED-UNVERIFIED.
