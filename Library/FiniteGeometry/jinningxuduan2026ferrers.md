# New constructions of optimal Ferrers diagram rank-metric codes for quasi-block monotone Ferrers diagrams

## Verified locator

- Version 1, Section 4, Problem 1, PDF page 18. https://arxiv.org/abs/2611.19070v1
- Definition 2.1 (p. 3) and the matrix-shape definition (p. 4) give the support convention. Notation 2.10 (p. 6) gives the block notation. Example 3.5 (pp. 11–12) specifies the profile and proves the binary bound is attained. https://arxiv.org/pdf/2611.19070v1

## Example

> For example, does there exist an optimal Ferrers diagram rank-metric code for \(\mathcal{D}=\big[[2,3,4,4]\big]_{3}\) and \(d=9\) when \(q>3\) is an odd prime power?

[Section 4, Problem 1, p. 18, arXiv v1](https://arxiv.org/pdf/2611.19070v1#page=18)

Notation 2.10 and Example 3.5 give the heights \((6,6,6,9,9,9,12,12,12,12,12,12)\). Example 3.5 shows the top-aligned columns. A matrix of this shape vanishes outside the diagram’s dots by the matrix-shape definition on page 4. The dimension bound is 27.

The construction of a code attaining that bound in the stated range is repository-derived. The broader family question in Problem 1 remains open in this development. The comparison with earlier constructions covers their directly stated criteria for this profile. Priority through unexamined results or indirect reductions remains unresolved.
