# OEIS A379464

The OEIS entry defines `a(n)` as the number of paths from `(0,0)` to `(n,0)` with steps `(1,1)`, `(1,0)`, and `(1,-3)`, staying on or above `y=-2`. Its FORMULA line attributes the displayed eight-term recurrence to R. J. Mathar and labels it a conjecture. The entry has no arXiv identifier for this assertion.

The formalization uses the literal step set `{1,0,-3}`, the endpoint sum, and every prefix bound. Zero steps are inserted into zero-free paths, and the resulting generating series satisfies the candidate-specific differential certificate whose coefficients are the eight displayed polynomials.
