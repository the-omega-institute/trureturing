The source's name is:

> Number of distinct ways to place bishops (up to 2n-2) on an n X n chessboard so that no bishop is attacking another and that it is not possible to add another bishop.

The conjectured formula is:

> Conjectured to be a(n) = O(n^(n-1)).

The native objects are all subsets of the fixed-coordinate n by n board, nonattacking in both diagonal directions and maximal under inclusion. There is no quotient by rotation or reflection, no prescribed cardinality and no maximum-size condition. The entry explicitly identifies maximal independent vertex sets of the bishop graph.
