# Exact semimonotone order and the inverse question

Bharat Pratap Chauhan and Dipti Dubey, *On semimonotone matrices of exact order two*,
arXiv:2603.00639v1 (2026).

Section 2 defines a semimonotone matrix by requiring every nonzero entrywise
nonnegative vector to have a strictly positive coordinate whose image is
nonnegative. The same section defines a Z-matrix by nonpositive off-diagonal
entries. Definition 3.1 defines exact semimonotone order using principal
submatrices of the stated sizes. Remark 4.1, second unlettered bullet, asks
whether an $E_{0_k}$ matrix with the introductory range $n \geq 3$ and
$1 \leq k < n$ must have negative determinant and an inverse that is a
Z-matrix.
