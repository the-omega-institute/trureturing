# A397436 Conjecture 3

## Primary statement

[OEIS A397436 revision 44](https://oeis.org/A397436/internal) states:

> 3) More generally, let m_1, ..., m_r be integers and M a positive integer. Define u(n) = Sum_{k = 0..M*n} binomial(m_1*n, k)*...* binomial(m_r*n, k). The supercongruence u(p^r) == u(p^(r-1)) (mod p^(3*r)) holds for all primes p >= 5 and all positive integers r (the present sequence is the case M = 1, m_1 = -1 and m_2 = -3).

## Domain and convention

The literal same-r reading uses r for both the number of factors and the
lift exponent. The sum includes k=0 and k=M*n. Each m_i is an arbitrary
integer; the full entry supplies no negative-only condition or two-factor
minimum. Restrictions belonging to Conjectures 1 and 2 are not imported.
The parenthetical two-factor example leaves author intent about separate
factor and lift indices unresolved. The witness sets both indices to one,
so also refutes an unrestricted reading with independent positive indices.
No claim about an unprinted restriction is made.

The direct cross-reference A333592 explicitly uses
C(-n,k)=(-1)^k*C(n+k-1,k). Pinned Mathlib's Ring.choose on Int has this
negative-upper convention, satisfies the descending-factorial identity,
and equals Nat.choose for natural upper arguments by Ring.choose_natCast.
The witness uses only positive upper arguments while the quantified
statement retains all signed parameters.
