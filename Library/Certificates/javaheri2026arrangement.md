# A new arrangement inequality

Mohammad Javaheri's revised preprint defines the cyclic arrangement inequality
for nonnegative real parameters and cyclic nonnegative tuples, and defines the
largest valid dimension together with the threshold dimension from the sine
condition. Conjecture 1.3 asserts equality of these two dimensions for every
allowed parameter pair.

## Verified locator

- DOI: 10.48550/arXiv.2610.33653
- URL: https://arxiv.org/abs/2610.33653v1
- Locator: arXiv:2610.33653v1, Section 1, Conjecture 1.3 and Theorem 1.2;
  Proposition 3.1, Lemma 4.3, and Section 8, PDF page 10.

The revised arXiv record lists v1 as the inspected source version. The formal
result refutes the literal universal conjecture at the parameter pair (6,1).
Section 8 separately predicts the exact four-variable validity region from
the weak triangle inequalities for sqrt(a), sqrt(b), 1. The corresponding
four-variable refutation uses (a,b)=(4,1) and the cyclic tuple (10,9,7,7),
whose left-minus-right difference is 327. Proposition 3.1's smaller linear
triangle region is a separate sufficient condition.
