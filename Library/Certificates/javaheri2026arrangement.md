# A new arrangement inequality

Mohammad Javaheri's revised preprint defines the cyclic arrangement inequality
for nonnegative real parameters and cyclic nonnegative tuples, and defines the
largest valid dimension together with the threshold dimension from the sine
condition. Conjecture 1.3 asserts equality of these two dimensions for every
allowed parameter pair.
