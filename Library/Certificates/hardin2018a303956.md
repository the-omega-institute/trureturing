> Number of n X 3 0..1 arrays with every element unequal to 0, 1, 2 or 5 king-move adjacent elements, with upper left element zero.

> Empirical: a(n) = a(n-1) +2*a(n-2) +3*a(n-3) +2*a(n-4) -2*a(n-5) -6*a(n-6) -4*a(n-7) for n>8.

The offset is 1,1. Neighbours are distinct other cells in the finite
rectangle at row and column distance at most one. Bits are compared for
inequality. Every cell must have an unequal-neighbour count in
$\{0,1,2,5\}$; the upper-left bit is zero. There is no wrapping, padding,
self-neighbour, symmetry quotient or complement division. This coordinate
formulation adapts the source's ordinary finite-rectangle king adjacency.
The finite table is neither a definition nor a proof of the recurrence.
A303961 column 3 states the same assertion.
