# Factoring rational polynomials

The source is A. K. Lenstra, H. W. Lenstra Jr. and L. Lovász, “Factoring
polynomials with rational coefficients”, *Mathematische Annalen* 261 (1982),
515–534, DOI [10.1007/BF01457454](https://doi.org/10.1007/BF01457454),
[author-hosted scan](https://pub.math.leidenuniv.nl/~lenstrahw/PUBLICATIONS/1982d/art.pdf).

The result is used only as a boundary example: a compact polynomial expansion
does not by itself identify an NP-hard inverse problem. Factoring is a separate
task with its own input encoding and output contract; it does not recover an
arbitrary generation history, and it supplies no FIB readout or observer-growth
interface.
