The near-unanimity definition is on page 23. Example 72, pages 34–35,
provides the common-carrier subpower generation mechanism used here.

## Statement scope

Example 72, pages 34–35, states that if a structure has a k-ary
near-unanimity polymorphism, a subpower is generated by any subset with
the same projections onto each set of k-1 coordinates. The survey's
definition of a near-unanimity operation appears on page 23.

The finite-coordinate interpolation proof uses the same closure mechanism:
choose k distinct coordinates, interpolate after deleting each one, and
apply the near-unanimity operation to the resulting k tuples. At each
coordinate all but at most one tuple have the prescribed value.

The Lean statement permits independent universes, an arbitrary coordinate
type and dependent coordinate carriers. Its conclusion concerns a specified
finite coordinate set. It does not assert a simultaneous extension over
infinitely many coordinates. The survey's finite common-carrier statement
is the source of the mechanism, rather than a verbatim statement of that
more general domain.

The classical interpolation background is Kirby A. Baker and Alden F.
Pixley, *Polynomial interpolation and the Chinese Remainder Theorem for
algebraic systems* (1975), DOI 10.1007/BF01187059. The original theorem's
full text is not used as an exact statement source here.
