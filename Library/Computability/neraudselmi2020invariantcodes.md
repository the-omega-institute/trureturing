# Finite word defect

Jean Néraud and Carla Selmi, *Embedding a θ-invariant code into a complete one*,
*Theoretical Computer Science* (2020), DOI
[10.1016/j.tcs.2018.08.022](https://doi.org/10.1016/j.tcs.2018.08.022).
The primary preprint is [arXiv:1801.05164v3](https://arxiv.org/pdf/1801.05164v3).

The introduction's Theorem 1 and Section 3's Theorem 3.2 (page 6 of the
preprint) give a defect bound for invariant sets. Setting the automorphism θ
to the identity gives the ordinary finite-set defect theorem: a finite set X
which is not a code is contained in a free submonoid generated by a code Y
with cardinality at most |X| − 1. The Lean target uses only the existence of
fewer generators and reconstruction, not freeness, minimality or uniqueness.

The repository statement is labelled: f maps Fin n to words over an arbitrary
alphabet. Repeated labels can already give ambiguity even when the image set
is a code; an empty word can be removed. If all words are distinct and
nonempty, noninjectivity of labelled concatenation is exactly failure of the
image set to be a code. These labelled and degenerate cases are interface
extensions of the cited finite-set formulation. The proof candidate uses
length descent and elementary prefix substitutions, independently of the
paper's invariant-submonoid proof. New generators need not belong to the
monoid generated by the original labelled family.

This note supplies a primary citation and scope comparison. It imports no
article text, source code or empirical data and makes no novelty claim.
