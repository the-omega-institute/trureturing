# OEIS A322844 and the serpentine matrix A317614

## Source statements

> a(n) = (1/12)*n^2*(3*(1 + n^2) - 2*(2 + n^2)*(n mod 2)).

> For n > 1, a(n) is the absolute value of the trace of the 2nd exterior power of an n X n square matrix M(n) defined as M[i,j,n] = j + n*(i-1) if i is odd and M[i,j,n] = n*i - j + 1 if i is even (see A317614). Equivalently, a(n) is the absolute value of the coefficient of the term [x^(n-2)] in the characteristic polynomial of the matrix M(n), or the absolute value of the sum of all principal minors of M(n) of size 2.

> For k > 2, the trace of the k-th exterior power of the matrix M(n) is equal to zero.

The entries have integer arithmetic and one-based source indices. The Lean matrix uses `Fin n` and adds one to each index. The exterior trace is encoded by the signed characteristic coefficient for `k ≤ n`, and by zero for `k > n`. This is the characteristic-coefficient formulation stated by the source; the encoding does not construct an exterior-power linear map. The sequence value is rational, with the integer absolute trace cast into the rationals.

## Result and boundary

Over the rationals the matrix factors through a two-dimensional space. The rectangular characteristic-polynomial identity gives the higher-coefficient vanishing. Centered linear, quadratic and alternating moments evaluate the second coefficient as the negative of the displayed sequence value, which is nonnegative. A separate exact-rank theorem and a separately expanded full characteristic polynomial are not supplied.
