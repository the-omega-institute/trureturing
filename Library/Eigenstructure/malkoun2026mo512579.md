Only the explicit two-matrix question is considered. The later unspecified
promotion question is outside the assertion. Eigenvalues count algebraic
multiplicity; the matrices are complex Hermitian positive semidefinite, the
order n is any positive integer, and k ranges from one to n. No positivity
of XY+YX is assumed. The question text is licensed under
[CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/).

The proof uses the existing public cauchyBinet in CompoundMatrices and pinned
Mathlib spectral and principal-minor identities. CompoundMatrices already
contains the source and Apache-2.0 attribution for its supplier; no supplier
code is copied here. No claim of worldwide literature priority is made.
