# Algebraic Structures on Graphs Joined by Edges

The class of labelled operands in §1 has at least twice the join parameter
many vertices. Definition 1.1 shifts a right label i by the left order m.
For j = 1 the single joining pair is (m, m + 1). All original edges are
retained with the corresponding translations. Applying the rule in sequence
attaches the current last block to the next block. [arXiv:2409.02355v2, Definition 1.1, p. 2](https://arxiv.org/pdf/2409.02355v2#page=2)

The paper studies algebraic properties of the operation and determinant
representations. Its cited definition supplies the label convention for the
tree classification question. [Pinzon et al., arXiv:2611.34794v1, reference [8]](https://arxiv.org/pdf/2611.34794v1#page=9)
