# D'Alembert functions on compact groups

Aequationes Math. 76 (2008), no. 1-2, 33-53. For a topological group $G$, a
d'Alembert function is a continuous $f\colon G\to\mathbb C$ with
$f(xy)+f(xy^{-1})=2f(x)f(y)$. On a compact group every such solution comes from
a continuous homomorphism $G\to\mathrm{SU}_2(\mathbb C)$. A d'Alembert function is
called basic if $f(xy)=f(y)$ for all $y$ forces $x=e$; every d'Alembert function
factors through a basic one, the compact groups that support a basic d'Alembert
function are exactly those topologically isomorphic to compact subgroups of
$\mathrm{SU}_2(\mathbb C)$, and every subgroup of $\mathrm{SU}_2(\mathbb C)$, compact or
not, supports one.

The general topological-group form $f=\tfrac12\operatorname{tr}\circ h$ with
$h\colon G\to\mathrm{SL}_2(\mathbb C)$ is in
[davison2009dalembertmonoids](davison2009dalembertmonoids.md), which also records
how these results bound the novelty of the round-trip comparison law.
