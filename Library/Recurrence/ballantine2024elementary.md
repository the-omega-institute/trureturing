# Elementary symmetric partitions

Ballantine, Beck, Merca and Sagan define the elementary symmetric image of a
partition and count its regular members. Section 5, Conjecture 16 on printed
page 19 gives four residue-class columns for the difference between the
degree-two and degree-three counts.

The literal table is false at `d = 5` and `n = 4`. The degree-two image set is
`{(3), (4), (2,2,1), (1,1,1,1,1,1)}`, whose four members are all 5-regular.
The degree-three image set is `{(2), (1,1,1,1)}`, whose two members are also
5-regular. Their count difference is two, while the residue-four cell of the
printed table gives one.

Version 3, dated October 25, 2024, retains Conjecture 16 and has no journal
reference on arXiv. Searches recorded with the source found no later paper
settling Conjecture 16. Google Scholar and Semantic Scholar coverage was not
verified.
