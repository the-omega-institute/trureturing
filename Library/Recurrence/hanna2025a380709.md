# OEIS A380709

Paul D. Hanna's entry of February 9, 2025 defines the generating function
by the displayed equation and states the binomial parity conjecture.
Here `abs` takes the absolute value of each coefficient of the reciprocal
series before cubing. The Lean module constructs the unique integer solution
with constant coefficient one and proves the conjecture for every positive
index. At index zero, the convention `binomial(-1, 0) = 1` is represented
separately by `a_zero : a 0 = 1`.
