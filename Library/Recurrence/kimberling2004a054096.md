# OEIS A054096

The NAME of A054096 states:

> T(n,2), array T as in A054090.

Ralf Stephan's target COMMENT states:

> Conjecture: sequence is A006183 shifted right. - _Ralf Stephan_, Jan 15 2004

The NAME of A054090 states:

> Triangular array generated by its row sums: T(n,0) = 1 for n >= 0, T(n,1) = r(n-1), T(n,k) = T(n,k-1) - (-1)^k * r(n-k) for k = 2, 3, ..., n, n >= 2, r(h) = sum of the numbers in row h of T.

Its FORMULA line states:

> T(n, k) = T(n, k-1) - (-1)^k * Sum_{j=0..n-k} T(n-k, j), with T(n, 0) = 1, and T(n, 1) = Sum_{j=0..n-1} T(n-1, j).

The NAME of A006183 states:

> a(n) = (n+1)*a(n-1) + (2-n)*a(n-2).

The AUTHOR line of A054096 is:

> _Clark Kimberling_

Clark Kimberling authored the sequence, while Ralf Stephan authored the
target conjectural comment. The AUTHOR line is undated; the bibliographic
year 2004 records the date of Stephan's conjecture.
