# OEIS A331474 and its source sequence

Paul Barry submitted A331474 on January 17, 2020 as the Hankel transform of
A331473. The entry has offset 0 and prints the rational generating function

`(1 + 3*x + 16*x^2 - 8*x^3 + 36*x^4 - 12*x^5 + x^6 - x^7) / (1 + 7*x^2 + x^4)^2`

with the explicit qualifier `(conjecture)`.

A331473 defines its offset-zero sequence by
`s(n) = Sum_{k=0..n} (-1)^(n-k)*binomial(2*k+2,k)`. Therefore A331474 means
the determinants `H(n) = det(s(i+j))` for `0 <= i,j <= n`; it does not mean a
sequence separately defined by the displayed rational function.
