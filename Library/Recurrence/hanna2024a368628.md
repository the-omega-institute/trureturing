# A368628: source equation and parity conjecture

## Verified locator

url: https://oeis.org/A368628

doi: null

The official internal page https://oeis.org/A368628/internal was read on 2026-09-10 (HTTP 200). The entry credits Paul D. Hanna, January 10, 2024. Its NAME and formula (1) define

A(x) = 1 + x(A(x)^2 - A(-x)^2)/2 + x(A(x)^4 + A(-x)^4)/2.

The COMMENT says: “Conjecture: a(n) is odd when n = (4^k - 1)/3 for k >= 0, and even elsewhere.” The entry's first ten terms are 1, 1, 2, 14, 32, 345, 810, 10492, 24880, 356252.

## Coefficient interpretation

The constant coefficient is 1. For n>0 even, the coefficient is degree n-1 of A squared; for n odd, it is degree n-1 of A to the fourth power. Both are finite natural-number convolutions using only earlier coefficients. This determines the sequence independently of the parity conjecture. The Lean definition uses well-founded recursion and a zero extension of the earlier coefficients; the coefficient recurrence proves that the extension does not affect the result.
