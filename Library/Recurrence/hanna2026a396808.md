# A396808 modulo three

The entry defines the normalized integer generating series by
`(n+1)[x^n]A^(n+1)=n[x^n]A^(n+2)` for n>1, with a(0)=a(1)=1.
Its comments state the two mod-three support claims as conjectures. The
proof in TernaryTraceSupport is derived in this repository and reuses the
integer sequence and its source equation from ArtinSchreierTracePowersOfTwo.
