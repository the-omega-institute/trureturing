# OEIS A068551

A068551 is "a(n) = 4^n - binomial(2*n,n)." (offset 0, data `0, 2, 10, 44,
186, 772, …`). A comment by Geoffrey Critzer (2012) reads

> Total number of returns to the x axis in all lattice paths using steps
> (1,1) and (1,-1) from the origin to (2n,0).

and the formula field contains

> Conjecture: n*a(n) + 2*(3-4*n)*a(n-1) + 8*(2*n-3)*a(n-2) = 0. - _R. J.
> Mathar_, Apr 01 2012
