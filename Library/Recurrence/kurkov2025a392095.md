# Kurkov's antidiagonal array

Mikhail Kurkov's entry is dated December 30, 2025. Its NAME and FORMULA
in the fixed official export read:

> Array read by downward antidiagonals: A(n,k) = A(n-1,k+1) + Sum_{j=0..k} A(n-1,j)*A(k-j,0) with A(0,k) = 1.

> Conjecture: A(n,0) = A088713(n+1).

The offset is `0,3`. The recurrence applies for positive n and every
natural k; replacing n by n+1 gives the Lean predicate `IsArray`.
The sum includes j=0 and j=k. The conjecture includes n=0, where the
column value is one and the source coefficient is that at index one.
The independent source equation is quoted in `hanna2003a088713.md`.
Neither the example array nor the PARI program is an additional premise.
