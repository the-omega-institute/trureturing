# On the Einstein Podolsky Rosen paradox

John S. Bell formulates the locality obstruction for the entangled EPR spin
setting. The repository uses this only as the literature setting for an
elementary algebraic witness: the coefficient matrix of the Bell vector
`|00> + |11>` is not a simple tensor.

The Lean theorem proves no Bell inequality, locality premise, measurement
statistics, hidden-variable exclusion, or optimal quantum violation. It does
not attribute the observer source's hidden-address interpretation to Bell.
