# OEIS A072872

The NAME of A072872 defines the sequence as:

> a(n) is the smallest positive number k such that n divides 2^k - k

The COMMENTS state:

> If n is a power of 2, a(n) = n. Conjecture : if n > 47, a(n) < prime(n). - _Benoit Cloitre_, Jul 28 2002

The formalization records the sequence definition, the literal prime-index
upper-bound conjecture, and a certified counterexample. It makes no general
existence claim for the defining set.
