# Detection and exactly preserving generators

## Primary source and locator

Physical Review A 55 (1997), 900-911, published 1 February 1997. Authors,
title, DOI and publication date were checked on the primary APS record.
The accessible record and abstract were read; no subscription full-text or

## Use and scope

The RT support argument assumes the standard detection statement
P O P = lambda(O) P for every operator supported on fewer than d_code
physical positions. It applies that statement to a specified GKLS generator:
exact invariance makes every nonnegative instantaneous leakage term vanish,
so each small-support jump restricts to a scalar and the logical generator
vanishes. This is an application of established error-detection theory,
not a new general error-correction criterion.

The result concerns a fixed code and exact preservation at every time.
It does not rule out gate sequences that leave the code temporarily,
active error correction, ancillary systems, approximate codes, moving
code spaces, or effective higher-order interactions. The paper-derived
application has not been checked by Lean or independent review.
