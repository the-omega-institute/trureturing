# OEIS A097602

The entry defines a sequence beginning at index one by adding the number of
square values already seen. The formal definition uses zero at index zero only
to totalize the recurrence; no source claim about index zero is asserted.

The entry records Zumkeller's conjecture that the square values attained by the
sequence have roots not divisible by three. It also records Jovovic's assertion
that square terms occur exactly at indices congruent to one or four modulo nine.
