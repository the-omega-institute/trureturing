# OEIS A177680

The entry defines the positive integers for which both 6n and 12n are averages
of twin-prime pairs. Its formula relates the sequence to A066388 by
`a(n)=A066388(n)/6`.

The proof of Dale's conjecture is an elementary residue argument modulo 5; no
priority claim is made.
