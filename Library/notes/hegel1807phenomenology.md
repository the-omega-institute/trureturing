# 黑格尔：概念受检验时，尺度也进入了问题

本笔记讨论《精神现象学》导论 §§81–88。作品发表于 1807 年。所读材料为 Marxists Internet Archive 的英文转录及其链接的德文《导论》；以下按网页中的段落编号定位。英文页面未提供足以在此确认其译者和印本版次的书目说明，因此不把它归给某一特定英译版。中文解释以两种语言中可对照的段落为依据，不作为现成中译本的引文。

## 1. 为什么检验的尺度本身会成为问题

§81 提出一个困难：要检验知识，似乎得先有一个接受了的尺度，才能判被检验的东西是否与它相合。但在通向科学知识的考察开始时，科学本身或某个尺度尚未证明自己的资格。如果研究者先把自己的立场当成绝对尺度，考察就已经预支了它要达到的结果。

§§82–84 的回答从被考察的意识自身入手。意识一方面具有关于对象的知识，另一方面把某种东西当作对象本身或真。这两个方面的区别已经存在于它的活动之中。于是，考察能够追问：它实际拥有的知识，是否符合它自己承认的真之尺度。

§84 的关键句是意识在自身给出尺度。其德文是“Das Bewußtsein gibt seinen Maßstab an ihm selbst”。这里不能读成“只要我相信，我就正确”。尺度与知识虽然都在被考察的意识中，却承担不同角色；正因为二者有可能不相合，检验才有内容。

这也不是给研究者授权，让他替任何观点编造一个方便击败的标准。黑格尔的要求是辨认被考察的意识所承认的真，与它关于这个真的知识之间的关系。这个方法的忠实性仍要靠具体章节说明；仅写下“内在批判”四个字还没有完成一次批判。

## 2. AHH：一次失败能够把原先的裁判标准变成被考察者

在 §85，最初的预期是：如果知识与对象不相合，就改变知识，使它符合对象。但黑格尔进一步说，在知识的改变中，对象也改变；原先被当作自在者的东西，现在显出只是对这种意识而言的自在者。该段最后把这一过程明确写成既检验知识，也检验它的尺度。

值得保存的阅读转折在这里：认识失败不一定只在一个始终固定的提问方式中产生新答案。它还会迫使我们说明，先前把什么当作对象、怎样理解“符合对象”，以及为什么采用那个标准。

§86 把涉及知识和对象的这种运动称为经验。这不同于只向一个不变分类表添加新条目，也不同于把每次意外简单归入“信息不够”。被动摇的，有时正是决定哪些信息相关、什么结果算成功的构造。

不过，不能把“对象也改变”改写成只要改变想法，外部物体就随意发生物理改变。这一段的论证围绕对象的自在性、对象对意识的呈现和知识的关系展开。它包含黑格尔的哲学主张；一个关于分类的简易模型既没有证明这种主张，也没有替它消除解释争议。

## 3. 用信息逃逸重述时，先指出哪个关系改变了

[尼采笔记](nietzsche1911early.md)借“叶子”例子讨论概念省略的差别，以及这些差别在另一问题中的相关性。沿这条线索阅读黑格尔，可以得到一个当代比较问题：当原来答不了的问题“变得可答”，究竟改变了什么？

下面四项是比较时需要交代的方面；一次修订可以同时涉及多项，它们不是互相排斥的历史类型。

| 改变的方面 | 修订需要说明的关系 |
| --- | --- |
| 保留的区分 | 新概念增加了什么读数，怎样处理旧概念合并的情形 |
| 所考察的对象域 | 新陈述仍谈哪些对象，被排除的旧对象如何说明 |
| 所要求的答案 | 原问题和新问题是否仍在问同一件事 |
| 评价或成功标准 | 为什么改用新标准，它怎样回应旧标准暴露的困难 |

例如，一份记录把不同叶片都写成“叶子”，后来改为记录各自的标本身份，这是对同一辨认任务补入区分。如果改问“这些标本是否都属于叶子”，则换了问题。后一问题得到回答，并不表示原来的个体辨认已经完成。这是本文的说明性比较，不是黑格尔原文的例子。

既有[目标恢复判据](../../D5/S3/ConceptDynamics/Restoration/TargetRecoveryCriterion.lean)固定对象域、概念读数与目标，然后检查目标能否沿读数恢复。它帮助辨认第一类信息缺口；要据它比较前后两个阶段，仍须说明两阶段的对象和目标怎样对应。改变目标、限制对象域或改变评价条件时，不能直接沿用“同一个缺口已经消失”的说法。

这一重述的价值，是保留“概念相对性”的可检验部分：先说明相对什么，再说明变化前后哪一项困难得到处理。它没有把黑格尔的经验概念缩减为一个固定目标下的数学完成算子。

## 4. 为什么这不等于随意更换标准

更换标准会引出一个正当的反问：如果每次失败都能换一把尺子，什么还能算失败？把相对性解释为永远可以换标准免除困难，会使批评失去着力点。

黑格尔在 §87 要求，结果是所失败的那个知识形态的否定，包含此前形态的真，不能坍缩成空无。新对象与新形态因此应从前一形态的具体失败中形成。至少在导论所陈述的方法上，这与随手换到一个不相干的问题不同。

这里仍须把作者的要求与要求已经履行分开。指出一个旧标准出了问题，还没有展示唯一的新标准；说明某个新标准解决了一项困难，也没有自动完成通往终点的必然序列。每一步怎样产生、保留什么、改变什么，正是后续章节需要承担的内容。

在本文的比较方法中，可以据此提出一项纪律：陈述新结论时，同时交代旧结论在原条件下是否仍有效，原来的反例是否仍然成立，以及新条件为何值得采用。它是从对读中提出的研究建议，不是把黑格尔归入现代实验预注册，也不是从几段导论导出了一个通用进步定理。

## 5. “对意识而言”与“对我们而言”的差别

§87 区分经历这一运动的意识与考察它的“我们”：在这里描述的经历中，对前者，新内容呈现为对象，而新对象的生成及其必然性并不作为这样的过程向它呈现；对“我们”，同一内容同时被把握为运动和生成。黑格尔把这种考察称为“我们的补充”，并说它使经验的序列成为科学的进程。因此，没有从外部带入检验尺度，并不等于取消这两个考察位置的区别。

这一区别也限制了简单类比。若把每个个体在事后讲出的成长故事都当作必然的辩证发展，就把需要展示的关系当成已经存在的关系。完整叙述、主观确信或一个圆满结局，都不能单独承担这种展示。

§§87–88 明确声称发展有必然性，并因此把通向科学的道路本身称为科学。本文必须保留这项较强主张；同时，本文没有证明它，也没有把一般的、可能失败的概念修订冒充这项必然性。

## 6. 与康德、塞拉斯的联系和仍存的问题

[康德笔记](kant1781critique.md)关注先天概念应用的合法性；[塞拉斯笔记](sellars1956empiricism.md)关注观察知识的权威及其背景条件。黑格尔导论让比较再增加一个问题：当知识与其承认的真发生张力时，原先采用的检验尺度是否也必须进入考察。

这些问题可以彼此推进，却不能只因都涉及“资格”“标准”就合并。康德的先验演绎、塞拉斯的可靠性与认识要求、黑格尔的内在检验及必然发展，各自有不同的对象和论证义务。

下一步需要具体辨认的，是尺度修订中的约束从哪里来：旧问题的哪些要求仍须履行，哪些要求可以受到批评，新尺度怎样与这些变化连接。把尺度本身纳入更大的概念结构，使这种关系可以被讨论；仅完成这种表示，仍没有证明应选择哪一套尺度。
