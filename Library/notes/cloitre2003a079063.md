# OEIS A079063

The NAME of A079063 defines the least-index sequence:

> Least k such that sqrt(prime(n+k))-sqrt(prime(n))>1

The COMMENTS line gives the motivation:

> Inspired by Andrica's conjecture. If it is true, a(n)>1 for all n.

The FORMULA line proposes an eventual square-root lower bound and more precise
limsup and liminf values. The repository result refutes the weakest quantified
eventual positive lower bound. It does not address Andrica's conjecture or
assert the existence of either limit.
