# OEIS A187941

The entry defines the least number having exactly a prescribed number of even
divisors and records the relation `a(n) = 2 * A005179(n)` for positive indices.

## Verified locator

- URL: https://oeis.org/A187941
- Locator: COMMENTS, "Conjecture: a(n) = 2^n only if n is prime or if n = 1."

The entry's offset 0 makes the literal statement false at `n = 0`, where `a(0) = 1 = 2^0`.
For positive indices, the implication is proved using the elementary multiplicative even-divisor count; no priority claim is made.
