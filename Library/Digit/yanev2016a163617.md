# OEIS A163617

The entry defines an integer-indexed recurrence and records Velin Yanev's
closed-form conjecture. The formal module proves the nonnegative-index half,
initialized by `a(0) = 0`. It does not claim the negative-index half, which
the entry relates to A163618.

The Gray-code term is OEIS A003188. Its entry names the decimal equivalent of
the Gray code for `n` and gives the formula `a(n) = n XOR floor(n/2)`, where
XOR is binary exclusive OR. For nonnegative `n`, the parity-split correction
used in the formal module equals `(6*n + 1 - (-1)^n)/4` over the integers.
