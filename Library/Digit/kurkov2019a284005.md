The entry's initial data supplies a(1)=2. A000120(n) is the number of

the NAME quotation is not a premise or conclusion of the native result.

## Exact question and native result

In normalized notation, for every integer n>1 set L=floor(log_2(n)),
f(n)=n-2^L and T(n,k)=floor(n/2^k) mod 2. The conjecture is

```text
a(n) = 2*a(f(n)) + Sum_{k=0..L-1} a(f(n)+2^k*(1-T(n,k))).
```

Every k from zero through L-1 is included. An existing one bit has
T(n,k)=1 and contributes a(f(n)); such repeated contributions remain
in the sum. The domain includes n=2 and all powers of two. It requires
no value of log_2(0) and asserts no lower-bit identity at n=0 or n=1.

The repository's native result uses the imported A284005 function and
binary digit sum, and contains the initial values, the defining recurrence
for every natural n>1, and the complete identity above. Natural-number
quantification represents exactly the source's integer domain n>1.
The source supplies the question, not the repository proof. The sequence
supplier's April 24, 2023 two-parameter binomial theorem is a distinct
identity and is not used as a substitute for this question.
