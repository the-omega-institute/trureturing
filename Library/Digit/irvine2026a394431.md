## Reading of the statement

Write `s_b(n)` for the base-`b` digit sum of `n`. The entry's value is the least base among those in
`1 < b < n` attaining the largest `s_b(n)`. The conjecture says this base is
`ceiling((n + 1) / 2) = floor(n / 2) + 1` for every `n > 8`. At `n = 8` it fails, since
`s_3(8) = s_5(8) = 4` and the least maximizing base is `3`.

## Scope of the recorded answer

The conjecture holds. Above half of `n` the expansion of `n` in base `b` is the two digits `1` and
`n - b`, so `s_b(n) = n - b + 1`, which is largest at the least such base `floor(n / 2) + 1` and
equals `n - floor(n / 2)` there. For a base `b` with `2 * b ≤ n`, write `n = q * b + r` with
`q ≥ 2` and `r < b`, so `s_b(n) = r + s_b(q)`. Every digit sum is at most its argument, and when
`q ≥ b` a further expansion gives `s_b(q) + (b - 1) ≤ q`. In both cases `2 * s_b(n) < n` once
`n > 8`, so `s_b(n) < n - floor(n / 2)`, strictly below the value at the first base above half. The single case of equality in these bounds
is `b = 3`, `q = r = 2`, that is `n = 8`.
