# Carryless multiplier containment

The source sequences use ordinary multiplication on the left and the binary
polynomial multiplication table A048720 on the right. The target assertion is
the all-natural-number implication

$$
13k=C(29,k)\quad\Longrightarrow\quad 11k=C(31,k).
$$

The retained source scope is the OEIS internal pages for A115803, A115805 and
A048720. It records source definitions and conjectured containment only; the
finite checks reported there are not universal proofs. This note does not make
a worldwide-priority or exhaustive-literature claim.
