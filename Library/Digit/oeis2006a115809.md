# The seventeen-times containment question

A115809, revision 5, names the integers satisfying `17*k = 49 X k`.
Its comment specifies that `*` is ordinary multiplication and `X` is
carryless multiplication in GF(2)[X], using A048720.
The cross-reference asks: `Cf. Subset of A115801 ?`
The author line attributes the entry to Antti Karttunen in 2006.

A115801, revision 20, defines the nonnegative integers satisfying
`9*k = A048720(25,k)`. A048720, revision 62, defines binary polynomial
multiplication over GF(2). The containment question therefore asks whether,
for every natural number k, `17*k = C(49,k)` implies `9*k = C(25,k)`.
The same k occurs throughout, zero is included, and the other products
are ordinary natural-number products.

The operation and question are from these entries. The universal
containment proof uses a finite closed relation of carry states.
