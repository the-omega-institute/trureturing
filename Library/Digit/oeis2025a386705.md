The entry is attributed to Paolo Xausa and identifies A166751 as the
underlying triangle grouped by bit length.

The NAME requires positive even integers of bit length exactly `2*n`.
Every maximal run of zeros has the same length as the maximal run of ones
immediately before it. The row sum counts each integer once. The FORMULA
states, with the label "Empirical":

> a(n) = 12*a(n-1) - 36*a(n-2) + 32*a(n-3), with a(1) = 2, a(2) = 22, a(3) = 192.

The universal recurrence is read for every integer index `n >= 4`, with
integer arithmetic. Encoding such words by ordered positive part lengths
is already part of the A166751 composition relation; it is not a new
combinatorial observation.
