# OEIS A351858

The NAME field defines a(n) = [x^n] (1+x+x^2)^(3*n)/(1+x)^(2*n).
Peter Bala's FORMULA entry asks for the inclusive finite sum
Sum_{k = 0..floor(n/2)} C(3*n,k)*C(n-k,k).
The coefficient is taken in the formal expansion at zero. The denominator
has constant coefficient one. This question includes n = 0 and n = 1.
The separate supercongruence on the same sequence is a different assertion.
