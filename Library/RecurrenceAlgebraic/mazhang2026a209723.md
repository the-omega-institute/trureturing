# Beck and Peterson identities for the three-column clockwise-difference count

## Verified locator

DOI: 10.5281/zenodo.23903301

Source: https://doi.org/10.5281/zenodo.23903301

The written proofs are by **Haobo Ma and Wenlin Zhang**, *OEIS A209723: Barker's
conjectures on distinct clockwise edge differences*, public version 2, exact-version DOI
https://doi.org/10.5281/zenodo.23903301, Corollary 1. R. H. Hardin posed the array
problem in OEIS A209721–A209727; Colin Barker gave the empirical formulas. The two-step
recurrence and the triangle reading are Richard Locke Peterson's COMMENTS (Apr 26 2020)
in OEIS A209721, and the A029744 formula is George Beck's conjecture (Mar 26 2022) there;
see Library note hardinbarker2012a209721.

## Statement

Let a(n) be one quarter of the number of (n+1) X 3 arrays over 0..2 whose consecutive
2 X 2 squares have distinct clockwise edge differences, so a(n)=T(n,2) in A209727. For
n >= 1, a(n) = A029744(n+1)+1, where A029744 lists the numbers 2^k and 3*2^k in
increasing order with offset 1. For n >= 3, a(n) = 2a(n-2)-1, and a(n) is the number of
positive integers c forming a nondegenerate triangle with sides a(n-1) and a(n-2); these
are exactly a(n-1)-a(n-2)+1 <= c <= a(n-1)+a(n-2)-1. The proof combines the order-three
recurrence with a(1)=3, a(2)=4, a(3)=5: the quantity a(n+2)-2a(n) is constant, equal to
-1, and the two-step law with the first two values identifies a(n)-1 with A029744(n+1).
Since a is increasing, the triangle inequalities leave an interval of 2a(n-2)-1 integers.
