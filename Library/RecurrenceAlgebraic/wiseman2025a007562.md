# Wiseman's A007562 question

## Verified locator

The A007562 item under **Open Problems** in revision 1666467 asks whether the counts agree.

> Let a(n) be the number of planted trees where non-root, non-leaf nodes an even distance from root are of degree 2. Let b(n) be the number of unlabeled rooted trees with n nodes in which every non-leaf node has at least one leaf. Is a(n) = b(n) for all n?

[Wiseman's pinned question](https://oeis.org/wiki/User:Gus_Wiseman?oldid=1666467#Open_Problems)

The OEIS definition line repeats the planted-tree condition. Its comment says
“There is no planted tree on one node by definition.” The b-file starts with
`1 1`, assigning value one to the sequence at index one.

## Reading of the statement

The plant is the root and has exactly one child. A nonroot internal vertex
has one edge to its parent, so graph degree two means it has exactly one
child. Depth counts edges from the plant, and the vertex count includes
the plant. On the right a leaf child is an immediate child.

At size one the literal planted count is zero and the leaf-child count
is one. The normalized left class adds the singleton, realizing the
entry's sequence convention. The equality of literal object counts is
for sizes at least two, and the normalized equality is for positive sizes.
