# OEIS A358587

## Verified locator

[OEIS A358587, revision 14](https://oeis.org/A358587/internal) gives the
counting class, the offset at index one, and the seven initial values
0, 0, 0, 0, 1, 4, 14. The formula block attributes the generating function
and the recurrence for indices greater than seven to Chai Wah Wu.

## Reading of the statement

Trees are unordered and counted up to root-preserving isomorphism. Height
counts vertices on a longest root-to-leaf path. The first tree in the
entry's examples has five vertices, vertex height three and three
internal vertices. A singleton has vertex height one and zero internal
vertices. The formal series uses integer coefficients and a zero
constant term. The recurrence uses signed integer arithmetic.
