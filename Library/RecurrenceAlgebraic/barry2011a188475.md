# Barry's original shifted Hankel conjecture

Paul Barry's A188475 revision 2 states: “Hankel transform of A137398(n+1)
(conjecture).” Its offset is zero, and its name is
`a(n) = (2*n^3 + 3*n^2 + n + 3)/3`.

A137398 had offset zero in the original conjecture. Its revision 11 changes
`0,3` to `1,3`. Write q for its current one-based recurrence-defined sequence:
q(1)=0, q(2)=1, q(3)=2, and
q(r)=2q(r-1)+2q(r-2)+sum(k=1..r-3,C(k)q(r-k-1)) for r>=4.
The original shifted Hankel matrix therefore has entries q(i+j+2), with
i,j from zero through n. The auxiliary value q(0)=0 does not change that
matrix or the positive-index recurrence. Tabulated terms do not define q.
