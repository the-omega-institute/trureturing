> Conjecture: every rational number in the interval (0,1] occurs exactly once in T.

> Starting with g(1) = (1), write the numbers in the ordered union of g(1), g(2), ..., g(n) as (x(1),x(2),...,x(m)). Then for i = 1..m, write x(i)/(1 + x(j)) for j = 1..m, and expel all the numbers that have previously occurred. The result is ordered union of g(1), g(2), ..., g(n+1).

The source program starts with `x = {1}` and applies
`DeleteDuplicates[Join[x, Map[x[[#[[1]]]]/(1 + x[[#[[2]]]]) &, Tuples[Range[Length[x]], {2}]]]]`.
Its coordinate outputs are `Numerator[x]` and `Denominator[x]`.
DeleteDuplicates retains the first occurrence without reordering:
https://reference.wolfram.com/language/ref/DeleteDuplicates.html.

## Formal interpretation

The Lean cumulative list at zero is the source's U(1). The pair list is a
flatMap over the whole cumulative list, followed by a map over that same
list: the numerator index is outermost, the denominator index innermost,
and diagonal pairs are included. The old list is retained as a prefix;
its new suffix is first-retention filtering of previously absent pair values.
Equality to first-retention deletion of the full concatenation is proved
using Lean's eraseDups, which retains first occurrences. List.dedup has
different semantics and is not used.

Generation numbers and positions are positive in Occurs. The infinite
fraction function uses index zero for the first source entry. Its finite
prefixes agree with the ordered concatenations of generations; those
prefixes have unbounded length. Every rational in (0,1] has exactly one
valid generation/index pair. Every flattened index has exactly one such
owner, and the fraction function is injective. Numerator and denominator
are the canonical rational projections of this same fraction function,
with coprimality and positive denominators, not separate uniqueness claims.

The proof uses strong induction on a positive integer denominator. For
p<q, use the diagonal pair at p/(q-p) when 2p<=q, and the pair
(1,(q-p)/p) otherwise. Both inputs belong to one common cumulative list.
The seed handles p=q. Existing rational representation and finite-list
facts are reused from the pinned Lean and Mathlib versions.

The denominator-induction candidate was supplied by a GPT Pro search and
checked ordinarily before this formalization. This is an application to
the exact published source question, without an independent-discovery or
research-difficulty claim. Finite published array digits and Mathematica
execution are outside the formal statement.
