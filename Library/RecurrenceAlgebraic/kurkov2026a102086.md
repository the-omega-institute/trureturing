## Source statements

NAME, verbatim:

> Triangular matrix, read by rows, that satisfies: T(n,k) = [T^2](n-1,k) when n>k>=0, with T(n,n) = (n+1).

FORMULA, verbatim:

> Conjecture: n-th row polynomial is P(n+1, n) where P(n, k) = P(n, k-1) + (k+1) * P(n-1, k) for 0 < k < n with P(n, n) = x^n, P(n, 0) = 1, P(n, k) = 0 for k < 0 or k > n. - _Mikhail Kurkov_, Jul 03 2026

OFFSET, verbatim: `0,3`. The first row is `[1]`. The row polynomial uses
coefficients in increasing powers, without reversal. The matrix-square
entry is the finite sum over `k <= j < n` of `T(n-1,j)T(j,k)`.
The second index of P ranges over all integers, including negative ones.
The diagonal and zero-column rules agree at P(0,0)=1=X^0.

## Mathematical scope and prior support

The formal claim includes existence of both source tables and the identity
for every source pair and every natural row, including zero. The independent
P recursion, finite linear operator shift, coefficient bounds and table
uniqueness supply the bridge to the matrix-square definition.

Fedor Petrov's accepted [MathOverflow answer 477153](https://mathoverflow.net/a/477153)
provides a general scalar power-series inversion algorithm. It does not
state the polynomial-diagonal table or its identification with this
matrix-square triangle. OEIS A102316 has the same scalar interior recurrence
but a different diagonal. The existing A107667 weighted-ballot theorem uses
a column shift in the matrix square and a three-argument scalar table.
The existing A340991 convolution theorem uses powers of a generating series
and a different shifted-tail array. None supplies the whole present claim
by direct substitution. Pinned Mathlib owns Polynomial.lsum, linearity,
finite coefficient expansion and extraction; these are reused directly.
