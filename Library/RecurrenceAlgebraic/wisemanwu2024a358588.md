# OEIS A358588

## Verified locator

[OEIS A358588, revision 12](https://oeis.org/A358588/internal) gives the
counting class in the name field and starts at index one. The formula block
attributes the generating function and the recurrence for indices greater
than seven to Chai Wah Wu. The first seven entries are 0, 0, 0, 0, 1, 8, 41.

## Reading of the statement

The shape is a rooted tree with an ordered list of children at each vertex.
Height counts the vertices on a longest root-to-leaf path, as in the
[OEIS A358552 height convention](https://oeis.org/A358552/internal).
A singleton has height one and zero internal vertices. The series uses
integer coefficients and a zero constant term. The recurrence uses signed
integer arithmetic. [OEIS A358587](https://oeis.org/A358587/internal) counts
unordered shapes.
