# Yu, Jayachandran, Burchardt, Cai, Brunner and Scarani, absolutely entangled sets for multipartitions

B. Yu, P. Jayachandran, A. Burchardt, Y. Cai, N. Brunner and V. Scarani, Physical Review A 104, 032414 (2021), DOI 10.1103/PhysRevA.104.032414; arXiv:2106.16216v3 (4 October 2021; v1 30 June 2021). Quotations are from the arXiv v3 TeX source, with cross-references omitted.

The definition (partitions are the factorizations $d=d_1\cdots d_k$ of the dimension):

> Consider a set of quantum states $S=\{\rho_1,\ldots,\rho_N\}$ in a Hilbert space $\mathbb{C}^d$ of non-prime dimension $d$. (i) The set $S$ is said to be *absolutely entangled with respect to the $(d_1,d_2,\ldots,d_k)$-partition* where $\prod_{i=1}^k d_i =d$, if for every unitary matrix $U\in SU(d)$, at least one state $U\rho_nU^\dagger$ is entangled with respect to multipartition $\mathbb{C}^{d_1}\otimes\cdots\otimes\mathbb{C}^{d_k}$. (ii) Let P be the set of all possible partitions of $\mathbb{C}^d$. The set is said to be *absolutely entangled with respect to any partition*, if for every partition $p\in P$ and every unitary matrix $U \in SU(d)$, at least one state $U\rho_{n}U^\dagger$ is entangled with respect to $p$.

After constructing a set that is absolutely entangled with respect to any partition (a Corollary with a fixed orthonormal basis $\{\xi_i\}$ of $\mathbb C^d$), the source asks:

> This result guarantees that, given any $U$ and any partition $P$, there exists at least one entangled state. An interesting open question is whether one can find an AES, such that, for every $U$, there exists a state that is entangled according to all partitions. This would arguably be the strongest form of genuine multipartite entanglement.
