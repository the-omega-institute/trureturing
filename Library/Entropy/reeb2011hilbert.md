# Projective metric contraction and bandwidth

For the positive map that tensors the bath input with a maximally mixed memory, applies a unitary and traces out the bath, the normalized bath identity maps to the normalized memory identity. Contraction bounds the output log spectral ratio by the input bath ratio βW. The Lean proof bounds both ends of the matrix order interval directly.
