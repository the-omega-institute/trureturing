# Odd-width honeycomb cylinders

The graph has vertices A(i,j) and B(i,j), for integer i,j. The neighbours of A(i,j)
are B(i,j), B(i−1,j), B(i,j−1). The odd cylinder identifies a vertex with its translates
through (n+1,n), preserving its A or B label.

## Verified locator

OEIS: https://oeis.org/A329515.
The [immutable source](https://raw.githubusercontent.com/oeis/oeisdata/77073cc8105b8042be07ec0d885da5ea5960ff3c/seq/A329/A329515.seq)
is revision 32. Its NAME is:

> Array read by upward antidiagonals: row n = coordination sequence for cylinder formed by rolling up a strip of width 2*n+1 hexagons cut from the hexagonal grid by cuts perpendicular to grid lines.

Its conjectural FORMULA lines are:

> The g.f.s for the rows could be found using the "trunks and branches" method (see Goodman-Strauss and Sloane), as was done in A329508. This step has not yet been carried out, so the following g.f. is at present only conjectural.
>
> The g.f. G(n) for row n (n>=0) is (strongly) conjectured to be
>
> (1/(1-x))*(1 + 2*x + 3*x^2*(1-x^(2*n-1))/(1-x) - (n-2)*x^(2*n+1) - n*x^(2*n+2)).

The formalization uses the denominator-cleared identity over `PowerSeries ℤ`.

At n=0 the source uses the Laurent expression x^(−1). Combining it with x² before clearing denominators gives 3X²−3X^(2n+1), valid for every natural n. The coefficient n−2 is an integer subtraction. Since 1−X has constant coefficient one, it is a unit.
