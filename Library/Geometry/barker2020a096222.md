# Rectangles in an alternately folded grid

## Verified locator

https://oeis.org/A096222/internal?rev=13

OEIS revision 13, FORMULA, the entire Colin Barker conjecture block:

```text
Conjectures from _Colin Barker_, Feb 04 2020: (Start)
G.f.: (1 - 3*x - 9*x^2 + 24*x^3) / ((1 - 2*x)*(1 - 4*x)*(1 - 8*x^2)).
a(n) = 6*a(n-1) - 48*a(n-3) + 64*a(n-4) for n>3.
(End)
```

The COMMENTS sentence fixes the object: "In this sequence we count the rectangles
in an a X b array of squares, where a=2^floor(n/2) and b=2^ceiling(n/2)."
The entry was submitted by Bill Liebeskind. Its existing FORMULA already gives
`a(n) = a b (a+1) (b+1)/4` with these same sides; that count formula is prior work.

## Mathematical correspondence

The Lean count is the cardinality of pairs of natural endpoint pairs, with
`x0 < x1 <= 2^(n/2)` and `y0 < y1 <= 2^((n+1)/2)`. Natural coordinates provide
nonnegativity. Choosing grid-line intervals is a bijective description of a
rectangle's location, width and height; distinct endpoints give distinct placements.
Natural division by two implements the floor, and `(n+1)/2` the ceiling.
`PowerSeries.mk` uses all natural coefficients, starting at `n=0`. Signed
subtraction in the recurrence takes place after casting counts to the integers.
The denominator has constant coefficient one, giving its formal-series inverse.

literature search.
