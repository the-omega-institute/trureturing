# Wu's two equality conjectures in A227244

OEIS A227244 revision 54, FORMULA, Chai Wah Wu, July 10, 2026, states:

> Conjecture 1: a(20*n+16) = 101 for n >= 0.
> Conjecture 2: a(220*n+8) = 47 for n >= 0.

The NAME defines a(n) as the smallest prime factor of
`(2^(2^n) + 1)*2^(2^(2^n)) - 1`. All exponents are natural.
The corresponding Lean expression uses integer multiplication and subtraction.
Both equality families include n = 0 and have no upper cutoff.

The COMMENT bound `a(20*n+16) <= 101` establishes only an upper bound;
the equality additionally excludes every smaller prime divisor.
The 2019 proof of the first conjecture addresses the older lower bound
`a(n) >= 11`, rather than the 2026 Conjecture 1 equality.
