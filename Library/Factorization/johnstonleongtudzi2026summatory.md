# The signed Omega summatory function

## Verified locator

https://arxiv.org/abs/2408.04143v3

DOI: 10.1080/10586458.2025.2483942

*Experimental Mathematics* 35 (2026), no. 3, 453–479.
The specified arXiv version is v3.

## Source statement

Section 5.2, Conjecture 5.1:

> Let s_a be defined as in Theorem 1.5. Then lim_{a→∞} s_a = 1.

Theorem 1.5 uses real $a>2$, $v_a=\log_2a$,
$W_a(x)=\sum_{n\le x}(-a)^{\Omega(n)}$, and
$s_a=\limsup_{x\to\infty}|W_a(x)|/x^{v_a}$.
Here $\Omega$ counts prime factors with multiplicity.
