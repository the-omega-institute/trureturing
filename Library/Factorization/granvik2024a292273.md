# Granvik's A292273 real-part formula

The source definition is: "For odd n: a(n) = 0, and for even n: a(n) =
-mu(n), where mu is Moebius function (A008683)." The offset is one.
The conjecture is: "Conjecture: a(n) = Re(A008683(n)*(i^n)). - _Mats
Granvik_, Jul 06 2024". The exponent is the natural index, mu is the
ordinary integer Mobius function and i is the complex imaginary unit.

The arithmetic definition and real-part identity concern every positive
index. The Collatz-trajectory interpretation in the comment and program
sections is outside this assertion. No trajectory-termination assumption
or conclusion is used.
