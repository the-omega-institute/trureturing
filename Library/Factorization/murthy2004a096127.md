# OEIS A096127

Amarnath Murthy's entry defines `a(n)` as the largest exponent for which
`(n!)^a(n)` divides `(n^2)!`, with offset 2. The comment quoted below states
that equality `a(n)=n+1` occurs only for primes and prime powers. OEIS
A096126 records the same assertion.

The formal theorem proves the closed biconditional: the exponent `n+1` works
but `n+2` does not exactly when `n` is a prime power. Legendre's formula and
base-`p` digit sums compare the two factorial valuations.
