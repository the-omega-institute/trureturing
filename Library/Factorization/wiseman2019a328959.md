# OEIS A328959

The entry defines the integer-valued sequence
`a(n) = sigma_0(n) - 2 - (omega(n) - 1) * nu(n)`, where `sigma_0` is
A000005, `nu` is A001221, and `omega` is A001222. Thus the entry's `omega`
counts prime factors with multiplicity, while its `nu` counts distinct prime
factors. In conventional notation the formula is
`a(n) = sigma_0(n) - 2 - (Omega(n) - 1) * omega(n)`.

The conjecture asserts nonnegativity except at `n = 1`, where `a(1) = -1`.
The formal theorem proves the nonnegative branch for every `n >= 2`.
