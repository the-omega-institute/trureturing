# OEIS A167857

The Online Encyclopedia of Integer Sequences, entry author T. D. Noe, defines:

> That is, these numbers n have the property that there is a polynomial f(x) with integer coefficients whose values at x=0..tau(n)-1 are the divisors of n, where tau(n) is the number of divisors of n.

It asks:

> Are there terms with three distinct prime divisors?

The increasing example and the Mathematica Divisors/PARI divisors conventions
fix increasing order. The sequence offset does not shift the polynomial inputs.
The reference to A073103 as primes 210k+1 is inconsistent with that entry's
actual description and is excluded as a mathematical premise.
