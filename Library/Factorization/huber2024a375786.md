## Source statement

OEIS A375786, NAME (unpaginated):

> a(n) is the minimum volume of an integer-sided cuboid having the same surface as a cube with edge length n.

OEIS A375786, COMMENTS (unpaginated):

> Conjecture: From the integer-sided cuboids with same surface 6*n^2 always the one with the smallest edge length has the minimum volume. If there are several integer-sided cuboids having the smallest edge length, then the one with the smallest second smallest edge length has the minimum volume (checked up to a(1000)).

## Mathematical scope

For n ≥ 1, list positive integer edge lengths as x ≤ y ≤ z. Equality
of surfaces is xy + yz + xz = 3n². The conjecture compares the volume
xyz of a least pair (x, y) in lexicographic order with every other
solution, by a non-strict inequality. It does not assert uniqueness.

The repository proof uses xS ≤ 2xyz + x³ for S = xy + yz + xz,
together with 3x² ≤ S. Odd n has a first-edge-one solution; even
n = 2m has the solution (2, 2, 3m² − 1). The finite interval encoding
bounds each edge by 3n², which follows from positivity of the other edges.
