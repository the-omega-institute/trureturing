# Digraphs — Theory, Algorithms and Applications

The second edition treats Hamilton cycles in semicomplete digraphs. The
classical longest-cycle argument allows both reciprocal arcs and directed
cycles of length two. The formal statement uses a finite subset of an arbitrary
vertex type, restricts every arc endpoint to that subset, and returns a simple
spanning closed chain based at any specified vertex.
