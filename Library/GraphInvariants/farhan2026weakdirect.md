## Source question

> The result above clearly leads to a question concerning the exact value of
> wdim4(Kn × Kn) when n ≥ 4.

The product is direct: both coordinates differ along an edge. The introductory
weak-resolution definition omits the distinct-pair restriction, which is
explicit in Proposition 2.2. Self-pairs have zero separation, so the stated
positive-parameter results require that restriction.

## Repository result and boundary

The owning theorem proves the exact value
$2n+\lceil2n/11\rceil+\mathbf1_{n=5}$ for every $n\ge4$, using actual shortest
graph distances, a universal lower bound, an order-five obstruction, and
equality-size constructions at every order. The source is a problem input,
not an assumed theorem establishing this answer.
