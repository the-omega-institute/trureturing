## Self-sweep before mirror-ready (binding)

The mirror's reuse scan is the same scan you must run yourself first; a continuation that fixes only the named findings hands the next mirror a new list. Before returning `mirror-ready`, over every declaration this delivery adds or edits (published owner keywords excluded):
- **Definitions, by body.** Search frozen D5 (private included) and pinned Mathlib for an owner with the same defining expression, generic owners included (`Function.update`, `midpoint`, `Finset.centerMass`, `Equiv`/`Unitary.map` constructions, `WithLp` norms…); concrete literal data is exempt. **The preregistered binding conventions are exempt too: never rewrite the body of a definition that the preregistration issue fixes (its literal text is binding); reuse applies to the delivery's own helpers and non-preregistered definitions.**
- **Every helper theorem and every closed local `have`.** Run `exact?` on its statement **in the delivered module's own import environment** (a scratch file with the module's imports; a smaller environment does not count) with `set_option maxHeartbeats 1000000 in`, rerunning any probe that exhausts once with `4000000`; also run a conclusion-shape search (`rg` over `D5` with private declarations and over `.lake/packages/mathlib/Mathlib`).
- **Same-delivery owners.** Check every helper and every closed local `have` also against every other declaration of this delivery (all delivered modules, private included): a local fact that restates an earlier declaration of the delivery, or a specialization of it, is replaced by an application of that declaration (move the declaration earlier if needed; it stays private unless another module consumes it). `exact?` does not see private same-module declarations, so test each candidate by a compiled direct application.
- **Report one row per item**: item, `exact?` outcome (hit name / no match / exhausted at budget B), shape-search command and hit count, and the action taken (replaced by owner X / kept, no owner). A probe that still exhausts at `4000000` heartbeats is recorded as inconclusive together with its conclusion-shape search; that row is complete (an exhausted search is not a defect), and every shape-search candidate it names must be tried by a compiled application.
- Apply every hit (direct application of the owner; publish a frozen private owner only by removing `private`, with its Scribe node and audit-issue mention, after counting its transitive importers — above ~80 importers, ask by returning `open` instead).
