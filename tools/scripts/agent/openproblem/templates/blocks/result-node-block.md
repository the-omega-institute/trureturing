
## The settling result node (binding)
The Scribe node of `result` displays the full statement it proves, built from the real Lean names, with its Library acknowledgement edge: for a proof, the whole `claim` proposition; for a refutation, `¬` followed by the whole `claim` proposition. A formula that is only the name `claim` (or `¬ claim`) is a blocking defect at every stage. The mirror-check seat checks this item; a Stage B seat that finds it expands the formula in the same builder commit (this edit is authorized despite any Stage B formula freeze) and reports the change.
