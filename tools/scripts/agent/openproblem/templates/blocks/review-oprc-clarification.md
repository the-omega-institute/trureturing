
## Clarifications that bind this review (open-problem-resolution deliveries)

- **Definition fidelity and reuse.** CLAUDE.md §4.3 requires reusing an existing frozen owner rather than restating it. CLAUDE.md §3.2 condition (a) bars companion theorems from an open-problem-resolution module, including a standalone "public identity" theorem.
  - So, for these modules, a reused frozen definition satisfies definition fidelity when it is equal to the source's expression on the source's stated domain, the Scribe definition node displays the source's expression, and the equality is proved inside the proof wherever the proof relies on it. A missing public identity theorem is then not a defect.
  - A *new* definition must still be the literal source expression.
- **PR-body provenance.** The independent judgement-form/mirror seat is named once, as a carriers-and-roles fact (CLAUDE.md §5.2). The completed-round standing table is required provenance.
  - A sentence narrating an implementation sequence ("Freeze order: …", "Production order: …") is process narration under §2.10: report it if present.
  - Naming the reviewer seat in the carriers-and-roles line is not narration.
