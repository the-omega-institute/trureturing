## Compile-cost gate (binding before Stage B; CLAUDE.md §10.2)
Measure every delivered module alone with `/usr/bin/time -l lake env lean -Dprofiler=true -Dtrace.profiler=true -Dtrace.profiler.threshold=1000 <module>.lean`. Each must stay within 600 s wall and 9 GB peak RSS (the import-only baseline is about 5.7 GB of shared mapping). Report wall seconds, peak RSS, kernel-checked seconds and the top-10 profiler blocks per module, plus the import-only baseline. If a module exceeds a limit, optimize it in this round (split large `nlinarith`/`decide`, close certificate identities with `linarith`, precise imports, `simp only`) without changing any public statement.
