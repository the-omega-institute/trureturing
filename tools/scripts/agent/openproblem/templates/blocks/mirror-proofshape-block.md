
## Proof-shape findings need a compiled route (binding)
A finding that relabels a declaration from `content` to `bind-only` must attach the compiled inlined proof: a scratch file that proves the declaration's statement from frozen owners and pinned Mathlib using only instantiation, projection, logical regrouping and the normalization of CLAUDE.md §3.2, with its `lake env lean` exit code 0. An argument sketch is not a route. In particular, natural-number or integer case splits that establish a new nonnegativity or polynomial certificate (`rcases`/`by_cases` with `nlinarith`, `omega` over new case facts) are not normalization unless the compiled route shows every atomic fact is supplied by an owner. Without such a route, report the doubt as an advisory, not as a blocking relabel.
