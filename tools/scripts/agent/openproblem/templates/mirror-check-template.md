## Checklist (each item: PASS / FAIL with file:line evidence; a FAIL on any item = verdict `reject`)
1. **Visible grouping**: every visible parenthesis is built with the landed `Parenthesized(...)` helper (`Seq(Open, value, Close)`), never with raw `Open`/`Close` tokens and never with `Grp(...)` (which emits TeX braces that print no parentheses — `n·Grp(xy+xz+yz)` renders `nxy+xz+yz`). Check the emitted `.md`: every grouping the Lean statement needs (products of `(p − 1)`, conjunct scopes, quantified clauses joined by `∧`) is visibly delimited.
2. **Conjunct scopes**: for every public theorem whose statement is a conjunction of quantified clauses, each complete quantified clause is parenthesised and the outer `∧` sits outside the parentheses; no `∧` token appended inside an `Aligned` row.
3. **Binder/body symbols and named objects**: every symbol appearing in a rendered formula is either a bound variable of that formula, a Lean public declaration name mirrored in this module, or a Mathlib/atom-defined object — NEVER an ad-hoc abbreviation (`red(u,n)` for `reducedState u n` was a quality-seat reject after freeze, skolem #5597);  every quantified variable is emitted with the SAME symbol in the binder and in the body (`Bound("gamma", …)` with a `γ` body is a FAIL); every binder in the `.md` occurs in its body.
4. **Coercions**: every `.val`, `↑`, `Fin`→`ℕ`, `ℕ`→`ℚ` cast that appears in the Lean statement is mirrored (landed convention `Call("val", …)`); a `Fin 17` passed where the Lean applies `.val` is a FAIL.
5. **Integer division / mod / floors**: `Nat.div`, `/` on ℕ or ℤ, `%`, `Nat.floor` are rendered as integer division (floor notation or a named operator with the convention stated in the Describe prose), NEVER as `Formula.Fraction`. Fractions only for field division (ℚ/ℝ/ℂ).
6. **Relation nodes**: no relation (`=`, `≤`, `∣`, `≠`, `∈`) inside `LatexGroup.Items` (uncovered corpus shape `precedence:relation` → CI red); run `dotnet test tools/tests/StrataLint.Scribe.Tests/StrataLint.Scribe.Tests.csproj --configuration Release --filter FullyQualifiedName~FormulaCorpusInventoryTests` and report EXIT (must be 0).
7. **Completeness**: every public theorem/def in the Lean module has a mirror (public `def`s included — a checker predicate or witness table that is public but absent from the mirror is a FAIL; large kernel-decided tables are mirrored by a node stating their type and describing the list, not by transcribing every entry; a helper that no public statement mentions should be `private` in Lean rather than mirrored — say which; zarembav3 mirror reject 2026-09-05); every conjunct and hypothesis of each public statement appears in the mirror (no dropped side conditions such as `n ≥ 2`, `k > 0`, `Even n`); no mirror claims a statement stronger than Lean.
8. **Value check**: instantiate each public statement at one small concrete value in your head (e.g. a=1,q=2 for a Euclid step; n=15 for a totient product) and confirm the rendered formula gives the same value as the Lean definition would.

9. **Header**: the six-line module header is canonical — `GID:` equals the path, `generality:` matches the weakest import, `mirror-B`/`mirror-E` present, **`anchors: []`** unless every listed anchor is a canonical external anchor accepted by SL-015 (theory-volume labels like `PZG-6.217` are NOT canonical anchors → admission red), `digest:` one line under 100 characters ending the comment with `-/` on line 6.

10. **Definitions**: every symbol the atom defines by a formula (kernel, energy, count, predicate) is rendered in the mirror with its defining expression (or the mirror shows the public identity to the atom expression) — never as an opaque `Call("F", …)` abbreviation without definition; compare the rendered expression against the atom text.

11. **Provenance**: if the Describe prose, the Lean docstring, the atom text or the PR body attributes any public statement to a named author / year / paper (e.g. "Moser (1953)", "classical", "Leung–Zhou"), the Scribe node MUST use `AssessedProvenance.FromLiterature(LibraryNoteRef.Create("D5/L/<Area>/<key>"))` with an L-plane note `Library/<Area>/<key>.md` present in the diff (frontmatter: bibkey, authors, year, title, doi/arxiv, claim, strata_touched, license: citation-only, triage: anchor); `FromRepo()` on a statement the text itself calls a known result is a FAIL (quality-seat reject on #5537, 2026-09-05). `git grep -n "FromRepo\|FromLiterature" -- Blueprint/<module>.scribe.cs` and read the Describe prose. The note must carry a `doi:` or `arxiv:` (Scribe refuses DOI-less academic citations); a DOI-less classic must be attested via a DOI-bearing secondary source that states the theorem, with the original attribution inside `claim`.

12. **Import minimality**: for EACH direct `import` line of the module, delete it alone (process substitution, no tracked edit) and recompile with `lake env lean`; an import whose deletion still gives EXIT=0 is a false dependency edge (tests-seat reject on #5537: `Mathlib.Tactic.Ring` and `Lean.Elab.Tactic.Omega` were both redundant). Report the per-import EXIT table.
