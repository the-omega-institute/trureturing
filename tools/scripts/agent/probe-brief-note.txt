- **落盘纪律(放在 brief 最前,不放最后)**:
  **每答完一问、每拿到一批检索读数、每验过一个 Lean 片段,就 `git commit` + `git push`。
  报告边做边写,不要攒到最后。**

  案由(2026-09-09 实测,两席同时死于同一次载体网络断流
  `stream disconnected before completion: Transport error … error decoding response body`,
  `carrier_exit: 1` / `CARRIER_EXIT_NONZERO`):

  **探针的中间产物同样是几十分钟的工作**,而且「报告最后写」使**最脆的一段恰好排在最后**。
  故本条不分阶段:实施 / 探针 / 筛选 / 地图席**一律适用**。

  **辨析(与 openproblem Stage A 的「STOP HERE, 不 commit」不冲突)**:
  那条禁的是**过 deposit/cover 门之前不要冻结与开 PR**,针对的是同一 worktree 里

  凡 brief 明写某阶段不得提交(Stage A 一类),以该 brief 为准,但报告仍须边做边写。
