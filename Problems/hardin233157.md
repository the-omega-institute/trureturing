# Hardin's recurrence for the 4-row three-state sum-exclusion strip

## Problem

[OEIS A233157](https://oeis.org/A233157), by R. H. Hardin, has NAME
(verbatim from the [text export](https://oeis.org/search?q=id:A233157&fmt=text)):

> Number of 4 X n 0..2 arrays with no element x(i,j) adjacent to value 2-x(i,j) horizontally or antidiagonally.

The empirical recurrence in that export is, verbatim:

```text
Empirical: a(n) = 9*a(n-1) - 15*a(n-2) + 6*a(n-3) for n>7.
```

This is row 4 of the table A233155: the height is fixed and the width grows.
A bond joins horizontal neighbours $(i,j),(i,j+1)$ or antidiagonal neighbours
$(i,j+1),(i+1,j)$; its values must have natural-number sum different from
$2$. Every labelled function counts, without normalization. No vertical or
main-diagonal bond condition is imposed.
