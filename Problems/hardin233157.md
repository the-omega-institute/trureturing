# Hardin's recurrence for the 4-row three-state sum-exclusion strip

## Problem

[OEIS A233157](https://oeis.org/A233157), by R. H. Hardin, has NAME
(verbatim from the [text export](https://oeis.org/search?q=id:A233157&fmt=text)):

> Number of 4 X n 0..2 arrays with no element x(i,j) adjacent to value 2-x(i,j) horizontally or antidiagonally.

The empirical recurrence in that export is, verbatim:

```text
Empirical: a(n) = 9*a(n-1) - 15*a(n-2) + 6*a(n-3) for n>7.
```

This is row 4 of the table A233155: the height is fixed and the width grows.
A bond joins horizontal neighbours $(i,j),(i,j+1)$ or antidiagonal neighbours
$(i,j+1),(i+1,j)$; its values must have natural-number sum different from
$2$. Every labelled function counts, without normalization. No vertical or
main-diagonal bond condition is imposed.

1. **Literal-count equivalence.** `U4 n` is `HardinA233155RowTransfer.T n 4`, whose filtered
   cardinality counts all labelled `Fin 4 × Fin n → Fin 3` functions.
   `HardinA233155ColumnTransfer.properEquiv 4 n` applies powers of
   `Fin.revPerm` to the column labels. Exchanging the row binders and
   reversing the corresponding equalities identifies its target predicate
   with `HardinA233259PairTransferCore.Proper`. Cardinality is preserved.
2. **Frozen all-length count.** The private `counting_bridge` directly
   applies `HardinA233259PairTransferCount.count_transfer` and proves
   `(U4 (n + 2) : ℤ) = dotProduct
   HardinA233259PairTransferCore.weights
   ((HardinA233259PairTransferCore.Q ^ n).mulVec 1)`.
   The exponent is `n`; the weights count compatible pairs of columns.
3. **Finite relation in the existing matrix.** `finite_certificate` uses
   `HardinA233259PairTransferPowers.W` and its `powers_table` for `Fin 9`
   to establish
   $Q^7\mathbf1=6Q^4\mathbf1-15Q^5\mathbf1+9Q^6\mathbf1$,
   with $Q$ equal to `HardinA233259PairTransferCore.Q`.
4. **All source indices.** At width 8, the frozen power table evaluates
   powers three through six. For each later width,
   `TransferMatrix.scalarRelationShift` propagates the finite relation;

   A233259 owners. The conclusion settles the external assertion under
   `open-problem-resolution` preregistered in #29231; this route supplies
   no new continuation-induction escape witness.
