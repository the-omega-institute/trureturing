# Barker's generating function for the two-column eight-colour pair-exclusion strip

## Problem

[OEIS A233196](https://oeis.org/A233196), by R. H. Hardin, has NAME

> Number of n X 2 0..7 arrays with no element x(i,j) adjacent to itself or value 7-x(i,j) horizontally, antidiagonally or vertically, top left element zero, and 1 appearing before 2 3 4 5 and 6, 2 appearing before 3 4 and 5, and 3 appearing before 4 in row major order (unlabeled 8-colorings with no clashing color pairs).

and FORMULA

> Conjectures from _Colin Barker_, Oct 10 2018: (Start)
> G.f.: x*(1 - 17*x + 40*x^2) / ((1 - 4*x)*(1 - 16*x)).

Each row is a pair of cells joined by a horizontal bond; consecutive rows are
joined by the two vertical bonds and the antidiagonal bond
$(i,1)$–$(i+1,0)$: a two-leg strip of the triangular lattice. A bond is legal
when its endpoints differ and do not sum to $7$.

## Route

1. **Scanner and pairs.** An eight-colour row-major scanner with seen flags
   for colours $1,2,3$ represents the literal precedence conditions; the map
   $c\mapsto\min(c,7-c)$ onto `Fin 4` turns each bond condition into
   inequality of pair labels.
2. **Classes.** After the first row colour $1$ is always seen. Boundaries are
   grouped by the flags for colours $2$ and $3$: class $0$ (only $1$ seen,
   $2$ boundaries), class $1$ ($1,2$ seen, $6$ boundaries), class $2$
   ($1,2,3$ seen, $12$ boundaries). The unique first row starts in class $0$.
3. **Transfer.** Kernel decisions over single rows give the class matrix
   $T=\begin{pmatrix}0&2&1\\0&4&6\\0&0&16\end{pmatrix}$ and
   $a(n+1)=(T^n\mathbf 1)_0$. The finite relation
   $T^3\mathbf 1=-64\,T\mathbf 1+20\,T^2\mathbf 1$ is propagated by
   `TransferMatrix.scalarRelationShift`, giving
   $a(n+4)=20a(n+3)-64a(n+2)$ and the series identity.

### What the settlement shows

The class matrix is upper triangular with diagonal $(0,4,16)$. A row that
keeps colour $2$ unseen cannot follow another such row (the $0$ entry), so
the first class only feeds the others. The eigenvalue $4$ is the sector with
colours $1$ and $2$ seen but not $3$, and $16$ the sector with all three
seen; these are Barker's factors $1-4x$ and $1-16x$. The degree-three
numerator reflects the nilpotent first class, which is why Hardin's
recurrence starts only at $n>3$.
