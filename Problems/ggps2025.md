# The reverse Mittag-Leffler modulus characterization is false

## Problem

Garrappa, Gerhold, Popolizio and Simon, *On some inequalities for the
two-parameter Mittag-Leffler function in the complex plane*, arXiv:2410.11852v4,
p. 18, Conjecture 25 (journal DOI 10.1016/j.jmaa.2025.129588):

> For every α ∈ (1, 2), one has
> The inequality (1.4) holds globally ⇐⇒ β ∈ [α − 1, α] ⇐⇒ 1/Eα,β(x) is CM on (0, ∞).

Here $\beta\ge0$, and (1.4) is
$|E_{\alpha,\beta}(z)|\ge E_{\alpha,\beta}(\operatorname{Re}z)$ for every
$z\in\mathbb C$. Equation (1.1), p. 1, defines
$E_{\alpha,\beta}(z)=\sum_{k=0}^{\infty}z^k/\Gamma(\alpha k+\beta)$ for
$\alpha>0$ and every real $\beta$. The reciprocal Gamma value at a pole is
zero. Complete monotonicity means a smooth positive-valued function on
$(0,\infty)$ whose signed derivatives of all natural orders are nonnegative.

## Route

For each $1<\alpha<2$, set $\eta=\pi(2-\alpha)/4$, $t=\tan\eta$ and
$w=-1+it$. The literal source series is identified with the Barnes integral
on the one-half line using actual residues, horizontal decay and the
moving-left limit. Shifting right through one and two gives
$E_{\alpha,\alpha-1}(z)=c_\alpha/z^2+R(z)$, where
$c_\alpha=\alpha(\alpha-1)(\alpha+1)/\Gamma(2-\alpha)>0$.
The first reciprocal-Gamma coefficient is zero. The actual five-halves-line
integral bounds $R(rw)$ by a fixed constant times $r^{-5/2}$.

Consequently the scaled negative-axis real part tends to $c_\alpha$ and
the scaled ray norm tends to $c_\alpha/(1+t^2)$. Their strict gap supplies
one finite positive radius $r$. Only after choosing $z_\alpha=rw$ does
beta-continuity supply $0<\epsilon_\alpha<1$, so that the strict deficit
holds at that same point for every beta in the closed interval
$[\alpha-1,\alpha-1+\epsilon_\alpha]$.
