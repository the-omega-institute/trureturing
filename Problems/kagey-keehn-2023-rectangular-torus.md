# Rectangular-torus rotation descent

The source conjecture asks whether a plane tiling represented by an n x m torus and fixed by a translated 90-degree rotation, inverse rotation, diagonal reflection, or anti-diagonal reflection is equivalent to a gcd(n,m) x gcd(n,m) torus tiling.

The formal statement keeps an arbitrary tile type T, the source function on ZMod n x ZMod m, its literal integer-plane lift, the source right-action coordinate maps, arbitrary translation and tile-design action, and the exact pointwise plane equivalence. It covers unit and unequal dimensions and does not claim square minimality.

The settling declaration is `D5/S3/Combinatorics/KageyKeehnRectangularTorus.rectangular_torus_gcd_descent`. Stage A contains the D5 source and Blueprint Scribe; freeze, deposit, and publication remain separate.
