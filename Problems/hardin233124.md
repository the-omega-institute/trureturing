# Barker's generating function for the three-column six-colour pair-exclusion square strip

## Problem

[OEIS A233124](https://oeis.org/A233124), by R. H. Hardin, has NAME

> Number of n X 3 0..5 arrays with no element x(i,j) adjacent to itself or value 5-x(i,j) horizontally or vertically, top left element zero, and 1 appearing before 2 3 and 4, and 2 appearing before 3 in row major order (unlabelled 6-colorings with no clashing color pairs).

and FORMULA

> Conjectures from _Colin Barker_, Mar 19 2018: (Start)
> G.f.: x*(3 - 64*x + 192*x^2) / ((1 - 8*x)*(1 - 40*x + 128*x^2)).

Each row is a path of three cells, and consecutive rows are joined by the
three vertical bonds $(i,j)$–$(i+1,j)$: a three-leg strip of the square
lattice. A bond is legal when its endpoints differ and do not sum to $5$.

### What the settlement shows

The class transfer matrix is block triangular. The sector before colour $2$
is one-dimensional with eigenvalue $8$: only the pairs $\{0,5\}$ and
$\{1,4\}$ are available, so each row has $2^3$ continuations and the factor
$1-8x$ appears. Once all three pairs are available, the two classes with
equal and different end labels form the block
$\begin{pmatrix}24&16\\16&16\end{pmatrix}$ with characteristic polynomial
$t^2-40t+128$, which is Barker's second factor $1-40x+128x^2$. The
numerator records the initial distribution $(2,0,1)$ over the classes.
