# Mathar's generating function for the four-column six-colour pair-exclusion square strip

## Problem

[OEIS A233125](https://oeis.org/A233125), by R. H. Hardin, has NAME

> Number of nX4 0..5 arrays with no element x(i,j) adjacent to itself or value 5-x(i,j) horizontally or vertically, top left element zero, and 1 appearing before 2 3 and 4, and 2 appearing before 3 in row major order (unlabeled 6-colorings with no clashing color pairs).

and FORMULA

> Empirical: a(n) = 160*a(n-1) -6144*a(n-2) +86016*a(n-3) -393216*a(n-4).
>
> Empirical: G.f.: -2*x*(-5+352*x-7168*x^2+40960*x^3) / ( (16*x-1)*(24576*x^3-3840*x^2+144*x-1) ). - _R. J. Mathar_, Oct 31 2015

Each row is a path of four cells, and consecutive rows are joined by the
four vertical bonds $(i,j)$–$(i+1,j)$: a four-leg strip of the square
lattice. A bond is legal when its endpoints differ and do not sum to $5$.

### What the settlement shows

The class transfer matrix is block triangular. The sector before colour $2$
is one-dimensional with eigenvalue $16$: only the pairs $\{0,5\}$ and
$\{1,4\}$ are available, so each row has $2^4$ continuations and the factor
$1-16x$ appears. Once all three pairs are available, the three remaining
classes form the block
$\begin{pmatrix}48&64&16\\32&64&16\\16&32&32\end{pmatrix}$ with trace $144$,
second invariant $3840$ and determinant $24576$; its characteristic
polynomial $t^3-144t^2+3840t-24576$ gives Mathar's cubic factor. The
numerator records the initial distribution $(4,0,4,2)$. In the three
square-strip widths settled so far, the post-colour-$2$ sector has dimension
one, two and three; the number of boundary classes needed grows with the
width, so the class route does not by itself bound the order for wider
strips.
