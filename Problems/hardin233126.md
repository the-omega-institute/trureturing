# Hardin's recurrence for the five-column six-colour pair-exclusion square strip

## Problem

[OEIS A233126](https://oeis.org/A233126), by R. H. Hardin, has NAME

> Number of nX5 0..5 arrays with no element x(i,j) adjacent to itself or value 5-x(i,j) horizontally or vertically, top left element zero, and 1 appearing before 2 3 and 4, and 2 appearing before 3 in row major order (unlabelled 6-colorings with no clashing color pairs).

and FORMULA

> Empirical: a(n) = 544*a(n-1) -82944*a(n-2) +5144576*a(n-3) -146800640*a(n-4) +1879048192*a(n-5) -8589934592*a(n-6)

Each row is a path of five cells, and consecutive rows are joined by the
five vertical bonds $(i,j)$–$(i+1,j)$: a five-leg strip of the square
lattice. A bond is legal when its endpoints differ and do not sum to $5$.

### What the settlement shows

The class transfer is block triangular. The sector before colour $2$ is
one-dimensional with eigenvalue $32$: only the pairs $\{0,5\}$ and
$\{1,4\}$ are available, so each row has $2^5$ continuations, giving the
factor $x-32$ of Hardin's polynomial. After colour $2$ the six orbit classes
have characteristic polynomial
$(x+32)(x^5-512x^4+66560x^3-3014656x^2+50331648x-268435456)$. The mode
$-32$ is not excited by the first-row distribution, so the count satisfies
the order-six recurrence $(x-32)$ times the quintic, which is exactly
Hardin's. Across the square strips of widths two to five the sector after
colour $2$ has dimension one, two, three and six (five after the unexcited
mode is removed); the class count grows with the number of
relabelling-and-reversal orbits of proper label rows, so the class route alone does not bound the
order for wider strips.
