# Hardin's recurrence for the $3\times n$ 1-defect three-colour strip

## Problem

[OEIS A229536](https://oeis.org/A229536), by R. H. Hardin, has NAME

> Number of defective 3-colorings of a 3 X n 0..2 array connected horizontally, diagonally and antidiagonally with exactly one mistake, and colors introduced in row-major 0..2 order.

and the empirical recurrence

> Empirical: a(n) = 6*a(n-1) - a(n-2) - 28*a(n-3) - 4*a(n-4) + 16*a(n-5) - 4*a(n-6) for n>8.

Both quotations are from the [OEIS text export](https://oeis.org/search?q=id:A229536&fmt=text).
The assertion registered in
[issue #31121](https://github.com/the-omega-institute/trureturing/issues/31121)
is this recurrence for every $n\ge 9$, with the array shape and
fixed defect budget stated in the NAME. The source's `result` has exactly
that range.

For an array $f:\operatorname{Fin}r\times\operatorname{Fin}c\to\operatorname{Fin}3$, a defect is a bond whose endpoint colours agree. The HDA bonds are
$(i,j)$--$(i,j+1)$, $(i,j)$--$(i+1,j+1)$, and
$(i,j+1)$--$(i+1,j)$ whenever both endpoints lie in the array. There is no
vertical bond. Every bond changes the column index by one, so the array is
bipartite between even and odd columns, and every interior site has six
neighbours.

## Motivation

The settling declaration is
`D5/S3/StatisticalMechanics/Potts/CrossedStripDefects/HardinA229536Strip.result`.
The external assertion is preregistered in
[issue #31121](https://github.com/the-omega-institute/trureturing/issues/31121);
the source note has bibkey `hardin2013a229536`.

With antiferromagnetic Potts energy, each monochromatic bond contributes a positive unsatisfied-bond cost when $J>0$.
These canonical colourings are states of the three-state Potts
antiferromagnet with exactly $1 unsatisfied bonds on the
horizontal--diagonal strip without vertical bonds (HDA). The HDA graph is
bipartite by column parity and has six neighbours at an interior site.
The row-major condition chooses one representative for each global colour
relabeling orbit in the nonconstant range used by the proof. The theorem is
a finite combinatorial statement under this bond and energy convention.

## Gap

The OEIS formula is labelled empirical. The registered target is its
validity for every $n\ge 9$ from the literal array definition;
agreement with finitely many sequence terms does not supply that statement.

The literature check (the OEIS entry and its links; arXiv searches for Potts strips with unsatisfied bonds and for defective colourings; Chang–Salas–Shrock, J. Stat. Phys. 107 (2002) 1207–1253, which treats rectangular square-lattice strips) located no proof of this recurrence.
Worldwide priority and literature completeness remain unverified.

## Route

1. **Literal count and normalization.** `a` filters every `Fin 3 × Fin n → Fin 3` array by exactly one HDA defect and the lifted row-major canonical predicate.
2. **Column transfer.** The source explicitly sweeps columns. A transfer letter is a three-cell column; `between` is the seven horizontal, diagonal, and antidiagonal bonds from one column to the next, while the internal `horizontal` set is empty in this column presentation. The eight classes record the four `HardinColumnContinuations.classH` equality classes at residual budgets one and zero. The matrix uses `HardinColumnContinuations.Hfull` in both proper blocks, with the explicit defect transitions in the off-diagonal block. The finite certificate checks terminal acceptance, budget preservation, every transition, initialization, cached forward vectors, and the polynomial relation.
3. **Propagation.** `DefectTransfer.lumped_count` identifies the labelled column count with the matrix-power scalar product, and `DefectTransfer.forward_shift` propagates the relation. The row-major canonical count is recovered through the six-element colour orbit bridge, giving the recurrence at every index at least nine.

## Falsifier

A canonical HDA count at some $n\ge 9$ that violated the displayed recurrence, or a failed seven-bond column transition or class-continuation identity, would contradict the result theorem.

## Evidence

The source's eight-class column-sweep certificate calls the public `HardinColumnContinuations.classH` and `Hfull` tables, then exact-budget lumping and forward propagation prove the literal canonical recurrence.
