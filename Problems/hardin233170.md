# Barker's full generating function for Hardin's four-column diagonal strip

## Problem

[OEIS A233170](https://oeis.org/A233170), revision 10, has NAME

> Number of n X 4 0..5 arrays with no element x(i,j) adjacent to itself or value 5-x(i,j) horizontally, diagonally or antidiagonally, top left element zero, and 1 appearing before 2 3 and 4, and 2 appearing before 3 in row major order (unlabeled 6-colorings with no clashing color pairs).

The FORMULA block states

> Empirical: a(n) = 128*a(n-1) - 2816*a(n-2) + 16384*a(n-3).

> Empirical g.f.: 2*x*(5 - 240*x + 2048*x^2) / ((1 - 16*x)*(1 - 112*x + 1024*x^2)). - _Colin Barker_, Oct 10 2018

The source OFFSET is `1,1`. The target is the entire identity

$$
\sum_{n\geq 1} a(n)X^n
=2X(5-240X+2048X^2)\bigl((1-16X)(1-112X+1024X^2)\bigr)^{-1}
\quad\text{in }\mathbb{Q}[[X]].
$$

| Source clause | Formal counterpart |
| --- | --- |
| Every positive height, four columns, colours zero through five | `a n` independently counts all functions `Fin n × Fin 4 → Fin 6` satisfying `Legal` |
| Horizontal neighbours | `rowLegal` checks all three adjacent column pairs |
| Diagonally and antidiagonally | `bonds` checks both diagonals between each pair of consecutive rows |
| No equal or complementary colours on a constrained bond | Endpoints differ and their natural values do not sum to five |
| Upper-left zero | `Legal` requires the cell in row zero, column zero to be zero |
| Earlier 1 for every 2, 3 or 4; earlier 2 for every 3 | `Normal` uses strict rank `4*row+column`; absent colours are allowed |
| Literal source count | Vertical and wraparound bonds are unconstrained; there is no orbit divisor |
| Whole generating function | `result` includes the numerator and all coefficients; the added constant is zero and the first positive counts are 10, 800, 78336 |

The zero-height coefficient is the formal-series convention, not an additional source assertion about height zero. The denominator has constant coefficient one.
