# Hardin's seven-lag recurrence for literal five-row arrays

## Problem

R. H. Hardin's [OEIS A233260](https://oeis.org/A233260), revision 7,
has the following NAME and FORMULA in its
[immutable official export](https://raw.githubusercontent.com/oeis/oeisdata/571197984aeda7b8b680fe3a1f6a43f9898cd441/seq/A233/A233260.seq):

> Number of 5Xn 0..5 arrays with no element x(i,j) adjacent to itself or value 5-x(i,j) horizontally or antidiagonally, top left element zero, and 1 appearing before 2 3 and 4, and 2 appearing before 3 in row major order (unlabeled 6-colorings with no clashing color pairs).

> Empirical: a(n) = 512*a(n-1) -65536*a(n-2) +2490368*a(n-3) +17825792*a(n-4) -2818572288*a(n-5) +51539607552*a(n-6) -274877906944*a(n-7) for n>11

For every natural width n>=1, count every function
`Fin 5 × Fin n → Fin 6` satisfying precisely these conditions. Horizontal
bonds join (r,j) and (r,j+1); antidiagonal bonds join (r,j+1) and (r+1,j).
Bond endpoints differ and their natural values do not sum to five. The first
cell is zero. Every occurrence of 2, 3 or 4 has an earlier 1, and every 3
has an earlier 2, with strict row-major rank r*n+j. Colours may be absent.
The natural counts are cast to integers in the seven-lag equality, which
holds for every integer n>11. No assertion about a(0), generating functions,
surjectivity, extra bonds, finite cutoff or computational resources is part
of this event.

### Statement correspondence

`normal` expresses exactly the strict predecessors; `Legal` adds the first
cell and the two bond directions. `a` filters all functions by `Legal` and
takes their finite cardinality. `result` quantifies integers n with 11<n,
uses `Int.toNat` for the positive count indices, and has exactly the seven
signed coefficients in the source. No transposition or orbit division is
inserted into the definition of the count.

## Route

The complementary pairs {0,5}, {1,4}, {2,3} become three pair labels.
The existing `HardinA233251TriangleStrip.colour_bond_iff` identifies bond
legality with differing labels; `HardinA233177Canonical` supplies general
first-occurrence normalization and fibre counting. The new all-width
classification proves that every proper two-label pattern has constant
columns alternating between its labels, including the last column. Exactly
one is canonical. A canonical pattern using k labels has 2^(5*n-k) lifts.
Combining the two-label and three-label sectors proves
`counting_bridge`: for n>=2,

    48 * a(n) = 32^n * (L(n) + 6).

Here L counts all proper three-label patterns on the same five-by-n domain.
Five-cell column states have forty-one classes under label permutations.
Exact initial and transition counts connect their matrix Q to L using
`TransferMatrix.cardMatrix`. The vector polynomial

    x^7 - 16*x^6 + 64*x^5 - 76*x^4 - 17*x^3 + 84*x^2 - 48*x + 8

annihilates the relevant vector after four transitions. Its value at one is
zero, so the correction term six obeys the same scalar recurrence.
`TransferMatrix.scalarRelationShift` propagates the vector identity to all
later indices. The finite power table separately verifies index twelve;
scaling each lag by the corresponding power of thirty-two proves the source
recurrence at every integer n>11. The table is a finite certificate for an
unbounded argument, not a finite-width replacement of the event.
