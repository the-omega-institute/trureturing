# Hardin's recurrence for the 6-row three-state sum-exclusion strip

## Problem

[OEIS A233159](https://oeis.org/A233159), by R. H. Hardin, has NAME
(verbatim from the [text export](https://oeis.org/search?q=id:A233159&fmt=text)):

> Number of 6Xn 0..2 arrays with no element x(i,j) adjacent to value 2-x(i,j) horizontally or antidiagonally.

The empirical recurrence in that export is, verbatim:

```text
Empirical: a(n) = 30*a(n-1) -283*a(n-2) +1038*a(n-3) -573*a(n-4) -6705*a(n-5) +21056*a(n-6) -27636*a(n-7) +17216*a(n-8) -4128*a(n-9) for n>15
```

This is row 6 of the table A233155: the height is fixed and the width grows.
A bond joins horizontal neighbours $(i,j),(i,j+1)$ or antidiagonal neighbours
$(i,j+1),(i+1,j)$; its values must have natural-number sum different from
$2$. Every labelled function counts, without normalization. No vertical or
main-diagonal bond condition is imposed.

## Gap

A finite match leaves the all-index assertion unresolved by itself. The

## Route

1. **Unrestricted-column transfer.** The columns are all functions
   `Fin 6 → Fin 3`; there is no vertical bond.
   `HardinA233155ColumnTransfer.columnCompatible` checks exactly the
   horizontal and antidiagonal bonds between consecutive columns, and
   `grid_good` identifies literal legal arrays with compatible column lists.
2. **Equality-pattern quotient.** `HardinA233159Rows` defines the literal
   count `U6`, the 122 equality classes and their representatives by reusing
   `HardinA233179PairTransfer.orbit` and its representatives. The constant
   class has labelled weight 3; every other class has weight 6.
   `HardinA233159RowCertificate.quotient_certificate` verifies the successor
   multiplicities, initial weights and sparse matrix action, using
   `HardinA233155ColumnTransfer.quotient_rows` for the class transport.
3. **Finite power relation.** The power table in `HardinA233159Row`, checked
   through `TransferMatrix.tabulatedPowers`, supplies
   $Q^{15}\mathbf1=\sum_{j=0}^{8}c_jQ^{6+j}\mathbf1$, where
   $(c_0,\ldots,c_8)=(-4128,17216,-27636,21056,-6705,-573,1038,-283,30)$.
   Its `finite_certificate` combines that relation with the quotient and
   initial-weight identities from `quotient_certificate`.
4. **All-length counting and propagation.** The private `counting_bridge`
   applies `HardinA233155ColumnTransfer.count_transfer` to prove
   `(U6 (n + 2) : ℤ) = dotProduct weights
   ((quotient ^ (n + 1)).mulVec (1 : Fin 122 → ℤ))`.
   That generic theorem uses `TransferMatrix.cardMatrix`, whose live proof
   uses the private `TransferMatrix.cont_matrix` induction over arbitrary
   continuation length. `TransferMatrix` is unfrozen.
   `TransferMatrix.scalarRelationShift` shifts the certified vector relation
   by every natural `n`; the counting bridge gives the recurrence at width
   `n + 16`. The finite certificate and the continuation induction have
   these separate roles in the proof.

## Falsifier

A width $m\ge16$ at which the literal 6-row count violates the quoted
recurrence would contradict `result`, with its natural parameter set to
$m-16$. A mismatch in a model with additional bonds or label
normalization would test a different count.
