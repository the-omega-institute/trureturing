# Hardin's recurrence for the $4\times n$ one-defect three-colour strip

## Problem

[OEIS A229537](https://oeis.org/A229537), by R. H. Hardin, has NAME

> Number of defective 3-colorings of a 4 X n 0..2 array connected horizontally, diagonally and antidiagonally with exactly one mistake, and colors introduced in row-major 0..2 order.

and the empirical recurrence

> Empirical: a(n) = 6*a(n-1) + 23*a(n-2) - 102*a(n-3) - 288*a(n-4) + 250*a(n-5) + 787*a(n-6) - 238*a(n-7) - 741*a(n-8) + 124*a(n-9) + 196*a(n-10) - 16*a(n-11) - 16*a(n-12) for n > 14.

Both quotations are from the [OEIS text export](https://oeis.org/search?q=id:A229537&fmt=text).
The assertion registered in [issue #31548](https://github.com/the-omega-institute/trureturing/issues/31548) is this order-12 recurrence for every $n\ge 15$, with four rows, $n$ columns and exactly one monochromatic bond. The sequence offset is one. The source's `result t`, for every `t : Nat`, states the displayed integer recurrence at index $t+15$.

For an array $f:\operatorname{Fin}4\times\operatorname{Fin}n\to\operatorname{Fin}3$, a defect is a bond whose endpoint colours agree. The HDA bonds are $(i,j)$--$(i,j+1)$, $(i,j)$--$(i+1,j+1)$, and $(i,j+1)$--$(i+1,j)$, with both endpoints restricted to the array. There are no vertical bonds or periodic boundary bonds. Every bond crosses between adjacent columns, so column parity gives a bipartition; an interior site has six neighbours.

The source sweeps columns. Its generic transfer represents the array with exchanged coordinates, so the swept representation has the transposed bonds: vertical, diagonal and antidiagonal. In the original $4\times n$ coordinates these remain the HDA bonds above. The source's within-slice set `horizontal` is empty, and `between` contains the ten ordered row-index pairs $(r,s)$ with $|r-s|\le1$ between consecutive four-site columns. The row-major normalization retains the original rank $i n+j$.

A229537 is the four-row counterpart of the settled three-row A229536, registered in [#31121](https://github.com/the-omega-institute/trureturing/issues/31121) and merged in [#31278](https://github.com/the-omega-institute/trureturing/pull/31278). A229640 is the two-defect block extension of A229537.

## Motivation

The settling declaration is `D5/S3/StatisticalMechanics/Potts/CrossedStripDefectsWide/P4a/HardinA229537Strip.result`. The external assertion is preregistered in [issue #31548](https://github.com/the-omega-institute/trureturing/issues/31548); the source note has bibkey `hardin2013a229537`.

For antiferromagnetic Potts energy $E(f)=J\sum_{\{u,v\}\in B}\mathbf{1}_{f(u)=f(v)}$ with $J>0$, these canonical colourings are states of the three-state Potts antiferromagnet with exactly $D=1$ unsatisfied bonds on the horizontal--diagonal--antidiagonal strip without vertical bonds (HDA). The row-major condition selects one representative from each global colour relabelling orbit. In the nonconstant range used by the proof, the labelled count is six times the canonical count. The theorem concerns finite strips under this bond and energy convention.

## Gap

The OEIS formula is labelled empirical. The registered target is its validity for every $n\ge 15$ from the literal canonical array definition; agreement with finitely many terms does not supply that statement.

The literature check (the OEIS entry and its links; arXiv searches for Potts strips with unsatisfied bonds and for defective colourings; Chang–Salas–Shrock, J. Stat. Phys. 107 (2002) 1207–1253, which treats rectangular square-lattice strips) located no proof of this recurrence.
The literature scope is the one recorded in #31548. Literature completeness and worldwide priority remain unverified.

## Route

1. **Literal count and normalization.** `a` filters every original `Fin 4 × Fin n → Fin 3` array by exactly one monochromatic bond and the lifted row-major canonical predicate. `DefectTransfer.relabel_defects` gives colour-permutation invariance. Coordinate exchange is applied only to labelled arrays; the frozen `HardinA233177Canonical.canonical_pattern_card` supplies the six-to-one orbit bridge back to the original row-major arrays. A constant $4\times(m+1)$ array has $10m$ HDA bonds, so for $m\ge1$ it cannot have the prescribed defect budget. The labelled count is therefore six times the canonical count throughout the recurrence's range.
2. **Exact-budget transfer and frozen owners.** There are 14 column colour-pattern classes for each residual budget $d=1,0$, giving 28 states. `HardinA229537StripData.cl`, `initial` and `terminal` reuse the frozen `HardinA229589StripData` owner. `HardinA229589StripCertificate.structural_certificate` supplies terminal acceptance and initialization. With $Q=\operatorname{HardinA233177PairTransfer.Q}$, the matrix is $\begin{pmatrix}Q&B_1\\0&Q\end{pmatrix}$, where $B_1$ counts transitions using exactly one defect. The frozen `HardinA233177PairTransfer.quotient_rows` supplies the zero-defect transitions. `HardinA229537StripCertificate.one_counts` transports the finite representative counts to all labelled columns, using `HardinA233125SquareStrip.label_sum`.
3. **Finite relation and propagation.** The frozen `HardinA233177PairTransfer` owner supplies the zero-defect power table and degree-six relation, propagated by `TransferMatrix.vector_relation_shift`. The certificate's `powers` table combines this inherited tail with the one-defect coordinates. Its `finite_certificate` proves the class transitions and $T^{14}v=\sum_{k=0}^{11}c_kT^{2+k}v$, where the $c_k$ are the displayed recurrence coefficients in increasing-power order. `DefectTransfer.lumped_count` gives the labelled count as $u^{\mathsf T}T^m v$. The result multiplies the vector identity by $T^n$, takes the initial-vector scalar product, applies the six-to-one bridge and cancels six over $\mathbb Z$. The canonical recurrence holds at every index at least $15$.

## Falsifier

A literal row-major canonical HDA count at some $n\ge 15$ that violated the displayed recurrence, or a failed class-transition, terminal, initialization or vector-relation identity used by the source, would contradict the result theorem.
