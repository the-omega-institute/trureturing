# Hardin's recurrence for the $5\times n$ two-defect three-colour strip

## Problem

R. H. Hardin's OEIS entry gives this name. [OEIS A229641](https://oeis.org/A229641)

> Number of defective 3-colorings of a 5 X n 0..2 array connected horizontally, diagonally and antidiagonally with exactly two mistakes, and colors introduced in row-major 0..2 order.

The entry gives this empirical recurrence.

> Empirical: a(n) = 18*a(n-1) - 15*a(n-2) - 1191*a(n-3) + 3468*a(n-4) + 31983*a(n-5) - 108707*a(n-6) - 424479*a(n-7) + 1614489*a(n-8) + 2851598*a(n-9) - 13478352*a(n-10) - 7797810*a(n-11) + 66347438*a(n-12) - 12632640*a(n-13) - 190067859*a(n-14) + 147888798*a(n-15) + 287096430*a(n-16) - 412178619*a(n-17) - 138135927*a(n-18) + 522690894*a(n-19) - 168525432*a(n-20) - 273411640*a(n-21) + 227616084*a(n-22) + 9610272*a(n-23) - 73617984*a(n-24) + 21460464*a(n-25) + 7359984*a(n-26) - 4611168*a(n-27) + 186624*a(n-28) + 279936*a(n-29) - 46656*a(n-30) for n > 33.

Issue #32224 quotes both lines from OEIS and registers the order-30 recurrence for every $n\ge 34$, with five rows, $n$ columns and exactly two monochromatic bonds. The sequence offset is one. [Issue #32224](https://github.com/the-omega-institute/trureturing/issues/32224)

A defect is a bond whose endpoints have the same colour. The horizontal, diagonal and antidiagonal (HDA) bonds are $(i,j)$–$(i,j+1)$, $(i,j)$–$(i+1,j+1)$ and $(i,j+1)$–$(i+1,j)$, with both endpoints in the array. All bonds cross between consecutive columns. Each cut has thirteen bonds, indexed by the ordered row pairs $(r,s)$ with $|r-s|\le 1$.

The transfer sweeps columns. In its exchanged coordinates the bonds are vertical, diagonal and antidiagonal, and the within-slice bond set is empty. The canonical filter uses the original row-major rank $in+j$. A colouring satisfies this filter if every colour smaller than the colour at a given cell occurs at some earlier cell. For a nonempty array this forces the first cell to have colour zero and orders the first appearances of all colours used.

## Motivation

The settling declaration is `D5/S3/StatisticalMechanics/Potts/CrossedStripDefectsWide/P5a/HardinA229641Strip.result`. The source note has bibkey `hardin2013a229641`.

For the three-state Potts antiferromagnet with energy $J$ times the number of monochromatic bonds, where $J>0$, the count gives the number of colour relabelling orbits of finite-strip configurations with energy $2J$. The canonical predicate chooses one representative per orbit.
