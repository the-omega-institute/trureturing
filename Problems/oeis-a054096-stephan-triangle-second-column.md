# Stephan's A054096 second-column conjecture

## Problem

OEIS A054096, NAME (`%N`, verbatim):

> T(n,2), array T as in A054090.

Ralf Stephan's target COMMENT (`%C`, verbatim):

> Conjecture: sequence is A006183 shifted right. - _Ralf Stephan_, Jan 15 2004

OEIS A054090, NAME (`%N`, verbatim):

> Triangular array generated by its row sums: T(n,0) = 1 for n >= 0, T(n,1) = r(n-1), T(n,k) = T(n,k-1) - (-1)^k * r(n-k) for k = 2, 3, ..., n, n >= 2, r(h) = sum of the numbers in row h of T.

OEIS A054090, FORMULA (`%F`, verbatim):

> T(n, k) = T(n, k-1) - (-1)^k * Sum_{j=0..n-k} T(n-k, j), with T(n, 0) = 1, and T(n, 1) = Sum_{j=0..n-1} T(n-1, j).

OEIS A006183, NAME (`%N`, verbatim):

> a(n) = (n+1)*a(n-1) + (2-n)*a(n-2).

The literal proved statement is

`forall T B, IsA054090Triangle T -> IsShiftedA006183 B -> forall n, 2 <= n -> T n 2 = B (n - 1)`.

A054096 has offset 2 and A006183 has offset 1, and their `%S` and `%T` data
lines are term-for-term identical. Thus "shifted right" means
`A054096(n) = A006183(n-1)` for `n >= 2`. Writing `B(j) = a(j-1)` turns
A006183's recurrence into
`B(j) = j*B(j-1) + (3-j)*B(j-2)`, exactly the recurrence encoded by
`IsShiftedA006183`.

Not claimed here are other columns of A054090; the row-sum sequence A054091;
the generating-function form of A006183, including Gladkovskii's 2013
continued fraction `%F`, or its equivalence to the recurrence; or any
particular term of A054096.

## Motivation

Ralf Stephan stated the conjecture in January 2004. It had remained
unsettled for 22 years when this proof was checked in 2026. The result
identifies the complete second column from the defining row-sum equations,
while the row-sum invariant is reusable for the triangle's other columns and
for later work on A054091.

## Route

The cross-row induction proves that an entry in one row is the difference
between the first column and the next column of the following row. Summing
these identities across a row telescopes and yields the public invariant
`rowSum(T,n+1) = n*rowSum(T,n) + 2`.

The second-column defining equation identifies `T(n,2)` with the difference
of two successive row sums. A strong induction then shows that these
differences satisfy the shifted A006183 initial values and recurrence. The
two identities combine to give `T(n,2) = B(n-1)` for every `n >= 2`.

## Falsifier

A pair of integer-valued functions `T` and `B` satisfying the two stated
predicates, together with a natural `n >= 2` for which
`T(n,2) != B(n-1)`, would contradict `result`. A triangle satisfying
`IsA054090Triangle` and an index `n` whose row sums violate
`rowSum(T,n+1) = n*rowSum(T,n) + 2` would contradict the reusable lemma.
