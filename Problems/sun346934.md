# Sun A346934 composite-modulus permanent congruence

## Problem

OEIS A346934 revision 29, Conjecture 1, states:

> Conjecture 1: (-1)^n*a(n) > 0 for all n > 0. Also, a(n) == 0 (mod 2n+1) if 2n+1 is composite.

The NAME is:

> Permanent of the 2n X 2n matrix with the (i,j)-entry i-j (i,j=1..2n).

Only the sentence beginning “Also” is settled. The offset $1,2$ fixes $n\ge1$. Preregistration [#22031](https://github.com/the-omega-institute/trureturing/issues/22031) fixes the statement and its literature scope. The [source note](../Library/Factorization/sun2021a346934.md) cites the OEIS entry; arXiv:2108.07723v7 is background and does not contain this conjectural sentence.
