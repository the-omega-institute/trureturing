# Hardin's recurrence for the $n\times 3$ 2-defect three-colour strip

## Problem

[OEIS A229632](https://oeis.org/A229632), by R. H. Hardin, has NAME

> Number of defective 3-colorings of an nX3 0..2 array connected horizontally, diagonally and antidiagonally with exactly two mistakes, and colors introduced in row-major 0..2 order.

and the empirical recurrence

> Empirical: a(n) = 15*a(n-1) -81*a(n-2) +185*a(n-3) -162*a(n-4) +60*a(n-5) -8*a(n-6) for n>7.

Both quotations are from the [OEIS text export](https://oeis.org/search?q=id:A229632&fmt=text).
The assertion registered in
[issue #31121](https://github.com/the-omega-institute/trureturing/issues/31121)
is this recurrence for every $n\ge 8$, with the array shape and
fixed defect budget stated in the NAME. The source's `result` has exactly
that range.

For an array $f:\operatorname{Fin}r\times\operatorname{Fin}c\to\operatorname{Fin}3$, a defect is a bond whose endpoint colours agree. The HDA bonds are
$(i,j)$--$(i,j+1)$, $(i,j)$--$(i+1,j+1)$, and
$(i,j+1)$--$(i+1,j)$ whenever both endpoints lie in the array. There is no
vertical bond. Every bond changes the column index by one, so the array is
bipartite between even and odd columns, and every interior site has six
neighbours.

## Motivation

The settling declaration is
`D5/S3/StatisticalMechanics/Potts/CrossedStripDefects/HardinA229632Strip.result`.
The external assertion is preregistered in
[issue #31121](https://github.com/the-omega-institute/trureturing/issues/31121);
the source note has bibkey `hardin2013a229632`.

With antiferromagnetic Potts energy, each monochromatic bond contributes a positive unsatisfied-bond cost when $J>0$.
These canonical colourings are states of the three-state Potts
antiferromagnet with exactly $2 unsatisfied bonds on the
horizontal--diagonal strip without vertical bonds (HDA). The HDA graph is
bipartite by column parity and has six neighbours at an interior site.
The row-major condition chooses one representative for each global colour
relabeling orbit in the nonconstant range used by the proof. The theorem is
a finite combinatorial statement under this bond and energy convention.
