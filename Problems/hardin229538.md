# Hardin's recurrence for the $5\times n$ one-defect three-colour strip

## Problem

R. H. Hardin's OEIS entry gives this name. [OEIS A229538](https://oeis.org/A229538)

> Number of defective 3-colorings of a 5 X n 0..2 array connected horizontally, diagonally and antidiagonally with exactly one mistake, and colors introduced in row-major 0..2 order.

The entry gives this empirical recurrence.

> Empirical: a(n) = 12*a(n-1) + 26*a(n-2) - 566*a(n-3) - 123*a(n-4) + 8804*a(n-5) - 4121*a(n-6) - 59620*a(n-7) + 55115*a(n-8) + 183692*a(n-9) - 256127*a(n-10) - 211910*a(n-11) + 498819*a(n-12) - 48036*a(n-13) - 371692*a(n-14) + 214008*a(n-15) + 43848*a(n-16) - 64656*a(n-17) + 8640*a(n-18) + 5184*a(n-19) - 1296*a(n-20) for n > 22.

Issue #32224 quotes both lines from OEIS and registers the order-20 recurrence for every $n\ge 23$, with five rows, $n$ columns and exactly one monochromatic bond. The sequence offset is one. [Issue #32224](https://github.com/the-omega-institute/trureturing/issues/32224)

A defect is a bond whose endpoints have the same colour. The horizontal, diagonal and antidiagonal (HDA) bonds are $(i,j)$–$(i,j+1)$, $(i,j)$–$(i+1,j+1)$ and $(i,j+1)$–$(i+1,j)$, with both endpoints in the array. All bonds cross between consecutive columns. Each cut has thirteen bonds, indexed by the ordered row pairs $(r,s)$ with $|r-s|\le 1$.

The transfer sweeps columns. In its exchanged coordinates the bonds are vertical, diagonal and antidiagonal, and the within-slice bond set is empty. The canonical filter uses the original row-major rank $in+j$. A colouring satisfies this filter if every colour smaller than the colour at a given cell occurs at some earlier cell. For a nonempty array this forces the first cell to have colour zero and orders the first appearances of all colours used.

## Motivation

The settling declaration is `D5/S3/StatisticalMechanics/Potts/CrossedStripDefectsWide/P5a/HardinA229538Strip.result`. The source note has bibkey `hardin2013a229538`.

For the three-state Potts antiferromagnet with energy $J$ times the number of monochromatic bonds, where $J>0$, the count gives the number of colour relabelling orbits of finite-strip configurations with energy $J$. The canonical predicate chooses one representative per orbit.
