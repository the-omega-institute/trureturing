# Hardin's recurrence for the 5-row three-state sum-exclusion strip

## Problem

[OEIS A233158](https://oeis.org/A233158), by R. H. Hardin, has NAME
(verbatim from the [text export](https://oeis.org/search?q=id:A233158&fmt=text)):

> Number of 5Xn 0..2 arrays with no element x(i,j) adjacent to value 2-x(i,j) horizontally or antidiagonally.

The empirical recurrence in that export is, verbatim:

```text
Empirical: a(n) = 16*a(n-1) -64*a(n-2) +76*a(n-3) +17*a(n-4) -84*a(n-5) +48*a(n-6) -8*a(n-7) for n>11
```

This is row 5 of the table A233155: the height is fixed and the width grows.
A bond joins horizontal neighbours $(i,j),(i,j+1)$ or antidiagonal neighbours
$(i,j+1),(i+1,j)$; its values must have natural-number sum different from
$2$. Every labelled function counts, without normalization. No vertical or
main-diagonal bond condition is imposed.

## Route

1. **Colour-permutation equivalence.** Put $c(x)=2-x$ and replace the
   label in column $j$ by $c^j(x)$. Every horizontal or antidiagonal bond
   joins consecutive columns, so sum exclusion becomes inequality of the
   transformed labels. `HardinA233155ColumnTransfer.properEquiv 5 n` is the
   bijection on the legal subtypes, including at zero width. The private
   `HardinA233158Row.counting_bridge` applies `Fintype.card_congr` to prove
   `U5 n = HardinA233260Literal.L n` for every natural `n`.
2. **Frozen labelled proper-colouring count.**
   `HardinA233260Literal.L` is the auxiliary count of all labelled
   three-colourings on these horizontal and antidiagonal bonds. The proof
   calls its frozen `pair_base` at width 12 and `pair_tail n` at width
   `n + 13`. These relations are expressed for `L + 6` and use the same
   seven signed recurrence coefficients as the external question.
3. **Cancellation and range.** The coefficients sum to one, so the added
   constant six cancels from both sides. `linarith only [h]` obtains the
   recurrence for `L`, and the counting bridge transfers it to `U5`.
   The base and successor cases give exactly every width $m\ge12$.

## Falsifier

recurrence would contradict `result`, with its natural parameter set to
$m-12$. A mismatch in a model with additional bonds or label
normalization would test a different count.
