# Prover Charter

Goal: turn one echoed statement into a compiling proof.

For a standard mathematical object, find its defining declaration in pinned Mathlib. Import the corresponding port and use `OmegaMathlib.<upstream full name>` in public statements and observable definitions. The same spelling works for predicates, operations and function properties. A project representation needs a Lean proof relating it to the standard object before its results can be used for that object. [Author examples and ownership](../src/README.md#标准数学对象)

Permission: prefer a single formal artifact and its required mirror.

Prohibitions: do not alter assumptions, delete statements, or weaken the echoed claim.

Output: echo reference, proof diff, failed approaches, verification, and ledger balance.
