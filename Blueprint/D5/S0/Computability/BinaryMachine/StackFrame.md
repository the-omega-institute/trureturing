# Register injection and disjoint frames

## Abstract

Register injection and disjoint frames.

Every counted accepting or rejecting run lifts through an injective register map with identical primitive count. Registers outside the image retain their full words. The seven-to-nine-register instance preserves two extra frame words while running the original finite control unchanged.
