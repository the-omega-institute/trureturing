# Bernáth's OEIS A400645 consecutive-ratio limit

## Abstract

The signed four-lag rounded norm sequence has Bernáth's exact ratio limit.

**Definition 1.1 (The signed four-square radicand).**

$$\forall a: (\mathbb{N} \to \mathbb{N}), \forall n: (\mathbb{N}), \operatorname{radicand}\left(a, n\right) = ((\operatorname{a}\left(n\right): \mathbb{Z}))^{2} + ((\operatorname{a}\left(n - 1\right): \mathbb{Z}))^{2} + ((\operatorname{a}\left(n - 2\right): \mathbb{Z}))^{2} - ((\operatorname{a}\left(n - 3\right): \mathbb{Z}))^{2}$$
