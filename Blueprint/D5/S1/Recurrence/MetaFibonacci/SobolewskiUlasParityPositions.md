# Parity positions in the Sobolewski–Ulas meta-Fibonacci sequence

## Abstract

Both parity-position sequences of h(1,1) have finitely generated binary-kernel spans.

**Definition 1.1 (The nested recurrence).**

$$\begin{aligned}\operatorname{h}\left(0\right) = 1\\\operatorname{h}\left(1\right) = 1\\\forall n \in \mathrm{Nat},\; \operatorname{h}\left(n + 2\right) = \operatorname{h}\left(\operatorname{min}\left(n + 2 - \operatorname{h}\left(n + 1\right), n + 1\right)\right) + \operatorname{h}\left(n\right)\end{aligned}$$

*Commentary.*

Page 4: “We write h(n) = h_{1,1}(n) and in the sequel, we consider the sequence h = (h(n))_{n∈ℕ}.” Page 3 defines h_{a,b}; taking a=b=1 gives h(n)=1 for n≤1 and h(n)=h(n−h(n−1))+h(n−2) for n>1. Natural subtraction sends a negative argument to zero, where h is one. Positivity makes the minimum in the recursive definition select its first argument.

*Commentary.*

The proof chooses k=2 for both parities. Odd-index and even-index identities for h yield an exact parity table for each block of length sixteen. Every block contains eight zeros and eight ones. Thus the nth position is twice n plus an integer correction obtained by selecting within a block. The correction is the output of a finite state space stable under n↦2n and n↦2n+1, so its binary kernel is finite. Every binary-kernel sequence of the position enumeration lies in the ℤ-span of this finite kernel, the constant sequence one, and the sequence n↦n. A submodule of this finitely generated ℤ-module is finitely generated. This concerns h_{1,1} and its two parity classes; it asserts nothing about other parameters or moduli.
