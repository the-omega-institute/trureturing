# Buffered Whole-Path Retained-Cone Extension

A finite buffered mixed old/new graph retains every old whole path and has one outer-buffer tracer for every new whole path.

*Commentary.*

For finite old and new discrete alphabets, closed inner buffers are placed inside old P/C and new D interiors. A compactness transfer cover and the existing finite-open-cover HasShadowing contract produce a finite control cover T.

The graph has vertices V×T×B. Its edge relation contains the old edge and one actual point t in X witnessing every old P and new L constraint at both endpoints. The first-coordinate map preserves edges and lifts every specified complete old vertex path, retaining its time-zero vertex.

One shadowing tracer serves an entire new path, placing all its iterates in the outer C/D interiors. Conversely, one specified source x lifts every complete old-K/new-L name. This is a fixed finite cone result; it does not supply the global uniform-follower lemma or solve Peng Question 5.1.
