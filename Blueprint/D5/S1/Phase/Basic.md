# Golden Phase

`D5/S1/Phase/Basic` maps an integer `n` to `n*goldenRatio` in the additive circle modulo one. The map preserves zero, addition, and negation.

Two phases can coincide only if a nonzero integer multiple of the golden ratio is an integer. The irrationality of the golden ratio excludes that possibility, so the orbit is injective. No three-distance theorem is asserted here.
