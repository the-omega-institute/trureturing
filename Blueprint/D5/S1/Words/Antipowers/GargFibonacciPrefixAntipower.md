# Garg's Fibonacci Prefix Antipower

## Abstract

The first F_n−1 blocks of length F_n/2+F_{n−1} in the Fibonacci word are distinct whenever F_n is even.

$$\forall b \in \operatorname{Bool}\left(\right),\; \operatorname{digit}\left(b\right) = \operatorname{if} b \operatorname{then} 0 \operatorname{else} 1$$

**Definition 1.2 (Finite Fibonacci prefixes).**

$$\begin{aligned}\operatorname{S}\left(0\right) = [0]\\\operatorname{S}\left(1\right) = [0, 1]\\\forall n \in \mathbb{N},\; \operatorname{S}\left(n + 2\right) = \operatorname{S}\left(n + 1\right) ++ \operatorname{S}\left(n\right)\end{aligned}$$

*Commentary.*

Source definition (§3, printed page 5), verbatim: “We prove that the Fibonacci word $\mathbf{f}$, which is equal to $\varphi^{\omega}(0)$ for $\varphi(0)=01$, $\varphi(1)=0$ and thus pure morphic but not generated by a uniform morphism, also satisfies Conjecture 3.”

The Fibonacci word begins with 0 and is fixed by the morphism 0 ↦ 01, 1 ↦ 0. The recursive prefixes begin [0] and [0,1], followed by concatenation of the previous two prefixes in that order. The plus-plus symbol is List append.

**Definition 1.4 (The specified block length).**

$$\forall n \in \mathbb{N},\; \operatorname{blockLength}\left(n\right) = \operatorname{Nat}.\operatorname{div}\left(\operatorname{Nat}.\operatorname{fib}\left(n\right), 2\right) + \operatorname{Nat}.\operatorname{fib}\left(n - 1\right)$$

*Formalization.* `D5/S1/Words/Antipowers/GargFibonacciPrefixAntipower.blockLength` (`✓ std3`).

*Commentary.*

Conjecture 18 (printed page 8), verbatim: “Let $F_{n}$ be an even Fibonacci number. Then, there is an $(F_{n} - 1)$-antipower with block length $\frac{F_{n}}{2} + F_{n - 1}$ that is a prefix of $\mathbf{f}$.”

Nat.fib has F_0=0 and F_1=F_2=1. Nat.div denotes floor division on naturals; it is exact division by 2 for the even Fibonacci numbers in the claim. Natural subtraction is truncated subtraction.

**Definition 1.5 (Conjecture 18).**

$$(\operatorname{claim}\left(\right)) \Leftrightarrow (\forall n \in \mathbb{N},\; \forall i \in \mathbb{N},\; \forall j \in \mathbb{N},\; ((1 \le n) \land \left((\operatorname{Even}\left(\operatorname{Nat}.\operatorname{fib}\left(n\right)\right)) \land \left((i < \operatorname{Nat}.\operatorname{fib}\left(n\right) - 1) \land \left((j < \operatorname{Nat}.\operatorname{fib}\left(n\right) - 1) \land (i \ne j)\right)\right)\right)) \Rightarrow ((\operatorname{fun} (t : \operatorname{Fin}\left(\operatorname{blockLength}\left(n\right)\right)) \mapsto \operatorname{fibW}\left(i \cdot \operatorname{blockLength}\left(n\right) + \operatorname{val}\left(t\right)\right)) \ne (\operatorname{fun} (t : \operatorname{Fin}\left(\operatorname{blockLength}\left(n\right)\right)) \mapsto \operatorname{fibW}\left(j \cdot \operatorname{blockLength}\left(n\right) + \operatorname{val}\left(t\right)\right))))$$

*Formalization.* `D5/S1/Words/Antipowers/GargFibonacciPrefixAntipower.claim` (`✓ std3`).

*Citation.* Swapnil Garg (2021). *Antipowers in Uniform Morphic Words and the Fibonacci Word*. DOI: [10.46298/dmtcs.7134](https://doi.org/10.46298/dmtcs.7134). URL: <https://arxiv.org/abs/1907.10816v4>.

*Commentary.*

Conjecture 18 (printed page 8), verbatim: “Let $F_{n}$ be an even Fibonacci number. Then, there is an $(F_{n} - 1)$-antipower with block length $\frac{F_{n}}{2} + F_{n - 1}$ that is a prefix of $\mathbf{f}$.”

Source definition (printed page 1), verbatim: “Fici, Restivo, Silva, and Zamboni define a $k$-antipower to be a word composed of $k$ pairwise distinct, concatenated words of equal length.”

For every n ≥ 1 with Nat.fib(n) even, the indices i and j range over the first Nat.fib(n)−1 blocks. Each block is a function Fin(blockLength(n)) → Fin 2, starting at index i·blockLength(n) or j·blockLength(n). Distinct indices give distinct functions. Thus the concatenation is a prefix antipower.
