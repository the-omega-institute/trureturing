# Actual codebooks and the lower rate limit

## Abstract

Actual complete low words have positive rate, and codebooks from the original weak limsup approximate that rate with one fixed reset. The original lower-memory rates converge increasingly to the same value.

**Definition 1.1 (lowReturns).**

$$\forall choice \in Bool,\; \operatorname{lowReturns}\left(choice\right) = \operatorname{ifThenElse}\left(choice, \operatorname{list}\left(\operatorname{Return}\left(2, 1\right), \operatorname{Return}\left(1, 1\right)\right), \operatorname{list}\left(\operatorname{Return}\left(1, 1\right), \operatorname{Return}\left(2, 1\right)\right)\right)$$

*Formalization.* `D5/S3/ConceptDynamics/Coding/FibonacciFactorCompletion/LowerRateLimit.lowReturns` (`✓ std3`).

*Source.* Repository-derived.

*Commentary.*

The false choice is the complete return list (1,1),(2,1), and the true choice is (2,1),(1,1). Both m and r are positive. Their execution words are exactly c u c u u and c u u c u, and each has weight 58. Execution goes from the original tail toward the outside; the literal source uses the reversed list and retains each original block's label order.

**Definition 1.2 (lowChoices).**

$$\forall q \in Nat, z \in \operatorname{Fin}\left(q\right) \to Bool,\; \operatorname{lowChoices}\left(z\right) = \operatorname{flatten}\left(\operatorname{ofFn}\left((i : \operatorname{Fin}\left(q\right) \mapsto \operatorname{lowReturns}\left(\operatorname{apply}\left(z, i\right)\right))\right)\right)$$

*Commentary.*
