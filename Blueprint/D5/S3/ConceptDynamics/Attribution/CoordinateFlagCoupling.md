# Coordinate subgroups and prescribed common masses

## Abstract

Boolean-profile couplings realize the same masses as a family of coordinate fixed events.

**Theorem 1.1 (Exact invariant realization of two-row profile couplings).**

$$L \iff R$$

*Commentary.*

Let I be finite. Let the elementary abelian group of binary vectors on I act on a profile p together with a binary colour. The action keeps the profile and adds to the colour the sum of the coordinates of the acting vector where the profile is false. The subgroup generated by the coordinate vector at i fixes an output precisely when its profile is true at i.

Take two real row weight functions on profiles and a real target mass for each coordinate. Let R assert that there is a nonnegative coupling with the two profile marginals and the given masses of pairs that are true in both profiles at each coordinate. Let L assert that there is a nonnegative invariant coupling on coloured outputs, with each row weight divided equally between the two colours. Its mass of pairs fixed by the coordinate subgroup equals the target at every coordinate.

From a coloured coupling, sum over both colours. From a profile coupling, divide each pair weight equally among its four colour pairs. The action preserves that equal split, and the subgroup tests depend only on the profiles, so the two constructions preserve the marginals and all the specified masses.
