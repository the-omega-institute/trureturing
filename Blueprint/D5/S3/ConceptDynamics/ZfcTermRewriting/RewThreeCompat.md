# RewThreeCompat

## Abstract

Compatibility wrappers expose canonical ASCII selectors for punctuation-bearing RewThree declarations.

This compatibility layer preserves the frozen RewThree source while exposing ASCII GID selectors for source names containing question marks or a subscript. The wrappers carry no axioms and are used only as addressable mirrors.
