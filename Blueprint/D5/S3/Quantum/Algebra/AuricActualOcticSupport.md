# Actual octic support connectivity

## Abstract

Directed support and parameter determinants of the actual octic window operator.

F has characteristic zero, D/F has degree eight, and W is an arbitrary four dimensional F subspace whose multiplication idealizer is exactly F. The element a lies outside Q(W), the set of quotients of elements of W with nonzero denominator. K/F is a finite normal extension containing the same D, and L/K is any field extension. Omega consists of the literal F algebra embeddings of D into K.

nonzeroSupport(N) has an arrow from sigma to tau exactly when N(sigma,tau) is nonzero. StronglyConnected means that every ordered pair is joined by a finite directed path, allowing a path of length zero. The matrix map applies the coefficient embedding K to L to each entry; it leaves all embedding labels fixed. The constrained n and N express the let bindings defining the original inverse-obstruction matrix.

*Commentary.*

The canonical evaluation splitting sends c tensor d to the function sigma maps to c times sigma(d). The strict projection rank inequality gives 2 rho(S) at least card(S)+1 for every nonempty proper S. Rank-nullity for the same actual operator, whose kernel and image are the split window, bounds 2 rho(S) above by card(S) plus rank N[S,S complement]. Every such crossing block therefore has positive rank. If sigma cannot reach tau, let S consist of the vertices that can reach tau. It contains tau and excludes sigma. Every entry from S complement to S is zero, since a nonzero entry would extend a path to tau. This contradicts the positive crossing rank for S complement. Finally the coefficient embedding is injective, so every edge and every finite path remains present over L. The fixed-matrix row-parameter theorem now proves irreducibility of the determinant of I plus diag(x) times the coefficient image of this same actual N over L. The diagonal-parameter theorem proves irreducibility of det(diag(y)+N) for that same coefficient image, with the same literal embedding labels. No connectivity hypothesis is added to the original window telescope. The theorem does not identify this polynomial with the original multiplication obstruction in its chosen original basis; that normalization and coordinate bridge remain separate. The reciprocal determinant identity applies to this same N in any commutative coefficient ring with unit coordinates, including the Laurent polynomial ring.
