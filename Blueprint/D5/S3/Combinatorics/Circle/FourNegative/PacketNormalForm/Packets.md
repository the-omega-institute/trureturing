# Endpoint data

## Abstract

Seam and peak checks for physical packets

A packet check contains only its post-negative nonnegativity and pre-negative upper bound, followed by the checks of subsequent packets. Four negative labels give four pairs per row. Nonnegative packet steps imply all internal bounds in any order. The fresh ear can slide right within its current packet, preserving the same old word.
