# Physical construction

## Abstract

Corrected palindromic W and X windows

For c=b put y=qx, D=L-B and Dp=SV-SU. The corrected identities are ep0=Dp+SW-s1*SV=2E-H+s1*(y+1)-y; SW-1-2ep0=2K+H-1-4E-2s1*(y+1)+2y; ep0+A=2E+(A-H-y)+s1*(y+1). Here A-H-y=x+(x-2)y+(x-1)y^2>0. These exact corrections choose fresh before nW when ep0<0, and before nX otherwise. X windows use q=4,q=8 or q>=16. At x=4,q=8 the one U0/X0 exchange changes the X seam by (A-K,2A-SW), giving endpoints (80,1350).
