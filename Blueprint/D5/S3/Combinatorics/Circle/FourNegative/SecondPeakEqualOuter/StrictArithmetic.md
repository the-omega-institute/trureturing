## Abstract

U payment has exactly five exhaustive branches: q=z/x=2 uses v=2,t=s; q>=4,p=y/z>=4 uses v=1,t=floor(B/L); q>=8,p=2 uses v=2,t=3; q=4,p=2,x=4 uses v=4,t=6; q=4,p=2,x>=8 uses v=3,t=5. The singleton (a,b,c,d)=(2,5,4,2) is a leaf inside this unbounded construction. Its old/new third endpoints are 110,318. No finite grid supplies the unbounded conclusion.
