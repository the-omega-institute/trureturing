# Paired source arithmetic

## Abstract

Exact polynomial mask bounds: PlusThreeLarge

The nonnegative parameters describe an entire continuous orthant of the adjacent-tail source heads. Each inequality is proved by an exact polynomial identity with nonnegative coefficients after multiplying by a strictly positive denominator.

These inequalities bound the original mask stocks and the paired old and new residual windows. The integer selector substitutes exact dyadic quotient data into this family; no finite range of exponents is assumed.
