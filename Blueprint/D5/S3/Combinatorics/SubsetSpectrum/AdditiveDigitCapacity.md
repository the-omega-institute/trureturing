# Integer levels and relative additive orders

## Abstract

The reduced denominator limits how many integer levels a weighted digit grid can cover.

**Theorem 1.1 (A rational weight total bounds the number of distinct integer levels).**

$$\forall r k n A b w L, 0 < b \land \operatorname{Coprime}\left(A, b\right) \land \operatorname{WeightTotal}\left(w\right) = \frac{A}{b} \land \operatorname{DistinctLevels}\left(L, n\right) \land \operatorname{IntegerCoverage}\left(r, k, w, L\right) \Rightarrow b\cdot n \le (b+k)\cdot (k+1)^r$$

*Source.* Repository-derived.

*Commentary.*

Let r, k, n, A and b be natural numbers. There are r plus one real weights w. The positive denominator b is coprime to A and the total weight is A divided by b. L lists n pairwise distinct integers. IntegerCoverage(r,k,w,L) means each listed integer is a weighted sum with one digit per weight, each from zero through k.

Reduce the weights modulo the integers. Process the weights in order and take the additive order of each new weight modulo the subgroup generated by the previous ones. For a prescribed sum, each such order c limits the next digit to a single class modulo c. This gives at most the integer quotient k divided by c plus one choices. Infinite order permits at most one choice.

The product of finite relative orders annihilates the total weight modulo the integers. Its finite order is b because the defining fraction is reduced. Combining two factors uses (k+c)(k+d) at most (k+1)(k+cd), whose difference is k times (c-1) times (d-1). Each represented integer needs its own digit vector in the zero fiber.
