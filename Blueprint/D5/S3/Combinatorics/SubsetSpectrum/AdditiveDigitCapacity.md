# Integer levels and relative additive orders

## Abstract

The reduced denominator limits how many integer levels a weighted digit grid can cover.

**Theorem 1.1 (A rational weight total bounds the number of distinct integer levels).**

$$\forall r k n A b w L, 0 < b \land \operatorname{Coprime}\left(\operatorname{Abs}\left(A\right), b\right) \land \operatorname{WeightTotal}\left(w\right) = \frac{A}{b} \land \operatorname{DistinctLevels}\left(L, n\right) \land \operatorname{IntegerCoverage}\left(r, k, w, L\right) \Rightarrow b\cdot n \le (b+k)\cdot (k+1)^r$$

*Source.* Repository-derived.

*Commentary.*

Let r, k, n and b be natural numbers and A an integer. There are r plus one real weights w. The positive denominator b is coprime to the absolute value of A. The total weight is A divided by b. L lists n pairwise distinct integers. IntegerCoverage(r,k,w,L) means each listed integer is a weighted sum with one digit per weight, each from zero through k.

Reduce the weights modulo the integers. Take the additive order of each weight modulo the subgroup generated by the earlier weights. Count backwards. With later digits fixed and their contributions subtracted from the target, a finite relative order c restricts the current digit to one residue class. That gives at most the integer quotient of k by c plus one choices. An infinite relative order permits at most one choice.

The total weight has order b because its fraction is reduced. When every relative order is finite, their product annihilates the total weight and is a multiple of b. Combine pairs of factors using (k+c)(k+d) at most (k+1)(k+cd), whose difference is k times (c-1) times (d-1). When some relative order is infinite, its one-choice bound leaves at most the r-th power of k plus one combinations. Each represented integer needs its own digit vector in the zero fiber.
