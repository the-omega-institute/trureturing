# Centralizer constraints in both total-code cases

## Abstract

Centralizers and the normal core of a total perfect subgroup code.

**Theorem 1.1 (The whole normal core centralizes Y).**

*Citation.* Haobo Ma; Reza Nikandish; Wenlin Zhang (2026). *Subgroup total perfect codes in Cayley sum graphs: a missing case and its consequences*. DOI: [10.5281/zenodo.23375144](https://doi.org/10.5281/zenodo.23375144). URL: <https://doi.org/10.5281/zenodo.23375144>.

*Commentary.*

For a finite group G and a total perfect subgroup code H, every member of the actual normal core of H centralizes every connection element. Conjugation preserves the normal transversal and its coset; representative uniqueness forces equality. The extra identity in case (b) is handled separately. This is Proposition 3.1(ii).

*Commentary.*

H centralizes each element of Y intersect H, in both branches of the criterion. H need not be normal. This is Proposition 3.1(i), retaining both internal elements in the exceptional branch.

*Commentary.*

If H is normal, every element of Y intersect H is central in the ambient group G. All its conjugates stay in H, so uniqueness in the specified normal transversal applies to every ambient conjugator. This includes the central singleton used in Corollary 2.4; normality is essential to this ambient-center conclusion.

*Commentary.*

For a normal subgroup code and a connection set of size greater than one, there are two connection elements that are not conjugate in G. An internal connection element is central, so its conjugacy class is a singleton; any distinct element of Y lies in another class. This is Proposition 3.1(iv), and does not rely on a class-count proxy.

*Proof.* Machine-checked in Lean as `D5/S3/Combinatorics/CayleySumCodes/CodeCentralizers.connected_generates` (`✓ std3`). ∎

*Citation.* Haobo Ma; Reza Nikandish; Wenlin Zhang (2026). *Subgroup total perfect codes in Cayley sum graphs: a missing case and its consequences*. DOI: [10.5281/zenodo.23375144](https://doi.org/10.5281/zenodo.23375144). URL: <https://doi.org/10.5281/zenodo.23375144>.

*Commentary.*

Along each actual sum-graph edge, membership in the subgroup generated by Y propagates by h=g inverse times (g h). Following a path from 1 in a connected graph therefore puts every vertex in that subgroup. Only connectedness implies generation is asserted; generation alone is not claimed sufficient for connectedness.

*Proof.* Machine-checked in Lean as `D5/S3/Combinatorics/CayleySumCodes/CodeCentralizers.connected_core` (`✓ std3`). ∎

*Citation.* Haobo Ma; Reza Nikandish; Wenlin Zhang (2026). *Subgroup total perfect codes in Cayley sum graphs: a missing case and its consequences*. DOI: [10.5281/zenodo.23375144](https://doi.org/10.5281/zenodo.23375144). URL: <https://doi.org/10.5281/zenodo.23375144>.

*Commentary.*

A connected normal-connection sum graph with H as a total perfect code forces core G(H) into Z(G). Core centralization of Y extends to its generated subgroup, which connectedness makes the full group. Thus a noncentral core excludes every connected witness. This retains the Zhang 4.5 consequence cited after Proposition 3.1, without using the faulty singleton-only total-transversal criterion. The additional conjugacy-class index sum needs its own evidence.
