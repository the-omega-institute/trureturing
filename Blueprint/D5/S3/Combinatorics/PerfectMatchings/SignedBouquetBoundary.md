## Abstract

Signed ribbon boundary components and binary rank.

**Theorem 1.1 (Signed ribbon boundary components and binary rank).**

$$\forall R \in \operatorname{ValidSignedRibbonBouquets}\left(\right),\; \operatorname{Add}\left(\operatorname{BoundaryComponents}\left(R\right), \operatorname{SignedInterlacementRank}\left(R\right)\right) = \operatorname{Add}\left(\operatorname{BandCount}\left(R\right), 1\right)$$

*Commentary.*

Use the actual equivalence relation generated by local flag links with the specified twist and the cyclic successor links. On a one-vertex ribbon the number of boundary components plus the rank of the signed interlacement map equals the number of retained bands plus one. An untwisted crossing contributes its mod-two off-diagonal coefficient; a twisted band contributes a diagonal coefficient. This is a binary nullity formula, not a classification of knots.
