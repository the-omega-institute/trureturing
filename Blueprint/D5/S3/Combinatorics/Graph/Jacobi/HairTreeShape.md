*Commentary.*

HairTree C is a finite full binary tree with a color in C at each leaf. HairContext C is an explicit one-hole context, and fill inserts a tree into that context. The structural decomposition into a leaf or a context containing a pair of sibling leaves is used inside actual flag embeddings; it is an auxiliary shape calculation, not a separate mathematical endpoint.
