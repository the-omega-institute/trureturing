# An Upward Edge and a Later Intermediate Value

## Abstract

The cyclic successor of an earlier value cannot cross a later value in a 312-avoider.

**Theorem 1.1 (Exclusion of a crossing successor).**

*Commentary.*

In a 312-avoiding permutation, there are no letters x and z such that x occurs before z and x is smaller than z while z is smaller than the cyclic successor of x in its record block.
