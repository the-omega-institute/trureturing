# The High Prefix before One

## Abstract

A predecessor of one and the terminal value determine a decreasing prefix.

*Commentary.*

For a 231-avoiding permutation of size n ending with c, if one occurs at a position t strictly between zero and n minus one and is preceded by c plus one, then its first t letters are n, n minus one, down to c plus one.
