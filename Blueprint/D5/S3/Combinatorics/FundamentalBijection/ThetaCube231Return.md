# The Penultimate Record Block

## Abstract

A third-iterate return fixes an entry near the end of the inverse image.

**Theorem 1.1 (Two near the end of the inverse image).**

*Commentary.*

For a permutation of size n greater than three starting with n, one, ending with n minus one, and fixed by the third inverse iterate, the entry of its inverse image at position n minus three is two.
