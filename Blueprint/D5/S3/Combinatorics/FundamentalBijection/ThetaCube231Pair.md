# A Consecutive Pair Forced by a Return

## Abstract

A terminal one after two inverse applications determines an adjacent pair in the original permutation.

*Commentary.*

For a permutation of size n greater than one starting with n and ending with c, if its second inverse image ends with one, then c is below n and c plus one occurs immediately before one.
