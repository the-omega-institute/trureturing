# Wu’s Ordered Rooted-Tree Enumeration

## Abstract

The actual ordered-tree counts satisfy Wu’s formal generating function and signed recurrence.

*Commentary.*

For each natural n, Tₙ comprises the finite ordered rooted trees with n vertices whose longest root-to-leaf path measured in vertices has length equal to the number of nonleaf vertices. The singleton has vertex height one. The sequence a counts this finite set at each index.

The series equality is in the ring of formal power series over the integers. The Lean quotient uses the sign-normalized numerator and denominator. The normalized denominator has constant coefficient one, so it has a formal inverse over the integers. Every count in the recurrence is cast to an integer before arithmetic.

At fixed skeleton size u+3, two mandatory leaves and 2u+5 ordered gaps give weight x^(u+5)/(1−x)^(2u+5) per skeleton. Summing over the 2u+1 skeletons at each u uses the weighted geometric series whose coefficient at u is 2u+1. The coefficient proof uses a finite truncation at each degree. Multiplying by the denominator, then comparing coefficients above degree seven, gives the recurrence. The same all-size count formula evaluates a(5), a(6) and a(7).
