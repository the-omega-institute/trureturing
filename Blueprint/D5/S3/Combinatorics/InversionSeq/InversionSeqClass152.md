# Equinumerosity of Inversion Sequences in Class 152

## Abstract

The two pattern-avoidance classes in Class 152 are equinumerous at every length.

*Commentary.*

For every nonnegative n, the number of inversion sequences of length n avoiding 010, 100, 102 and 210 equals the number of inversion sequences of length n avoiding 011, 201 and 210.
