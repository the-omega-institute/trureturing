# Wu’s Unordered Rooted-Tree Enumeration

## Abstract

The actual unordered-tree counts satisfy Wu’s formal generating function and signed recurrence.

**Theorem 1.1 (The generating function, initial values and recurrence).**

$$\forall n \in \mathbb{N},\; \left(\begin{aligned}&\left(\operatorname{Finite}\left(\{T: \operatorname{TreeClass}\left(n\right) \mid \operatorname{classHeight}\left(T\right) = \operatorname{classInternalCount}\left(T\right)\}\right) \land \operatorname{a}\left(n\right) = \operatorname{ncard}\left(\{T: \operatorname{TreeClass}\left(n\right) \mid \operatorname{classHeight}\left(T\right) = \operatorname{classInternalCount}\left(T\right)\}\right)\right)\\&\land \operatorname{a}\left(0\right) = 0\\&\land \sum^{\infty}_{k = 0} \left(\operatorname{a}\left(k\right) : \mathbb{Z}\right)X^{k} = \frac{X^{5}\left(X^{2}-X+1\right)}{\left(X-1\right)^{2}\left(X+1\right)\left(2X-1\right)^{2}}\\&\land \left(\operatorname{a}\left(1\right) = 0\land \operatorname{a}\left(2\right) = 0\land \operatorname{a}\left(3\right) = 0\land \operatorname{a}\left(4\right) = 0\land \operatorname{a}\left(5\right) = 1\land \operatorname{a}\left(6\right) = 4\land \operatorname{a}\left(7\right) = 14\right)\\&\land \left(7 < n \Rightarrow \left(\operatorname{a}\left(n\right) : \mathbb{Z}\right) = 5\left(\operatorname{a}\left(n-1\right) : \mathbb{Z}\right)-7\left(\operatorname{a}\left(n-2\right) : \mathbb{Z}\right)-\left(\operatorname{a}\left(n-3\right) : \mathbb{Z}\right)+8\left(\operatorname{a}\left(n-4\right) : \mathbb{Z}\right)-4\left(\operatorname{a}\left(n-5\right) : \mathbb{Z}\right)\right)\end{aligned}\right)$$

*Commentary.*

For each natural n, the qualifying set consists of the classes of parent maps on Fin n under root-preserving vertex isomorphisms, restricted to trees whose vertex height equals their number of internal vertices. The children are unordered. A singleton has vertex height one and zero internal vertices.

Pruning the original leaves gives a unique fork. At least one arm has length one, and both have length one when c=0. The leaf counts on its spine and tips recover the original isomorphism class. For equal arms the sorted tip counts have the form m+1 and m+d+1, including the diagonal d=0. For unequal arms the two tip counts vary independently. The binomial sums count these decorations for every n.

Finite coefficient substitution turns the two sums into the generating series over the integers. The displayed denominator has constant coefficient one. The signed recurrence follows by comparing coefficients above degree seven after multiplication by that denominator.
