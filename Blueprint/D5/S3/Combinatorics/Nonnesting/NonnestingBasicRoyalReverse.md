# Reflection of Dyck Paths

## Abstract

Reversal with exchanged step directions is an involution on Dyck paths.

*Commentary.*

Reverse a Dyck path and exchange upsteps with downsteps. This operation gives a bijection of Dyck paths with itself, with the same operation as inverse.
