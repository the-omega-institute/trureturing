K Type Projection

Lowest K-type occurs once; K-types outside the cone above it do not occur.

*Commentary.*

Let l = 2λ be a parameter of some gap, x, b in U(diag ε), ν K-dominant. Then ∫_K conj(m_ν(k)) ψ_λ(xkb) dk is c_Λ ψ_λ(x)ψ_λ(b), c_Λ = ∫_K |m_Λ|², if ν = Λ, and 0 if ν ≠ Λ and ν − Λ lies outside HCParam.rootCone.
