# Line Parabolic

## Abstract

Line Parabolic

Tamely ramified characters, local components and residues; data and theta integrals named. Equivariant maps from local data to automorphic functions; real sign classes. Coordinates on radical and Levi factor of an isotropic line stabiliser.
