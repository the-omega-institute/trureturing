*Commentary.*

Almost descent: if π = ξ mod p kills the O^♭-module N and b is a perfect O^♭-algebra, then on p-adic tests S the functor Hom(b, S^♭) with coefficients S^♭ ⊗ N ⊗ 𝔪 has cohomology b ⊗ N ⊗ 𝔪, in degree 0.
