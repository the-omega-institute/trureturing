# Mackey Formula

## Abstract

Mackey Formula

Similarity classes of matrices, class functions, parabolic induction product, rank parts, means. Class functions under parabolic induction form a commutative ring; constant one is invertible. Block means (coproduct), cuspidality, inner product, adjoints, Brauer lift, cuspidal function. Group order times a central idempotent of the group algebra is a character. Mackey formula: block means are multiplicative for parabolic induction.
