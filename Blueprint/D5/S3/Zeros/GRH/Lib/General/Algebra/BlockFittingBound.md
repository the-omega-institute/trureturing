*Commentary.*

Let ψ: A → M_d(O) be onto, N ⊆ A^ι an A-submodule, p ≠ 0, b < v(p). If the w in ((O/p)^d)^ι killed by N through ψ lie in a submodule of length ≤ b, some square matrix B with rows in N has v(det ψ(B)) ≤ b.
