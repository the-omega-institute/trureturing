# PEL Data Existence

## Abstract

PEL Data Existence

Regular test function with cuspidal type that does not kill the given vector. Eigensystem of a definite form occurs in each Hodge weight for signature (1,n-1). Lagrangians exist; PEL data with odd theta group, good at the safe places.
