# Stable Cells

## Abstract

Stable Cells

Invariance of link, level and discriminant under unipotent groups; link is Lagrangian (link: classes of the pairs (y, γ⁻¹y), y orthogonal to X and γX, X spanned by e₁, …, e_ϱ).

*Commentary.*

Over a field with involution, let σ, τ fix all e_a, e*_a, and let w_p, w_q be Weyl elements of length ϱ. Then w_pσ and w_qτ have the same link if and only if σ = τ.
