Stable Spaces

A stable space containing a standard datum contains all partner data.

**Theorem 1.1 (partner_mem_of_unimodular_vanishing).**

*Commentary.*

Let P be GL_n(F)-stable and M contain all S_z(y) = S₀(y + LzK'y), S₀ the standard datum of K', with L, K' blocks of an IntegralFrame. If P contains each element of M killed by all Λ with Λ(S_z) = ψ(tr Tz)Λ(S₀), and Λ(S₀) = 0 if T is unimodular, then P contains every locally constant function having a partner.
