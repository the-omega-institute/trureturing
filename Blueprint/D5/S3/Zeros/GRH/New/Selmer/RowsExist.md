# Rows Exist

## Abstract

Rows Exist

A twist-free row gives traces of lifts; every good eigensystem has a row.

*Commentary.*

If the system p of Hecke eigenvalues occurs in a nonzero good form on W_m, then for 1 ≤ j ≤ m some T is a row for the untwisted j-th auxiliary pair and p, serving all twists (HasRow).
