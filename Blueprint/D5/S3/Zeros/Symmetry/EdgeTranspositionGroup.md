# Edge Transposition Group

## Abstract

Edge transpositions generate every permutation on each connected component.

**Theorem 1.1 (Edge transpositions generate the full component permutation groups).**

$$\forall V: \operatorname{Type}, G: \operatorname{SimpleGraph}(V),\\{}\operatorname{Finite}(V) \Rightarrow\\{}(\forall C: \operatorname{ConnectedComponent}(G), \operatorname{closure}(\left\{\Sigma \mid \Sigma \in \operatorname{Perm}(\operatorname{vertices}(C)), \exists a, b: \operatorname{vertices}(C), \operatorname{Adj}(\operatorname{componentGraph}(C), a, b) \land \Sigma = \operatorname{swap}(a, b)\right\}) = \operatorname{Perm}(\operatorname{vertices}(C))) \land\\{}(\operatorname{Connected}(G) \Rightarrow\\{}\operatorname{let} \Gamma = \operatorname{closure}(\left\{\Sigma \mid \Sigma \in \operatorname{Perm}(V), \exists a, b: V, \operatorname{Adj}(G, a, b) \land \Sigma = \operatorname{swap}(a, b)\right\}); \Gamma = \operatorname{Perm}(V) \land \forall a, b: V, \exists \Sigma: \Gamma, \Sigma(a) = b).$$

*Source.* Repository-derived.

*Commentary.*

Let graph be a finite simple graph. For each connected component, the subgroup generated by swaps across its edges is the full permutation group of that component.

For a connected graph, a path between two vertices gives a product of edge swaps transporting the first vertex to the second. Thus the generated subgroup acts transitively.

Pinned Mathlib's transitive-swap closure theorem then identifies the generated subgroup with the full symmetric group. The same identity supplies a generated permutation transporting any chosen branch to any other branch.

Repository and installed-package searches found no existing theorem combining the componentwise, connected-graph, and transport clauses.
