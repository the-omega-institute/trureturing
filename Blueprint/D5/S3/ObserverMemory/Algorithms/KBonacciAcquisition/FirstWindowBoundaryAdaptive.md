*Commentary.*

Fix m>=5, k=2m-2 and T=2m-1. The output universe is arbitrary, with separately distinct labels at each free value and arbitrary cross-value coincidences. The support may differ between free values. Every INITIAL phase and inherited tail remains in scope, and the legal or rejected history and its length remain unknown.

For a finite support J the branch fee is the length of that branch’s binary word list. The optimal adaptive budget is max(binaryCost(H(0)), binaryCost(H(1))). The remembered free value chooses the branch once. The selector stops when that branch's own list has ended; it emits no word belonging to the longer branch.

The decoder compares the acquired consecutive endpoint differences with the binary codes at actual phases. Code equality preserves membership in that branch's support. Empty supports have empty scripts and stop immediately; the independent bottom label also stops without a block. For every actual history, the paid trace contains exactly the selected binary words, and its block and bit lengths are binaryCost(H(v)) and m*binaryCost(H(v)) when the INITIAL record is live, and zero when it is bottom.

The lower bound applies the zero-block and nonempty one-block necessities at each arbitrary remembered value. The auxiliary target agrees with the original target on that same actual fibre, so neither a value-zero-only root lemma nor a shared branch length is assumed. All issued words are complete length-m blocks and are legal in either original alphabet since m<k.
