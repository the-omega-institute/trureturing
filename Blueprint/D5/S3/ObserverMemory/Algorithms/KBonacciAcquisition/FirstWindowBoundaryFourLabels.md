*Commentary.*

Fix m>=5, k=2m-2 and P=ZMod(2m-1). The arbitrary supports H(0),H(1) lie in B={1,...,m}; ell is their ordered membership pair. Its full image has four labels. The output labels A(v),B(v) differ separately for each free value, while all cross-value coincidences remain allowed. Y is an arbitrary type, without a finite-type hypothesis, and the separately observed bottom label is arbitrary. The theorem retains both original alphabets, every actual value and phase, all legal inherited tails, and unknown legal or rejected histories.

multiplicity(m,H,z) is the number of phases with ell(j)=z. Its domain is the phase set itself, so each phase contributes once; histories and tails do not repeat a contribution. pivot is the sum of ell(j) over all phases in the pair vector space. Since 2m-1 is odd, one or three multiplicity parities are odd. The first conclusion identifies pivot as the unique label whose parity differs from the other three. It includes both parity patterns. Pi4 means that erasing this label from the internal image leaves at most one label, and that an internal base occurrence forces the pivot to be base.

Necessity uses the actual common scheduled rows. Equal row pairs refine both membership coordinates, including sources with different stopping times. Four labels exhaust four binary codes. Choosing one representative per label gives an injective, hence bijective, code map; surjectivity then forces every phase of one label to have that same code. This no-splitting statement uses four labels. It imposes no corresponding restriction on three-label families.

For a bijection g of the four pair vectors, the sum of g(ell(j)) is g(pivot). This follows by grouping the phases by their four labels and using the odd total multiplicity. Both physical rows are even, so g(pivot)=00. The second row is zero on U={2,...,m-1}, leaving only codes 00 and 10 internally. Thus at most one internal label differs from the pivot. If base occurs internally, its second bit is zero there and its first bit is zero at exterior phase zero; its code is therefore 00 and bijectivity forces pivot=base.

For sufficiency the internal labels together with base and the two boundary labels fill the four-label set. Select a bijection with pivot code 00, first bit zero on base and second bit zero on the internal image. Its normalized boundary codes additionally satisfy the displayed seam disjunction. When the pivot differs from base, base has code 01, so every exterior phase, including m+1, has second charge one. When the pivot is base, the normalized last boundary has first charge zero, giving a zero-ending root before a possible all-one successor. These are the normalized alternatives of 29.20-29.22.
