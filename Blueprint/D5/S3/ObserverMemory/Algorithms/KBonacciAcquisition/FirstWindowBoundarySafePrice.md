*Commentary.*

Fix arbitrary universe-polymorphic Y and separately distinct label pairs. Labels from different values may coincide, and the independently observed bottom label is unrestricted. Both original alphabets, every original phase and inherited tail, and every unknown legal or rejected initial history are retained. The support membership image counts each phase once.

A SafePlan consists of literal words, all-phase chronological endpoint codes, their refinement of the ordered membership pair, and absence of bottom replies. For one image class choose the empty script. For two choose the binary script of the support union; the exact normalization allows either component to be empty. Three classes select the homogeneous or either internal two-label construction precisely when Pi3 holds. Four classes select the normalized safe bijective code assignment precisely when Pi4 holds. Every remaining case selects the pulse/donor three-block script. These are the existing physical constructions, including their exterior donors and safe whole-prefix seams; safety is asserted for the selected inverses.

The decoder searches the selected all-phase code and uses its own consecutive endpoint differences together with its remembered free value. Code refinement makes its INITIAL output well defined even when three-label classes split across four codes. The common words have exactly presetCost blocks. Every live original history executes that entire safe prefix; initial bottom executes none. The constant-length script bridge transports these exact selected words to a PaidTrace on the same actual source, with issued.length equal to fee(presetCost,q) and archiveWords.length equal to m times that fee. No unissued suffix is charged.

The maximizing witness is one jointly attained original state (value,phase,tail)=(0,0,0), on one original AllowedBlock history. The same history determines the initial record and its paid trace.
