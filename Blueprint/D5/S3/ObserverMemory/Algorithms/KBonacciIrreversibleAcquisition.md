# KBonacciIrreversibleAcquisition

## Abstract

Complete actual-history first-zero acquisition classification and uniform cost.

**Theorem 1.1 (Complete original first-zero acquisition theorem).**

$$\forall k: \mathbb{N}, m: \mathbb{N}, ell: \operatorname{Bool}, Y: \operatorname{Type}, target: \{q: \operatorname{Option}(\operatorname{LiveRecord}(k)) | \operatorname{SourceRecord}(k,m,q)\} \to Y, (((2 \leq k) \land (1 \leq m)) \implies (\operatorname{let} f = \operatorname{actualSourceTarget}(target); (\forall q: \operatorname{Option}(\operatorname{LiveRecord}(k)), ((\operatorname{SourceRecord}(k,m,q)) \iff (\exists history: \operatorname{List}(\operatorname{AllowedBlock}(k,m,ell)), (\operatorname{historyRecord}(history) = q)))) \land ((\operatorname{RecordAcquired}(k,m,ell,f)) \iff ((\operatorname{FirstZeroCriterion}(k,m,f,0,0,k,\{phi | \operatorname{divides}(\operatorname{gcd}(m,k+1),\operatorname{val}(phi))\})) \land (\operatorname{FirstZeroCriterion}(k,m,f,1,0,k,\{phi | \operatorname{divides}(\operatorname{gcd}(m,k+1),\operatorname{val}(phi))\})))) \land ((\operatorname{RecordAcquired}(k,m,ell,f)) \implies (\exists controller: \operatorname{Option}(\operatorname{ZMod}(2)) \to \operatorname{AcquisitionTree}(k,m,ell,Y,\operatorname{prefixBudget}(k,m,k)), ((\forall q: \operatorname{Option}(\operatorname{LiveRecord}(k)), ((\operatorname{SourceRecord}(k,m,q)) \implies (\operatorname{result}(\operatorname{controller}(\operatorname{endpointReading}(q)),q) = \operatorname{f}(q)))) \land (\operatorname{result}(\operatorname{controller}(\operatorname{none}),\operatorname{none}) = \operatorname{f}(\operatorname{none})) \land (\operatorname{archive}(\operatorname{controller}(\operatorname{none}),\operatorname{none}) = []) \land (\forall q: \operatorname{Option}(\operatorname{LiveRecord}(k)), (\operatorname{length}(\operatorname{archive}(\operatorname{controller}(\operatorname{endpointReading}(q)),q)) \leq \operatorname{prefixBudget}(k,m,k)))))) \land ((2 \leq m) \implies (\operatorname{prefixBudget}(k,m,k) = (k-1)/m+(k+1)/\operatorname{gcd}(m,k+1))) \land (\forall F: \operatorname{List}(\operatorname{AllowedBlock}(k,m,ell)) \to Y, ((\operatorname{HistoryAcquired}(ell,F)) \iff (\exists z: \operatorname{Option}(\operatorname{LiveRecord}(k)) \to Y, ((\forall history: \operatorname{List}(\operatorname{AllowedBlock}(k,m,ell)), *Commentary.*

For every k>=2, m>=1, either full or internally legal block alphabet, arbitrary label type Y and initial record target f on the actual SourceRecord subtype Q, six conclusions hold. actualSourceTarget extends f outside Q using f(bottom). Only Q participates in acquisition. SourceRecord is exactly the image of one actual finite block history from the empty word, including bottom and every joint value-phase-tail record. Uniform RecordAcquired is equivalent to the two root FirstZeroCriterion conditions A_0(0,P) and A_1(0,P). Every acquired target has a controller of horizon D+1+L, where D=floor((k-1)/m) and L=phaseCost; its initial bottom branch stops with f(bottom), an empty archive and zero issued blocks. When m>=2 this horizon equals D+p. For every raw initial history target F, HistoryAcquired is equivalent to factorization through historyRecord by some uniformly acquired record target. Finally the actual successful all-one archive has exactly prefixRecords with h=k-t*m and the same-history phase filter I_i(theta)=b_i; the current value is v+sum b_i and the current tail is s+t*m, while the target still uses initial v,theta,s. The initial current reading freely selects a tree. Each later action uses only its attained complete-block endpoint. There is no resetting, source copying, internal-bit reading, target observability or decidable equality assumption. The statement is not an optimal-cost claim for L.
