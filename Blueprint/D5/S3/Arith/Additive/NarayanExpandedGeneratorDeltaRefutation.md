# Expanded generators and factorization lengths

## Abstract

Expanded generators refute Narayan's delta-set formula by unit-length normalization.

**Definition 1.1 (The expanded generating tuple).**

$$\forall a \in \mathbb{N},\; \forall h \in \mathbb{N},\; \forall d \in \mathbb{N},\; \forall k \in \mathbb{N},\; \forall i \in \operatorname{Fin}\left(k + 2\right),\; \operatorname{generators}\left(a, h, d, k, i\right) = \operatorname{ite}\left(\operatorname{val}\left(i\right) = 0, a, a \cdot h + \left(\operatorname{val}\left(i\right) - 1\right) \cdot d\right)$$

*Formalization.* `D5/S3/Arith/Additive/NarayanExpandedGeneratorDeltaRefutation.generators` (`✓ std3`).

*Citation.* Ashwin Narayan (2026). *The Delta Set of a Numerical Monoid Generated by a Generalized Arithmetic Sequence*. DOI: [10.48550/arXiv.2610.02495](https://doi.org/10.48550/arXiv.2610.02495). URL: <https://arxiv.org/abs/2610.02495v1>.

*Commentary.*

Conjecture 18.3 (p. 22) states: “For Sₕ =⟨a,ah,ah+d,ah+2d,...ah+kd ⟩, Δ(Sₕ) = E(e,d)”. The index i : Fin (k + 2) retains a at zero and ah at one. All later coordinates are ah + (i.val − 1)d; no displayed generator is removed.

**Definition 1.2 (Coordinate factorizations).**

$$\forall p \in \mathbb{N},\; \forall g \in \operatorname{Fin}\left(p\right) \to \mathbb{N},\; \forall n \in \mathbb{N},\; \operatorname{Z}\left(g, n\right) = \{z : \operatorname{Fin}\left(p\right) \to \mathbb{N} \mid \sum_{i : \operatorname{Fin}\left(p\right)} (z\left(i\right) \cdot g\left(i\right)) = n\}$$

*Commentary.*

Section 3 (p. 2) states: “Suppose the set of factorizations of n ∈ S is given by Z(n) = { (z₁, z₂, …, zₚ) ∈ ℕᵖ ∣ z₁ n₁ + z₂ n₂ + … + zₚ nₚ = n }”. The p coordinates are indexed from zero by Fin p and take nonnegative integer values, including zero as in the paper's subsequent inequalities. The sum is over every coordinate.

**Definition 1.3 (Length sets).**

$$\forall p \in \mathbb{N},\; \forall g \in \operatorname{Fin}\left(p\right) \to \mathbb{N},\; \forall n \in \mathbb{N},\; \operatorname{L}\left(g, n\right) = \operatorname{Set}.\operatorname{image}\left(\operatorname{fun} (z : \operatorname{Fin}\left(p\right) \to \mathbb{N}) \mapsto \sum_{i : \operatorname{Fin}\left(p\right)} (z\left(i\right)), \operatorname{Z}\left(g, n\right)\right)$$

*Commentary.*

Section 3 (p. 3) states: “If z = (z₁, z₂, z₃, …, zₚ) is a factorization of n, then the length of z is given by |z| = z₁ + z₂ + z₃ + … + zₚ”. It continues: “The set of lengths of n is defined by L(n) = {|z| | z ∈ Z(n)} ⊂ ℕ”. Set.image applies the coordinate sum to all factorizations of n.

**Definition 1.4 (Positive consecutive length differences).**

$$\forall p \in \mathbb{N},\; \forall g \in \operatorname{Fin}\left(p\right) \to \mathbb{N},\; \operatorname{delta}\left(g\right) = \{q : \mathbb{N} \mid \exists n \in \mathbb{N},\; \exists lone \in \mathbb{N},\; \exists ltwo \in \mathbb{N},\; (lone \in \operatorname{L}\left(g, n\right)) \land ((ltwo \in \operatorname{L}\left(g, n\right)) \land ((lone < ltwo) \land ((q = ltwo - lone) \land (\forall l \in \mathbb{N},\; (l \in \operatorname{L}\left(g, n\right)) \Rightarrow (\neg ((lone < l) \land (l < ltwo)))))))\}$$

*Commentary.*

Definition 3.1 (p. 3) states: “We define the delta set as Δ(Sₕ) = { l₂ − l₁ : l₂,l₁ ∈ L(s), L(s) ∩ (l₁,l₂) = ∅ }”. Here s ranges over all represented natural numbers and l₁ < l₂, so differences are positive and the endpoints are distinct. The final quantified clause excludes every intermediate length. Subtraction is natural-number subtraction.

$$\forall s \in \mathbb{N} \times \mathbb{N},\; \operatorname{euclidStep}\left(s\right) = \operatorname{ite}\left(\operatorname{Prod}.\operatorname{snd}\left(s\right) < \operatorname{Prod}.\operatorname{fst}\left(s\right), (\operatorname{Prod}.\operatorname{fst}\left(s\right) - \operatorname{Prod}.\operatorname{snd}\left(s\right), \operatorname{Prod}.\operatorname{snd}\left(s\right)), \operatorname{ite}\left(\operatorname{Prod}.\operatorname{fst}\left(s\right) < \operatorname{Prod}.\operatorname{snd}\left(s\right), (\operatorname{Prod}.\operatorname{fst}\left(s\right), \operatorname{Prod}.\operatorname{snd}\left(s\right) - \operatorname{Prod}.\operatorname{fst}\left(s\right)), s\right)\right)$$

*Commentary.*

Definition 3.2 (p. 3) states: “We define the subtractive Euclidean Algorithm in this way: Let x₀ and y₀ = (e,d)” and “Recursively define” the next pair as (xᵢ−yᵢ,yᵢ) if xᵢ>yᵢ, (xᵢ,yᵢ−xᵢ) if yᵢ>xᵢ, and “terminate” if xᵢ=yᵢ. The function ite selects its second argument when its first argument holds and its third otherwise. The equal pair is stationary; Prod.fst and Prod.snd are its coordinates.

*Commentary.*

Conjecture 18.3 (p. 22) states: “For Sₕ =⟨a,ah,ah+d,ah+2d,...ah+kd ⟩, Δ(Sₕ) = E(e,d)”. Section 3 (p. 2) assumes “gcd(a,d) =1, 1<k<a, h > 1” and sets “e =h−1.” All four parameters are positive natural numbers; Nat.Coprime expresses the stated greatest-common-divisor condition. The equality uses every coordinate of the expanded tuple.

**Theorem 1.9 (The expanded-generator equality is false).**

$$\neg (\forall a \in \mathbb{N},\; \forall h \in \mathbb{N},\; \forall d \in \mathbb{N},\; \forall k \in \mathbb{N},\; (0 < a) \Rightarrow ((0 < h) \Rightarrow ((0 < d) \Rightarrow ((0 < k) \Rightarrow ((\operatorname{Nat}.\operatorname{Coprime}\left(a, d\right)) \Rightarrow ((1 < k) \Rightarrow ((k < a) \Rightarrow ((1 < h) \Rightarrow (\operatorname{delta}\left(\operatorname{generators}\left(a, h, d, k\right)\right) = \operatorname{E}\left(h - 1, d\right))))))))))$$

*Commentary.*

Take (a,h,d,k)=(3,2,2,2), whose expanded tuple is (3,6,8,10). For every positive a coprime to 2, the tuple (a,2a,2a+2,…,4a−2) has delta set {1}. Replacing 2a by two copies of a, and replacing two other occurrences according to their index sum, preserves value and increases length by one. Strong induction on value minus length reaches a terminal factorization. Coprimality makes that endpoint unique by its residue modulo a; induction on a rewrite trace supplies every intervening length. Thus no larger consecutive gap occurs. Lengths 1 and 2 both occur at value 2a. At a=3 this contradicts the initial Euclidean value 2 ∈ E(1,2). The equality for the tuple omitting ah and the catenary conjectures are separate assertions.
