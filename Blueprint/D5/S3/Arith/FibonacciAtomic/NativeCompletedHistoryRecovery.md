# The completed native menu and its acquired inputs

## Abstract

Unknown-entry native completed histories have an executable inverse and only the beta first-choice ambiguity.

Letter has precisely the distinct constructors F and G. For every X : Letter and t : Source, act X t is the existing global substitution when X is F, and the current leftmost-beta split when X is G. The guarded execution theorem identifies F with replay of the sealed OLD frontier and G with the acquired current leftmost split. For every t : Source and W : List Letter, run t W folds those actual logical actions in chronological order. The empty word leaves t unchanged. The domain Native contains every attained beta-positive tree, with arbitrary unknown composition, depth and shape.

For every n0 : Nat and z : Source, recover n0 z receives only the authenticated exact entry event index and acquired final logical syntax. It does not receive the old tree, its composition, its depth, a word length, a retained pair or another acquired field. The executable computation rejects indices at most one; the beta case is classified separately. The syntax input is the existing full ordered labelled Source type, including nonnative inputs.

For every e : NativeLocalSourceExecution.Event, toCall e selects the original Geometry.NativeGuardedLeafRepair.Call.promote or Call.split at its literal logical address. For every c : Geometry.NativeGuardedLeafRepair.Call, fromCall c recovers its address and original guard tag. Address induction identifies edit with the existing subtree guard and existing replacement; chronological induction proves equality of replay with the canonical guarded-call interpreter on the converted list, including every rejected input. Converting in both directions identifies Native with actual guarded attainment from alpha with alpha excluded.

For every X : Letter and t : Source, macroCalls X t seals the original frontier for F and acquires the current leftmost beta for G. For every t : Source and W : List Letter, primitiveWord t W concatenates these actual canonical calls, recomputing each next macro frontier on its current input. Guarded-call concatenation and the one-macro correspondence prove that the entire primitive expansion reaches run t W on every native input. Its exact length is the final event index minus the entry event index. This is a proved source-run correspondence, without an assumed decoder-correctness certificate.

For every native t : Source, actual guarded attainment and the existing run_preserves_D imply the original material birth condition D. For every native t : Source, W : List Letter, labels : RawMap, next : Integer and x : Value, the existing history_preserves_values applied to the proved primitiveWord trace supplies labelsPrime : RawMap, nextPrime : Integer and y : Value for an actual nativeRun whose source is run t W. Every old material address keeps its value and every fresh material address has value zero. This connects the completed logical word to the existing guarded source, raw-label and value execution; it does not certify an installation's serialized outer return.

In the statement, Source, Address and Event are the types of NativeLocalSourceExecution; Source is ordered Bool-labelled binary syntax and Address is List Bool. NativeGuardedLeafRepairCall denotes Geometry.NativeGuardedLeafRepair.Call, and guardedRun denotes that module's run, as distinct from the macro run. RawMap is the type of functions from integers to Address, Value is the type of functions from Address to rational numbers, and Int denotes the integers. For every t : Source, material t is Geometry.NativeMaterialRootRecognition.material t, the list of material addresses. The function mem denotes membership in this list; subtract denotes truncated natural subtraction. The functions pair and quad denote ordered tuples, some and none denote Option constructors, nil denotes the empty list, cons denotes list cons, and length counts list entries. The expression map applied to an event list and toCall denotes that list mapped by toCall. The symbols F and G are the distinct Letter constructors, and K is the ordered beta/alpha branch.

## Native overlap and the exact predecessor

For every z : Source, collapse z searches only its left spine and collapses the deepest beta/alpha pair to beta. Failure means there is no such native G predecessor. For every z p : Source, collapse z equal to some p implies splitLeft p equal to z, and Native z implies Native p. For every native t : Source, collapse of splitLeft t returns t.

For every t : Source, H t retains its terminal left leaf and globally substitutes each old right subtree on the left spine. On a native input t, substitution t equals splitLeft of H t, and H t is native. Collapse of H t always fails: each deepest right subtree is a substitution image and cannot be alpha. Its event index plus one equals the entry event index plus its old leaf count. Consequently, at a multileaf native entry its event index strictly exceeds the entry index. This is the native overlap boundary, rather than a disjoint-image root-graft argument.

For every z : Source, rhoPredecessor z runs the existing inverseCode at rank one on encode z, expands the candidate and checks literal forward substitution equality. The existing finite_normal_inverse supplies the candidate on every actual image; the existing public substitution injectivity identifies its expansion. The final equality test rejects any phantom candidate on other inputs. No new copy of the substitution parser or assumption of decoder correctness is used.

For every n0 : Nat and z : Source above the entry index, previous first requires a successful collapse c. It chooses G when c has index n0 or itself admits collapse. Otherwise it requires a successful rhoPredecessor and a native predecessor and chooses F. In an actual G-ending history, c is the preceding tree: it is either the entry or a nonempty macro output. In an actual F-ending history from a multileaf tree s, c is H s: collapse fails there and its index strictly exceeds n0. Thus this test selects the actual last letter, including histories whose entry and word length were unknown.

## Total finite decoding and both inverse laws

For every fuel : Nat, n0 : Nat and z : Source, recoverFuel returns a pair whose first component is a Nat accepted-transition count and whose second component is an optional pair of entry Source and literal List Letter. It rejects a nonnative tree, an index at most one, or a current index below n0. Equality of indices returns the current tree and empty word. Otherwise a positive fuel permits exactly one previous transition, with an explicit test that its index lies between n0 and the current index, strictly below the latter. It recursively decodes that predecessor, increments the returned count once even if a later check rejects, and appends the selected last letter to a successful answer. For every n0 : Nat and z : Source, recover uses exactly eventIndex z minus n0 as fuel and projects that computation’s answer; recoverySteps projects the same computation’s count. Structural recursion on this computed natural fuel terminates on every finite input.

*Commentary.*

Induct on the chronological word by appending its last letter. The native overlap boundary selects the actual predecessor and strict event growth supplies sufficient smaller fuel. This proves recovery of the entire original pair on every actual input, with the empty word included. Conversely induct on decoding fuel. Every accepted predecessor really replays to the supplied syntax; the accepted base is native and has exactly the supplied entry index. Hence every accepted answer is in the actual image. The public success equivalence states the entry domain directly as actual canonical guarded attainment from alpha. Positive entry index excludes alpha and the proved sort equivalence supplies Native; no attainment witness is a runtime input. The success equivalence yields rejection exactly off that image, and applying it to two purported answers proves injectivity even across different unknown entries.

Every successful primitive adds one event. Every macro adds at least one. Induction on fuel bounds the accepted-transition count on every input, including inputs eventually rejected. On success that count equals the returned literal word length. Thus the number of accepted predecessor transitions is at most the final event index minus n0. Every accepted previous transition has a strictly smaller event index. This counts descriptive predecessor transitions; it supplies no bit-complexity, physical driver-duration or uniform workspace bound.

At index one the attained entry is beta. Strict event growth makes its empty word the only history ending again at beta. Both first letters send beta to K, the ordered beta/alpha pair of index two. Applying the already established index-two inverse to any nonempty beta endpoint gives one unique entire suffix U : List Letter. Its full fibre consists exactly of F followed by U and G followed by U. No other word or entry belongs to this fibre.

For every supplement type A, function E from literal words to A and suffix U, there exists a decoder of E on this concrete fixed endpoint fibre exactly when E gives different values on F followed by U and G followed by U. Equal supplementary values force the same decoder answer for two distinct targets. Distinct values select their first letter and share the recovered suffix. For every W : List Letter, firstChoice W is true exactly when its first letter is F, and is false at G or the empty word. This explicit Boolean supplement has a checked decoder on each nonempty endpoint fibre. Thus one binary first-macro choice is necessary and sufficient under this conditioning. An actual retained request or script channel can already supply that distinction; no additional bit is then required. This is a two-point native fibre statement, with no general coding or information theorem substituted for it.

The same-source acquisition, rights, lawful stationary traversal, complete ancestral tapes and finite backing premises remain explicit. All primitives and outer macros must have completed their actual replies, acknowledgements and returns. Parsed syntax alone does not certify that completion. The inverse computes descriptions only. It grants no source reset, deletion, physical undo, old pointer restoration, copying authority, elapsed-time recovery or reduced total installation storage. The unfinished-history join can use this completed inverse only for macros whose outer returns have actually completed.
