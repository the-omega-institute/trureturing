# Native Literal Moore Budgets

## Abstract

Exact literal submission budgets on the entire actual stationary Moore fiber.

Full original fiber and four prices

Fix a finite prefix-free cut P and an arbitrary actual finite reference origin uo. Write C=canonicalRow(P,rho(uo)). OriginFiber(P,C) is the entire actual set of finite ordered alpha/beta origins u with canonicalRow(P,rho(u))=C. ImageValues(C) contains the acquired injective class values whose filling is an actual substitution image. The existing imageOriginEquiv is their bijection. The complete exterior, every reached occurrence, repeated-class partition, all different-class disequalities and every blocked-cut guard remain fixed. The whole target is target(C,theta)=canonicalRow(P,u), by native_full_root_feasibility. There is no source-size, depth or intrinsic-rank bound.

Occurrences(C,d) filters the original physical holeAddresses by holeLabel=d. Shortest(C,d) minimizes the pair (length(p),p) in lexicographic product order; price(C,d) is its length. The private shortest_spec applies the existing labels_witness and pinned Mathlib List.argmin and List.le_of_mem_argmin. Its first conclusion is occurrence membership; every occurrence p has length at least price(C,d), and equality of lengths implies shortest(C,d) is lexicographically at most p. Original numeric class names do not change. NativeWholeRowService.representative chooses the first lexicographic occurrence and is not assumed shortest.

For the existing Controller and Run, nativeCost(M,tr) sums length(M.addr(s)) over the exact running-state visit list tr. RootCost(T,tr) sums price(C,T.coord(s)) over that same kind of list. These are per-input sums before upper bounds. Repeated coordinates, repeated words, absence and empty words each cost one call; the empty word costs zero literal letters. An initial halt has empty trace and zero of both charges. No new controller, evaluator or candidate enumeration is introduced.

NativeLiteralFeasible extends the original NativeFeasible telescope with nativeCost at most ell on each original actual origin. The code is a function of actually acquired ImageValues and is the current initial state itself. RootLiteralFeasible extends RootFeasible with rootCost at most ell on every attained Chart. The remaining upper bounds are code-image cardinality at most r, cardinality of all installed running plus halting states at most K, and at most q calls. Unused states, equal-output halts and unused addresses count. Both encoder and table may be reselected.

Acquisition, genuine pre-cut export, complete access isolation, authenticated one-update continuity, lawful common entry and the stationary native port remain supplied paid premises. Literal cost prices only physically submitted words. Address construction and storage, table storage, whole-output representation, local work, elapsed time, acquisition, export, authentication, isolation, entry and service retain their separate costs. No mathematical theorem certifies those physical services.

The public supplier interfaces retain one original implementation and proof: NativeWholeRowService.labels_witness supplies occurrence nonemptiness; ActualObserverAbsorbingNormalization.skip_exact, skip_retained and skip_removed supply finite first exits; NativeSharedMooreSynthesis.referenceValues and referenceType supply truthful actual witnesses, and its evaluate_halt, evaluate_exact, evaluate_reindex, candidate_complete, bounded_mem and bounded_size supply exact evaluation and enumeration. All types in these public signatures are reachable through their original imports. Literal_candidate_sound is consumed by finite_literal_synthesis and the actual full-fiber candidate application; zero_call_literal is consumed by zero_budget_endpoint and its Reg family. Public visibility contributes no new mathematical content.

Static forced-successor contraction

The firstClass traversal is reused with its original hole identities and below-hole flag. Literal_geometry establishes two exhaustive implications. An exterior result inl(z) gives readout(a,evaluateRow(f,C))=z for every filling f, including arbitrary fillings not in the actual image. A hole result inr(d,below) gives an actual physical occurrence p of d and a suffix w with a=p++w, rowAt(p,C)=hole(d), and below exactly when w is nonempty. This includes visible ancestors, concrete leaves, blocked cones and absent extensions.

A running state survives exactly when its word enters a hole. Halts are always retained. For removed states the forced successor is M.next(s,z), where firstClass supplies the exterior reply z. ContractCode is a single finite static map on the entire installed carrier. It returns the first surviving running state or original halt along forced successors; when no exit exists it returns one fixed original halt z0. The public original skip_exact, skip_retained and skip_removed suppliers provide the finite first-exit facts. Their finite-orbit machinery identifies a nonexiting finite basin with eventual repetition. Every state of that basin has the same completion z0.

The exitAdapter only instantiates the existing finite first-exit proof. Its predicate labels and empty decoder are proof data, never an installed state, cache, field, service or query. No cached-observer normalization theorem is applied to a native run. Only the exact finite first-exit primitives are reused, under their own finite carrier assumptions.

A terminating Run on any filled row cannot start in or reach a nonexiting forced basin: induction on that exact Run gives a finite first exit. This also applies when the exported initial state is removed. Different inputs may still use opposite edges of a shared cycle; the argument excludes only a forced constant cycle on one required input.

Contract installs the surviving subtype of the original running carrier together with every original halt. Surviving addresses and all halt outputs are unchanged; next(s,z) is ContractCode(M.next(s,z)). It does not clone histories or add a state. The export is actually replaced before entry by ContractCode composed with the original acquired code. This changes the exported code itself and retains no copy of the old code. An initial forced chain ending at a halt initializes that halt directly; no post-entry silent step, phase or extra field is introduced.

Contract_run proves the exact filtered original successful Run, ending at the identical original halt. Its first conjunct is the live transfer input. The separate run_exit basin-exclusion proof supplies its second conjunct, which the main transfer projects away; basin exclusion remains an independently required source conclusion. SurvivingTrace deletes exactly the removed running visits and retains their order. Each next edge jumps across the intervening forced segment. Thus calls and submitted words are precisely the surviving calls and words of the same original input. Filtered_resources bounds both its length and its sum by the corresponding original quantities. The code image is an image of the old code image, and the surviving carrier is a subtype, so neither cardinality increases. The arbitrary nonexiting-basin completion is used on no required path.
