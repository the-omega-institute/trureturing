# Ordered source syntax and original local guards

## Abstract

Guarded native source execution, birth sorts and exact successful-event indices.

Source is the existing free ordered binary magma over Bool: true labels alpha and false labels beta. Address is List Bool, with false for a left edge and true for a right edge. Event is Address times Bool. For every t : Source, p : Address and k : Bool, edit t p k navigates existing logical binary children. At a reached leaf labelled b it succeeds exactly when b equals k, returning its original local replacement. Thus true is precisely promotion P at alpha and false is precisely split S at beta. A wrong tag, branch target, absent address or attempted descent through a leaf rejects. Beta's unary material marker is excluded from this logical navigation.

For every t : Source and es : List Event, replay t es executes these guarded events chronologically, propagating rejection. For every t : Source, oldFrontier t is the finite left-first list of its original leaf addresses and their actual labels. The list is sealed before replay. Each branch concatenates the left list, prefixed by false, and the right list, prefixed by true. Newly created leaves do not enter this list. For every t : Source, leftmost t follows only left logical children; splitLeft t changes just its terminal beta on the native domain.

For every a : Bool and t : Source, native a t is the birth-sort test: at a leaf labelled b it tests whether a is true or b is false; at a branch it tests the left child at false and the right child at true. For every t : Source, Native t means native false t is true. The root sort true is exactly attainment from alpha by the original guarded events. The root sort false is exactly such attainment with alpha excluded. These tests retain all irregular shapes and every finite depth, with no composition restriction.

For every t : Source, eventIndex t is the number of alpha leaves plus twice the number of beta leaves, minus one. This is an alpha-origin successful-event count. It is not material size, elapsed time or replacement quantity.

In the statement, of is the labelled leaf constructor, some is the successful Option constructor, and List is the finite-list type constructor. The function length counts leaves on Source and entries on lists. The function composition returns the ordered pair of alpha and beta leaf counts. The function add denotes natural addition or componentwise addition of these natural pairs, and pair denotes an ordered pair.

*Commentary.*

Lift a finite guarded replay into either child of a fixed branch. Chronological concatenation then proves, by induction over the entire original tree, that the sealed frontier reaches precisely the existing global substitution. The proof covers both leaf tags and every ordered pair. It executes one event per original leaf. The left descent of a native tree ends at beta, so its single S guard succeeds; induction preserves the right siblings and gives the alpha-translation composition law.

Each successful P or S increases eventIndex by exactly one. Address induction transports that equality through an arbitrary enclosing ordered source; chronological induction sums it over a successful replay. Leaf-count total is directly the existing ActualObserverAbsorbingNormalization.composition_total, and substitution composition is directly the existing fiberMap law. Together with the native beta count this gives the full-frontier increment equal to the old number of leaves, the leftmost-split increment one, and eventIndex one exactly at beta.

For the attained-domain equivalence, a guarded edit preserves the birth-sort test, and hence so does every successful replay. Conversely construct every accepted target from its birth tag. At a branch, perform its necessary root promotion, if any, and root split, then replay the constructed left child from beta and the right child from alpha. Prefixing the two child event lists gives actual legal guarded source executions. Thus no unattained tree is silently admitted and no attained beta-positive entry is omitted.

The physical interpretation retains one authentically bound root, source and epoch, current exclusive rights, stable finite traversal and actual reached operands. Every primitive performs all ancestral-tape maintenance and consumes its literal reply, acknowledgement and inner return. A completed outer F or G additionally consumes its own full reply, acknowledgement and real return. These are completion and resource premises of the native installation; logical replay does not certify controller bytes or an unfinished outer call. Finite reference, exact counter, frontier, traversal, workspace and output backing are supplied for each finite run. There are no interleaved source edits and no fixed finite arena for all histories.
