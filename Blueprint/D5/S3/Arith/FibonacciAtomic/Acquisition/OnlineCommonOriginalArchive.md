# An online common-original arithmetic archive

## Abstract

Successively acquired precisions label one original source and every authentic retained cut, with a cumulative bound on actual paid reads.

The source is one natural pair v0, including zero, at one opaque retained binding h. The original actions are R(a,b)=(b,a+b) and G(a,b)=(a+1,b); true denotes R. SourceService gives their actual completed effects, fixed acknowledgements and a nondestructive paid current reply gcd(2a+3b,H). Its value map is a semantic projection and is never a program input. VariableCompletion(B,h) requires completion at every positive public modulus used by the program. This includes its envelopes, not just the requested moduli. Lawful rights, exclusive serialization, absence of side channels and adequate finite material for each chosen finite run remain supplied premises.

**Definition 1.1 (One public integer covers a budget).**

$$(\forall b \in \operatorname{Nat}\left(\right), \operatorname{envelope}\left(b\right) = \prod_{p \in \operatorname{Nat}\left(\right), \operatorname{Prime}\left(p\right) \land p \le b+1} p^{\left\lfloor\frac{b}{p-1}\right\rfloor}), \operatorname{envelope}\left(0\right) = 1$$

*Formalization.* `D5/S3/Arith/FibonacciAtomic/Acquisition/OnlineCommonOriginalArchive.envelope` (`✓ std3`).

*Source.* Repository-derived.

*Commentary.*

primes(b) is the prime filter of range(b+2), and envelope(b) is the product of p^(b/(p-1)) over it. Division is natural integer division. Thus envelope(0)=1. For every positive H, H divides envelope(b) exactly when costBound(H)<=b; costBound(envelope(b))=b. Increasing b increases the envelope by divisibility.

**Definition 1.2 (Least covering power of two).**

$$(\forall m \in \operatorname{Nat}\left(\right), \operatorname{budget}\left(m\right) = \operatorname{ite}\left(m = 0, 0, \operatorname{pow}\left(2, \operatorname{clog}\left(2, m\right)\right)\right))$$

*Formalization.* `D5/S3/Arith/FibonacciAtomic/Acquisition/OnlineCommonOriginalArchive.budget` (`✓ std3`).

*Source.* Repository-derived.

*Commentary.*

Nat.clog is the integer ceiling logarithm. For m>0 this gives m<=budget(m)<2m, and budget(m)<=2^k for every integer k with m<=2^k. It uses integer computation.

Memory has precision, joint, requests, tape, original and current fields. The two residue registers belong to (ZMod envelope(precision)) squared. initial has precision 0, joint 1, empty requests and tape, and the singleton zero registers. Every actual completed action and its fixed acknowledgement is recorded as an action event. Each paid reply records both its modulus and value. Compute events are local intervals with no source reply. letters removes computes and replies, reads counts every reply occurrence, and cutWord(tape,t) takes the first t actual source letters. TapeRun is generated by the actual service calls on this same binding. Every t up to the letter count consequently names an actual past cut, including acquisition and closing cuts.

A delivered positive request H is covered when costBound(H)<=precision. A covered request updates the request list and its lcm with no source call. On a miss the new precision is budget(costBound(H)); the program runs PositiveClosingExecution.controller at its exact envelope. RequestRun requires that controller's actual ServiceRun, starting at the current world, including all closing letters. Only after it halts does install append the stamped tape, store the earned stage-entry label d as current, and set original=rewind(E,oldLetters,d). Rewind reverses recorded letters locally: R is inverted by (x,y)->(y-x,x), and G by (x,y)->(x-1,y), in the residue ring. It calls no source inverse and inspects no hidden integer. The fixed acquisition code takes only public arithmetic and replies acquired on its actual execution.

A continuation input supplies a finite chronological word. ContinueRun uses the existing request, actual completion, fixed acknowledgement and local commit protocol, with original immutable and current updated by scratch. advanceMemory appends its actual action letters. There is no read instruction in this protocol. OnlineRun sequentially composes these request and continuation calls, admitting the next input only at their completed cuts. Its rules consult only that next delivered input. Quantification over every finite input list therefore includes every realized finite adaptive history, repeated requests and empty continuations, without any promise of future precision or source-independent choices by the environment.

*Commentary.*

Induction over actual request and continuation segments establishes Sound. At a miss, the invariant consumes the arbitrary-modulus UpgradeRecovery theorem at the newly chosen envelope. Physical acquisition returns the current source modulo that envelope. Local rewind recovers the same v0 from its authentic old prefix. The executed full tape then labels every actual past cut.
