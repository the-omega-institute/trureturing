# The Actual Merca Real Quadratic Subfield

## Abstract

The quadratic Gauss sum in the actual prime cyclotomic field identifies the Merca quartic field's maximal real subfield with Q(sqrt(r)).

For every prime r congruent to five modulo eight, the quadratic Gauss sum squares to r. The actual quartic kernel has odd order, so the quadratic character is one on it. Galois action on the Gauss sum is a multiplicative shift, proving that this root lies in the actual quartic fixed field. Every complex embedding of the root has positive real square r, hence real image. The resulting quadratic embedding is onto the degree-two maximal real subfield. No choice of sign for the Gauss root is needed for this field identification.

The order generated by (1 plus sqrt(r)) divided by two has integer polynomial X squared minus X minus (r minus one) divided by four. Its order discriminant is the prime r. The existing squarefree-discriminant maximality theorem identifies this order with the actual ring of integers of Q(sqrt(r)), through an explicit algebra equivalence.
