# Absolute Scalar Height

## Abstract

Absolute scalar logarithmic height is relative logarithmic height normalized by field degree.

**Theorem 1.1 (Absolute Scalar Height).**

*Commentary.*

For a number-field element, multiplying absolute logarithmic height by the field degree gives the relative scalar logarithmic height.
