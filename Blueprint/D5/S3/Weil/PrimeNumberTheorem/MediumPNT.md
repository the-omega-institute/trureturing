# MediumPNT

## Abstract

The Chebyshev psi error decays by an exponential power of logarithm.

**Theorem 1.1 (MediumPNT).**

*Commentary.*

There exists a positive real c such that the second Chebyshev function minus the identity is bounded asymptotically by a constant times x times exp of minus c times the one-tenth power of log x. Neither c nor the eventual multiplicative bound is asserted to be explicit.
