# PntLongVertical

## Abstract

The long vertical contour admits a uniform logarithmic-power estimate.

*Commentary.*

Let the real smoothing kernel be continuously differentiable and supported in [1/2, 2]. Assume LogDerivZetaHasBound A Cζ, with Cζ positive and 0 < A ≤ 1/2. There is a positive constant C such that, for every X > 3, T > 3 and 0 < epsilon < 1, setting sigma₁ = 1 − A/(log T)^9 gives the bound ‖I₃‖ ≤ C times X times X to the power −A/(log T)^9, divided by epsilon.
