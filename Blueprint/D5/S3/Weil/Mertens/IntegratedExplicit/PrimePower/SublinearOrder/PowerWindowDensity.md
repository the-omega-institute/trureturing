# Combination of the signed responses

## Abstract

Power-weighted prime-window density

For a prefix estimate of order q^β, the signed arithmetic tail and near centered response have coefficients of order q^β. The signed trivial-root term has an extra 1+log q factor.

If the far omitted-root sum has coefficient q^κ with κ>β, the trivial-root logarithm is absorbed by the slack κ−β. Each contribution has the same exponential density factor.
