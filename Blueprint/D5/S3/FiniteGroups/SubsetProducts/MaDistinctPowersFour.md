# Ma's distinct powers question

## Abstract

An n-element subset (n > 0) of a finite group with no elements of orders 2 through n + 1 admits pairwise distinct powers with exponents 1 through n if its generator classes have size at most four.

**Theorem 1.1 (The size-four extension of Theorem 1.1).**

$$\forall (n : \mathbb{N}) (G : Type) [Group\left(G\right)] [Finite\left(G\right)] (A : Finset\left(G\right)), 0 < n \to A.card = n \to (\forall (x : G) (k : \mathbb{N}), 2 \le k \to k \le n + 1 \to orderOf\left(x\right) \neq k) \to (\forall (x : G), x \in A \to \operatorname{Nat.card}\left(\{y : G \mid y \in A \land \operatorname{Subgroup.zpowers}\left(y\right) = \operatorname{Subgroup.zpowers}\left(x\right)\}\right) \le 4) \to \exists (a : Fin\left(n\right) \equiv \{x : G \mid x \in A\}), \forall (i j : Fin\left(n\right)), (a\left(i\right) : G)^{i.val + 1} = (a\left(j\right) : G)^{j.val + 1} \to i = j$$

*Commentary.*

Remark 2.2 and Section 9 ask about every positive subset size n. The group is arbitrary and finite. The order exclusion applies to every element of G and every integer from 2 through n + 1, inclusive. For each x in A, the subtype in the class bound counts precisely the members of A generating the same cyclic subgroup as x. The equivalence enumerates the members of A once and gives exponents 1 through n by adding one to the zero-based index. The last implication expresses pairwise distinctness. The hypotheses include subsets containing the identity.

As in Ma's proof of Theorem 1.1, an admissible exponent preserves the cyclic subgroup generated by the element, so powers from different classes cannot coincide. Complementary endpoint pairs go to two-element classes, consecutive triples and quadruples go to the corresponding classes in the remaining interval, and the last positions go to singletons.

In a four-element class the four distinct coordinates are units modulo the full common order. The order-four Latin-array proof gives a transversal, equal column symbol sets, or a specified motif. A commutative product array excludes the motif. Equal columns would force a multiplicative coset after reduction to a prime dividing the order. The first and second power sums of the four consecutive coefficients rule it out. The transversal therefore supplies a valid block even when the reduced generator coordinates repeat.
