# Finite conjugation subquandles

## Abstract

Shared source-attributed definitions for finite conjugation subquandles, used by both Ta counterexamples.

**Definition 1.1 (Closure under conjugation).**

$$\forall (G : \operatorname{Type}) [\operatorname{Group}\left(G\right)] [\operatorname{DecidableEq}\left(G\right)], (\forall X : \operatorname{Finset}\left(G\right), (\operatorname{ConjClosed}\left(X\right) \Leftrightarrow (\forall x : G, ((x \in X) \Rightarrow (\forall y : G, ((y \in X) \Rightarrow (x \cdot y \cdot x^{-1} \in X)))))))$$

*Formalization.* `D5/S3/FiniteGroups/Quandles/ConjugationSubquandle.ConjClosed` (`✓ std3`).

*Citation.* Lực Ta (2025). *Good involutions of conjugation subquandles*. DOI: [10.48550/arXiv.2505.08090](https://doi.org/10.48550/arXiv.2505.08090). URL: <https://arxiv.org/abs/2505.08090v5>.

*Commentary.*

Ta, Lemma 2.10, printed page 5: "For all subsets X ⊆ G, the pair Conj X := (X, s|_X) is a subquandle of Conj G if and only if X is closed under conjugation by elements of the subgroup ⟨X⟩ of G generated by X." Here G is a group with decidable equality and X is a finite subset. ConjClosed uses the element-wise closure condition for conjugation by elements of X. For finite X these conjugation maps are injective self-maps and hence permutations; closure then extends to H = ⟨X⟩.

**Definition 1.2 (The restricted conjugation operation).**

$$\forall (G : \operatorname{Type}) [\operatorname{Group}\left(G\right)] [\operatorname{DecidableEq}\left(G\right)], (\forall X : \operatorname{Finset}\left(G\right), (\forall h : \operatorname{ConjClosed}\left(X\right), (\forall x : X, (\forall y : X, (\operatorname{s}\left(h, x, y\right) = \langle\operatorname{val}\left(x\right) \cdot \operatorname{val}\left(y\right) \cdot \operatorname{val}\left(x\right)^{-1}, h\left(\operatorname{val}\left(x\right), \operatorname{property}\left(x\right), \operatorname{val}\left(y\right), \operatorname{property}\left(y\right)\right)\rangle)))))$$

*Formalization.* `D5/S3/FiniteGroups/Quandles/ConjugationSubquandle.s` (`✓ std3`).

*Citation.* Lực Ta (2025). *Good involutions of conjugation subquandles*. DOI: [10.48550/arXiv.2505.08090](https://doi.org/10.48550/arXiv.2505.08090). URL: <https://arxiv.org/abs/2505.08090v5>.

*Commentary.*

Ta, Example 2.6, printed page 5: "Let G be a group, and define s : G → S_G by sending each element g ∈ G to the conjugation map defined by s_g(h) := ghg⁻¹ for all h ∈ G. Then Conj G := (G, s) is a quandle called a conjugation quandle or conjugacy quandle. Note that s_g⁻¹ = s_{g⁻¹} for all g ∈ G." The domain X in s is the subtype of elements of the finite subset; val forgets the membership proof and property supplies it. The argument h : ConjClosed X certifies that the displayed value belongs to X.

**Definition 1.3 (Good involutions).**

$$\forall (G : \operatorname{Type}) [\operatorname{Group}\left(G\right)] [\operatorname{DecidableEq}\left(G\right)], (\forall X : \operatorname{Finset}\left(G\right), (\forall h : \operatorname{ConjClosed}\left(X\right), (\operatorname{Good}\left(X, h\right) = \{\rho : X \to X \mid ((\forall y : X, (\rho\left(\rho\left(y\right)\right) = y)) \land (\forall x : X, ((\rho \circ \operatorname{s}\left(h, x\right) = \operatorname{s}\left(h, x\right) \circ \rho) \land ((\forall y : X, (\operatorname{s}\left(h, \rho\left(x\right)\right)\left(\operatorname{s}\left(h, x\right)\left(y\right)\right) = y)) \land (\forall y : X, (\operatorname{s}\left(h, x\right)\left(\operatorname{s}\left(h, \rho\left(x\right)\right)\left(y\right)\right) = y))))))\})))$$

*Formalization.* `D5/S3/FiniteGroups/Quandles/ConjugationSubquandle.Good` (`✓ std3`).

*Citation.* Lực Ta (2025). *Good involutions of conjugation subquandles*. DOI: [10.48550/arXiv.2505.08090](https://doi.org/10.48550/arXiv.2505.08090). URL: <https://arxiv.org/abs/2505.08090v5>.

*Commentary.*

Ta, Definition 3.8, printed page 7: "Let R = (X, s) be a rack. A good involution of R is an involution ρ ∈ S_X that satisfies the equalities ρ s_x = s_x ρ, s_{ρ(x)} = s_x⁻¹ for all x ∈ X. We denote the set of good involutions of R by Good R." Good X h is the subtype of functions ρ : X → X satisfying these conditions. Involutive means ρ(ρ(y)) = y for every y; it implies bijectivity. The two displayed inverse identities encode Function.LeftInverse and Function.RightInverse, respectively, without requiring x⁻¹ ∈ X. The fixed parameter h certifies closure.

**Definition 1.4 (Automorphisms).**

$$\forall (G : \operatorname{Type}) [\operatorname{Group}\left(G\right)] [\operatorname{DecidableEq}\left(G\right)], (\forall X : \operatorname{Finset}\left(G\right), (\forall h : \operatorname{ConjClosed}\left(X\right), (\operatorname{Aut}\left(X, h\right) = \{\phi : X \to X \mid ((\operatorname{Bijective}\left(\phi\right)) \land (\forall x : X, (\forall y : X, (\phi\left(\operatorname{s}\left(h, x, y\right)\right) = \operatorname{s}\left(h, \phi\left(x\right), \phi\left(y\right)\right)))))\})))$$

*Formalization.* `D5/S3/FiniteGroups/Quandles/ConjugationSubquandle.Aut` (`✓ std3`).

*Citation.* Lực Ta (2025). *Good involutions of conjugation subquandles*. DOI: [10.48550/arXiv.2505.08090](https://doi.org/10.48550/arXiv.2505.08090). URL: <https://arxiv.org/abs/2505.08090v5>.

*Commentary.*

Ta, Definition 2.17, printed page 6: "Given two racks (X, s) and (Y, t), we say that a map φ : X → Y is a rack homomorphism if φs_x = t_{φ(x)}φ for all x ∈ X. A rack isomorphism is a bijective rack homomorphism, and a rack automorphism of a rack R is a rack isomorphism from R to itself." Definition 2.20, printed page 6: "We denote the automorphism group of a rack R = (X, s) by Aut R." Aut X h is the subtype of bijections satisfying the homomorphism identity pointwise for all x and y.

**Definition 1.5 (The number of conjugation orbits).**

$$\forall (G : \operatorname{Type}) [\operatorname{Group}\left(G\right)] [\operatorname{DecidableEq}\left(G\right)], (\forall X : \operatorname{Finset}\left(G\right), (\operatorname{orbitCount}\left(X\right) = \operatorname{FinsetCard}\left(\operatorname{image}\left((x \mapsto \operatorname{filter}\left((y \mapsto \exists g : G, ((g \in \operatorname{closure}\left((X : \operatorname{Set}\left(G\right))\right)) \land (g \cdot x \cdot g^{-1} = y))), X\right)), X\right)\right)))$$

*Formalization.* `D5/S3/FiniteGroups/Quandles/ConjugationSubquandle.orbitCount` (`✓ std3`).

*Citation.* Lực Ta (2025). *Good involutions of conjugation subquandles*. DOI: [10.48550/arXiv.2505.08090](https://doi.org/10.48550/arXiv.2505.08090). URL: <https://arxiv.org/abs/2505.08090v5>.

*Commentary.*

Ta, section 6.3.1, printed page 14: "In the following, let X/H denote the set of orbits of X under the action of H by conjugation." Corollary 6.12 begins: "Let k(X) := |X/H|." Here H = Subgroup.closure (X : Set G). The image sends each x ∈ X to the finite subset of y ∈ X of the form g x g⁻¹ for some g ∈ H. Its cardinality counts distinct orbit subsets, with duplicates removed by Finset.image. The existential variable g has type G; membership in H is an explicit conjunct. filter and image have the predicate/function first and the finite subset second.
