*Commentary.*

If the realization of an order map is nullhomotopic, composing with enough iterated chain-maximum projections gives an order map joined to a constant by a finite fence of pointwise comparisons. The iterated maximum is supported in each original carrier. Taking the maximum of an image chain commutes with the given order map, so the first map of the fence is the exact composite.
