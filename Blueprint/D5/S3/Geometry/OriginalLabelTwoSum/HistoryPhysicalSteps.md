# Physical rows and earlier-history step outputs

## Abstract

Physical rows and earlier-history step outputs.

The actual wheel labels identify physical rim rows and their projected incidence. Leaf and neighbour cases are proved at those original positions. Earlier-history outputs then construct empty-row, zero-local, unused-local, marker and intact terminal steps, using the stated old-history input and the same residual masks.
