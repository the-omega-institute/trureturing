# Original-label path components

## Abstract

Original-label path components.

Rows keep their actual indices and multiplicities. Singleton constraints force original labels, while pruning removes only redundant size-two rows touching those forced labels. Connectivity is characterized by surviving consecutive cut intervals; component roots, singleton ghosts and untouched endpoint connectivity use the same original path positions.
