# Balanced transitions on actual face-paired edge stars

## Abstract

Each actual occurrence contributes one transition; path ends are signature changes.

RawFacePairing on an arbitrary finite type T retains every actual face slot, the involutive face pairing and its inverse slot maps. GlobalEdge is the equivalence class generated by paired slots. A Boolean color is shared on that class. ValidColoring requires every local face to have one or two low edges. No manifold or geometric realization is a hypothesis of these combinatorial statements. Prefix notation denotes the named definitions; snd is the second projection of an occurrence.

**Theorem 1.1 (Path ends and successor signature).**

$$\forall T \in Type, Edge \in Type, s \in EdgeStars\left(T, Edge\right), i \in Occurrence\left(T\right),\; Fintype\left(T\right) \Rightarrow \left(\left(isPathEnd\left(localColor\left(s, i\right), snd\left(i\right)\right) \Leftrightarrow signature\left(s, i\right) \ne signature\left(s, next\left(s, i\right)\right)\right) \land signature\left(s, next\left(s, i\right)\right) = decide\left(faceLowCount\left(localColor\left(s, i\right), outgoing\left(s, i\right)\right) = 2\right)\right)$$

*Commentary.*

An occurrence is a path end exactly when its incoming and successor signatures differ. Face-slot transport identifies the successor signature with the outgoing face low-count-two indicator. **Theorem 1.2 (Rise equals fall and path-end count is even).**
