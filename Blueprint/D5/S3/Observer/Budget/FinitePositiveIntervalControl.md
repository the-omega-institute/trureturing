# Finite Stationary Positive Interval Control

## Abstract

A finite stationary unit table realizes positive interval sensing, recovers both source labels, and attains its logarithmic worst read count.

Fix natural p>=2 and P>0. Set H=clog(2,P), B=H(P-1), and X=ZMod(pP). The physical source starts at the unknown x. A wait adds one to the source and returns no information; a read preserves the source and returns floor([s]_(pP)/P). The table has one common Start control.

Apart from Start, a control stores a first digit in Fin(p), an ordered pair of interval endpoints in Fin(P), an elapsed count in Fin(B+1), a remaining-wait counter in Fin(P), and a mode in Fin(3). The modes are Wait, Read, and Done. Every changing field belongs to this finite carrier Q. The fixed action, wait successor, read successor, and output tables use only these fields and, for a read successor, the actual digit. Write Q=Control(p,P,B) and C for this fixed table.

The first read stores its digit and the full interval. A singleton enters Done; otherwise the control enters Wait with the positive phase distance minus one in the countdown. Each Wait performs one source increment, increments the stored elapsed count, and either decreases the countdown or enters Read when it was zero. Read splits the interval at its midpoint, using the retained digit and stored elapsed count to decode the actual answer. The successor is Done for a singleton and otherwise Wait. Waiting requires the elapsed count to be below B; a final read remains available at B. Other nonterminal rows perform a read and enter Done, so all nominal rows and all digits have a defined successor.

For a natural list w, Unit(w) concatenates W repeated w_i times and one R for each entry. Follows(C,c,v,z) recursively checks that each letter of v is exactly the action prescribed at c, then applies the corresponding unit transition. It ends at z with no additional action. RCount and WCount count the corresponding letters. Initial(q)=bP+L modulo pP and Current(q)=bP+L+E modulo pP are fixed functions of the terminal control. All letters in R::Unit(w) are actual source actions.

**Theorem 1.1 (Finite execution, both outputs, exact counts, and the singleton case).**

$$\forall p : \mathbb{N}, \forall P : \mathbb{N}, \left(2 \leq p \land 0 < P\right) \implies \left(\operatorname{Finite}\left(\operatorname{Control}\left(p, P, \operatorname{clog}\left(2, P\right) \times \left(P - 1\right)\right)\right) \land \operatorname{action}\left(\operatorname{table}\left(p, P, \operatorname{clog}\left(2, P\right) \times \left(P - 1\right)\right), Start\right) = R \land \left(\forall x : \operatorname{ZMod}\left(p \times P\right), \exists q : \operatorname{Control}\left(p, P, \operatorname{clog}\left(2, P\right) \times \left(P - 1\right)\right), \exists w : \operatorname{List}\left(\mathbb{N}\right), \left(\operatorname{Follows}\left(\operatorname{table}\left(p, P, \operatorname{clog}\left(2, P\right) \times \left(P - 1\right)\right), \operatorname{Pair}\left(x, Start\right), \operatorname{Cons}\left(R, \operatorname{Unit}\left(w\right)\right), \operatorname{Pair}\left(\operatorname{Current}\left(q\right), q\right)\right) \land \operatorname{action}\left(\operatorname{table}\left(p, P, \operatorname{clog}\left(2, P\right) \times \left(P - 1\right)\right), q\right) = halt \land \operatorname{Initial}\left(q\right) = x \land \operatorname{Current}\left(q\right) = \operatorname{Add}\left(x, \operatorname{Cast}\left(\operatorname{sum}\left(w\right), \operatorname{ZMod}\left(p \times P\right)\right)\right) \land \operatorname{length}\left(w\right) \leq \operatorname{clog}\left(2, P\right) \land \operatorname{sum}\left(w\right) \leq \operatorname{clog}\left(2, P\right) \times \left(P - 1\right) \land \left(\forall v : \mathbb{N}, v \in w \implies \left(0 < v \land v < P\right)\right) \land \operatorname{RCount}\left(\operatorname{Cons}\left(R, \operatorname{Unit}\left(w\right)\right)\right) = 1 + \operatorname{length}\left(w\right) \land \operatorname{WCount}\left(\operatorname{Cons}\left(R, \operatorname{Unit}\left(w\right)\right)\right) = \operatorname{sum}\left(w\right)\right)\right) \land \left(\exists x : \operatorname{ZMod}\left(p \times P\right), \exists q : \operatorname{Control}\left(p, P, \operatorname{clog}\left(2, P\right) \times \left(P - 1\right)\right), \exists w : \operatorname{List}\left(\mathbb{N}\right), \left(\operatorname{Follows}\left(\operatorname{table}\left(p, P, \operatorname{clog}\left(2, P\right) \times \left(P - 1\right)\right), \operatorname{Pair}\left(x, Start\right), \operatorname{Cons}\left(R, \operatorname{Unit}\left(w\right)\right), \operatorname{Pair}\left(\operatorname{Current}\left(q\right), q\right)\right) \land \operatorname{action}\left(\operatorname{table}\left(p, P, \operatorname{clog}\left(2, P\right) \times \left(P - 1\right)\right), q\right) = halt \land \operatorname{RCount}\left(\operatorname{Cons}\left(R, \operatorname{Unit}\left(w\right)\right)\right) = 1 + \operatorname{clog}\left(2, P\right)\right)\right) \land \left(P = 1 \implies \forall x : \operatorname{ZMod}\left(p \times P\right), \exists q : \operatorname{Control}\left(p, P, \operatorname{clog}\left(2, P\right) \times \left(P - 1\right)\right), \left(\operatorname{Follows}\left(\operatorname{table}\left(p, P, \operatorname{clog}\left(2, P\right) \times \left(P - 1\right)\right), \operatorname{Pair}\left(x, Start\right), \operatorname{Singleton}\left(R\right), \operatorname{Pair}\left(x, q\right)\right) \land \operatorname{action}\left(\operatorname{table}\left(p, P, \operatorname{clog}\left(2, P\right) \times \left(P - 1\right)\right), q\right) = halt \land \operatorname{Initial}\left(q\right) = x \land \operatorname{Current}\left(q\right) = x\right)\right)\right)$$

*Commentary.*

Induction on the interval tree constructs the same physical execution as its query semantics. A countdown segment executes exactly its positive number of unit waits, with every intermediate elapsed count inside Fin(B+1). The ensuing read selects the correct child interval. The budget inequality guarantees that the waiting guard succeeds, including a segment whose last wait reaches B. At a leaf, the two fixed outputs equal the original and current sources. The original source P-1 follows the rightmost path and attains exactly 1+H reads. For P=1 the sole first read immediately reaches the correct halt control.
