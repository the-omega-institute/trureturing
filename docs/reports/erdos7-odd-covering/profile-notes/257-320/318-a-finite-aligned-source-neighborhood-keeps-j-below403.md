## A strict endpoint gap gives a finite-source neighborhood

By317, the open subset

    O={f in F_align:E(f)>E*/2 and J_env(f)<803/2}

contains Z*. On the compact complement F_align minus O, the continuous
function

    h(f)=max(1-qJ(f),|rho(f)-r*|)

has no zero. If this complement is nonempty, h has a positive minimum;
choose epsilon strictly below it and at most1/1000. If the complement
is empty, any sufficiently small positive epsilon works. Therefore
qJ>=1-epsilon and |rho-r*|<=epsilon imply membership in O.

For a finite actual aligned source,311 gives

    rho>=r*-7(1-qJ)/36

on this domain. Consequently qJ>=1-epsilon together with the single
upper condition rho<=r*+epsilon already implies |rho-r*|<=epsilon.
This proves(AN1), with complete denominator uniformly greater than E*/2.

The argument applies to finite sources near the actual countable
endpoint; it does not require a finite source with qJ exactly1.
No endpoint zero column is presumed to remain zero away from the
endpoint, and no endpoint dual price is transported numerically.
An explicit radius, the full global join, later-prime continuation,
Gamma19 and unrestricted Erdős7 remain separate obligations. This is
an ordinary proof using302's complete-tail theorem and317's strict
endpoint comparison, with no new Lean claim.
