## Restore every endpoint zero column

The original2645-step zero induction uses unchanged zero-right-side
rows on aligned315;316 preserves these rows. Given actual residual
bound r, start with no zero columns. In an oriented row with negative
antecedents already bounded x_i<=b_i*r, each new positive column has

    x_j <= b_j*r,
    b_j=(1+sum_negative |a_i|b_i)/a_j.

An equality may use either sign and an inequality only its original
sign. The existing306 restoration theorem supplies exactly4634
columns, max b_j=17 and sum b_j=56866/5. The published315 zero-induction
result and316's model inclusion transport those same established
bounds. Thus none of their actual masses is set to zero in this
neighborhood. The new helper consumes these prior results without
repeating the2645-step derivation or recomputing its b_j coefficients.

For any adopted dual, the unzeroed objective is bounded by the checked
endpoint upper plus

    r*(sum nonnegative inequality prices+sum absolute equality prices)
       +r*sum_(discarded columns j) b_j*c_j,

where c_j is that objective's original nonnegative coefficient or an
upper bound for all descendants of its covering node. Every physical
column must be priced. The unchanged heavy function can reuse306's
universal restored-column price; other objectives must supply their
own coefficients. Appended316 E5 zero rows do not license further
