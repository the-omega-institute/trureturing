## Proof for each original label

Fix a label with five exponent b>=2, positive-seven exponent e>=1,
weight u=u_e and t=u*5^-b. Let v be its actual coarse restricted measure.
Its nominal coefficient k is h for a pure-five label and h1 for an
alpha-five label. Define its reference vector n by

    n(c,s)=t*eta_c*1_(s=Q)                       [pure-five],
    n(c,s)=t*eta_c*ROOT(c)*1_(s=Q)               [alpha-five].

Let d=kt-v(1)>=0 be this same label's nominal capacity defect. Missing
labels have v=0 and satisfy all following inequalities immediately.

If the pure-five label lies in Q, then v<=n coordinatewise, because
Lambda<=eta tensor Haar5. The same domination holds for an alpha label
in root1 and Q. Thus ||v-n||_1=d in either of these good cases.

Otherwise the actual and reference vectors have disjoint coarse supports:
a non-Q label occupies a different slot; an alpha label in root0 and Q
occupies a different ternary root; a killed-root alpha label has v=0.
For non-Q labels,319(L1) gives v(1)<=(k-a)t. For wrong-root alpha on Q,
the bound v(1)<=h0*t and h1-h0>=a gives the SAME inequality. Hence

    v(1) <= (k/a-1)d,
    ||v-n||_1=v(1)+kt=2v(1)+d <=(2k/a-1)d.

This explicitly covers wrong-root alpha on Q. Its sharper available
coefficient is h/(h1-h0), but it is no larger than the common alpha
coefficient used in(ET1).

The sum of all reference vectors is M, since

    sum_(b>=2,e>=1)u_e*5^-b=1/100.

Summing the triangle inequality with the complete nonnegative capacity
defects proves(ET1). Every absent tail label remains in the reference

The series converge absolutely by the same complete geometric budgets.
