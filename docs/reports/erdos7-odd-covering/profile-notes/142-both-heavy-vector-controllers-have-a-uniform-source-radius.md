actual first-beta cell. Put b=1/4-sum_(j>=2)beta_j. General packing gives

    beta_L>=1/5-b, 0<=b<=delta/4.

Delete root0 beta mass and add exactly b to beta_L. The resulting beta*

satisfies the first-label inequality. Project the other source factors

    ||n-n*||1 <= N=delta/2,

    ||d-d*||infinity <= D=3delta/4.                  (HV2)

denominator. The face has s*=1/4, h*=1/2. No reference positive measure

## 2. Complete raw operators have finite Lipschitz prices

The general raw-operator lemma in140 supplies, for each original convex
eventually affine or quadratic cost f, three nonnegative prices

    |raw_f(theta)-raw_f(theta*)|
         <=L_n*N+L_eta*E+L_d*D.                    (HV3)

It includes all finite seven blocks and the exact infinite polynomial
tail. The first price also pays the scalar source mass s=sum n.
For a raw35 operator, the pure-coordinate price splits into the
maximum centered correction and a price Pplus for the entire
positive-five part. Each fixed positive-five branch of91 has the same
Pplus bound: it is a nonnegative combination of one fixed affine
functional, the maximum of those functionals and the complete tail.
The fixed branch's coefficient norm is bounded by the same uniform
coefficient norm used in the raw positive-five maximum.

For the common expression raw357(f)-raw35(f_zero), add the two absolute
prices(HV3). This is conservative but legitimate; no convexity of a
difference of raw maxima is required.
