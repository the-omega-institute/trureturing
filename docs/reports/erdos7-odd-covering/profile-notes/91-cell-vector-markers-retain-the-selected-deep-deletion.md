## 5. Preserve the old branch excess and the actual carrier average

For each of the100 old pairs(b,c5), let m_(b,c5)(theta,pi) be its old
conditional branch value, averaged using the actual pi. Put

    A_f=min_(b,c5)[m_(b,c5)+Q_v-DeepShift],
    P_f=max_(b,c5)P_v,
    m_old=sum_c pi_c*min_(b,c5)m_(b,c5)(theta,c),
    g_f=A_f-m_old.                                  (C1)

Then the actual margin for this original cost satisfies

    margin>=m_old+[g_f-P_f*rho']_+.                  (C2)

The exact branch-dependent penalty in(P5) can also be retained. The
uniform P_f in(C1) gives the stated simpler interface.

The order in(C1) matters. First average the new fixed branch using the
same actual pi, and then minimize over original tests. The old baseline
is the existing average of conditional minima. For a mixed pi,

    min_branch sum_c pi_c*m_branch(theta,c)
                       >=sum_c pi_c*min_branch m_branch(theta,c),

and its excess is retained. Even for a single carrier, replacing(C1)
by the minimum of every branch's credit would discard any old branch
excess. The checker reconstructs all18 old conditional minima from the
same100 branches before comparing the new function.

No sign for g_f is assumed across(V1). A consumer combining several
costs must add their weighted penalties P_f; it cannot give every cost
a separate copy of the mass reserve.
