## 2. A finite capacity LP tolerates simultaneous changes

Let G_1,...,G_m be disjoint groups partitioning the coordinates.
Write

    L(a,u,b)=max sum_i a_i x_i

subject to

    0<=x_i<=u_i,
    sum_(i in G_g)x_i<=b_g.

All capacities, budgets and objective coefficients are nonnegative.
For old(a,u,b) and new(a',u',b'), choose

    U_i>=a'_i,
    D_i>=(a'_i-a_i)_+.

Then

    L(a',u',b')<=L(a,u,b)
       +sum_i (u'_i-u_i)_+ U_i
       +sum_g (b'_g-b_g)_+ max_(i in G_g)U_i
       +sum_i u_i D_i.                            (ST2)

To prove this, start with any new feasible x. Clip it to
xtilde_i=min(x_i,u_i). The clipped-off contribution costs at most
the first increment in(ST2). In each group whose remaining mass
exceeds b_g, reduce that group's coordinates until its total is
b_g. The removed mass is at most(b'_g-b_g)_+, giving the second
increment. These reductions leave an old feasible vector y.
Finally

    sum_i a'_i y_i
      <=sum_i a_i y_i+sum_i u_i D_i
      <=L(a,u,b)+sum_i u_i D_i.

This proves(ST2) for every new feasible vector. Disjoint groups
make all reductions compatible. The two loss estimates may pay
for more than actually needs removal; this only raises the bound.
No assumption about common old/new maximizers is used.

Here the three groups are cell0, cell1 and the three root1 cells,
each including all five slots. The new source changes all three
budgets, several capacities and the source score. Relative to166's
original delta0=1/22, R0=1/20000 scan, the budget increments are

    (409/848232, 1/3564, 1/1071).                 (ST3)

The nonzero source scores change from21/22 to17/18. The helper
recompiles the exact finite coefficients, so their change includes
both the score change and the moving q vertex. It bounds U_i,D_i
using every local head value v=1,...,6 and positive-seven
multiplicity m=0,1,2. These contain every actual original head and
all ten independent21/35 projections. Thus(ST2) is an all-layout
bound, not a check only at the old maximizing layout.
