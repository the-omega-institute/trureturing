positive survival denominator. Put

    e0 = E0/2,
    T = 402.96171658030220372542654057055937794339...,
    e0 = 0.04292500255272389856037647442690492192....

Then there exists epsilon>0 such that every original effective9 source

The comparison in this theorem is explicitly the complete actual-source
envelope defined in section4 below. It is not the face-only numerical

## 2. The zero set is exactly the actual saturated J faces

put p=(d1,d2), h=(pi_(0,1),pi_(0,0)); each vector is nonnegative with sum

## 3. Complete independent tests remain continuous

For an independent original test configuration t, let A_t be its complete
357 load, including the unit, and let A_(t,N) retain exponents<=N. By62(7),
uniformly in source and test assignments,

    integral (A_t^2-A_(t,N)^2) dmu_f
      <= (6/5) sum_(max(a,b,e)>N)
         (2a+1)(2b+1)(2e+1)3^-a5^-b7^-e =: R2(N) -> 0.

The factor2a+1 counts ordered exponent pairs with maximuma; the original
residues need not be equal. A compatible intersection has Haar measure
the reciprocal of the LCM, and an incompatible intersection is empty.
The nonnegative expansion and monotone convergence prove the whole tail.
This is the existing ordered-pair bound, not a first-moment substitute.

Every one of299's59 target functions has its stated finite integer head
and an affine or quadratic polynomial continuation from9. Hence there is
an explicit finite L_f such that

    |f(n+1)-f(n)| <= L_f*((n+1)^2-n^2), n>=1.

For the tail f(n)=a*n^2+b*n+c, use |a|+|b|/19; for n=1,...,8 use the
largest exact ratio, retaining the transition8->9. Telescoping gives
|f(A)-f(A_N)|<=L_f*(A^2-A_N^2), including all finite integer loads. For each
fixed test, infinite loads occur on a Haar-null set because its complete
first moment is finite. That null set may depend on the test; domination
by6/5 times Haar makes it null for every source, and no common null set
across different tests is required. Thus the complete target integrals are uniformly approximated
by finite-label integrals. Those are jointly continuous in source and
test configurations by section1 and finite-coordinate stabilization.
It follows that

    I_f(source,test)=integral f(A_test) dmu_source

is jointly continuous on the compact product. This supplies exactly the
52-cost passage of65 section4 and also covers all four AP11 functions,
H4, mean and square. The source299 helper's all-load identities bind
these59 functions to the unchanged actual original targets.

For each target define its source-only uniform envelope

    V_f(source) = max_test I_f(source,test).

Compactness gives the maximum; joint continuity gives continuity of V_f.
For completeness, along source_n->source, take maximizers test_n and a
convergent subsequence for the upper limit, while any maximizer at source
gives the lower limit by keeping that test fixed. This is a maximum over
actual independent test labels, not over a moment relaxation or dual bank.
Different V_f may have different maximizing tests. No common optimizer
is required or inferred.

## 4. The complete signed comparison is continuous near its zero set

Use299's unchanged positive cost weights w_i, negative signed mass price
cS, positive square price cQ, offset C0, and complete count coefficients

    a=1/7986, b=1/87846.

Define, on actual sources,

    N(f)=cS*S(f)+sum_(i=0..51) w_i*V_(cost_i)(f)+cQ*V_square(f),
    Tcount(f)=a*(V_mean(f)-S(f))+b*S(f),
    E(f)=S(f)-V_H4(f)/6
                      -[sum_(j=0..3)V_(AP11_j)(f)+Tcount(f)]/7.

These are continuous by sections1 and3. The count expression is the
complete original count-tail bound, not a finite set of later11 labels:

complete source-to-AP comparison therefore uses E as a valid denominator
lower and N as a valid numerator upper whenever E>0. The exact mass S is
retained in both expressions, including its negative numerator coefficient.

All59 source299 bounds hold at each f in Z, for all independent tests,

    J(f):=C0+N(f)/E(f) <= U < T.

In a neighborhood where E>0, J is continuous. Thus

    O = {f : E(f)>E0/2 and C0+N(f)/E(f)<T}
