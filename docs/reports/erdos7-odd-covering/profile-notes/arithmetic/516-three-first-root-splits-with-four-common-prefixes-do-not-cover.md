# Three first-root splits with four common prefixes do not cover

Let P={3,5,7,11,13,17,19}. Consider any finite family of congruence classes
with pairwise distinct odd numerical moduli greater than1, supported on
P union{23,29}. Suppose two fixed global old references A,B satisfy:

- A and B differ modulo each of3,5,7.
- Each original later numerical label m=d*23^j*29^k, j+k>0, has its actual
  old residue equal to A or B modulo d. Each complete numerical label makes
  one fixed choice, shared by all points and all estimates. Different full
  labels may make different choices, including labels with the same d.
- For p in{11,13,17,19}, A=B modulo p^H_p, where H_p is the largest old
  p-exponent queried by an original later class. Take H_p=0 if none is queried.

Then the family does not cover the integers. Its complement has positive
natural density, because the original family has a finite period.

Old-only residues, all original finite heights, and all23/29 phases are
arbitrary. The unit old cofactor d=1 is included. No original shallow class
is required to exist, and no reference is required to avoid a selected
pure3/5 root. The common-prefix assumption concerns the finite queried
depths, not equality of distinct integer references as infinite p-adic paths.

The theorem extends the fixed-reference conclusion of
[report515](515-actual-anchor-reserves-close-the-fixed-mixed-chart.md)
to every reference chart in this split/common pattern. It is an ordinary
deduction from the inherited source construction and exact rational
certificates, not new Lean verification or an unrestricted Erdős#7 result.
The source remains Michael Schroeder's *Nine Prime Divisors in Odd
Distinct Covering Systems*, edition1.0.1, with attribution and its local
verification boundary in the
[library entry](../../../../../Library/Arith/schroeder2026nine.md).

It refunds the45/75 terms' separately charged overlaps with known pure

    delta=0.00000037390992803820547...>1/3000000.          (R2)

## One valid row matrix, with weights recalculated in every chart

The split/common pattern is fixed throughout this theorem. Each signed
profile determines two exponent boxes of original old numerical labels.
For any chosen old points and weights v_i, a full label d has one A/B
selector, so its weighted capacity is computed by

    sum_d max(sum_(i:d in A_i) v_i, sum_(i:d in B_i) v_i).

This depends on the labelled boxes, not on absolute reference prefixes.
Therefore report509's pair, genuine triple, four-point, binary clique,
finite-height zero-only pair and order rows remain valid at all44
representatives. No map between different stabilizer orbits is needed to
transfer row validity. Their numerical weights must still be recalculated.

For the joint initial chart A8(r,s), use exact3/5 Haar shells and the same
split7/common11/13/17/19 comparison laws. Profiles with Q<=19 are safe.
The complete overflow is

    H(A8(r,s))-sum_(all23408 profiles with Q<=38) weight(profile).

It includes every infinite valuation tail. In particular, the subtraction
includes the safe finite profiles as well as the20076 middle profiles.
For nonnegative rational prices y on the valid rows Az<=b,

    U=overflow+y dot b
        +sum_(middle i) max(weight_i-(A^T y)_i,0).        (R4)

All negative child contributions from order rows are retained before the
positive-part operation. This is a bound for every admissible binary zero
support, not the mass of one trial support.

The consumer uses seven price vectors: the original509 prices, the two
report515 vectors, and four new rational vectors with denominator10^14.
Each new price refers directly to one already validated509 row. No new
geometric row, optimizer assumption or source kernel is introduced.

The finite evaluation uses two sound cases. If an A6 upper is already
below m7, deleting the actual45/75 classes can only decrease the same
fixed-price upper, and their reserve credit is nonnegative. That check
covers all561 phases of that orbit. Otherwise, the consumer reconstructs

one complete global phase pair is held fixed through each comparison.

Together these checks cover all44*561=24684 representative phase cases.
Every case has a strictly positive rational margin, with minimum R2.
The scalar reserve, upper weights and selector constraints always belong
to the same actual completed family.

## Removing shallow-presence and deleted-root assumptions

For any original old-only family, choose one legal selected completion as
in reports466/491. A missing selected class may be inserted. An existing
selected class meeting a previously selected proper-divisor class is
already contained in it, so moving that redundant class only enlarges the
old forbidden union. Original later classes and selectors are unchanged.

Normalize the one completion to one of the eight coarse types. The seven
nonworst types are already excluded by
[report491](491-all-split-common-patterns-force-six-shallow-classes.md)
for this split/common pattern. The worst type has the source used in R1.
Thus the proof does not assume that any of the selected shallow classes
was originally present.

If a reference lies in a selected deleted root at p=3 or5, add that pure
p-class to the finite original family only when its numerical modulus is
absent. If present, the source retained it, since a prime has no nonunit
proper divisor. Remove every later class selecting that reference whose
old cofactor is divisible by p: it is contained in the added pure class
and is redundant. The remaining later labels selecting that reference
are p-free, so its now-unused p-coordinate can be moved to a surviving
root distinct from the other reference. Finite CRT realizes both updated
global references while retaining all other queried coordinates.

At most two pure classes are added, all moduli remain distinct, and the
new covered union contains the original union. The old completion and
source law remain literally unchanged. On that source's support, the
removed later classes were already inactive, so

    s_augmented(x)=s_original(x).                       (R5)

Deleting labels cannot increase any required queried height. The finite
common-prefix and split conditions are retained. If a later prime is
unused, its cutoff may be padded to at least1; missing labels only reduce
the deletion budgets. One can now apply the44-orbit argument to the
surviving-root references without changing the exact-zero event on the
source.

## The contradiction and its quantitative limit

Under an assumed original full covering, finite CRT makes later-fibre
survival zero at every old point surviving its original old-only classes.
After the preceding reductions and one simultaneous orbit transport,

    m7+c(r,s)<=nu(1)=nu({s=0})
       <=U(rho,r',s')<m7+c(r',s')=m7+c(r,s),

where(r',s') is the one transported actual phase pair. This contradiction
proves the opening theorem. It includes arbitrary finite original heights
and arbitrary old-only phases under the stated later two-centre condition.

Some reused rows exclude simultaneous exact-zero fibres through strict
finite-height bounds that tend to zero as heights increase. Hence R2 is
not a uniform positive Haar-density floor. For each individual finite
family, noncoverage and its finite period imply positive density; no
fixed large-prime tail continuation is inferred. Other worst-source
split/common patterns, later separations after a common prefix, and
unrelated old residues of later labels remain outside this theorem.
