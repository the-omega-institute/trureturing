## A collision-dependent marked-query interface for the existing random source

[Report466](../450-499/466-randomized-completion-retains-full-original-survivor-support.md) already chooses T+ uniformly among all size-s supersets of T, simultaneously at each coarse cell and before any query is supplied. Fix the completed original family and its actual anchor A. Let omega denote this finite collection of padding choices; for each omega run its complete admissible source, including that source's own subsequent kernels and deletions. Average the unnormalized live measures only after their construction. Each source has the old uniform mass guarantee and the same caps, so the average preserves both. This is one fixed-family mixture; it does not join separately optimized source marginals.

Put t(x)=|T(x)| and

    gamma(x)=(6-s(x))/(6-t(x)),
    C_eff(x)=(3/2)gamma(x).

For every actual nonzero7 root r outside T, the probability of not being added by the random padding is gamma. Every individual live7 density is at most3/2 and vanishes on its added roots. Consequently its averaged unnormalized live density satisfies, pointwise above the complete old history h,

    k7_bar(h,z7)<=C_eff(x)
                    1_(z7 mod7 notin {0} union T(x)).

Here x is the actual135-cell of h. This is an absolute density bound on the live subprobability kernel. Dividing by its surviving mass would change the cap. Arbitrary further mixed7 restrictions or higher pure7 holes only decrease its support, so the bound does not assume those restrictions are independent of T+.

For a marked anchor event E, a fixed7 query of positive depth e7 and root r, and any fixed higher queries of depths e_p at p=11,...,23, reverse integration of each actual source followed by averaging gives

    nu_bar23(E intersect C7 intersect higher_queries)

          integral_(A intersect E)
             C_eff(x)1_(r notin {0} union T(x)) dH_(3,5).

    nu_bar23(E intersect higher_queries)
      <=product_(p>7,e_p>0)(C_p/p^e_p)

    S_s=min(1,(3/2)(6-s)/7).

The same averaged source serves every phase and depth. The proof first integrates the11--23 coordinates with their own unchanged conditional caps, for each omega; those resulting nonnegative bounds can then be averaged at7. No independence of the true later coordinates and no access to an auxiliary variable are needed.

The attributed subprobability comparison lemma therefore applies on every actual coarse cell with total upper mass S_s and tails C_eff/7^e. Since S_s>=C_eff/7, its comparison atoms are

## Existing results and the remaining obligation

[Report468](../450-499/468-current-loss-optimal-kernels-can-lose-two-step-survival.md) already shows that a current-loss-optimal kernel need not maximize two-stage survival, including a fixed original family and equal caps. Report466 already randomizes charged size-s padding supersets and computes the survival factor(6-s)/(6-|T|). Neither general principle is new here. The concrete additional example is the actual A1 budget vertex and legal charged-padding collision above, with explicit all-height pure completion, equal23 mass and exact fixed29 loss separation.

For a uniform improvement one would need usable bounds on actual marked intersections and future losses for arbitrary families, or a controlled source choice retaining those relations. The source comparison value rho_s=S_s-3/14 is an auxiliary positive component. It supplies no positive lower bound on a physical zero7 subsource. Physical135-cell marks and7-root marks are legitimate; they require their actual masses, densities and deletion intersections.

Some histories have no padding freedom. In this same A1 core, cell23 has s=0. Therefore the example does not by itself resolve the bottleneck histories, the source's small uniform reserve, or the original ninth-prime29 goal.
