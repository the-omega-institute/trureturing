old45 shapes and pairs the sharp complete-query mean, saturated cylinder
cost, H4 and H6 on each SAME actual uniform315 source. All112,893 actual

The results below are finite ordinary mathematics and exact native/integer
computation, not Lean verification.

## Exact cylinder costs on the same source

For a uniform actual315 source, a zero7 cylinder with old cofactor d has
cap max_C sum_(x in C) r(x)/N. A positive7 cylinder with old cofactor d
has cap max_C |C|/N: the untouched row attains that maximum. For d=1 the
latter is |S|/N. All original phases stay fixed; query phases are free
parameters in the declared comparison interface.

Use this numerical label order:

    d=(3,5,9,15,45,7,21,35,63,105,315).

Write cap_d=C_d/N. The maximum nonunit complete-query mean is

    c=M/N,   M=sum_d C_d.

Each label has its own query phase, so these maxima can be selected jointly
within one complete query. This does not select a different actual source.

Call a prime saturated in d when its exponent is respectively2,1,1 at
3,5,7. Define

    kappa(d)=product_(p saturated in d)(1+1/(p-1))-1.

The integer coefficients48 kappa(d), in the label order above, are

    (0,12,24,12,42,8,8,22,36,22,57).

Thus the exact saturated cylinder cost of this same source is

    lambda_kappa=sum_d kappa(d)cap_d=K/(48N),
    K=sum_d (48 kappa(d)) C_d.

This coefficient is the complete geometric charge of all nonempty
excess-depth supports above the shallow core cutoff. It does not assume
that different actual original phases can be optimized independently.

## Exact H4 and H6, including all nonexceptional sources

A complete315 query has a genuine old45 layout A, with unit term, and six
positive7 slots whose old layout B is another genuine complete45 query.
Both A and B take values1,...,6 on the SAME points x. All positive7 query
phases may be placed at the untouched row y0. The increasing-convex
concentration argument of Report745 then gives EXACTLY

    max_query E phi(Q)
      =(1/N) max_(A,B) sum_x [(r(x)-1)phi(A(x))
                              +phi(A(x)+B(x))].       (J1)

Indeed, for fixed x the increments phi(A+v)-phi(A) are superadditive for
nonnegative v. Including an increment on a deleted row can only enlarge
the bound. Moving all positive7 events to y0 attains the bound on every
x at once, while preserving their old phases. No independent rearrangement
of B at different x is used.

For H4 put h_A(x)=(A(x)-4)_+ and

    J4(A)=max_B sum_x(A(x)+B(x)-4)_+.

The exact numerator for a given b is

    J(b)=max_A [5 sum_x h_A(x)+J4(A)-sum_x b(x)h_A(x)]. (J2)

The native program exhausts ALL unordered genuine(A,B) pairs, updating
J4 for both orders. It then groups equal vectors h_A while keeping their
maximum constant5 sum h_A+J4(A). This is an exact elimination of duplicate
linear forms, not a relaxation. It evaluates(J2) for EVERY generated b.
Accordingly every H4 entry in all3193 paired groups is a sharp actual
query maximum J(b)/N. None is an inherited/global bound or a rounded
multiple of a global H4 estimate.

For H6 the prefix vanishes because A<=6. The same complete enumeration
finds

    max_(A,B) sum_x(A(x)+B(x)-6)_+=10

in each of the six shapes. Hence the actual uniform H6 is exactly10/N
for every b. This scalar numerator cannot be reused unchanged for a
nonuniform source; (W) gives a separate upper bound for weighted H6.

The final group key is(N,M,K,J). All four entries belong to the SAME b.
Grouping neither identifies their extrema across sources nor changes the
actual source after a query is chosen.

## Weighted laws by same-source pointwise domination

Fix nonnegative integers v_x, not all zero. On every actual surviving
live7 cell over x assign probability w_x=v_x/D, where D=sum_x r(x)v_x.
The raw core Haar cap is315 max_x v_x/D. Zero weights are allowed.
Zero7 cylinder numerators are max_C sum_(x in C)r(x)v_x; positive7
numerators are max_C sum_(x in C)v_x. The untouched row still attains
each positive7 cylinder maximum.

Let t=max_x v_x. For every genuine complete query its hinge summands
are nonnegative. Hence the pointwise inequality v_x<=t gives

    H4(weighted)<=t J(b)/D,   H6(weighted)<=10t/D.       (W)

The uniform maxima on the right belong to the SAME actual b. These are
upper bounds for the weighted hinges, not claims of weighted sharpness.
They require no new weighted query enumeration. The exact weighted caps,
(W), and the same weighted Haar cap suffice for all116 fixed witnesses
in [Report754](754-last-three-shallow-supports-with-arbitrary-core-heights.md).
The uniform J(b)=29 on each of those exceptions; using28 would be false.


The consumer builds with undefined-behavior checks and reconstructs all
112,893 effective padded sources and64,105,860 unordered genuine query
pairs, then compares the full result. It rejects a stale retained result.
The weighted continuation uses fixed rational witnesses and exact caps;
it needs no solver or claim of optimality. A second native implementation
independently reproduced all sources, group multiplicities and uniform
hinges, and independent integer arithmetic checked the weighted domination
bounds and the paired continuation constants. Neither is Lean verification.

The boundary b is sufficient for the stated free complete convex queries
because a common untouched row exists. It is not claimed sufficient for
marked high-prefix operations, arbitrary future interfaces, or arbitrary
shallow multioutside originals. Those require a separate same-source
transport argument. In particular, the marked counterexamples of
[Report750](750-marked-boundaries-and-joint-deletion-updates.md) and
[Report752](752-joint-deletion-credit-distinguishes-equal-marginal-sources.md)
retain distinctions that a free-query maximum need not retain.
