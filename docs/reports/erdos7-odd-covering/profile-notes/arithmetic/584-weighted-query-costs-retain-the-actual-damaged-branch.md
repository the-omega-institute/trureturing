## 1. Bounded weights inherit a query estimate

For any threshold t>=0, measurable0<=f<=h with finite h, and same-source all-layout hinge bound K_t,

    R_Q(f nu)<=h K_t+t integral f dnu.                       (W3)

Indeed fL<=h(L-t)_++tf for every query count L. Integrate and apply the uniform hinge bound. For a fixed finite numerical inventory, the supremum of integral fL over its phase choices is exactly the sum of its query maxima under f nu. Increasing finite inventories gives the complete R_Q(f nu). Thus W3 retains every query height and uses one common weighted measure.

This is the information omitted by replacing every weighted query with h times its unweighted maximum. In particular W1 gives W3 at t=3 without needing further high-threshold estimates.

## 6. The exact event-query interpretation

For any probability nu on the same Q-adic carrier and any t>=0, put

    Theta_nu(t)=sup_(finite query layouts L) integral(L-t)_+ dnu.

The complete query sum excludes the unit. Then, allowing extended
nonnegative values,

    Theta_nu(t)=sup_(measurable E)[R_Q(nu restricted E)-t nu(E)]. (W11)

For one finite layout the positive-part identity is

    integral(L-t)_+ dnu=sup_E[integral_E L dnu-t nu(E)].

The independent suprema over events, finite numerical inventories and
fixed phases commute. For each event and finite inventory, maximizing
each phase under that SAME restricted measure gives the sum of its
query maxima. Exhausting the countable numerical inventory proves W11.
If the test interface names only complete exponent boxes, every partial
layout extends to such a box without decreasing its hinge, so the
supremum is unchanged.

Thus an all-layout bound K_t is equivalent to the event-wise family

    R_Q(nu restricted E)<=K_t+t nu(E), for EVERY E.          (W12)

This equivalence shows why separate original-layer moments omit useful
information. W3 is its bounded-weight consequence. No event-dependent
change of the actual original phases or of nu occurs.

There is also a precise finite-inventory exclusion. For an actual
layout L with label set D and E contained in{L>=t}, append any finite
unused-label query layout, maximizing its phases under nu restricted E.
Pointwise comparison of positive parts and then label exhaustion give

    K_t>=integral(L-t)_+ dnu
          +sum_(d notin D,d>1)q_d(nu restricted E).         (W13)

Since modulus d partitions E into d residues, the final sum is at least

    delta_D nu(E),
    delta_D=product_(q in Q)q/(q-1)-1-sum_(d in D)1/d>0.

This proves the exact-plateau exclusion in section3. It does not supply
a uniform positive gap: finite inventories can exhaust the reciprocal
sum, making delta_D tend to zero. In particular the raw Report581
barrier persists at event mass at least0.5677319298..., while a
reciprocal-only six-tail bound would need delta_D>0.7044098707... to
exclude that whole range. W8--W9 instead retain the weighted query
numerator directly; they do not infer a quantitative gain from mere
strict nonattainment.
