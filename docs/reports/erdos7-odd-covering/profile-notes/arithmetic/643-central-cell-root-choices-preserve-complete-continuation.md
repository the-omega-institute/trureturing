## 4. More than one root: a valid common-budget sufficient condition

More generally let `R_q(c)` be a fixed table of live-root sets absorbing every active constrained original as above. Suppose there is **one** Report641 positive budget `dbar` such that

    |R_q(c)|<=dbar_q for every coordinate q and every cell c.

Pad each `R_q(c)` to exactly `dbar_q` live roots, once for the whole family. This is possible because each positive budget has `dbar_q<=q-2`, leaving at least one live root. Padding preserves all absorption conditions. The resulting actual source is still dominated by `rho`, and every unqueried factor has the constant mass

    A_q=1-dbar_q/(q-1).

Consequently its complete response table and gate are exactly Report641's at `dbar`. This proves a complete-head survivor under the conditional root-set incidence, with that budget's certified lower bound. The unchanged joint caps remain available for continuation, but a proposed network must still be paid from that budget's actual gate. Positivity alone does not imply that every Report641 budget has enough margin for the full625 network.

If different cells are bounded only by different positive budgets, Report641 cannot be applied by cellwise substitution. A selector maximum is taken over central cells before the512 fees are summed. The resulting response table need not be a single641 product response or a global convex combination of such responses. A common positive dominating budget, or a new complete calculation on the actual nonseparable response table, supplies the missing obligation. No claim that all pointwise-positive budget tables pass is made here.
