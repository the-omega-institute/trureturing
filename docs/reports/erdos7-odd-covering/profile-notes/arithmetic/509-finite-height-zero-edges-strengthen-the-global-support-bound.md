There are20076 middle profiles with20<=Q<=38. Profiles with Q<=19 cannot
belong to the zero support. The full comparison mass for Q>=39, including
all infinite tails, is added on the upper side. Every middle profile uses
its original literal eta shell weight and the same common-source caps;
an auxiliary profile's weight is not an assertion that the source occupies

    sum_i eta_i*z_i
      <=sum_r y_r*b_r

The total row-price numerator is86263567002. The consumer reconstructs all

mass. In particular an order row contributes both its positive parent
coefficient and negative child coefficient before the positive-part step.
The resulting value is Z1. Validity needs neither optimal multipliers nor
a feasible support supplied by a solver.

This is a universal upper for binary supports satisfying the declared
rows; it is not a restriction to deleting points from a previous example.
Adding other valid constraints cannot invalidate the upper. Conversely,
the finite set of active rows does not certify an optimum of the full
system, and Uzero is not a realized support mass or an original family.
The difference in Z2 compares the complete certificates, including their
different active rows and prices; it is not an isolated marginal value
assigned only to the qualitative pairs.
