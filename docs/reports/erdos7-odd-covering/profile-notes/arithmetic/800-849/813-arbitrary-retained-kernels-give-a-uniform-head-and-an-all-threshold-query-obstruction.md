This bound holds throughout the full product of capped categorical probability simplexes, hence for every actual old pure-q law satisfying the inherited cylinder caps. It removes the negative uniform source bound of the fixed Report808 core.

There is also a separate obstruction. The obstruction concerns this specified sufficient method. It is not an actual covering, an impossibility theorem for all source methods, or a resolution of unrestricted Erdős#7. Both results are ordinary proofs with exact rational verification, not Lean results.
