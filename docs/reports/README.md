# Experimental materials

Experimental programs, datasets and their accompanying reports live in the private [trureturing-experiments repository](https://github.com/the-omega-institute/trureturing-experiments).

Clone it beside this repository:

```sh
git clone https://github.com/the-omega-institute/trureturing-experiments.git ../trureturing-experiments
```

Run experiment commands from that checkout. Original paths under `docs/reports/` and `experiments/` are preserved there. This directory contains the third-party licenses and notices required by source files in the main repository.

Repository admission rejects experimental materials under `experiments/`, `Evidence/D5/experiments/` and `docs/reports/`, including files explicitly added to FILEMAP. Only this entrypoint and source licenses/notices are admitted under `docs/reports/`.
