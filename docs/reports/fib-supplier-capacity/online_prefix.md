# Actual TM58 online prefixes and saturated request memory

These mathematical artifacts support [TM62.2–10](../../develop/theory/RECURSIVE_RELATIONAL_OBSERVATION_TRANSPORT_MEMORY_COMPLETION.md#TM62-L2). The source, original literal target, authentic supply and fixed trace are exactly TM58 on complete U_H. The new counts distinguish source response behavior from the controller's original-target and remaining-progress obligations.

Run with Python 3.9 or newer and only the standard library:

```sh
python3 -I -S -B /path/to/online_prefix.py
```

[online_prefix.py](online_prefix.py) recomputes and compares [online_prefix.json](online_prefix.json) byte for byte. `--write` generates the canonical finite data, and `--certificate PATH` selects a result file. The exact original target, supply, composition guard, decoder, ordered trees and Clifford arithmetic are imported from [terminal_checkpoint.py](terminal_checkpoint.py) and its existing h15 helper. No solver, network or source supplier is used.

The arithmetic image domain contains all positive composition points at h=2 through 32 and all four H residues: H=8 through 131. Every tag-0 hidden composition is checked before targets are deduplicated. Each reached macro prefix is encoded with its actual initialization, context-response, Size interval or post-rejection output stage. Each response advances that same representation; no new initialization or omitted program counter is introduced. A state must reconstruct its exact legal macro history. A separate pruned midpoint-tree recursion checks the image count, unary-node count and distinct-entry leaves. Complete source lifting for unenumerated words, brackets and larger caps is the ordinary proof in TM62.10.

For every original target, the experiment checks l<M<=u, the first interval with u=M, its saturated rejection tail and the count including the mandatory final single-leaf request. At the dyadic caps 16,32,64,128,256,512,1024 it checks every legal Size entry's trailing-two-adic valuation identity and all authentic symbol-1 target contributions. The resulting B1 values are 18,38,78,158,318,638,1278, respectively; the corresponding TM61 checkpoint capacities are 4,9,19,39,79,159,319. The actual tree experiment covers every positive composition at h=2 through 16, all four residues and the two literal bracket choices left-associated and balanced: 5,440 executions. Each constructs the whole ordered candidate, checks its true leaf count, executes the original guard, updates the prefix representation and checks the Size invariant on the actual current tree. It verifies three initial unit products, exact terminal Clifford products in all residues, original target decoding, acceptance at equality, final mandatory actual rejection, at most one accepted rho and the original simultaneous call bound.

A separate exhaustive domain contains every actual U_H tree for H=8,9,10,11. All 70 words with four alpha and four beta leaves are considered; exactly eight have all three unit products. Every one of their 429 ordered binary bracketings is executed at all four caps: 13,728 full executions. This bounded completeness does not assert enumeration at larger caps.

Four additional actual balanced-tree executions check the original response-erasure falsifiers at H=80 and H=72. At H=80, (6,11) and (16,21) have common i and Size entry but different context responses and different original targets. At H=72, (6,10) and (10,19) likewise differ in the rho response. The H=21, i=2, (2,3) case checks genuine omission with positive residue: no context request, no fictitious response, material zero, OA and entry 12.
