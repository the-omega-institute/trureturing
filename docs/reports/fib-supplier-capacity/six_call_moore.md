# Six-call complete Moore memory on the original source

These artifacts support [TM66](../../develop/theory/RECURSIVE_RELATIONAL_OBSERVATION_TRANSPORT_MEMORY_COMPLETION.md#TM66-D1). Under the complete original $U_H$, authentic fixed TM58 supplier and literal INITIAL target, with every reachable mutable calibration, history, stage, action and output state counted jointly,

$$
61\le K_6(H)\le111,\qquad
109\le K_{6,\mathrm{noRead}}(H)\le111,
\qquad H\in\{60,61,62,63\}.
$$

Both exact minima remain unresolved. The all-controller lower bound uses the published TM60.5 four-symbol obstruction and all 56 literal output states. The no-Read strengthening uses a source-specific unavoidable unary request on authentic symbol4. Their universal quantifiers are established by the paper proofs, not by controller enumeration.

For any reachable complete correct controller, with $d_k$ the number of **distinct genuine original Read responses** occurring at a shared Read state over the complete legal input domain,

$$
K+\sum_{\mathrm{Read}\ k}(d_k-2)\ge108.
$$

Responses that share a successor still count separately. A value $K<108$ requires net actual Read fanout excess of at least $108-K$. The graph argument covers merges, cycles, repeated histories and legitimate information in the original controlled source; it never assumes binary Read fanout.

[six_call_moore.py](six_call_moore.py) constructs just two concrete source-specific policies and checks [six_call_moore.json](six_call_moore.json). It requires Python 3.9 or newer and the standard library. Its imports are existing mathematical evidence in this directory: [six_call_material.py](six_call_material.py) supplies actual ordered trees, authentic TM58 labels, literal targets, original whole-action semantics and TM28 integer normal forms; [h15_joint_cover.py](h15_joint_cover.py) supplies independent exact rational Clifford matrices. It does not use TM64's altered symbol4 context or TM65's smaller material prefix.

From any working directory:

```sh
python3 -I -S -B /absolute/path/to/six_call_moore.py
```

The default recomputes the exact evidence and compares canonical certificate bytes; `--write` regenerates the certificate, and `--certificate PATH` selects another result file. No personal environment, network, installed mathematical package or shell configuration is required. Executions from a different working directory and a copied directory whose path contains spaces are checked on the available macOS/Python environment; other platforms are not measured here.

The JSON retains the complete finite `c` initialization and each counted state's literal instruction and response successors. A context action includes its complete leaf word and the fixed left-associated bracket convention. Each Halt includes the original full nested target. `otherwise` defines transitions on unrealized responses, and Halt updates can be completed by self-loops. `proof_nodes` lists candidate entries, offsets and pivots as static proof annotations. The running controller never reads these fields: after authentic initialization, only its current state address and the actual source response select its next instruction. Hidden source size, original target, simulation call counter and reached-state sets belong solely to the experimental emulator and checker. No external runtime decoder, archive, retained symbol, phase register or clock participates in the policy.
