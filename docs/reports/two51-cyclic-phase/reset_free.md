# 无外部复位的有限准备证书

本报告对应[理论卷第90节](../../develop/theory/RECURSIVE_RELATIONAL_OBSERVATION_CONTEXT_GEOMETRY.md#90-付费定位后准备输入无须外部归零)。构造仍假定可以持续、非破坏性地查询同一个源样本的四个坐标，源查询不移动表盘；新增有限控制全部计入状态数。它消去第88节的外部复位前提，没有证明原算术档案允许该源接口，也没有证明两份档案全部操作的等价或全局最优费用。

[verify_reset_free.py](verify_reset_free.py) 使用 Python 3.10 及以上版本的标准库，生成完整类型化后继表，再按实际启用动作解释执行。运行方法：

```sh
python3.12 -B docs/reports/two51-cyclic-phase/verify_reset_free.py --output docs/reports/two51-cyclic-phase/reset_free_results.json
```

脚本拒绝 `-O` 或其它关闭断言的执行方式。配套导入按脚本位置解析；输出路径按调用者的当前目录解析。[reset_free_results.json](reset_free_results.json) 保留两份完整转移表、动作答案集合、计数、费用分布、最坏实例与反例，支持单独重放。

|方案|名义控制态|物理可达态|启用后继槽|源查询次数|最多表盘读取|最多单位等待|
|---|---:|---:|---:|---:|---:|---:|
|`full_turn`|474|459|1165|4|8|37|
|`known_read`|469|454|1160|4|8|36|

两种方案均枚举25个初始表盘位置与60个源配置的全部1500种组合。`full_turn` 完整保留第二次原控制器调用；零距离时实际等待25步。`known_read` 在65个零距离组合中省略已知的初次读取，从相应等待态开始，其余1435个组合仍完整调用。物理表盘与持续源载体不计入表中控制态数。

检查覆盖定位的真实当前位置、源查询时的位置保持、交接、逐点恢复、全部物理动作词的正等待间隔、最后一次读取后停止、终端标签、可达性、费用和最坏实例。终态没有启用动作，不用人工自环计作执行。另检查全部启用后继槽及实际轨迹的五重循环相容性、全部75个终端解码标签，以及三类反例：

- 零距离直接接下一次读取，会有65条路径违反正等待间隔。
- 把初态标签当作当前位置，从初态0准备源全零时会错误恢复为 `(0,1,0,0)`。
- 保留第60节未用槽的原样补全时，每份完整表有20个循环相容性失败槽，但1500条物理执行均不变。证书使用第84节的对称补全。

这些是精确整数的有限程序核验，配合正文中的普通证明；不等于完整控制器的 Lean 形式化或物理设备测试。这里复用原机器、整数商余和有限循环群的标准性质，不作新颖性声明。
