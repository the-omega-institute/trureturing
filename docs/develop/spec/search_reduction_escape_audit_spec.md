# 搜索约化逃逸审计契约

## 1. 目的与边界

本契约观察一个已交付、经 kernel 接受的证明图，判断同一原任务在加入结构 `S` 后是否沿作者路线变得更容易。结果永远是 `Observe`；本契约不产生 Block、总分、权重或新的准入状态。Lean kernel 是判词与读数的唯一真源，JSON 只是投影。旧结算保留其原有基底和判据。

“更容易”是相对于登记的图、局部重建者和预算的有限读数，不是绝对证明难度，也不是 P/NP、NP/coNP、复杂度下界或证书。引理选择的难度不测量：头的选择属于绑定，边只计算该步在给定直接前提下重新确定数据的难度。

## 2. 登记和作用域

首跑前固定原任务 `T`、证明图 `G`、局部重建者 `R_loc`、前沿宽度 `k=2` 和实际使用预算 `B_used`。每个读数带完整作用域：`[G, R_loc, k, B_used]`。

`T` 保留完整 telescope、局部假设、宇宙、量词和目标类型。`G` 由编译表达式提取，叶子是基底事实，中间结论是作者节点，根是 `T`；同批 helper 在提取前内联。`B_used` 是实际载入且通过隔离核验的基底叶子，不把作者证明体、属性、simp 表、实例注册或全库索引带入探针。预算、工具链、策略表和模块 scope 一并记录；预算耗尽、缺件、故障和隔离失败都属于 `unknown/incomplete`。

不测引理选择难度，不把作者写证明的墙钟时间、程序字节或文件布局计入边价。

## 3. 图、边和局部重建

作者超边 `e` 的结论是 `v`，直接前提是 `pred(e)`，代价 `c_X(e)` 由参照重建者只看这些前提和作用域种子 `X` 判定。`X=B_used` 得到基底臂，`X=B_used∪S` 得到配对臂；两臂使用同一 `G`、同一 `R_loc`、同一定价函数，只改变种子。

### 3.1 隐去数据位

局部重建不读取作者证明体。按类型划定隐去边界：非 `Prop` 实参是数据位，包括 `Exists.intro`、`Subtype.mk`、`Sigma.mk` 的数据字段、后续字段依赖的结构数据、motive、非 `Prop` 的 let 值和未由合一确定的隐式实参。`Prop` 实参是前提；作用域局部变量和分支内 IH 保留真实类型；实例只从 `B_used` 所有者通过 `synthInstance` 合成。

数据元变量只可由按固定顺序的 `isDefEq`、`synthInstance`、`rfl` 确定。剩余目标必须恰为非种子直接前提的类型并通过 kernel 复核。所有确定性、不回溯、不查全库的局部规则组成冻结的 `R_loc`：`intro`、`assumption`、`rfl`、And/Iff/Exists/Subtype 的结构引入和消去、按顺序对单一直接前提 `apply` 后用 `assumption` 闭合、只用直接等式/iff 前提的 `simp only`，以及仅对无元变量目标使用 `omega`。每次尝试有固定心跳预算。

`c_X(e)=0` 表示上述过程闭合该步并核验；`c_X(e)=1` 表示所有正常尝试结束仍未闭合；预算、故障或缺件是 `unknown`，绝不记为 `1`。允许表不得包含 `exact?`、`apply?`、`aesop`、默认 `simp`、完整 `solve_by_elim`、`nlinarith`、`tauto` 或 `polyrith`。

### 3.2 判形分歧与升级

旧的全库组合搜索、全局 `exact?` 以及“作者写得出即非 bind-only”均不是本契约判形。薄包装、别名、重述、行政包装、死项和零价细分由图结构与根探针归入 bind-only。带作用域的 `non-bind-only[G,R_loc,k,B_used,closure]` 只是一条 Observe 读数；把它升级为 §3.2 的 content 判形须另取得 owner 裁决，形式化或校准不代替该裁决。

## 4. 动态规划读数

对每个顶点，min-max DP 取所有入边候选的最小值，入边深度为其代价加直接前提深度的最大值；叶子种子深度为零。`k=1` 的直接边保留；`k=2` 至多为每个作者节点追加一个统一的两层祖先前沿，不枚举前提子集，不由跳边生成新窗口；超出容量记 incomplete。DP 同时计算可见数据位的 `d_vis` 与隐去数据位的 `d_hide`，验收只报告消融，不把可见值带入生产判词。

未知边在区间 DP 中取 `[0,1]` 端点。因而每条臂有 `[L_X(T),U_X(T)]`；任一端点未知时不得声称严格下降。DP 应提供最短路径回溯，供核对 `S` 是否位于配对臂的最优路径。

## 5. 判词、闭合强度和防刷

根探针各执行一次：基底叶子 `B_used`，以及 `B_used∪S`。成功且 kernel 复核时加入共享的零价根超边；基底根探针成功立即给出 bind-only。现有 R_v1 的成功证书同样给出 bind-only；R_v1 耗尽不构成新下界。

`bind-only` 满足呈现证书、`U_B(T)=0`、基底根探针成功或已有 R_v1 成功之一。

`non-bind-only[G,R_loc,k,B_used,closure]` 必须同时满足：图提取完整；隔离、呈现和宽 `S` 排除完成；两臂区间有限；`L_B(T)>U_{B∪S}(T)`；`S` 的种子实际位于配对臂最优路径；且 `closure=zero` 当 `U_{B∪S}(T)=0`，否则为 `partial`。`d_B>0` 且差为零记“未见约化”。

其余结果为 `insufficient-evidence`；unknown/incomplete 永不判 non-bind-only。图外存在更短路线、预算变化导致的非单调、猜测型绕路注水和只改命名/文件/私有性都不能被当前图判为收益；这些限制必须在读数中显式保留。零价边、零价细分、死 `have/show/let` 和 helper 拆并不增加距离。

## 6. 呈现和宽 `S` 排除

呈现证书只证明一条实际基底声明的受支持有限呈现，保留完整 telescope；多条事实的组合交由图和 `R_loc`。`T`、其别名/重述及传递依赖不得进入配对环境；`S` 若自身是基底的单源呈现，则视同基底。目标藏入、打包目标、私有常量、等价证书、死依赖和猜测型绕路均属宽排除。无法完整核验时是 incomplete，而不是 content。

## 7. AURIC FIB

AURIC 不提供 P 侧边价，也不改变 P 侧判词。复用实际 `LawFact`：`.separated` 判 `strict`，`.identifiable` 判 `collapsed`，两者均未取得则 `unknown`。同族同域 strict 与 collapsed 互斥；三态穷尽。正宽度、正 `Δ` 或单点数值不能代替任一 LawFact。

有限候选域上的双前提模型给出单向桥：两前提数据元变量不共享且四格律中 `z=0` 时 `Δ≡0`，可得到 collapsed；共享且四格均非空时可得到 strict。逆命题不成立：常值律可 collapsed 而 `Δ>0`，strict 的二点族也可常数规模枚举，不能推出搜索下界。既有观察的后处理和常量身份元数据不切开同一纤维；完整状态身份可能切开，须另行证明。

## 8. 模型定理与校准

生产 Graph/DP/classifyGraph 与模型共用本模块。模型至少证明：DP 是最小 min-max 深度且可回溯；种子扩大时距离不增（前提是 R 对假设单调）；零价边、零价细分、死项、行政包装不增距离；`d_hide≥d_vis`；零价路径可装配成原 `T` 的 kernel 证明；允许表取 `⊤` 时全零、取 `⊥` 时全一且所选表非退化；三态互斥且穷尽；unknown/incomplete 不判 non-bind-only；图外短路线可消除图上正差；AURIC 单向桥及逆命题反例。

校准必须在真实提取图上，不手填边权：`∃n,n*n=1764` 的 `d_B=1` 与 `S={42*42=1764}` 的零价闭合；作用域变量见证 `c=0`；两层嵌套只给一层的 partial；alias/wrapped/package/splitHelper/算术呈现 bind-only；死项、零价细分、helper 拆并不增距；图外短路线 bind-only；unknown、超预算和缺证明体不能判 content。真实图上的 bind-only 与 non-bind-only 都必须非空；全零或全一如实标校准失败。

## 9. 与现行准入及 owner 字面提问的关系

本契约只替换搜索约化的 Observe 判形，不删除 §3.2 的活推导路径、有消费辅助声明、模块准入、open-problem-resolution 或 §3.9 四槽义务；搜索约化读数不自动取得 content，也不替代 AURIC 来源绑定。任何带作用域判词升级仍须 owner 裁决。

“只要能写出 Lean 代码就是非 bind-only”若赋予无界写作者会把别名和薄包装都判 content，违反原搜索变容易和防刷；把所有已证明结论当无界前置又会令 content 为空。本契约采用有限、固定、可复现的图和 `R_loc`，把“变容易”落到 `d_B(T)-d_{B∪S}(T)`，保留 unknown 与校准边界。
