# 永续自主研究规范

## 摘要

本规范定义一个不依赖人类出题、可以无限期运行的自主研究系统：研究者本体是仓库状态与一个调度循环，每一轮由新会话完成一个有界研究单元；研究价值用不依赖人类偏好的结构判据衡量，用预登记的读数检验，用 AURIC FIB 逃逸审计的五模式律与残余纤维充分性审计价值读数本身。

本规范是研究循环的工作规范，不是准入规范：它不新增准入门，不修改 CLAUDE.md 第 3.2 条的判形、逃逸见证与准入依据，也不修改第 3.3 条的用途规则。研究循环产出的每一项形式化交付仍按现行准入规则逐项判定。

## 1. 研究者本体与边界

### 1.1 本体

研究者由三层组成：

| 层 | 内容 | 存放 |
|---|---|---|
| 永恒层 | 冻结的 Lean 真值 DAG、问题账、研究线障碍登记、问题卷宗、逐结算记录 | git |
| 循环层 | 一轮研究：观察、选题、预登记、执行、结算、生成、复盘（§7） | 一次性会话 |
| 元层 | 出题来源与轨道的产出评估、配额调整、harness 修复（§7.4） | 定期会话 |

任何单个会话都不是研究者本体。会话崩溃、换模型、上下文清空不影响永恒层；每一轮读永恒层、写回结果后退出，可安全重跑。

### 1.2 不依赖人类出题的含义

外部具名开放问题仍按第 3.2 条「开放问题结算依据」与第 3.6 条处理。本规范补充的是：在没有人类出题时，研究循环用 §2–§4 的结构判据选择和评价研究；人类的历史判断只用于校准判据（§10），不作为选题前提。

### 1.3 不变量

- 不放宽 bind-only 的定义，不把判形改造成奖励。
- 不按模块数、声明数、结算个数或席位数衡量研究价值。
- 不把多个价值坐标合成一个总分；比较按逐坐标弱支配（CLAUDE.md 第 2.7 条）。
- 预测与判据必须在动手前登记；结算只按登记的判据。
- 出题、预测、解题由不同席位承担；同一席位不得评价自己提出的问题。
- 允许空闲：没有候选超过价值门槛时，本轮只做出题与检索，并如实报告空闲，不生产填充性结算。

## 2. 结构价值

### 2.1 定义

一个结果 \(R\) 相对当前库 \(L\) 有结构价值，当且仅当同时满足：

1. **难以得到**：\(R\) 不能由 \(L\) 中的既有冻结声明与钉版上游声明经实例化、投影、前提代入与规范化得到（即按第 3.2 条判形不为 bind-only，或其答案在动手前不可预测，见 §3 判据 4）；
2. **使他物容易**：把 \(R\) 加入 \(L\) 后，有另外的既有或候选陈述变为可由 \(L\cup\{R\}\) 廉价得到。

条件 2 是 bind-only 的反面：bind-only 描述"从现有库可廉价得到"，结构价值要求"让别的东西变得可廉价得到"。

### 2.2 判形是诊断，不是价格

第 3.2 条的判形度量结论离现有库的推导距离。研究价值还可能位于三处，均不出现在证明项中：

- **找对象**：反例、模型或参数需要搜索才能找到；写下后验证只需代入与规范化；
- **建模**：选择哪个数学对象代表所研究的情形；
- **接到实际系统**：证明具体模型满足定理的前提。

物理类结算以 bind-only 为主时，价值通常落在前两处；前提兑现落在第三处，且通常为 content。判形照实报告，不因价值位置而改写。

## 3. 价值判据

### 3.1 门槛与六坐标

判据 0 是门槛，不通过即不作为研究单元。判据 1–6 是价值坐标。

| # | 判据 | 测量 | 及格线 | 防刷 |
|---|---|---|---|---|
| 0 | 不可约 | 动手前登记预算的廉价探针：库检索、仅用实例化与规范化的证明尝试、小范围数值搜索 | 探针在预算内不能解决 | 探针预算与内容预先登记 |
| 1 | 生成力 | 在实验分支把 \(R\) 加入库，统计因此变为廉价可得的既有定理、未决项与候选问题，或相关证明总长度的下降 | 至少两个独立消费者（第 4.8 条） | 消费者须在活证明路径上使用 \(R\)（第 4.3 条），仅 import 不计 |
| 2 | 连接 | 比较加入前后领域级依赖图 | 首次接通一对原本不连通的领域，两侧均有消费者 | 同上 |
| 3 | 锐度 | 对每条假设给出去掉后的编译反例；界给出达到例 | 有反例的假设占比；全部有反例为精确定位边界 | 反例须编译，不接受描述 |
| 4 | 判别 | 不同模型族的独立席位在动手前给出答案与概率；结算后计算意外度 | 席位不全部高度确信同一答案 | 预测席不参与解题；预测用对数或 Brier 规则计分 |
| 5 | 普适 | 相对已知最强结果去掉的假设数；覆盖的语义不同非平凡特例数 | 至少去掉一条假设或多覆盖一类特例 | 特例须语义不同，换记号不计 |
| 6 | 延续 | 由 \(R\) 引出、并通过判据 0 与 4 的新问题数 | 至少一个 | 新问题本身须过判据 |

### 3.2 零价值标记

命中任一项即不作为研究单元：相对当前库为 bind-only 且答案在动手前已被确信预测；只是重述或换名；只计算单个有限实例而无族推广；某条假设已包含结论；常数为使命题成立而凑出；既无消费者、也不接通领域、也不锐。

### 3.3 合成与排序

不合成总分。调度排序可使用代理

$$
\text{priority}=\frac{\widehat{P}_{\text{success}}\cdot H_{\text{prior}}\cdot(n_{\text{yes}}+n_{\text{no}})}{\widehat{C}},
$$

其中 \(H_{\text{prior}}\) 是预登记预测的分歧熵，\(n_{\text{yes}},n_{\text{no}}\) 是答案为是、为否时会改变状态的具体陈述数（每项附链接），\(\widehat C\) 是预计成本。该代理只决定尝试顺序，须由 §10 的回测校准；它不是价值。

## 4. 研究结果的五模式律

### 4.1 映射

对每个研究单元的结果取三个二值量：

- \(x=1\)：结果在活证明路径上含 content（第 3.2 条判形）；
- \(y=1\)：真实答案相对预登记预测的意外度不低于事先登记的阈值；
- \(z=1\)：到截止时间未结算，仅留下障碍登记。

\(x\) 与 \(y\) 都以已结算为前提，故 \(xz=yz=0\)；\(x,y\) 可同时为 1。这正是 AURIC FIB 规范 §2.1 的合法关系，五个模式的研究含义为：

| 模式 | \((x,y,z)\) | 含义 |
|---|---|---|
| 0 | \((0,0,0)\) | 已结算，无新推导、答案在意料之中 |
| 2 | \((1,0,0)\) | 新推导，答案在意料之中 |
| 5 | \((0,1,0)\) | 答案意外，推导为 bind-only（典型为搜索得到的反例） |
| 25 | \((1,1,0)\) | 新推导且答案意外 |
| 3 | \((0,0,1)\) | 未结算，留下障碍 |

### 4.2 律与读数

对每个出题来源或轨道，逐结算记录模式，形成经验五模式律 \(p=(p_0,p_2,p_5,p_{25},p_3)\)。\(X,Y,Z,r,\kappa,\Delta,w\) 按 AURIC FIB 规范 §2.2–§2.3 定义：\(X\) 为新推导率，\(Y\) 为意外率，\(Z\) 为未结算率，\(\kappa\) 为两者兼有的比例。

- 三个率 \((X,Y,Z)\) 不决定 \(\kappa\)：沿 \((1,-1,0,-1,1)\) 方向移动律不改变三率；报告必须给出完整五格律，不得只报比例。
- bind-only 标签只读出 \(x\)，其纤维合并模式 0 与 5、模式 2 与 25；区分模式 0 与 5 必须有 \(y\)。

### 4.3 价值函数与充分统计

研究循环须预先登记五模式上的价值函数 \(f\)。按 AURIC FIB 规范 §2.4，

$$
\mathbb E_p[f]=f_0+(f_2-f_0)X+(f_5-f_0)Y+(f_3-f_0)Z+J_f\kappa,\qquad J_f=f_{25}-f_2-f_5+f_0 .
$$

- \(J_f=0\) 时三率足以比较出题来源；
- \(J_f\neq0\) 时比较须使用完整律；用三率加条件独立补全估计的误差为 \(J_f\Delta/r\)（\(r>0\)），取值宽度为 \(|J_f|w\)。

价值函数的取值是登记的选择，不由本规范给出；本规范只规定在该选择下必须测量的量。

## 5. 价值读数的审计

### 5.1 四栏审计

每个价值读数（判形标签、导入数、活路径使用、结算个数、意外度等）在使用前按四栏写明：生成式、逆式或充分判据、遗漏项、取得条件。这是理论卷《FIB 原子—金字塔—边界演算》（`docs/develop/theory/AURIC_FIB_ATOM_PYRAMID_BOUNDARY_CALCULUS.md`）定理 14.1 与约定 14.2 的读口要求在研究价值上的应用：读数够不够，取决于目标在该读数的纤维上是否不变。

### 5.2 残余纤维充分性

把一批研究结果作为通用有限呈现的状态，把价值读数作为读出，把价值目标作为任务，提交给 AURIC FIB 分析器（`tools/scripts/auric-fib-analysis.sh`）的 typed-source 入口。分析器报告：

- 逃逸对、唯一捕获、留一捕获与分层捕获谱（AURIC FIB 规范 §5.1–§5.3）；
- `continuation_target.residual_sufficiency`：任务冲突对、充分性、冲突率与首个决定层（AURIC FIB 规范 §5.5）。

规则：

- 唯一捕获为 0 的读数是冗余读数；分层谱中塌缩的层是零边际分辨力；
- 冲突对非空时，现有读数不足以决定价值目标；补救须加入能切开冲突对的新读数（CLAUDE.md 第 2.7 条盲核），不得对现有读数作后处理；
- 冲突对本身登记为新问题：什么性质区分这两个结果（§6 分辨题）。

### 5.3 基线读数

2026-10-16 在 dev `53ec26edbed43dc4f4862d2db303ad80cb3dbd92` 上对 2026-10-01 至 10-16 创建并合并的 36 个物理类结算做了一次普查，读出为判形、准入依据、结论类型、用途分类、搜题轨道、合并时段，任务为是否有交付外的 D5 导入者。数据、生成程序与读数在私有实验仓库 `trureturing-experiments` 的 `docs/reports/physics-settlement-value-census/`。读数为 Python 预览结果，分析器本体尚未在该输入上运行：

- 六个读数下 1,260 个有序对中 102 个不可分；
- 结论类型与用途分类的唯一捕获均为 0（全部 14 个反驳带 `certified-instance` 头，证明与库结果均不带）；
- 读数不决定任务：5 个无序冲突对，位于纤维 {15354, 16702, 16902, 17145, 17605} 与 {16971, 17778}；
- 最大纤维为 9 个速度轨 bind-only 认证实例反驳，全部无导入者，现有读数无法再分；
- 判形与合并时段相关（早期 10 个中 6 个为 content），36 个状态不能分离两者的影响。

同期仓库读数：`Problems/` 卷宗中标注判形的物理类卷宗 118 个全 bind-only、64 个 content；非物理类 66 与 80（按卷宗前 3,000 字关键词分类，约半数卷宗无判形标注）。

## 6. 出题来源

研究循环不以人类问题清单为前提，使用以下出题来源。每个来源对应 §3 的一个判据，候选问题出生时附 §9.2 的问题卡。

| 来源 | 生成方式 | 对应判据 |
|---|---|---|
| 压缩搜索 | 把证明骨架相似的既有定理聚类，求共同推广；优先高使用节点附近 | 生成力 |
| 桥搜索 | 陈述形状相似而依赖图不连通的领域对，求桥定理 | 连接 |
| 锐度搜索 | 对高使用定理逐条去掉假设，求证明或编译反例 | 锐度 |
| 分歧搜索 | 批量生成候选陈述，取多模型族预测分歧最大者 | 判别 |
| 残余搜索 | 四槽登记中 `continuation := .unknown` 的残余（2026-10-16 读数：2,072 条中 2,050 条） | 延续 |
| 机理推广 | 卷宗 Triage 中的未决项（2026-10-16 读数：123 份卷宗共 143 条，按行首格式匹配，有漏计） | 普适、延续 |
| 分辨题 | §5.2 的冲突对；两模型在已知可观测量上一致而在可计算量上不同 | 判别 |
| 冲突题 | 两个既有结论或近似在某区域给出相反预测，求该区域 | 判别 |

物理方向的不依赖人类出题的优先类：

1. 原则锐度：对正定性、完全正定性、局域性、有限维、对称性逐条做锐度检验，定位每个结果实际使用的物理原则；
2. 跨模型桥：同一不等式或机理在经典与量子、不同统计系综间的统一陈述；
3. 模型分辨：在已知可观测量上一致、在某可计算量上不同的两个模型，该量即实验应测之量；
4. 前提兑现：结算的物理识别留在 Lean 之外或作为文献前提时，下一目标是对具体模型证明该前提。

本仓库只结算数学问题；经验性物理主张只能改写为"模型推出可观测后果"的数学陈述，不替代实验（CLAUDE.md 第 2.12 条）。

## 7. 永续循环

### 7.1 一轮

| 步 | 输入 | 输出 |
|---|---|---|
| 观察 | 问题账、未结预登记 issue、研究线障碍登记、CI 状态 | 本轮候选集 |
| 选题 | 候选集、§3.3 排序、探索配额 | 一个研究单元；默认至少 20% 的轮次分配给新出题来源或新领域 |
| 预登记 | 研究单元 | 预测（席位、模型族、概率）、成功/推翻/停止判据、截止时间、价值函数版本 |
| 执行 | 预登记 | 小问题走两阶段管线（CLAUDE.md 第 3.6 条），族推广与证明开研究线 |
| 结算 | 执行结果 | 五态终局（CLAUDE.md 第 2.7 条局部结算）与 §4.1 模式 |
| 生成 | 结算 | 至少一个附问题卡的新候选，或登记"本结算未产生新候选"及原因 |
| 复盘 | 本轮记录 | 出题来源的逐结算模式记录 |

### 7.2 选题停手规则

同一出题来源或同一问题族内连续两次得到模式 0 或模式 5 的结算后，下一研究单元转向该族的族推广或前提兑现。该规则是循环的选题规则，与第 3.2 条的准入及其停手计数相互独立：外部开放问题结算的准入不受本规则影响。

### 7.3 调度

每一轮由定时任务新建会话执行；并发上限按可用席位预算确定。会话只读写永恒层并在结束前提交、推送其结果；未完成的单元按截止时间结算为障碍登记。

### 7.4 元层

定期评估每个出题来源的五模式律、意外度分布与延续数；按 §4.3 的登记价值函数调整配额；同一失败形态出现第二次即修复其根因（CLAUDE.md 第 7.11 条）。

## 8. 失效形态与防护

| 失效 | 读数 | 防护 |
|---|---|---|
| 空转刷形状 | 2026-10-01 至 10-16 创建的物理类 PR 抽样中，10-14 及以后合并的 21 个结算有 17 个为 bind-only，其中 10 个的判形说明为同一模板（PR 正文自报，未复核 Lean 源码） | §7.2 停手规则；价值按意外度与后续使用计 |
| 死磕 | 边际改进递减（`budget_envelope_infimum_and_limit`） | 研究线自带停止判据；连续两周无边际改进即换 Γ |
| 自问自答 | 查表复制器零信息（`lookup_copy_zero_loss_and_nonanticipating_failure`） | 席位分离；判据 0 探针 |
| 状态腐烂 | 长寿上下文与工单继承死状态（CLAUDE.md 第 5.10 条） | 每轮新会话；过期工单关闭重开 |
| 错误累积 | 误判为真者须连同后代撤销（第 1.3 条） | 定期抽查旧结算由独立席复核；预测席校准计分 |
| 尺子漂移 | 读数成为目标后被优化 | §10 回测；以后续活路径使用与文献采纳校准 §3.3 代理 |

## 9. 数据记录

### 9.1 逐结算记录

每个结算在其问题卷宗 `## Triage` 节记录一行：模式、\((x,y,z)\)、意外度阈值与实测意外度、预登记 issue。物理类结算另记每条物理前提的状态：已对具体模型证明、作为假设挂在定理中、在 Lean 之外。

### 9.2 问题卡

AI 提出的问题以问题卡登记，字段为：出题来源、陈述（量词写全）、外部锚点（可空）、答案为是/为否时会改变状态的具体陈述及链接、预测（席位、模型族、概率、登记时点）、判据 0 探针的预算与结果、预计成本、状态、结算链接、实测意外度、延续问题。问题卡的存放路径须在 `Meta/FILEMAP.toml` 登记后启用。

### 9.3 聚合

出题来源的五模式律、意外度分布与 §5.2 普查结果按需现算到标准输出，不提交聚合物（CLAUDE.md 第 4.5 条）。实验程序与数据放入 `trureturing-experiments`（CLAUDE.md 第 2.10 条）。

## 10. 判据回测

- **内部回测**：取冻结满 60 天的模块，按入库时可得信息计算 §3 判据，与现时活路径使用量比较；判据不能预测后续使用的，降权或撤除。
- **外部回测**：把 §3 判据盲用于一组公认高使用的结果（如 Mathlib 中被大量使用的引理）与一组随机结果；判据不能分开两组的，撤除。
- 人类历史只作校准样本；回测结果按 CLAUDE.md 第 2.6 条留底，失败的判据按第 2.7 条换 Γ。
