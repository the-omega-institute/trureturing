# 【批 1 增补(v0.1):§1 引言 与 §2 预备】

# 1. 引言

## 1.1 处境与问题

母论文 [界面] 处理了一个几何问题:可数的名如何触碰不可数的体——其答案是一族渐近不变量(速度、硬度、恰点集、暗面测度、层谱、边界)。本文处理与之正交的经济问题:**触碰是有价的**。一纸等式 x = y,在操作意义上从不是静态的同一性宣告,而是一对变换之见证;见证是名,名有价。由此出发,三个古老的问题获得同一张账簿:一条等式携带多少信息(算法问题);一次表示转换兑换多少位数(遍历问题);一盏测试绿灯认证多少行为(工程问题)。本文的主张是:三者是同一个对象——**带价等式**——在三条高度滤链上的读数,而软件测试是这套理论的第一个可实测实验室。

具体而言,本文考察四栏价格:算法栏(见证之描述长)、率栏(表示塔间之位数汇率)、肉身栏(执行之时空成本)、热栏(逻辑不可逆之擦除计数)。第一部(§3–§5)证明这四栏的结构定理:何者构成严格的高度滤链(定理 3.4),可逆性在各栏分别压出何种不变量(命题 3.5–3.9),时间有界名价与肉身价何时不可同时最小化(定理 4.5),以及率栏为何是导出栏而非原栏(定理 4.8)。第二部(§6–§8)将行为空间实例化为第五座经典命名塔,证明测试的两种价值——体积约束与行为钉住——在自由选点的塔中解耦(定理 6.4),并证明认证价值的相变开关不在套件之内而在选择之时序(定理 8.2)。

## 1.2 贡献

**(一)多滤链命名系统与硬度曲面**(定义 3.3;定理 4.7)。母论文之单参硬度谱推广为多预算帕累托曲面;曲面之非平凡弯曲获无条件证明。

## 2.1 可计算性与复杂度 [典]

固定前缀通用机 U 与标准配对编码 ⟨·,·⟩。K(x) 为 x 之前缀复杂度;不变性定理保证换机差 O(1) [Li–Vitányi]。次可加性 K(x, y) ≤ K(x) + K(y) + O(1) [典]。对可计算时间界 t,时限复杂度 K^t(x) 为在 t(|x|) 步内产出 x 之最短程序长;K^t 可计算,且 K ≤ K^t [典]。部分可计算函数 f 之复杂度 K(f) 为其最短实现程序长(§0.4)。停机问题不可判定与 Rice 定理 [典] 于 §6 调用。

## 2.2 命名系统 [典·母论文]

**定义 2.1(重述 [界面] 定义 2.1)**。命名系统为四元组 𝒩 = (N, X, ν, h):X 为不可数 Polish 空间,携无原子 σ-有限测度类 μ;N 为可数名集;ν: N ⇀ X 为部分赋值;h: N → ℕ 使 N_Q = {a ∈ N : h(a) ≤ Q} 对每一 Q 有限。界面 𝕀(𝒩) 为滤链像 {ν(N_Q)}_Q 于 X 上诱导之渐近结构;硬度 β(x) = liminf_Q w(Q)·dist(x, ν(N_Q)),w 为塔之自然归一。母论文之六不变量(速度、硬度、恰点集、暗面测度、层谱、边界)本文仅调用硬度与暗面测度二者。

## 2.3 配对与对偶 [典]

Chu 空间为三元 (A, r, B),r: A × B → Σ。行分离(A 中无重行)、列分离(B 中无重列)俱备者称双延展;任意 Chu 空间有唯一双延展商(粘合重行重列)[Pratt]。转置 (B, rᵀ, A) 给出对合,平方同构于恒等 [Barr]。本文 §4 之对偶三条款(完美配对、反转对合、可选势分解)以此为底自足陈述。

## 2.4 测度与拓扑准备 [典]

X = ∏_{i∈ℕ} O_i,|O| = n ≥ 2,取乘积拓扑与均匀乘积测度 μ:X 为 Polish 空间,μ 无原子;有限支撑柱集为既开且闭,μ(柱集 over S) = n^{−|S|};稠集交一切非空开集。此为 §6 全部拓扑所需。

# 【批 2 增补(v0.2):§3 带价等式与税单结构】

# 3. 带价等式与税单结构

## 3.1 定义群

**定义 3.1(带价等式)**。设 x, y ∈ 𝔻。x 与 y 间之**带价等式**为三元 E = (u, v, τ),其中 u, v 为部分可计算函数,u(x) = y,v(y) = x(称**见证对**),τ(E) 为**税单**四栏向量:

- **算法栏** τ_K(E) = (K(u), K(v));
- **率栏** τ_H:仅当 E 为表示塔间之翻译态射时定义(命题 3.8);其为导出栏而非原栏之判定见定理 4.8,本定义先行挂注;
- **肉身栏** τ_C(E) = (t_u, s_u, t_v, s_v):见证实现之时间与空间成本,各为输入尺度 ℓ 之函数——肉身栏本性双参(名 × 尺度);
- **热栏** τ_L(E):见证实现之逻辑不可逆擦除计数 [典 Landauer 1961]。

**税附于见证条款**:税单是见证对之属性,非等式本身之属性;同一等式有多见证,故有多税单。

**定义 3.2(价面)**。等式 x ≐ y 之**价** 𝒫(x ≐ y) 为其全体见证税单在逐栏偏序下之帕累托前沿;函数值栏(τ_C)以终占优序比较。价不是一个数,是一张面;其时间有界名价变体之真多维性见定理 4.5,plain K 可行域内之分离见定理 5.1。

**定义 3.3(多滤链命名系统)**。**多滤链命名系统**为 𝒩 = (N, X, ν, (h₁, …, h_m)),各 hᵢ: N → ℕ,携**主滤链条款**:至少存在一个 i 使 {a ∈ N : hᵢ(a) ≤ Q} 对每一 Q 有限。联合预算集 N_{Q⃗} = {a : hᵢ(a) ≤ Qᵢ, ∀i} 由主栏保有限。点 x ∈ X 之**硬度曲面** β(x; ·) 为可达三元组 (Q⃗, dist(x, ν(N_{Q⃗}))) 之帕累托前沿;m = 1 时退化为 [界面] 之单参硬度。

## 3.2 税单分类定理

**定理 3.4(税单分类)[证]**。以程序为函数之名,则:(a) 算法栏为严格高度滤链;(b) 肉身栏单独不是滤链;(c) Levin 混合栏 Kt(p) = |p| + log(time_p) 恢复滤链性 [典 Levin 1973]。

*证明*。(a) 前缀域中长度 ≤ Q 之程序至多 2^{Q+1} 个,水平集有限。(b) 反例:常值函数族 {f_c : c ∈ 𝔻} 各有恒定时间实现,时间预算 T 之水平集含无穷多互异函数之名。(c) |p| + log t ≤ Q 强制 |p| ≤ Q,水平集有限;此即 Levin 通用搜索之记账函数 [典]。∎

**判读**。四栏地位不对等:算法栏独任主滤链;肉身栏之正形是定义 3.3 意义下与主栏配对之副栏(联合预算有限由主栏担保);率栏之地位由定理 4.8 裁决。多滤链结构非记账便利,而是税单自身的形状。

## 3.3 诸栏之可逆性定律

**命题 3.5(算法栏价签)[典·组装]**。设 E = (u, v, τ) 为 x, y 间带价等式。则

K(y) ≤ K(x) + K(u) + O(1),K(x) ≤ K(y) + K(v) + O(1),

从而 |K(x) − K(y)| ≤ max(K(u), K(v)) + O(1)。

*证明*。取机器 M:输入 ⟨q, p⟩,模拟 U(p) 得 x,再以 q 号程序作用之。以 u 之最短程序为 q、x 之最短程序为 p,得首式;对称得次式 [典 Li–Vitányi,不变性与次可加性之直接推论]。∎

**紧性注(带对数缝)[证]**。取长 ℓ 之不可压串 r(K(r) ≥ ℓ),令 u_r = 与 r 逐位异或(自逆),x = 0^ℓ,y = r。则 K(y) − K(x) ≥ ℓ − O(log ℓ);另一方面 K(u_r) ≤ ℓ + O(1),且由 r = u_r(0^ℓ) 得 K(r) ≤ K(u_r) + O(log ℓ),故 K(u_r) ≥ ℓ − O(log ℓ):上界在 O(log ℓ) 缝内可达。**常数 = 名价**:可逆变换之信息差被见证名价封顶,且封顶紧。∎

**命题 3.6(离散熵栏)[典]**。X 为可数支撑随机变量,f 于支撑上单射,则 H(f(X)) = H(X)(广义实数意义)。*证明一行*:单射保概率多重集。∎ 非单射且合并正测原子者严格减 [典]。

**命题 3.7(微分熵墙)[典]**。设 X 为绝对连续随机向量,h(X) 为有限值,f 为微分同胚,且 E[|log |det Df(X)||] < ∞,则 h(f(X)) = h(X) + E[log |det Df(X)|] [典·换元公式]。修正项通常依赖分布与映射;若 |det Df| 在 X 的支撑上恒为 c > 0,则修正项为常数 log c。**墙条款**:连续栏禁引"可逆差常数",违者列冒充。

**命题 3.8(率栏)[典]**。正熵遍历区间映射生成之两表示塔,熵 h₁, h₂:由 Q 位 𝒩₁-展开所确定之 𝒩₂-位数 Q′(Q) 满足 Q′/Q → h₁/h₂ 几乎处处 [典 Lochs 1964;一般形 Dajani–Fieldsteel 2001]。十进/连分数实例:6 ln2 ln10/π² ≈ 0.9703。〔价签:正熵前件;零熵塔之 Lochs 型定理存在而汇率非线性,见 §11 与文献〔核对签〕〕

**命题 3.9(肉身栏)[典]**。热栏可零:逻辑可逆计算存在 [典 Bennett 1973]。而肉身栏付对价:不可逆计算之可逆模拟有时间-空间权衡上界族 [典 Bennett 1989],且该权衡在可逆卵石博弈模型内为最优 [典·核对签 Li–Tromp–Vitányi 线]。〔价签:一般计算模型之无条件下界开放——本文之肉身栏下界主张限卵石模型,此为对工作稿之**收紧**,收紧记录入验收件〕

**本节合影**。可逆性在四栏各压出不同的不变量:算法栏压出常数(= 见证名价,至 O(log) 缝),离散熵栏压出零,率栏压出线性汇率(正熵前件下),热栏可压至零,而肉身栏拒绝归零(模型内下界)。"可逆不免税,只换税种"——此句之精确内容即上列五枚落款。

# 【批 3a 增补(v0.3a):§4 前半——边界配对、封顶与暗面】

# 4. 边界配对、封顶与分离(前半)

本节把"函数即边界"由口号铸为判据(4.1),把边界对体的封顶铸为定理(4.3–4.4),并为对偶之熵化立窗(4.2)。

## 4.1 对偶化判据

**定理 4.1(对偶化判据)[典 + 证 + 识别]**。设 r: A × B → Σ 为配对,r̂: A → Σ^B 与 ř: B → Σ^A 为其两向柯里化。

(a) **[典 Barr;Pratt]** r 行列俱分离(双延展)⟺ r̂ 与 ř 皆单;任意配对有唯一双延展商(粘合重行与重列);转置给出对合 ι,ι² ≅ id。

(b) **图配对判据 [证]**。对普通函数 f: A → B,其图配对 r_f(a, b) = [f(a) = b] 双延展 ⟺ **f 单射且 B ∖ im f 至多一点**。

*证明*。行 r_f(a, ·) 为单点集 {f(a)} 之指示,两行相等 ⟺ f(a) = f(a′),故行分离 ⟺ 单射。列 r_f(·, b) 为纤维 f^{−1}(b) 之指示;b ≠ b′ 之非空纤维不交,故两列相等仅当双双为空,即 b, b′ ∉ im f;故列分离 ⟺ 像外至多一点。∎

(c) **识别**。图配对之双延展坍缩恰粘合两类对象:定义域侧之**同纤维冗名**与值域侧之**像外冗名**。**边界之规范形 = 消冗后之命名系统**;"定义域与值域成对偶体"由此非公设而系判据——对偶是挣得的,其买价即消冗。

## 4.2 命名对偶熵化窗 [猜·窗]

**窗 4.2**。设 𝒩 = (N, X, ν, h),取逼近配对 p(a, x) = −log dist(ν(a), x)。**猜**:存在势对 (Ψ_N, Ψ_X)——Ψ_N 由高度生成、Ψ_X 由硬度生成——使 Fenchel–Young 型不等式 Ψ_N(a) + Ψ_X(x) ≥ p(a, x) 成立,且等号恰于最优逼近对达成;间隙候为丢番图**迁移亏差**。锚:Mahler 对偶、Khintchine 迁移原理 [典];参数数几何(Schmidt–Summerer;Roy)〔核对签〕。**被推翻方式**:若在有理塔上最优逼近对(连分数渐近分数)不落等号零集,窗降类比档。本窗于本文不承载任何下游定理。

## 4.3 界封体律

**约定**。取定默认符号 o₀ ∈ 𝔻。有限表 T ⊂ 𝔻 × 𝔻 称**函数性**,若无一输入配两输出;函数性 ⟺ 存在通过 T 之全函数程序(可满足)。

**定理 4.3(界封体律)[典·民俗]**。T 为有限函数性表,则 min{K(P) : P ⊨ T} ≤ K(T) + O(1)。

*证明*。由 T 之最短程序构造桩 P_T:输入 z,若 z ∈ dom T 则输出 T(z),否则输出 o₀。P_T 通过 T,且 K(P_T) ≤ K(T) + O(1)。∎

**注(枚举变体)**。当通过谓词仅半可判而无典范桩(如量化性质规格),只要存在停机通过体,对 (程序, 步数) 双重枚举之首中者同样给出 min K ≤ K(规格) + O(1);此变体于 §6 内涵名情形调用。

**落款申明**。上式属民俗层:其精形——一致分类器最小复杂度之期望紧界(以目标概念复杂度与标签条件熵计)——归 Epstein 2022,回归情形归 Epstein 2023;PAC-Occam 谱系归 Blumer–Ehrenfeucht–Haussler–Warmuth。本文不认领不等式,认领其读法与合装(推论 4.3.1 与定理 4.4 之配对,及 §7 之工程兑现)。

**推论 4.3.1(Dijkstra 定量形)**。任何有限函数性套件被某 K ≤ K(T) + O(1) 之实现通过;故一盏绿灯对实现之认证内容至多 K(T) + O(1) 比特——"测试只能证明缺陷存在,不能证明缺陷不存在"之定量化:绿灯所不能排除者,恰是名价高于套件名价之全体行为。

## 4.4 暗面双定理

**定理 4.4(暗面双定理)[证]**。X = ∏_{i∈ℕ} O_i 携均匀乘积测度 μ(§2.4)。

(a) **绿类正测**。支撑 S、|S| = m 之有限表 T,其全绿类 G(T) = {x : x|_S = T} 满足 μ(G(T)) = n^{−m} > 0:有限认证之剩余不确定性有显式正下界,且只依预算不依内容。〔价签:等式形限均匀 μ;一般无原子乘积测度下正测性仍立,常数改为边际质量之积〕

(b) **常道守恒**。任何可数名族经 ν 至多钉住可数点集;μ 无原子,故匿名集满测度,且沿整条滤链逐层不损分毫 [证·一行,承 [界面] 定理 5.1]。

*证明*。(a) §2.4 柱测度公式。(b) 可数并可数仍可数;无原子测度下可数集零测。∎

**判读**。(a) 与 (b) 分职:前者给**单套件**之剩余不确定性以显式正下界,后者说**整座塔**之极限亦不减匿名测度。与推论 4.3.1 合读:绿灯之封顶是双重的——信息上被套件名价封顶,测度上被预算指数封顶;两枚封顶互不可推(证人于定理 7.4 陈列)。

# 【批 3b 增补(v0.3b):§4 后半——分离、双图卡与栏目约化】

## 4.5 双点定理

**定理 4.5(双点定理:时间有界名价形)[证]**。设 t 为可计算时间界,且足以输出 ℓ 位串(吸收机器常数后 t(ℓ) ≥ ℓ)。固定充分大的机器常数 c₀,c₁,令 B(ℓ) := c₀·t(ℓ),T(ℓ) := c₁·t(ℓ)·log t(ℓ);K^{B(ℓ)}(u) 表示在 B(ℓ) 步内输出见证代码 u 的最短描述长。则存在一致可计算之串族 (x_ℓ)、|x_ℓ| = ℓ,使等式族 0^ℓ ≐ x_ℓ 满足:

(i) **快者必长**:凡于 t(ℓ) 步内实现 0^ℓ ↦ x_ℓ 之见证 u,K^{B(ℓ)}(u) ≥ ℓ/2 − O(log ℓ);
(ii) **短者必慢**:存在 ℓ₀,凡 ℓ ≥ ℓ₀ 且 K^{B(ℓ)}(u) ≤ ℓ/4 之见证,用时逾 t(ℓ);
(iii) **双端俱实**:表见证(K^{B(ℓ)} ≤ ℓ + O(log ℓ),线性时间)与枚举见证(K^{B(ℓ)} = O_t(1),用时逾 t)皆存在。

故以 K^{B(ℓ)} 为算法栏之价面无条件含两个互不支配点,且两点之时间尺度间隙可取任意可计算函数之宽。

*证明*。**构造**。K^T 可计算:对给定 x,候选程序限长 |x| + O(1)(打印界),逐一模拟 T(|x|) 步即可穷验。令 x_ℓ 为字典序首个满足 K^T(x_ℓ) > ℓ/2 之长 ℓ 串;存在性由计数:长 ≤ ℓ/2 之程序不足 2^{ℓ/2+1} < 2^ℓ 个。族 (x_ℓ) 一致可计算。

**(i)**。设 u 于 t(ℓ) 步内自 0^ℓ 算出 x_ℓ,令 q_u 为在 B(ℓ) 步内输出 u 的最短描述。取程序 p = ⟨q_u, ℓ 之自定界码⟩,解释为:先在 B(ℓ) 步内解出 u,再生成 0^ℓ 并模拟 u 于其上。|p| ≤ K^{B(ℓ)}(u) + 2 log ℓ + O(1);由 B(ℓ) = c₀t(ℓ) 及通用模拟开销,总用时 ≤ T(ℓ)(c₁ 吸收诸项)。故 K^T(x_ℓ) ≤ K^{B(ℓ)}(u) + 2 log ℓ + O(1);与 K^T(x_ℓ) > ℓ/2 并读得 K^{B(ℓ)}(u) ≥ ℓ/2 − O(log ℓ)。

**(ii)** 为 (i) 之带边距逆否:ℓ/2 − O(log ℓ) > ℓ/4 对充分大 ℓ 成立。

**(iii)**。表见证:硬编码 x_ℓ,输入核对 0^ℓ 后输出之;其代码可由长 ℓ + O(log ℓ) 的直印描述在 O(ℓ) ≤ B(ℓ) 步内生成,故 K^{B(ℓ)} ≤ ℓ + O(log ℓ),执行时间线性;逆向见证为常值映射,K^{B(ℓ)} = O(log ℓ)。枚举见证 u_e:**自输入 0^ℓ 读出 ℓ**,按定义重算 x_ℓ(穷验字典序诸串之 K^T)后输出;u_e 为仅依 t 的固定代码,故 K^{B(ℓ)}(u_e) = O(K(t)) + O(1) = O_t(1),与 ℓ 无关;由 (ii),其用时必逾 t(ℓ)。互不支配即两端点之逐栏比较。∎

**勘误价签(为何不用 plain K)**。x_ℓ 由 ℓ 一致可计算,故字面表程序 u_ℓ := “print x_ℓ” 本身可由一个先无时限重算 x_ℓ、再打印 u_ℓ 的描述生成,从而 plain K(u_ℓ) = O(log ℓ),而 u_ℓ 的执行仍为线性时间。旧版以 q_u 的长度为 K(u) 却未把 q_u 的解码时间计入 T,故线性下界不成立;改用 K^{B(ℓ)} 后,该短而慢的元描述不在 B(ℓ) 解码预算内,反例不再满足 (i) 的短名前件。

**约定申明**:本定理之时间以特定输入族 0^ℓ 上之逐点用时计;此记账约定随定理冻结。**可行域申明 [条件形]**:双端点俱多项式时间之分离(查表对公式在可行域内之真分离)系于单向函数类假设,于定理 5.1 明码陈列;本定理之无条件性以忙碌海狸尺度换得,两档并存各持价签。

## 4.6 双图卡定理

设 T 为十进前缀塔至连分数前缀塔之统一翻译:w ↦ 由 w 所确定之最长 CF 前缀(即含 w 之十进柱之最小 CF 柱之地址)。

**定理 4.6(双图卡)[证 + 证·a.e. + 典]**。

(a) **内容正向(逐点)[证]**:K(T(w)) ≤ K(w) + O(1)(T 可计算)。

(b) **内容逆向(几乎处处)[证]**:对 μ-a.e. x,沿其前缀族终有 K(w_Q) ≤ K(T(w_Q)) + O(log Q)。**且逐点形不成立**:逆向修剪费在最坏情形无界。

*证明*。恢复 w_Q 需 T(w_Q) 之外再付两笔:长度 Q(O(log Q) 位)与 w_Q 之十进柱在 CF 柱内之序号。序号代价 = log(柱测度比 + O(1))。测度比受下一 CF 位控制:log(|C_m|/|D_Q|) = O(log a_{m+1}) + O(1);由 Borel–Bernstein 定理 [典],a.e. x 之位列终有 a_m ≤ m²,故序号代价 a.e. 终为 O(log Q)。逐点反例:取 CF 位塔状增长之点(Liouville 型),测度比沿子列超多项式,序号费无界。∎

(c) **高度图卡 [典 Lochs;Dajani–Fieldsteel]**:Q′(Q)/Q → h₁/h₂ 几乎处处。

(d) **判词**:同一态射两张图卡——**汇率是坐标现象**(高度重参数化之线性系数,一阶),**内容是图内现象**(a.e. 对数级,渐近零阶);二者无冲突,因各居其图。两图之 a.e. 价签同源(遍历层担保),于 4.8 复合时不加新税。

## 4.7 税面弯曲定理

**定理 4.7(税面弯曲)[证]**。存在多滤链命名系统与点 x*,其硬度曲面沿任一预算轴皆非柱面:可达域边界真依赖预算方向。

*证明*。取 X 为序列空间、N = 程序(双预算:代码长 Q_K = |u|、逐位时间 Q_C)、ν 为程序之输出序列、度量承 §2.4。以 4.5 之族对角化一点:x* 之第 ℓ 块 := x_ℓ。沿 C-轴(代码长预算钉于 O_t(1)):枚举见证逐块算尽,dist → 0——短码方向可达任意逼近。反向钉时间预算于 t:因 t(ℓ) ≥ ℓ,凡 |u| ≤ ℓ/4 − O(1) 之代码均可在 B(ℓ) 内由字面描述输出,故 K^{B(ℓ)}(u) ≤ |u| + O(1) ≤ ℓ/4;由 4.5(ii),第 ℓ 块必错,dist ≥ 2^{−pos(ℓ)} 有显式正下界。故等代码长预算线上可达距离随 C-预算真变动,等 C-预算线上随代码长预算真变动;曲面两向皆弯。∎

**判读**。[界面] 之单参硬度是此曲面沿主轴之边际;经济结构(定理 4.5)强迫几何结构(弯曲)——界面几何由线升面,弯曲有证书。

## 4.8 栏目约化

**定理 4.8(栏目约化)[独立复算]**。正熵遍历塔上,几乎处处 K(前缀_Q)/Q → 塔熵(比特计)[典 Brudno 1982];复合双图卡 (a)(b),两塔之 K-密度比被迫等于高度汇率:

## 5.1 列分离强形

**定理 5.1(可行域列分离)[条件形]**。设存在对非一致多项式对手安全之单向函数族 (f_n)。则函数级等式族 id_n ≐ f_n 满足:正向见证居 (K = O(1), 多项式时间);而任何逆向见证族 (v_n),若其以不可忽略概率(输入均匀)实现平均逆,则 K(v_n) + time(v_n) 联合超多项式。双端点俱实:穷举逆(K = O(1),时间 2^n·poly)与全表逆(K = O(2^n n),线性时间)。故价面在可行域内真多维,禁角为 (poly, poly)。

# 【批 6 增补(v0.6):§7 边界体问题】

# 7. 边界体问题

**开题**。一个软件项目的权威对象是什么——代码文本、套件文本、还是别的?本节以第一部之工具作四答:权威对象是判决配对之双延展商(7.3);构造边界者(变异/差分)之统计学由母论文恰式接管且获新职务(7.1–7.2);一盏绿灯之全部认证内容是一张四栏收据(7.4)。

## 7.1 差分测试恰式

**定理 7.1(差分测试恰式)[证·搬运]**。设参照目录 g: A → Y^A(名 = 输入,每参照为 A 上全行为表;自应用之字面形),扭 f: Y → Y 为输出级变异算子,k = |Fix f|。对角变异体 d_g(a) = f(g(a)(a))——对目录中每个参照在其自名处求值再扭。则 d_g 逃逸(异于目录中每一参照)均匀随机目录之概率**恰为** (1 − k n^{−A})^A [搬运 [界面] 定理 3.4;n = |Y|]。∎

**等价变异体条款 [识别 + 典]**。扭之不动点恰为变异不可见之输出——**k 即等价变异行为之计数**。单例等价性不可判定 [典 Budd–Angluin 1982];k 以整体参数身份进入恰式——逐点不可判定之量,其总量可测(兑现于 7.2)。

**前件条款(职务申明)[典·工程]**。均匀独立前件在人写参照上经验性破产:Knight–Leveson 1986 以 27 版本、百万测试统计拒绝独立性假设;2026 年 AI 代理复现同判(共发失效 429 例对独立预言 115.36 例)。**裁决:不修恰式,改其职务**——恰式为**零模型**,实测逃逸率对恰式之偏差 = 参照共模相关之测量仪(共模仪,附录 B 协议一);失配非定理之死,乃仪器之生。

## 7.2 变异分定标公式

**定理 7.2(变异分定标)[证]**。前件:(i) 单点均匀变异——均匀选位 a ∈ A,置 x′(a) = f(x*(a));(ii) 行为无偏——P[x*(a) ∈ Fix f] = k/n(位上平均)。套件 T 支撑 S ⊆ A、|S| = m,判决以期望值 x*|_S 为准。则

杀灭概率 = (m/A) · (1 − k/n)。

*证明*。杀灭 ⟺ 变异位落 S 且扭于该位可见;两事件在前件下独立,概率各为 m/A 与 1 − k/n。∎

**判读**。变异分四十年来被当单一质量数使用,本式判明其为两个正交量之积:**覆盖率**(预算几何)×**扭可见度**(不动点质量);等价变异体偏置项恰为 k/n。**统计柔道**:对变异语料回归"实测杀灭率对覆盖率",斜率估 1 − k/n,按算子分表即扭质量表(附录 B 协议二)——不可判定之量,其测度可测。〔价签:前件二连;多点变异与行为偏置之受控实现居附录 B〕

## 7.3 真实源与冗名定理

**定理 7.3(真实源与冗名)[典·重铸 + 证]**。设判决配对 r: 𝔓 × 𝔗 → {绿, 红}(实现种群 × 测试全集)。

(a) **真实源裁决 [典·重铸,经定理 4.1]**:项目之权威对象为 r 之双延展商;代码文本与套件文本皆代表元,非对象本身。

(b) **极小化 = 列坍缩**:判决列全同之测试互为冗名;无损极小化 ⟺ 在当前片段内选列代表元。

(c) **片段相对性 [证]**:坍缩以实现种群 𝔓 为指标——扩充种群(注入新实现或变异体)可分裂原先全同之列。*证明一行*:取二测试于 𝔓 上列全同,构造新实现恰在二者判决处分歧,加入种群即裂。∎ 故**"冗余测试"非绝对属性,乃种群索引属性**。

**工程史对位 [典·工程,清讫]**。套件约简之经典冲突:Rothermel–Harrold 等(ICSM 1998;STVR 2002)测得约简可严重损伤检出力,而 Wong 等(ICSE 1995;SPE 1998)测得影响可忽略,后续工作于同库复测得小损——文献自认结果相冲。(c) 予其结构解释:**约简之无损性是种群索引命题,两阵营各执一个种群(程序库、故障池、套件型)而互指其谬**;争议之持久,恰因双方都对。

## 7.4 绿灯四栏收据定理

**定理 7.4(绿灯四栏收据)[证·合装]**。有限套件 T(支撑 S,预算 m,内容编码 T)全绿之认证内容为向量:

| 栏 | 内容 | 出处 |
|---|---|---|
| 信息栏 | ≤ K(T) + O(1) 比特 | 定理 4.3;推论 4.3.1 |
| 测度栏 | 剩余不确定性 = n^{−m} | 定理 4.4(a) |
| 度量栏 | 漂移半径 = 2^{−γ(S)}〔度量相对〕 | 定理 6.4(b) |
| 层谱栏 | 规格索引免责:活性无条件盲;可穷尽窗口例外 | 命题 6.6、6.7 |

**前三栏(套件统计量)两两独立,证人五枚 [证]**:①可压缩大套件(K 塌、m 大);②同预算不可压套件(K 满、m 同)——①②定信息栏之自由;③同预算前缀对带洞支撑(测度同、直径异)——定度量栏之自由;④远位加一算法可定之测(m 增、K 仅 +O(1)、γ 不动)——定测度栏之自由;⑤Occam-皱面证人:可压缩套件恰恰邀请低名价模式体通过(4.3 之桩居压缩表上)——信息栏之塌有工程后果,非记账巧合。**第四栏地位申明(收紧)**:层谱栏为**规格索引之免责栏**,常于套件而变于性质——工作稿"四栏两两不推出"判过宽,正确形为"前三栏两两独立 + 第四栏异类",证人清单由四改五,收紧入册。∎

**判词**。**绿灯不是一个比特,是一张收据**:三个套件统计量加一条规格免责。§8 之税单公示条款以此为公示内容;证人⑤为 §8 之 AI 节备好弹药——可压缩评测集主动邀请博弈,有其定理形动机。

# 【批 7 增补(v0.7):§8 制度与人工智能 + 中缝签字门二】

# 8. 制度与人工智能

本节之定理不关于套件,而关于**格局**:法官与被告的相对位置与出场次序。

## 8.1 认证价值

**定义 8.1(认证价值)**。固定输入坐标上之部署分布 𝔇 与预期行为 x* ∈ X。实现 P 之部署损失 L(P) = Pr_{i∼𝔇}[P(i) ≠ x*(i)]。一盏绿灯之**认证价值**为其所担保之 (ε, δ) 对全体:"绿 ⟹ 以置信 ≥ 1 − δ 有 L(P) ≤ ε"。价值以担保内容计,不以套件规模计。

## 8.2 法官时序定理

**定理 8.2(法官时序)[证 + 典·民俗]**。设套件预算 m。

(a) **塌缩半 [证]**:若 (P, T) 可共选(P 于见 T 后定型,或同一优化器控制二者),则存在全绿对使 L(P) = 𝔇(ℕ ∖ S(T)):绿灯之担保不逾受测质量;𝔇 弥散而 S 有限时,认证价值塌缩至零(无任何 ε < 𝔇(ℕ∖S) 获担保)。*构造*:P = 于 S 上贴 x* 之桩(§4.3 约定),界外处处反 x*。∎

(b) **恢复半 [典·民俗 + 证]**:若法官独立——P 先冻结,T 之 m 个检查点自 𝔇 独立采样并以 x* 为准判决——则

Pr[全绿 ∧ L(P) > ε] ≤ (1 − ε)^m ≤ e^{−εm},对一切 ε 同时成立。

*证明*。L > ε 时每样本以概率 > ε 捕获分歧;独立采样连乘。∎〔价签:**分布匹配前件**——检查点分布 = 部署分布;失配情形由标准协变量移位界折算,居注记不居定理〕

(c) **判词**。同一套件规模、同一份全绿笔录,认证价值在 0 与 e^{−εm} 之间**相变**;开关唯一:**选择之时序**(谁后手)。工程宪法"法官在彼岸、被告不得改判自己的边界"由道德条款升格为此相变之执法。

## 8.3 强化学习之二相

**推论 8.3(RLVR 二相)[条件形]**。以 harness 判决为训练信号之优化,分两相:

**共适应相**——奖励套件于训练期固定且可见:优化器与实现联合选择,8.2(a) 接管;由定理 4.3,近优通过率之解族含 K ≈ K(T_train) + O(1) 之桩型体,部署损失不受约束——**奖励博弈非异常,乃该相之通有最优**〔条件:优化近达最优通过率、无额外正则〕;定理 7.4 证人⑤补一刀:可压缩奖励集主动邀请模式体。

**外置相**——奖励检查点逐期自 𝔇 新采、对优化器保盲:8.2(b) 接管,通过率之优化获部署担保。

**锚外置细则**:判决通道之**出身**定相——自产判决(模型自测自评)落共适应相,"被告自判"即 8.2(a) 之字面;冻结外部 harness 落外置相。经验邻证:§6.7 之 AI 代理多版本实验示生成代码之共模失效同样实存——外置相之独立采样前件在生成时代须显式建造而非默认成立。此推论为 [界面] §11 两枚条件定理(对齐残差、锚外置)供工程骨架。

## 8.4 释义外置

**命题 8.4(释义外置)[证]**。存在两世界 W₁(共选)与 W₂(独立采样)产生**逐比特相同**之判决笔录,而认证价值分别为塌缩与 (ε, e^{−εm})(据 8.2)。故担保不是笔录之函数;判决位不携带自身释义;释义 = 笔录外元数据(出身、时序、独立性)。

*证明*。令 W₂ 采样得套件 T₀ 而 P 先冻;令 W₁ 之共选方恰选 T₀ 且提交同一 P 文本(共选方合法可为:它见 T₀ 后有权照抄)。两笔录逐位同。价值差由 8.2 两半分别给出。∎

**推论**。独立性前件**不可由笔录内证**——其为 (P, T) 联合分布之性质,于任何单一笔录不可见,故只能由制度见证。**签署行为由此获得非仪式性职能:它是笔录外前件之制度载体。**(限结构呼应:本文不涉签署之语义学,只证其信息论必要性。)

## 8.4″(iii) 详式

## 候签定理 8.2‴(饥饿速率:Fano 形)

**设置**。承 8.2′:θ ∼ π,固定套件 T 含 m 例,标签字母表尺寸 n,d(θ, θ′) = Pr_{z∼𝔇}[θ(z) ≠ θ′(z)]。**前件(装填条件)**:π 之支撑含 d-度量下两两 ≥ 2δ 分离之族 {θ₁, …, θ_M}(价签一:装填存在性系先验之富度)。

**定理 [证]**。任何以 T 为唯一 θ-通道之学习者(任意轮数、任意算法):

E[L] ≥ δ · (1 − (m log₂ n + 1) / log₂ M)。

*证明*。取 π 均匀于装填族。译码 θ̂ = argmin_j d(P, θ_j):若 L(P) = d(P, θ) < δ,则对 j ≠ θ 有 d(P, θ_j) ≥ 2δ − δ > d(P, θ),故 θ̂ = θ——即 θ̂ ≠ θ ⟹ L ≥ δ。链 θ → T → P → θ̂ 加 Fano:P[θ̂ ≠ θ] ≥ 1 − (I(θ; T) + 1)/log₂ M;而 I(θ; T) = I(θ; 标签 | 输入) ≤ m log₂ n。合成 E[L] ≥ δ · P[θ̂ ≠ θ]。∎

**推论(学习相变轮数)**。外置臂 k 轮累积 km 例,同式以 km 代 m:地板在
