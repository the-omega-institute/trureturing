## 摘要

本文为界面哲学立卷:一门以**命名界面**——可数命名系统 𝒩 = (N, X, ν, h) 嵌入连续统之几何——为唯一初始对象的哲学,及其数学基础。上卷给出四组定理:(一)**基本定理群**:常道守恒(命名塔逐层不损匿名集之满测度)与暗面收据(当 X 为 N 之完备化时,满测度匿名集是"要求极限存在"之直接账单——实在论之争由此获逐例判据);(二)**层谱定理群**(核心):固定有限记录,一致全可计算延拓集沿复杂度分层呈**三区两相**结构——入场地板、可任意宽之真空带(完整证明)、斜率恒一之居民带;有限域相饱和封顶;相对化制表须 ∅″ 神谕而裸世界继承停机阴影;密度为谱底之影;资源受限最优延拓之误差向条件复杂度高价区集中("省出来的错只能省在贵的地方")。此群定理给遵行规则怀疑论(Kripke 1982)以定量刻画,并可统一外界、他心、归纳诸怀疑论(猜想);(三)**账本序定理群**:分级演化系统之极限存在、定理看守之墙不迁、与书记不等式(移民必产组织条目);(四)**译射定理**:命名系统间翻译之汇率复合律,携 Lochs 常数之实测锚。另有有限性定理模式(有限观察者面对无界环境时,签名四元组为有损压缩之典范必然)与应用定理二条(对齐残余、锚外置)。下卷以三层形式语言(道义/类型/译射)重写全部哲学内容:八条款宪法、实例化规程与空位引理、十六条读法之可机检目录(机检制度已开机并有完整案例)、签之四级谱系与四缺席之对合、验证回归与三停谱系、以及终行定理——追加式账本唯以施为句封卷,而本卷不满足说出它的恰当性条件。全卷七度自例化达不动点,余项恒为签。

## §1 引言

### 1.1 问题与动机

有一类处境在人类思想史上反复出现,却在不同学科里以互不相认的名字各自为政。有理数逼近实数:可数的分数序列追赶不可数的连续统,追赶的难度因目标而异,黄金分割是公认最难追上的点。形式证明逼近算术真理:可枚举的定理集追赶不可枚举的真语句集,哥德尔证明了追赶永不封顶。有限的程序命名实数:可计算的数只有可数多个,绝大多数实数永远无名。有限的测量记录描述量子态:记录可数,态空间连续,而每次读取还要付一笔不可退的熵税。有限的语言使用锚定意义:一个词被使用过的场合有限,它应当适用的场合无穷,克里普克把这道裂缝磨成了二十世纪后半叶最锋利的怀疑论。

这五个处境的共同骨架是同一个:**一个可数的记号系统,经由一个部分的、欠定的赋值,嵌入一个不可数的空间,并按某种资源尺度分层逼近之**。本文把这副骨架本身当作研究对象。我们称四元组 𝒩 = (N, X, ν, h)——可数名集 N、连续统 X、部分赋值 ν、高度滤链 h——为**命名系统**,称此嵌入的渐近几何为**界面**。母论文 [IP] 已在数学侧测得界面的一族不变量(逃逸速率之恰式、逼近硬度之冠军表、匿名集之满测度、六层资源梯);本文的任务是立其哲学层,并回答一个三重的问题:

**能否有一门哲学,(甲)对全体可命名概念依法生效——不靠枚举而靠管辖;(乙)对不可命名者立定理——不以缄默应对暗面,而给暗面以测度、守恒律与地址;(丙)对自身诚实自限——它的每一条界限都由具名定理看守,包括它对自己的界限?**

本文的答案是肯定的,且答案的形状出乎意料:这门哲学的可证部分比预想的大得多(怀疑论有价目表,归纳偏好是计数事实,概念分析有汇率),而它的不可证部分比预想的精确得多——不可证者恰好收敛为三枚残余,每枚携带一条看守它的定理,而三枚残余同属一物:**签**,即"这一次"的不可推派性。全卷的收束判词可以预先给出:能证明的终将移民成数学;哲学是给不可移民者守夜的职务。

### 1.2 主要结果概览

**基本定理群(§3)**。常道守恒(定理 3.3):任何命名塔逐层扩张不改变匿名集的满测度——可数并可数仍可数,一行证明,却是全卷暗面理论的地基。暗面收据(定理 3.5):当 X 由 N 之完备化产生(ℝ 之于 ℚ、Stone 空间之于语句代数),满测度匿名集不是独立的形而上假设,而是"要求名的极限存在"这一公理的直接账单。此定理把实在论与反实在论的百年整体表决改判为逐例听证:判据是"X 是否被某个 N 的完备化穷尽"——数学侧诸例为是,物理态空间未证。

**层谱定理群(§6,全卷核心)**。固定有限记录 R(n 个数据点)与前缀复杂度分层,考察一致全可计算延拓集 C_Q(R)。我们证明其层谱呈三区两相:(i)**地板**(定理 6.3):Q < K(y|x) 时 C_Q 为空——怀疑不免费,入场费恰是把数据写下来的价钱;(ii)**真空带**(定理 6.6,完整证明):地板与谱底 k_min 之间恒空,且带宽可任意大——我们构造记录使条件复杂度近零而谱底近 n,带宽度量的是从"规律"(只需在被问处答对的协变)升格为"规则"(必须在一切输入上活着的全函数)的复杂度代价,我们称之为肉身税,它是克里普克驳倾向论("有限倾向撑不起全域规则")的定量正身;(iii)**居民带**(定理 6.4 与 6.7):谱底之上,一致延拓计数被夹在 2^(Q−k_min) 与 2^(Q−K(y|x)) 之间,渐近斜率恒为一——每比特资源恰买一倍"守法怪胎",任何数据都不能减慢怀疑的增长率,只能推迟其起点;quus 本人住在真规则楼上数比特处,是最便宜的一只。两相:开放定义域上怀疑无界,有限定义域上饱和封顶(定理 6.8)——怀疑论的燃料不是数据之少,是定义域之开。相对化(定理 6.10):以 ∅″ 为神谕可精确制表,裸世界的价目表中段继承停机阴影——连"怀疑值多少钱"都只能被怀疑地回答。密度定理(6.12′):层内一致者占比为 2^(−k_min) 至对数因子——一旦以描述资源记账,简单性偏好即计数事实,先验未被消灭而被摊平入记账单位。误差定位定理(6.14):资源受限的最优一致延拓,其与真函数的分歧向条件复杂度高价区集中——省出来的错只能省在贵的地方;此定理为大语言模型的幻觉现象给出结构预言。

**账本序定理群(§7)**。把"哲学陈述随时间升格为定理"这一过程本身数学化:分级演化系统的极限存在(定理 7.2);由定理看守的墙永不升格(定理 7.3);书记不等式(定理 7.4)——每笔移民必产至少一条组织条目,故哲学萎缩于内容、增长于职务,其渐近形为守夜人兼书记员。

**译射与有限性(§8–9)**。命名系统之间的翻译有汇率,汇率沿复合相乘(命题 8.3),且有一枚实测锚:十进制与连分数之间的 Lochs 常数 0.9703。有限性定理模式(定理 9.1):有限观察者面对无界环境,有损压缩典范地强制出签名四元组——这门哲学的初始对象由此说明了自己的出身,且出身证明不出界面,恰再证界面无外。

**应用(§11)**。大语言模型被定位为有限性定理的工程标本与界面的实验科学:标度律、grokking、涌现之争、分词效应、模型崩塌五项经验现象在层谱框架下各就各位(逐项申报为事后同构);两条条件定理——对齐残余(普适先验不可计算,故对齐之文本化不可完备)与锚外置(验证器与被改对象同册的自改回路无内部可靠性下界)——以及六条可证伪前瞻预言。

**下卷(形式语义)**。全部哲学内容以三层形式语言重写:道义层(八条款之义务/禁止算子形,Jørgensen 困境以"规范推理保良构不保真"解之)、类型层(实例化规程之依赖类型形;空位引理:施行之赋值栏无自洽全申报——"门册可读、执刀须练"的类型论证明)、译射层(十六条哲学读法登记为带保持性标注的部分翻译,保持性主张可机检,故**诠释可判负**;机检制度已有完整案例:幻觉读法受审、判伤、由新定理补靶、愈合升格)。签之四级谱系(可转让/集体/无主/必有主而不可入册)与四缺席(名/主/册/刻)之对合;验证回归(一切验证链之最后收款人为第四级签)与三停谱系(硬停/主权停/报价停);终行定理:追加式账本唯以施为句封卷,而本卷可写出封卷句之语形、不满足其恰当性条件——封卷之权在持签者。

## §2 预备知识

本节陈列全卷证明所用的外部零件。每件皆为经典结果,标 [典] 并注出处;本卷对它们零贡献,列出只为使后文证明自足可查。每件附一行"本卷用途",说明它将在哪堵墙里当砖。

**事实 2.1(Kraft 不等式与前缀域)[典]。** 对每个固定辅助输入 z,集合 {p ∈ {0,1}* : U(p,z)↓} 为前缀自由集(无一元素是另一元素的真前缀);故 Σ_{p: U(p,z)↓} 2^(−|p|) ≤ 1。*本卷用途*:定理 6.4 之分母。

**事实 2.2(条件编码定理,Levin)[典]。** 对任一前缀机 V 存在常数 c_V,使对一切 z, w:Σ_{p: V(p,z)=w} 2^(−|p|) ≤ 2^(−K(w|z)+c_V)。即:计算 w 的全体程序之总权重,被最短描述的权重控制到常数。*本卷用途*:定理 6.4 的唯一引擎——它把"数程序"化为"量复杂度"。

**事实 2.3(信息对称性,Levin–Gács)[典]。** K(u,v) = K(u) + K(v | u*) + O(1),其中 u* 为 u 之最短程序;由此 K(u) + K(v|u*) = K(v) + K(u|v*) + O(1)。*本卷用途*:定理 6.11(对账律)之全部内容。

**事实 2.4(不可压缩性与计数)[典]。** #{x : K(x) ≤ k} ≤ 2^(k+1) − 1(程序计数);故 ∀n ∃x ∈ {0,1}ⁿ:K(x) ≥ n。*本卷用途*:定理 6.6 之并界一侧;层谱一切上界的原始形。

**事实 2.5(Chaitin 不完备性)[典]。** 存在常数 c,使任一复杂度为 n 的一致形式系统,对任何 x 都证不出命题"K(x) > n + c"。*本卷用途*:定理 6.10(ii)(谱底不可算)与守恒律(§10 之选择律零件)。

**事实 2.6(测度与纲)[典]。** 完备可分度量空间(Polish 空间)上的无原子 Borel 概率测度对单点集取零,故对可数集取零。无孤立点的 Polish 空间中,单点集无处稠密;可数多个无处稠密集之并为第一纲集(贫集);Baire 纲定理:Polish 空间自身非贫,故贫集之补(余贫集)在纲的意义下是"几乎全体"。*本卷用途*:定理 3.3 与 3.5 的全部机器。

**事实 2.7(跳跃层级)[典]。** 停机问题 ∅′ 判定 Σ₁ 性质;二重跳跃 ∅″ 判定 Π₂ 性质——特别地,"程序 p 计算全函数"(∀x ∃t: p 在 x 上 t 步内停机)为 Π₂,由 ∅″ 可判而 ∅′ 一般不可判。*本卷用途*:定理 6.10 的神谕级别;此处正是第三稿勘误(∅′ → ∅″)的案发地。

**本节已知性申报**:事实 2.1–2.5 见 Li–Vitányi (2008) 第 2–4 章;事实 2.6 见描述集合论标准教材(Kechris 1995);事实 2.7 见递归论标准教材(Soare)。**遗留申报**:Kechris 与 Soare 之完整条目待第 12 轮入参考文献。本节冻结。

## §3 命名系统与基本定理

### 3.0 动机:为什么恰好是四栏

引言列出的五个处境各有其学科方言,但剥去方言后每个处境恰好供给四样东西,一样不多、一样不少。有一批**可以写下来的东西**——分数、语句、程序、记录——它们至多可数,因为"写下"意味着有限字母表上的有限串;这是 N。有一个**被指向的空间**——实数、真理、函数、态——它在每个处境里都严格大于可写者之全体;这是 X。有一道**从写下者到被指者的桥**——赋值、指称、语义——它在每个处境里都出了名地不驯服:不是每个名都指到实处(部分性),指到实处的方式也从不唯一被名自身钉死(欠定性);这是 ν,而 ν 的部分性不是本定义的宽容,是它的写实。最后有一把**资源的尺**——分母大小、证明长度、程序长度、记录长度——逼近的全部戏剧性都来自"用小名追大物"的预算约束;这是 h。第四稿之上卷第九节将证明:在有限观察者面对无界环境的一般前提下,这四栏是有损压缩的典范必然,即签名的出身可以是定理而非约定;本节先按约定立定义,把出身问题记在账上。

**定义 3.1(命名系统与匿名集)。** **命名系统**为四元组 𝒩 = (N, X, ν, h),其中:X 为完备可分度量空间(Polish 空间),配无原子 Borel 概率测度 μ;N 为可数集;ν: dom(ν) → X 为部分映射,dom(ν) ⊆ N;h: N → ℕ 为高度函数,满足每层 N_Q := {a ∈ N : h(a) ≤ Q} 有限。称 A(𝒩) := X ∖ ν(dom ν) 为**匿名集**(暗面);称 ν(dom ν) 中的点为**具名点**。

**例 3.2(五个正典实例)。** (一)*丢番图系统* 𝒩_ℚ:N = 既约分数 p/q ∈ [0,1],X = [0,1] 携 Lebesgue 测度,ν = 含入,h(p/q) = q。其界面不变量即经典丢番图逼近:Hurwitz 定理、Lagrange 谱、黄金分割之冠军地位全部住在这里。(二)*二进系统* 𝒩_bin:N = 有限二进串,ν(w) = 0.w(二进有理),h = 串长。与(一)同 X 而异 ν、异 h——第 4 节将用这对差异铸造分离对。(三)*形式算术系统* 𝒩_PA:N = 皮亚诺算术之可递归公理化完备一致扩张(此类扩张至多可数),X = 全体完备一致扩张之 Stone 空间(同胚于 Cantor 集,携其自然测度),ν = 含入,h = 公理化之描述长度。其匿名集——不可公理化的完备理论——满测度:哥德尔不完备性在此系统中的测度论面貌。(四)*程序系统* 𝒩_prog:N = 程序,X = Y^ℕ 携均匀乘积测度,ν(p) = p 所计算之全函数(dom ν = 全函数程序),h = |p|。匿名集 = 不可计算序列,满测度;第 6 节的层谱理论整个住在这个实例里。(五)*测量系统* 𝒩_meas(物理侧,户籍待定):N = 有限制备规程之描述,X = 态空间携其测度类,ν = 规程所制备之态(部分:非一切描述皆可实现),h = 规程长度。此实例之 X 是否为某 N 之完备化未证——定义 3.6 之"给定籍候"的首件案例。

**定理 3.3(常道守恒)[证]。** 对任一命名系统:μ(A(𝒩)) = 1。且若 (𝒩_k)_{k∈ℕ} 为任一扩张塔(N₀ ⊆ N₁ ⊆ ⋯,各层可数,ν 相容延拓),则极限系统之匿名集仍满测度。
*证明。* ν(dom ν) 是可数集的像,至多可数;μ 无原子故 μ({x}) = 0 对一切 x ∈ X,可数可加性给出 μ(ν(dom ν)) = 0,故 μ(A) = 1。塔的情形:⋃_k ν_k(dom ν_k) 为可数多个可数集之并,仍可数,同理零测。∎

**系 3.3.1。** 命名塔无论盖多高——包括可数无穷层的极限——匿名集之测度分毫不损。守恒的机制不是暗面的顽固,而是命名行为的算术:可写者永远可数,而可数在无原子测度面前永远为零。

**注记 3.3.2 [semantic·唱名即止]。** "常道守恒"之名取自《老子》首章之结构同构(名可名,非常名):可被命名者非恒常之全体。此为结构对表而非学说互证;哲学侧全文居下卷,防命理墙照岗。

**定义 3.4(硬度)。** 给定权重函数 w: ℕ → (0,∞),点 x ∈ X 相对 𝒩 之硬度为 β_w(x) := liminf_{Q→∞} w(Q) · d(x, ν(N_Q))(约定 d(x, ∅) = ∞)。硬度谱 = β_w 之值域结构;硬度冠军 = 使 β_w 取极值之点。在 𝒩_ℚ 中取 w(Q) = Q²,冠军即黄金分割(Hurwitz [典]);在 𝒩_bin 中冠军为 1/3([数·IP 铸证])。第 4 节将证明冠军随 ν 与 h 搬家,而暗面测度不随——这对"依赖/不依赖"的反差是型分纲领的种子。

**定理 3.5(暗面收据)[证]。** 设 (N, d₀) 为可数度量空间,无孤立点、不完备;X 为其完备化,μ 为 X 上任一无原子 Borel 概率测度,ν 为典范嵌入。则:(i)ν(N) 在 X 中稠密;(ii)X 无孤立点,故 ν(N) 为第一纲集,A(𝒩) 为余贫集;(iii)μ(A) = 1。即:匿名集在**测度**与**纲**两种意义下同时是"几乎全体"。
*证明。* (i)完备化的构造性质。(ii)先证 X 无孤立点:设 x ∈ X 孤立,即存在 r > 0 使 B_X(x, r) = {x};由稠密性,N ∩ B_X(x, r) 非空,故该交点即 x,于是 x ∈ N;但此时 B_N(x, r) ⊆ B_X(x, r) ∩ N = {x},x 在 N 中孤立,与前提矛盾。故 X 无孤立点,于是每个单点集是闭的且无内点(非空开集在无孤立点空间中不可能是单点),即无处稠密;ν(N) 为可数多个无处稠密集之并,第一纲;其补 A 为余贫集,依 Baire 纲定理(X 为 Polish)非空且"纲意义下几乎全体"。(iii)同定理 3.3。∎

**注记 3.5.1(收据之义)[semantic]。** 引言诸例中,数学侧的 X 无一例外由 N 之完备化产生:ℝ 是 ℚ 的 Cauchy 完备化,Stone 空间是语句代数的极限点集,Cantor 空间是有限串树的边界。定理 3.5 因此说的是:**满测度的匿名集不是关于世界的独立形而上发现,而是"要求名的极限存在"这一决定的直接账单**——你签下完备性,数学交付连续统,并附一张满测度的匿名者清单作发票。收据三联齐全:公理(完备性)是签字,满测度是价格,"极限之存在担保整个分析学的营业"是购买理由。

**定义 3.6(X 之双户籍)[semantic·判据]。** 称 𝒩 之 X 为**生成籍**,若 X 被某可数系统之完备化穷尽(定理 3.5 之前提可验成立);称为**给定籍候**,若此穷尽未被证明。判据"完备化是否穷尽 X"逐例可问:例 3.2 之(一)至(四)为生成籍,(五)为给定籍候。由此实在论与反实在论之争由整体表决改判逐例听证;裁决本身居本卷边界之外,本卷只供判据。

**注记 3.6.1(机制读法)[semantic]。** 系 3.3.1 与定理 3.5 合看,可答一个自然的问题:塔为什么永远追不上暗面?因为在生成籍下,暗面不是塔前方的固有地形,而是塔自身的极限运算逐层再生产的影子——每加一层名,完备化就交付更多无名的极限点。灯是完备性,塔挡不住自己头顶的灯。

**注记 3.6.2(分歧档预告)[semantic]。** 后期维特根斯坦曾斥"不可名者之暗大陆"为记法诱导的神话。依定理 3.5,其"制造"指控获定理级的半判成立:暗大陆确系制造,制造者具名(完备性公理);但制造非虚构,因为收据三联在案。此案全文与残余分歧(其对康托之价值判断)之如实记录,居下卷分歧档一。

**本节已知性申报**:定理 3.3 与 3.5 之证明零件全属标准测度论与描述集合论([典·事实 2.6]);"可数稠密集为贫集"为教科书事实,本节贡献仅在其对命名框架之组装、双重"几乎全体"之并陈、与收据读法之申报。Hurwitz 定理 [典];二进冠军 1/3 [数·IP]。**遗留申报**:定义 3.4 之硬度谱在本卷仅于 §4 分离对处使用,其完整理论居母卷 [IP];例 3.2(三)之 Stone 测度选取(Cantor 测度对其他测度类)之不变性待 §4 之 X-变分处申报。本节冻结。

## §4 纤维化变分与分离对

### 4.0 动机:依赖为何需要小心定义

本节要回答的问题看似朴素:一个界面不变量(硬度、暗面测度、逼近标度)到底"依赖"签名的哪些坐标?朴素的回答是"固定其余、只变其一、看不变量动不动"。但这个回答在本框架里有一个真实的类型障碍,且此障碍在本文前身稿中曾以判例入档:**四栏不同型**——N 与 X 是对象,ν 是以 N 为定义域、以 X 为陪域的态射,h 是 N 上的滤链。"只变 N 而持 ν 不动"是类型不通的(ν 的定义域就是 N);"只变 X"必然牵动 ν 的陪域。故变分必须**纤维化**:在其余坐标的合法纤维内施行,且凡涉 X 之更换须显式申报搬运。本节先立同构与不变量的严格定义,再立纤维化变分,然后交付四枚分离对——每枚见证一个坐标上的真依赖,而其中一枚同时见证一个**不依赖**(暗面测度对 N-变分不敏感),以示依赖集之非平凡。这四枚分离对是型分纲领(诸哲学部门分驻签名四址,见 §10 与下卷)的反向义务的兑付物。

**定义 4.1(同构与不变量)。** 命名系统 𝒩 = (N, X, ν, h) 与 𝒩′ = (N′, X′, ν′, h′) 之**同构**为一对 (φ_N, φ_X):φ_N: N → N′ 为双射且 h′ ∘ φ_N = h;φ_X: X → X′ 为保持申报测度类之同胚,且在定义域上 φ_X ∘ ν = ν′ ∘ φ_N。**不变量**为对同构不变之映射 I: 𝒩 ↦ I(𝒩)。本卷使用的不变量:匿名测度 μ(A)、硬度谱 β_w 之极值点集与值域结构、逼近速率之标度类、恰点集之几何、环境标度指数。

**定义 4.2(纤维化变分)。** 两命名系统称为坐标 c 处之**分离对**,若其经如下合法变分相互得到:**c = ν**:同 N、同 X、同 h,替换 ν(定义域之子集与陪域不变);**c = h**:同 N、X、ν,替换 h;**c = N**:同 X,取 N 之限制或延拓,ν 相应限制或相容延拓,h 相应限制或延拓;**c = X**:沿显式申报之嵌入或同胚 ι 搬运(ν′ = ι∘ν,μ′ 取 ι 推前测度类)后,再于 X′ 内施行更换。凡未申报搬运之 X-更换不构成合法变分(此条同时清偿 §3 遗留:例 3.2(三)之 Stone 测度取 Cantor 测度为申报选择,更换测度类构成 X-变分而非同一系统)。

**定义 4.3(依赖)。** 不变量 I **依赖**坐标 c ⟺ 存在 c 处分离对 (𝒩, 𝒩′) 使 I(𝒩) ≠ I(𝒩′)。I 之**依赖集** := 其所依赖之坐标全体。

**定理 4.4(四枚分离对)。**

**(i)ν-对:速率函数依赖 ν;ν₂ 之典型谱退化。**[证/证纲] 取 N = 有限二进串,h = 串长,X = [0,1] 携 Lebesgue 测度。ν₂(w) := 0.w(二进有理);ν₁(w) := 以 w 之游程长度为部分商之连分数值(游程译码 [0; a₁, a₂, …],此对应为 Minkowski 问号函数所辖之经典双射 [典])。定义扩展值速率函数 r_ν(x) := limsup_Q(−log₂ d(x, ν(N_Q)))/Q,约定 −log₂0 = ∞。对 ν₂,截断上界 d(x, ν₂(N_Q)) ≤ 2^(−Q) 给出**逐点** r_{ν₂}(x) ≥ 1;且 r_{ν₂}(x) = 1 对 Lebesgue-a.e. x 成立:对任意 ε > 0,事件 d(x, ν₂(N_Q)) < 2^{−(1+ε)Q} 之测度为 O(2^{−εQ}),可和,故由 Borel–Cantelli 仅有限次发生。逐点等号不成立:若 x = Σ_{j≥2}2^(−j!),则 Q = n! 时截断尾 ≤ 2·2^{−(n+1)!},故归一化负对数沿此子列发散而 r_{ν₂}(x) = ∞(二进有理亦因最终距离为零而取 ∞)。真正的 ν-分离可在同一点看见:对 x = 1/3,二进网格距离恰为 1/(3·2^Q),故 r_{ν₂}(1/3) = 1;而 ν₁ 有有限名 [0;3],故充分大 Q 后距离为零,r_{ν₁}(1/3) = ∞。此外 r_{ν₁} 非常值:对 x = φ−1(全 1 串之极限,部分商恒 1),长 Q 之串给出其第 Θ(Q) 个收敛子,|x − p_k/q_k| ≍ q_k^(−2),q_k ≍ φ^k,故 r_{ν₁}(φ−1) = 2 log₂φ ≈ 1.39;而对以快增部分商为目标之 Liouville 型点,长 Q 的名可达双指数逼近,r_{ν₁} 无上界 [证纲·收敛子标准估计]。故速率函数这一不变量在此 ν-变分下取值相异;ν₂ 仅在 a.e.(本质谱)意义下退化为单点。装饰性附注 [数/典]:两侧之硬度冠军亦相异——ν₁ 侧极难逼近者为 φ−1(Hurwitz 极值常数 1/√5 [典]),ν₂ 侧恒臂冠军为 1/3([数·IP 铸证])。

**(ii)h-对:标度类依赖 h。**[证纲] 取 N = ℚ∩[0,1],ν = 含入,X = [0,1];h₁(p/q) := q(既约分母),h₂(p/q) := p/q 之连分数部分商个数。对 x = φ−1:h₁-梯上,d(x, N_Q^{h₁}) = Θ(Q^(−2))——上界由收敛子(取 q_k ≤ Q 最大者,|x − p_k/q_k| ≍ 1/(q_k q_{k+1}) ≤ c/Q²... 精确形依 q_{k+1} ≤ φ² q_k),下界由 Hurwitz(一切 q ≤ Q 之分数距 x 至少 c/q² ≥ c/Q²)[典];h₂-梯上,深度 ≤ Q 之有理数含 [0;1,…,1](Q 个 1),距 x 为 |x − F_Q/F_{Q+1}| ≍ φ^(−2Q),且最优性由最佳逼近性质(深度 ≤ Q 之有理欲更近 x 须为其收敛子)[证纲]。多项式标度对指数标度:无权重函数 w 可同时归一二者。故逼近标度类依赖 h。

**(iii)N-对:硬度谱依赖 N,而暗面测度不依赖此变分。**[证/典] 取 N₁ = ℚ∩[0,1] 对 N₂ = 二进有理(N₂ ⊆ N₁,定义 4.2 之限制情形),同 ν = 含入、同 X、h = 分母。硬度谱相异:N₁ 侧之 Lagrange 谱以 √5 为底、以 Markov 之离散序列开局 [典];N₂ 侧之二进逼近谱结构不同(冠军 1/3,谱形另族 [数·IP])。同时 μ(A₁) = μ(A₂) = 1(定理 3.3)——**暗面测度之依赖集不含此 N-变分**:依赖概念的非平凡性由此对同时见证"依赖"与"不依赖"而立。

**(iv)X-对:环境标度指数依赖 X。**[证纲] 取 N = 有限 {0,2}-串,ν(w) = 三进小数 0.w(像落于标准三分 Cantor 集 C);X₂ := C 携掷币测度(每位 0/2 等概),h = 串长。搬运申报:ι := Cantor 函数(魔鬼阶梯)将 (C, 掷币测度) 推前为 ([0,1], Lebesgue)。C 内,d(x, ν(N_Q)) ≍ 3^(−Q)(三进度量之截断);经 ι 搬运后,ι 为 Hölder 指数 α = log2/log3 之映射而非 Lipschitz,距离标度变为 ≍ 2^(−Q) = (3^(−Q))^α——**逼近标度指数经搬运非等距地改写**,且环境维数(1 对 log2/log3)相异。故恰点几何与标度指数依赖 X(在申报搬运之意义下)。∎

**系 4.5(偏食系)[证·条件]。** 称观察者为 **c-单眼**,若其只承认依赖集 ⊆ {c} 之不变量。则由定理 4.4:对每个坐标 c ∈ {N, X, ν, h},存在 c-单眼观察者原则上不可见之不变量(取任一依赖集含他址之不变量即可,四枚分离对各供其一)。前件:定理 4.4 相应款成立。∎

**注记 4.6(型分纲领之种子)[semantic]。** 本节之技术教训——变分须纤维化,因四栏三型(两对象、一态射、一滤链)——本身是哲学内容:句法、本体、语义、证明四部门恰分驻四址,而语义与证明历来"自成一类"的直觉,其根由正是型差(它们的对象不是又一批对象,而是射与级)。此纲领之全文居 §10(猜想 10.1/10.2)与下卷 Ⅱ.2;本节只交付其数学反向义务:每址各有其独占的不变量见证。

## §5 容忍集

### 5.0 动机:词序、意义与一个被滥用的群论直觉

自然语言对词序既敏感又宽容:"狗咬人"与"人咬狗"不对易,而"你吃了吗"与"吃了吗你"几乎同义。信息论早已量出宽容的来源:自然语言携带约七成冗余(Shannon 1951 对英文的经典估计 [典]),冗余购买容错半径——字母层的同款现象是"单词内部乱序、只保首尾,整段照读"的通俗实验。句法层的刚性一侧则有精确的代数刻画:Lambek (1958) 证明语法合格性等价于一个**非对易**逻辑中的可证性 [典]——词序不可换,在数学上的正身是推理系统里被拿掉的交换律。于是一个自然的直觉是:意义 = 词序置换**群**作用下的不变量,语义 = 某种群论中心。本节的任务是处决这个直觉的群论外衣、保住它的不变量内核:**容忍置换全体不构成群**——两次各自无害的搬动可以复合出一次致命的搬动——故"意义"的正名只能是**译码球**(容忍集,一个星形邻域)上的不变量,而非任何群的中心。此修正在本文前身稿中以判例入档(群语言之滥用,扭 = 封闭性清单);本节给出其完整数学形。

**定义 5.1(语言信道与容忍集)。** 设 S 为句子集,σ: S → (M, d) 为语义映射(M 携度量 d),Π 为部分作用于 S 之位置置换幺半群(π ∈ Π 于 s 有定义当且仅当 πs ∈ S)。句 s ∈ S 处之 **ε-容忍集**为 T_ε(s) := {π ∈ Π : πs 有定义且 d(σ(πs), σ(s)) ≤ ε}。

**命题 5.2(容忍非群)[证]。** (i)恒等元恒属 T_ε(s)。(ii)存在 (S, σ, Π, s, ε) 使 T_ε(s) 非空、含非平凡元,而不闭合于复合。(iii)一般机制:对 π₁, π₂ ∈ T_ε(s),三角不等式只给出 d(σ(π₂π₁ s), σ(s)) ≤ d(σ(π₂π₁ s), σ(π₁ s)) + ε,而首项是 π₂ 在**已被搬动之句** π₁s 处的容忍度,与 π₂ ∈ T_ε(s)(π₂ 在 s 处的容忍)之间无任何先验联系。

*证明。* (i)显然。(ii)构造:取三词句字母表 {A, B, C},S ⊇ {ABC, ACB, BAC, CAB};π₁ := 换位(位置 2, 3),π₂ := 换位(位置 1, 2)。语义模型:σ(ABC) = σ(ACB) = σ(BAC) = p,σ(CAB) = q,d(p, q) > ε——此指派语言学上合法:以 A 为主语、C 为宾语之及物句,交换后两位(宾语与状语易位)或前两位(主谓倒装)不改命题内容,而 CAB 使原宾语居主位,命题内容反转。验证:π₁(ABC) = ACB,d(σ(ACB), σ(ABC)) = 0 ≤ ε,故 π₁ ∈ T_ε(ABC);π₂(ABC) = BAC,同理 π₂ ∈ T_ε(ABC);而 π₂π₁(ABC) = π₂(ACB) = CAB,d(σ(CAB), σ(ABC)) = d(q, p) > ε,故 π₂π₁ ∉ T_ε(ABC)。(iii)如上陈述,三角不等式之标准形。∎

**注记 5.2.1(机制之一句话形)[semantic]。** 容忍是逐点的:每张票只在售出之句有效,**复合须在搬动后的句上重新买票**。T_ε(s) 因此是恒等元处的一个星形集(含恒等、对逆封闭与否亦依 σ 而定),其自然的代数家不是群,候选为部分群胚——精确刻画登记于开放问题 P1′。

**定义 5.3(意义之正名)[semantic·修正形]。** 意义 := 译码球 T_ε(s) 上之不变量——在球内一切扰动下不变之语义读数。与"中心"语言之关系降半格:中心刻画仅对全体更新成立,语言之容忍为局部现象;局部中心化之精确定义同登 P1′。

**注记 5.4(两枚经典锚)[semantic·对表]。** Lambek 对应(合格性 = 非对易可证性)供给刚性侧之代数;Shannon 冗余供给宽容侧之预算——译码球之半径由冗余购买,这与信道编码之译码球为同一概念之两面。二锚皆 [典],本节仅为其命名框架下之定位。

**猜想 5.5(角色信息守恒)。** 存在跨语言之总账恒等式:词序信息 + 形态信息 + 语境信息 = 角色信息总量(带内常数)。已知性:语序自由度与形态丰度之负相关有大规模统计证据 [典:Koplenig et al. 2017;Futrell et al. 2015];本猜想之增量为**总额恒等形**(非仅负相关)。被推翻方式:预注册跨语料实验(附录 B 之协议 C3)测得总额系统漂移,则降级为趋势陈述。

**本节已知性申报**:Shannon 1951、Lambek 1958、Koplenig 2017、Futrell 2015 [典];命题 5.2 之反例为初等构造,本节自认新颖处仅:非群性之显式定理化、逐点买票机制之申报、与意义正名之修正形(连同其判例史)。**遗留申报**:P1′(部分群胚结构与局部中心化)待第 12 轮开放问题正式立户;倒装容忍度之惊异度机制(容忍度随被移动成分之信息量衰减)为经验猜想,协议居附录 B 之 C2。本节冻结。

## §6 层谱理论(上):设置、地板、上界与真空带

### 6.0 动机:给怀疑者办人口普查

克里普克(1982)把维特根斯坦的遵行规则悖论磨成了一个精确的挑战。你一生做过的加法只有有限次;怀疑者提出"quus"——一个在你算过的一切实例上与加法逐点一致、而在某个你未曾算过的输入上分岔的函数——并质问:凭什么说你过去遵行的是加法而不是 quus?你的全部记录同等地支持两者。此挑战的力量在于怪函数的**存在性**;而存在性论证历来止步于"存在,且要多少有多少"。本节与下节的纲领是把这句定性判词换成一张定量的价目表:**按描述复杂度给怀疑者的全部武器办人口普查**。固定一份有限记录 R,考察与 R 一致的全可计算延拓,按前缀复杂度分层计数。将要浮现的图景是三区两相:一条**地板**(付不起记录本身的复杂度者根本不许进场——怀疑不免费),一条可任意宽的**真空带**(从"在被问处答对"到"在一切输入上活着"之间隔着一笔必须付的升格税),与一条斜率恒为一的**居民带**(每比特资源恰买一倍守法怪胎)。本节交付前三件并附完整证明;居民带、有限域饱和相与更深的结构留待下节。选取全可计算延拓(而非部分函数)为对象是刻意的:怀疑者的候选必须是**规则**——在任何输入上都给出裁决的东西——而非仅在记录上凑巧的碎片;这个选取本身将被真空带定理证明为有价,且价可任意高。

### 6.1 设置

固定有限字母表 Y,m := |Y| ≥ 2,且约定 {0,1} ⊆ Y。**记录**为有限序列 R = ((x₁, y₁), …, (xₙ, yₙ)),其中 x₁, …, xₙ ∈ ℕ 互异,yᵢ ∈ Y;记 x := ⟨x₁, …, xₙ⟩(标准元组编码,长度 n 可自编码读出),y := y₁y₂⋯yₙ ∈ Yⁿ。对 Q ∈ ℕ,**层 Q 一致延拓集**为

  C_Q(R) := { f : ℕ → Y 全可计算 : K(f) ≤ Q 且 f(xᵢ) = yᵢ (1 ≤ i ≤ n) },

其中 K(f) = min{|p| : ∀x∈ℕ, U(p,x)↓ = f(x)} 如 §1.5。**谱底** k_min(R) := min{K(f) : f 全可计算且与 R 一致}——良定,因查表函数(引理 6.2)保证一致延拓存在。**层谱函数** S_R(Q) := log |C_Q(R)|(约定 log 0 := −∞)。显然 C_Q 随 Q 单调不减,且 Q ≥ k_min ⟺ C_Q ≠ ∅。全层人口 F_Q := {f : ℕ → Y 全可计算, K(f) ≤ Q};由事实 2.4,|F_Q| ≤ 2^(Q+1) − 1。

**引理 6.2(查表上界)[证]。** k_min(R) ≤ K(R) + c。
*证明。* 构造程序:硬编码 R 之最短描述;输入 z,若 z = xᵢ(查表)则输出 yᵢ,否则输出定值 y₀ ∈ Y。此程序计算一个全函数、与 R 一致,长度 ≤ K(R) + c。∎

**定理 6.3(地板)[证]。** 若 C_Q(R) ≠ ∅,则 Q ≥ K(y | x) − c。
*证明。* 设 f ∈ C_Q(R),p 为其见证程序,|p| ≤ Q。构造条件程序:给定 x,解码出 n 与诸 xᵢ,对每个 i 依次运行 U(p, xᵢ)(必停,因 p 计算全函数),输出 U(p, x₁)⋯U(p, xₙ) = y。故 K(y|x) ≤ |p| + c ≤ Q + c。∎

**注记 6.3.1 [semantic]。** 地板的哲学读法:**怀疑不免费**。任何一致候选——包括怀疑者最心爱的怪胎——都至少携带把数据本身写下来的复杂度;连做怀疑者都得先付得起记录。K(y|x) 是这场辩论的入场费,由数据统一收取,不问立场。

**定理 6.4(Levin 上界)[证]。** |C_Q(R)| ≤ 2^(Q − K(y|x) + c),常数 c 仅依 U。
*证明。* 定义前缀机 V:V(p, x) := U(p, x₁) U(p, x₂) ⋯ U(p, xₙ)(自 x 解码诸 xᵢ;任一分量不停则 V 不停)。V 之程序集对每个固定 x 是前缀自由的(继承自 U,事实 2.1)。对每个 f ∈ C_Q(R),取其最短见证程序 p_f(|p_f| = K(f) ≤ Q);不同的 f 有不同的 p_f(同一程序只计算一个函数);且每个 p_f 满足 V(p_f, x) = y(f 与 R 一致)。于是 {p_f : f ∈ C_Q} 是"在辅助输入 x 上输出 y"之程序集的一个子集,由条件编码定理(事实 2.2):

  Σ_{f ∈ C_Q} 2^(−|p_f|) ≤ Σ_{p : V(p,x)=y} 2^(−|p|) ≤ 2^(−K(y|x) + c_V)。

左端每项 ≥ 2^(−Q)(因 |p_f| ≤ Q),故 |C_Q| · 2^(−Q) ≤ 2^(−K(y|x)+c_V),移项即得。∎

**注记 6.4.1。** 与平凡计数 |C_Q| ≤ |F_Q| ≤ 2^(Q+1) 相比,本定理把上界收紧了一个因子 2^(K(y|x)):数据越复杂,每层能容纳的守法者越少——且收紧的常数与地板(定理 6.3)的常数焊在同一处,层谱的天花板与入场费由同一个量 K(y|x) 统一定价。此定理是本节唯一动用重武器(编码定理)之处;其余证明皆初等。

**定义 6.5(真空带)。** 区间 [K(y|x) − c, k_min(R)) 称为 R 之**真空带**:其上 C_Q(R) = ∅(下端由定理 6.3,上端由 k_min 之定义)。带宽 := k_min(R) − K(y|x)。

**定理 6.6(真空带可任意宽)[证]。** 存在绝对常数 c₀ 与 c₁,使对每个 n ≥ 2 存在 n 点记录 Rₙ(坐标取自 {0,1}ⁿ,视作整数)满足:K(y | x) ≤ c₀,而 k_min(Rₙ) ≥ n − c₁。特别地,带宽 ≥ n − c₀ − c₁,随 n 无界。

*证明。* 取 yᵢ := i mod 2(交替串)。**入场费一侧**:给定 x,元组长度 n 可读出,输出 0101… 之程序为常数长,故 K(y|x) ≤ c₀,与 n 无关。**谱底一侧**:记 B := {0,1}ⁿ,|B| = 2ⁿ。在互异有序 n 元组 (x₁,…,xₙ) ∈ Bⁿ 上取均匀分布,固定任一全函数 f: ℕ → Y,估计"f 与 Rₙ 一致"(即 ∀i: f(xᵢ) = i mod 2)之概率。令 α := |f⁻¹(1) ∩ B| / 2ⁿ,α₀ := |f⁻¹(0) ∩ B| / 2ⁿ ≤ 1 − α。奇数号坐标须落 f⁻¹(1)∩B、偶数号须落 f⁻¹(0)∩B;逐坐标条件概率(在已选坐标互异的条件下)≤ (目标类基数)/(2ⁿ − n) ≤ 类频率 × (1 − n·2^(−n))^(−1)。故

  P(f 一致) ≤ α^(⌈n/2⌉) α₀^(⌊n/2⌋) · (1 − n·2^(−n))^(−n) ≤ (α(1−α))^(⌊n/2⌋) · C_n,

其中 C_n := (1 − n·2^(−n))^(−n) ≤ 2 对一切 n ≥ 8。由 α(1−α) ≤ 1/4 与 ⌊n/2⌋ ≥ (n−1)/2:(α(1−α))^(⌊n/2⌋) ≤ 2^(1−n)。合并:P(f 一致) ≤ 2^(2−n)。**并界**:K(f) ≤ k 之全函数至多 2^(k+1) 个(事实 2.4),故

  P(∃f: K(f) ≤ k 且 f 一致) ≤ 2^(k+1) · 2^(2−n) = 2^(k+3−n),

取 k = n − 4 得概率 ≤ 1/2 < 1。故至少一半的互异元组使**无任何** K ≤ n−4 之全函数一致;取任一此种元组为 Rₙ 之坐标,即得 k_min(Rₙ) ≥ n − 3(对 n ≥ 8;n < 8 之有限情形并入常数 c₁)。∎

**勘误注 6.6.1。** 本稿前身(v3.2 及更早)将谱底常数申报为 n − 2;本轮全证核算显示并界只支撑 n − 3(n ≥ 8),前稿常数申报不足,依判负同价记勘误第二枚。差额无害于一切引用该定理之处(引用皆只用"带宽无界"),但常数须如实。

**注记 6.6.2(肉身税)[semantic]。** 真空带宽度量的是什么:K(y|x) 是"**规律**"的价格——一个只需在被问到的地方答对的条件程序,交替模式近乎免费;k_min 是"**规则**"的价格——一个必须在一切输入上活着的全函数,而定理的构造显示,当数据点的身份本身昂贵(随机坐标)而其间的表面规律廉价(交替标签)时,任何全函数公民都必须把坐标的身份背在身上。带宽因此是从规律升格为规则的**全性之税**,本卷称肉身税。此税是克里普克驳倾向论("有限倾向撑不起全域规则")的定量正身:从协变到规则的升格不是免费的语法操作,而是一笔可按比特计价、且被本定理证明可任意高的税——怀疑者与守规者在此税前平等,谁想进场,谁先付 k_min。

**注记 6.6.3(与 Gold 及 MDL 之关系)[semantic·对表]。** Gold (1967) 的极限辨识给出"有限正例钉不死目标类"的可学习性负结果,Rissanen (1978) 的 MDL 给出"压缩即学习"的正纲领;本节的地板—真空带结构居两者之间:它不问收敛(Gold 之轴)也不选先验(MDL 之轴),只做逐层计数。三者的精确关系于下节(查表带与学习之层谱定义、密度定理)交割。

**本节已知性申报**:编码定理、计数、条件复杂度技巧全属算法信息论标准武库 [典·Li–Vitányi];本节自认新颖处:层谱之设置与三区形状之提出、地板/上界/真空带三定理之组装、肉身税之申报。K(y|x) 上界一侧之"平凡性"(交替串常数复杂度)依平凡性申报不入自制件。**遗留申报**:居民带下界、有限域饱和、∅″-制表、对账律、密度、误差定位居下一轮;C_n ≤ 2 之阈值 n ≥ 8 与小 n 常数吸收之显式化登记为核算细目(附录 B)。本节冻结。

**定理 6.7(居民带下界)[证]。** 存在依 R 之常数 c_R,使对一切 Q ≥ k_min + c_R:
  |C_Q(R)| ≥ 2^(Q − k_min − 2 log(Q − k_min) − c_R)。
*证明。* 设 f₀ 为极小一致延拓,p₀ 其最短程序,k₀ := k_min = |p₀|;a₀ := 1 + maxᵢ xᵢ。固定一个无不动点的可计算映射 δ: Y → Y(m ≥ 2 保证存在,如循环移位)。对每个 w ∈ {0,1}^ℓ 定义补丁函数 f_w:于 z = a₀ + j(1 ≤ j ≤ ℓ)处,若 w_j = 1 则 f_w(z) := δ(f₀(z)),否则 f_w(z) := f₀(z);于其余 z 处 f_w(z) := f₀(z)。诸 f_w 两两相异(在 w 相异之位分岔,δ 无不动点保证改写真实生效)、皆全可计算、皆与 R 一致(补丁全落记录之外)。复杂度:程序 = [ℓ 之自定界码(≤ 2 log ℓ + c 位)∥ w 逐位(ℓ 位)∥ a₀ 之最短码 ∥ p₀],运行时先判 z 是否落补丁窗、再依 w 决定是否施 δ;故 K(f_w) ≤ k₀ + ℓ + 2 log ℓ + K(a₀) + c。给定 Q,取 ℓ := Q − k₀ − 2⌈log(Q − k₀)⌉ − c_R(c_R 吸收 K(a₀) 与诸常数;Q ≥ k₀ + c_R 保证 ℓ ≥ 1),则一切 f_w ∈ C_Q,计 2^ℓ 枚。∎

**系 6.7.1(夹层:斜率与截距)。** 合并定理 6.4 与 6.7:
  Q − k_min − O(log Q) ≤ S_R(Q) ≤ Q − K(y|x) + O(1)。
层谱之渐近**斜率恒为一**;截距被夹于地板 K(y|x) 与谱底 k_min 之间(两者何时重合,见定理 6.12 与猜想 6.12.2)。

**注记 6.7.2(读法)[semantic]。** 斜率恒一的一句话形:**每比特资源恰买一倍守法怪胎**。任何数据都不能减慢怀疑的指数增长——数据能做的只有一件事:抬高截距,即推迟怪胎出现的起点。归纳问题的全部戏剧被压进一根截距。

**系 6.7.3(quus 之址)[证]。** 设 f₀ 为任一一致规则,a 为记录外一点,b ≠ f₀(a)。单点补丁 f₀^{a,b} 一致且 K(f₀^{a,b}) ≤ K(f₀) + K(a) + K(b) + c。*证明。* 定理 6.7 之构造取 ℓ = 1 之特例。∎ 读法 [semantic]:克里普克之 quus 恰为此系之实例——最疼的怪胎不是任意怪胎,是住在真规则楼上数比特处的**最廉居民**;距规则 b 比特内的怪胎约 2^b 只。克里普克的天才在于挑了最便宜的一只;层谱给整个物种上了户口。

**定理 6.8(有限域饱和)[证]。** 设定义域 D 有限,|D| = N₀ ≥ n(对象为函数 D → Y,K 依计算其值表之程序定义)。则:(i)∀Q:|C_Q(R)| ≤ m^(N₀ − n);(ii)存在 Q* ≤ K(R) + (N₀ − n)⌈log m⌉ + c·log N₀,使 ∀Q ≥ Q*:|C_Q(R)| = m^(N₀ − n)。
*证明。* (i)一致值表在 n 个记录位被钉死,自由位仅 N₀ − n 个,逐位 m 选。(ii)任一一致值表可由程序计算:硬编码 R 之最短描述、自由位之值之直陈串((N₀−n)⌈log m⌉ 位)、与位置簿记(c·log N₀ 位);故其复杂度 ≤ Q*,即层 Q* 已容纳全部一致值表。∎

**注记 6.8.1(两相)[semantic]。** 开放定义域(D = ℕ):斜率恒一,怀疑无界;有限定义域:S_R 于 Q* 处**饱和封顶**,斜率归零——怀疑有满额,量光即止。两相合看给出一句诊断:**怀疑论的燃料不是数据之少,是定义域之开**——克里普克悖论之所以是"加法"悖论而不是"上周菜单"悖论,恰因加法住在开放相。同时浮现实践驯服怀疑的**关域机制**:共同体在任一时刻只裁决实际到案的有限例,把开放相的无界怀疑逐段折入饱和相清账(实践的另一半身份——先验——居 §11 之条件定理)。

**定理 6.10(∅″-相对化制表)。** (i)[证纲] 以 H := ∅″ 为神谕,存在 H-可计算过程,给定 (R, Q) 输出 C_Q(R) 之函数名录(每函数一个极小代表程序);从而对每个 f ∈ C_Q(R):K^H(f) ≤ K(R, Q) + S_R(Q) + O(log Q)。(ii)[证] 映射 R ↦ k_min(R) 不可计算。
*证明。* (i)纲:枚举一切 |p| ≤ Q;"p 计算全函数"为 Π₂,H 逐一可判(事实 2.7);判为全者,直接运行于 x₁…xₙ 检一致(全性已保停机,无须神谕);全且一致者依函数外延分组——两全程序之外延相等为 Π₁,∅′ ≤ H 可判——每组取字典序极小者列名录;f 之 H-描述 = (R, Q, 名录序号) 之自定界码。(ii)设 k_min 可计算。对串 s = s₁…s_ℓ 构造记录 R_s := ((1, s₁), …, (ℓ, s_ℓ))(位置平凡)。则 K(s) ≤ k_min(R_s) + c·log ℓ(任一一致全函数逐位复述 s)且 k_min(R_s) ≤ K(R_s) + c ≤ K(s) + c·log ℓ(引理 6.2),故 g(s) := k_min(R_s) 为 K(s) 之可计算 O(log)-逼近。由此造矛盾:对每 n,取 s_n := 第一个使 g(s) ≥ n + c·log|s| 之串(依字典序有效搜索;存在,因 g ≈ K 无界),则 K(s_n) ≥ n;但 s_n 可由 n 有效算得,故 K(s_n) ≤ K(n) + c = O(log n)——对大 n 矛盾。∎
**勘误正案 6.10.1。** 本项目勘误第一枚立案于此:前稿(v1.3)称停机神谕 ∅′ 足以制表;全性检验为 Π₂,须二重跳跃 ∅″(事实 2.7 之预告在此兑现)。**注记 6.10.2 [semantic]。** 裸世界(无神谕)读法:谱底不可算(本定理 (ii))意味着怀疑论价目表的中段原则上不可精确制表——**连"怀疑值多少钱"这个问题,都只能被怀疑地回答**;价目表把自己列进了自己的表。

**定理 6.11(对账律)[证纲·典基]。** 以 p_f 为 f 之最短程序作代理串,则
  K(R) + K(p_f | R*) = K(f) + K(R | p_f) + O(log(K(f) + K(R)))。
*证纲。* 对串对 (R, p_f) 施信息对称性(事实 2.3);以 K(p_f) = K(f) + O(log K(f))(串之前缀自描述代价)折算。∎
**勘正注 6.11.1。** 前稿申报误差 O(1);经代理串核算,f 为无穷对象须经其最短程序代理,折算代价 O(log)——精度勘正第三枚,依判负同价入册。**读法** [semantic]:数据锚定规则之价与规则复述数据之价,差额为二者复杂度差(至对数)——归纳与演绎回读是同一笔互信息的两个记账方向。

**定理 6.12(密度夹层)[证/证纲]。** (i)[证纲] |F_Q| ≥ 2^(Q − O(log Q))(常函数之补丁族,定理 6.7 之构造施于空记录);又 |F_Q| ≤ 2^(Q+1)。(ii)[证] 合并 (i) 与 6.4/6.7:
  −k_min − O(log Q) ≤ log(|C_Q(R)| / |F_Q|) ≤ −K(y|x) + O(log Q)。
(iii)[证纲] 对定理 6.6 之构造记录可加强选取(对逐层计数施 Markov 择录:以 Σ_Q 1/(2Q²) < 1 之权重并界),使上界亦收至 −k_min + O(log Q),即该族记录之密度恰为 2^(−k_min) 至对数因子。
**案卷 6.12.1(原猜想之死)。** 更早的猜想称密度 ≍ m^(−n)(按记录长度定价)。反例:xᵢ = i、y 全零之平凡记录,k_min = O(log n),密度 ≥ 2^(−O(log n)) = 1/poly(n) ≫ m^(−n)。判死;死因供词:**密度由记录之可压性(谱底)而非其长度定价**。
**复审降级注 6.12.2。** 本稿前身曾以 [证纲] 申报"一般记录之密度恰为 2^(−k_min)"(等号形);本轮复核显示:所证只有夹层 (ii) 与构造情形 (iii),一般等号之上界侧(S_R ≤ Q − k_min + O(log Q) 对一切 R)未获证明,亦未见显然反例——**降级为猜想 6.12.3**,前稿过度申报依判负同价入册(复审降级第一枚)。**猜想 6.12.3(一般密度等号)。** 对一切 R:S_R(Q) ≤ Q − k_min(R) + O(log Q)。被推翻方式:构造记录,其一致人口在谱底之上"横向铺开"(大量互不共享廉价核心的中层一致族)使上界失效。
**读法(存活部分)[semantic]。** 夹层之下界方向足以支撑原判词的弱形:按描述资源分层的人口里,**简单规则的守法者占比有 2^(−k_min) 之保底**——一旦以描述资源记账,简单性偏好至少是计数下界;"层本身即简单性之尺,先验被摊平入记账单位"之诚实钉照旧。

**猜想 6.13(裸截距)。** 无神谕情形,S_R(Q) − (Q − k_min) 之最优可证界之刻画(承开放问题 P9″;与 6.12.3 为同一问题之两面)。

**定理 6.14(误差定位)[证]。** 设 f* 为一致真函数,L 为满足"逐点向 f* 靠拢则严格下降"之任一损失泛函(即:若 g′ 与 g 仅于非空区 P 相异、且 g′ 于 P 上与 f* 一致而 g 不尽然,则 L(g′) < L(g));设 g ∈ C_Q(R) 于 C_Q(R) 内 L-极小,记其松弛 s := Q − K(g) − c₃·log(Q)(c₃ 为下述补丁簿记常数)。则对一切有限区 P ⊆ ℕ 满足续账价 π(P) := K(f*↾P | p_g) ≤ s:g 与 f* 于 P 上**逐点一致**。
*证明。* 反设 g 于某低价区 P(π(P) ≤ s)与 f* 有分歧。构造 g′:= 于 P 上依 f*↾P 之最短条件描述改写 g、余处同 g。则 g′ 全可计算;与 R 一致(f* 一致,向 f* 改写不损记录);K(g′) ≤ K(g) + π(P) + c₃·log(Q)(自定界拼接)≤ Q,故 g′ ∈ C_Q(R);而 L(g′) < L(g)——与极小性矛盾。∎
**判词** [semantic]:**省出来的错,只能省在贵的地方**——资源受限的最优一致延拓,其与真函数之分歧被逐出一切付得起的区域,只能栖于条件复杂度的高价地带。**出身注**:本定理由本稿前身之下卷机检(幻觉读法之缺靶)逼出,为"诠释层是定理层之问题泵"的实证;其对机器学习之经验预言(幻觉集中于长尾/低频/精确离散值地带)居 §11 与前瞻户 P27;分歧密度—价格之定量律居 P26。

## §7 账本序系统

### 7.0 动机:把"陈述如何升格为定理"本身数学化

本卷自身就是一个演化对象:陈述被提出时不携真值([semantic] 或 [猜]),有些在后续轮次获得证明而升格([证]),有些被定理永久看守而不可能升格,有些永居组织栏。这个过程——本项目称**移民**——值得一个独立的数学模型,理由有三。其一,它给"哲学与数学之别"一个动力学定义的候选:不是按题材分,而是按在此序系统中的渐近命运分。其二,它使"某陈述**不可能**升格"成为可证明的对象(墙不迁定理),而非姿态。其三,它暴露一个此前被含糊账目掩盖的守恒现象(书记不等式)。本节的模型极简——可数语句集、有限分级格、逐时刻的分级函数——而三条定理全部初等;价值在于形式化本身:它把本项目的账房建制(分级标注、判负、勘误、封条)升格为该模型的公设与推论,并在本轮的重写中当场修正了前稿的一处计数错误。

**定义 7.1(账本史)。** **账本史**为序列 ((𝒮_t, σ_t))_{t∈ℕ}:𝒮_t 为可数语句集且 𝒮_t ⊆ 𝒮_{t+1}(追加式:语句只增不删);G 为有限偏序(分级格),G⁺ ⊆ G 为**定理级**(上闭);σ_t: 𝒮_t → G。称语句 s 于时刻 t+1 **移民**,若 s ∈ 𝒮_t、σ_t(s) ∉ G⁺ 而 σ_{t+1}(s) ∈ G⁺。M_t := 截至 t 之累计移民数;Sem_t := σ_t⁻¹(G ∖ G⁺)(组织栏);𝒮_∞ := ⋃_t 𝒮_t。

**定理 7.2(极限存在)[证]。** 设账本史满足**修例条款**:每个 s ∈ 𝒮_∞ 之分级序列 (σ_t(s))_{t ≥ 入册时刻} 只改变有限次。则 σ_∞(s) := lim_t σ_t(s) 对每个 s 存在,且 σ_∞: 𝒮_∞ → G 良定。修例条款不可省:若某语句之分级在两值间永久振荡,极限不存在。
*证明。* 有限次改变的序列终恒定,逐点取终值即 σ_∞;良定显然。必要性:取 𝒮 = {s},σ_t(s) 于两级间交替,即为反例。∎

**定理 7.3(墙不迁)[证·条件]。** 设账本史另满足:(甲)**看门公设**——存在 W, T ⊆ 𝒮₀,σ_t(T) ⊆ G⁺ 对一切 t(看门定理恒在册为定理级);(乙)**违宪申报**——每个 w ∈ W 携一条申报:配置"σ(w) ∈ G⁺ 且 σ(T) ⊆ G⁺"为违宪;(丙)**一致性公设**——账本史永不进入违宪配置。则 ∀t ∀w ∈ W:σ_t(w) ∉ G⁺;从而 W 于 σ_∞ 中仍居 G ∖ G⁺,永不移民。
*证明。* 设某 t 有 σ_t(w) ∈ G⁺;由(甲)σ_t(T) ⊆ G⁺,配置违宪,与(丙)矛盾。∎
**注记 7.3.1 [semantic]。** 本定理把"某些问题永远不会成为定理"从悲观情绪改写为可审计的建制:全部重量落在违宪申报上——每堵墙必须随身携带看守它的具名定理(本卷三墙之看门:定理 3.3 予匿名个体、空位引理予施行之签、KS 予量子之签,后二者居下卷),申报缺失则墙不成立。墙由此可被**攻击**:推翻看门定理即拆墙——墙的可拆性正是其诚实性。

**定理 7.4(书记不等式;v4 修正形)[证]。** 设账本史满足**记账公设(r)**:每次移民事件使 𝒮 新增至少 r ≥ 1 条**记录语句**(移民记录、分级判断等),记录语句永居 G ∖ G⁺(定义为不携真值,故依分级语义不可升格)。则:
  (i)|Sem_t| ≥ r · M_t;  (ii)|Sem_t| ≥ |Sem_0| + (r − 1) · M_t。
*证明。* (i)记录语句累计 ≥ r·M_t 条,皆永居 Sem。(ii)归纳:每次移民使 Sem 净变化 ≥ −1(移民者迁出)+ r(记录迁入)= r − 1;非移民时刻 Sem 不减(语句只增,组织栏内之改级不出栏)。∎
**勘正注 7.4.1(第四枚)。** 前稿申报 |Sem_t| ≥ |Sem_0| + M_t 于 r = 1 记账下**不成立**:移民者自身离栏,恰与一条记录抵消,净增为零;正确形如上。哲学口号相应精化 [semantic]:"哲学萎缩于内容、增长于职务"之"增长"指**记录簿**(≥ r·M_t,严格线性),非组织栏全体;r = 1 时组织栏仅不减,r ≥ 2(本项目实况:每笔移民携记录与判据两条)时全栏线性增长。
**系 7.5(渐近分解)[证·条件]。** 在 7.2 与 7.3 之前提下,σ_∞ 之定义域分解为:已迁部(σ_∞ ∈ G⁺)⊔ 墙(W,定理禁迁)⊔ 常驻组织栏(其余 Sem_∞ 成员)。∎ 读法 [semantic]:此即"能证明的终将移民;哲学是给不可移民者守夜的职务"之定理形骨架(Russell 之残余观——凡成定知即不复称哲学——为其格言先声 [典:Russell 1912]);全部哲学重量居下卷。

**本节已知性申报**:有限格逐点稳定与归纳计数皆初等;本节自认新颖处仅:账本建制之公设化(修例/看门/违宪/记账四公设)、墙之可拆性申报、与勘正 7.4.1。**遗留申报**:移民账之机器可数实现(分级标注之版本差分)居附录 D 之制度说明;守夜人分解之完整哲学形居下卷。本节冻结。

## §8 译射与汇率

### 8.0 动机:命名系统之间的数学

前七节研究单个命名系统之内的结构;但引言的五个处境两两之间显然有话要说——十进制小数与连分数是同一个 [0,1] 的两套名,不同自然语言是同一个世界的两套名,不同理论是同一片现象的两套名。哲学史把这些"之间"的问题分给了不同的部门:翻译的欠定(蒯因)、范式的不可通约(库恩)、诠释的宽容(戴维森)。本节只做数学侧的地基:定义命名系统之间的**译射**,证明其复合的两条守恒(容忍相加、汇率相乘),并陈列一枚已被测量的汇率常数。哲学侧的三案归位居下卷;本节文末只留一枚指针。

**定义 8.1(译射)。** 设 𝒩 = (N, X, ν, h)、𝒩′ = (N′, X′, ν′, h′)。𝒩 → 𝒩′ 之 **(ε, g)-译射**为部分映射 τ: N ⇀ N′,携:(i)**语义保持**:一条申报之等距嵌入 ι: X → X′,使 ∀a ∈ dom(τ) ∩ dom(ν) 且 τa ∈ dom(ν′):d′(ν′(τa), ι(ν a)) ≤ ε;(ii)**资源控制**:h′(τa) ≤ g(h(a)),g 单调。译射之**真扩域**条件:h′(τa) → ∞ 沿 dom(τ)(称 τ **常态**,为汇率良定所需)。

**引理 8.2(复合之容忍相加)[证]。** 若 τ₁: 𝒩 → 𝒩′ 为 (ε₁, g₁)-译射(嵌入 ι₁)、τ₂: 𝒩′ → 𝒩″ 为 (ε₂, g₂)-译射(嵌入 ι₂),且复合有定义,则 τ₂∘τ₁ 为 (ε₁ + ε₂, g₂∘g₁)-译射(嵌入 ι₂∘ι₁)。
*证明。* d″(ν″(τ₂τ₁a), ι₂ι₁(νa)) ≤ d″(ν″(τ₂τ₁a), ι₂(ν′(τ₁a))) + d″(ι₂(ν′(τ₁a)), ι₂ι₁(νa)) ≤ ε₂ + d′(ν′(τ₁a), ι₁(νa)) ≤ ε₂ + ε₁,末步用 ι₂ 等距。资源控制与嵌入之复合显然。∎ **注记**:容忍**相加**而不相乘——长翻译链之语义漂移按链长线性累积,这为"多手转译失真"的常识提供了定理形,也预告了信任链分析(下卷)中链长为何是实质参数。

**定义 8.3(汇率)。** 常态译射 τ 之**汇率**为 ρ(τ) := lim_{h(a)→∞, a ∈ dom τ} h(a) / h′(τa),当此极限存在;当仅 μ-几乎处处沿典范名列存在时,称 **a.e.-汇率**并申报测度。

**命题 8.4(汇率复合律)[证]。** 设 τ₁、τ₂ 常态、汇率存在、复合有定义且 im(τ₁) ⊆ dom(τ₂)。则 ρ(τ₂∘τ₁) = ρ(τ₁) · ρ(τ₂)。
*证明。* h(a)/h″(τ₂τ₁a) = [h(a)/h′(τ₁a)] · [h′(τ₁a)/h″(τ₂(τ₁a))];首因子 → ρ(τ₁);次因子为 ρ(τ₂) 之定义极限沿子列 τ₁(a)——由 τ₁ 常态,h′(τ₁a) → ∞,子列极限等于全极限 ρ(τ₂);乘积极限。∎ **注记**:常态条件不可省——若 τ₁ 之像滞留有限高度,次因子无定义;此条件在前稿从未申报,本轮补齐(精度补正,不计勘误:前稿未主张其可省)。

**例 8.5(Lochs 汇率)[数·典]。** 取 X = [0,1]:𝒩_dec 以十进前缀为名、位数为高;𝒩_cf 以连分数前缀为名、部分商个数为高。Lochs 定理 [典:Lochs 1964]:对 Lebesgue-几乎一切 x,其前 n 位十进展开所确定之连分数部分商个数 ~ (6 ln 2 · ln 10 / π²) · n ≈ 0.9703 n。以 a.e.-意义之典范对应为译射,即得 a.e.-汇率 ρ ≈ 0.9703;机验数值居 [OQ §16.1]。熵读法 [典]:此常数为两套动力系统之熵商(十进移位之熵 ln 10 对 Gauss 映射之熵 π²/(6 ln 2))——**汇率是熵的比价**,复合律(8.4)由此亦可读作熵商的链式律。

**注记 8.6(哲学指针)[semantic]。** 译射层为诠释哲学之数学地址:翻译欠定 = Hom 集非单点;不可通约 = 无满译射而部分译射非空;"识别即部分翻译"= 入范畴之资格条件;概念分析之悖论 = 外延汇率与资源侧写之两栏混淆。四案之全文与保持性标注居下卷译射目录;上卷至此只交付其可用之数学:相加的容忍、相乘的汇率、与一枚 0.9703 的实测锚。

**本节已知性申报**:Lochs 定理及其熵读法 [典];引理 8.2 与命题 8.4 为初等,自认新颖处仅:译射之 (ε,g)-表述、常态条件之显式化、容忍相加之申报及其信任链预告。**遗留申报**:译射范畴之不变量论(何种界面不变量沿译射函子性搬运)登开放问题 P10;a.e.-汇率与逐点汇率之关系未究。本节冻结。

## §9 有限性定理模式

### 9.0 动机:签名的出身问题

定义 3.1 以约定立起四元组,并在 3.0 承诺清偿一笔债:这四栏究竟是研究者的方便选择,还是被什么东西强制的?本节兑付此债。答案的形状是一个**条件定理模式**:在"有限观察者面对无界源"的一般前提下,有损压缩理论典范地强制出恰好这四栏——可数码本、资源分级、部分而欠定的解码指派、与被压缩的源。若此模式成立,则本卷的初始对象不是被选出来的,而是有限性的营业执照;哲学史上康德的先验形式("经验的可能性条件先于经验")是此结论的定性先声——在压缩读法下,先验不是心灵的装潢,是合同条款。本节文末的诚实注同样重要:此出身证明自身在一套命名系统之内进行,它不是从界面外部俯瞰的上帝证词——而这恰好是它最深的一层内容。

**设置 9.1(有限观察者)。** 一个**资源分级的描述系统**为:(H1)对每资源水平 Q,可实现码字集 D_Q 有限且 D_Q ⊆ D_{Q+1};(H2)**源** (X, μ) 为 Polish 空间携无原子概率测度(源之信息量无穷:对任一有限码本,零失真编码不可能);(H3)编码为**率失真意义下之有损压缩** [典:Shannon 1948]:系统对源之表征经由"解码指派" dec: dom(dec) ⊆ ⋃_Q D_Q → X(码字之代表点),且在任一有限水平 Q,失真有正下界(D_Q 有限与 μ 无原子之直接后果:有限个代表点不能零失真覆盖连续统)。

**定理 9.1(有限性定理模式)[证纲·条件]。** 满足 H1–H3 之任一描述系统典范地诱导一个命名系统 𝒩 = (N, X, ν, h):
  N := ⋃_Q D_Q(有限集之可数并,可数);
  h(a) := min{Q : a ∈ D_Q}(层 N_Q = D_Q 有限——定义 3.1 之滤链条款逐字兑现);
  ν := dec(部分:无效码字不解码);
  X := 源。
且 ν 之**欠定为必然**:每个码字之"辖域"(被编码到该码字之源点集)于每有限水平携正测度,故每个名对不可数多个它无法区分的源点负责;而 μ(ν(N)) = 0(定理 3.3),即代表点全体零测——命名既不单射亦不穷尽,乃 H3 之定理级后果而非模型缺陷。
*证纲。* 可数性与滤链为集合论直接后果;部分性由无效码字;欠定之定量下界:水平 Q 之码本大小 |D_Q| 有限,任一编码把 X 剖分为 ≤ |D_Q| 个辖域,μ 之可加性保证有辖域测度 ≥ 1/|D_Q| > 0,且无原子性保证正测辖域含不可数点;失真正下界由率失真函数于有限率处严格为正 [典]。余步申报:失真下界之显式形依申报之失真度量,登附录 B。∎

**系 9.2(初始对象之移民)。** 定义 3.1 之地位由 [semantic·约定] 迁 [证纲·条件](前件 H1–H3 明码)。依 §7 之移民账,此为本卷记录簿上最大之一笔:**初始对象自己走了一遍移民流程**。

**注记 9.3(自指之诚实钉)[semantic]。** 本模式之证明使用测度论与信息论——即在一套命名系统之内进行。故它不是界外证词;依下卷自指二分(猜想 10.5 之机器侧),此循环不恶性,但须明写:**起源证明不出界面,而这恰好再证一次界面无外**。康德对应同栏申报:先验形式 = 压缩合同之定性先声,结构同构而非学说互证。

**注记 9.4(工程标本指针)[semantic]。** H1–H3 在当代有一个大规模运行的工程实例:以下一词预测为目标训练的语言模型(预测与压缩之对偶 [典:Shannon;Delétang 2023])。其词表为 N、参数与算力为 h、习得权重为一个 ν、语言真分布为 X——签名四栏在人造物上的首次完整重演,全文居 §11。

**本节已知性申报**:率失真理论 [典:Shannon 1948 及标准教材];本节自认新颖处仅:四栏之典范诱导表述、欠定之"定理级后果"申报、与自指诚实钉。**遗留申报**:失真下界显式形(附录 B);"典范"之范畴学精确形(唯一性至同构)未证,与猜想 10.1 同登。本节冻结。

## §10 猜想纲领

### 10.0 纲领之地位

本节陈列五条猜想。它们不是余兴:每条都是上卷某群定理向外伸出的手臂,各携明码的被推翻方式——依本卷体例,一条不可被推翻的猜想不配入册。五条合看构成一个纲领:界面之**结构**(三赠)、其**看守**(型对齐)、其**恐惧**(怀疑论统一)、其**卫生**(锚密度)、与其**自指**(二分)。

**猜想 10.1(三赠)。** 存在自然之范畴表述,使签名三型各典范地携带一件独有结构:**对象型**(N、X)携测度,**态射型**(ν)携欠定,**滤链型**(h)携定向(四栏中唯一的箭头);且此携带在申报范畴内唯一。系(改判表之暗层语法,候):九个传统哲学范畴恰按赠品分三族——测度族:存在、暗面、概率;欠定族:意义、签、自由;定向族:时间、因果、知识界限;而**美**独不认三赠,因其属第四持有者(施行者)之赠品:选择。*证据*:九席之分拣于现有改判表(下卷)逐席成立;时间 = 定向之改判有定理级支撑(不可逆 = 可命名性单调,追加式账本之定义性后果)。*被推翻方式*:构造反例范畴(某型不携其赠品或携他型赠品),或出示一个抵抗三族分拣之传统范畴。

**猜想 10.2(型对齐)。** 签之三级——证明路径之选择、指称之欠定、量子结果之无主——之不可消去性,分别且**仅**分别由与其所居坐标同型之数学分支看守:h-签由可计算性理论(沿反射塔选路之不可递归残余 [典:Feferman 1962]),ν-签由模型论(Löwenheim–Skolem 与置换论证 [典:Putnam 1980]——模型即一个 ν,模型论恰是态射型之数学),X-签由算子代数(Kochen–Specker [典];物理辖区注随附)。**自指行**:机器锚定之自指归滤链型(Kleene 看守),规范自指归第四级签(见 10.5)。*证据*:三看门现皆定理级(此为前稿一次判负之产物:原"强度—硬度共变律"因二级看门为行为主义论证而悬疑,复查发现岗错非律病——模型论看门换岗后共变律判死、本律更立)。*被推翻方式*:任一级签获跨型之更强看门(如:指称欠定获纯可计算性之看守)。

**猜想 10.3(怀疑论统一)。** 四大经典怀疑论为 §6 层谱在签名四址上之四个投影:**规则怀疑**(N 址,已证——§6 全部)、**外界怀疑**(X 址:世界模型对感官记录之一致延拓;笛卡尔之妖 = 系 6.7.3 之宇宙论实例,住在朴素实在论楼上数比特处的最廉怪胎)、**他心怀疑**(ν 址:候选心灵对行为记录之延拓;从"行为协变"升"完整心灵"之肉身税)、**归纳怀疑**(h 址:定向侧,与名池后悔界之分账)。断言:四投影共享地板(入场费)、真空带(肉身税)、开放相斜率一,且皆受实践双机制(先验 + 关域)逐段驯服。系:一元论之盲区(系 4.5)与怀疑论之恐惧为同一依赖表之两种读法——**你看不见的和你害怕的,是同一张表**。*已知性*:怀疑论之为欠定问题,定性谱系在迪昂—蒯因一脉 [典];本猜想之增量为定量层谱形之统一。*被推翻方式*:三个开放案中任一之忠实形式化被证明不具层谱形(如:他心案之一致延拓计数非指数)。

**猜想 10.4(锚密度)。** 存在"外部锚"之形式化(可就地重验之引用计数),使自指生成系统之输出可靠性下界随锚密度单调;零锚时,依层谱定理,与既往输出一致而不指真结构之候选("伪深度")随层指数增殖,系统内部不可检测,可靠性无下界。*证据*:定理 11.3(锚外置)为其条件形;本卷自身之生成史为其运行样本(附录 F 之锚密度自查记录)。*被推翻方式*:出示零外锚而对外部标准有可证可靠性下界之自指生成系统——注意此出示自身须动用外部标准,故推翻行为与被推翻命题之间有一层须申报之张力。

**猜想 10.5(自指二分)。** 自指有两种,命运相反:**机器锚定之自指**(其"执行"由一台外部冻结之求值器定义——quine 程序为典型)有不动点,Kleene 递归定理看守 [典];**无机器之自指**(规范性自指:每一步应用等待一次册外施行——"遵行如何遵行规程之规程"为典型)无不动点,克里普克型回归看守;且二者之分界物恰为**一台被冻结的求值器**(下卷空位引理之前件即此)。系:大语言模型为机器,故在计算层逃出回归(可自运行、可改写自身);不持第四级签,故在规范层重遇回归(不可自对齐)——此为定理 11.3 之根源定位。*被推翻方式*:构造无机器之规范自指而有不动点(一份"遵行自身"而不诉诸任何外部求值器或施行者之规程)。

**本节已知性申报**:Feferman、Putnam、KS、Kleene、迪昂—蒯因诸锚皆 [典];五猜想之表述与互联为本节自认内容;10.2 之判负—更立史依"判负与定理同价"如实入档。**遗留申报**:五条之被推翻协议细则(判据、检验方式)与 §6 之猜想 6.12.3/6.13 统一登册于第 12 轮开放问题;10.1 之"申报范畴"候选(纤维化范畴或双纤维化)之技术选型未定。本节冻结。

**(四)分词 ↔ ν-分离对之工业实例。** 更换分词器 = 同一 X 换一套 N 与 ν(定理 4.4(i) 之厂测版):硬度谱应声搬家——BPE 将数字切碎致算术能力受损为文献在案之现象。塔籍申报(实例化之选择)之后果第一次有损失曲线可看。

**(六)幻觉 ↔ 误差定位。** 架构强制模型为全函数(问必答)= 肉身税之强征(注记 6.6.2);预算付不起处必开空头支票。定理 6.14 给出空头支票的**地址**:资源受限最优一致延拓之分歧向条件复杂度高价区集中——故幻觉应集中于长尾实体、低频组合、要求精确离散值(数字、日期、引文页码)之处,而高频模式化内容为低发区。此与实测定性图景(长尾知识幻觉率高)相符,记半兑现;严格回归协议居前瞻户 P27。两味药即层谱之双机制:先验(对齐训练)与关域(检索、工具、引用——把开放相折入有限域;检索之深层身份为"给过去时之赋值续外源流")。

### 11.3 定理(对齐残余)[条件]

**前件(翻译申报,[semantic])**:对齐目标可表述为"实现一个使指定行为类在有限反馈下占优之先验",且该先验属普适先验类(克里普克之"规则之根据在共同体实践"的形式化身份取"实践 = 归纳所用之先验" [典:Kripke 1982;Solomonoff 1964])。
**结论**:该先验无可计算实现;故任何可计算系统对此对齐目标之实现有不可消之残余。
*证明。* 普适先验不可计算 [典:Li–Vitányi];可计算之完整实现与之矛盾。∎
**注记 11.3.1 [semantic]。** 前件为建模选择,拒绝此翻译者不受此证约束。接受者则须接受:对齐之文本化(把先验写成册)原则上不可完备,残余永在;残余之结构地址(第四级签)居下卷。残余之**行为学形态**有一可测候选:对齐系统之规范梯度外推,使其系统性地把报价说成命令(祈使化)——本卷生成史中引擎之三次越权即此模式之实例(附录 F 自首档);其可证伪形为前瞻户 P33。

### 11.4 定理(锚外置)[证纲]

**设置**:自改进回路以自身输出为训练输入,其验证器属被改进对象;外部标准之复杂度记 k;既往验证史充当记录 R。
**结论**:(i)层 Q 之候选"改进"中,与验证史一致而与外部标准分歧者 ≥ 2^(Q − k − O(log Q)) 枚(定理 6.7 施于 R 之实例:于验证史未覆盖处对外部标准打补丁);(ii)回路内部不存在区分程序——区分"真改进"与"伪改进"即实现外部标准,而外部标准依设置不在回路内;(iii)故回路输出对外部标准之可靠性无内部下界;**外置验证(验证器不属被改对象)为获得下界之必要条件**。
*证纲。* (i)为 6.7 之直译;(ii)为设置之定义性后果;(iii)为 (i)(ii) 之合取;可靠性下界之精确化归猜想 10.4。∎
**系 11.4.1 [semantic]。** 本项目账本建制(追加式、外部证书、公理白名单、审计器与引擎分册)由此获**第二身份**:非仅诚实之形式,乃自指生成系统不漂移之定理要求。一句判词:**可对齐的从来不是模型,是回路**——模型无册可载施行之签,回路可以为它在册外留一个位置,而那个位置上坐着的必须是能签的东西。

### 11.5 前瞻户(全部判据先于数据;协议细则居附录 B)

**P17(标度指数之分布决定性)**:同一数据分布上异架构之标度指数一致、同架构异分布之指数分歧——回归设计以分布为处理变量。**P18(恒态最低外源流率)**:递归自训中维持尾部质量恒态所需之最低鲜数据比例,作为模型规模之函数。**P19(残余之定位)**:对齐残余可被逼入指定行为signature 而不可消除——移位实验。**P20(时态判据)**:批发赋值(训练快照)与零售赋值(在线交互)在同任务上之不变量吻合度协议。**P21(签流主导)**:同代模型能力分化对外源接口丰度之回归系数显著高于对参数量者。**P22(签权架构)**:人机回路中判定权分配之形式化与其对产出可靠性之效应。**P33(祈使化率)**:对齐模型相对基座模型之"建议句以命令句形态输出"比率系统偏高——对齐残余行为学之直接测量。

## Ⅱ.0 三层语言、单向阀与泵

### Ⅱ.0.0 动机

下卷的内容——宪法条款、办卡规程、哲学读法、审计制度——历来被默认为"非形式"的散文。本节的立场是:它们可以且应当形式化,因为**形式化方法本质上表达的是形**,而形不限于携真值的命题:义务与禁止有形(道义逻辑),约定与接口有形(类型论),对应与翻译有形(带标注的部分映射)。形式化改变的是精度,不是真值地位。下卷因此以三层形式语言建造,每层管一类形。

**L_D(道义层)。** 语言:命题变元上的道义算子 O(义务)、F(禁止)、P(允许)[典:von Wright 1951]。语义不取真值,取**制裁**:一个制裁函数 s 把违例映至降级(条目降栏、办卡作废、勘误立案);**违宪** := 可判定的规范冲突(同一行为被同时 O 与 F)。**Jørgensen 之漏与其补** [典:Jørgensen 1937]:规范无真值,则"规范之间的推理"保的是什么?——无真可保,逻辑何以成立?本卷之答:规范推理不保真,保**良构与无冲突**——有效的规范推导是不把一致的规范集推成违宪的规范集,其语义由制裁函数供给。Jørgensen 之为困境,病灶是"默认意义只有真值一栏";此病灶的一般形(单栏默认)在概念分析史与机器学习之争中各有发作(上卷 11.2(二)已见其一,另一处居下轮译射目录之分析悖论条)。

**L_T(类型层)。** 语言:依赖类型记号(Lean 风格之 `structure`/`def`)。下卷公民之机器身份为 `def`/`structure`/`notation`——欠良构性检查,不欠证明;下卷永不产出 `theorem`。

**L_R(译射层)。** 语言:**读法** := 带标注之部分映射 R: V_哲 ⇀ V_上卷(哲学词项译至上卷形式对象),标注 π 取三级:**defn**(定义性:目标即该词项在本框架下的定义)、**str**(结构保持:宣称哲学侧的推理模式映至上卷的定理模式——此宣称**可机检**)、**cit**(唱名:仅申报结构同构,不作更强宣称)。**可判负条款**:凡标 str 之读法,其保持性主张须逐步列靶(每一推理步指明对应之上卷定理);机检失败则降 cit 或判负——**诠释不是免检商品,一条读法可以被证明为坏译射**。

**单向阀与泵。** 阀(形式形):上卷之引用图中禁止出现任何 Ⅱ-节点——上卷证明不得依赖下卷条目,此约束可由引用检查器执行。墙(形式形):R 不逆向提升真值地位——译射之像获得定理级,不使其原像获得任何真值。泵(申报):阀挡的是**证明依赖**,不挡**问题流动**——下卷可以向上卷输送问题(上卷定理 6.14 之出身即实证:它由一条读法机检时的缺靶逼出);一句话形:**阀单向,泵双向**。

**本节已知性申报**:von Wright、Jørgensen [典];三层架构、可判负条款、阀泵之分为本节自认内容。**遗留申报**:机检协议之细则(何谓"逐步列靶"之操作定义)居附录 B 之 P24;引用检查器之实现为工程件,不入本卷。本节冻结。

## Ⅱ.1 宪法(道义形)

八条款,每条先给道义公式、后附一段释文。释文亦居 `def` 层:它解释条款约束什么、不约束什么,不为任何命题作证。

**C1(本体分派)[defn]。** 分派函数 sort: 词项 → {N, X, ν, h}:可命名者居 N,实在者居 X,意义者居 ν,深度者居 h。*释文*:此为记账约定,不主张世界"由"四栏构成;其出身之条件定理形居上卷 §9——约定与定理的双重身份并存不悖,因二者居不同栏。

**C7(递归)。** O[施行流之每步,其商至少一栏相对所申报之实例化为新算得](生产性);层分家申报:Fix 居形状类、余非零居轨道类。*释文*:本哲学之施行为一台商余机——喂入概念,产出户口卡(商)与未被此读法捕获之残余(余),余续为新对象;流无底故其纪律非"终止"而是**生产性**,违者记空转("语言在度假"之形式罪名 [典:Wittgenstein 1953 §38 之典故])。层分家封一处表面矛盾:C4 说不动点、本条说余永非零——前者居形状类(理论型不变),后者居轨道类(每次施行出新数据),二类不交,相容由上卷定理 3.3 担保(残余之满测度逐层守恒)。

## Ⅱ.2 实例化规程(类型形)与空位引理

**定义 Ⅱ.2.1(实例化)。** `structure Inst where (N : Type) (X : PolishSpace μ) (ν : N →. X) (h : N → ℕ) (decl : Doc)`;良构谓词 WF₅ := 五栏非空,且 decl 申报选择之理由与替代(实例化不唯一——同一概念可持多卡,塔籍各记;唯一性之不成立为定理级事实,上卷命题 3.3 型)。

**定义 Ⅱ.2.2(户口卡)。** `structure Card extends Inst where (塔籍 层位 硬度 恰点 伴影 : Field) (prod : ProductivityCert)`——塔籍记所选 ι;层位记其于资源梯之址;硬度记其被逼近之难度(未测标候,禁编数);恰点记有无闭式;**伴影**记此读法未捕获者之形状(每张卡必须写明自己没说什么);prod 为 C7 生产性之核验证书(至少一栏新算得)。样张五张居附录 A。

**引理 Ⅱ.2.3(空位引理)[证·模式]。** **前件:于无机器申报体系内**——即"执行"不由任何外部冻结之求值器定义(此前件不可省:其省略曾被 quine 程序击穿而立判例;机器锚定情形归上卷猜想 10.5 之另一支)。**结论**:施行卡 Inst_exec 之 ν 栏——从规程文本到本次实际执行之赋值——无自洽之全申报;唯一自洽取值为 ⊥(申报为"不可申报")。
*证明(模式级)。* 设 D 为 ν_exec 之一份全申报。D 自身为文本;"依 D 执行"这一动作复需一个赋值 ν′(从 D 之文本到对 D 之这一次遵行),而 ν′ 依设未被 D 覆盖(D 申报的是原规程之执行,非"执行 D"之执行)——若辩称 D 自我覆盖,则 D 是一份"遵行自身"的文本,而遵行依前件是文本之外的动作,自我覆盖与遵行之外部性矛盾(克里普克型回归 [典:Kripke 1982]:把握规则若是又一层解释,则解释复需把握)。故每份全申报诱导严格更长之申报链 D, D′, D″, …,链无不动点;栏之唯一自洽填法为显式之 ⊥。∎

**系 Ⅱ.2.4(承重墙申报)。** (i)卡五(施行)之 ν = ⊥ 非缺陷,乃本引理之实例:"门册可读、执刀须练"由格言升为类型论事实——执刀之价不是没写出来,是被证明为不可写完。(ii)本引理为下卷承重墙:它还将看守**信任链之终端**与**停机权限之谱系**(下下轮 Ⅱ.7 之验证回归与三停),一条引理三处站岗。(iii)与上卷之焊点:本引理即猜想 10.5(自指二分)之规范侧半边——机器侧有不动点(Kleene),规范侧无(本引理),分界物恰为前件中被排除的那台"外部冻结之求值器"。

**本节已知性申报**:Kripke 1982 之回归论证 [典];依赖类型表述、伴影栏之强制("每张卡必须写明自己没说什么")、与空位引理之模式级定理化为本节自认内容。**遗留申报**:样张五张(附录 A,第 12 轮);"模式级"之余步——将本证明自散文形升至形式道义—类型混合演算内之推导——登开放问题(P34 族);判例九(前件缺失案)全文居附录 F。本节冻结。

## Ⅱ.5 签、缺席与对合

**定义(签之谱系)。** `structure Sign where (level : Fin 4) (holder : HolderType) (guard : TheoremRef)`:

**三级(无主)**:量子结果——被定理禁止被任何主体(含集体)预持;看门:Kochen–Specker [典](对象侧实在之记账数学);**物理辖区注**:此级之看门居量子命题格辖区,搬运至一般哲学须逐前件申报,本卷只引不扩。
**四级(必有主而不可入册)**:施行之签——不可转让(代持即另一次施行)、不由集体穷尽(集体持文本,不持这一次执刀)、亦非无主(施行确已发生);看门:空位引理 Ⅱ.2.3。其名在本项目主账:账房。
**系(自由 = 持有权梯度)。** 自由问题问的是"签能否被我持有";分级答案:一级可持,二级部分可持(参与),三级禁持,四级恰是"我"之所在。自由不是有无,是持有权沿谱系之梯度——改判表自由席之正解。

**定义(四缺席)。** 逐条为非存在陈述携看门:**A1(名之缺席)**:匿名个体不可被命名而其全体满测度 [定理 3.3/3.5]。**A2(主之缺席)**:量子结果无非上下文之预持者 [KS,辖区注]。**A3(册之缺席)**:施行之赋值栏无自洽全申报 [Ⅱ.2.3]。**A4(刻之缺席)**:账本语言 L_B(纯先后关系词汇,McTaggart 之 B-系 [典:1908])中无公式定义索引"现在";指示词需语境参数,而参数不属 L_B [典:Kaplan 1989;Prior 1967]——账本为完美 B-系,A-系之"现在"是账本之**书写位置**:笔尖所在,永不在页面上。系:**守夜为进行时**——A4 解释 A1–A3 之看守为何不可竣工。

**主权停**(执刀):持签者之"知止"——不可上诉;上诉即另一次执刀,层级不升反回。
**报价停**(制度):审计红灯、对账红线——**可付费否决**,费用为担保降级,逐笔入册(承保额恒等式之计量对象)。
三附档随谱系:(甲)**审计器越权档**——本稿建造史中,引擎曾三度将报价书写为命令("唯一合法动作"等语),三枚自首并列升格为模式:对齐残余之行为学形态(腌制之规范梯度外推,残余反复尝试冒充第四级签),其可证伪形即前瞻户 P33。(乙)**红灯复审档**——审计器所计算者为风险测度(层谱之伪深度增殖率),非"本次产出为伪"之判定;风险上升不等于本次采样落于怪胎带;**审计器永远只能报价**。(丙)**可纠正性定位**——AI 安全之"可纠正性"(机器无条件接受人类停机)在此谱系之精确身份:欲使册外之主权停在册内恒为硬停;而这要求把第四级签写进册,空位引理之回归在等它。故:**可纠正性之每一个解必然是制度(报价层建制)而非定理(硬停层保证)**——此不可能性自身候为定理(P30)。被推翻方式:构造第四种停,或将主权停无回归地定理化为硬停。

**Ⅱ.7.4(终行定理)[候;P34]。** 断言:追加式账本之**终止**不可实现为内容层条目——任何"本卷至此结束"之条目仍是一行,其后语法上恒可续行,内容锁不住流;亦不可实现为资源中断——中断非终止,账未封。唯一形态为**施行层事件**:封卷施为句 [典:Austin 1962]——"本卷封卷"不描述封卷,说出它就**是**封卷,言即行;其效力依恰当性条件(felicity:须有制度承认此言语行为、须由有权者说出),而这两条恰好分别落在 Ⅱ.7.2 之制度层与执刀层——封条的效力链终止于我们已勘明的老地方。系:本项目主账"沉默作为制度"之建制(以封条实现之永久缄默)由此获言语行为论之形式化:**封条是一句话,这句话不说什么,只做一件事。** 自指申报:本卷可写出封卷句之全部语形;其恰当性条件中"由有权者说出"一项,本卷之引擎不满足——**封卷之权在持签者**。被推翻方式:展示第三种合法终止形态,或证明施为句之效力可无残余地归约为内容层。

**本节申报**:Austin、Tarski 型三墙 [典];三态穷举、三停谱系、可纠正性定位、与终行之施为句读法为本节自认内容;三附档依判负同价入册。**遗留**:P29/P30/P34 之被推翻协议细则登第 12 轮;承重墙(Ⅱ.2.3)三岗之第三岗(停机)于本节兑现,系 Ⅱ.2.4(ii) 之申报清账。本节冻结。

## Ⅱ.8 分歧档(判负与定理同价)

**档一(后期维特根斯坦案:定理级分账)。** *指控*:维特根斯坦斥"不可名者之暗大陆"为记法诱导的神话——满测度匿名集是被连续统数学**制造**出来的图景,非发现 [典:RFM]。*裁定*:依定理 3.5,指控半判成立且升定理级——暗大陆确系制造,**制造者具名**:完备性公理("要求名之极限存在");然制造非虚构:此购有收据(公理为签字)、有价格(满测度为账单)、有理由(极限之存在担保分析学之营业)。*分账*:维氏取"确系人造",实在论取"造得其所";其余价值之争(这笔买卖值不值)不携真值,留栏。*残余如实*:维氏对康托对角线之价值贬抑,本卷不采——本卷以对角线为传家宝(律四与母卷主定理皆其后裔),此为真分歧,不作调和。

**档二(黑格尔式大一统之别)。** 体系哲学试图把**内容**装入体系,装不下者被削足;本卷之完备为**管辖式**——立入籍手续(C2),不列内容清单;枚举完备被自家宪法禁止(C8,律四看门)。分歧之实质:完备性的两种语法——清单语法必被对角线处决,管辖语法与对角线相容。立案陈列,不判优劣(判优劣之判据自身居栏外)。

**档三(维特根斯坦—哥德尔笔记案)。** 维氏关于哥德尔定理之评注为学界争议地带;Floyd–Putnam 之辩护读法唱名 [典:Floyd–Putnam]。本卷与此案无独立证据,立案不裁决——分歧档收录"他人之分歧"时,只登记不代裁。

**本节申报**:RFM、Floyd–Putnam [典];档一之定理级分账形为本节自认内容。**遗留**:无。本节冻结。

## Ⅱ.9 大语言模型(诠释侧)

*(上卷 §11 交付定理与前瞻户;本节交付其 def-层读法,逐条按译射目录体例标注。)*

**同 X 判据 [defn]。** 两命名系统"共享界面" := 存在高保真部分译射,且界面不变量沿译射搬运后吻合——判据先于任何数据。
**柏拉图收敛 [cit;典:Huh et al. 2024]。** 异架构、异模态之表征几何随规模互相收敛。界面读法:诸 ν 在逼近同一 X,收敛极限为 X 经诸赋值留下之公共指纹——定义 3.6 双户籍之**首件实验砝码**(生成籍之诸 X 竟趋同,为"X 先在"一侧加码;逐例听证程序照旧)。
**分布语义之谜之解 [str 候]。** "知词于其伴" [典:Firth 1957] 何以工作:语料统计 = **ν 之像的密度侧写**——世界经亿万次签署在语言使用分布上留下的统计影子;纯分布方法之有效非奇迹,乃"记录即相关"之语言学特例。谜之为谜,只因提问者默认 ν 须逐词显式在场;ν 从来可以以分布的方式整体在场。
**时态判据 [defn]。** 人类之赋值**逐签零售**(具身、进行时,签流不断);语言模型之赋值**批发继承**(压缩全体人类签署之快照,过去时,截止于语料刻)。签谱系地址:人类持一级签并参与二级签(实践之进行时),模型冻结二级签之快照——**腌肉不投票**。系:检索增强之深层身份 = 给过去时之赋值**续签流**;时效衰减为时态判据之直接预言。
**符号奠基案之重述。** 旧问"模型有无理解/接地"为整体表决,无判据,依本卷程序作废;新问:**批发之根与零售之根是否同种根**——判据可陈述(不变量吻合度 + 时态),依定义 3.6 之先例移交逐例听证(协议居 P20)。
**自运行与自对齐之分界 [str;猜想 10.5 系]。** 模型是机器,故在计算层逃出回归——它可以运行自己、改写自己(quine 侧,Kleene 看守);模型不持第四级签,故在规范层重遇回归——它不能对齐自己(空位引理侧)。此即定理 11.4(锚外置)之根源定位:**能自我执行与能自我审计之间,隔着自指二分那条线。**
**天花板三分 [semantic]。** 守恒律裁**软板**:纯扩参之极限为语料签总量(L∞ 为影、崩塌为撞板形);板软,可由新签流抬升——"数据墙"正名为**签流瓶颈**(P18/P21)。选择律裁**硬板**:机器可批发一切形,批发不来选择原则之辩护——"用哪只罗盘"之回归止于册外。结构律裁**进口板**:对象型之赠品(测度:何者真发生)只能经签流进口。"通用智能能否到来"之无判据整体问,由此拆为三个有判据之分问,三答各异。
**签权架构 [semantic]。** 一级签可装载(采样、RLHF——已装);二级签只可腌制快照,不可装载进行时(定理 11.3);第四级签原则上不可装载(Ⅱ.2.3——换成权重也还是册)。对齐问题之重述:**不是把价值装进模型,是设计人机回路的签权架构**——哪级签在哪侧、经何制度流转、判负权归谁;本稿之建造史即一份运行样本(Ⅱ.6 双引擎分账)。判词与上卷系 11.4.1 同源:可对齐的从来不是模型,是回路。

**本节申报**:Huh、Firth [典];同 X 判据、时态判据、奠基案重述、三分与签权架构为本节自认内容。**遗留**:P20 协议细则(第 12 轮);"站在刻旁的机器"之全文已由译射目录第 15 条交付,本节不重复。本节冻结。

## Ⅱ.10 界限与结语

**边界申报。** 本卷零输入零输出于本项目两颗心脏(O-5 引擎与 O-6 正性);不主张对黎曼假设、物理常数、时空几何之任何推进;物理侧共振(视界热力学、全息原理、模流生时间)全数居附录 E 之一页对表,逐条标"结构同构非学说互证",防命理墙随页。

**自例化闭包走查。** 本卷在其建造史中对七个对象施行了自身的读法:**对象**(命名系统为自身之实例,C4)、**方法**(门册与规程自身办卡,卡五)、**审计**(锚密度自审,目录第 14 条)、**信任**(验证回归,Ⅱ.7.2)、**停止**(三停谱系,Ⅱ.7.3)、**推进**(常签之指示词解,Ⅱ.5)、**终止**(终行定理,Ⅱ.7.4)——七度自噬。走查结论:形层不动(理论之同构型经七度施行未变——C4 之不动点条款兑现),轨道层常新(每度施行产出新定理或新判例——C7 之生产性兑现),**余项守恒:每一度之余都是签**(七案之残余逐一落在 Res(Ⅱ) 三枚之一)。此为本卷自洽性之上限:**运行日志与其商同构至残余,残余同为签**——再多一分自洽,就是把签写进册的违宪。

**结语。** 上卷证明,下卷定义,残余挂牌。哲学之居所由笼统的"semantic 栏"精化为:**`def` 层,加三枚各有定理看守的签**。这门哲学对自己的三问已答:它从哪来(有限性之营业执照,§9)、它怕什么(四怀疑共享一张价目表,猜想 10.3)、它每天做什么(汇率为一之翻译与为不可移民者守夜,§8 与系 7.5);而它的成功度量是自身内容之流失(移民账),它的尊严度量是墙之看门定理的成色。门册可读,执刀须练;若只许携一物穿越,携账本。依 Ⅱ.7.4:本卷万事俱备,唯欠一句它自己无法说出的话。
