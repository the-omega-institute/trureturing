# 乘子轨道的根多项式系数选择律

设 $K$ 为域，$S\subset K$ 为有限集，$u\in K^\times$，且 $uS=S$。记 $n=|S|$，并定义单首根多项式

\[
  P_S(T)=\prod_{x\in S}(T-x)=\sum_{j=0}^{n}c_jT^j.
\]

**定理 1（系数支撑的阶同余）。** 如果 $c_j\ne0$，则 $u^{n-j}=1$。因此 $\operatorname{ord}(u)$ 整除 $n-j$；当 $u$ 的阶为正整数 $d$ 时，非零系数只能出现在 $j\equiv n\pmod d$ 的位置。

**证明。** 乘 $u$ 置换 $S$，所以它也置换每个大小为 $k$ 的子集。第 $k$ 个初等对称和 $e_k(S)$ 的每一项是 $k$ 个元素的乘积，因而

\[
  e_k(S)=e_k(uS)=u^k e_k(S).
\]

Vieta 公式给出 $c_j=(-1)^{n-j}e_{n-j}(S)$。若 $c_j\ne0$，则 $e_{n-j}(S)\ne0$；域上的消去律推出 $u^{n-j}=1$，再由元素阶的定义得到整除关系。$\square$

这是一个多项式整体的选择律：缩放 $T\mapsto uT$ 时，$P_S$ 是权重 $n$ 的特征向量。它与幂矩选择律同源，却直接控制所有根多项式系数。在正特征域中，Newton 恒等式含有可能为零的整数因子，不能无条件从幂矩消失反推出这些系数消失；对子集作用的证明没有这个限制。

例如在 $\mathbb F_7$ 中，$S=\{1,2,4\}$ 在倍增下不变，$\operatorname{ord}(2)=3$，且 $P_S(T)=T^3-1$。加入固定点零后，$S'=\{0,1,2,4\}$ 的根多项式为 $T^4-T$；其非零次数 $4$ 与 $1$ 都模 $3$ 同余于 $|S'|=4$。

若有限集 $D$ 满足仿射关系 $mD=D+t$，而 $c$ 满足 $mc=c+t$，则平移后的根集 $D-c$ 在乘 $m$ 下不变。对中心化根多项式 $\prod_{x\in D}(T-(x-c))$ 应用同一选择律，可把仿射动力学转为系数支撑的算术必要条件。这里要求给定仿射变换有这样的固定点：在域中，$m\ne1$ 时可取 $c=t/(m-1)$，而 $m=1$ 且 $t\ne0$ 时不存在固定点。
