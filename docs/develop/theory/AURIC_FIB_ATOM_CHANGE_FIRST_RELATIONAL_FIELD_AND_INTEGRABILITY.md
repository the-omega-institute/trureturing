## 一、变化优先本体

令 $\mathcal E$ 是事件或局部状态的集合。

不预设外部空间，也不预设全局时间，只定义允许的局部变化关系：

```math
e\longrightarrow e'.
```

一条有限因果历史是：

```math
h=(e_0\longrightarrow e_1\longrightarrow\cdots\longrightarrow e_n).
```

真正原始的对象不是某个外部容器，而是：

```math
\boxed{
\mathscr D=(\mathcal E,\longrightarrow,\delta)
}
```

其中：

- $\mathcal E$：局部状态；
- $\longrightarrow$：允许发生的变化关系；
- $\delta(e,e')$：从 $e$ 到 $e'$ 的变化内容。

如果坚持“只有变化”这一更强的观点，可以把状态本身也降为历史的端点：

```math
e_i=\partial_i h.
```

此时基本对象不再是“物体在空间中的位置”，而是：

```math
\boxed{
\text{哪些局部变化可以连接，}
\quad
\text{以及这些变化如何继续变化。}
}
```

## 二、一个场与变化之间的关系

假设存在一个值域 $\mathcal A$，它可以是：

- 实数或复数空间；
- 向量空间；
- 矩阵代数；
- 概率律空间；
- 关系代数；
- FIB 状态函数空间。

一个所谓“统一场”可以写成：

```math
\Phi:\mathcal E\longrightarrow\mathcal A.
```

变化则是：

```math
\delta_\Phi(e,e')
=
\Phi(e')-\Phi(e).
```

但是这里有一个关键事实：

> 并不是每一个变化场 $\delta$ 都能由一个全局单值场 $\Phi$ 表示。

因此，严格的逻辑顺序应当是：

```math
\boxed{
\text{变化是原始对象，}
\quad
\text{场是变化在满足可积条件时的势表示。}
}
```

## 三、定理：何时变化可以还原成一个全局场

设 $G=(V,E)$ 是一个连通图，每条有向边 $e=(u,v)$ 赋予一个变化量：

```math
\delta(u,v)\in A,
```

其中 $A$ 是交换群，并规定反向边满足：

```math
\delta(v,u)=-\delta(u,v).
```

对一条闭合回路：

```math
C=(v_0,v_1,\ldots,v_n=v_0),
```

定义变化环量：

```math
\oint_C\delta
=
\sum_{i=0}^{n-1}\delta(v_i,v_{i+1}).
```

### 定理一：变化—场可积定理

存在一个全局场：

```math
\Phi:V\longrightarrow A
```

使得：

```math
\delta(u,v)=\Phi(v)-\Phi(u)
```

对所有边成立，当且仅当：

```math
\boxed{
\oint_C\delta=0
}
```

对图中的每一条闭合回路成立。

若该场存在，则它在加上一个整体常数后唯一。

#### 证明

先证明必要性。

如果：

```math
\delta(u,v)=\Phi(v)-\Phi(u),
```

那么对任意回路：

```math
\begin{aligned}
\oint_C\delta
&=
\sum_{i=0}^{n-1}
\bigl(\Phi(v_{i+1})-\Phi(v_i)\bigr)
\\
&=0,
\end{aligned}
```

因为中间项全部抵消。

再证明充分性。

选定一个根节点 $v_\ast$，令：

```math
\Phi(v_\ast)=0.
```

对任意节点 $v$，选一条从 $v_\ast$ 到 $v$ 的路径 $p$，定义：

```math
\Phi(v)=\sum_{e\in p}\delta(e).
```

如果选择另一条路径 $q$，那么 $p$ 与 $q$ 拼成一条闭合回路。由假设：

```math
\oint_{p\cup\bar q}\delta=0,
```

所以：

```math
\sum_{e\in p}\delta(e)
=
\sum_{e\in q}\delta(e).
```

因此 $\Phi(v)$ 与路径选择无关。

对于任意边 $u\to v$，取根到 $u$ 的路径再接上该边，就得到：

```math
\Phi(v)=\Phi(u)+\delta(u,v),
```

所以：

```math
\delta(u,v)=\Phi(v)-\Phi(u).
```

唯一性方面，若 $\Phi_1,\Phi_2$ 都表示同一个变化，则：

```math
(\Phi_1-\Phi_2)(v)
```

沿每条边都不变。因为图连通，它只能是整体常数。

证毕。

### 这个定理对你的时间观有什么含义

如果局部时钟边权 $\omega(e,e')$ 满足：

```math
\oint_C\omega=0,
```

那么可以定义一个全局时间势：

```math
T(e')-T(e)=\omega(e,e').
```

但如果存在某条回路满足：

```math
\oint_C\omega\neq0,
```

则不存在一个全局单值时间函数 $T$ 能同时解释所有局部时钟。

这时：

```math
\boxed{
\text{局部时钟是真实的，}
\quad
\text{但全局时间势不存在。}
}
```

这比简单地说“时间不存在”更精确：

- 局部变化存在；
- 局部等待和因果顺序存在；
- 但它们不一定能够拼成一个全局线性时间轴。

所以你的“只有变化”观点，实际上包含了一个重要方向：

```math
\boxed{
\text{全局时间是局部变化在零环量条件下的积分结果。}
}
```

## 四、空间、时间和因果都可以成为变化的派生结构

在这个框架中，空间、时间和因果不再是三种并列本体。

### 1. 因果

因果是变化关系的支持：

```math
e\to e'
```

表示该变化被允许。

如果：

```math
e\not\to e',
```

则不是“距离太远”这么简单，而是：

```math
\boxed{
\text{不存在一条当前模型允许的变化路径。}
}
```

所以因果场可以定义为：

```math
\mathcal C(e,e')
=
\mathbf 1_{\{e\to e'\}}.
```

它不是与统一场并列的第二个场，而是统一变化场的零值结构和支持结构。

---

### 2. 局部时间

局部时间是变化边上的等待核：

```math
K_{e,e'}\in\operatorname{Prob}(\mathbb R_{\ge0}).
```

它描述：

```math
e\to e'
```

这一变化在局部观察中可能经历什么等待分布。

因此：

```math
\boxed{
\text{时间}
=
\text{变化之间的局部测度与顺序}.
}
```

如果这些局部测度能够积分成全局势，才会出现一个全局时间参数。

---

### 3. 空间

空间可以从变化路径的可达性和代价中派生。

给每条变化一个非负成本：

```math
c(e,e')\ge0.
```

定义路径距离：

```math
d(e,e')
=
\inf_{h:e\leadsto e'}
\sum_{(u,v)\in h}c(u,v).
```

在满足对称性、三角不等式和可分辨性等条件时，$d$ 才能成为度量。

因此：

```math
\boxed{
\text{空间不是先验容器，}
\quad
\text{而是变化路径的可达几何。}
}
```

但需要强调：三维空间不会仅仅因为某个 FIB 读出有三个坐标就自动被证明。要得到三维，需要证明某个宏观极限中的局部变化距离具有三维流形或三维度量结构。

```math
\eta_{13}
```

```math
g=a_0+a_1x+a_2z+a_3y+\eta_{13}xy.
```


五个状态上的取值全部相同，因此 $g=f$。

## 七、变化不是普通的“导数”，而是路径上的操作

如果没有全局时间，就不能把变化首先定义为：

```math
\frac{d\Phi}{dt}.
```

更一般的定义是：对每个合法局部动作 $a$，设其转移为：

```math
U_a:\mathcal H\to\mathcal H.
```

定义变化算子：

```math
D_a=U_a-I.
```

那么：

```math
D_a\Phi
```

表示场在动作 $a$ 下发生的变化。

对于动作词：

```math
w=a_1a_2\cdots a_n,
```

定义：

```math
U_w=U_{a_n}\cdots U_{a_2}U_{a_1}.
```

相应总变化为：

```math
D_w=U_w-I.
```

如果两个动作 $a,b$ 可以交换，则：

```math
U_aU_b=U_bU_a.
```

如果不能交换，则：

```math
[U_a,U_b]
=
U_aU_b-U_bU_a
```

就是路径次序产生的变化差异。

这提供了一个新的 FIB 解释：

```math
\boxed{
\text{空间方向}
\sim
\text{可交换或近似可交换的变化方向},
}
```

```math
\boxed{
\text{时间方向}
\sim
\text{变化操作的实际排列顺序},
}
```

```math
\boxed{
\text{因果方向}
\sim
\text{哪些操作序列是合法的}.
}
```

这里没有引入三个独立本体，而是从一个变化代数中提取出三个不同的结构。

## 八、生命、物质、衰变和辐射都可以降为变化类型

在这个框架中：

### 物质

物质不是一个额外场，而是一个具有稳定内部变化闭包的局部模式：

```math
U_a(\Phi)\approx\Phi
```

对某些允许变化 $a$ 成立。

也就是说，物质是：

```math
\boxed{
\text{在一组变化下保持结构的局部闭合模式}.
}
```

### 衰变

衰变是某个状态经过合法变化后离开原有闭包：

```math
U_{\mathrm{decay}}\Phi
\notin
\mathcal M,
```

其中 $\mathcal M$ 是原物质模式的状态集合。

衰变不是“时间流过之后物质自动消失”，而是：

```math
\boxed{
\text{原有变化闭包失去不动性}.
}
```

### 辐射

辐射是变化被分解为局部残留和外传输出：

```math
U_{\mathrm{decay}}\Phi
=
\Phi_{\mathrm{remain}}
+
\Phi_{\mathrm{out}}.
```

这里的加法只是在线性化场表示中的示意；更一般地，可以写成一个输出映射：

```math
R_{\mathrm{ray}}U_{\mathrm{decay}}\Phi.
```

如果：

```math
R_{\mathrm{observer}}
\bigl(
\Phi_{\mathrm{out}}
\bigr)=0,
```

则对于当前观察者，辐射携带的变化不可见。

如果辐射被吸收，变化会转移到另一个局部状态：

```math
\Phi_{\mathrm{out}}
\longrightarrow
\Phi_{\mathrm{absorber}}.
```

所以：

```math
\boxed{
\text{辐射不等于信息凭空消失，}
}
```

而是：

```math
\boxed{
\text{变化从一个局部载体转移到另一个载体}.
}
```

### 生命

生命可以被定义成一种能够主动选择变化路径的局部闭包：

```math
\pi:
\text{局部观察}
\longrightarrow
\text{动作选择}.
```

它不需要“逆转所有变化”。更严格的说法是：

```math
\boxed{
\text{生命是对变化路径的选择性控制}.
}
```

当一个系统能够选择动作，使自己始终留在未来可维护区域 $K$ 内时，它就具有维护性质。

因此：

```math
\boxed{
\text{生命不是没有变化，}
\quad
\text{而是能够利用变化维持自身结构}.
}
```

## 适用条件与更正

以下命题是编辑给出的适用条件和反例，与上方完整供文分开。它们点名原节与原定理的适用范围，保留原有表述的来源归属；普通数学说明不构成新增形式验证。

### Q1：差分的值域条件（原第二、七、九节）

**适用命题 Q1。** 要使原文的 $\Phi(e')-\Phi(e)$、$\Delta(e,e')$ 和算子差具有所用的加法差分意义，须先指定加法群或向量空间作为共同环境。实数、复数、向量空间及矩阵代数的加法结构可承担这些式子；“概率律空间”或任意“关系代数”这个名称本身不提供该结构。

例如两个概率向量 $(1,0)$ 与 $(0,1)$ 的差为 $(-1,1)$，不是概率向量。有限概率单纯形可嵌入实向量空间，概率测度可嵌入有限符号测度空间，然后在该环境中相减；所得差不是新的概率律。集合关系的并、交或关系复合也不自带加法逆元，集合差不能替代交换群差分。原文定理一的交换群假设须实际成立，不能仅凭第二节的值域枚举推广到全部候选值域。

### Q2：势的精确性、形式逆行与时钟边界（原第三、十节，定理一及定理三的第一、二点）

**适用命题 Q2。** 取底层无向图连通的图，为每条选定定向的边赋交换加法群 $A$ 中的值；对该边的形式反向遍历赋相反值。势存在的条件是每一条带符号闭合游走的和为零，包括需要反向遍历、重复顶点或重复边的游走。原文的 $\bar q$ 在此是路径求和中的形式逆行，不是合法的反向因果动作。若图有平行边，遍历及边值还须保留边身份。

在这些条件下，定理一的路径求和证明给出 $\delta(u,v)=\Phi(v)-\Phi(u)$。任意两条根到顶点的底层路径之差是带符号闭合游走，故求和一致；两势之差沿边恒定，故连通时仅差一个常数。底层图不连通时，应分别在每个连通分量选根，每个分量各有一个独立常数，不能要求全图只差一个共同常数。

**反例 Q2.a：只查有向回路不足。** 取有向无环菱形图 $u\to v\to t$ 与 $u\to w\to t$，依次赋边值 $1,1,1,2$。它没有有向闭合回路，因而“所有有向回路和为零”空泛成立；两条 $u$ 到 $t$ 的路径和却分别为 $2$ 和 $3$。带符号闭合游走 $u,v,t,w,u$ 的和为 $1+1-2-1=-1$，不存在同时拟合四条边值的势。定理三必须继承上述底层图、交换群与全部带符号闭合游走条件，不能以“连通因果图”替代这些假设。

**适用命题 Q2.b：精确时钟势与坐标时间不同。** 非零带符号环量只否定满足所指定边差 $T(e')-T(e)=\omega(e,e')$ 的那个精确势，不否定所有全局坐标时间。在上述菱形图上仍可取 $T(u)=0$、$T(v)=T(w)=1$、$T(t)=2$，使每条因果边上 $T$ 严格增加；它只是没有拟合边 $w\to t$ 所指定的增量 $2$。

如果实值因果边增量严格为正且确为某个势的差，则任何非空有向闭合游走都不可能存在：沿该游走的增量和严格为正，而势差的望远镜求和为零。这说明正增量精确势排除有向循环；它不把形式反向遍历变成负等待时间的物理过程。等待核是一族概率律，并不自动是可求势的实边权；须另给标量化、联合等待规则或其他明确的可积对象。即使有这些数学对象，原文“局部时钟是真实的”仍属模型解释，没有获得经验实现认证。

### Q3：直接边、可达性与零变化（原第一、四节）

**更正命题 Q3。** 原文 $e\not\to e'$ 仅表示没有直接合法边，不能推出没有多步路径。例如仅有 $e\to m$ 和 $m\to e'$ 的三顶点图没有 $e\to e'$ 这条边，却有合法历史 $e,m,e'$。若要表达不存在任何有限合法路径，须使用可达关系的否定 $e\not\leadsto e'$，并明确是否允许空路径。

合法支持也不能一律由 $\delta\ne0$ 读出：模型可以允许等待、自环或在所选读出下零变化的转移。两个不同顶点之间的合法边可有 $\delta=0$；同一常值势配合不同边集合也有同样的零差分。因果关系应作为独立指定的合法域或关系保留，除非另有假设将合法性与非零值等同。原文“零值结构和支持结构”的关联需要这个附加合同。

### Q4：全定义关系场与未提供的结构（原第九、十节，定理三的第三点）

**更正命题 Q4。** 按原文所写，全函数 $\Phi:\mathcal E\times\mathcal E\to\mathcal A$ 在每一对事件上都有定义，因此 $\mathbf1_{\{\Phi(e,e')\text{ 可定义}\}}$ 恒等于一，不能编码一般因果支持。要使这一支持指示有意义，须改用指定域 $D\subseteq\mathcal E\times\mathcal E$ 上的部分场、取值于 $\mathcal A\sqcup\{\bot\}$ 的 option-valued 场，或另行指定合法关系 $C$。若要保留 $S(e)=\Phi(e,e)$，还须规定全部对角点可取值；若这些对角点只用于状态记录而不表示合法动作，合法因果域需与记录域分开。

一元势差 $\delta=d\Phi$ 只确定每个连通分量中的相对值，恢复势需要参考值或规范选择。第九节的二元定义有更大的未定项：对任意选定的 $S(e)$，

```math
\Phi(e,e')=S(e)+\Delta(e,e')
```

均给出同一个 $\Delta$，只要 $\Delta(e,e)=0$。因此 $\Delta$ 本身不恢复对角状态值 $S$；不能把一元势与二元关系场当成已证明等价的类型。

**反例 Q4.a：相同零差分，不同等待律。** 在同一合法边上，两个模型都取 $\Phi=0$、$\delta=\Delta=0$，一个指定等待律 $K=\operatorname{Dirac}_1$，另一个指定 $K=\operatorname{Dirac}_2$。两者差分完全相同，等待时间却不同。同样的零差分可配不同成本、输出映射与状态转移；常值读出也不能区分保持状态的动力学与把不同状态合并的动力学。

因此，定理三第三点的可用版本是：在给定合法边与路径、明确的状态或场载体、参考值、等待核、成本、输出读口、FIB 指示函数及转移规则之后，局部路径和读出分析可以不依赖全局势。它没有证明仅由 $\delta$ 恢复这些附加结构。若坚持将它们“由 $\Phi$ 诱导”，须明确给出例如 $K=k(\Phi(e,e'))$、成本函数及更新/输出函数的模型映射；这些映射是附加数据，不由一个函数类型或其差分唯一指定。

### Q5：最短路径距离的实际类型（原第四、九节）

**适用命题 Q5。** 固定有向合法图与非负边成本，允许长度零、成本零的空路径，令无路径时的下确界为 $+\infty$。原文路径下确界定义给出取值于 $[0,+\infty]$ 的扩展非对称伪距离：$d(e,e)=0$，但不同顶点之间可以距离为零，也可以不可达而距离为无穷。

三角不等式来自合法路径拼接：接上从 $e$ 到 $m$ 与从 $m$ 到 $e'$ 的路径，成本相加。两段距离有限时分别选任意接近下确界的路径，再令误差趋零，得到

```math
d(e,e')\le d(e,m)+d(m,e').
```

有无穷项时使用扩展实数的同一不等式。无需把三角不等式列作独立的未知额外条件；对称性、不同点的正分离以及距离处处有限才需另给假设。

**反例 Q5.a。** 只有单向成本为 $1$ 的边 $u\to v$ 时，$d(u,v)=1$ 而 $d(v,u)=+\infty$；两个方向成本分别为 $1$ 与 $2$ 时，距离虽都有限仍不对称；若两个不同点之间有零成本边，便有 $d(u,v)=0$。一个足够的普通度量条件是有限连通无向图及每条边成本严格为正，或相应的双向等成本有向表示。无限图中仅逐边正成本不保证不同点的距离正，仍需排除趋零路径成本。

这是一种指定图与成本的可达几何。三个 FIB 均值既不提供这些成本，也不证明三维流形、局部欧氏结构、物理空间维数或宏观极限；原第四节关于三维的限制须保留。

### Q6：操作、场与函数必须有共同类型（原第一、七、八、九节）

**适用命题 Q6。** 为使用 $D_a=U_a-I$、$D_a\Phi$ 和交换子，须指定共同的线性空间 $\mathcal H$，使 $U_a$ 与恒等算子 $I$ 是其上的线性端同态，而 $\Phi$ 是该空间中的元素；或明确说明采用何种加法环境及逐点差分。如果 $U_a$ 只在状态集合上作用、$\Phi$ 却是状态函数或关系场，原式尚未良好定型。

例如确定状态映射 $t:S\to S$ 可诱导概率律的推前 $`t_*p`$ 与函数的拉回 $`t^*f=f\circ t`$；有限随机核采用行向量约定时，概率律更新为 $p\mapsto pT$，测试函数拉回为 $f\mapsto Tf$，二者由期望配对相容。场若位于 $\mathcal A^{\mathcal E}$ 或 $\mathcal A^{\mathcal E\times\mathcal E}$，仍须指定动作如何作用于这些函数空间。推前、拉回及其复合方向不能仅凭同一个 $U$ 字母互换；原文的动作词顺序只在选定约定下解释。

不可逆输运默认只有合法复合，没有群逆。例如把两个状态都映到同一个状态的确定转移不是单射，不能恢复初态；其在线性律空间上的转移矩阵也不可逆。闭合游走中的形式逆行不授权写 $U_a^{-1}$。交换子非零表示共同域上两次复合的净差，不能直接赋予物理曲率、空间方向或时间方向。

把状态称作“历史端点”仍需端点对象域、空历史/恒等操作以及端点匹配的复合规则。不同纤维上的箭头 $U_{e\to e'}:\mathcal H_e\to\mathcal H_{e'}$ 只有在类型可接时才能复合；若要减去一个恒等算子或比较两种次序，还需共同端点空间或指定识别。“只有变化”不会消去这些对象、身份与合法性条件。

### Q7：FIB 指标、线性观察核与可识别条件（原第五、六、十节，定理二）

**适用命题 Q7。** 原文的五态分解须将状态理解为合法潜在索引集合 $\varnothing,\{1\},\{2\},\{3\},\{1,3\}$，$F[I]$ 是这些集合的输出标签。取 $x=\mathbf1_{\{1\in I\}}$、$y=\mathbf1_{\{3\in I\}}$、$z=\mathbf1_{\{2\in I\}}$。这不是对 Fibonacci 输出列表的数值成员测试；例如 $F[1]=[2]$ 的 $x=1,z=0$，不能因输出中出现数值 $2$ 就令 $z=1$。

| 源状态 | 潜在索引集合 $I$ | $x$ | $y$ | $z$ | $xy$ |
| --- | --- | ---: | ---: | ---: | ---: |
| $s_0=F[\mathrm{null}]$ | $\varnothing$ | 0 | 0 | 0 | 0 |
| $s_1=F[1]$ | $\{1\}$ | 1 | 0 | 0 | 0 |
| $s_2=F[2]$ | $\{2\}$ | 0 | 0 | 1 | 0 |
| $s_3=F[3]$ | $\{3\}$ | 0 | 1 | 0 | 0 |
| $s_{13}=F[1,3]$ | $\{1,3\}$ | 1 | 1 | 0 | 1 |

在这个明确的表上，$1,x,z,y,xy$ 是五态实函数空间的一组基，定理二是有限集合函数的 Möbius/混合差分分解。五个函数值仍是五个独立实参数；$xy$ 虽是两个指标的乘积，在线性意义上独立于 $1,x,y,z$。原文“不是第五个独立字段”只能按该模型的非原始联合模式理解，不能否定第五个线性基方向。线性观察空间 $\mathcal B=\operatorname{span}\{1,x,y,z\}$ 不是乘法闭合代数，因为 $x,y\in\mathcal B$ 而 $xy\notin\mathcal B$。“最小”也只能相对于所选五态窗口与观察合同，不能作为所有变化系统的普遍最小性结论。

**更正命题 Q7.a：切空间与环境核不同。** 以源次序 $(s_0,s_1,s_2,s_3,s_{13})$ 取 $\mathcal H=\mathbb R^5$、$d=(1,-1,0,-1,1)$，令 $P_3(p)=(X,Y,Z)$。在零总质量切空间 $\mathcal H_0=\{q:\sum q_i=0\}$ 中有

```math
\ker P_3\cap\mathcal H_0=\operatorname{span}\{d\}.
```

但在整个 $\mathbb R^5$ 中，$\ker P_3$ 是二维，包含质量方向 $e_0=(1,0,0,0,0)$。只有质量增广映射 $P_4(p)=(\sum p_i,X,Y,Z)$ 才在整个环境中满足 $\ker P_4=\operatorname{span}\{d\}$。概率单纯形上的固定三均值纤维属于总质量为一的仿射超平面，不能把其切方向直接冒称环境中三行映射的全部核。

固定 $X,Y,Z$ 后的实际可行律为

```math
p_\kappa=(1-X-Y-Z+\kappa,\ X-\kappa,\ Z,\ Y-\kappa,\ \kappa),
\qquad
\max(0,X+Y+Z-1)\le\kappa\le\min(X,Y).
```

非空性要求该区间确实非空；比较隐藏差异要求其中至少有两个不同点。$p_{\kappa=0}$ 作为仿射基点未必是概率律，单位方向 $d$ 也不要求对应两个相距一的合法概率律。

**适用命题 Q7.b：响应为线性对偶配对。** 已知同一读出 $f$ 与同一可见均值时，$\eta_{13}=d\cdot f$，并有

```math
E_{p_{\kappa'}}[f]-E_{p_\kappa}[f]
=(\kappa'-\kappa)\eta_{13}.
```

因此在非退化可行纤维上，已知的非零 $\eta_{13}$ 与精确期望值可恢复 $\kappa$。这是一条状态律与函数的线性对偶配对，没有指定辛形式、泊松括号或哈密顿结构，不能把“共轭坐标”理解为已取得规范辛共轭。单点纤维上 $\kappa$ 已被均值确定，即使响应为零也不影响唯一性。

同理，局部等待核必须是共同且已知的概率核，在符号测度环境中取

```math
\operatorname{Curv}_K=K_{s_0}-K_{s_1}-K_{s_3}+K_{s_{13}}.
```

它非零时需选一个已指定可测集合 $B$，使 $\operatorname{Curv}_K(B)\ne0$，用精确混合律的事件概率恢复 $\kappa$；不能直接用一个测度去“除以”另一测度。未来项 $dM_\omega g$ 还须给出同源的合法动作词、输出分支核、共同转移与测试函数；非负子核及每个动作的总核规范是概率解释的条件。任意实 $g$ 给期望探针，只有事件指标或 $[0,1]$ 值随机测试才直接给概率。

这些判据是概率律层面的识别，不是有限样本的精确历史重建。例如取 $X=Y=1/2,Z=0$，有 $0\le\kappa\le1/2$；读 $xy$ 的响应为一，但任意有限 $n$ 次独立同分布抽样全为零的概率 $(1-\kappa)^n$ 对所有 $0<\kappa<1/2$ 都为正。同一个有限记录不能精确确定连续参数，更不能恢复产生它的唯一完整历史。未知核、不同来源、未配对的边缘样本或未取得的完整期望也不能通过上述非零代数响应自动解决。

### Q8：近似稳定、维护与输出消除的边界（原第八、九、十节）

**适用命题 Q8。** $U_a(\Phi)\approx\Phi$ 须先指定状态/场空间、度量或范数、容差、尺度与所选操作族，例如规定 $\|U_a\Phi-\Phi\|\le\varepsilon$ 对哪些 $a$ 成立。单次近似不变不保证任意长复合仍在容差内，也不保证结构闭包或资源维持。仅选恒等动作会使任意模式精确稳定，因此“对某些动作稳定”不足以成为物理物质或生命的定义。

可维护性须在实际指定的控制模型中量化：初始 belief 非空并包含于安全域，动作对 belief 中所有可能状态共同合法，后继规则、观测、策略记忆、终止或死锁约定固定，能源、耗材、预算等资源纳入状态与合法动作菜单；若未来允许扰动，须对所有合法扰动与非空观测后继保持条件。单步可以留在 $K$ 不等于始终能留在 $K$：例如安全状态 $s_1$ 只有到 $s_2$ 的动作，而安全状态 $s_2$ 的唯一动作离开 $K=\{s_1,s_2\}$，初步安全仍无无限维护策略。稳定性与受控安全是模型性质，没有独立给出物理物质、衰变、辐射或生物生命的经验定义。

**更正命题 Q8.a：辐射分解取决于表示。** $\Phi_{\mathrm{remain}}+\Phi_{\mathrm{out}}$ 仅在线性表示与已指定残留/输出分解中解释，不能作为任意状态空间的固有加法。一般需给完整状态与环境的联合载体、输出映射和观察者实际可取得的记录。当前一个输出映射取零只说明该读口无响应，不自动说明所有过去记录、其他环境或全部合法未来读口皆无响应。

**反例 Q8.b：最终边际相同，过去输出不同。** 令过程先输出初始比特 $b\in\{0,1\}$，再把系统重置到同一状态 $s_0$。最终系统状态对两种初态完全相同，保留的输出却分别是 $0$ 和 $1$。最终状态边际的差被压到零，过去输出或环境记录仍可携带差异。原文的信息消除与辐射解释只能相对于明确的状态载体和记录范围表态；吸收或局部零读出并不认证宇宙全局信息已保存或已消灭。

### Q9：本体主张与仪器分辨深度（原第七、八、十节及最终结论）

**限定命题 Q9。** 原文关于没有独立时间、空间、物质、辐射与生命实体的最终表述，是所提出的关系本体解释；交换群势定理、五态函数分解和非零线性响应都没有推出这些实体在现实中不存在。将若干结构打包在一个关系场中，也不证明等待律、动力学和读口可从差分唯一导出。数学可表示性、操作合法性、可取得性、形式证明及物理/生物实现须分别保留其条件。

最小分辨深度只相对于选定的合法操作、仪器、末端测试与完整概率律定义。同一隐藏参数可以被一个直接联合读口立即看见，也可以在另一仪器中先执行若干无响应动作才读取，或始终不可见；深度随合同改变。一个过程还可先暴露差异、再重置系统，使较晚的终态读口重新看不见。若确实保留共同模型中的全部嵌套前缀记录，较长完整记录仍包含较短记录；这种可区分关系是记录保留条件下的信息序，不是单调物理时间方向。原文将操作次序、可达几何或稳定模式称作时间、空间或生命，均保留为开放模型解释，本文不据此认证新物理或生物理论。
