
# Relational quantum automaton as a fixed-point closure

## Status

This document specifies the missing closure layer between the six-rule visual auditor and the conditional quantum representation theorem. It is a mathematical interface and implementation target. It does not claim that the full construction is already proved in Lean.

The current visualizer exposes a finite audit vector for one record:

\[
\operatorname{Audit}(\sigma)\in\{\mathrm{WAIT},\mathrm{PASS},\mathrm{FAIL}\}^{6}.
\]

That vector is evidence, but it is not yet a closure theorem. The closure theorem must quantify over sets of records, generated gates, effects, successor branches, and independent composites.

## 1. Records, rules, and admissibility

Let \(\mathsf{Rec}\) be the type of finite relational records. A record contains:

\[
r=(n,\phi,a,b,\mathcal E,K),
\]

where \(n\) is the closure order, \(\phi\) the relative phase, \(a,b\in\mathbb C\) the active amplitudes, \(\mathcal E\) a finite relation-edge set, and \(K\) the tested positive kernel.

Let \(\mathsf{Adm}(r)\) mean that the record satisfies the declared finite contract:

- normalization and nonnegative readout;
- positive semidefinite tested Gram tables;
- orientation and phase compatibility;
- zero Schur residual when the record claims to be carrier-complete;
- successor-kernel consistency for declared continuations;
- product-kernel consistency for declared independent ports.

The six rules are represented by rule transformers \(F_i\). Each transformer has

\[
F_i:\mathcal P(\mathsf{Rec})\to\mathcal P(\mathsf{Rec}),
\]

and adds all records generated by \(R_i\) from the current family.

For \(S\subseteq\mathsf{Rec}\), define

\[
\Phi_i(S)=S\cup
\{r'\mid
\exists r\in S,\;
\operatorname{Prem}_i(r),\;
\operatorname{Next}_i(r,r'),\;
\mathsf{Adm}(r')
\}.
\]

The combined one-step operator is

\[
\Phi(S)=\bigcup_{i=0}^{5}\Phi_i(S).
\]

The essential property is monotonicity:

\[
S\subseteq T\Longrightarrow\Phi(S)\subseteq\Phi(T).
\]

This lets the automaton grow without invalidating previously generated records.

## 2. The closure operator

A family \(T\) is \(R\)-closed when it contains every record generated by every rule:

\[
\operatorname{Closed}_R(T)
\;:\Longleftrightarrow\;
\bigwedge_{i=0}^{5}\Phi_i(T)\subseteq T.
\]

The closure of a seed family \(S\) is the least closed family containing it:

\[
\operatorname{Cl}_R(S)
=
\bigcap
\left\{
T\subseteq\mathsf{Rec}
\mid
S\subseteq T
\land
\operatorname{Closed}_R(T)
\right\}.
\]

On a finite carrier it can be computed by iteration:

\[
S_0=S,\qquad S_{k+1}=\Phi(S_k),
\]

stopping at the first \(N\) with \(S_{N+1}=S_N\). On an infinite carrier the intersection definition is primary; iteration may require a directed or transfinite limit.

The required closure laws are:

\[
\begin{aligned}
&\textbf{Extensive:} &&S\subseteq\operatorname{Cl}_R(S),\\
&\textbf{Monotone:} &&S\subseteq T\Rightarrow
\operatorname{Cl}_R(S)\subseteq\operatorname{Cl}_R(T),\\
&\textbf{Idempotent:} &&
\operatorname{Cl}_R(\operatorname{Cl}_R(S))
=
\operatorname{Cl}_R(S).
\end{aligned}
\]

Closed relational worlds are exactly the fixed points:

\[
\operatorname{Closed}_R(T)
\Longleftrightarrow
\operatorname{Cl}_R(T)=T.
\]

The repository already contains the canonical machinery needed here:

- D5/S3/ConceptDynamics/Closure/DefinitionClosureOperator.lean bundles a semantic closure as Mathlib's ClosureOperator;
- D5/S0/Diagonal/Lawvere/TheoryIsConsequenceFixedPoint.lean proves the fixed-point characterization, least fixed point above generators, complete lattice of closed theories, and closure under intersections.

The relational automaton should reuse these interfaces rather than introduce a second closure notion.

## 3. Rules generate the quantum interface

The six rules form a dependency cycle.

### R0: identity and normalization

The seed contains \(\Omega\). Every generated record must preserve

\[
\|\psi\|^2=|a|^2+|b|^2=1.
\]

### R1: binary distinction

R1 introduces the first nontrivial split:

\[
p(0)=p(1)=\frac12.
\]

The split creates the two labels whose relation is promoted by R2.

### R2: oriented ternary closure

R2 promotes the relation between the two branches into a tested three-history record:

\[
|\mathcal E|\geq3,\qquad \phi\in\mathbb R,
\]

together with the signed orientation term. A phase coordinate without a loop test is only a coordinate. Nontrivial holonomy requires an additional closed-loop witness.

### R3: successor consistency

For equal current records \(u,v\), all later tests must agree on the successor kernel:

\[
\langle\Phi_e(u),\Phi_e(v)\rangle
=
\langle u,E_ev\rangle.
\]

The current visualizer uses

\[
|\mathcal E|=6,\qquad \|\psi\|^2=1
\]

as a finite network proxy. This is useful evidence, but does not establish universal successor-kernel equality.

### R4: complete positive readout

R4 requires

\[
p_e(\rho)=\operatorname{Tr}(E_e\rho),
\qquad
0\preceq E_e\preceq I.
\]

The finite check is

\[
p_0=|a|^2,\qquad p_1=|b|^2,\qquad p_0+p_1=1.
\]

A complete theorem must quantify over the effect menu and prove compatibility with balanced re-encoding and refinement.

### R5: independent-history composition

R5 generates joint records from independent ports:

\[
K_{AB}((a,b),(a',b'))
=
K_A(a,a')K_B(b,b').
\]

The finite visual check uses a six-edge joint record as a proxy. Universal composition requires joint effects and must rule out marginal-only observation.

## 4. Gates are closed endomorphisms

For a closed family \(S\), a legal gate is a partial map

\[
g:S\rightharpoonup S
\]

such that

\[
K(gx,gy)=K(x,y)
\]

and \(g\) preserves all previously passed audit rules. A reversible gate also has a legal inverse. After the positive Gram quotient, such closed endomorphisms become unitary operators:

\[
\text{closed relation rewrite}
\Longrightarrow
\text{isometry of the positive quotient}
\Longrightarrow
\text{unitary gate}.
\]

## 5. Counterexamples return to the closure operator

For each rule \(R_i\), define a witness type consisting of a finite extension \(w\) with

\[
\operatorname{Prem}_i(r)\land\neg\operatorname{Adm}_i(w).
\]

The basic soundness obligation is

\[
\mathsf{Witness}_i(r)
\Longrightarrow
r\notin\operatorname{Cl}_R(S),
\]

unless the carrier is explicitly enlarged.

For a declared finite contract, the target completeness statement is

\[
r\notin\operatorname{Cl}_R(S)
\Longrightarrow
\exists i,w\;\mathsf{Witness}_i(w).
\]

The visualizer's counterexample button is therefore a test of interface sensitivity. The next experiment should generate actual failed records:

- norm-breaking successor;
- unequal binary branch weights;
- erased triangle phase;
- successor kernels disagreeing on a shared prefix;
- negative or nonquadratic readout;
- joint records with equal marginals but changed cross-correlation.

Reuse the existing ClosureOperator API. The minimum declarations are:

    structure RelRecord where
      order : Nat
      phase : ℝ
      amp0 : ℂ
      amp1 : ℂ
      edges : Finset Edge
      kernel : KernelData

    inductive Rule
      | identityNorm
      | binarySplit
      | orientedTernary
      | successor
      | positiveReadout
      | independentComposition

    def RelationalClosure :
        ClosureOperator (Set RelRecord) := ...

    theorem closure_extensive (S : Set RelRecord) :
        S ⊆ RelationalClosure S := ...

    theorem closure_mono {S T : Set RelRecord} :
        S ⊆ T → RelationalClosure S ⊆ RelationalClosure T := ...

    theorem closure_idempotent (S : Set RelRecord) :
        RelationalClosure (RelationalClosure S) =
          RelationalClosure S := ...

    theorem closed_iff_fixed (S : Set RelRecord) :
        IsClosed S ↔ RelationalClosure S = S := ...

    theorem closure_least_closed_above
        (S T : Set RelRecord)
        (hS : S ⊆ T)
        (hT : IsClosed T) :
        RelationalClosure S ⊆ T := ...

The first milestone is structural and need not prove the full quantum representation. After that add rule soundness and counterexample soundness. A suitable path is:

    D5/S3/Quantum/Automaton/RelationalAutomatonClosure.lean

with separate files for rule semantics and counterexample witnesses if needed.

## 7. Experiment and visualization target

The finite experiment should emit a closure trace in addition to one final result:

    {
      "seed": ["identity"],
      "rounds": [
        {
          "round": 0,
          "records": 1,
          "passed": ["R0"],
          "waiting": ["R1", "R2", "R3", "R4", "R5"]
        }
      ],
      "fixed_point": false
    }

The final output should report fixed_point=true when no rule adds a new admissible record, fixed_point=false when the finite horizon ends before closure, or counterexample when a rule produces a witness violating admissibility.

The visualization should display

\[
S_0\subseteq S_1\subseteq S_2\subseteq\cdots
\]

and stop when \(S_{k+1}=S_k\). An animation shows a trajectory. A closure view shows the generated family and its fixed point.

## 8. Closure criterion

The relational quantum automaton is closed only when:

1. every generated state remains in the admissible positive-kernel family;
2. every legal gate is a relation-preserving endomorphism;
3. every declared reversible gate has a legal inverse;
4. every readout descends to a positive effect;
5. every successor branch has a common continuation kernel;
6. every independent product has a joint kernel and joint effects;
7. every finite failure has a named witness or triggers explicit carrier enlargement;
8. the generated family is a fixed point of the rule closure operator.

In one line:

\[
\boxed{
\operatorname{Cl}_R(S)=S
\land
\operatorname{Gate}(S)\subseteq\operatorname{End}_{K}(S)
\land
\operatorname{Readout}(S)\subseteq\operatorname{Eff}_{+}(S)
\land
\operatorname{Compose}(S)\subseteq S
}
\]

Only after this fixed-point condition is established can the representation theorem be called a closed quantum automaton. Before that point the object is a finite relational trace with partially verified rules.
