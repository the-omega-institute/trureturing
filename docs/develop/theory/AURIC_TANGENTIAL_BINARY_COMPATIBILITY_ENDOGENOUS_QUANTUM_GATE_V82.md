# 2 单点切向为什么不足以锁住量子门

在有限复 Hilbert 空间 H 中，内积对第二变量线性。令 ψ 为单位向量，ξ 与 ψ 复正交。

**引理 2.1 任意单点水平切向都可以由某个自伴算符实现。**

定义

```math
H_\psi=i\hbar\bigl(|\xi\rangle\langle\psi|-|\psi\rangle\langle\xi|\bigr).
```

则

```math
H_\psi^*=H_\psi,\qquad
-\frac{i}{\hbar}H_\psi\psi=\xi.
```

\*\*证明。\*\*括号中的算符反自伴；作用于 ψ 时，第二项因正交为零，第一项给 ξ。证毕。

一般单位球切向可写成

```math
v=\xi+i\beta\psi,\qquad \langle\psi,\xi\rangle=0,\quad \beta\in\mathbb R.
```

此时所有实现该切向的自伴算符都可写为

```math
H=i\hbar\bigl(|\xi\rangle\langle\psi|-|\psi\rangle\langle\xi|\bigr)
-\hbar\beta|\psi\rangle\langle\psi|+B,
\qquad B=B^*,\quad B\psi=0.
```

因此单点切向留下了 ψ 的正交补上的任意自伴作用。更重要的是，即使一个实际场是非线性的，也可能在每个点分别配出不同的 Hψ。

\*\*白话图景。\*\*只看一个点朝哪里走，几乎总能给它配出一个转动。要证明它是一扇共同的量子门，必须比较两个内容的箭头能否同时来自同一个作用。新条件因此落在二元关系上。

# 3 v82 切向二元相容候选

共同复正核、相干比较及复方向 J=i 沿用此前已供应的接口。有限维限制作用于当前截口，不把整个 Ω 限定为有限对象。

定义

```math
g(x,y)=\operatorname{Re}\langle x,y\rangle,\qquad
S(H)=\{x\in H:\|x\|=1\}.
```

给实际场 v(H)→H，此时不假定它连续、可加、齐次或线性。

**定义约束 T 切向保强度。**

```math
v(x)\in T_xS(H)
\quad\Longleftrightarrow\quad
g(x,v(x))=0.
```

这恰好说明原强度的一阶变化为零。它是“强度球面切向量”的定义内容。

\*\*定义约束 J 有限共同复方向。\*\*选复正交单位基 a₁,…,a_d，要求

```math
v(ia_j)=iv(a_j),\qquad j=1,\ldots,d.
```

所有比较使用同一内部相干参考。x 与 −x 在证明中是相对于该参考的反向幅度；这不把整体的不可读全局相位当作一个外部可观察量。

**定义 3.1 二元分离率。**

```math
\Gamma_v(x,y)=2g(x-y,v(x)-v(y)).
```

它等于两条起始切向历史的弦差平方的一阶变化率：

```math
\Gamma_v(x,y)=
\left.\frac{d}{d\varepsilon}\right|_{\varepsilon=0}
\bigl\|x+\varepsilon v(x)-y-\varepsilon v(y)\bigr\|^2.
```

这里写直线只为计算一阶项；任何具有这些切向的球面曲线给出同一个导数。

**唯一新增候选 D 切向二元相容。**

```math
\boxed{\Gamma_v(x,y)\le0\qquad(x,y\in S(H)).}
```

这个条件作用于同一完整门推进的两个内容，不作用于已选择某结果并重新归一化的后选择支路。

\*\*白话图景。\*\*每个内容先沿着自己的强度球面走。同一个小门同时推动两个内容时，不能凭空让它们的一阶相干差别变大。总量由切向定义保住，共同方向由内部参考固定。

# 4 反推删除条件的后果

## 缺少二元约束会出现相容失败

在 H=ℂ² 上取

```math
v(z_1,z_2)=(0,i|z_1|^2z_2).
```

它光滑、处处切向，并满足全局相位协变，因而通过有限 J 校准。其实际流为

```math
(z_1,z_2)\longmapsto(z_1,e^{it|z_1|^2}z_2).
```

取两个单位内容

```math
x=\frac{e_1+e_2}{\sqrt2},\qquad y=-ie_2.
```

则

```math
v(x)=\frac{i}{2\sqrt2}e_2,\qquad v(y)=0,
\qquad
\Gamma_v(x,y)=\frac1{\sqrt2}>0.
```

也可以直接展开完整距离：

```math
\|x(t)-y(t)\|^2=2+\sqrt2\sin(t/2).
```

每个点都沿球面运动，但同一个协议对两端施加了不同的强度依赖扭转。失败的两个元已经明确。

## 缺少切向保强度会允许整体流失

取 v(x)=−x，仍满足 J，且

```math
\Gamma_v(x,y)=-2\|x-y\|^2\le0.
```

但 g(x,v(x))=−1，内容沿径向缩小。因此单侧不分离本身允许耗散；完整强度球面的定义有不可省略的内容。

## 缺少共同复方向会破坏虚比较

在 ℂ² 上取

```math
v(z_1,z_2)=(\bar z_2,-\bar z_1).
```

它实线性反对称，因此切向且 Γ 恒为零，却满足 v(iz)=−iv(z)。

对 x=e₁、y=ie₂，

```math
\langle v(x),y\rangle+\langle x,v(y)\rangle=-2i.
```

实差分保持，复比较的虚部已经改变。

上述反例都是满足其余条件的自洽数学模型。它们说明删除哪一条会容许哪一种变化，而不是从纯逻辑证明这些变化不可能存在。候选 D 将相干差分的一阶放大排除在完整相干门定义之外。

\*\*白话图景。\*\*单看每个点不掉出球面，仍容许不同点各自扭转；只要求两点不分离，又容许所有内容一起缩小；保住实距离，还可能翻掉共同复方向。每一个条件都排除一类可以直接写出的失败。

# 5 主定理从单侧切向条件推出共同生成元

\*\*定理 5.1 切向二元刚性。\*\*实际场 v 满足 T、D、J，当且仅当存在唯一复线性算符 K，使

```math
\boxed{v(x)=Kx\quad(x\in S(H)),\qquad K^*=-K.}
```

此时全部二元分离率自动等于零。无需先假定实际场连续、线性或具有反向流。

\*\*证明第一步 展开二元条件。\*\*两端切向给

```math
\frac12\Gamma_v(x,y)
=-g(x,v(y))-g(y,v(x)).
```

所以令

```math
B_v(x,y)=g(x,v(y))+g(y,v(x)),
```

则 D 等价于 Bv(x,y)≥0。

\*\*第二步 相干反向点迫使奇性。\*\*分别使用 y 与 −y，再相加：

```math
g(x,v(y)+v(-y))\ge0
\qquad\text{对所有单位 }x.
```

单位球同时包含 x 与 −x，故左边只能恒为零；实配对非退化给

```math
v(-y)=-v(y).
```

这里没有使用时间反转，只使用同一相干接口中的反向幅度。

\*\*第三步 单侧条件被夹成等式。\*\*将奇性代回 Bv(x,−y)≥0 得 −Bv(x,y)≥0，因此

```math
\boxed{g(x,v(y))+g(y,v(x))=0.}
```

\*\*第四步 全部实际坐标被确定。\*\*取实正交单位基

```math
b_1,\ldots,b_{2d}=a_1,ia_1,\ldots,a_d,ia_d.
```

对所有单位 x，

```math
g(b_j,v(x))=-g(x,v(b_j)).
```

定义实线性算符

```math
Kx=-\sum_{j=1}^{2d}g(x,v(b_j))\,b_j.
```

这给出 v(x) 的全部实坐标，所以实际 v 在整个单位球上等于 Kx。切向条件给 g(x,Kx)=0，实齐次延拓和极化进而给

```math
g(x,Ky)+g(y,Kx)=0
\qquad(x,y\in H).
```

因此 K 实反对称。

\*\*第五步 有限 J 校准给复线性。\*\*基上的 K(ia_j)=iK(a_j)，连同实线性，给 KJ=JK。故 K 复线性。将实反对称关系再用于 ix、y，可以恢复虚部，得到

```math
\langle Kx,y\rangle+\langle x,Ky\rangle=0.
```

因此 K\*=−K。基上的实际速度给唯一性。反向直接将任意复反自伴 K 代入 T、D、J，Γ 等于零。证毕。

\*\*白话图景。\*\*先要求两点不被同一个小门拉开，再把其中一点换成共同参考下的反向幅度，原来的单侧条件就只能取等号。所有箭头的实坐标随之被同一套比较锁住，内部四分之一周方向再锁成复线性。整个场必然是一场共同转动。

# 6 有限有符号锚已经足够

\*\*定理 6.1 有限比较锚。\*\*保留 T 和 J，仅要求

```math
\Gamma_v(x,b_j)\le0,\qquad
\Gamma_v(x,-b_j)\le0,
\qquad j=1,\ldots,2d,
```

对全部单位 x 成立，也能得到定理 5.1。

\*\*证明。\*\*将相反锚的两个不等式相加，得到

```math
g(x,v(b_j)+v(-b_j))\ge0
```

对全部单位 x 成立，故锚速度反向。再夹逼得到

```math
g(b_j,v(x))=-g(x,v(b_j)).
```

这些式子直接确定全部实坐标，完成主定理的第四步；随后用有限 J 完成第五步。证毕。

有限的是 4d 个有符号锚。输入槽 x 仍为整个声明域，不能把它改写成有限次采样已经认证任意未知场。

\*\*推论 6.2 全幅度版本。\*\*若把定义域取为整个 H，要求同样的 T、D、J，则同一结论成立；v(0)=0 由奇性推出，无须另设。反向相容还可直接对非退化配对证明可加性和实齐次性。

\*\*白话图景。\*\*并不需要预先比较所有点对。把每个内容与一套覆盖实方向及其反向的共同锚比较，就能锁住所有箭头坐标。但这些锚必须真正约束全部输入，不能只抽查几个样本。

# 7 切向场积分成有限门

\*\*定理 7.1 自主门的积分。\*\*若同一内部续接规则的实际场满足主定理，则

```math
\dot x=v(x)=Kx,\qquad
x(t)=e^{tK}x(0).
```

因为 K\*=−K，完整传播 U(t)=e^{tK} 为酉。定义

```math
H=i\hbar K,
```

得到 H\*=H 及

```math
\boxed{i\hbar\dot x=Hx.}
```

\*\*证明。\*\*有限维矩阵指数是线性初值方程的唯一解；直接微分 U(t)\*U(t) 得零，初值为 I。代入 H 的定义得到薛定谔方程。证毕。

\*\*定理 7.2 随内部时刻变化的场。\*\*若每个时刻的实际 v_t 都满足同一候选，且有限锚速度随 t 连续，则

```math
v_t(x)=K(t)x,\qquad K(t)^*=-K(t)
```

且 K(t) 连续。有限维线性方程有唯一传播子

```math
\partial_tU(t,s)=K(t)U(t,s),\qquad U(s,s)=I.
```

它满足

```math
U(t,s)^*U(t,s)=I,\qquad
U(t,s)U(s,r)=U(t,r).
```

\*\*证明。\*\*主定理的实坐标公式将 K(t) 的全部矩阵元写为锚速度的固定配对，所以连续。微分 U\*U 得零；初值唯一性给接续律。证毕。

这里 t 是对内部历史推进的参数标定；该参数的物理单位以及 ℏ 的经验单位值由内部时钟和读出校准供应。一般时变门不自动成为自主群。

\*\*推论 7.3 接回 v81。\*\*对任意传播 U(t,s) 和全幅度 x,y,c，

```math
\|U(t,s)(x+c)-U(t,s)(y+c)\|^2

```

因此 v81 的共享相容成为结论。反向，v81 给出的同维完整门若组成可微酉族，其实际瞬时场满足 v82。v81 的跨维等距还需完整内部酉扩张，本轮的直接生成元定理针对固定完整载体。

# 8 同一个切向不能唯一决定完整门与曲率

\*\*命题 8.1 单点求值的自由度。\*\*固定单位 ψ，对复反自伴 K 的求值 K↦Kψ 的核，是在 ψ 的正交补上任意作用、并消去 ψ 的反自伴算符。其真实参数维数为 (d−1)²。

\*\*证明。\*\*Kψ=0 与反自伴性共同保证 ψ 的正交补不变；限制在该补空间上的任意反自伴算符又可延拓为这样的 K。该补空间复维数 d−1，其反自伴矩阵实维数为 (d−1)²。证毕。

\*\*命题 8.2 同一初始箭头允许不同曲率。\*\*令 ψ,u 正交归一，ν>0，定义

```math
H_0=i\hbar\nu
\bigl(|u\rangle\langle\psi|-|\psi\rangle\langle u|\bigr),
\qquad
H_\kappa=H_0+\hbar\kappa|u\rangle\langle u|.
```

则二者在 ψ 上的初始切向相同：

```math
-\frac{i}{\hbar}H_0\psi
=-\frac{i}{\hbar}H_\kappa\psi=\nu u.
```

但二阶变化为

```math
-\frac{H_0^2}{\hbar^2}\psi=-\nu^2\psi,\qquad
-\frac{H_\kappa^2}{\hbar^2}\psi=-\nu^2\psi-i\nu\kappa u.
```

\*\*证明。\*\*Hκψ=iℏνu，Hκu=−iℏνψ+ℏκu，连续作用一次即得。证毕。

在基 (ψ,u) 的 Bloch 球中，

```math
H_\kappa=\frac{\hbar\kappa}{2}I+
\frac{\hbar}{2}(0,2\nu,-\kappa)\cdot\boldsymbol\sigma.
```

初始球点为 (0,0,1)，两者的初始速度均为 (2ν,0,0)，但加速度为

```math
\ddot{\mathbf r}(0)=(0,-2\kappa\nu,-4\nu^2).
```

因此切线并不指定随后怎样弯曲。

有限端点门也不唯一决定历史。对投影 P 和 T>0，

```math
e^{-iT(0)/\hbar}=I,\qquad
e^{-iT(2\pi\hbar P/T)/\hbar}=I.
```

中间的切向历史却不同。

\*\*白话图景。\*\*当前箭头只说明眼前的一步。正交方向上还藏着怎样作用，会影响下一步怎样转弯。绕过一圈再回到同一个门，也不会使中间路线自动变成没有发生。

# 9 二元关系所属的更大几何结构

主定理所得生成元满足

```math
K^*=-K,\qquad KJ=JK.
```

它们构成酉群 U(d) 的李代数。对实系数 α,β，αK+βL 仍反自伴；交换子也满足

```math
[K,L]^*=-[K,L].
```

这是代数上的闭合；实际菜单是否供应对应控制，还须沿用项目的操作条件。

有限门的小回路显示顺序关系：

```math
e^{\varepsilon K}e^{\varepsilon L}
e^{-\varepsilon K}e^{-\varepsilon L}
=
I+\varepsilon^2[K,L]+O(\varepsilon^3).
```

\*\*证明。\*\*将四个矩阵指数展开到二阶，一阶项相消，二阶剩余 KL−LK。证毕。

共同复结构还同时给出实度量与反对称比较：

```math
g(u,v)=\operatorname{Re}\langle u,v\rangle,\qquad
\omega_0(u,v)=\operatorname{Im}\langle u,v\rangle=g(Ju,v).
```

酉流保留两者。商去不可读的整体相位以后，纯态射线空间具有相容的度量、复结构与辛结构；保度量的场称为 Killing 场。v82 将这个几何结构的入口供应为尚未预设光滑或线性的实际场上的二元条件。

# 10 当前态和切向的三维提升

设完整演化为

```math
\dot\psi=-\frac{i}{\hbar}H\psi,\qquad H=H^*,\quad \|\psi\|=1.
```

记 h=⟨ψ,Hψ⟩。去掉沿原射线的相位分量，得到水平切向

```math
\boxed{\xi=-\frac{i}{\hbar}(H-hI)\psi,\qquad
\langle\psi,\xi\rangle=0.}
```

**定理 10.1 方差给射线速度。**

```math
\boxed{\|\xi\|^2=\frac{\langle H^2\rangle-h^2}{\hbar^2}
=\frac{(\Delta H)^2}{\hbar^2}.}
```

\*\*证明。\*\*展开 (H−hI)² 的期望即得。证毕。

采用

```math
ds_{\mathrm{FS}}^2
=\langle d\psi,d\psi\rangle-|\langle\psi,d\psi\rangle|^2,
\qquad
d_{\mathrm{FS}}([\psi],[\phi])
=\arccos|\langle\psi,\phi\rangle|,
```

故 FS 速度为 ΔH/ℏ。单位 Bloch 球的速度是这一速度的两倍。这里的尺度约定已经固定，不能与含 2ℏ 因子的另一度量混用。

\*\*定理 10.2 即时二能级截面。\*\*若 ξ≠0，当前态和切向落在复二维空间 span{ψ,ξ} 中。取与 ψ 正交的单位 u，若 ξ=zu，则在基 (ψ,u) 下

```math
\dot\rho=|\xi\rangle\langle\psi|+|\psi\rangle\langle\xi|
=
\begin{pmatrix}0&\bar z\\z&0\end{pmatrix},
```

因此

```math
\mathbf r(0)=(0,0,1),\qquad
\boxed{\dot{\mathbf r}(0)=(2\operatorname{Re}z,2\operatorname{Im}z,0).}
```

这是当前一阶信息的完整三维提升，不保证以后一直留在同一二维载体。

\*\*命题 10.3 该切向的规范圆实现。\*\*令 ν=‖ξ‖>0、u=ξ/ν，取

```math
K_{\min}=|\xi\rangle\langle\psi|-|\psi\rangle\langle\xi|.
```

则

```math
e^{tK_{\min}}\psi
=\cos(\nu t)\psi+\sin(\nu t)u.
```

\*\*证明。\*\*Kminψ=νu，Kminu=−νψ，且在二者正交补上为零；指数级数直接给该式。它水平且在局部最短区间内是 FS 测地线。证毕。

```math
\|K\|_{\mathrm{HS}}^2
=2\|\xi\|^2+\|C\|_{\mathrm{HS}}^2.
```

所以 Kmin 是这一指定矩阵范数下唯一的最小实现。这个优化定义给规范圆，并没有证明自然的实际 Hamiltonian 必须选择该最小值；第 8 节已经给不同曲率反例。此处最小的是指定的 Hilbert–Schmidt 范数，并非未经定义的最短时间或最低实验能耗。若 ξ=0，规范生成元为零，规范曲线就是常值。

\*\*白话图景。\*\*当前内容加上眼前的变化方向，只需两个相干方向就能看清；归一以后是球上的一点和切箭头。把当前看不见的额外动作都取零，就有一条规范大圆。实际历史是否沿它走，还由整个门决定。

# 11 两个门的切向关系给出不确定性

设 A,B 为自伴读口，ψ 归一。记

```math
a=\langle\psi,A\psi\rangle,\qquad
b=\langle\psi,B\psi\rangle,\qquad
u=(A-aI)\psi,\quad w=(B-bI)\psi.
```

它们与对应门的水平切向只差 −i/ℏ 及各自的参数标定。

**定理 11.1 切向 Gram 相容。**

```math
\boxed{
(\Delta A)^2(\Delta B)^2
\ge
\operatorname{Cov}(A,B)^2+
\frac14|\langle[A,B]\rangle|^2.
}
```

其中协方差为中心化反交换子的期望之一半。

\*\*证明。\*\*二元 Gram 正性给

```math
\|u\|^2\|w\|^2\ge|\langle u,w\rangle|^2.
```

又

```math
\|u\|^2=(\Delta A)^2,\quad
\|w\|^2=(\Delta B)^2,
```

```math
\operatorname{Re}\langle u,w\rangle
=\frac12\langle AB+BA\rangle-ab,
\qquad
\operatorname{Im}\langle u,w\rangle
=\frac{\langle[A,B]\rangle}{2i}.
```

取复数模平方即得。证毕。

## 量纲一致的三维提升

A 与 B 可能具有不同单位。先用内部声明的正尺度 a₀,b₀ 无量纲化：

```math
\widetilde u=\frac{u}{a_0},\qquad
\widetilde w=\frac{w}{b_0},\qquad
U=\|\widetilde u\|^2,\quad W=\|\widetilde w\|^2,\quad
z=\langle\widetilde u,\widetilde w\rangle,\quad s=U+W.
```

当 s>0，定义

```math
\boxed{
\mathbf r=
\left(
\frac{2\operatorname{Re}z}{s},
\frac{2\operatorname{Im}z}{s},
\frac{U-W}{s}
\right).
}
```

则

```math
1-\|\mathbf r\|^2=\frac{4(UW-|z|^2)}{s^2}\ge0.
```

乘回单位尺度，恰好恢复上述不确定性不等式。球坐标依赖内部标定，物理不等式不依赖标度选择。若 s=0，两切向都为零，不定义归一球点。

这个标准不确定性关系允许某个读口在其本征态上具有零方差；它约束两个读口的联合切向关系，不推出“每一种量在每个态上都必须测不准”。

\*\*白话图景。\*\*两个读口在当前内容上各有一个变化方向。方向的长度、夹角和相位，必须能组成同一个正的二元关系。归一后三维球容不下的组合，就是不确定性所排除的组合；不需要另加一条禁止精确值的规则。

# 12 门与测量在完整内部过程中的统一

\*\*定义 12.1 带结果续接。\*\*一次测量记录由实际分支及其后继共同组成。酉门 U 是一个结果的仪器：


结果概率恒为一，但不同 U 具有不同后继。把所有门纳入广义测量定义时，必须保留后继内容；一个恒等效果不能替代整个门。

\*\*定理 12.2 有限仪器的完整门实现。\*\*给有限分支

```math

```

令 W 为输出直和，Vx=⊕eMex，则 V 是等距。它有一个固定完整内部载体上的酉扩张，并能由反自伴生成元的平滑门流到达。

\*\*证明。\*\*完整载体可取

```math
\mathcal K=H\oplus W.
```

从准备子空间 (x,0) 到输出子空间 (0,Vx) 的映射保内积。两子空间维数相同，正交补维数也相同；补齐正交基映射，得到完整酉 U。


取 K=i∑rθrPr，则 K\*=−K，U=eᴷ。路径 exp(tK) 满足 v82。证毕。

```math
X(M_{e\alpha}^*\otimes I)\ge0.
```

因此得到完全正仪器。不同结果输出空间可不相同，此时保留结果标签的直和是完整通道；同一可见输出空间上才可直接把结果映射求和。

# 13 条件测量的切向为什么可以不同

令 A≥0，对 τ≥0 定义成功滤波

```math
M_\tau=e^{-\tau A/2},\qquad
p_\tau=\langle\psi,e^{-\tau A}\psi\rangle,\qquad
\psi_\tau=\frac{M_\tau\psi}{\sqrt{p_\tau}}.
```

**定理 13.1 成功条件下的切向。**

```math
\boxed{
\left.\frac{d\psi_\tau}{d\tau}\right|_{0^+}
=-\frac12(A-\langle A\rangle)\psi.
}
```

\*\*证明。\*\*M′₀=−A/2，p′₀=−⟨A⟩，对商式微分即得。该向量与 ψ 复正交，所以确为水平切向。证毕。

在本稿 FS 度量下，

```math
\operatorname{grad}\langle A\rangle
=2(A-\langle A\rangle)\psi,
```

因此条件化切向是 −1/4 倍的梯度。相应相位门的水平切向则为 −i(A−⟨A⟩)ψ/ℏ；两者使用同一个中心化方向，却具有不同的完整过程含义。

\*\*明确二元见证。\*\*取

```math
A=|1\rangle\langle1|,\qquad
x=|1\rangle,\qquad y=\frac{|0\rangle+|1\rangle}{\sqrt2}.
```

对上述条件场 η，

```math
\eta(x)=0,\qquad
\eta(y)=\frac{|0\rangle-|1\rangle}{4\sqrt2},
```

所以

```math
\Gamma_\eta(x,y)=\frac{\sqrt2}{4}>0.
```

这没有违背完整理论：已选择成功结果，又除以依输入而变的成功概率，故 η 不是本候选所约束的完整门场。完整过程还包括失败分支

```math
N_\tau=\sqrt{I-e^{-\tau A}}.
```

在非零谱方向上 Nτ 从 √τ 级别出现；它在 τ=0 不具有普通有限导数。这个事实将在下一节与平滑门的零支路定理吻合。

\*\*白话图景。\*\*看全部记录，测量属于整体的共同门。只留下成功的一条路，再把它重新放大到单位强度，就会看到内容聚拢或分开。条件结果的切向和完整内容的切向都在 Ω 内，但它们承担不同的比较条件。

# 14 平滑零支路的概率必从二阶开始

\*\*定理 14.1 零支路二次律。\*\*设完整幅度族 V(t) 在零点可微，固定结果读口给 Me(t)=PeV(t)，且 Me(0)=0。对固定单位输入 ψ，

```math
p_e(t\mid\psi)
=t^2\|\dot M_e(0)\psi\|^2+o(t^2),

```

\*\*证明。\*\*可微性给

## 一个完整的精确模型

取 A=A\*，内部记录为两态系统。令

```math
U_\varepsilon=e^{-i\varepsilon A\otimes\sigma_y}.
```

由 σy²=I 及 σy|0⟩=i|1⟩，

```math
U_\varepsilon(\psi\otimes|0\rangle)
=
\cos(\varepsilon A)\psi\otimes|0\rangle+
\sin(\varepsilon A)\psi\otimes|1\rangle.
```

完整切向为 Aψ⊗|1⟩，而新记录概率为

```math
\boxed{
p_1(\varepsilon)=\varepsilon^2\langle A^2\rangle+O(\varepsilon^4).
}
```

取 A=(π/2)P，其中 P 为投影，在 ε=1 得到

```math
\cos A=I-P,\qquad \sin A=P,
```

```math
\psi\longmapsto
(I-P)\psi\otimes|0\rangle+P\psi\otimes|1\rangle.
```

这就是完整投影测量。新结果的条件态在 ε→0⁺ 时可趋向 Aψ/‖Aψ‖，未必趋向原态，因为该结果概率同时趋于零；零概率点不指定归一条件态。

## 同一事实的通道版本

\*\*定理 14.2 固定有限记录的一阶约化变化。\*\*设内部记录准备固定为 |0⟩，完整 U(t) 为 C¹ 酉族、U(0)=I，定义 H=iℏU̇(0)。则

```math
\Phi_t(\rho)
=\operatorname{Tr}_R\!\left[
U(t)(\rho\otimes|0\rangle\langle0|)U(t)^*
\right]
```

满足

```math
\boxed{
\dot\Phi_0(\rho)
=-\frac{i}{\hbar}[H_{\mathrm{eff}},\rho],
\qquad
H_{\mathrm{eff}}=(I\otimes\langle0|)H(I\otimes|0\rangle).
```

\*\*证明。\*\*在固定记录基下，初始记录分支 M₀(t)=I−itHeff/ℏ+o(t)，其他分支 Mα(t)=O(t)。代入 Kraus 求和，一阶只有初始记录分支贡献，得到交换子。证毕。

# 15 共同参考和圆周历史

## 射线相同不等于实际幅度场相同

共同参考是 Ω 内的比较资源，不是外部绝对相位。若只保留射线而丢掉全部相干参考，主定理便不能原样约束实际幅度场。

例如单位球上的

```math
v(x)=i|x_1|^2x
```

处处切向且满足相位协变。其每条轨迹只改变自身相位，所以全部射线不动，所有射线转移概率不变。但在维数至少为二时，实际场不由同一个复线性 K 实现：对 e₁、e₂ 的作用分别为 ie₁、0，对二者等幅叠加的作用却为其自身的 i/2 倍。

这并不否定其射线演化的酉表示；该射线演化就是恒等。它说明主定理关于实际幅度提升的结论，使用了已经声明的共同相干参考。

\*\*白话图景。\*\*每条路各自转过多少相位，单独看终点可能完全看不出来。把两条路放回同一个干涉参照，差别才成为可比较内容。本候选锁住的是这套完整比较。

## 保留共享子态的圆和几何相位

取互相正交的 q、r，令 ‖q‖²=p，‖r‖²=1−p，0\<p<1。共享 q 的历史可写为

```math
\psi(\theta)=q+e^{i\theta}r.
```

它具有 2π 周期，并满足

```math
\langle\psi(\theta),\partial_\theta\psi(\theta)\rangle=i(1-p).
```

其水平提升为

```math
\phi(\theta)=e^{-i(1-p)\theta}\psi(\theta),
\qquad
\langle\phi,\partial_\theta\phi\rangle=0,
```

故绕一周得到

```math
\phi(2\pi)=e^{-i2\pi(1-p)}\phi(0).
```

这是指定水平接续产生的几何相位。不能把它当成任意实际圆周门必有的额外净相位。原历史也可由

```math
U_\theta=P_q+e^{i\theta}(I-P_q)
```

实现，且 U₂π=I。以 θ 为参数，它的生成元对应 Hθ=−ℏ(I−Pq)；动态相位 +2π(1−p) 与几何相位 −2π(1−p) 抵消。要把几何相位单独读成相对结果，需要指定水平接续或动态补偿，并带着内部参考比较。

## 几何圆怎样变成时间周期

圆提供周期坐标，实际时间周期还取决于推进规律。对自主 H，将初态分解到非零能量分量 ψj，记对应本征值 Ej。射线在 T>0 后返回，当且仅当

```math
\frac{(E_j-E_k)T}{\hbar}\in2\pi\mathbb Z
\quad\text{对全部非零分量 }j,k.
```

\*\*证明。\*\*各正交分量演化为 exp(−iEjt/ℏ)ψj。总向量回到原射线当且仅当所有非零分量取得同一个相位，消去共同相位即得条件。证毕。

两能量分量具有单个相对频率；多个不共度能隙可以没有有限的精确共同周期。圆的存在不会自动把所有历史强迫成同一个时间周期。

## 历史切向和椭圆之间的精确条件

沿用历史弧的单位三维球截面。给起点 p、目标 q∈S²，q≠p，以及起点单位切向 u，令 b=p×u。若明确要求轨迹属于平面截球的圆类，则对应圆所在平面唯一为

```math
(b+\kappa p)\cdot r=\kappa,
\qquad
\kappa=\frac{b\cdot q}{1-p\cdot q}.
```

\*\*证明。\*\*圆平面法向必须垂直 u，故在 p、b 张成的平面中。非退化情形可写为 b+κp；通过 p 给常数 κ，通过 q 即得该公式。由于 q≠p，分母为正。证毕。

写 r=Xp+Yu+Zb，圆平面给 Z=κ(1−X)，代入单位球得

```math
X^2+Y^2+\kappa^2(1-X)^2=1.
```

因此历史平面的投影在 κ=0 时为圆，κ≠0 时为椭圆。目标落在起点与历史切向张成的大圆上时 κ=0；不在时得到小圆及上述椭圆投影。参数方向由 u 固定，绕行次数还需指定。光滑性与端点条件本身不强迫轨迹属于圆类。

\*\*白话图景。\*\*圆确实带来周期，保留共享部分时，相对相位绕一圈会回到原来。历史切向把出发方向固定；在圆类中，目标决定圆平面怎样倾斜，倾斜后的投影就是椭圆。若要判断绕一圈到底留下什么，仍要看完整门和内部记录如何接续。

# 16 从内部接口重构有限维量子规则

v82 的新条件负责把实际完整切向场锁成共同生成元。复正核、复方向、完整读口、组合接口和概率标定沿用此前已经明确供应的结构。将它们写在同一套定义中，才能准确判断各条量子规则从何而来。

## 正核给出共同幅度空间

\*\*定理 16.1 有限正核表示。\*\*设内容集合上的共同复核 k 满足：任意有限集合的 Gram 矩阵为正半定。对形式有限和定义

```math
\left\langle\sum_i c_i\delta_{x_i},\sum_jd_j\delta_{y_j}\right\rangle
=\sum_{i,j}\bar c_i k(x_i,y_j)d_j.
```

商去零范数元后得到内积空间。若该截口秩有限，则得到有限维复 Hilbert 空间 H，并且 k(x,y)=⟨ι(x),ι(y)⟩。

\*\*证明。\*\*正性给半内积；对任意两向量使用复参数二次式的非负性，得到 Cauchy–Schwarz。不等式说明零范数向量与所有向量正交，故商空间内积良定义。有限秩给有限维，因而自动完备。证毕。

这给内部比较的一套共同坐标。只有再带着实际相干组合的闭包，才可把整个向量空间中的组合都解释为被声明允许的内容；表示定理本身不制造实验控制。

## 全效果响应给出密度算子

\*\*定理 16.2 全效果状态表示。\*\*在全部效果 0≤E≤I 上，设同一个实际响应 f 满足

```math
f(E)\ge0,\qquad f(I)=1,\qquad
f(E+F)=f(E)+f(F)\quad(E,F\ge0,\ E+F\le I).
```

则存在唯一

```math
\rho\ge0,\qquad\operatorname{Tr}\rho=1,
\qquad
\boxed{f(E)=\operatorname{Tr}(\rho E).}
```

\*\*证明。\*\*有限可加给 f(E/n)=f(E)/n，故有有理齐次。正性及部分可加给单调性。有理数从两侧夹住任意 t∈[0,1]，即得 f(tE)=tf(E)，无需先假定连续。

对任意 A≥0，选正整数 n 使 A/n≤I，定义 F(A)=nf(A/n)。共同细分说明该定义与 n 无关。选择足够大的共同 n，便得正锥上的可加性和实齐次。再按自伴算符的正负分解延拓，得到自伴空间上的实线性泛函。

有限维迹配对非退化，故存在唯一自伴 ρ 表示 F。对所有一维投影的非负响应给 ρ≥0；F(I)=1 给迹一。证毕。

前件是全部效果以及跨合法菜单相同的响应，不能替换成只在一份有限原生菜单上的数值表。此证明适用于二能级，不使用仅针对投影且带维数限制的替代前件。

## 投影概率不单独决定测后状态

\*\*定理 16.3 固定本征态的投影更新。\*\*设同一输入输出 H 上，一个结果的实际操作为

```math
\mathcal I_P(\rho)=\sum_\alpha A_\alpha\rho A_\alpha^*,
\qquad
\sum_\alpha A_\alpha^*A_\alpha=P,
```

其中 P 是正交投影。进一步要求对每个 ran P 中的单位纯态 ψ，

```math
\mathcal I_P(|\psi\rangle\langle\psi|)
=|\psi\rangle\langle\psi|.
```

则唯一可能的操作是

```math
\boxed{\mathcal I_P(\rho)=P\rho P.}
```

\*\*证明。\*\*对 ker P 中向量 x，∑α‖Aαx‖²=0，故每个 Aα=AαP。纯态输出为秩一，正项不能相互抵消，因而 Aαψ 始终与 ψ 共线。一个线性算符若使某个子空间内每个向量都沿自身方向，则在该子空间上为同一个标量：对独立 ψ、φ 比较 ψ+φ 即得标量相同。因此 Aα=cαP。效果等式给 ∑α|cα|²=1，代回即得。P=0 时所有 Kraus 算子为零，结论同样成立。证毕。

条件概率非零时归一，得到 PρP/Tr(ρP)。仅有效果 P 不够；例如 A=WP，W 在 ran P 内作非平凡酉转动，仍有 A\*A=P，却改变了该子空间内的状态。记录可重复与逐一固定每个本征子空间纯态也不是同一条件。

## 组合核给出张量积

若独立准备满足

```math
k_{AB}((x,y),(x',y'))
=k_A(x,x')k_B(y,y'),
```

则对应映射 ιAB(x,y)↦ιA(x)⊗ιB(y) 在乘积准备的线性张成上保内积。商去零元后得到等距。若乘积准备张成所声明的复合空间，便得到 H_AB≅H_A⊗H_B。允许的整体相干组合包括不可分解向量，便产生纠缠态。

实际局部端口由 A⊗I、I⊗B 实现时相互对易。对 B 上迹保持仪器忽略其结果，

```math
\begin{aligned}
p_A(E)
&=\sum_e\operatorname{Tr}\!\left[
(E\otimes I)(I\otimes M_e)\rho(I\otimes M_e^*)
\right]\\
&=\operatorname{Tr}[(E\otimes I)\rho],
\end{aligned}
```

其中使用 ∑eMe\*Me=I。这给相应局部操作下的无信号性。乘积核本身不能替代实际局部端口及其可用性的说明。
