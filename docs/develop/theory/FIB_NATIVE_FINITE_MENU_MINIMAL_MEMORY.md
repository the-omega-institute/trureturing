# Native finite-menu minimal memory

## 1. The finite supplied-count problem

For a public finite menu of literal tree addresses, the information needed
to predict every future reply can be smaller than a losslessly retained
table of boundary coordinates. This volume determines that information
exactly for the initial family
$\mathcal F_D=\{\langle\alpha,v\rangle:\operatorname{height}(v)\le D\}$,
where $D\ge1$. Menus may be empty or nested. The update count is a
separate supplied input, with the promise that it counts genuine updates
of the same register from the specified initial capture.

The construction prunes unused subtrees and identifies precisely one
kind of leaf/branch collision. It yields a finite normal form, an exact
state-count recurrence, representatives within the original height
bound, and an attainable minimum over arbitrary deterministic retained
encodings. A separate criterion determines exactly when the initial
selected-reply vector itself is sufficient: the relative menu must be
prefix-closed, including the empty prefix.

The reference [AAR], *Adaptive acquired references and the retention
frontier*, supplies the native interface and the finite initial family.
Its §10 concerns fresh acquisition of an **unknown** lag after arbitrary
bounded retention. Its §11 instead supplies the count and proves an
exact theorem for fixed public ray-coordinate tables. The present task
has the latter supplied-count interface and permits arbitrary retained
encodings. Neither §10's query frontier nor §11's number of ray
coordinates is an arbitrary-memory state count.

These are ordinary mathematical statements with proofs. The
source-relative contribution is the native collision classification,
the constructive normal form and count, bounded common realization,
minimal effective coding, and the exact prefix-completeness boundary.
The generic deterministic separation principle is background. The
results are `repo-derived`; external originality is unverified.

## 2. Trees, menus and the complete retained interface

**Definition 2.1 (native trees and literal values).** Let $\mathcal T$
be the finite nonempty ordered full binary trees generated by two leaves
$\alpha,\beta$ and the constructor $\langle x,y\rangle$. Set

$$
\begin{aligned}
\operatorname{height}(\alpha)&=\operatorname{height}(\beta)=0,\\
\operatorname{height}(\langle x,y\rangle)
 &=1+\max(\operatorname{height}(x),\operatorname{height}(y)).
\end{aligned}
$$

The one-register update is the homomorphism

$$
\rho\alpha=\beta,\qquad
\rho\beta=\langle\beta,\alpha\rangle,\qquad
\rho\langle x,y\rangle=\langle\rho x,\rho y\rangle.
\tag{FM.1}
$$

A literal is a finite word over $\{L,R\}$; $\varepsilon$ denotes the
empty word. Let $\operatorname{Pos}(u)$ be the reached node addresses of
$u$. The value $\operatorname{val}(q,u)$ is $\alpha$, $\beta$ or
$\mathsf{br}$ according to the constructor at a reached $q$, and is
$\mathsf{abs}$ if navigation is blocked by a leaf at a strict prefix of
$q$. The root is always reached. An actual native
$\operatorname{Read}(q)$ submits the entire materialized literal and
returns this value at its actual event. Computing the value of this
function does not create a Read event.

**Definition 2.2 (the exact initial family and public menu).** For public
$D\ge1$, let

$$
\begin{aligned}
\mathcal F_D
 &=\{\langle\alpha,v\rangle:v\in\mathcal T,
                      \ \operatorname{height}(v)\le D\},\\
A_D&=\{p:1\le |p|\le D,\ p\text{ begins with }R\},\\
P&\subseteq A_D,\qquad
S=\{q:Rq\in P\}.
\end{aligned}
\tag{FM.2}
$$

$P$ is public and finite, with no prefix-free restriction. Thus $S$ can
contain $\varepsilon$ and nested words, and each $q\in S$ has
$|q|\le D-1$. A public ordering fixes the order of every output vector.
For any finite relative menu $S$, write

$$
S_L=\{r:Lr\in S\},\qquad S_R=\{r:Rr\in S\},\qquad
d(S)=
\begin{cases}
-1,&S=\varnothing,\\
\max_{q\in S}|q|,&S\ne\varnothing.
\end{cases}
\tag{FM.3}
$$

Membership of $\varepsilon$ is separate from the two child menus.
The source's bound
$\operatorname{height}(\langle\alpha,v\rangle)\le D+1$ in [AAR,
Definition 11.1] is exactly (FM.2), since that height equals
$1+\operatorname{height}(v)$.

**Proposition 2.3 (relative-menu reduction).** For every $v\in\mathcal T$,
every literal $q$ and every $k\ge0$,

$$
\operatorname{val}(Rq,\rho^k\langle\alpha,v\rangle)
 =\operatorname{val}(q,\rho^k v).
\tag{FM.4}
$$

Consequently the original $P$-vector is exactly the $S$-vector in the
right subtree, with the public relabeling $q\mapsto Rq$.

Proof. Induction on $k$ in (FM.1) gives
$\rho^k\langle\alpha,v\rangle=\langle\rho^k\alpha,\rho^k v\rangle$.
Its root remains a branch. The first $R$ therefore always reaches the
right child; all subsequent successful or blocked navigation is exactly
navigation by $q$ in that child. This proves the identity also for
absent targets and for $q=\varepsilon$. $\square$

**Definition 2.4 (arbitrary deterministic retention).** A first capture
has actual source $t\in\mathcal F_D$. An encoder retains an arbitrary
deterministic state $m(t)$. Every accessible source-bearing distinction
at the handoff is a fixed function of $m(t)$ and the public $D,P$ and
program data. This includes control, prior outputs, reply latches,
query histories, descriptors, pointers, region identities, lengths,
capacities and allocation metadata. Naming one variable $m$ does not
exclude extra readable information from this condition.

A passive deterministic decoder receives $m(t)$ and an exact
$k\in\mathbb N$, with the authentic same-root, same-register promise
$U_w=\rho^k t$. Its required output is

$$
V_P(U_w)=\bigl(\operatorname{val}(p,U_w)\bigr)_{p\in P}.
\tag{FM.5}
$$

It has no fresh source access. Correctness ranges over every initial
$t\in\mathcal F_D$ and every $k\ge0$. The state to be minimized is the
initial source-dependent retained state; the count is a separate input.
The promise is a hypothesis, not something authenticated by the code.

**Definition 2.5 (separate resource coordinates).** The number of
reachable initial states is $|m(\mathcal F_D)|$. A fixed-width binary
payload of width $b$ has at most $2^b$ values, including one empty
codeword when $b=0$. Immutable source-independent code, public menus,
preprocessing, initial acquisition, encoder and decoder workspace,
local bit/cell work, output storage and cleanup have separate costs.
The acquisition, transmission and working representation of $k$ are
also separate. An integer is charged by its representation, not as one
unbounded cell. For actual submitted literals $p_1,\ldots,p_T$, query
count, total literal letters and maximum operand length are separately

$$
T,\qquad \sum_{i=1}^T|p_i|,\qquad
\max(\{0\}\cup\{|p_i|:1\le i\le T\}).
$$

Repeated submissions count repeatedly. Physically retained but
inaccessible storage still has a physical storage cost. The optimum
below concerns reachable information states and their fixed binary
payload, not a joint optimum over all these resources.

## 3. Atomic paths and finite signatures for whole futures

**Definition 3.1 (weights and atomic iterates).** Put

$$
s(q)=\#_L(q)+2\#_R(q),\qquad
e(\alpha)=0,\quad e(\beta)=1,\qquad T_n=\rho^n\alpha.
$$

For nonempty $r$, let $\ell(r)=1$ if its last letter is $L$, and
$\ell(r)=0$ if its last letter is $R$.

**Lemma 3.2 (atomic path law, including presence).** For all $n\ge2$,

$$
T_n=\langle T_{n-1},T_{n-2}\rangle.
\tag{FM.6}
$$

For every nonempty word $r$ and every $n\ge0$,

$$
r\in\operatorname{Pos}(T_n)
 \quad\Longleftrightarrow\quad n\ge s(r)+\ell(r).
\tag{FM.7}
$$

When present, its subtree is $T_{n-s(r)}$. At $\varepsilon$ the values
are $\alpha$ for $n=0$, $\beta$ for $n=1$, and $\mathsf{br}$ for
$n\ge2$. At a nonempty $r$ ending in $R$, the values are

$$
\operatorname{val}(r,T_n)=
\begin{cases}
\mathsf{abs},&n<s(r),\\
\alpha,&n=s(r),\\
\beta,&n=s(r)+1,\\
\mathsf{br},&n\ge s(r)+2.
\end{cases}
\tag{FM.8}
$$

At a nonempty $r$ ending in $L$, they are

$$
\operatorname{val}(r,T_n)=
\begin{cases}
\mathsf{abs},&n<s(r)+1,\\
\beta,&n=s(r)+1,\\
\mathsf{br},&n\ge s(r)+2.
\end{cases}
\tag{FM.9}
$$

In particular the final-$L$ case has no alpha phase.

Proof. $T_0=\alpha$, $T_1=\beta$ and
$T_2=\langle\beta,\alpha\rangle$. Applying the homomorphism to the
last identity proves (FM.6) by induction. A legal step from an atomic
branch subtracts one from its index for $L$ and two for $R$. It is
legal exactly when the index before that step is at least two.
Therefore the successive steps of $r$ are all legal exactly when

$$
n\ge s(a)+2\quad\text{for every proper prefix }a\prec r.
$$

These conditions are necessary by following a reached path and
sufficient by successively applying (FM.6). Since every letter has
positive weight, the greatest proper-prefix weight is the weight just
before the last letter. The condition is consequently
$n\ge s(r)+1$ for a final $L$, and $n\ge s(r)$ for a final $R$.
Subtracting the traversed weights gives the subtree $T_{n-s(r)}$.
Indices zero, one and at least two give alpha, beta and branch. Index
zero is not reached in the final-$L$ case. This proves all formulas.
The beta starting leaf is covered by $\rho^k\beta=T_{k+1}$.
$\square$

**Definition 3.3 (initial blocker signature).** For a finite tree $u$
and a literal $q$, write $r_q(u)=\operatorname{val}(q,u)$. If this is
$\mathsf{br}$, put $b_q(u)=0$. Otherwise there is a unique initial
leaf $a\preceq q$ reached along the attempted path: it is $q$ itself
if $q$ is a leaf, and its strict blocking prefix if $q$ is absent.
For every nonbranch initial reply set $b_q(u)=s(q)-s(a)+2-e(u|_a)$. In all cases
the signature is

$$
K_q(u)=(r_q(u),b_q(u)).
\tag{FM.10}
$$

The notation $u|_a$ is used only at this initially present leaf.

**Theorem 3.4 (complete response formula and explicit separation).**
For every $u\in\mathcal T$ and literal $q$, $b_q(u)$ is the first
nonnegative count at which $q$ is a branch, and

$$
0\le b_q(u)\le s(q)+2.
\tag{FM.11}
$$

The signature $K_q(u)$ determines every future reply. An initial branch
stays branch; an initial alpha gives alpha at zero, beta at one and
branch thereafter; an initial beta gives beta at zero and branch
thereafter. If the initial reply is absent and $b=b_q(u)$, the formula
is

$$
\operatorname{val}(q,\rho^k u)=
\begin{cases}
\mathsf{br},&k\ge b,\\
\beta,&k=b-1,\\
\alpha,&k=b-2\text{ and }q\text{ ends with }R,\\
\mathsf{abs},&\text{otherwise},
\end{cases}
\qquad k\ge0.
\tag{FM.12}
$$

For absent final-$R$ targets $b\ge3$; for absent final-$L$ targets
$b\ge2$. For two actual trees $u,u'$, equality of their signatures at
$q$ is equivalent to equality of all their values there at common
counts. If the signatures differ, a separating count is zero when the
initial replies differ, and otherwise the smaller of their two
distinct branch counts.

Proof. An initially present branch has only branch ancestors and
remains a branch under the homomorphism. In the other cases follow the
initial branch ancestors down to the leaf $a$ in Definition 3.3.
Induction along that path and on $k$ gives the actual subtree
$\rho^k(u|_a)=T_{k+e(u|_a)}$ at $a$. No transport assertion is made at
an initially absent $q$.

Write $q=ar$. If $r=\varepsilon$, the two possible initial leaf labels
give the stated sequences and first branch count $2-e(u|_a)$. If
$r\ne\varepsilon$, Lemma 3.2 gives branch exactly when
$k+e(u|_a)\ge s(r)+2$. This is precisely (FM.10). The same path law
gives (FM.12), since $r$ and $q$ have the same last letter. A final
$R$ has $s(r)\ge2$, giving $b\ge3$; a final $L$ has $s(r)\ge1$,
giving $b\ge2$. The upper bound follows from
$s(a)+e(u|_a)\ge0$.

Equal signatures give equal sequences by these formulas. Conversely
equal sequences have equal initial values and equal first branch
counts. If just those counts differ, say $b<b'$, at count $b$ the first
tree gives branch and the second does not. Both histories use that
same nonnegative count. This also proves the separating rule.
$\square$

**Corollary 3.5 (exact menu saturation and the distinguishing horizon).**
For nonempty $S$ define

$$
B(S)=\max_{q\in S}(s(q)+2).
\tag{FM.13}
$$

Every finite initial tree has branch at all $S$-targets for every
$k\ge B(S)$. For menus in (FM.2), this is the least uniform saturation
threshold over $\mathcal F_D$, and $B(S)\le2D$. Every pair of initial
sources with different future $P$-responses is separated by a legal
target and one common count $0\le k<2D$. Indeed $k<B(S)$ suffices.
For $P=A_D$, $B(S)=2D$. For an empty menu the vector is always empty;
its least threshold is zero, without taking a maximum over an empty
set.

Proof. Apply (FM.11) to each relative target and use Proposition 2.3.
Since $|q|\le D-1$, $s(q)+2\le2D$. For sharpness take the one actual
source $t_0=\langle\alpha,\alpha\rangle\in\mathcal F_D$. In its
right subtree every $q$ has first branch count exactly $s(q)+2$.
At a target attaining $B(S)$, the value at $B(S)-1$ is beta by
Lemma 3.2, including the case $q=\varepsilon$. Hence any proposed
smaller uniform threshold fails at that later count.

For separation, unequal future vectors have some unequal signature by
Theorem 3.4. Its rule uses zero or the smaller of two unequal branch
counts bounded by $B(S)$, and therefore a count strictly below
$B(S)\le2D$. Each initial source undergoes exactly those $k$ updates
on its own register. For the full menu the relative target
$R^{D-1}$ attains weight $2(D-1)$, proving $B(S)=2D$. This includes
$D=1$. $\square$

## 4. All collisions between native constructors

**Definition 4.1 (response equivalence and the strict-left condition).**
For a finite menu $S$ and actual finite trees, write

$$
u\equiv_S u'
\quad\Longleftrightarrow\quad
\forall q\in S\ \forall k\ge0,\quad
\operatorname{val}(q,\rho^k u)=\operatorname{val}(q,\rho^k u').
\tag{FM.14}
$$

This notation specifies the property to be characterized. The finite
construction below does not define its states as infinite response
functions. For nonempty $S$, the strict-left condition is

$$
S\subseteq\{Lr:r\ne\varepsilon\}.
\tag{FM.15}
$$

It excludes $\varepsilon$, $L$ itself, and every target beginning with
$R$; it includes every finite nonempty collection of strict descendants
of $L$, regardless of nesting.

**Lemma 4.2 (complete constructor classification).** Let $S$ be a
nonempty finite menu. Then alpha and beta are inequivalent; alpha is
inequivalent to every branch; and beta is equivalent to a branch if
and only if (FM.15) holds. Under that condition, for all $x,y$,

$$
\beta\equiv_S\langle x,y\rangle
\quad\Longleftrightarrow\quad x\equiv_{S_L}\alpha
\quad\Longleftrightarrow\quad x=\alpha.
\tag{FM.16}
$$

The right child is unrestricted. In particular one common tree
$\langle\alpha,y\rangle$ matches beta simultaneously on the whole
menu. For any two branches, whether or not $S$ contains
$\varepsilon$,

$$
\langle x,y\rangle\equiv_S\langle x',y'\rangle
\quad\Longleftrightarrow\quad
x\equiv_{S_L}x'\ \text{ and }\ y\equiv_{S_R}y'.
\tag{FM.17}
$$

For $S=\varnothing$ all trees are equivalent instead.

Proof. For every $q$, including $\varepsilon$, atomic alpha and beta
have first branch counts $s(q)+2$ and $s(q)+1$. Any target of a
nonempty menu separates them by Theorem 3.4.

Compare alpha with a branch. If $\varepsilon\in S$, their initial
root values differ. Otherwise choose any $q=cr\in S$, where $c$ is
one letter. Alpha has first branch count $s(r)+s(c)+2$ there. In a
branch source, the target is $r$ in its actual $c$-child, so its first
branch count is at most $s(r)+2$. Since $s(c)>0$, these times differ.
Thus the alpha equivalence class on every nonempty menu contains only
the literal leaf alpha: beta and all branches have been excluded.

Next compare beta with a branch. A target $\varepsilon$ separates at
count zero. A target $Rr$ has beta first branch count $s(r)+3$, whereas
the branch's right-child response has first branch count at most
$s(r)+2$. A target $L$ is initially absent in beta and present in every
branch, so also separates at zero. These three obstructions exhaust
the failure of (FM.15), proving necessity.

Suppose (FM.15) holds. Every target is $Lr$ with $r\ne\varepsilon$.
At zero, beta at $Lr$ and alpha at $r$ are both absent. For every
$k\ge1$, the left child of $\rho^k\beta=T_{k+1}$ is $T_k$ by
(FM.6), which is also $\rho^k\alpha$. Consequently beta's entire
$S$-vector equals that of $\langle\alpha,y\rangle$ at every count,
for every finite $y$. This proves simultaneous sufficiency, including
all overlaps between targets. Against a general branch
$\langle x,y\rangle$, comparison is exactly comparison of $x$ with
alpha on $S_L$; $S_R$ is empty. Since $S_L$ is nonempty, the alpha
class just proved is the singleton $\{\alpha\}$, giving (FM.16).

Finally, a branch remains a branch at its root, and each nonempty
target follows one actual child under every iterate. Splitting all
targets by that first letter proves both directions of (FM.17).
An empty-word target contributes the same permanent branch in both
sources. Empty menus impose no conditions at all. This covers every
pair of native constructors. $\square$

The strictness in (FM.15) matters. For $S=\{L\}$, beta and
$\langle\alpha,\alpha\rangle$ differ initially by absent versus
alpha. For $S=\{LL\}$, they agree at all counts by Lemma 4.2.
Counting two additional leaf classes in every menu would count beta
twice in the latter case.

## 5. A pruned normal form and its exact recurrence

**Definition 5.1 (menu-typed normal forms).** For the empty menu set
$\mathcal C(\varnothing)=\{\star\}$ and
$\nu_{\varnothing}(u)=\star$ for all trees. For nonempty $S$ put

$$
\eta(S)=
\begin{cases}
0,&S\subseteq\{Lr:r\ne\varepsilon\},\\
1,&\text{otherwise},
\end{cases}
$$

and define the disjoint syntactic sum

$$
\mathcal C(S)=\{\mathsf A\}
\ \sqcup\ \bigl(\{\mathsf B\}\text{ if }\eta(S)=1\bigr)
\ \sqcup\
\{\mathsf{Pair}(c_L,c_R):
       c_L\in\mathcal C(S_L),\ c_R\in\mathcal C(S_R)\}.
\tag{FM.18}
$$

Tags are interpreted with their public menu type; $\mathsf A$ and
$\mathsf B$ are state names, not literal replies. Define

$$
\begin{aligned}
\nu_S(\alpha)&=\mathsf A,\\
\nu_S(\beta)&=
\begin{cases}
\mathsf B,&\eta(S)=1,\\
\mathsf{Pair}(\mathsf A,\star),&\eta(S)=0,
\end{cases}\\
\nu_S(\langle x,y\rangle)
 &=\mathsf{Pair}(\nu_{S_L}(x),\nu_{S_R}(y)).
\end{aligned}
\tag{FM.19}
$$

Empty menus are handled before this nonempty case; their vacuous
inclusion in (FM.15) creates no extra state.

**Lemma 5.2 (typing, finiteness and termination).** For every finite
$S$, $\mathcal C(S)$ is finite and (FM.19) is a well-typed terminating
structural procedure on every finite actual tree. It need not inspect
any subtree whose corresponding menu is empty.

Proof. Every nonempty child menu has strictly smaller maximum word
length than its parent. If $d(S)=0$, $S=\{\varepsilon\}$ and both
children are empty. Induction on that depth with the empty-menu base
therefore defines finite child sets and then the finite sum (FM.18).
It also terminates the normalization. In the exceptional case
$\eta(S)=0$, $S_L$ is nonempty, so $\mathcal C(S_L)$ contains a
well-typed alpha tag, while $\mathcal C(S_R)=\{\star\}$. Hence
$\mathsf{Pair}(\mathsf A,\star)$ belongs to the indicated product;
it is not an additional leaf tag. On an empty menu the result is
constant and requires no navigation in the tree. $\square$

**Theorem 5.3 (exact structural equivalence).** For every finite menu
$S$ and all actual finite trees $u,u'$,

$$
\nu_S(u)=\nu_S(u')\quad\Longleftrightarrow\quad u\equiv_S u'.
\tag{FM.20}
$$

For the original family this characterizes equality of all future
$P$-vectors by $\nu_S(v)$ for $t=\langle\alpha,v\rangle$. Unequal
normal forms in that family have a legal common-count separator with
$0\le k<2D$.

Proof. Induct on menu depth as in Lemma 5.2. The empty case has one
state and no required responses. At a nonempty menu, two branches
have equal forms exactly when the corresponding child forms are
equal. The induction hypotheses and (FM.17) identify this with their
response equivalence.

Two equal leaves plainly have equal forms and responses. Alpha and
beta have different forms, since beta is either $\mathsf B$ or a
pair, and Lemma 4.2 separates them. Alpha and a branch have different
tags and are likewise separated. For beta against a branch when
$\eta=1$, the tags differ and Lemma 4.2 excludes every collision.
When $\eta=0$, beta's form equals the branch's form exactly when the
left child's form is $\mathsf A$; the right form is necessarily
$\star$. By induction this is precisely left-child equivalence to
alpha on $S_L$, which (FM.16) identifies with beta/branch equivalence
on $S$. These cases exhaust all source constructors and prove both
implications without any further identifications.

Proposition 2.3 transfers the result to the original menu. If two
forms differ, the equivalence just proved gives a differing signature
at some target, and Theorem 3.4 and Corollary 3.5 give the separator.
It can be found by finite navigation to obtain the signatures, or by
following unequal child forms until reaching a constructor case in
Lemma 4.2. No search through an unbounded sequence of epochs is
required. $\square$

**Theorem 5.4 (exact symbolic count and bounded common realization).**
Define

$$
N(\varnothing)=1,\qquad
N(S)=N(S_L)N(S_R)+1+\eta(S)\quad(S\ne\varnothing).
\tag{FM.21}
$$

Then $N(S)=|\mathcal C(S)|$. Every state has an actual representative
of height at most $\max(0,d(S)+1)$, normalizing to that state. For
every height cap $H\ge\max(0,d(S)+1)$, $N(S)$ is exactly the number
of response classes among trees of height at most $H$. In particular,
the number of classes of $\mathcal F_D$ for the original menu is
$N(\{q:Rq\in P\})$.

Proof. Finiteness is already established. The tags in (FM.18) are
disjoint; its branch part is the product of the two child state sets.
This gives the formal count (FM.21). To identify it with actual
classes, define representatives by

$$
\begin{aligned}
\operatorname{Rep}_{\varnothing}(\star)&=\alpha,\\
\operatorname{Rep}_S(\mathsf A)&=\alpha,\\
\operatorname{Rep}_S(\mathsf B)&=\beta
                    &&\text{when }\eta(S)=1,\\
\operatorname{Rep}_S(\mathsf{Pair}(c_L,c_R))
 &=\langle\operatorname{Rep}_{S_L}(c_L),
          \operatorname{Rep}_{S_R}(c_R)\rangle.
\end{aligned}
\tag{FM.22}
$$

Induction gives
$\nu_S(\operatorname{Rep}_S(c))=c$ for every state. In the
strict-left case the state $\mathsf{Pair}(\mathsf A,\star)$ is
represented by $\langle\alpha,\alpha\rangle$; beta is another source
in the same class, and has not been added a second time.

For the height bound, the empty representative has height zero. If
$d(S)=0$, both child menus are empty, so every pair representative
has height one. If $d(S)\ge1$, each nonempty child menu has maximum
length at most $d(S)-1$; its representatives therefore have height at
most $d(S)$ by induction. Empty children have height zero. Pairing
increases the maximum child height by one; leaf representatives have
height zero. This proves the claimed bound.

Every pair of child classes is thus joined into one actual full tree
with the prescribed height bound. This is the common realization
justifying the product in (FM.21). Target signatures are not being
chosen independently: correlations from common blockers, shared
prefixes and nested targets are already contained in their actual
child normal forms. Any queried parent is a branch in the joined tree.

Every tree normalizes to some state, every state has a representative,
and distinct states are response-distinct by Theorem 5.3. Hence there
are exactly $N(S)$ classes at every stated height cap. For (FM.2),
$d(S)\le D-1$ when nonempty, so

$$
t_c=\langle\alpha,\operatorname{Rep}_S(c)\rangle\in\mathcal F_D
\quad(c\in\mathcal C(S)).
\tag{FM.23}
$$

For the empty menu, $\langle\alpha,\alpha\rangle$ represents its
only state. Thus all lower-bound witnesses belong to the exact
original family. $\square$

## 6. Attainable minimum over arbitrary retained encodings

**Theorem 6.1 (arbitrary-encoding necessity).** Under Definition 2.4,
every correct deterministic encoder and passive decoder satisfy

$$
m(\langle\alpha,v\rangle)=m(\langle\alpha,v'\rangle)
\quad\Longrightarrow\quad \nu_S(v)=\nu_S(v')
\tag{FM.24}
$$

for all initial sources in $\mathcal F_D$. Consequently at least
$N(S)$ initial retained states are reachable.

Proof. If equal retained states had unequal normal forms, Theorem 5.3
would supply $p\in P$ and a common $0\le k<2D$ at which the required
values differ. Use the two valid initial sources and exactly $k$
genuine updates on each one's own register. The decoder's public
parameters, supplied count and retained state are identical. By the
complete-state hypothesis every other accessible source-bearing
distinction is also identical. Determinism therefore gives the same
output, contrary to the two required vectors. This proves (FM.24).

Apply it to the $N(S)$ sources (FM.23). Their distinct forms must
receive distinct states. The argument allows arbitrary encodings and
arbitrary finite source-independent public code. It is the elementary
same-input/different-output separation principle, applied after the
native classes and their witnesses have been established. $\square$

**Definition 6.2 (canonical rank and unrank).** Give $\star$ rank zero
at the empty menu. At a nonempty menu write $a_S=1+\eta(S)$, assign
$\mathsf A$ rank zero and $\mathsf B$ rank one when present, and set

$$
\operatorname{rank}_S(\mathsf{Pair}(c_L,c_R))
 =a_S+\operatorname{rank}_{S_L}(c_L)N(S_R)
       +\operatorname{rank}_{S_R}(c_R).
\tag{FM.25}
$$

For an integer $j\ge a_S$ in the product interval, subtract $a_S$,
divide by $N(S_R)$, and unrank its quotient on $S_L$ and its remainder
on $S_R$. Smaller valid integers select their leaf tags. Empty-menu
unranking returns $\star$.

**Proposition 6.3 (effective bijection).** For every finite menu $S$,
rank is a bijection

$$
\mathcal C(S)\longrightarrow\{0,\ldots,N(S)-1\},
$$

with the terminating inverse in Definition 6.2.

Proof. By induction the child ranks range bijectively over intervals
of lengths $N(S_L)$ and $N(S_R)$. Quotient and remainder uniquely
decompose each integer from zero through their product minus one.
Adding $a_S$ places that product after precisely the $a_S$ leaf
tags. Formula (FM.21) identifies the endpoint as $N(S)-1$. Child
menu depth decreases, so the inverse terminates. In the strict-left
case beta has the rank of $\mathsf{Pair}(\mathsf A,\star)$, namely
one; there is no separate beta tag. The empty case has a one-element
bijection. $\square$

**Theorem 6.4 (exact retained-state and fixed-width minima).** In the
interface of Definition 2.4 the minimum reachable initial state count
is $N(S)$, and the minimum fixed binary payload width is

$$
b(D,P)=\left\lceil\log_2 N(S)\right\rceil.
\tag{FM.26}
$$

Both minima are attained by an effective encoder and a total passive
decoder. For an empty menu they are one state and zero bits.

Proof. For $t=\langle\alpha,v\rangle$, encode
$\operatorname{rank}_S(\nu_S(v))$. All $N(S)$ ranks occur by
Theorem 5.4. Store the rank in exactly $b(D,P)$ bits, in a fixed
public region with extent fixed by $D,P$. At handoff all other
accessible source-dependent data must be cleared or be a fixed
function of this code and the public data.

Given a valid code, unrank it to $c$ and construct
$v_c=\operatorname{Rep}_S(c)$. For each $q\in S$, finite navigation
in this reconstructed tree yields the signature $K_q(v_c)$: either
a branch, a reached leaf, or its actual blocking leaf. Evaluate
Theorem 3.4 at the supplied $k$ and relabel the output by $q\mapsto
Rq$. The representative has the same normal form as $v$, so
Theorem 5.3 and Proposition 2.3 prove that the entire output is
exactly $V_P(\rho^k t)$. This requires no source access and no
materialization of $\rho^k t$. Invalid codewords can return a fixed
default vector, making the decoder total on all codewords and
nonnegative counts. Correctness is asserted on the promised inputs.

Theorem 6.1 proves the state lower bound. A binary payload of width
$b$ has at most $2^b$ values, so it can distinguish $N(S)$ states
only if $b\ge\lceil\log_2N(S)\rceil$; the construction meets it.
For $S=\varnothing$ the sole empty code returns the empty vector.

The recursive menu data, integers $N(S')$, rank arithmetic and
representative construction are all finite and effective. This
establishes existence of an encoder and decoder, not zero cost for
their code, public storage, preprocessing, local work or workspace.
They may compute the recurrence as needed or retain public
preprocessing, with its cost separately charged. Source-dependent
preprocessing cannot remain accessible outside the code without
enlarging the retained interface. A readable code length, selected
pointer, capacity or output remnant is information and cannot evade
Theorem 6.1. $\square$

## 7. Exactly when the initial reply vector suffices

**Definition 7.1 (relative prefix completeness).** A finite menu $S$ is
prefix-closed if every prefix of every member, including
$\varepsilon$ and the member itself, belongs to $S$. The empty menu
is prefix-closed. This is a condition after deleting the initial
$R$ from the original menu; it does not require the original empty
address to be in $P$.

**Theorem 7.2 (exact initial-vector criterion).** Fix the entire family
and interface (FM.2). The following are equivalent:

1. The initial vector
   $I_S(v)=(\operatorname{val}(q,v))_{q\in S}$ and a supplied $k$
   determine all future selected values for every
   $\operatorname{height}(v)\le D$ and every $k\ge0$.
2. For every such $v,v'$, equality of $I_S(v),I_S(v')$ implies
   $\nu_S(v)=\nu_S(v')$.
3. $S$ is prefix-closed, with the empty case allowed.

In item 1 one total computable decoder suffices whenever a
single-valued decoder exists. If prefix closure fails, actual
sources in $\mathcal F_D$ with equal entire initial selected vectors
and different future vectors can be constructed from any missing
proper prefix.

Proof. Item 1 implies item 2 by Theorem 5.3: equal initial vectors
cannot support unequal future vectors at the same count. We prove
that item 3 yields both items with an effective reconstruction, then
that its failure contradicts both of them.

Suppose $S$ is prefix-closed. The empty case has no values to recover.
Otherwise $\varepsilon\in S$, and each nonempty child menu is
prefix-closed. The initial root reply distinguishes alpha, beta and
branch. If it is a leaf, that label fixes all future values, including
those at initially absent descendants, and fixes the normal form.
If it is a branch, the initial subvector on $Lr\in S$ is exactly
the initial vector of the actual left child on $S_L$, and similarly
for the right child. Induction on menu depth reconstructs both child
normal forms; empty child menus supply $\star$. Their pair is exactly
$\nu_S(v)$. This proves item 2 and provides a finite reconstruction
procedure on attained vectors. A fixed default on unattained vectors
makes the composed decoder total.

Conversely suppose $S$ is not prefix-closed. Choose $q\in S$ and
a proper prefix $a\prec q$ with $a\notin S$. Write $q=ar$ with
$r\ne\varepsilon$. Define an actual path context by

$$
\begin{aligned}
C_{\varepsilon}[z]&=z,\\
C_{Lb}[z]&=\langle C_b[z],\alpha\rangle,\\
C_{Rb}[z]&=\langle\alpha,C_b[z]\rangle.
\end{aligned}
\tag{FM.27}
$$

Take

$$
v=C_a[\alpha],\qquad v'=C_a[\beta],\qquad
t=\langle\alpha,v\rangle,\quad
t'=\langle\alpha,v'\rangle.
\tag{FM.28}
$$

The right subtrees have height $|a|$. Since
$|a|\le|q|-1\le D-2$, both original sources lie in $\mathcal F_D$.
When $a=\varepsilon$ they are simply the two leaves as right
subtrees, so this case is included. Non-prefix-closure cannot occur
at $D=1$, since its only possible relative word is $\varepsilon$.

The two trees differ only in the leaf label at $a$. Every proper
ancestor target is branch in both; every strict descendant target of
$a$ is absent in both; and every target not comparable with $a$
has the same navigation and value in both. The sole literal whose
initial value changes is $a$ itself, and $a\notin S$. Therefore
the entire initial $S$-vectors agree, not just their values at $q$.

At the selected descendant $q=ar$, the first branch counts are
$s(r)+2$ and $s(r)+1$ by Theorem 3.4. At the one common count

$$
k=s(r)+1
\tag{FM.29}
$$

the first source gives beta and the second branch, by both
final-letter cases of Lemma 3.2. Transport here is at the initially
present $a$, not at the initially absent $q$. In the original sources
the differing target is $Rq\in P$. Each source performs exactly
$k$ genuine updates; the same public count is supplied to both
decoders. Thus item 1 and item 2 fail. This proves necessity and
the complete constructive counterexample for any missing prefix.
$\square$

## 8. The full menu and the separate fixed-ray count

**Corollary 8.1 (full-depth state recurrence).** Let $P=A_D$, put
$S_d=\{q:|q|\le d-1\}$ for $d\ge1$ and $S_0=\varnothing$, and set

$$
C_0=1,\qquad C_d=2+C_{d-1}^{\,2}\quad(d\ge1).
\tag{FM.30}
$$

The exact minimum is $C_D$ reachable states and
$\lceil\log_2 C_D\rceil$ fixed bits. The initial full-menu reply
vector already determines all future full-menu replies. For $D=1$
the nonempty menu has three states and requires two fixed bits;
the empty menu has one state and requires zero bits.

Proof. Every nonempty $S_d$ contains $\varepsilon$, so $\eta(S_d)=1$,
and both child menus are $S_{d-1}$. Substitution into (FM.21) gives
(FM.30); Theorem 6.4 supplies the minima. These menus are prefix-closed,
so Theorem 7.2 gives the initial-vector assertion.

At $D=1$, $S_1=\{\varepsilon\}$ and the three forms are
$\mathsf A$, $\mathsf B$ and $\mathsf{Pair}(\star,\star)$.
They are realized by the right subtrees alpha, beta and
$\langle\alpha,\alpha\rangle$, all of height at most one.
Their original $R$-values are alpha, beta and branch. No absent
$R$ is possible, since the outer root is a branch. Thus $C_1=3$
and its fixed width is two; the empty-menu assertion follows from
the base case. $\square$

**Proposition 8.2 (symbolic bit bounds).** For every $D\ge1$,

$$
3^{\,2^{D-1}}\le C_D,\qquad
C_D+1\le4^{\,2^{D-1}},
\tag{FM.31}
$$

and hence

$$
\left\lceil2^{D-1}\log_2 3\right\rceil
\le\left\lceil\log_2 C_D\right\rceil\le2^D.
\tag{FM.32}
$$

Proof. $C_1=3$ and $C_d\ge C_{d-1}^2$ prove the lower bound by
induction. For $x\ge1$, $x^2+3\le(x+1)^2$; therefore
$C_d+1\le(C_{d-1}+1)^2$. Induction from $C_1+1=4$ proves the upper
bound. Logarithms give the lower width bound. The upper bound yields
$\log_2 C_D<2^D$, whose ceiling is at most the integer $2^D$.
$\square$

**Mathematical citation 8.3 (the published sampling theorem).**
[AAR, Theorem 11.4 and Corollary 11.6] considers a different retained
interface. For a fixed finite public set $Q$ of distinct eventually-right
rays, the retained table is

$$
Z_Q(t)=(h_t(\omega))_{\omega\in Q},\qquad
h_t(\omega)=s(a)+e(t|_a),
\tag{FM.33}
$$

where $a$ is the actual leaf on $\omega$. The boundary coordinate
advances by $k$ under $\rho^k$. For exactly the family (FM.2) and
all supplied counts, that table is sufficient precisely when

$$
Q\cap[pR]\ne\varnothing\quad(p\in P),\qquad
Q\cap[aR]\ne\varnothing\quad(aL\in P),
\tag{FM.34}
$$

where $[b]$ is the set of rays with prefix $b$. Define

$$
\begin{aligned}
B_P&=\{pR:p\in P\}\cup\{aR:aL\in P\},\\
B_{P,\max}&=\{b\in B_P:\text{no strict extension of }b
                                      \text{ belongs to }B_P\}.
\end{aligned}
$$

The published minimum is $|B_{P,\max}|$ ray coordinates, attained
by one eventually-right ray through each maximal cylinder. In
particular it is $2^{D-1}$ for $P=A_D$ and zero for the empty menu.

The counting argument uses the published criterion (FM.34). Distinct
maximal words are prefix-incomparable, so their cylinders are disjoint
and each needs its own ray. Every required word has a maximal
extension in the finite set, so those rays suffice. For $A_D$, the
maximal words are exactly the words of length $D+1$ beginning and
ending in $R$, giving $2^{D-1}$. This is a credited consequence of
the fixed-ray theorem, not a new arbitrary-memory lower bound.

The three optimized quantities have different meanings:

| Interface and resource | Full-menu optimum |
| --- | --- |
| Arbitrary complete retained information states | $C_D$ |
| Arbitrary fixed-width binary payload | $\lceil\log_2 C_D\rceil$ |
| Fixed public ray-coordinate table, number of distinct coordinates | $2^{D-1}$ |

One coordinate may carry several bits, and coordinates need not vary
independently. A lossless ray table may also preserve distinctions
irrelevant to this menu. At $D=1$, for instance, right subtrees
$\langle\alpha,\alpha\rangle$ and
$\langle\alpha,\beta\rangle$ are in the same permanent-branch task
state at $R$, although their scores on $R^\infty$ are respectively
four and five. The single ray satisfies (FM.34), but its lossless
value is not the same resource as the three-state reply code.

## 9. Preserved counterexamples and the limits of the output

**Proposition 9.1 (the two published sampling collisions remain distinct).**
Let

$$
t_\beta=\langle\alpha,\beta\rangle,\qquad
t_{\mathrm{pair}}=\langle\alpha,\langle\alpha,\alpha\rangle\rangle,
\qquad Q=\{RLR^\infty\}.
$$

The sampled score is three for both sources. At $P=\{R\}$ their
initial replies differ by beta versus branch, with witnesses in
$\mathcal F_1$. At $P=\{RL\}$ their initial replies differ by absent
versus alpha, with witnesses in $\mathcal F_2$. Both pairs have
different normal forms for their respective menus. The same local
distinctions persist at correspondingly prefixed targets when placed
in any common actual branch context whose resulting sources meet
the stated height bound.

Proof. The ray meets beta at $R$ in the first tree, with score
$s(R)+1=3$, and alpha at $RL$ in the second, with score
$s(RL)=3$. For $P=\{R\}$ the relative menu is
$\{\varepsilon\}$, distinguishing $\mathsf B$ from
$\mathsf{Pair}(\star,\star)$. For $P=\{RL\}$ it is $\{L\}$,
which fails the strict-left condition because $L$ itself is selected.
Beta is absent there, while a branch with alpha left child gives
alpha, and their forms remain distinct. The first sampled ray misses
$[RR]$; in the second task it meets $[RLR]$ but still misses the
required parent-right cylinder $[RR]$. These are exactly the two
obstructions in [AAR, Example 11.5]. A common path context preserves
the local initial values because every path ancestor is an actual
branch. $\square$

**Proposition 9.2 (a sparse initial vector loses a future distinction).**
For $D\ge2$, $P=\{RL\}$ and
$t=\langle\alpha,\alpha\rangle$, $t'=\langle\alpha,\beta\rangle$,
the initial selected vectors agree but their count-one vectors differ.

Proof. Initially $RL$ is absent in both trees. After one update the
right subtree of $t$ is beta, so $RL$ is still absent. The right
subtree of $t'$ is $\langle\beta,\alpha\rangle$, so $RL$ is beta.
On the relative menu $S=\{L\}$ the first branch counts are three
and two and the forms are $\mathsf A$ and $\mathsf B$.
Thus the optimal code preserves the distinction discarded by the
initial selected values. This is [AAR, §11.7]'s example and a case
of Theorem 7.2. $\square$

**Proposition 9.3 (equal optimal codes do not determine hidden equality
or the source).** Set

$$
\begin{aligned}
X&=\langle\alpha,\alpha\rangle,&
Y&=\langle\beta,\alpha\rangle,\\
t&=\langle\alpha,\langle X,X\rangle\rangle,&
t'&=\langle\alpha,\langle Y,X\rangle\rangle.
\end{aligned}
\tag{FM.35}
$$

Both sources lie in $\mathcal F_2$. Their optimal codes agree for
$P=\{RL,RR\}$ and also for $P=A_2=\{R,RL,RR\}$. Every selected
value is branch at every count. Nevertheless their complete rows for
the prefix-free cut $\{RL,RR\}$ have different hidden equality
partitions at every common count, and the sources are different.

Proof. Each right subtree has height two. On $S=\{L,R\}$, both
selected child roots are branches in both sources, and each child
form on $\{\varepsilon\}$ is $\mathsf{Pair}(\star,\star)$.
The whole forms therefore agree. Adding $\varepsilon$ to $S$ adds
only their common branch root value. Branches persist, so all these
values remain branch forever.

For clarity, a complete cut row retains the literal exterior with
addressed holes, concrete blockers for unreached cut words, and every
equality and disequality between reached hidden subtrees, as in [AAR,
Definition 1.2]. Here both cut words are reached. At count zero the
common exterior is
$\langle\alpha,\langle\square_{RL},\square_{RR}\rangle\rangle$.
In $t$ the holes contain equal $X$ copies; in $t'$ they contain
$Y$ and $X$.

At count $k$, the hidden pairs are respectively
$(\rho^k X,\rho^k X)$ and $(\rho^k Y,\rho^k X)$. To prove the
latter unequal at every count, define

$$
c(\alpha)=0,\quad c(\beta)=1,\quad
c(\langle x,y\rangle)=2+c(y).
$$

Structural induction gives $c(\rho u)=c(u)+1$: the alpha case is
$1=0+1$, the beta case is $2+c(\alpha)=1+1$, and the branch case
uses the induction hypothesis for its right child. Hence $c(T_n)=n$.
The left children of $\rho^k Y$ and $\rho^k X$ are $T_{k+1}$ and
$T_k$, whose distinct clocks prove they are different. The row
exteriors remain identical, now with $T_k$ at $L$, while the
partitions remain different.

This also preserves [AAR, Counterexample 11.9]'s ray-table witness.
For $Q=\{RLR^\infty,RRR^\infty\}$ the initial scores are five and
six in both sources, from the common alpha leaves at $RLR$ and
$RRR$. The rays satisfy (FM.34), including after $R$ is added to
the menu. Thus both the sufficient table and the optimal task code
fail to recover the complete row or full source. $\square$

**Proposition 9.4 (the supplied count cannot be omitted).** For every
nonempty $P\subseteq A_D$, no passive decoder with only initial
source-dependent state and the public $D,P$ can recover all future
$P$-vectors without a count or new source-bearing input, even if it
retains the entire initial tree.

Proof. Fix the same initial source
$t_0=\langle\alpha,\alpha\rangle$ and any $q\in S$. Let
$b=s(q)+2$. At the two authentic continuations with counts $b-1$
and $b$, Lemma 3.2 gives respectively beta and branch at $Rq$.
With no count or other new source-bearing input, the passive
decoder's entire input is identical in these two histories, even
when it includes $t_0$. Its required outputs differ. Determinism
rules out the proposed decoder. $\square$

Saturation permits a consumer supplied with a sufficiently large
count to ignore its exact excess for this value-only output. It
does not discover that a threshold was reached. Nor do selected
values identify the epoch: by Corollary 3.5 every count at least
$B(S)$ has the same all-branch vector. Exact count storage or a
losslessly translated nonempty ray table has a different unbounded
range of values. These facts preserve the count distinction in
[AAR, Propositions 11.7 and 11.10].

## 10. Conditional native capture and the cost of a clean handoff

**Proposition 10.1 (guarded acquisition of an initial code).** Suppose
an initial $\mathcal F_D$ version is available for native acquisition.
Read $L$ as alpha, acquire the full finite tree by literal traversal,
and reread $L$. Conditional on the two guard replies being alpha,
the acquired tree and its canonical code describe one actual version
at the final guard Read. On a stationary initial $\mathcal F_D$
source the procedure terminates and succeeds. With the complete
cleanup condition of Definition 2.4, it realizes the retained payload
of Theorem 6.4. It asserts no guarantee of obtaining such an initial
capture after an unprotected writer has already changed $L$.

Proof. At an actually observed alpha leaf, the fixed address's future
root replies are alpha, then beta, then permanently branch. These
follow directly from (FM.1), with transport through its initial
branch ancestors. Equal alpha guards therefore exclude every
update between the two observations. A traversal submitting each
present literal, descending into both children only after a branch
reply, acquires exactly the one stationary finite tree during a
successful guarded body. The final guard Read is a common validation
of its structure and leaf labels. The given initial family condition
then holds at that capture.

Compute the normal form and its rank from the acquired data. Export
only the fixed-width code in a fixed public region. Clear or retract
the full acquired tree, guard records, operand and traversal buffers,
reply latches, temporary outputs, counters and all nonpublic control
or allocation distinctions. The complete interface is obtained only
if no additional transcript, metadata or other source-bearing state
remains accessible through the host. Inaccessible residual bytes
remain a physical storage cost. These are the same complete-state
conditions used by the lower bound.

For a successful full traversal of $t$, with each present node
visited once in its body, the actual query account is exactly

$$
T=|\operatorname{Pos}(t)|+2,\qquad
A=\sum_{p\in\operatorname{Pos}(t)}|p|+2,\qquad
Q_{\mathrm{operand}}=\operatorname{height}(t)\le D+1.
\tag{FM.36}
$$

The two extra literals are the guards $L$. Since $t\in\mathcal F_D$
has height at least one, they do not increase the maximum operand
length. Constructing and submitting every complete word, storing
the acquired tree and code, computing the rank, and clearing all
temporary regions are additional finite paid work. Any unsuccessful
attempt's actual queries and work are added to these costs; they
are not hidden in the successful formula. No acquisition or workspace
optimality is asserted.

The historical capture is the final guard Read, not Return or the
end of cleanup. Updates during later encoding or cleanup do not
change the historical tree that the code represents; the supplied
$k$ must include all updates from that actual capture. If the writer
has changed $L$ before a successful guarded interval, alpha never
returns there. The procedure therefore supplies no unprotected
initial-capture liveness theorem. $\square$

This is a conditional realization of the encoder, consistent with
[AAR, Proposition 11.8]. The later service proved in that reference
can separately acquire a count by actual leaf Reads along
$L,LR,LR^2,\ldots$ using the originally validated alpha at $L$.
Its acquisition, operands and capture-origin requirements remain
additional obligations. Passive prediction in Theorem 6.4 does not
include that service or its costs.

## 11. Operation boundaries and remaining questions

**Proposition 11.1 (the initial family is not update-invariant).** For
every $t=\langle\alpha,v\rangle\in\mathcal F_D$,
$\rho t\notin\mathcal F_D$.

Proof. Formula (FM.1) gives
$\rho t=\langle\beta,\rho v\rangle$. Its left child is beta,
whereas every member of $\mathcal F_D$ has left child alpha.
$\square$

The structural recursion on $S$ and the initial tree establishes
normalization, rank/unrank, representative choice and supplied-count
evaluation. Each of these operations has its own proof above. This
does not by itself provide an observer's arbitrary-operation algebra,
an in-family update service, rerooting, unrestricted menu expansion
or rebasing to a new capture. In particular changing the capture
changes the meaning of the count unless an origin relation is
separately retained and justified. The lack of update invariance is
not a failure of the decoder: it evaluates the unbounded continuation
from the fixed initial code without asserting a new initial-family
membership for the current tree.

The output remains a literal-value vector at the promised version.
Producing it creates no actual Read events at its targets. A later
Read can occur after further updates. A task requiring simultaneous
actual observations must acquire and validate that body with its own
paid operations. Likewise, a complete exterior with its equality
partition has a different information requirement, as Proposition 9.3
demonstrates. Neither the code nor clock agreement authenticates the
same-register premise, an external origin, or the placement of
unobserved events.

**Open problem 11.2 (resource optima outside initial payload).**
Determine exact costs for forming and using the minimal code when
native query count, total operand letters, maximum operand length,
public installation, local bit work, transient workspace and cleanup
are jointly charged. Theorem 6.4 optimizes only the initial reachable
state count and fixed payload width. Proposition 10.1 supplies one
conditional finite acquisition procedure, not a joint optimum or
an interference-optimal procedure.

**Open problem 11.3 (broader recovery interfaces).** Determine the
corresponding frontiers for all-source families, unknown future menus,
source-dependent ray selection with charged selection information,
complete-row acquisition, hidden equality and full-source recovery.
For changes of reference or capture, specify and prove the needed
common-history relation and every supported operation. The finite
supplied-count theorem does not settle these tasks or the broader
programme relating spatial, temporal, boundary and memory
descriptions. [AAR, Open problems 9.4 and 11.12] retain these broader
resource and interface questions.
