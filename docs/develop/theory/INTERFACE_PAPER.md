## 摘要

我们引入**命名系统**(可数名集经部分赋值映入连续统)与其**界面**(该嵌入的渐近几何),并系统研究界面的六项不变量:速度、硬度、恰点集、暗面测度、层谱与边界。主要结果:(一)**逃逸率恰式**(定理 3.4):在有限自应用片段中,设名集规模 |A| = A、值域 |Y| = n、扭 f: Y → Y 有 k 个不动点,则对角构造 d_g(a) = f(g(a)(a)) 逃逸随机清单 g: A → Y^A 的概率恰为 (1 − k n^{−A})^A;此为 Lawvere 不动点定理的定量化,并给出 Poisson 极限、渐近全逃逸与稠密不动点相变等推论。(二)**距离向量独立与等变大一统**(定理 3.7–3.9):对角点至诸名之距离联合独立、分布闭式;任意群对称下逃逸率 = ∏(1 − k/n^{ω_i})(按稳定子轨道折算火力);对角点以线性边距、典型轮廓逃逸。(三)**冠军表**(定理 4.2′):奇 b 塔之硬度上确界恰为 1/2 由 x = 1/2 达成;偶 b 塔恒臂族 (b/2)/(b+1)(b = 2 予经典 1/3);"每塔各有其贵族"共变猜想据此修订。(四)**暗面守恒**(定理 5.1):任何可数命名塔逐层不改变匿名集之满测度。(五)**税表闭式**(定理 5.4–5.5):普适量子克隆机之机器熵恰为 log₂3 − 2/3 比特,Haar 平均测量记录熵恰为 1/(2 ln 2) 比特,由此拟合"保真–擦除价"三点单调曲线。(六)**解析二分与恰点星座**(定理 6.1;计算机辅助结果 6.4):参数族上的恰关系或恒成立或孤立;对幂均值曲率泛函 J(p) 给出五个闭式值(五个全部完全证明(其二经符号积分)),及负向证据下的星座有限性猜想。全文严格区分完全证明([证])、计算机辅助([机验],附精度)与猜想([猜])。

## 2. 定义

**定义 2.1(命名系统)。** 命名系统为四元组 𝒩 = (N, X, ν, h),其中:X 为不可数 Polish 空间,携无原子 σ-有限测度类 μ;N 为可数集(**名**);ν: N ⇀ X 为部分映射(**赋值**);h: N → ℕ 满足 N_Q := {n ∈ N : h(n) ≤ Q} 对每一 Q 有限(**高度滤链**)。

**例 2.2。** (a) 有理塔:X = ℝ,N = {p/q},h = q,ν 为含入;(b) 二进塔:X = [0,1],N = 二进有限小数,h = 位长;(c) 形式算术:X = 真算术语句集之 Stone 空间侧,N = 证明,ν = 结论映射(部分性反映不可判定);(d) 量子记录:X = 纯态流形,N = 有限测量记录。

**定义 2.3(界面)。** 𝒩 之**界面** 𝕀(𝒩) 为 X 上由滤链 {ν(N_Q)}_Q 诱导之渐近结构,含以下不变量:

1. **速度**:自应用片段中的逃逸率(第 3 节);
2. **硬度**:β(x) := liminf_Q w(Q) · dist(x, ν(N_Q)),其中 w 为塔之自然归一(有理塔 w = q²,二进塔 w = 2^Q);
3. **恰点集**:参数化量族在给定常数基下取闭式值之参数集(第 6 节);
4. **暗面**:X ∖ ν(N) 及其测度(第 5 节);
5. **层谱**:按 ν 之定义资源分层(定义 5.2);
6. **边界**:结构失效条件(第 7 节)。

**定义 2.4(自应用片段)。** 若另有有限集 A, Y,称映射 g: A → Y^A 为一张**清单**(A 中每名 a 命名一个函数 g(a): A → Y)。给定**扭** f: Y → Y,**对角构造**为 d_g ∈ Y^A,d_g(a) := f(g(a)(a))。称 g 被**逃逸**若 d_g ∉ g(A)。

此片段中 Lawvere 定理 [Law69] 的定性形式为:若 f 无不动点,则每张清单被逃逸(Cantor、Gödel、Tarski、Turing 论证之共同抽象)。下节将其定量化。

## 3. 主定理:逃逸率恰式

以下固定 |A| = A ≥ 1,|Y| = n ≥ 1,扭 f 有 k = |Fix(f)| 个不动点。清单全体 𝒢 = (Y^A)^A,|𝒢| = n^{A²}。

**引理 3.1(落点引理)。** 若 g(a₀) = d_g,则 g(a₀)(a₀) ∈ Fix(f)。

*证明。* 在坐标 a₀ 处取值:g(a₀)(a₀) = d_g(a₀) = f(g(a₀)(a₀))。∎

**引理 3.2(交计数)。** 对任意 S ⊆ A,|S| = s ≥ 1,有
$$ \#\{g \in \mathcal{G} : \forall a \in S,\ g(a) = d_g\} = k^{s}\, n^{A(A-s)} .$$

*证明。* 构造双射至参数集 Fix(f)^S × (Y^A)^{A∖S}。给定参数 (v, (g_a)_{a∉S}):定义 d ∈ Y^A 为 d(a) := v(a)(a ∈ S),d(a) := f(g_a(a))(a ∉ S);再令 g(a) := d(a ∈ S),g(a) := g_a(a ∉ S)。验证 d = d_g:当 a ∈ S,d_g(a) = f(g(a)(a)) = f(d(a)) = f(v(a)) = v(a) = d(a)(因 v(a) ∈ Fix(f));当 a ∉ S,d_g(a) = f(g_a(a)) = d(a)。故 g(a) = d = d_g 对 a ∈ S 成立。反之,任一满足事件之 g 唯一给出参数:v(a) := g(a)(a)(a ∈ S;由引理 3.1 落于 Fix(f),且 g(a) = d_g 迫使 S-列全等于公共函数 d_g,其 S-坐标为 v),自由列为 (g(a))_{a∉S}。两向互逆。∎

**注 3.3。** 引理 3.2 之右端与 S 之选取无关,仅依 |S|;且当 s = A 时给出 k^A(全体列相等且为不动点向量之情形)。

**定理 3.4(逃逸率恰式)。** 被逃逸清单数为
$$ N_{\mathrm{esc}}(n, A, k) = (n^A - k)^A, $$
故均匀随机清单被逃逸之概率恰为
$$ P_{\mathrm{esc}} = \left(1 - \frac{k}{n^{A}}\right)^{A}. $$

*证明。* 由含入–排出与引理 3.2,
$$ N_{\mathrm{non}} = \sum_{s=1}^{A} (-1)^{s+1} \binom{A}{s} k^s n^{A(A-s)} = n^{A^2} - \sum_{s=0}^{A} \binom{A}{s} (-k)^s (n^A)^{A-s} = n^{A^2} - (n^A - k)^A. $$
∎

**定理 3.4′(隐藏独立性)。** 捕获事件 E_a := {g(a) = d_g}(a ∈ A)在均匀清单测度下**联合独立**,各以概率 k/n^A 发生;定理 3.4 即其一行推论 P(∩E_a^c) = (1 − k/n^A)^A。

*证明。* 引理 3.2 给出一切有限交之测度 (k/n^A)^{|S|},即独立性之定义。∎(穷举核验于 (n,k) 诸配置至三重交,恰合 [机验]。)

**定理 3.8(距离向量独立定理)。** 令 D_a := dist_H(g(a), d_g)。则随机向量 (D_a)_{a∈A} **联合独立**,且每一 D_a 分布为 Bern((n−k)/n) + Bin(A−1, (n−1)/n) 之独立和。由此:P(∀a: D_a ≥ r) = (1 − p_r)^A,其中 p_r = P[D < r];r = 1 退化为定理 3.4/3.4′。

*证明(启示论证)。* 分两步揭示均匀随机清单 g。第一步揭示对角值 X_a := g(a)(a)(a ∈ A):iid 均匀于 Y;此时 d_g = f∘X 完全确定,且对角失配指示 1[X_a ∉ Fix f] 为 iid Bern((n−k)/n)。第二步揭示非对角格 g(a)(a′)(a ≠ a′):A(A−1) 个全新 iid 均匀值,与第一步独立;格 (a, a′) 之失配指示 1[g(a)(a′) ≠ f(X_{a′})] 因 g(a)(a′) 独立均匀而为 Bern((n−1)/n),且诸格两两独立、与对角项独立。故 A² 个失配指示联合独立;D_a 为按行求和,行间无共享格,独立性与分布皆得。∎(穷举核验:联合分布对乘积之最大偏差为 0,诸配置 [机验];该核验现仅为冗余保险。)

**注 3.5(检验)。** 公式经穷举验证于 (n, A) ∈ {2,3,4} × {2,3} 之全部 17 组 (k)-层(附录 A.1),无一例外;含 n = 3, A = 3, k = 1 之 2107/19683 等。[机验·穷举恰合]

**推论 3.6。** (i)(定性 Lawvere)k = 0 ⟹ P_esc = 1;(ii)(单调性)P_esc 关于 A 单调不减,A = 1 时为 1 − k/n;**小清单是有不动点之扭的唯一庇护所**;(iii)(渐近全逃逸)n ≥ 2 固定、A → ∞ 时 P_esc → 1:对角线的统治在大清单极限中普适;(iv)(Poisson 域)k A n^{−A} → λ 时 P_esc → e^{−λ};(v)(稠密相)k = c n^A(0 < c < 1)时 P_esc = (1−c)^A 指数衰减:不动点密度正比例时完备侧胜。

*证明。* 皆为恰式之直接分析。∎

**定理 3.7(等变逃逸大一统恰式)。** 设有限群 G ≤ Sym(A) 以坐标置换作用,清单限于等变者(g(σa) = g(a)∘σ⁻¹)。对每一 G-轨道 O_i 取代表 a_i,记 ω_i := Stab(a_i) 在 A 上之轨道数。则
$$ P^{\mathrm{eq}}_{\mathrm{esc}} = \prod_{i} \left(1 - \frac{k}{n^{\omega_i}}\right). $$
两极皆回收:G 平凡 ⟹ 每点一轨、ω_i ≡ A,得自由式 (1 − k/n^A)^A;G 传递 ⟹ 单因子 1 − k/n^ω。

*证明。* **常值引理**:等变性予 g(σa)(σa) = g(a)(a),故对角在每一轨道上常值,d_g 在 O_j 上恒取 c_j := f(X_j),X_j := g(a_j)(a_j)。**捕获刻画**:g(a) = d_g(a ∈ O_i)⟺ u_i := g(a_i) 逐块等于 (c_j)_j;在自身块上迫使 X_i = f(X_i) ∈ Fix f,其余 ω_i − 1 个 Stab(a_i)-轨道块被 (c_j) 唯一确定。**条件启示**:先揭诸 X_j(独立均匀),再揭 u_i 之非对角块(逐 i 不相交、独立均匀):给定 X,事件 E_i 条件独立且 P(E_i | X) = 𝟙[X_i ∈ Fix f]·n^{−(ω_i−1)};对 X 取期望,因 𝟙[X_i ∈ Fix] 相互独立,得 P(∩E_i^c) = ∏(1 − (k/n)·n^{−(ω_i−1)}) = ∏(1 − k/n^{ω_i})。∎

*实证*(穷举恰合):传递三例——正则 ℤ₃:8/9;正则 ℤ₄:14/16;非正则 S₃(ω = 2):6/9,且被捕清单恰为 Fix-常函数三张;非传递双轨(ℤ₂ 于 {0,1} ⊔ {2},ω = (3, 2)):12/32 = (1 − 2/8)(1 − 2/4)。[机验] **判词:对称按"稳定子轨道数"折算每一轨道的命名火力,再按轨道连乘**。

**定理 3.9(线性边距)。** 沿定理 3.8 之记号,对 0 < α < (n−1)/n:
$$ \Pr\left[\min_a D_a < \alpha A\right] \le A\, e^{-(A-1)\, \mathrm{KL}\left(\alpha \middle\| \tfrac{n-1}{n}\right)} \to 0, $$
故对角点渐近几乎必以线性边距逃逸,且边距密度趋于典型值 (n−1)/n:**对角点不仅逃逸,且以典型点的距离轮廓逃逸**。*证明*:D_a 独立(定理 3.8),单项 Chernoff,联合界。∎(A = 12 实测集中带 [0.17, 0.42]·A [机验]。)

**注 3.5(检验)。** 公式经穷举验证于 (n, A) ∈ {2,3,4} × {2,3} 之全部 17 组 (k)-层(附录 A.1),无一例外;含 n = 3, A = 3, k = 1 之 2107/19683 等。[机验·穷举恰合]

**推论 3.6。** (i)(定性 Lawvere)k = 0 ⟹ P_esc = 1;(ii)(单调性)P_esc 关于 A 单调不减,A = 1 时为 1 − k/n;**小清单是有不动点之扭的唯一庇护所**;(iii)(渐近全逃逸)n ≥ 2 固定、A → ∞ 时 P_esc → 1:对角线的统治在大清单极限中普适;(iv)(Poisson 域)k A n^{−A} → λ 时 P_esc → e^{−λ};(v)(稠密相)k = c n^A(0 < c < 1)时 P_esc = (1−c)^A 指数衰减:不动点密度正比例时完备侧胜。

*证明。* 皆为恰式之直接分析。∎

**定理 3.7(等变逃逸恰式;三例穷举 + 证明纲要)。** 设传递群 G ≤ Sym(A) 以坐标置换作用于清单空间,等变清单由 u := g(a₀) ∈ Y^A 之 Stab(a₀)-不变性刻画,即 u 因子化经 Stab(a₀)-轨道空间,自由度 n^ω,ω := Stab(a₀) 在 A 上之轨道数。则等变系综之逃逸率为
$$ P^{\mathrm{eq}}_{\mathrm{esc}} = 1 - \frac{k}{n^{\omega}} . $$
*纲要与实证。* 传播:等变性使捕获沿 G-轨道全域传播,A 个捕获事件塌缩为单事件(相关系数恰 1 [机验]);约化落点:事件内 u(a₀) ∈ Fix f 予因子 k,其余轨道坐标被事件确定。实证三例:正则 ℤ₃(ω = 3):8/9 = 1 − 3/27;正则 ℤ₄(ω = 4):14/16 = 1 − 2/16;**非正则 S₃**(Stab(0) = ⟨(1 2)⟩,ω = 2):6/9 = 1 − 3/9。[机验·穷举三例] 对比自由系综 (1 − k/n^A)^A:**对称将 A 次独立捕获机会塌缩为一次,且约化命名空间由稳定子轨道计数**。一般(含非传递)情形与纲要之双射化列为开放问题 8.3′。

## 4. 硬度与恒定臂距

**定义 4.1。** 塔之**硬度谱**为 {β(x) : x ∈ X};β(x) > 0 者称**恶劣可逼近**。有理塔中 sup 归一下 β 之上确界结构即 Lagrange–Markov 谱 [Mar79, CF89],其底为 1/√5,由 x ∼ φ(连分数尾全 1)达成 [Hur91]。[典]

**命题 4.2(二进恒定臂距)。** 二进塔中,对一切 Q ≥ 1:
$$ 2^{Q}\, \mathrm{dist}\!\left(\tfrac13,\ D_Q\right) = \tfrac13, \qquad D_Q = \{m 2^{-Q}\}. $$

*证明。* |1/3 − m/2^Q| = |2^Q − 3m| / (3 · 2^Q)。因 gcd(3, 2) = 1,2^Q ≢ 0 (mod 3),故 min_m |2^Q − 3m| = 1,距离恰为 1/(3·2^Q)。∎

**注 4.3。** 1/3 的二进展开为周期尾 0101…,恰为二进塔上"最简周期尾";黄金比之连分数尾全 1 为有理塔之对应物。随机点之归一距离在 [0, 1/2] 近均匀分布(实测中位 0.249 对预言 0.25,Q = 16,2×10⁴ 样本 [机验]),liminf 几乎必为 0:典型点与名时贴时离,而champion 独守恒定臂距。

**定理 4.2′(b-进冠军表)。** (i) 一切 b ≥ 2:b^Q·dist(1/(b+1), D_Q) ≡ 1/(b+1)(因 b ≡ −1 (mod b+1));(ii) **奇 b**:sup_x liminf_Q b^Q dist(x, D_Q) = **1/2**,由 x = 1/2 达成(b^Q 奇 ⟹ 距最近 b-进名恒为半格;上界 1/2 平凡);(iii) **偶 b**:x = (b/2)/(b+1) 恒臂 b/(2(b+1))(同 (i) 之同余论证;b = 2 予经典 1/3)。

## 6. 解析二分与恰点星座

**定理 6.1(解析二分)。** 设 P ⊆ ℝ 为区间,F: P → ℝ 实解析,B ⊂ ℝ 有限。若关系 F(p) ∈ span_ℚ B 不恒成立于任一子区间,则对每一固定 (q_i) ∈ ℚ^{|B|},集 {p : F(p) = Σ q_i b_i} 于 P 离散。

*证明。* 实解析函数之非恒零者零点孤立(唯一性定理)。∎

**注 6.2。** 此平凡观察的价值在其解释力:参数族上"整洁恰关系"必二分为**定律**(恒成立)或**特权**(孤立),不存在中间形态;寻找反例须离开解析范畴。

**案例研究:幂均值曲率泛函。** 对 p ∈ ℝ 定义
$$ J(p) = \int_0^1 \frac{1-t}{t^2} \left[ \frac{1}{2 M_p\!\left(\frac{1+t}{2}, \frac{1-t}{2}\right)} - \frac{1}{1-t^2} \right] dt, \tag{6.1} $$
其中 M_p 为幂均值(M₀ = 几何均值)。此泛函出自算子均值单调度量族之山腰曲率理论(项目内部编号 C3;其算子论背景非本文所需,(6.1) 自足)。

**定理 6.3。** J(1) = −ln 2;J(0) = 1 − 2 ln 2;J(−1) = 0。

*证明。* p = 1:M₁ = 1/2,被积化为 −1/(1+t),积分 −ln 2。p = 0:2M₀ = √(1−t²) =: s。因 s² = 1 − t²,括号 = 1/s − 1/s² = (s − 1)/s²,故被积 = −(1−t)/[(1−t²)(1+s)] = −1/[(1+t)(1+s)]。代换 t = sin θ:被积 = −cos θ/[(1+sin θ)(1+cos θ)],初等原函数存在;定积分 = 2 ln 2 − 1(常规计算,数值核验 10⁻⁵² [机验];细节见附录 B.1)。p = −1:调和均值 M₋₁((1+t)/2, (1−t)/2) = (1 − t²)/2,故 2M₋₁ = 1 − t²,括号恒零。∎

**定理 6.4(新恰式两枚)。**
$$ J(1/2) = \frac{5 - 12 \ln 2}{6}, \qquad J(-1/2) = \frac{1 - 2\ln 2}{2}, \tag{6.2} $$
并满足仿射关系 J(1/2) = (5/6)J(0) + (1/3)J(1),J(−1/2) = J(0)/2。

*证明。* p = −1/2:2M = 2s²/(1+s),括号 = (1+s)/(2s²) − 1/s² = (s−1)/(2s²),恰为 p = 0 情形括号之半,故 J(−1/2) = J(0)/2(符号复核比值 ≡ 1/2)。p = 1/2:2M = (1+s)/2;经 Weierstrass 代换 t = 2u/(1+u²)、s = (1−u²)/(1+u²) 被积化为 u 之有理函数,符号积分得 J(1/2) = 5/6 − 2 ln 2(零差)。∎(机制:两参数处 M_p 为 s-圆锥之有理函数,故必初等且常数属 {1, ln 2} 类。)

**负向证据 6.5。** p ∈ {1/3, 2/3, 3/2, ±2, ±3, 4} 于诸原理基(含 {1, ln2, ln3};对 p = ±2 含 {1, ln2, ln(1+√2), √2, π, arctan√2} 之十元基,容差 10⁻⁴⁵、系数 ≤ 60)内均无 PSLQ 关系。[机验·缺席系证据非证明] 另记:一次五元基、容差 10⁻¹⁶ 之大系数"命中"经 80 位复核判为伪(残差 10⁻¹⁶ ≠ 10⁻⁴⁰),据此本文采用**扩基一次性与系数封顶**之防伪协议。

**猜想 6.6(星座有限)。** (6.1) 之 {1, ln 2}-恰点集恰为 {−1, −1/2, 0, 1/2, 1},即 M_p 可被 s-圆锥有理化之全体参数。[猜;机制 6.4 + 负向证据 6.5]

**注 6.7(c\* 之定义方程)。** 同一理论中,常数 c\* 由下式唯一确定(I₃(c) = (2/√(1−2c)) artanh √(1−2c) − ln(1/c)/(1−c)):
