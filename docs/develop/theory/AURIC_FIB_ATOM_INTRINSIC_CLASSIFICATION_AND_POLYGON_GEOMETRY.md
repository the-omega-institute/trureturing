## 2. 从三条距离到有向三角响应

**定义 B-2.1（共同标定的局部模型）。** 在一个实欧氏平面中，已知 $`a=\|u\|`$、$`b=\|v\|`$、$`c_-=\|u-v\|`$。定义


<table><tbody><tr><td>

```math
g(u,v)=\frac{a^2+b^2-c_-^2}{2}=\langle u,v\rangle.
```

</td></tr></tbody></table>


若 $`a,b\gt 0`$，定义 $`\chi_{\rm ang}=g/(ab)`$。锐、直、钝关系分别为 $`g\gt 0,g=0,g\lt 0`$；共同换长度单位 $`\lambda\gt 0`$ 后 $`g`$ 乘 $`\lambda^2`$，$`\chi_{\rm ang}`$ 不变。零向量仍有内积与面积，但没有此归一化角度。共同标定与观察关系的约定采用 [B-S8] 定义2.1、假设2.2的内部标架接口。

**命题 B-2.2（几何缩并所用的角度桥）。** 对已记录的连续边 $`u=p_1-p_0`$、$`v=p_2-p_1`$，缩并弦是 $`u+v`$，其长度 $`c_+=\|u+v\|`$ 满足


```math
g(u,v)=\frac{c_+^2-a^2-b^2}{2}.
```


顶点 $`p_1`$ 的两条外发射线是 $`-u,v`$；若二者非零且顶点凸，其内角 $`\theta`$ 满足 $`\cos\theta=-g/(ab)`$。因此共同原点的差弦、连续边的和弦、顶点内角使用不同的符号。

证明。展开 $`\|u\mp v\|^2=a^2+b^2\mp2\langle u,v\rangle`$，再用 $`\langle-u,v\rangle=-g`$。直线退化时面积为零；内角的凸域说明不把无向 $`\arccos`$ 用来区分反角。∎

**命题 B-2.3（缩并响应的标定与边长任务，复用 [B-S2] §§49–50的经典工具）。** 在固定定向正交基下，令


```math
\tau(u,v)=\frac12\det(u,v),\qquad
4\tau^2=a^2b^2-g^2.
```


它是折线 $`p_0p_1p_2`$ 换成弦 $`p_0p_2`$ 时旧有向面积减新有向面积。三条有效边长 $`a,b,c`$ 满足严格三角不等式时，三角形在欧氏等距（含镜像）下唯一，绝对面积唯一，并有


<table><tbody><tr><td>

```math
16A_\triangle^2
=2a^2b^2+2b^2c^2+2c^2a^2-a^4-b^4-c^4.
```

</td></tr></tbody></table>


若 $`E=a^2+b^2+c^2`$ 固定，则


```math
E^2-48A_\triangle^2
=2\bigl[(a^2-b^2)^2+(b^2-c^2)^2+(c^2-a^2)^2\bigr],
\qquad A_\triangle\le\frac E{4\sqrt3},
```


等号恰为等边。任意分别双线性、交错的平面响应 $`\omega`$ 都形如 $`\omega(u,v)=\omega(e_1,e_2)\det(u,v)`$。

证明。若 $`u=(u_1,u_2)`$、$`v=(v_1,v_2)`$，展开得到 $`\det(u,v)^2=\|u\|^2\|v\|^2-\langle u,v\rangle^2`$。鞋带式中被替换两边减去新边，等于 $`\det(p_1-p_0,p_2-p_1)/2`$。共同原点三角形可经等距把 $`u`$ 置为 $`(a,0)`$；三边给 $`g=(a^2+b^2-c^2)/2`$，于是 $`v=(g/a,\pm\sqrt{b^2-g^2/a^2})`$。严格三角不等式使根号正，两号由镜像互换，证明形状唯一的准确范围；绝对位置、定向与来源不由此恢复。将 $`c=\|u-v\|`$ 代入并展开，得到 Heron 多项式形式；再展开 $`E^2`$ 得预算式。双线性展开 $`\omega`$ 后，同方向项为零，交叉项互为负号，得唯一尺度。此处的 Gram、Heron 与交错形式是经典中间工具，承担已记录边界的响应标定，不主张它们是新发现。∎

**命题 B-2.4（边长不充分的最小反例，复用 [B-S2] §51）。** 一个或两个点的凸包面积为零，三个非共线点的面积为 $`|\det(B-A,C-A)|/2\gt 0`$。但边长同为 $`\ell\gt 0`$ 的菱形面积为 $`\ell^2\sin\theta`$，$`0\lt \theta\lt \pi`$；取 $`\theta=\pi/2`$ 与 $`\pi/6`$ 得面积 $`\ell^2`$ 与 $`\ell^2/2`$。

证明。前两种凸包的仿射维数至多一，第三种的两个差向量独立。菱形由两条长度 $`\ell`$ 的向量张成，其行列式绝对值给公式。故三边的刚性、二维最小性与跨多边形的效率比较是不同任务；后一任务须先声明预算。∎

## 3. 规则性、定向、凸凹与直角反射

**定义 B-3.1（正多边形及局部转向）。** 对 $`N\ge3,R\gt 0`$，给已标定中心 $`O`$，按圆周次序连接


```math
v_j=O+R\left(\cos\frac{2\pi j}{N},\sin\frac{2\pi j}{N}\right),
\quad 0\le j\lt N,
```


得到简单凸正多边形。规则性指等边、等角；定向指边界遍历次序；凸性指所有两点间的线段在区域内。对一般简单非退化多边形，记 $`p_N=p_0`$、$`e_i=p_{i+1}-p_i`$、


```math
\mathcal{\text{𝒜}}(P)=\frac12\sum_i\det(p_i,p_{i+1}),\qquad
\sigma=\mathrm{sign}\mathcal{\text{𝒜}}(P).
```


在 $`p_i`$ 比较入边 $`e_{i-1}`$ 与出边 $`e_i`$。连续共线顶点另作退化，不以严格符号分类。

**命题 B-3.2（同一标定的分类与反向）。** 正 $`N`$ 边形的内角是 $`\theta_N=\pi-2\pi/N`$；$`N=3,4,\ge5`$ 分别为锐、直、钝，但均小于 $`\pi`$。简单多边形的凹顶点是内角 $`\gt \pi`$，不是 $`\gt \pi/2`$。在通常简单等边等角约定下不存在凹正多边形。反向遍历使 $`\mathcal{\text{𝒜}}`$ 及对应转向行列式同时反号，故 $`\sigma\det(e_{i-1},e_i)`$ 不变；可逆仿射变换保持区域凸性。

证明。凸 $`N`$ 边形剖分的内角和为 $`(N-2)\pi`$，等角给公式。简单多边形若所有内角相同，它们等于 $`(N-2)\pi/N\lt \pi`$，故无反角。逆时针简单边界的左转是凸、右转是凹；反向在同一个材料顶点把边对换为 $`(-e_i,-e_{i-1})`$，行列式为原值的负数，鞋带式也逐边反号。仿射映射 $`Lx+t`$ 保持凸组合，逆映射给双向等价。它不保持一般长度或角度。星形自交路径属于另一载体。∎

**命题 B-3.3（反射与补角只供应关系操作）。** 对 $`u\ne0`$ 定义


```math
R_u(v)=v-2\frac{g(u,v)}{\|u\|^2}u.
```


则 $`R_u^2=I`$、$`g(u,R_uv)=-g(u,v)`$、$`\|R_uv\|=\|v\|`$、$`\det(u,R_uv)=\det(u,v)`$。若 $`v\ne0`$，夹角变成 $`\pi-\theta`$；固定向量恰满足 $`g=0`$。相反，$`v\mapsto-v`$ 同时反转 $`g`$ 与有向面积。

证明。令 $`t=g/\|u\|^2`$，内积为 $`g-2t\|u\|^2=-g`$；范数平方为 $`\|v\|^2-4tg+4t^2\|u\|^2=\|v\|^2`$；行列式中的新增项是 $`-2t\det(u,u)=0`$。再次应用给原向量，非零向量的余弦公式给补角，包括共线的 $`0\leftrightarrow\pi`$。当 $`v=0`$ 仅代数式有意义。∎

**命题 B-3.4（三种角操作的不同背景）。** 局部平面集合补把区域楔角 $`\theta`$ 换成 $`2\pi-\theta`$。凸楔的外法向锥角为 $`\pi-\theta`$，仅在 $`0\lt \theta\lt \pi`$ 的凸域内使用。关系反射的 $`\pi-\theta`$ 不自动诱导全部正多边形之间的可逆映射；例如 $`60^\circ`$ 只变为 $`120^\circ`$，分别是正三角形与正六边形的内角。

证明。小圆周上区域与补区域的弧长角度合为 $`2\pi`$。凸楔的两条向外法向各转边线 $`\pi/2`$，其法向锥开角为外转角 $`\pi-\theta`$；凹顶点不能代入得到负锥角。反射保持具体补角参数，不能把任意钝角统一送到 $`60^\circ`$。∎

## 4. 局部三角核与整体拼接的准确条件

**定义 B-4.1（同一顶点集上的响应）。** 给每个合法有向三角形一个实响应 $`K(a,b,c)`$。对严格凸多边形的三角剖分，把各三角形同向响应相加。局部翻转条件是对按圆周次序的四个凸顶点要求


<table><tbody><tr><td>

```math
K(a,b,c)+K(a,c,d)=K(a,b,d)+K(b,c,d).
```

</td></tr></tbody></table>


对固定多边形只要求其顶点四元组；对全部凸多边形的定理才量化全部凸四元组。

**命题 B-4.2（缩并总响应的剖分充分性）。** 对固定严格凸顶点集，全部三角剖分的响应相同，当且仅当每个四元组满足定义B-4.1的翻转条件。鞋带三角核


```math
K(a,b,c)=\frac12[\det(a,b)+\det(b,c)+\det(c,a)]
```


满足此条件，并在任何已给合法一致定向的简单多边形剖分中给 $`\mathcal{\text{𝒜}}(P)`$。

证明。固定根顶点 $`a`$。若剖分不是以 $`a`$ 为根的扇形，其星形三角区与余区间至少共用一条内部边 $`bc`$。根侧三角形是 $`abc`$，另一侧是 $`bcd`$；严格凸性保证四点为凸四边形。把 $`bc`$ 翻成 $`ad`$，删去的边不接 $`a`$，新增边接 $`a`$，其余根边未删，故根的对角线条数严格增加。至多 $`N-3`$ 条后成为扇形；每次只改变一个四边形的两块三角形，翻转条件保持响应。必要性：任选四元组，在它的外侧各顶点区间固定同一剖分，内部选两条对角线；全响应相等消去相同外侧项，得到条件。若量化所有多边形，直接取四边形即可。

对面积核，内部每条有向边 $`ab`$ 与 $`ba`$ 成对出现，$`\det(a,b)+\det(b,a)=0`$，只留下外边界。因此翻转与剖分式均成立，凹域同样成立于已给合法剖分，而不是任意不合法扇形。无新增顶点时，设三角数 $`t`$、内部边数 $`d`$；每加一条合法内对角线，把一个区域分成两个，最终区域数为 $`d+1=t`$。边计数 $`3t=N+2d`$ 得 $`t=N-2`$。凸正多边形另加中心则是 $`N`$ 块。这里使用成熟的翻转结构 [B-L2]；[B-L3] 的着色限制不是本命题的动作菜单，其不连通结论不替代无着色翻转证明。∎

**命题 B-4.3（正方形测试的不足）。** 响应 $`K'(T)=\mathrm{Area}(T)^2`$ 在所有正方形上通过翻转测试，但在严格凸四边形 $`(0,0),(3,0),(2,1),(0,2)`$ 上失败。

证明。正方形两条对角线均给两块相等面积。所列四边形的连续转向均正；一条对角线给 $`3/2,2`$，另一条给 $`3,1/2`$，总面积同为 $`7/2`$，平方和却为 $`25/4`$ 与 $`37/4`$。因此特例测试不替代量化全部四元组的相容条件。∎

**假设 B-4.4（凹域的剖分合同）。** 一般简单凹多边形使用合法内对角线及耳切分，或直接提供一致定向剖分；它不允许从任意点向所有顶点作线。经典两耳定理的范围是至少四顶点的简单多边形，其耳三角内部在多边形内且不含其他顶点，见 [B-L4]。本卷只在已给合法剖分上使用命题B-4.2的边消去，不用文献名称授予实际操作。

## 5. 从记录边界的资源冲突产生五模式

**定义 B-5.1（开放缩并轮）。** 记录五个不同的连续顶点 $`p_0,\ldots,p_4`$、四条旧边 $`e_i=p_i-p_{i-1}`$。候选 $`C_i`$ 删除 $`p_i`$，用弦 $`p_{i-1}p_{i+1}`$ 替代两条旧边，$`i=1,2,3`$。同轮一条旧边最多消费一次。动作必须保证新旧整体边界简单、弦非退化、无未声明交叉或触碰；内删耳要求耳内部在旧区域内，外填凹口要求替弧构成声明的外部填补。联合 $`C_1C_3`$ 必须在同一旧边界上共同合法。对凸域，可用内部不交的耳；对有向链，可用边差的可加性，但后者不证明区域动作合法。

**命题 B-5.2（最小冲突结构及其计数）。** 当三个单动作和两端联合动作都合法时，选择恰为 $`\Sigma`$：$`C_1,C_2`$ 共享 $`e_2`$，$`C_2,C_3`$ 共享 $`e_3`$，$`C_1,C_3`$ 不共享旧边。四条开放边是同时存在冲突与独立动作对的最小长度。对仅受旧边不重复消费约束的 $`N`$ 条开放边，方案数


```math
D_0=D_1=1,\quad D_N=D_{N-1}+D_{N-2}
=F_{N+1},
```


前项为 $`1,1,2,3,5,8,13`$。四边的加权多项式为


```math
Z_4(w_1,w_2,w_3)=1+w_1+w_2+w_3+w_1w_3.
```


若首尾接缝也参与的四边环，方案是空、四个单动作、两对对边双动作，共七种。

证明。候选共享图是三点路径，其独立集只有所列五种；至多三条边时，至多两个候选且互相冲突。一般第一条边不消费时剩 $`N-1`$ 条，和第二条合并时剩 $`N-2`$ 条，两分支互斥穷尽，得递推及初值。权重逐方案相乘得多项式。闭环候选共享图为四环，其独立集数 $`1+4+2=7`$。路径独立集的 Fibonacci 计数是经典中间步骤 [B-L1]，标准索引的路径与环计数亦见 [B-L10] 页129–130；本卷将它消费为已记录几何资源的选择语言。若再加几何守卫，实际语言是这些方案的子集，计数不再无条件成立。四边环的双缩并甚至可能只留两条边，须区分有向链合同与非退化区域合同。∎

**命题 B-5.3（选择对应不等于来源更新对应）。** 映射 $`C_1\mapsto1,C_2\mapsto2,C_3\mapsto3,C_1C_3\mapsto13`$ 保持冲突与独立选择；它不强迫面积参数等于 $`2,3,5`$，不把缩并认作 $`\rho`$，也不把不缩并认作原生空窗口的恒等更新。

证明。面积随共同几何尺度平方变化，冲突图不变。原生空窗口仍更新 $`C'=SC`$、$`s'=0`$；几何空选择保持记录边界。取 $`C\ne0`$ 即可区分两种更新，故选择语法的同构没有推出动态同构。∎

## 6. 五模式平均几何及完整概率纤维

**接口 B-6.1（几何任务的概率输入）。** 五模式凸包 $`\mathcal{\text{𝒫}}`$、坐标体积 $`1/3`$、概率反解和四松弛量宽度使用 [A 卷 §2](AURIC_FIB_ATOM_OBSERVER_AND_ARITHMETIC_RELATIONS.md#2-三均值关联纤维与目标差分) 命题A-2.2–A-2.3。这里记 $`L=\kappa_-=\max(0,X+Y-r)`$、$`U=\kappa_+=\min(X,Y)`$、$`w=U-L`$；同一几何来源律在此完整闭纤维上变化。概率均值坐标的体积与几何区域面积、物理体积分别定型。

## 8. 原树的顺序面积估值与不能删除的来源

**定义 B-8.1（端点—面积估值）。** 另供定向实平面中的原子位移 $`u_\alpha=u`$、$`u_\beta=v`$。每片叶面积零，叶路径从零开始，按原树左叶到右叶读取；对其折线顶点 $`q_0=0,\ldots,q_m`$ 定义


```math
\mathbf{\text{𝐪}}=q_m,\quad A=\frac12\sum_{j=1}^m\det(q_{j-1},q_j),
\quad G(T)=(\mathbf{\text{𝐪}},A).
```


末点到原点的数学补弦贡献零，不是实际逆门。开放折线、自交、重走可用此代数面积；无重数区域面积只用于简单闭边界。此估值及拼接归 [B-S7] §§160–162、175；经典面积群律见 [B-L5] §3式(13)、§4。

**命题 B-8.2（被缩并记录实际消费的面积接缝）。** 若先走来源段 $`s`$ 再走平移后的段 $`t`$，则


```math
(\mathbf{\text{𝐪}},A)\star(\mathbf{\text{𝐫}},B)
=(\mathbf{\text{𝐪}}+\mathbf{\text{𝐫}},A+B+\tfrac12\det(\mathbf{\text{𝐪}},\mathbf{\text{𝐫}})).
```


此估值结合，且 $`2A=\sum_{i\lt j}\det(\xi_i,\xi_j)`$，其中 $`\xi_i`$ 是依叶序的逐步向量。命题B-7.4的内部面积记录恰保存被弦替换遗忘的接缝。

证明。把第二段每个顶点平移 $`\mathbf{\text{𝐪}}`$，面积新增


```math
\frac12\sum_j\det(\mathbf{\text{𝐪}},r_j-r_{j-1})
=\frac12\det(\mathbf{\text{𝐪}},\mathbf{\text{𝐫}}).
```


三段拼接的两种括号相等，因为


```math
\det(\mathbf{\text{𝐪}},\mathbf{\text{𝐫}})+\det(\mathbf{\text{𝐪}}+\mathbf{\text{𝐫}},\mathbf{\text{𝐬}})
=\det(\mathbf{\text{𝐫}},\mathbf{\text{𝐬}})+\det(\mathbf{\text{𝐪}},\mathbf{\text{𝐫}}+\mathbf{\text{𝐬}}).
```


取四点 $`0,\mathbf{\text{𝐪}},\mathbf{\text{𝐪}}+\mathbf{\text{𝐫}},\mathbf{\text{𝐪}}+\mathbf{\text{𝐫}}+\mathbf{\text{𝐬}}`$，其面积核的两种对角剖分恰给上述两边除二。因此在四点严格凸时，它是定义B-4.1的实际面积翻转；在其他域中仍是有向链恒等式，不授予不合法剖分。由 $`q_{j-1}=\sum_{i\lt j}\xi_i`$ 展开逐边面积，得叶对式。两步换弦丢失 $`\det(\xi_1,\xi_2)/2`$，恰是累计内部记录补回的量。此结合律只说明端点与面积不读括号，不授予对原树的重括号操作。∎

**命题 B-8.3（规范 FIB 来源的面积修正）。** 令 $`T_n=\rho^n\alpha`$，$`G(T_n)=(\mathbf{\text{𝐪}}_n,A_n)`$，$`d=\det(v,u)`$。有


```math
\mathbf{\text{𝐪}}_0=u,\quad \mathbf{\text{𝐪}}_1=v,\quad A_0=A_1=0,
\qquad \mathbf{\text{𝐪}}_{n+2}=\mathbf{\text{𝐪}}_{n+1}+\mathbf{\text{𝐪}}_n,
```


```math
A_{n+2}=A_{n+1}+A_n+\tfrac12\det(\mathbf{\text{𝐪}}_{n+1},\mathbf{\text{𝐪}}_n),
\qquad \det(\mathbf{\text{𝐪}}_{n+1},\mathbf{\text{𝐪}}_n)=(-1)^nd,
```


<table><tbody><tr><td>

```math
A_n=\frac d2\bigl(F_{n-2}+(-1)^n\bigr),\quad n\ge2.
```

</td></tr></tbody></table>


证明。保持有序配对的替换给 $`T_{n+2}=\langle T_{n+1},T_n\rangle`$，应用命题B-8.2得到两个递推。下一行列式为 $`\det(\mathbf{\text{𝐪}}_{n+1}+\mathbf{\text{𝐪}}_n,\mathbf{\text{𝐪}}_{n+1})`$，是原值负数，从初值 $`d`$ 归纳。$`A_2=d/2,A_3=0`$ 与显式式相合；Fib 项满足齐次递推，交替项的二阶递推余量正好为 $`(-1)^nd/2`$，归纳证明全部 $`n\ge2`$。$`d=0`$ 时全部面积为零，端点递推仍成立。∎

**命题 B-8.4（任意来源继续所需的计数）。** 对标准单位位移 $`u=(1,0),v=(0,1)`$，若组成为 $`(a,b)`$，原生替换的叶序是 $`\alpha\mapsto\beta,\beta\mapsto\beta\alpha`$，于是


```math
(a,b,A)\mapsto(b,a+b,-A-b/2).
```


一般任意校准的 $`(\mathbf{\text{𝐪}},A)`$ 不必足以继续 $`\rho`$；例如 $`u=v\ne0`$ 时，两原子估值相同，替换后的端点却为 $`v`$ 与 $`v+u`$。

证明。标准坐标直接线性运输顶点 $`M`$ 使面积反号。每片旧 $`\beta`$ 的弦 $`(1,1)`$ 必须改为先 $`(0,1)`$ 后 $`(1,0)`$ 的两步折线，内部面积为 $`-1/2`$，共 $`b`$ 片，得到修正。这是 [B-S7] 定理162.2的同源范围。一般 $`u=v`$ 的两原子都给 $`(u,0)`$，而 $`\rho\alpha=\beta`$、$`\rho\beta=\langle\beta,\alpha\rangle`$ 的端点不同，故不存在仅凭此摘要的普遍更新。若菜单包括该替换，应保留组成或原来源，并供应实际运输合同；不能从规范序列的闭式推广出任意校准的闭包。∎

## 9. 固定尺度下的多边形、圆与方向压缩

**命题 B-9.1（几何缩并标定的统一尺度，消费 [B-S2] §52）。** 在定义B-3.1中，边长 $`\ell=2R\sin(\pi/N)`$、内切半径 $`r_{\rm in}=R\cos(\pi/N)`$、周长 $`P=N\ell`$，有


<table><tbody><tr><td>

```math
\begin{aligned}
A_N&=\frac{NR^2}{2}\sin\frac{2\pi}{N}
=\frac{N\ell^2}{4}\cot\frac\pi N\\
&=\frac{Pr_{\rm in}}2
=Nr_{\rm in}^2\tan\frac\pi N.
\end{aligned}
```

</td></tr></tbody></table>


固定 $`R\gt 0`$ 时 $`A_N`$ 随 $`N`$ 严格增加到 $`\pi R^2`$，且对 $`R\ge0,N\ge3`$


<table><tbody><tr><td>

```math
0\le\pi R^2-A_N\le\frac{2\pi^3R^2}{3N^2}.
```

</td></tr></tbody></table>


固定周长时


```math
A_N=\frac{P^2}{4N}\cot\frac\pi N,\qquad
\frac{4\pi A_N}{P^2}=\frac\pi N\cot\frac\pi N\lt 1.
```


证明。中心的 $`N`$ 个三角形面积各为 $`R^2\sin(2\pi/N)/2=\ell r_{\rm in}/2`$；相加并用两倍角式及 $`\ell=2r_{\rm in}\tan(\pi/N)`$ 得四种表达，分别适用于已指定的外半径、边长、周长、内半径预算。圆面积可由同一标定的边界积分 $`\tfrac12\int_0^{2\pi}R^2\,dt=\pi R^2`$ 得出，积分约定见 [B-S7] §175。令 $`t=2\pi/N\in(0,\pi)`$，$`\sin t-t\cos t`$ 的导数为 $`t\sin t\gt 0`$，零点极限为零，所以 $`\sin t/t`$ 随 $`t`$ 下降，随 $`N`$ 上升。对全部 $`t\ge0`$，$`t-\sin t=\int_0^t(1-\cos s)ds`$；$`1-\cos s=2\sin^2(s/2)\le s^2/2`$，给 $`0\le t-\sin t\le t^3/6`$，代入得尾界。周长式由 $`\ell=P/N`$，而 $`\tan t\gt t`$ 在 $`0\lt t\lt \pi/2`$ 由导数 $`\tan^2t\gt 0`$ 得出，故 $`t\cot t\lt 1`$。$`R=0`$ 时式子退化为零，无严格增性。∎

**命题 B-9.2（面积比较的预算条件）。** 给简单非退化 $`N\ge3`$ 边形，固定正周长 $`P`$，其绝对面积不超过 $`P^2\cot(\pi/N)/(4N)`$，等号仅为凸正多边形的相似类（可反向或刚体移动）。此经典多边形等周结论作为标定比较的中间工具，使用 [B-L6] 的简单多边形范围；不推断素数边数有面积优势。

证明。先取凸包：面积不减，周长不增，顶点数至多 $`N`$；必要时按比例扩大到同周长，只会增加面积。对弱凸至多 $`N`$ 顶点、周长 $`P`$ 的闭紧族，平移首点到零后所有坐标有界，最大面积存在。令 $`c_n=\cot(\pi/n)/(4n)`$；它随 $`n`$ 严格增加，因为 $`t\cot t`$ 的导数为 $`(\sin t\cos t-t)/\sin^2t\lt 0`$。归纳排除最大值在较少顶点的退化边界：较少 $`k\lt N`$ 的最大面积至多 $`c_kP^2\lt c_NP^2`$，而正 $`N`$ 边形已达到右端。

在严格凸最大形中，固定邻点及相邻两边长之和，顶点在椭圆上变动；面积随它到邻点弦的垂直高度线性变动。局部最大高度位于垂直平分线上，所以相邻边相等；对所有顶点得到共同边长 $`\ell=P/N`$。面积与周长的梯度必须同一比例：若入、出边单位向量为 $`a,b`$，外转角 $`\delta\in(0,\pi)`$，则


```math
\nabla_i\mathcal{\text{𝒜}}=-\frac\ell2J(a+b),\qquad
\nabla_iP=a-b,
```


其中 $`J`$ 是逆时针直角旋转。旋转到 $`a=(\cos(\delta/2),-\sin(\delta/2))`$、$`b=(\cos(\delta/2),\sin(\delta/2))`$，二梯度比例为 $`\ell\cot(\delta/2)/2`$。周长梯度非零（缩放方向的导数为 $`P`$），故约束极值条件适用；共同乘子与 cot 的单射性使全部 $`\delta`$ 相同，总外转角 $`2\pi`$ 给 $`\delta=2\pi/N`$。所以最大形正，命题B-9.1给其面积。基例 $`N=3`$ 用同一椭圆论证得等边，退化面积零，完成归纳及等号条件。凸包步骤若严格增加面积或缩短周长，则不能等号；故简单非凸形无等号。∎

**命题 B-9.3（固定半径实例与两种极限）。** 同 $`R\gt 0`$ 时 $`A_3=3\sqrt3R^2/4`$、$`A_4=2R^2`$、$`A_6=3\sqrt3R^2/2`$。另给局部方向环境，定义


```math
\pi_{\rm dir}(n,R_{\rm loc})=p+R_{\rm loc}n,
\quad n\in S^1,\quad R_{\rm loc}\ge0.
```


$`R_{\rm loc}\gt 0`$ 时位置恢复方向与半径，$`R_{\rm loc}=0`$ 时所有方向落到 $`p`$；这是方向遗忘，不是 $`S^1=W\setminus\{p\}`$。此处的局部半径与原生替换 $`\rho`$ 分别记名。固定 $`R`$、$`N\to\infty`$ 与固定 $`N`$、$`R\to0`$ 分别给面积 $`\pi R^2`$ 与零。

证明。面积值直接代入命题B-9.1。非零位置差给 $`R_{\rm loc}=\|\pi_{\rm dir}-p\|`$、$`n=(\pi_{\rm dir}-p)/R_{\rm loc}`$，零差无方向逆式。极限由命题B-9.1的尾界及面积的平方缩放得出。裸点没有供应方向环境。∎

## 10. 顶点循环与有理中心任务

**命题 B-10.1（访问任务中的素数条件）。** 在顶点域 $`\mathbb{\text{ℤ}}/N\mathbb{\text{ℤ}}`$ 上给固定步长 $`k`$，首次返回长度为 $`N/\gcd(N,k)`$。对 $`N\ge3`$，每个非零步长走全圈当且仅当 $`N`$ 为素数；这不限制三角剖分。

证明。写 $`N=gN',k=gk'`$ 且 $`\gcd(N',k')=1`$。$`N\mid mk`$ 等价于 $`N'\mid m`$，最小正 $`m=N'`$。素数时全部非零 $`k`$ 与 $`N`$ 互素；合数时取真因子 $`k`$ 得较短圈。六边形 $`k=2`$ 长度三，五边形 $`k=2`$ 长度五，三角形仅有 $`k=\pm1`$ 两种反向。任意凸 $`p`$ 边形仍有 $`p-2`$ 个三角形剖分，所以循环不可分性与面积不可分性不同。经典根单位背景见 [B-L7] §1。∎

**命题 B-10.2（精确计数读口与实混合读口不相同）。** 令 $`p`$ 为素数，$`\zeta_p=e^{2\pi i/p}`$。若有理（可带符号）权重满足


```math
\sum_{j=0}^{p-1}\lambda_j=1,\qquad
\sum_{j=0}^{p-1}\lambda_j\zeta_p^j=0,
```


则全部 $`\lambda_j=1/p`$；概率权重另要求非负。合数 $`N`$ 有非均匀有理概率中心表示。对任意 $`N`$ 个非共线固定平面点，在存在全正表示的均值处，实概率纤维局部维数为 $`N-3`$。

证明。令 $`f(T)=\sum\lambda_jT^j`$。经典分圆不可约性 [B-L7] §5在这里由 Eisenstein 直接证明：


```math
\Phi_p(T+1)=\frac{(T+1)^p-1}{T}
=\sum_{i=1}^{p}\binom pi T^{i-1}.
```


最高系数一，其余系数皆被 $`p`$ 整除，常数 $`p`$ 不被 $`p^2`$ 整除，故在 $`\mathbb{\text{ℚ}}[T]`$ 不可约。因 $`\zeta_p`$ 是 $`f`$ 的根且次数至多 $`p-1`$，$`f=c\Phi_p`$；归一化得 $`c=1/p`$。若 $`N`$ 合数，选 $`2\le d\lt N`$ 真因子，在顶点 $`j=sN/d`$，$`0\le s\lt d`$ 各放 $`1/d`$，其他放零，非平凡 $`d`$ 次单位根和为零，给非均匀中心表示；$`d=2`$ 是一对直径端点，六边形 $`d=3`$ 是交替三点。实域中矩阵的三行是 $`1`$ 及两个坐标，非共线使秩三，核维 $`N-3`$；全正性使核中足够小扰动仍合法。∎

**命题 B-10.3（精确与近似中心的可取得结论）。** 对正素数 $`p\ge5`$，


```math
\lambda_j=1/p+\varepsilon\cos(4\pi j/p),\qquad |\varepsilon|\lt 1/p
```


给非均匀全正实中心表示（$`\varepsilon\ne0`$）。前一扰动要求 $`p\ge5`$；对任意素数 $`p\ge3`$ 和 $`m\gt 0`$ 个实际顶点样本，经验均值精确在中心时，每点次数为 $`m/p`$，所以 $`p\mid m`$；任意固定正精度却不能对无上界样本量认证这个整除。

证明。余弦展开给频率 $`\pm2`$；总权重的扰动和为零，中心的扰动为频率 $`3,-1`$ 的单位根和，$`p\ge5`$ 时均非零模 $`p`$，故为零；幅度界保证正性。实纤维维数为 $`p-3`$，正五边形为二，三角形为零。实际计数是有理权重，应用命题B-10.2。反例取总样本 $`pm+1`$：某顶点计数 $`m+1`$，其他各 $`m`$，中心误差为 $`R/(pm+1)`$，可任意小但总数不被 $`p`$ 整除。故有限精度不是精确代数等式的认证。∎

## 11. 步长面积代数与实际耳预算

**命题 B-11.1（同一顶点集的面积谱约束）。** 对奇素数 $`p\ge3`$、$`R\gt 0`$、$`1\le k\le(p-1)/2`$，步长绕行的鞋带有向面积与无量纲平方为


```math
A_{p,k}=\frac{pR^2}{2}\sin\frac{2\pi k}{p},\qquad
q_{p,k}=\frac{16A_{p,k}^2}{p^2R^4}=4\sin^2\frac{2\pi k}{p}.
```


它们满足 $`\sum_kq_{p,k}=\prod_kq_{p,k}=p`$，每个 $`q_{p,k}`$ 的最小有理多项式次数为 $`(p-1)/2`$。此面积在自交步长路径上按绕数计权，不是未规定的星形填充面积。

证明。步长遍历全 $`p`$ 点，每条边相对中心的贡献相同，给面积式。令 $`z=\zeta_p^{2k}`$，有 $`q=2-z-z^{-1}=(1-z)(1-z^{-1})`$；$`\pm2k`$ 恰覆盖全部非零模类，单位根和为 $`-1`$ 给总和 $`p`$，$`\prod_{j=1}^{p-1}(1-\zeta_p^j)=\Phi_p(1)=p`$ 给乘积。$`[\mathbb{\text{ℚ}}(z):\mathbb{\text{ℚ}}]=p-1`$；$`\mathbb{\text{ℚ}}(q)`$ 是实域，而 $`z`$ 非实且满足 $`T^2-(2-q)T+1=0`$，所以 $`[\mathbb{\text{ℚ}}(z):\mathbb{\text{ℚ}}(q)]=2`$，塔式次数给所述次数。此经典分圆工具被用于同源耳预算，不作为新命名的分圆定理。∎

**命题 B-11.2（小素数面积谱与 FIB 的准确代数桥）。** 所有相应 $`q`$ 满足

| $`p`$ | 最小多项式 $`P_p(Q)`$ |
| --- | --- |
| $`3`$ | $`Q-3`$ |
| $`5`$ | $`Q^2-5Q+5`$ |
| $`7`$ | $`Q^3-7Q^2+14Q-7`$ |
| $`11`$ | $`Q^5-11Q^4+44Q^3-77Q^2+55Q-11`$ |

对 $`p=5`$，$`q_\pm=(5\pm\sqrt5)/2`$，$`\varphi=q_+-2`$ 满足 $`\varphi^2=\varphi+1`$。有实际有理代数同构


```math
\mathbb{\text{ℚ}}[Q]/(Q^2-5Q+5)\ \longrightarrow\ \mathbb{\text{ℚ}}[M],
\qquad Q\longmapsto M+2I.
```


证明。令 $`h=(p-1)/2`$，逐项二项式展开给


```math
z^hP_p(2-z-z^{-1})=(-1)^h(1+z+\cdots+z^{p-1})
```


在所列四个 $`p`$ 上的多项式恒等式。代入原始根给零，命题B-11.1的次数使所列首一式就是最小多项式。五边形式求根并平移得黄金式。$`M^2=M+I`$，故 $`(M+2I)^2-5(M+2I)+5I=0`$；$`I,M`$ 线性独立，像维二，而源是不可约二次商域，非零同态单射且满射，得同构。等价地 $`Q-2\mapsto M`$。这是一项代数映射；它不保持几何动作或原生读器的控制合同。七边形最小次数三，不能普遍黄金化，也不因两种计数都为五而建立模型等价。∎

**命题 B-11.3（同源耳面积预算消费上述谱）。** 在逆时针凸正 $`N\ge5`$ 边形上固定五个连续不同顶点，三个删耳及联合均合法；令 $`\alpha=2\pi/N`$，每个耳面积及占总面积比例为

## 13. 相对补集的类型与立方体几何

**定义 B-13.1（固定背景的取补）。** 对声明的来源域 $`\Omega`$ 与事件 $`E\subseteq\Omega`$，定义 $`\neg_\Omega E=\Omega\setminus E`$。位置配置取补 $`C_U(I)=U\setminus I`$ 则是 $`2^U`$ 上的点映射，不是 $`\Sigma`$ 的事件族补集。相对补集的原有区分归 [B-S2] §§42–48。

**命题 B-13.2（类别补与关系反射不共享固定点）。** 双补还原，事件及其补不交且并为 $`\Omega`$；$`\Omega\ne\varnothing`$ 时没有固定事件，空域时唯一事件 $`\varnothing`$ 固定。若 $`\Omega_{\rm reg}=\{P_N:N\ge3\}`$，则正三角形类的补包括正方形及全部 $`N\ge5`$ 类；只有显式在 $`\Omega_* =\Omega_{\rm reg}\setminus\{P_4\}`$ 中取补，才得到三角形类与 $`N\ge5`$ 类互补。

证明。逐元素两次否定即还原。非空背景任取元素，固定事件要求它属于事件当且仅当不属于，矛盾；空域只有空集。正多边形域逐项排除得到所列类别。命题B-3.3的直角固定关系属于另一映射，不能当作布尔补集固定事件。若把点、圆加入域，须额外定义其事件归属。∎

**命题 B-13.3（合法配置补的最小封闭域）。** 五模式的位置补为

| --- | --- | --- |

| $`1`$ | $`\{2,3\}`$ | 否 |
| $`2`$ | $`\{1,3\}`$ | 是 |
| $`3`$ | $`\{1,2\}`$ | 否 |

证明。逐位置取 $`b\mapsto1-b`$ 得表，两次还原。原域缺少的三个配置恰是前三种域外结果，所以任何闭扩展包含八项。合并后三个不同输入有同一输出，任何仅依合并输出的后处理无法恢复它们。八配置的代数域不授予非法原生输入执行许可。∎

配置补 $`C_U(\{2\})=\{1,3\}`$ 给一个配置，而事件补 $`\Sigma\setminus\{2\}`$ 给四种模式。一般 $`\mathrm{conv}(\Sigma\setminus E)\ne\mathcal{\text{𝒫}}\setminus\mathrm{conv}(E)`$。

证明。逐模式评价 $`x,y,z`$，其零事件的顶点恰为各行右端，取凸包得到平面方程。对 $`E=\{2\}`$，右边集合差仍含 $`\tfrac12v_0+\tfrac12v_2=(0,0,1/2)`$，左边凸包全部在 $`Z=0`$，故不等。这个见证区分模式事件、混合点与集合差。∎

## 14. 补集的正交表示与重叠读口

**定义 B-14.1（经典事件表示）。** 取计数内积空间 $`H=\mathbb{\text{ℝ}}^\Sigma`$，基 $`e_I`$ 正交归一化。事件 $`E`$ 表为 $`H_E=\mathrm{span}\{e_I:I\in E\}`$ 及对角投影 $`P_E=\sum_{I\in E}e_Ie_I^{\mathsf{\text{𝖳}}}`$。

**命题 B-14.2（本卷事件取补的正交实现范围）。** 有 $`H_{\Sigma\setminus E}=H_E^\perp`$、$`P_{\Sigma\setminus E}=I-P_E`$、$`P_EP_F=P_{E\cap F}=P_FP_E`$；$`E=\{2\}`$ 的补空间维四。一般向量空间中的集合差却不等于正交补。

证明。互补事件把五个互相正交的基向量分成两组，其直和是全 $`H`$，得正交补及投影公式。乘积逐基评价即为交集。空、满事件也分别给零投影与恒等投影。反例在 $`V=\mathbb{\text{ℝ}}^2`$、$`U=\mathbb{\text{ℝ}}(1,0)`$ 中，$`(1,1)\in V\setminus U`$ 却不在 $`U^\perp`$，而零向量在 $`U^\perp`$ 却不在集合差。此表示的全部事件投影交换，正交记号不因此成为非对易量子测量。∎

**定义 B-14.3（对数重叠代价）。** 在给定实或复内积空间中，对非零 $`u,v`$ 定义


```math
s(u,v)=\frac{|\langle u,v\rangle|^2}{\|u\|^2\|v\|^2},\qquad
\mathcal{\text{ℐ}}(u:v)=-\log_2s(u,v),\qquad -\log_20=+\infty.
```


经典 Cauchy–Schwarz 给 $`0\le s\le1`$。若另供归一化纯态及投影测量，平方重叠是该概率，也是 [B-L8] 的平方保真度约定；未供量子载体时只使用内积定义。

**命题 B-14.4（该读口的分辨边界）。** 对实方向 $`s=\cos^2\theta`$，所以锐角与补钝角有同一 $`\mathcal{\text{ℐ}}`$。正交单位向量有 $`\mathcal{\text{ℐ}}=+\infty`$，但欧氏距离 $`\sqrt2`$；反向单位向量距离二。$`\mathcal{\text{ℐ}}`$ 不满足三角不等式，也不区分正负同一射线。

证明。正交使重叠零，范数差平方为二；反向的差是两倍单位向量，而 $`s=1`$、代价零。三个方向角 $`0,45^\circ,90^\circ`$ 的相邻平方重叠各 $`1/2`$、代价各一，但端点代价无穷，违背三角不等式。另定义 $`\mathcal{\text{𝒟}}=\sqrt{1-s},\mathcal{\text{𝒱}}=\sqrt s`$ 时，$`\mathcal{\text{𝒟}}^2+\mathcal{\text{𝒱}}^2=1`$，正交给 $`(1,0)`$；这些量的物理可见度含义仅在 [B-S2] §108 所供纯路径记录、等幅比较及共同环境合同下使用，不能推广成任意仪器的关系。∎

## 15. 底面相对翻转、数量中心化与原生守卫

**命题 B-15.1（完整概率的被动翻转）。** 底面事件指示是原子函数 $`b=1-z`$，其质量是 $`r=1-Z`$，混合点上的 $`r`$ 不是几何面的零一指示。定义


```math
C_x(x,y,z)=(1-z-x,y,z),\qquad C_y(x,y,z)=(x,1-z-y,z).
```


它们是 $`\Sigma`$ 及 $`\mathcal{\text{𝒫}}`$ 上交换的对合，顶点 $`v_2`$ 固定。按本卷顺序，概率推前为


```math
(C_x)_*p=(p_1,p_0,p_2,p_{13},p_3),\qquad
(C_y)_*p=(p_3,p_{13},p_2,p_0,p_1).
```


均值及联合项变换为


```math
C_x:(X,Y,Z,\kappa)\mapsto(r-X,Y,Z,Y-\kappa),
```


```math
C_y:(X,Y,Z,\kappa)\mapsto(X,r-Y,Z,X-\kappa).
```


令 $`\Delta=r\kappa-XY=p_0p_{13}-p_1p_3`$，每个单翻转使 $`\Delta`$ 反号，双翻转使其不变。

证明。在底面是普通二位翻转，在顶点两端为零，代入得到对合及交换；均值 $`X\le r,Y\le r`$ 保证凸包保持。原子排列 $`C_x`$ 交换 $`0,1`$ 与 $`3,13`$，$`C_y`$ 交换 $`0,3`$ 与 $`1,13`$，给推前表。$`xz=yz=0`$ 使 $`\mathbb{\text{𝔼}}[(1-z-x)y]=Y-\kappa`$，另式对称。反式展开得 $`\Delta=p_0p_{13}-p_1p_3`$，且 $`r(Y-\kappa)-(r-X)Y=-\Delta`$。$`r=0`$ 时一切为零，底面条件化不定义。$`r\gt 0`$ 时，条件联合概率 $`\kappa/r`$ 与条件边缘积 $`XY/r^2`$ 相等恰为 $`\Delta=0`$，并由二位概率逆式得底面条件独立；它不推出全模式中的无条件独立，更不推出不同窗口独立。公式复用 [B-S4] §8。∎

**命题 B-15.2（原生语言不因该翻转封闭）。** $`C_x,C_y`$ 的同窗推前不自动是可执行的原生历史变换。合法双词 $`(0,3)`$ 经 $`C_x`$ 变成 $`(1,13)`$ 而拒绝；合法双词 $`(1,0)`$ 经 $`C_y`$ 变成 $`(13,3)`$ 而拒绝。对命题B-12.1的原模式，若仅把它被动改记为 $`x'=1-z-x`$，则后缀成功指示必须运输成 $`1-x=z+x'`$。

证明。两原词的共享守卫均为零，变换词的 $`x(I)y(J)`$ 均为一。被动等式由 $`x'=1-z-x`$ 立即得到，成功质量为 $`Z+\mathbb{\text{𝔼}}(x'y)=Z+Y-\kappa`$ 于奇偶事件中使用。若另外在推前律上运行未运输谓词的假设标准读器，其奇偶拒绝率变为 $`(Y-\kappa)/m`$；而原拒绝的布尔补是 $`1-\kappa/m=(Z+Y-\kappa)/m`$，差 $`Z/m`$。所以忽略顶点背景会给错误“取补”回复，推前合同也不授予在原读器中执行翻转。∎

**命题 B-15.3（数量反号的固定整体及相位实现界限）。** 对 $`j\ge0`$ 令


```math
a_j=F_{3j+3},\quad b_j=F_{3j+4},\quad
c_j=F_{3j+5}=a_j+b_j,
```


在全部八配置上取 $`V_j(I)=a_j\mathbf{\text{𝟏}}_{1\in I}+b_j\mathbf{\text{𝟏}}_{2\in I}+c_j\mathbf{\text{𝟏}}_{3\in I}`$。则


```math
V_j(C_U(I))=2c_j-V_j(I),\qquad
\widetilde V_j=V_j-c_j\quad\Longrightarrow\quad
\widetilde V_j(C_U(I))=-\widetilde V_j(I).
```


零层 $`a_0,b_0,c_0=2,3,5`$，合法补对数量 $`3\leftrightarrow7`$ 关于五对称；位置 $`\{3\}`$ 与非法 $`\{1,2\}`$ 都给五，来源却不同。

证明。全部三位置权重和是 $`2c_j`$，配置与其补不交并为全部位置，得公式，中心化后反号。等数量由 $`c_j=a_j+b_j`$；非法配置有相邻一，不能赋合法事件身份。此中心化复用 [B-S2] §43。

若另选择 [B-S2] §§101–103、107 的具体矩阵代表，取


```math
\sigma_x=\begin{pmatrix}0&1\\1&0\end{pmatrix},\qquad
\sigma_y=\begin{pmatrix}0&-i\\i&0\end{pmatrix},\qquad

```


直接相乘得 $`a^2=b^2=-I`$、$`ab=-ba`$。单模式代表为 $`I,a,b,c,ca`$，其中 $`ca=ba^2=-b`$，于是选定的联合代表与中间代表相差负号。换成另一有序树代表 $`ac=aba=b`$ 就不同；整体相位也不改变单支密度算子。相对号的取得需实际相干比较和共同环境，不是位置语法给出的 Pauli 或量子许可。叶矩阵乘积对状态先作用右因子，这与左到右叶序分别约定。∎

## 16. 观察纤维上的补集与阈值任务

**定义 B-16.1（实际像的两个事件读口）。** 对 $`\eta:\Omega\to B=\eta(\Omega)`$，令

```math
\eta_\exists(E)=\{b:\eta^{-1}(b)\cap E\ne\varnothing\},\qquad
```

每个实际像纤维非空；空来源域的实际像也为空。此区分采用 [B-S2] §47。

**命题 B-16.2（补集不会恢复旧读口遗忘的信息）。** 有


<table><tbody><tr><td>

```math
\qquad
\eta_\forall(\Omega\setminus E)=B\setminus\eta_\exists(E).
```

</td></tr></tbody></table>

**命题 B-16.3（原生失败阈值的同背景存在与保证）。** 在命题B-12.3中取 $`m=Y+Z\gt 0`$，定义律空间上的失败率 $`f=\kappa/m`$ 与事件 $`E_\tau=\{f\le\tau\}`$，$`0\le\tau\le1`$。固定三均值时

| --- | --- | --- |
| $`E_\tau`$ | $`L\le\tau m`$ | $`U\le\tau m`$ |
| $`E_\tau^c`$ | $`U\gt \tau m`$ | $`L\gt \tau m`$ |

证明。失败率是 $`\kappa`$ 的严格递增仿射函数，区间两端给四种量词。固定纤维内的端点不等号逐项给事件及补，内部切点两侧都有点。严格正律空间里可在 $`p_3`$ 与 $`p_{13}`$ 间作足够小质量交换，保持 $`m`$ 不变而改变 $`\kappa`$；故 $`h_\tau=0`$ 的邻域两侧均非空。连续性使其他点不在边界。若切点在纤维外或端点，直接用定义及相对拓扑，不套用内部切点陈述；$`m=0`$ 不定义条件失败率。∎

## 17. 共同边界、方向链与外背景项

**定义 B-17.1（集合边界与链背景）。** 对拓扑背景 $`W`$ 的事件 $`E`$，使用相对边界 $`\partial_WE=\overline E^{\,W}\cap\overline{W\setminus E}^{\,W}`$。另对有限共同单元分解的有向背景，$`C_W`$ 是一致定向的顶维链，$`C_E`$ 为其中选定顶单元的链，$`C_{\rm rest}=C_W-C_E`$。后者指剩余闭单元的带重数链，不是半开集合差的逐点编码。

**命题 B-17.2（阈值与立方体任务的共同分界）。** 事件与其相对补集有相同集合边界。链的关系为


<table><tbody><tr><td>

```math
\partial C_{\rm rest}=\partial C_W-\partial C_E.
```

</td></tr></tbody></table>


只有 $`\partial C_W=0`$、取相对外边界商，或明确只比较内部界面时，才可写内部反号；完整链仍须保留外背景。对命题B-16.3的内切点，


```math

\qquad \partial C_{\rm rest}=[U]-[k_0].
```


证明。集合边界的两个闭包项交换而交集不变。链公式由线性性。区间的三个边界分别为 $`[U]-[L]`$、$`[k_0]-[L]`$、$`[U]-[k_0]`$，逐项给补关系；内点符号相反，但外端点不消失。命题B-13.4的共同六四面体分解同样使共面内项成对相消，真实集合差的严格接缝约定与闭链的边界约定分别保留。这一链中间工具的符号约定采用 [B-L9] §2.1，供同背景补集判断消费。∎

**命题 B-17.3（点、线、面、体的闭合检验）。** 在有序单纯形链约定中


```math
\begin{aligned}
\partial[a,b]&=[b]-[a],\\
\partial[a,b,c]&=[b,c]-[a,c]+[a,b],\\
\partial[a,b,c,d]&=[b,c,d]-[a,c,d]+[a,b,d]-[a,b,c].
\end{aligned}
```


其二次边界为零，但这不表示边或点不存在。对已有合法区域剖分，命题B-4.2的鞋带面积就是此边界消去的数值读出。

证明。一般 $`\partial[v_0,\ldots,v_n]=\sum_i(-1)^i[v_0,\ldots,\widehat v_i,\ldots,v_n]`$。删除 $`i\lt j`$ 的两条路径分别有系数 $`(-1)^i(-1)^{j-1}`$ 与 $`(-1)^j(-1)^i`$，相加为零，故 $`\partial^2=0`$；所列低维式是逐项展开。内部边被两个三角链以相反方向使用，因此面积评价只留下外边界。合法区域面积还需共同定向、几何顶点与剖分，不能仅凭点数恢复。∎

**命题 B-17.4（顶点方向的参数背景）。** 金字塔近顶点可写


```math
(X,Y,Z)=(ru,rv,1-r),\quad 0\le r\le1,\quad u,v\in[0,1].
```


$`r\gt 0`$ 时 $`u=X/r,v=Y/r`$；$`r=0`$ 时整张方向方形被投到顶点。若只研究侧面，方向参数是方形周界，拓扑上为圆；它不是单位度量圆，也不是顶点的普通集合补。

证明。域条件等价于 $`0\le X,Y\le r`$，非零 $`r`$ 时反解唯一，零 $`r`$ 时全部 $`(u,v)`$ 同像。四条侧面恰为 $`u=0,v=0,u=1,v=1`$，周界的逐边线性参数化给圆周同胚。是否实际保留方向标签必须由记录合同给出，坐标压缩本身没有恢复逆式。∎

## 18. 从同一有向边界到几何体积

**假设 B-18.1（三维生成与参照）。** 体积任务另供三维欧氏标定。对全维凸多面体 $`K`$，选共同内部参照 $`o`$、外向一致边界三角剖分；边界三角形可退化贡献零。对平面多边形，另给高度 $`H\gt 0`$ 和棱柱或棱锥生成规则；未知内部密度不作为已知输入。

**命题 B-18.2（边界恢复体积的量与遗漏）。** 在假设B-18.1下


<table><tbody><tr><td>

```math

```

</td></tr></tbody></table>


该数与共同内部参照选择无关；外边界本身不能恢复任意未知密度积分。

证明。每个外向三角形与内部点组成正向四面体，射线从 $`o`$ 到边界把凸体分成这些内部不交的四面体；单个的体积为三重积除六，或底面积乘垂直高度除三。求和得体积。更直接，参照改为 $`o+t`$ 时，一个三重积的变化为

```math
-t\cdot[(b-a)\times(c-a)].
```


而 $`(b-a)\times(c-a)=a\times b+b\times c+c\times a`$，在闭边界上每条有向边对向出现，求和为零，故参照差不改变总数；此代数式也可扩展到非内部参照的有向总和，但内部四面体分割的正体积证明使用内部条件。共同平移全部点与 $`o`$ 不改变差向量。低维平面体的三维体积零；退化三角贡献零，不用不确定法向的高度式。

同一 $`K`$ 配常密度一或二，积分分别为 $`\mathrm{Vol}(K)`$ 与两倍，外边界完全相同；故未知密度需要另供规律或内部读出。∎

**命题 B-18.3（多边形生成及五顶点的正确含义）。** 平面多边形本身三维体积零；棱柱与棱锥分别有体积 $`A_NH`$、$`A_NH/3`$。正 $`N`$ 边形底、固定 $`R,H`$ 的棱锥体积为


```math
\frac{NR^2H}{6}\sin\frac{2\pi}{N}\ \longrightarrow\ \frac{\pi R^2H}{3}.
```


$`N`$ 边形底棱锥有 $`N+1`$ 顶点、$`2N`$ 棱、$`N+1`$ 面。三维最小全维单纯形是四个非共面点，三个差向量的体积为 $`|\det(u,v,w)|/6`$。FIB 平均金字塔是四边底、五顶点八棱五面，顶点在底角上方，不是正五边形底，也不是中心轴正棱锥。

证明。棱柱各高度截面相同。棱锥的平行截面在高度 $`z`$ 是底面的 $`(1-z/H)`$ 倍相似形（顶点的水平投影位置不影响比例），面积为 $`A_N(1-z/H)^2`$，积分 $`0\le z\le H`$ 得三分之一；命题B-9.1给正底公式与极限。逐数底顶点加一个顶点、底边及侧棱各 $`N`$、侧面 $`N`$ 加底面一个，得组合计数。四点非共面恰有三个独立差向量，参照四面体的行列式给体积；三点仿射维数至多二。$`\mathcal{\text{𝒫}}`$ 的四底点在 $`Z=0`$，顶点 $`(0,0,1)`$ 在底角上方，侧棱长为 $`1,\sqrt2,\sqrt2,\sqrt3`$，非正棱锥，坐标体积是 $`1/3`$，见 [B-S2] §53。五模式、五顶点与五边形是三种计数，不相互替代。∎

## 19. 共同记录的三角 Gram 与高阶边界

**假设 B-19.1（另供的记录载体）。** 给同一个复 Hilbert 空间中的单位记录 $`e_1,e_2,e_3`$，内积对第二变量线性。记 $`a=\langle e_1,e_2\rangle,b=\langle e_2,e_3\rangle,c=\langle e_3,e_1\rangle`$，Gram 候选是


```math
G=\begin{pmatrix}
1&a&\bar c\\
\bar a&1&b\\
c&\bar b&1
\end{pmatrix}.
```


归一化记录的模型和共同环境边界采用 [B-S2] §§107–109；其通道系数 $`\Gamma_{hk}=\langle e_k,e_h\rangle`$ 是此约定的 $`G^{\mathsf{\text{𝖳}}}`$，不能直接混用共轭位置。经典向量 Gram 不自动意味着量子实验；物理记录取得及共同相干实现另外供应。

**接口 B-19.2（几何记录的共同实现条件）。** [C 卷 §9](AURIC_FIB_ATOM_HIDDEN_RELATIONS_STATISTICS_PHASE_AND_SEAMS.md#9-共同记录的圆盘与参考递归) 命题C-9.6证明 Hermitian、单位对角、三模长界和循环行列式非负恰为共同实现条件；预定维数 $`d`$ 另须秩不超过 $`d`$，最小抽象载体维数等于秩。本卷采用假设B-19.1的同一载体和索引约定，不能用三个分别合法的仪器对子替代此条件。

**命题 B-19.3（闭环相位与所有三角检验的局限）。** 若三模长均为 $`1/\sqrt2`$，共同三记录要求闭环相位 $`\Phi_{\rm G}=\arg(abc)`$ 满足 $`\cos\Phi_{\rm G}\ge1/\sqrt2`$。全四记录候选的对角为一、非对角皆 $`-2/5`$，所有三阶主块正定，整个四阶却非半正定。

证明。三记录相位条件、重相位不变性及 $`(1\pm i)/4`$ 共同二维例使用 [C 卷 §9](AURIC_FIB_ATOM_HIDDEN_RELATIONS_STATISTICS_PHASE_AND_SEAMS.md#9-共同记录的圆盘与参考递归) 命题C-9.7，三阶式及其普通证明均在那里给出。

四阶候选写成 $`(7/5)I_4-(2/5)\mathbf{\text{𝟏}}\mathbf{\text{𝟏}}^{\mathsf{\text{𝖳}}}`$。全一方向的特征值为 $`7/5-8/5=-1/5`$，正交补为三重 $`7/5`$；三阶主块相应为全一方向 $`1/5`$、二重 $`7/5`$，均正。因此所有三角共同正性都不能放行该四记录共同来源。三记录是首个闭环检验，非所有高阶检验的终点；Gram 秩是响应表示维数，不是环境的全部物理成本或空间维度。∎
