### 一、五个基础模式与唯一隐藏方向


- $`x=1`$：输入中选择了位置 $`1`$；

也就是说，中间模式 $`z`$ 不能和两个端点同时出现；两个端点 $`x,y`$ 却可以共同出现，因此存在联合项 $`xy`$。

### 三、第二定理：并不是所有读数都能发现隐藏信息

设 $`f:\Sigma\to\mathbb R`$ 是一个读出函数。定义其四角差：

```math

\mathbb E_p[f]+tJ_f.
```

1. 若 $`J_f=0`$，则 $`f`$ 对 $`\kappa`$ 完全不敏感；
2. 若 $`J_f\ne0`$，则在已知 $`(X,Y,Z)`$ 时，$`\mathbb E[f]`$ 可以恢复 $`\kappa`$。

#### 证明

由 $`p(t)=p+td`$：

```math
\mathbb E_{p(t)}[f]
=
\sum_{\sigma}
(p_\sigma+t d_\sigma)f_\sigma
=
\mathbb E_p[f]
+
t\sum_\sigma d_\sigma f_\sigma.
```

而

```math
\sum_\sigma d_\sigma f_\sigma
=
f_0-f_2-f_5+f_{25}
=
J_f.
```

所以结论成立。证毕。

### 四、第三定理：遮挡相当于增加第二个投影

原来的可见投影为

```math
P(p)=(X,Y,Z).
```

它的隐藏核由 $`d`$ 生成：

```math
\ker P=\operatorname{span}\{d\}.
```

现在加入遮挡后的联合读出：

```math
Q(p)=(X,Y,W),
\qquad W=Z+\kappa.
```

定义另一个方向

```math
e=(2,-1,-1,-1,1).
```

检查：

```math
\Delta X=-1+1=0,
```

```math
\Delta Y=-1+1=0,
```

```math
\Delta W=\Delta Z+\Delta\kappa=-1+1=0.
```

所以

```math
\ker Q=\operatorname{span}\{e\}.
```

但是

```math
Q(d)=(0,0,1)\ne0.
```

因此两个投影的隐藏方向不同：

```math
\ker P\cap\ker Q=\{0\}.
```

### 五、把物理射线写成信息通道

先区分射线种类。真空中的伽马射线是光子，沿光速传播；阿尔法和贝塔射线分别是有质量粒子或带电粒子，不能直接套用“光子永远追不上”的论证。[www.nist.gov](https://www.nist.gov/system/files/documents/oles/DHS_102-06-PPEGuideFinalReport-3-20-07.pdf?utm_source=chatgpt.com)

在狭义相对论的普通因果结构中，光速是因果影响传播的上限。[www.einstein-online.info](https://www.einstein-online.info/en/explandict/light-cone/?utm_source=chatgpt.com)

但是：

```math
\text{无法从后面追上同一光子}
\ne
\text{所有信息永远无法被任何方式接收}.
```

设完整历史为 $`h`$，衰变后的全局状态为

```math
\mathcal E(h)
=
\bigl(S'(h),R(h),A(h),E(h)\bigr),
```

其中：

- $`S'`$：衰变后的残余物；
- $`R`$：自由传播的射线；
- $`A`$：挡板或吸收体；
- $`E`$：其他环境自由度。

观察者只能使用可访问投影：

```math
O_A(h)=\Pi_A\bigl(\mathcal E(h)\bigr).
```

定义观察纤维：

```math
\mathcal F_A(y)=\{h:O_A(h)=y\}.
```

若两个历史 $`h,h'`$ 满足

```math
O_A(h)=O_A(h'),
```

那么对于只依赖 $`A`$ 的观察者，它们是不可区分的。

#### 定理 4：局部恢复定理

在经典情况下，历史集合 $`C`$ 上存在精确恢复函数

```math
R_A:O_A(C)\to C
```

当且仅当

```math
O_A|_C
```

是单射。

#### 证明

若存在恢复函数，显然两个不同历史不能有相同的观察结果。

反过来，若 $`O_A`$ 在 $`C`$ 上单射，则对每个 $`y\in O_A(C)`$，定义 $`R_A(y)`$ 为唯一满足 $`O_A(h)=y`$ 的历史。证毕。

因此，所谓“信息被恢复”在最基本的数学上就是：

```math
\boxed{\text{观察投影在目标历史集合上变成单射。}}
```

所谓“信息不可恢复”就是：

```math
\boxed{\text{不同历史落入同一个观察纤维。}}
```

这与 FIB 的 $`d`$ 方向完全相同。

### 六、遮挡的五种不同结果

#### 情形一：射线自由逃逸

若

```math
R(h)\notin A
```

并且之后没有反射、散射或吸收返回通道，则

```math
O_A(h)
```

不包含 $`R(h)`$。

如果两个历史只在射线部分不同：

```math
S'(h)=S'(h'),
\qquad
A(h)=A(h'),
\qquad
E(h)=E(h'),
\qquad
R(h)\ne R(h'),
```

则

```math
O_A(h)=O_A(h').
```

观察者局部不可恢复。

这不是说全局信息在某个数学意义上已经被删除，而是说它进入了当前观察者的隐藏纤维。

#### 情形二：提前放置的探测器

如果探测器已经位于射线未来路径上，则不需要追赶光子。射线可以被探测器截获，信息进入 $`A`$。

在 FIB 中，这相当于：

```math
P(p)=(X,Y,Z)
\quad\longrightarrow\quad
(P(p),W(p)).
```

如果探测器记录的是 $`\chi`$，则

```math
\kappa=W-Z
```

可以恢复，完整概率律可以重建。

#### 情形三：相干反射或相干吸收

若挡板把射线映射到一个可控的记录系统：

```math
R[I]\otimes A_0
\longrightarrow
\mathrm{vac}\otimes A[I],
```

且 $`I\mapsto A[I]`$ 在目标集合上是单射，那么信息只是从 $`R`$ 搬到了 $`A`$。

在量子系统中，如果保留完整相干自由度，光与物质之间的映射原则上可以是可逆的；实验上也有相干光—物质映射和再读取的接口。[www.nature.com](https://www.nature.com/articles/nature07607?utm_source=chatgpt.com)

### 八、最新动态结果：静态 $`\kappa`$ 还不是完整未来记忆

```math
\sum_\ell\mu(\ell)r_\ell^{A_h}s_\ell^{B_h}
```

```math

\quad\Longleftrightarrow\quad
```

#### 定理 5：动态未来商定理

在先验 $`\mu`$ 至少包含两个不同的正概率深度时：

```math
\boxed{
h\sim_{\mathrm{Fut}}h'
\Longleftrightarrow
\bigl(a(h),A_h,B_h\bigr)
=
\bigl(a(h'),A_{h'},B_{h'}\bigr).
}
```

#### 证明

若三元组相同，则当前 phase 相同，并且

```math
\mu(k)r_k^{A_h}s_k^{B_h}
=
\mu(k)r_k^{A_{h'}}s_k^{B_{h'}}
```

对所有 $`k`$ 都相同。因此后验 $`\nu_h=\nu_{h'}`$，完整未来律相同。

反过来，若未来律相同，则当前 phase 必须相同，且后验必须相同。于是对两个正概率深度 $`i,j`$：

```math
\left(\frac{r_i}{r_j}\right)^{A_h-A_{h'}}
\left(\frac{s_i}{s_j}\right)^{B_h-B_{h'}}
=1.
```

项目中的 Fibonacci 比率分离引理说明，在非单例正支持下，上式只能在

```math

\qquad
B_h-B_{h'}=0
```

时成立。因此三元组相同。证毕。

- 如果射线被完整记录，历史计数可以更新，未来商保持精确；

### 十一、信息逃逸与时间方向的条件定理

设 $`M_t`$ 是观察者在时刻 $`t`$ 所拥有的全部有效记录。定义：

```math
h\sim_t h'
\quad\Longleftrightarrow\quad
M_t(h)=M_t(h').
```

如果无返回通道，并且后续只是继续丢弃记录，使得存在函数 $`G_t`$ 满足：

```math
M_{t+1}=G_t\circ M_t,
```

那么：

```math
M_t(h)=M_t(h')
\Longrightarrow
M_{t+1}(h)=M_{t+1}(h').
```

所以

```math
\boxed{
\sim_t\subseteq\sim_{t+1}.
}
```

观察纤维只会扩大，局部可恢复区别只会减少。

#### 定理 6：单调粗粒化的时间箭头定理

若每一步观察记录都满足

```math
M_{t+1}=G_t\circ M_t,
```

则局部不可区分关系单调增加：

```math
\sim_0\subseteq\sim_1\subseteq\sim_2\subseteq\cdots.
```

#### 证明

若 $`h\sim_t h'`$，则

```math
M_t(h)=M_t(h').
```

对两边施加 $`G_t`$，得到

```math
M_{t+1}(h)
=
G_t(M_t(h))
=
G_t(M_t(h'))
=
M_{t+1}(h').
```

故 $`h\sim_{t+1}h'`$。证毕。

但是，如果挡板产生新记录 $`b_t`$，则更新可能是：

```math
M_{t+1}
=
\bigl(G_t(M_t),b_t\bigr).
```

这时不再有单纯的

```math
M_{t+1}=G_t\circ M_t.
```

新的记录可能把原先相同的两个历史分开：

```math
M_t(h)=M_t(h'),
\qquad
b_t(h)\ne b_t(h').
```

于是：

```math
M_{t+1}(h)\ne M_{t+1}(h').
```

因此：

> 时间方向只有在“信息持续离开当前可访问边界，且没有新的相干返回记录”的条件下，才表现为观察纤维单调扩大。

这给你的观点一个严格而有限的表述：

```math
\boxed{
\text{时间箭头}
=
\text{局部观察商上的不可区分关系不断扩大}
}
```

但它还不能推出：

```math
\text{时间在本体论上不存在}
```

也不能单独推出：

```math
\text{引力就是时间}
```

它证明的是一个观察者相对于开放边界的有效时间模型。

### Q1. 归一化域、可行纤维与回路（原文一、二、四）

固定分量次序 $(0,2,3,5,25)$。概率律位于单纯形 $\Delta_4$，其仿射包及扰动空间分别为

```math
H=\left\{p\in\mathbb R^5:\sum_\sigma p_\sigma=1\right\},\qquad
T=\left\{\delta\in\mathbb R^5:\sum_\sigma\delta_\sigma=0\right\}.
```

原文的“一维核”和“核交为零”仅对线性映射限制到 $T$ 后成立：$\ker(P|_T)=\mathbb R d$、$\ker(Q|_T)=\mathbb R e$，交为零。在环境空间 $\mathbb R^5$ 上，两映射的核均为二维，且

```math
u_0=(1,0,0,0,0),\qquad
\ker P=\operatorname{span}\{u_0,d\},\qquad
\ker Q=\operatorname{span}\{u_0,e\},\qquad
\ker P\cap\ker Q=\mathbb R u_0.
```

这是归一化约束的必要区分：$P,Q$ 都不读取 $p_0$，而合法扰动必须总和为零。核不同本身也不足以保证联合单射；在指定扰动域内核交为零才是此处的联合条件。

```math
\max(-p_0,-p_{25})\le t\le\min(p_2,p_5).
```

在边界上，“任意小的 $t$”不保证两种符号的增量都合法。原文四的逆式给出概率律还须满足五个重建质量均非负；不可行的四坐标只给出 $H$ 中的有符号向量。纤维是可能退化为点的线段；正方形是生成隐藏方向的四顶点仿射回路，不是纤维本身的形状。

### Q2. 同源读数、精确期望与恢复目标（原文三、四、六、七）

$q$ 的五个取值 $0,2,3,5,7$ 互异，完整逐次 $q$ 记录已能辨认每次的五态符号；丢失联合信息的是只保留它的一阶平均。一个符号记录不确定整条概率律，精确律的辨识也不恢复任意个别历史、来源树或量子态。$\chi$ 与 $q^2$ 的公式是指定五态函数的期望关系；将它们实现为能量、涨落或符合事件仍是待定义的探测器模型。

### Q3. 动态未来等价的原生条件（原文八）

原文定理 5 保留为对[动态未来商来源](AURIC_FIB_ATOM_DYNAMIC_FUTURE_QUOTIENT_AND_FUTURE_CLOSED_MEMORY.md)的归属主张，采用该卷 Q1–Q4 及 Part I 的活动历史域，不在本卷重证或认证。它要求一个固定、有限或可数、定义在正整数深度上的非单例正支持先验；隐藏 $K$ 在首次实际 Read 前只抽取一次，并为所有 Reads 共享，Reads 在给定这个 $K$ 后按来源模型取样。

历史必须是第三标记写入并锁存后的、正概率可达的第四段活动历史，保留付费的等对拒绝、返回、实际记录和合法残余操作；不对未来接受事件另作条件化。$(a,A_h,B_h)$ 的可达集合不是任意计数格点集合。比较的是该合法域上的完整概率残余未来律，不是均值、单条回复或外部观察者未取得的记录。

由完整未来律识别 phase 和后验、以及 Fibonacci 比率的整数指数分离，是所引来源中的承重前提，仍需其精确条件，本卷不提供新的分离证明。活动、pending$_0$、pending$_1$ 与 delivered 是不同边界域：pending 只准原有匹配 Stop，delivered 的未来为空，不能用活动分类一律替代。单例先验另有例外。将静态 $\kappa$ 与后验计数合并还需共同来源、联合律和响应核；原文八未证明任意静态五态律与该动态过程之间的接口。把射线事件等同于实际 $\alpha/\beta$ 记录、或把预测差异归因于未记录历史，均保留为需该接口的解释。

### Q4. 配对校准的数组、参数域与共同可实现性（原文九）

原文的可识别性限于[配对可观测性来源](RECURSIVE_RELATIONAL_OBSERVATION_PAIRED_CALIBRATION_OBSERVABILITY.md) §§2–4 的完整配置索引事件数组。两相读出分别是各个配置上规定事件 $E_p=\{w_{0,1},w_{1,1},w_{2,1}\}$ 和 $E_\beta=\{\beta,\alpha w_{0,1}\}$ 的概率；一个平均后的标量 $f$ 与一个标量 $h$ 不替代这些数组。此处 $h$ 是数组记号，不是原文五的个别历史；响应律 $W_y$ 也不是静态的 $W=Z+\kappa$。

共同原料为固定的有限随机 acquired kernels $B:X\to Y$、$A:Y\to X$，严格正的兼容平稳行 $\pi B=\tau$、$\tau A=\pi$，以及 regular 参数 $u_x,v_y\in[1/3,2/5]$。在同一循环的这个参数域内，来源定理 4.1 才给出全局唯一性和完整生成律的确定；本卷将其作为来源主张引用。任意提议数组还须满足来源推论 4.2 的未投影相容性方程，落在读数区间或存在投影反馈不动点均不自动等于共同可实现。

回接原生风险任务时还须继承该来源 §2 的 once-sampled 深度、完整记录、付费拒绝、合法第四段与终止域等约束，其中规定的原生先验满足 $\mu(1),\mu(2)>0$。其离线语义重建不新增实际查询、运行时读口、后验端口或保资源的观察者替换。静态线性核与非线性反馈逆在此只作比较；没有给出对象、操作、量词与误差的双向对应，故原文的“完全同构”是类比，不是已建立的同构或射线探测器实现。

### Q5. 两窗口的支持与读数秩（原文十）

$25$ 维完整函数空间和 $9$ 维未观察空间采用不受守卫限制的 Cartesian 域 $\Sigma^2$，且可用读数是整个 $V\otimes V$ 的期望。这包含跨窗口乘积 $x_1x_2,x_1y_2,\ldots,z_1z_2$，不只是两组各自的线性边际；允许窗口相关，不要求概率独立。

若只保留各窗口的三个均值，则可用函数空间是

```math
\operatorname{span}\{1,x_1,y_1,z_1,x_2,y_2,z_2\},
```

维数为 $7$，在 $\Sigma^2$ 的 $25$ 维函数空间中留下 $18$ 个隐藏方向。两组完整单窗分布又是不同的读数合同，不能用这些均值计数代替。接缝守卫、重叠窗口或固定支持须在真实允许对集上重新限制函数并计算秩；可行边界也会缩小实际纤维。原文的 scoped $12$ 另属其固定边际、守卫与双窗口合同，本卷不推导它，也不用它替代 $9$ 或 $18$。

### Q6. 经典左逆与可访问边界（原文五至七）

经典“恢复函数”的含义必须包含

```math
R_A\circ(O_A|_C)=\operatorname{id}_C.
```

只要求存在某个映射 $O_A(C)\to C$ 并不表达恢复。指定这个左逆等式后，单射性给出的是集合论上的逆，不保证可计算、可取得、可校准或成本可接受；还需声明目标历史类 $C$。五态概率律单射性与完整历史单射性属于不同域，原文的“完全相同”只在不可区分纤维的抽象关系上作类比。

原文的吸收体 $A$ 与“全部可访问子系统”也须区分。射线不在吸收体内，不自动说明残余物、环境或其他可访问记录未保留相应区别。自由逃逸例成立的条件是观察投影确实只依赖所列相等部分，并且没有取得能区分这对历史的新记录；局部不可区分不判断全局信息是否被删除。

### Q7. 量子恢复、no-hiding 与探测背景（原文六、七）

量子通道须明确码空间、初始辅助态、吸收体及残余物的归属，并将所有输出自由度分成可访问 $A_{\rm acc}$ 与其补系统 $B_{\rm env}$。若用等距扩张表示，纯化后的形式为 $V:\mathcal H_C\to\mathcal H_{A_{\rm acc}}\otimes\mathcal H_{B_{\rm env}}$；吸收体自由度须包含在相应因子内，不能既作为记录又从扩张中遗漏。精确量子恢复要求一个完全正保迹（CPTP）的物理通道 $\mathcal R$，对声明码上的所有目标密度算符满足

```math
\mathcal R\circ\mathcal N_{A_{\rm acc}}(\rho)=\rho.
```

仅在一组状态上有集合论单射性不足以保证这种 CPTP 左逆。原文的相干转移箭头需在指定模式和输入族上保留内积、相干性及相关自由度；有光—物质记忆接口的例子不确定此处的 FIB 实现。保持 $A[I]$ 同时产生 $E[I]$ 的乘积箭头只可示意适当的经典或正交记录，不描述任意未知非正交量子态的复制。温度粗粒化的多对一性与量子退相干也不是同一命题；要讨论退相干须给出量子态、系统—环境耦合及局部约化。

两个输入满足 $\mathcal N_A(\rho_0)=\mathcal N_A(\rho_1)$，只推出任何共同局部后处理仍不能区分这两个输出。no-hiding 的适用前提更强：在指定的整个输入空间上，局部输出对每个输入态均为同一个固定态，并有包含辅助态纯化的等距或幺正扩张；在这些前提下，输入信息可由补系统恢复，不仅藏在两部分的相关中。环境能否被当前观察者取得是另一问题。该前提不是一对输出相等、一般温度读数相等或任意吸收事件。

这里所引定理原始来源为 Samuel L. Braunstein 与 Arun K. Pati，*Quantum information cannot be completely hidden in correlations: implications for the black-hole information paradox*，Phys. Rev. Lett. **98**, 080502，[DOI 10.1103/PhysRevLett.98.080502](https://doi.org/10.1103/PhysRevLett.98.080502)，[gr-qc/0603046](https://arxiv.org/abs/gr-qc/0603046)。原文保留的 [1004.5073](https://arxiv.org/abs/1004.5073) 是 Jharana Rani Samal、Arun Kumar Pati 与 Anil Kumar 的 *Experimental Test of Quantum No-Hiding Theorem*，不是原始定理出处。

原文的 NIST 材料、光锥说明、[nature07607](https://www.nature.com/articles/nature07607) 光学记忆例及 Schlosshauer 的退相干综述只支持各自限定的物理背景；它们没有把 $q,\chi,\kappa$ 认证为能量、射线或实际吸收体的输出。探测器噪声、可达模式、因果路径与有效记录各须另行建模；本卷不从这些文献推出遮挡的一般可逆性或 FIB 的物理定律。

### Q8. 记录因子化、时间与生命解释（原文十一、十二及最终统一命题）

在同一历史域上，原文定理 6 的关系包含只由实际因子化 $M_{t+1}=G_t\circ M_t$ 推出。没有返回射线本身不保证因子化：残余物、环境、其他传入信号或新增测量仍可提供此前未记录的信息。包含可以取等号，不能据此断言每一步都有严格损失、纤维严格增大或熵严格增加。

加入 $b_t$ 可以区分一对原先同记录的历史，但更新 $(G_t(M_t),b_t)$ 也可能丢失其他旧区别；不能默认整个新分划细于旧分划。若要保证保留全部旧区别，还须能从新记录恢复旧记录，或直接维护 $(M_t,b_t)$。反过来，仅有新的返回记录也不保证它实际切开目标纤维。

把该观察商包含称为“有效时间箭头”，以及把主动记录、反馈和维护称为“生命”或“逆衰变”，均是所提供文本的操作性提案。因子化不推出物理时间不存在、引力等于时间、微观演化倒流、普遍热力学箭头或生物学定义。能量、校准、容量、控制、排热及资源耗尽后的行为仍须相应资源与维持模型；原文没有证明它们的预算或可行性。

最终统一命题应逐项携带以上条件：第一项须明确可访问边界及未取得新区别的条件，不能只用射线无返回；第二项针对同律的校准精确期望及可行非退化纤维；第三项须保留原读出、要求重建质量非负，并在 $T$ 上使用核交为零；第四项的局部不可恢复须针对相同局部输出的历史或状态，或针对没有恢复左逆的指定目标域；第五项须有 $M_{t+1}=G_t\circ M_t$，且允许不可区分关系保持不变；第六项须有可取得的新读出与实际反馈、保存和维持能力。它是一份附条件的来源综合，不是经认证的射线—时间—生命统一定理。
