## 摘要

一个持续运营的 agent 会犯错。本卷的中心观察是:**经验不是记忆的堆积,而是一个从错误类到制度的单调映射;运营者的成熟度不是错误率,而是该映射的延迟分布**。由此得到五个可形式化的对象:学费单调律(每类恰付一次)、捕获阶梯(撞墙→拦截→写时自查的三级滤链)、工件不变量(杀伤无谓性的充要条件)、产物-信封分离(裁决不依赖自报)、让渡代数(多运营者的无协调分工)。全部结构有限、可判定,义务清单 T-A..T-H 预登记于第八部。

$$
\boxed{\text{经验}=\text{错误类}\xrightarrow{\ \text{单调}\ }\text{制度};\quad \text{成熟度}=\text{捕获延迟的分布左移}.}
$$

---

# 第一部　对象

**定义 1.1(运营轨迹)**。运营轨迹是四元组 $(E,\ \mathrm{cls},\ I,\ \iota)$:错误事件的线性序 $E$;分类映射 $\mathrm{cls}:E\to C$ 到错误类集 $C$;制度集 $I$(机器可执行的守卫:断言、门、brief 条款、记忆条目);登记映射 $\iota:C\rightharpoonup I$(偏函数——尚未立制的类即未定义处)。

**定义 1.2(错误类是商,不是清单)**。$C$ 是事件集对「同修复」等价关系的商:$e\sim e'$ 当且仅当消除其一的制度必然消除另一。类的内涵须推到不动点再枚举(判例:SL-019 五形,2026-08-25..27;「效果性产物未核实」四形收束为一类,2026-08-28)。**按槽立制是三病中的身份编码**:每槽一修,压缩为零。

**定义 1.3(捕获层级)**。每个事件带捕获标签 $\lambda(e)\in\{\mathrm{wall},\mathrm{gate},\mathrm{author}\}$:撞墙后发现(事后诊断)/被既有 fail-fast 拦截(损失有界)/写下时自查抓住(零损失)。三级构成全序 $\mathrm{wall}<\mathrm{gate}<\mathrm{author}$。
*判例锚*:msgfile 缺失类三次出现的层级序列恰为 wall(la25,08-29)→ gate(la48b,BAD_MSG 断言)→ author(la50 等待链,发射后一分钟自查补文件,08-30)。

# 第二部　学费单调律

**公理 T1(每类恰付一次)**。$\iota$ 一旦在 $c$ 处有定义,永不撤销(制度只增,append-only);且第二次出现同类事件而 $\iota(c)$ 已定义者,记为**制度缺陷事件**(其类属于元层:$\mathrm{cls}$ 或 $\iota(c)$ 本身错了),而非原类的又一次学费。
*判例锚*:回收器蒸发类第一次(la25 msgs/)被 mkdir 了事、第二次(wave-3 briefs)才立制——本卷把「第一次就立类」定为律,第二次的代价归为对律的违反(2026-08-29 实付)。

**定理骨架 T-A(制度映射单调)**。沿轨迹前缀序,$\mathrm{dom}(\iota)$ 单调不减;违律状态(同类二现且已立制)可判定。〔有限结构,elementary〕

**定义 2.1(学费经济)**。类 $c$ 的学费 = 首事件的全部损失;收益 = 此后所有同类事件被 $\iota(c)$ 压到 gate/author 级的损失差。**错误是燃料**(母仓第 20′ 条)在此取值化:轨迹的净资产 = $\sum_c(\text{避免损失}-\text{学费})$。

---

# 第三部　捕获阶梯与半衰期

**定义 3.1(成熟度)**。类 $c$ 的成熟度 = 其事件捕获层级的历史序列;运营者成熟度 = 各类层级分布随时间的左移(wall 占比降,author 占比升)。**不是错误率**:健康轨迹的错误率可以不降(新类持续出现是探索的证据),降的是**每类内部的捕获延迟**。

**定义 3.2(错误类半衰期)**。$h(c)$ = 从首事件到该类稳定达到 gate 级以上所经的事件数(或挂钟)。
*判例锚(实测序列)*:「凭印象写谓词」类:dotnet 中文输出(旧账)→ 收卷器状态词(wall,08-30)→ `.git` 文件谓词(wall,同日,**墨迹未干再犯**)——半衰期尚未收敛,该类在第八部记开放义务(T-C 的反面样本)。

**定理骨架 T-B(阶梯是滤链)**。以捕获层级给事件集分层得滤链;T1 下,已立制类的事件层级不降(除非发生制度缺陷事件)。〔有限偏序,elementary〕

**响应升级律(公理 T2)**。对重复刺激禁止重复响应:同一外部刺激(杀链、超时、同判词红)第 $n$ 次出现时,响应必须与第 $n-1$ 次不同(换假设、换工具、或停止并立案)。盲重试 = 对 T2 的违反。
*判例锚*:三连批杀的响应序列=逐一验尸(5min)→ 快速重驱(2min)→ 单探针+预登记停止条件(2026-08-29);nyxid 三败的响应序列=拆分→池假设→换池,零盲重试(08-30)。

# 第四部　工件不变量与杀伤无谓性

**定义 4.1(工件充分)**。运营状态在时刻 $t$ 工件充分,若恢复继续运营所需的一切信息都在持久工件(提交、落盘脚本、issue 留痕)中,会话内存清零亦可重建。

**定理骨架 T-D(杀伤无谓)**。若轨迹处处工件充分,则任意外部杀伤(进程组清除、会话中断)的损失上界 = 自上次工件化以来的挂钟,且**字节损失为零**。逆命题:存在非工件化状态 ⟹ 存在使其不可恢复的杀伤。〔玩具转移系统上可 kernel 化〕
*判例锚*:四次批杀,累计字节损失 0;la28/la47 两席被杀于信封窗口,数学以提交幸存,由产物判收落地(2026-08-29/30)。

**推论 4.2(检查点密度)**。提交越早越密,杀伤越无谓;席位工作流「先数学后信封」使杀伤面天然偏向可恢复侧——**工件纪律同时是审计、恢复、协作三件事的载体,一次投资三处分红**。

---

# 第五部　产物-信封分离

**定义 5.1**。席位交付有两个通道:**信封**(自报:conclusion/status)与**产物**(可独立验证的字节:提交、冻结事件、退出码)。裁决权威永远在产物;信封是路由提示。

**定理骨架 T-E(无信封判收的充要条件)**。信封缺失时,产物可独立判收当且仅当**判据在产物产生之前已预登记**(义务原文在卷、判据写死)。预登记的第二红利:**席位死亡时遗产可继承**。〔可在有限见证结构上形式化〕
*判例锚*:la28(57.3-A)与 la47(OP1 分裂判决)均于载体中断后按产物落地,靠的都是预登记义务文本的逐字读back(08-29/30)。

**公理 T3(样本先行)**。凡对外部输出写判断谓词,先捕真实样本、从样本拟谓词;写侧对偶为「替换必断言」。违者归入 1.2 的同一错误类。

# 第六部　让渡代数(多运营者无协调分工)

**定义 6.1(先撞分配)**。多运营者共驱同一真源时,问题的实施权按「谁先撞上并留痕」分配;留痕(带读数的 issue 认领)即持有。

**公理 T4(让渡与收回)**。持有者活跃(有读数或在飞 PR)⟹ 他者让渡并留自己的受影响读数;持有者停滞超过声明阈值 ⟹ 任何人可收回,收回时留痕。活性判据必须**可判**(评论时间戳、PR 状态),不得凭感觉。
*判例锚*:#3940 让渡(对方 fix 轮进行中)与 #3363 反例(对方未动,等待是错)构成对照双判例;#4120 越线案从红到他机修复 PR 在飞 < 数小时,我方角色自动收缩为读数供给(08-29/30)。

**定理骨架 T-F(无协调不重复)**。若全体运营者遵守 T4 且留痕原子可见,则同一问题不会被两方同时实施(除可见性延迟窗口内);该窗口的期望碰撞率随留痕延迟单调。〔有限协议模型,elementary〕

---

# 第七部　理解不可外包与独立收敛

**公理 T5(中心语境即协调基底)**。orchestrator 对领域的**亲身模型**不可外包:派席适用于验证与平行视角,不适用于替代中心的理解。空心的中心协调不了任何东西——楔子地图、判据设计、收敛检验全部依赖中心语境的厚度。
*判例锚*:「先理解全部再奇思妙想」纠偏(2026-08-30):亲读五遍冻结面后自研四构思,与盲席(跨模型族)三处独立相撞——**收敛检验之所以可能,恰因中心没有外包理解**。

**定理骨架 T-G(收敛的证据值)**。独立收敛的判别力随视角独立性(可见输入不相交、模型族不同)单调;同族同输入的「收敛」判别力为零。〔可在有限贝叶斯玩具上形式化〕

# 第八部　证明义务清单(预登记)

以下义务 elementary(单命题、单模块、有限构造、无测度前件),先于任何证明写下:

- **T-A(制度映射单调)**:轨迹前缀序上 $\mathrm{dom}(\iota)$ 单调不减;同类二现违律可判定。
- **T-B(阶梯滤链)**:捕获层级滤链在 T1 下的不降性;制度缺陷事件为唯一例外并可定位。
- **T-C(半衰期良定)**:$h(c)$ 在有限轨迹上可计算;给出「墨迹未干再犯」的反例轨迹见证其非平凡。
- **T-D(杀伤无谓)**:玩具转移系统上,工件充分 ⟺ 任意杀伤零字节损失。
- **T-E(预登记判收)**:信封缺失时产物判收可行 ⟺ 判据先于产物;构造双向见证。
- **T-F(先撞分配不重复)**:有限协议模型上,T4 合规 ⟹ 无并发实施(可见性窗口外)。
- **T-G(收敛判别力)**:有限视角模型上,判别力对独立性的单调性;同族退化为零。
- **T-H(响应升级良基)**:T2 下对同一刺激的响应序列无穷不重复 ⟹ 存在停止或换类;盲重试轨迹违 T2 可判定。

**可证伪预测(第 5′ 条)**:若本卷抓对了类,则任何遵守 T1–T5 的运营轨迹上,wall 级占比随事件数下降的趋势可在本仓自身的审计链上**回测**(转录与 issue 时间戳皆在);若回测不显示左移,第三部的成熟度定义切错了面,修定义而不辩数据。

### v1.0.1 勘误注记 — 2026-08-30(措辞勘误,不改语义)

**「公理 T1–T5」的形式化居所澄清(owner 指出,母仓公理纪律)**:本仓 kernel 判决只认标准三公理闭包(propext、Classical.choice、Quot.sound),私 axiom 为硬禁、新增 axiom 属 τ=0 不可逆门。故本卷五条「公理」**一律不是 Lean axiom**:它们是**定义性运营律**——形式化时作为结构字段或定理前件落地(如「T1-合规轨迹」是一个 `structure`/谓词,义务对合规轨迹量化),任何席位不得据本卷引入 `axiom` 声明;义务 T-A..T-H 的证明必须保持标准三公理闭包,违者按第 4 条冒领论。初版正文措辞不回写(追加纪律),以本注记为准;正文中「公理 Tn」自此读作「律 Tn(定义性)」。
