## 一、原生公式：两个原子、有序组合与递归替换

**定义 1.1（来源语法）。** 自由有序二叉树及其替换为

```math
\mathbb T::=\alpha\mid\beta\mid\langle\mathbb T,\mathbb T\rangle,
\qquad
\rho(\alpha)=\beta,\qquad \rho(\beta)=\langle\beta,\alpha\rangle,
```

```math
\rho(\langle s,t\rangle)=\langle\rho(s),\rho(t)\rangle.
```

左右次序和括号是来源的一部分，特别是 $`\langle\alpha,\beta\rangle\ne\langle\beta,\alpha\rangle`$。

**数学引文 1.2（结构递归及组成桥）。** 按关系延拓几何定理 1.2、1.4，令 $`T_n=\rho^n(\alpha)`$，则对所有整数 $`n\ge0`$，

```math
T_0=\alpha,\qquad T_1=\beta,\qquad
T_{n+2}=\langle T_{n+1},T_n\rangle.
```

定义组成和数量行

```math
c(\alpha)=\binom10,\quad c(\beta)=\binom01,\quad
c(\langle s,t\rangle)=c(s)+c(t),\quad q=(2,3),
```

得到

```math
c(\rho t)=Mc(t),\qquad
M=\begin{pmatrix}0&1\\1&1\end{pmatrix},\qquad
M^2=M+I,\quad \det M=-1,\quad M^{-1}=M-I.
```

证明的对应如下：结构递归在 $`n=0`$ 是替换定义，施加保持有序括号的 $`\rho`$ 即完成归纳；组成式在两叶成立，在二叉节点由加法继续成立。矩阵恒等式直接相乘得到。若 $`F_0=0,F_1=1,F_{n+2}=F_{n+1}+F_n`$，则

```math
q c(\alpha)=2,\qquad q c(\beta)=3,\qquad q c(\rho^2\alpha)=5,
\qquad qM^n c(\alpha)=F_{n+3}\quad(n\ge0).
```

最后一式由初值二、三及 $`M^2=M+I`$ 的递推得到。矩阵逆只在组成表示上给逆线性运算；例如原生树 $`\alpha`$ 不在 $`\rho`$ 的像中，故没有对全部树的逆替换。来源到组成已合并两种叶序，组成到数量又合并 $`(3,0)`$ 与 $`(0,2)`$。后文的平均式不会恢复被这些映射删除的区别。

## 二、五模式公式：合法位词、函数代数与事件

**定义 2.1（两个坐标次序）。** 以 $`x`$ 表低端二位置、$`y`$ 表高端五位置、$`z`$ 表中间三位置，占位坐标按低—高—中排列；印刷三位始终按低—中—高排列。合法性为

```math
x,y,z\in\{0,1\},\qquad xz=0,\qquad yz=0.
```

两端没有彼此排斥条件，故 $`xy`$ 可为一。五模式集合记 $`\Sigma=\{0,2,3,5,25\}`$；概率分量全卷按这一次序书写。

| 模式 | 印刷位串 | 坐标 $`(x,y,z)`$ | 组成贡献 $`d_s`$ | 零层数量 $`qd_s`$ |
| --- | --- | --- | --- | ---: |
| $`[null]`$，简记 $`0`$ | $`000`$ | $`(0,0,0)`$ | $`(0,0)^{\mathsf T}`$ | $`0`$ |
| $`[2]`$ | $`100`$ | $`(1,0,0)`$ | $`(1,0)^{\mathsf T}`$ | $`2`$ |
| $`[3]`$ | $`010`$ | $`(0,0,1)`$ | $`(0,1)^{\mathsf T}`$ | $`3`$ |
| $`[5]`$ | $`001`$ | $`(0,1,0)`$ | $`(1,1)^{\mathsf T}`$ | $`5`$ |
| $`[25]`$ | $`101`$ | $`(1,1,0)`$ | $`(2,1)^{\mathsf T}`$ | $`7`$ |

$`[25]=[2+5]`$ 是同窗共同选择，数量为 $`2+5=7`$。零贡献是空窗口的贡献，不是原始非空树。实际读取 $`[null]`$、尚未读取、停止、空词和乘法单位各有不同语义；第十一节的实际空窗仍推进旧组成。

**数学引文 2.2（五函数展开与多项式商）。** 二阶关系完成定理 39.2 给每个 $`f:\Sigma\to\mathbb R`$ 的唯一展开

```math
f=c_0+c_xx+c_yy+c_zz+c_{xy}xy,
```

```math
c_0=f_0,\quad c_x=f_2-f_0,\quad c_y=f_5-f_0,\quad
c_z=f_3-f_0,\quad c_{xy}=f_{25}-f_2-f_5+f_0.
```

其多项式形式是代数同构

```math
\mathbb R[x,y,z]/(x^2-x,y^2-y,z^2-z,xz,yz)
\cong\mathbb R^\Sigma\cong\mathbb R^5.
```

证明。幂等关系把每个单项式的各变量幂降到零或一；含 $`xz`$ 或 $`yz`$ 的项消失，余项只可能是 $`1,x,y,z,xy`$。在 $`0,2,5,3`$ 四点评价依次强制前四系数，在 $`25`$ 评价强制最后系数。故五个余类独立，评价映射既满射又单射，并保持逐点乘法。这证明其核恰为所列理想，而不是仅声称五点上某些多项式为零。∎

完整事件的幂等元为

```math
e_0=1-x-y-z+xy,\quad e_2=x-xy,\quad e_3=z,\quad
e_5=y-xy,\quad e_{25}=xy,
```

```math
e_se_t=\delta_{st}e_s,\qquad \sum_{s\in\Sigma}e_s=1.
```

逐点评价得到一组互斥、穷尽的事件指示函数。特别 $`e_0\ne1`$：空窗是一个特定事件，常数一在全部合法模式成立。代数余类是函数表达方式；能够写下 $`e_s`$ 不等于已经取得该事件的实际记录或概率。

## 三、金字塔几何：五顶点、五面、八棱与全部单项式矩

**定义 3.1（占位凸体及尺子）。** 令

```math
v_0=(0,0,0),\quad v_2=(1,0,0),\quad v_5=(0,1,0),\quad
v_{25}=(1,1,0),\quad v_3=(0,0,1),
```

```math
\mathcal P=\mathop{\mathrm{conv}}\nolimits\{v_0,v_2,v_3,v_5,v_{25}\}.
```

面积和体积均取这组占位坐标上的标准欧氏内积与坐标 Lebesgue 测度。

**数学引文 3.2（凸体和面表）。** 金字塔关联与原生接续 §§一–二，以及 Stanley 的 chain-polytope 条款，在此给

```math
\mathcal P=\{(X,Y,Z):X,Y,Z\ge0,\ X+Z\le1,\ Y+Z\le1\}.
```

置 $`r=1-Z`$。当 $`r>0`$ 时，$`0\le X,Y\le r`$ 且

```math
(X,Y,Z)=r(X/r,Y/r,0)+Z(0,0,1).
```

底面点在单位正方形上，故这证明不等式域包含于凸包；反向逐顶点满足约束，凸性给包含。$`r=0`$ 时约束强制 $`X=Y=0`$，只有顶点。五条面约束均不可去掉，面表为

| 面 | 方程 | 面顶点 | 欧氏面积 |
| --- | --- | --- | ---: |
| 底面 | $`Z=0`$ | $`v_0,v_2,v_{25},v_5`$ | $`1`$ |
| 侧面一 | $`X=0`$ | $`v_0,v_5,v_3`$ | $`1/2`$ |
| 侧面二 | $`Y=0`$ | $`v_0,v_2,v_3`$ | $`1/2`$ |
| 侧面三 | $`X+Z=1`$ | $`v_2,v_{25},v_3`$ | $`\sqrt2/2`$ |
| 侧面四 | $`Y+Z=1`$ | $`v_5,v_{25},v_3`$ | $`\sqrt2/2`$ |

底面有四条边 $`v_0v_2,v_2v_{25},v_{25}v_5,v_5v_0`$；另四棱从 $`v_3`$ 接每个底角。故顶点数五、棱数八、面数五，$`5-8+5=2`$。三角面积由两条边的叉积范数除以二给出，表面积为

```math
S(\mathcal P)=2+\sqrt2.
```

固定 $`Z=t`$ 的截面边长为 $`1-t`$、面积为 $`(1-t)^2`$，所以

```math
\mathop{\mathrm{Vol}}\nolimits(\mathcal P)=\int_0^1(1-t)^2\,dt=\frac13.
```

**命题 3.3（所选体积测度的全部单项式矩）。** 对任意非负整数 $`a,b,c`$，

```math
\int_{\mathcal P}X^aY^bZ^c\,dV
=\frac{c!(a+b+2)!}{(a+1)(b+1)(a+b+c+3)!}.
```

证明。先在 $`0\le X,Y\le1-Z`$ 积分得到

```math
\frac1{(a+1)(b+1)}\int_0^1Z^c(1-Z)^{a+b+2}\,dZ.
```

记 $`B(c,d)=\int_0^1t^c(1-t)^d\,dt`$。$`B(0,d)=1/(d+1)`$；$`c>0`$ 时以 $`(1-t)^{d+1}`$ 的导数分部积分，边界项为零，得 $`B(c,d)=cB(c-1,d+1)/(d+1)`$。归纳得 $`B(c,d)=c!d!/(c+d+1)!`$，取 $`d=a+b+2`$ 即得。∎

前三个一阶矩为 $`\int X=\int Y=1/8`$、$`\int Z=1/12`$，除以体积给均匀体积重心

```math
\mathop{\mathrm{centroid}}\nolimits(\mathcal P)=(3/8,3/8,1/4).
```

均匀体积不是五顶点均匀律；后者平均点为 $`(2/5,2/5,1/5)`$。凸结构、所选度量与概率测度是不同输入。这些数值不规定物理长度单位、物理空间维数或各向同性。

## 四、正方形回路与完整概率纤维

**定义 4.1（同一窗口律）。** 给非负、归一化的

```math
p=(p_0,p_2,p_3,p_5,p_{25}),\qquad
X=p_2+p_{25},\quad Y=p_5+p_{25},\quad Z=p_3,
\quad r=1-Z,
```

```math
\kappa=p_{25}=\mathbb E_p[xy].
```

五纯模式彼此不同；歧义来自凸混合中的正方形关系

```math
v_0+v_{25}=v_2+v_5.
```

**数学引文 4.2（同均值核和非负区间）。** 复用二阶关系完成定理 53.1、金字塔关联与原生接续 §§三–四的逆式，在本卷分量次序为

```math
\begin{aligned}
p_0&=r-X-Y+\kappa,&p_2&=X-\kappa,&p_3&=Z,\\
p_5&=Y-\kappa,&p_{25}&=\kappa.
\end{aligned}
```

```math
\kappa_-:=\max(0,X+Y-r)\le\kappa\le
\kappa_+:=\min(X,Y).
```

由三个均值反解后，五项非负正好给这些界；对每个 $`P\in\mathcal P`$ 区间非空。两个同均值律恰有

```math
p'-p=t(1,-1,0,-1,1).
```

这是归一化概率超平面的唯一线性核方向；非负性将直线截成闭区间。其长度为

```math
w_\kappa=\kappa_+-\kappa_-
=\min\{X,Y,r-X,r-Y\}.
```

证明宽度式可按 $`X\le Y`$ 和 $`X+Y\le r`$ 的四种组合直接相减；例如两条件都成立时宽度为 $`X`$，$`X\le Y`$ 而 $`X+Y\ge r`$ 时为 $`r-Y`$，另两种对称。于是

```math
w_\kappa=0
\iff X=0\ \text{或}\ Y=0\ \text{或}\ X=r\ \text{或}\ Y=r.
```

这恰是四张三角侧面的并集，包含全部棱和顶点。底面内部 $`Z=0,0<X,Y<1`$ 的宽度严格正。顶点 $`r=0`$ 的唯一律为 $`p_3=1`$，其余为零。

例如 $`\tfrac12\delta_0+\tfrac12\delta_{25}`$ 与 $`\tfrac12\delta_2+\tfrac12\delta_5`$ 都给 $`(1/2,1/2,0)`$，但 $`\kappa`$ 分别为 $`1/2`$ 和零。完整五模式律是四维单纯形；金字塔是它投掉一条方向后的三维像，并非两个确定标签碰撞。

## 五、底面行列式：条件关联与绝对预算

**定义 5.1（底面四格）。** 以行表示 $`x=0,1`$，列表示 $`y=0,1`$，置

```math
Q=\begin{pmatrix}p_0&p_5\\p_2&p_{25}\end{pmatrix}
=\begin{pmatrix}r-X-Y+\kappa&Y-\kappa\\X-\kappa&\kappa\end{pmatrix},
```

```math
Q\mathbf1=(r-X,X)^{\mathsf T},\qquad
\mathbf1^{\mathsf T}Q=(r-Y,Y),\qquad
\Delta=\det Q=p_0p_{25}-p_2p_5.
```

**数学引文 5.2（条件行列式）。** 金字塔行列式卷 §四的公式在此为

```math
\Delta=r\kappa-XY.
```

仅当 $`r>0`$ 时可以写

```math
\kappa=\frac{XY+\Delta}{r},\qquad
\mathop{\mathrm{Cov}}\nolimits_p(x,y\mid z=0)=\frac\Delta{r^2}.
```

证明。展开四格行列式，二次 $`\kappa`$ 项相消。$`Q/r`$ 是底面条件律，其两个均值为 $`X/r,Y/r`$，共同概率为 $`\kappa/r`$，协方差相减即得。$`r=0`$ 时 $`Q=0,\Delta=0`$，但没有底面条件分布。∎

**数学引文 5.3（锐界与缩放）。** 同卷 §九给

```math
|\Delta|\le r^2/4.
```

若 $`\Delta\ge0`$，则 $`\Delta\le p_0p_{25}\le(p_0+p_{25})^2/4\le r^2/4`$；负号情形对 $`p_2p_5`$ 同理。底面对角各半的律达到正、负界，固定顶点质量 $`Z=1-r`$ 后仍达到。截面面积及未归一化关联预算都按 $`r^2`$ 缩小；$`\Delta/r^2`$ 的条件强度却可始终为 $`\pm1/4`$。行列式为概率律的二次统计，不是新增空间轴或免费单份读口。

## 六、同一 separator 上的三角边缘与乘积补全

**定义 6.1（共同中位）。** 两个边缘来自定义 4.1 的同一律，分别在 $`(x,z)=(0,0),(1,0),(0,1)`$ 及 $`(y,z)=(0,0),(1,0),(0,1)`$ 上为

```math
p_L=(r-X,X,Z),\qquad p_R=(r-Y,Y,Z),\qquad
p_z(0)=r,\quad p_z(1)=Z.
```

两侧的 $`z`$ 是同一个随机变量；相同名称或相同边缘数值不能替代这个来源关系。

**数学引文 6.2（指定乘积补全）。** 复用行列式卷 §五的拼接，以及 Wainwright–Jordan 例 2.2 的 separator 因子，定义

```math
p^\star(x,z,y)=
\begin{cases}
p_L(x,z)p_R(y,z)/p_z(z),&p_z(z)>0,\\
0,&p_z(z)=0.
\end{cases}
```

零 separator 下两边所有对应非负项均为零。正 separator 下求和得到 $`p_z(z)`$，故全律归一化并有原边缘。$`r>0`$ 时逐格为

```math
\begin{aligned}
p_0^\star&=(r-X)(r-Y)/r,&p_2^\star&=X(r-Y)/r,\\
p_3^\star&=Z,&p_5^\star&=Y(r-X)/r,&p_{25}^\star&=XY/r.
\end{aligned}
```

$`r=0`$ 时直接定义 $`p^\star=\delta_3`$。这也等于上式的连续顶点延拓：四个底面概率均不超过 $`r`$。

**命题 6.3（补全的性质及其适用范围）。** 在全部闭单纯形上，$`p=p^\star`$ 当且仅当每个正质量 $`z`$ 条件下 $`x\perp y\mid z`$。当 $`r>0`$ 时又等价于 $`\Delta=0`$；顶点时两者都成立。

证明。$`z=1`$ 的正质量纤维只有 $`(x,y)=(0,0)`$。$`z=0`$ 的二元表在 $`r>0`$ 时由固定行列边缘唯一给乘积表；Drton–Sullivant 例 16 的交叉乘积方程在此就是 $`\det Q=0`$，亦可由 $`\kappa=XY/r`$ 直接验证。零行或零列只留下确定边缘，仍成立；零质量纤维不声称存在条件分布。∎

分母使共同 separator 不被左右重复计数。乘积补全是一份合法选择；只有真实来源满足该条件独立时才等于来源律。它没有把可选 Markov 条件升级为任意任务的必要条件。

**数学引文 6.4（共同条件产生整体相关）。** 即使 $`\Delta=0`$，当 $`r>0`$ 时仍有

```math
\mathop{\mathrm{Cov}}\nolimits_{p^\star}(x,y)=\kappa^\star-XY
=XYZ/r.
```

由 $`\kappa^\star=XY/r`$ 及 $`1-r=Z`$ 得式；它严格正恰当且仅当 $`X,Y,Z`$ 都严格正。五模式均匀律 $`p_s=1/5`$ 给

```math
X=Y=2/5,\quad Z=1/5,\quad r=4/5,\quad
\kappa=1/5,\quad \Delta=0,\quad \mathop{\mathrm{Cov}}\nolimits(x,y)=1/25.
```

条件独立与无条件独立不同；共同顶点使两端一起为零。

## 七、指定目标的精确公式、固定纤维与 minimax

**定义 7.1（目标差分）。** 对有限实目标 $`f:\Sigma\to\mathbb R`$，定义

```math
J_f=f_{25}-f_2-f_5+f_0.
```

**数学引文 7.2（全部平均目标）。** 五函数基及行列式卷 §十给

```math
\begin{aligned}
\mathbb E_p[f]={}&f_0+(f_2-f_0)X+(f_5-f_0)Y\\
&+(f_3-f_0)Z+J_f\kappa.
\end{aligned}
```

将第四节的概率逆式代入即可。对全部五模式律，期望能仅由三个均值确定，当且仅当 $`J_f=0`$；必要性用第四节的两种对角中点律，充分性由式中删除联合项。

固定一个具体 $`P=(X,Y,Z)`$ 时，目标在其整个概率纤维上可识别的准确条件却是

```math
J_fw_\kappa=0.
```

所以边界纤维唯一时，有交叉项的目标也可识别。对单个当前律的乘积预测准确则是另一个条件。

**命题 7.3（当前律的乘积残差）。** 令 $`\widehat f=\mathbb E_{p^\star}f`$。在 $`r>0`$ 时，

```math
\mathbb E_pf-\widehat f
=J_f(\kappa-XY/r)=J_f\Delta/r,
\qquad
|\mathbb E_pf-\widehat f|\le |J_f|r/4.
```

证明。两律均值相同，只差共同占位项；使用第五节的锐界即得。顶点时两律相同、残差为零，直接计算而不除以 $`r`$。对当前律，准确当且仅当 $`J_f\Delta=0`$；这不表示整条当前均值纤维唯一。∎

**命题 7.4（固定均值的最优最坏绝对误差）。** 给定 $`P\in\mathcal P`$，令预测数可为任意实数，则

```math
\inf_{\widehat t\in\mathbb R}\sup_{p:\,\mathbb E(x,y,z)=P}
|\widehat t-\mathbb E_pf|=\frac{|J_f|w_\kappa}{2}.
```

取 $`\kappa_{\rm mid}=(\kappa_-+\kappa_+)/2`$ 代入目标式即达到。

证明。真实目标值是斜率 $`J_f`$ 作用于闭区间 $`[\kappa_-,\kappa_+]`$ 的像，其长度为 $`|J_f|w_\kappa`$。任一预测离至少一个端点不少于半长度，区间中点同时达到两端的半长度。$`J_f=0`$、$`w_\kappa=0`$、顶点均给零误差。∎

例如 $`X=Y=1/5,Z=0`$ 时 $`\kappa\in[0,1/5]`$；乘积选择 $`1/25`$，minimax 选择 $`1/10`$，二者不同。最大熵补全、最坏误差最小的目标预测和真实来源不是同一个概念。第十一节将 $`f=xy`$ 接到实际原生档案与继续拒绝事件上，使这里的误差和 minimax 有具体消费者。

## 八、两种四面体提升与指定内部积分

**数学引文 8.1（两条对角线、两种合法提升）。** 金字塔关联与原生接续 §五给

```math
\mathcal P=
\mathop{\mathrm{conv}}\nolimits\{v_0,v_2,v_{25},v_3\}
\cup\mathop{\mathrm{conv}}\nolimits\{v_0,v_5,v_{25},v_3\},
```

对应将 $`\kappa`$ 选为 $`\kappa_+=\min(X,Y)`$。若 $`X\le Y`$，$`p_2=0`$，落在第二个四面体；若 $`Y\le X`$，$`p_5=0`$，落在第一个。另有

```math
\mathcal P=
\mathop{\mathrm{conv}}\nolimits\{v_0,v_2,v_5,v_3\}
\cup\mathop{\mathrm{conv}}\nolimits\{v_2,v_5,v_{25},v_3\},
```

对应 $`\kappa_- =\max(0,X+Y-r)`$。$`X+Y\le r`$ 时 $`p_{25}=0`$；反之 $`p_0=0`$。三条顶点差向量的行列式绝对值在四个四面体都为一，各体积 $`1/6`$，交叠只是公共三角面。选择剖分即选择纤维端点，不等于观测到真实关联。

**数学引文 8.2（不存在全局仿射完整恢复）。** 若概率投影有仿射右逆，五个极端顶点因各自纤维唯一，只能被送回五个确定律。正方形关系却迫使

```math
\tfrac12(\delta_0+\delta_{25})=\tfrac12(\delta_2+\delta_5),
```

矛盾。因此两种分片仿射提升及乘积有理提升都不是全局仿射恢复。

**定义 8.3（指定有理延拓）。** 以 $`\widehat f(P)=\mathbb E_{p^\star(P)}f`$ 定义内部函数，顶点取 $`f_3`$。它有连续顶点值，因为底面总权 $`r`$ 趋零。Nigam–Phillips 式 (2.3)、(6.1) 的具体对应是

```math
X=u/(1+h),\quad Y=v/(1+h),\quad Z=h/(1+h),\quad r=1/(1+h),
```

```math
(p_0^\star,p_2^\star,p_5^\star,p_{25}^\star,p_3^\star)
=(\widetilde\pi_1,-\widetilde\pi_2,-\widetilde\pi_3,\widetilde\pi_4,\widetilde\pi_5).
```

两处负号按文献印刷形函数保留；这里的概率权全部非负。

**数学引文 8.4（该延拓的体积读出）。** 行列式卷定义 10.3 及其积分推导给

```math
\int_{\mathcal P}\widehat f\,dV
=\frac{f_0+f_2+f_5+f_{25}}{16}+\frac{f_3}{12}.
```

证明的换元为 $`X=ru,Y=rv`$，$`u,v\in[0,1]`$，体积 Jacobian 为 $`r^2`$。四底角权各是 $`r`$ 乘一个双线性正方形基函数，其正方形积分各为 $`1/4`$，因此体积分为 $`\tfrac14\int_0^1r^3dZ=1/16`$；顶点权积分是 $`\int_0^1Zr^2dZ=1/12`$。系数总和 $`1/3`$ 与体积相容。

这个公式只对指定 $`\widehat f`$ 有效。直接复用行列式卷推导 10.8 的气泡

```math
b(X,Y,Z)=ZXY(r-X)(r-Y),\qquad
\int_{\mathcal P}b\,dV=1/2016>0.
```

它在全部五个外面为零，故零函数与 $`b`$ 有相同顶点乃至外边界值而体积分不同。只给轮廓或顶点不能恢复任意内部响应。

## 九、正权重、闭支撑熵、精确 TV 与回复预测损失

**数学引文 9.1（严格正参数）。** 行列式卷 §七和 Drton–Sullivant 的正比坐标给：低、中、高活动权 $`a,b,c>0`$ 的模式律为

```math
p=\frac{(1,a,b,c,ac)}{(1+a)(1+c)+b},\qquad \Delta=0.
```

每份严格正且 $`\Delta=0`$ 的五模式律唯一具有此形式，参数为

```math
a=p_2/p_0,\qquad b=p_3/p_0,\qquad c=p_5/p_0.
```

所有严格正律则唯一写成

```math
p=\frac{(1,a,b,c,\eta ac)}{1+a+b+c+\eta ac},\qquad
\eta=\frac{p_0p_{25}}{p_2p_5}>0.
```

反解前三个比值，再由最后一式反解 $`\eta`$，归一化即证明唯一性。$`\eta=1`$ 恰为底面条件独立。零概率不进入这些比值或有限对数坐标；闭边界使用概率式本身。活动权乘法是假设的统计权重结构，不是原生数量加法，更不声称任意相关历史具有窗口乘积律。

**定义 9.2（支撑和对数惯例）。** 熵以二为底：

```math
H(p)=-\sum_s p_s\log_2p_s,\qquad
h_2(t)=-t\log_2t-(1-t)\log_2(1-t).
```

约定 $`0\log_2 0=0`$。有限律的现代相对熵定义为

```math
D_2(p\Vert q)=\sum_{s:p_s>0}p_s\log_2(p_s/q_s),
```

若存在 $`p_s>0=q_s`$，取 $`+\infty`$。有限值要求 $`\mathop{\mathrm{supp}}\nolimits p\subseteq\mathop{\mathrm{supp}}\nolimits q`$。Shannon 重印本 §6 支持熵及链式分解；其 §7 的 “relative entropy” 是同字母表的归一化熵比，不用于现代 KL 定义。此处后者采用 Wainwright–Jordan 式 (5.9)。

**定理 9.3（整个闭单纯形上的唯一最大熵补全）。** 固定 $`P\in\mathcal P`$，$`p^\star`$ 是该均值纤维上的唯一最大熵律。对 $`r>0`$，

```math
H(p^\star)=h_2(Z)+r\bigl[h_2(X/r)+h_2(Y/r)\bigr],
```

```math
H(p^\star)-H(p)=D_2(p\Vert p^\star)
=r\,I_p(x:y\mid z=0)\ge0.
```

这里最后一项是在正质量底面条件律中的互信息，再乘回 $`r`$。$`r=0`$ 时唯一律 $`\delta_3`$，两熵和 KL 都为零；不在该点定义 $`Q/r`$ 或其条件互信息。

证明。若一个底面格在 $`p`$ 中为正，则其行和、列和都正，所以对应乘积格在 $`p^\star`$ 中也正。顶点项两律相同。故支撑包含总成立，即使某行某列为零，也不会遇到正概率除以零。

当 $`r>0`$，令 $`q_{ij}=Q_{ij}/r`$，边缘为 $`u_i,v_j`$。按底面或顶点分组，用 Shannon 的有限链式公式得

```math
H(p)=h_2(Z)+rH(q),\qquad
H(p^\star)=h_2(Z)+r[H(u)+H(v)].
```

在 $`q_{ij}>0`$ 的格上 $`u_iv_j>0`$，展开有限和有

```math
\begin{aligned}
D_2(q\Vert u\otimes v)
&=\sum_{ij:q_{ij}>0}q_{ij}\log_2\frac{q_{ij}}{u_iv_j}\\
&=H(u)+H(v)-H(q)=I_p(x:y\mid z=0),\\
D_2(p\Vert p^\star)&=rD_2(q\Vert u\otimes v).
\end{aligned}
```

零边缘的项按零贡献处理。非负性及唯一等号可直接证明：对任意支撑包含的有限律 $`a,b`$，由 $`\ln t\le t-1`$，

```math
-D_2(a\Vert b)\ln2
=\sum_{i:a_i>0}a_i\ln(b_i/a_i)
\le\sum_{i:a_i>0}(b_i-a_i)\le0.
```

等号要求每个正支撑格 $`a_i=b_i`$，且 $`b`$ 在其余格无质量，所以恰为 $`a=b`$。应用于 $`p,p^\star`$ 证明唯一最大熵；退化纤维本来只有一个律也包含在此结论。∎

**命题 9.4（精确 TV）。** 对 $`r>0`$，

```math
\mathop{\mathrm{TV}}\nolimits(p,p^\star)
=\frac12\sum_s|p_s-p_s^\star|=2|\Delta|/r.
```

证明。两律之差为 $`\delta(1,-1,0,-1,1)`$，其中 $`\delta=\kappa-XY/r=\Delta/r`$。四个绝对值各为 $`|\delta|`$，得式。顶点的 TV 为零。一般 TV 等于任意事件概率差的最大值：将差的正分量求和，任一事件都不超过该和，正分量事件达到。这个距离比较完整有限律，不由一个样本或一份未知相关档案直接认证。∎

**定义 9.5（同源的对数预测任务）。** 第十一节的实际原生路径先保存首次数量的奇偶 $`A`$，再保存继续输入 $`[5]`$ 的回复 $`R`$。其五个可能档案对 $`(A,R)`$ 与五模式一一对应。令该档案律为 $`\mu_p`$，用补全律预测时令 $`\mu^\star=\mu_{p^\star}`$；对实际档案 $`o`$ 的对数损失为 $`-\log_2\mu^\star(o)`$。正概率档案的预测概率正，由定理 9.3 的支撑包含保证。

**推论 9.6（熵差的实际消费者）。** 同一档案任务的平均预测损失、相对于真律的额外损失以及 TV 分别为

```math
\mathbb E_p[-\log_2\mu^\star(A,R)]
=H(p)+D_2(p\Vert p^\star)=H(p^\star),
```

```math
D_2(\mu_p\Vert\mu^\star)=D_2(p\Vert p^\star),\qquad
\mathop{\mathrm{TV}}\nolimits(\mu_p,\mu^\star)=\mathop{\mathrm{TV}}\nolimits(p,p^\star).
```

证明。实际档案对与模式的双射重排概率分量，保持熵、KL 和 TV；对数损失的期望展开为 $`H+D`$。定理 9.3 给最后的熵等式。∎

此处熵比较承担具体的原生继续回复预测损失。它不说来源已经取得，亦不从高熵推出真实 $`\Delta=0`$。首次若保存精确数量，该次模式已经可恢复，预测条件应使用更细档案；上述任务专指奇偶保留合同。

## 十、条件取反、端点交换与有限几何对称

**数学引文 10.1（合法域上的端点取反）。** 复用行列式卷 §八，定义

```math
C_x(x,y,z)=(1-z-x,y,z),\qquad
C_y(x,y,z)=(x,1-z-y,z).
```

在底面翻转对应端点，在顶点保持两端零，故它们是合法五模式的置换，满足

```math
C_x^2=C_y^2=I,\qquad C_xC_y=C_yC_x.
```

均值变换分别为

```math
C_x:(X,Y,Z)\mapsto(r-X,Y,Z),\qquad
C_y:(X,Y,Z)\mapsto(X,r-Y,Z).
```

$`C_x`$ 后的共同占位 $`\kappa'=\mathbb E[(1-z-x)y]=Y-\kappa`$，于是

```math
\Delta'=r(Y-\kappa)-(r-X)Y=-\Delta.
```

$`C_y`$ 同理反号；端点交换 $`x\leftrightarrow y`$ 保持 $`\kappa,\Delta`$，将两种扫描核的端点角色互换。

**数学引文 10.2（中心对齐的仿射坐标）。** 取

```math
\xi=2X+Z-1,\quad \upsilon=2Y+Z-1,\quad h=Z,
```

```math
|\xi|\le1-h,\qquad |\upsilon|\le1-h,\qquad 0\le h\le1.
```

这给中心对齐的方底金字塔和有限正方形对称。其线性部分将 $`(1,0,0)`$ 的长度变为二，故不是原尺子下的刚体旋转；在原坐标内也不能把全部仿射自同构视为等距。占位对称没有授予原生读者这些置换操作：低端决定输出接缝，高端决定输入守卫，二者的在线角色不同。金字塔的有限对称不等于球的全部方向旋转对称。

## 十一、双扫描、概率加权行列式与实际原生继续回复

### 十一的单位置核与三个位置顺序

**定义 11.1（单位守卫核）。** 行是输入占位 $`i`$，列是新占位 $`j`$，已有一不能再选一：

```math
B(t)=\begin{pmatrix}1&t\\1&0\end{pmatrix}.
```

当 $`j=0`$ 权一，当 $`i=0,j=1`$ 权 $`t`$，冲突格权零。低、中、高活动权仍为 $`a,b,c`$。矩阵乘积按实际读取位置顺序排列，中间指标是同一个真实接缝。

**数学引文 11.2（原生与辅助核）。** 接缝卷 §二、金字塔关联卷推导 8.3 给两个不同接口：

```math
\begin{aligned}
K_{\rm low}(a,b,c)&=B(a)B(b)B(c)
=\begin{pmatrix}1+a+b&c(1+a)\\1+b&c\end{pmatrix},\\
K_{\rm high}(a,b,c)&=B(c)B(b)B(a)
=\begin{pmatrix}1+c+b&a(1+c)\\1+b&a\end{pmatrix}.
\end{aligned}
```

第一式是辅助 LOW-to-HIGH 扫描，输入一迫使 $`x=0`$，输出为 $`y`$。第二式才是原生 HIGH-to-LOW，输入一迫使 $`y=0`$，输出为最低位 $`x`$。直接相乘给

```math
\mathop{\mathrm{tr}}\nolimits K_{\rm low}=\mathop{\mathrm{tr}}\nolimits K_{\rm high}=1+a+b+c,
\qquad \det K_{\rm low}=\det K_{\rm high}=-abc.
```

单位活动权时两核相同：

```math
A=\begin{pmatrix}3&2\\2&1\end{pmatrix}=JM^3J,
\quad J=\begin{pmatrix}0&1\\1&0\end{pmatrix},
\quad A^2=4A+I,\quad \det A=-1.
```

因为 $`B(1)=JMJ`$，三步即得共轭式，矩阵乘法给二阶恒等式。这是两状态守卫的三位表达，不是五状态无约束递归。反转完整词须同时反转窗口次序和外端条件；它不保留在线前缀回复。比如辅助低到高词 $`([2],[3])`$ 对应原生逆词 $`([3],[2])`$，总数量都是十五，首窗回复却分别为二、三。

### 十一的绝对合法质量与两种行列式

**定义 11.3（同一局部权的概率核）。** 给定义 4.1 的绝对归一化律 $`p`$，将各模式概率作为未归一化合法质量。对于一个指定输入接缝 $`i`$，枚举守卫允许的输出接缝，得

```math
K_{{\rm low},p}=
\begin{pmatrix}p_0+p_2+p_3&p_5+p_{25}\\p_0+p_3&p_5\end{pmatrix}
=\begin{pmatrix}1-Y&Y\\1-X-Y+\kappa&Y-\kappa\end{pmatrix},
```

```math
K_{{\rm high},p}=
\begin{pmatrix}p_0+p_3+p_5&p_2+p_{25}\\p_0+p_3&p_2\end{pmatrix}
=\begin{pmatrix}1-X&X\\1-X-Y+\kappa&X-\kappa\end{pmatrix}.
```

原生高读的两行和为 $`1,1-Y`$，辅助低读为 $`1,1-X`$。若用同一 $`p`$ 作为对指定接缝的窗口提议律，拒绝质量分别为 $`iY`$ 和 $`iX`$；与输出零、一共同组成总质量一的回复。行不是默认随机转移行，不得把丢失质量当作没有发生。

若合同要求输入一时必合法，原生支撑须有 $`y=0`$，即 $`Y=0`$；辅助须有 $`X=0`$。若接缝和当前窗口本来相关，应在正质量接缝事件下使用其真实条件律 $`p(\sigma\mid i)`$；不能把无条件 $`p`$ 免费复用于两行。零质量输入事件不补出条件律。把第二行除以 $`1-Y`$ 或 $`1-X`$ 只在该分母正时定义，并将任务改为给定合法通过后的条件预测；两行独自归一化不会保留一般整链绝对质量。

**命题 11.4（两个概率核的同一全局协方差）。** 两个读向核均满足

```math
d:=\det K_{{\rm high},p}=\det K_{{\rm low},p}
=XY-\kappa=-\mathop{\mathrm{Cov}}\nolimits_p(x,y)=-\Delta-Z\kappa.
```

证明。高读行列式为 $`(1-X)(X-\kappa)-X(1-X-Y+\kappa)=XY-\kappa`$；低读交换 $`X,Y`$ 得同式。再用 $`\Delta=(1-Z)\kappa-XY`$。∎

例如均匀五模式的 $`\Delta=0`$，但 $`d=-1/25`$。底面条件协方差与整个律的协方差是两种量。同一律及读向合同固定后才能比较，不能把活动权核的 $`-abc`$ 与归一化概率核的行列式混为一项。

**命题 11.5（联合恢复、核的合法像及全部边界）。** 三个均值加 $`d`$ 以

```math
\kappa=XY-d
```

恢复完整五概率，合法性恰要求 $`P\in\mathcal P`$ 且 $`\kappa_-\le XY-d\le\kappa_+`$。此式不除以 $`r`$，故包括唯一顶点。

若原生核记为 $`K=\begin{pmatrix}a_0&b_0\\c_0&d_0\end{pmatrix}`$，再给 $`Z`$，完整逆式为

```math
(p_0,p_2,p_3,p_5,p_{25})
=(c_0-Z,d_0,Z,a_0-c_0,b_0-d_0).
```

其合法像恰为

```math
a_0+b_0=1,\quad 0\le d_0\le b_0,\quad
0\le Z\le c_0\le a_0.
```

辅助核以同样四格记号书写时，逆式则为

```math
(p_0,p_2,p_3,p_5,p_{25})
=(c_0-Z,a_0-c_0,Z,d_0,b_0-d_0),
```

合法像的不等式相同。

证明。逐格枚举立即给两个逆式；所列不等式恰保证五项非负，和由首行和一保证。代回核得到原四格。核单独只含 $`p_0+p_3`$，所以在 $`c_0>0`$ 时允许 $`Z\in[0,c_0]`$，合并空窗与中窗的拆分；$`c_0=0`$ 时拆分已唯一。高度补回正是这个缺项。在顶点，两核都为 $`\begin{pmatrix}1&0\\1&0\end{pmatrix}`$，加 $`Z=1`$ 给 $`\delta_3`$。∎

恢复公式是已知精确绝对律统计之间的逆式。如果只取得各行条件归一化比例而丢弃通过总质量，不能直接使用此逆式。行列式的二次性也不提供一次免费测量；取得前提见本节末。

### 十一的同源原生任务与误差、熵、minimax 的消费

**定义 11.6（既有原生继续合同）。** 直接使用关系延拓几何定义 7.1，以及行列式卷定义 10.4、命题 10.5–10.6 的同一个读者。单位位固定零、初态 $`(s,C)=(0,0)`$，窗口从高到低输入，允许高端空填充；每个有限前缀即时回复数量，没有额外 End 动作或最高窗口必须非空的检查。置

**命题 11.8（恢复的局部律预测同源允许回复）。** 由命题 11.5 恢复的 $`p`$，该继续回复的无条件律恰为

```math
\nu_p(5)=r-X-Y+\kappa,\quad \nu_p(18)=Z,\quad
\nu_p(26)=Y-\kappa,\quad \nu_p(\bot)=X.
```

令 $`m=P(A)=Y+Z`$。若 $`m>0`$，同一实际奇数记录下的下一回复律为

```math
\nu_{p,A}(18)=Z/m,\quad
\nu_{p,A}(26)=(Y-\kappa)/m,\quad
\nu_{p,A}(\bot)=\kappa/m.
```

事件目标

```math
f_A(\sigma)=\mathbf1_{A\cap\{R=\bot\}}=xy
```

在五个实际来源上逐点成立，故 $`J_{f_A}=1`$。当 $`r>0`$ 时乘积预测的精确误差及最优最坏误差为

```math
\begin{aligned}
P_p(A,R=\bot)-P_{p^\star}(A,R=\bot)&=\Delta/r,\\
P_p(\bot\mid A)-P_{p^\star}(\bot\mid A)&=\Delta/(rm),\\
\inf_{\widehat b}\sup_{p:\,\mathbb E(x,y,z)=P}
|\widehat b-P_p(\bot\mid A)|&=w_\kappa/(2m).
\end{aligned}
```

最后两式只在 $`m>0`$ 使用；无条件联合事件的 minimax 为 $`w_\kappa/2`$。条件任务在固定纤维上可识别恰当且仅当 $`w_\kappa=0`$，当前律的乘积拒绝率吻合恰当且仅当 $`\Delta=0`$。无条件拒绝率 $`X`$ 对全部纤维已可识别，不需要额外关联。

证明。以表逐项推前同一 $`p`$ 得两份回复律。奇数记录内只剩 $`3,5,25`$ 三支，记录质量 $`m`$ 是所有相容律共同的分母。实际联合事件只在 $`25`$ 为一。第七节的 $`J_f=1`$ 残差和区间 minimax 除以共同正质量 $`m`$ 即得；没有改变目标或另换来源。∎

若 $`m=0`$，奇数记录从不发生，没有其条件回复律。若 $`r=0`$，来源只能是 $`3`$，$`m=1`$，下一回复确定为十八，联合拒绝率及 minimax 都为零；不使用含 $`1/r`$ 的公式。若初接缝改成一而要求首次合法，须限制到 $`Y=0`$ 支撑，不能套用全五模式内点反例。

**命题 11.9（同源的距离和对数损失）。** 在 $`r>0`$ 下，令 $`\delta=\Delta/r`$，则

```math
\mathop{\mathrm{TV}}\nolimits(\nu_p,\nu_{p^\star})=|\delta|,
\qquad
\mathop{\mathrm{TV}}\nolimits(\nu_{p,A},\nu_{p^\star,A})=|\delta|/m\quad(m>0).
```

完整档案对 $`(A,R)`$ 的五项概率恰为 $`p`$ 的重排，所以第九节的熵差和 KL 正是这份实际档案任务的额外对数预测损失。更具体，当 $`0<m<1`$，

```math
D_2(p\Vert p^\star)
=mD_2(\nu_{p,A}\Vert\nu_{p^\star,A})
+(1-m)D_2(\nu_{p,\neg A}\Vert\nu_{p^\star,\neg A}).
```

其中 $`\neg A`$ 下回复 $`5,\bot`$ 的概率为 $`p_0/(1-m),p_2/(1-m)`$。因而 $`mD_2(\nu_{p,A}\Vert\nu_{p^\star,A})\le H(p^\star)-H(p)`$。

证明。无条件回复差只在 $`5,26`$ 两项为 $`\delta,-\delta`$；条件回复差只在 $`26,\bot`$ 为 $`-\delta/m,\delta/m`$，给 TV。KL 按 $`A`$ 分组，两律记录质量同为 $`m`$，概率比中的组质量消去，得链式式子。$`m=0`$ 或一时只保留实际正质量组，零组不给条件律；顶点时全部差为零。∎

**边界 11.11（概率律、已取得档案和跨窗来源）。** 首次精确数量 $`0,2,3,5,7`$ 在五模式上单射；保留它就确定该次模式，保留 $`(A,R)`$ 也确定该次模式。但一个样本不决定未知 $`p`$。有限样本的经验律及经验行列式只描述该档案；误差估计另需实际抽样条件。若确有两份独立同律样本 $`\sigma,\tau`$，则

-\mathbf1_{\sigma=2,\tau=5}]=\Delta.

没有真实独立取得合同，左侧是双份联合事件差，不能代换成概率乘积。这条数学表达不授予样本复制或重置。命题 11.8–11.9 是给定同一精确律后的预测，也不宣称实际已经取得各反事实输入的全部回复。

## 十二、整数回路计数与原生窗口历史两种数列

### 十二的固定概率分母和二次回路

**定义 12.1（整数占位计数）。** 对整数 $`m\ge1`$，写 $`p_s=n_s/m`$，$`n_s\in\mathbb N_0`$、$`\sum_sn_s=m`$。完整配置数为

```math
N_{\rm full}(m)=\binom{m+4}{4}.
```

可见整数位置

```math
U=n_2+n_{25},\quad V=n_5+n_{25},\quad W=n_3
```

满足 $`0\le W\le m`$、$`0\le U,V\le m-W`$。$`m=0`$ 只表示零倍格体的一点及全零计数，不使用除以零的概率定义。

**数学引文 12.2（格点数与生成函数）。** 金字塔关联卷 §九、Stanley 的 Ehrhart 归属给

```math
N_{\rm geom}(m)=\sum_{W=0}^m(m-W+1)^2
=\frac{(m+1)(m+2)(2m+3)}6,
```

```math
N_{\rm geom}(0),\ldots,N_{\rm geom}(5)=1,5,14,30,55,91,
\qquad
\sum_{m\ge0}N_{\rm geom}(m)t^m=\frac{1+t}{(1-t)^4}.
```

整数提升没有缺口：对任何该位置，取整数

```math
\max(0,U+V+W-m)\le k\le\min(U,V)
```

并置

```math
(n_0,n_2,n_3,n_5,n_{25})
=(m-U-V-W+k,U-k,W,V-k,k).
```

非负性即得精确提升。生成函数可在形式幂级数环中逐系数有限换序；解析使用时取 $`|t|<1`$。

**命题 12.3（单一整数回路与唯一规范代表）。** 保持 $`(m,U,V,W)`$ 的整数核由原始向量 $`(1,-1,0,-1,1)`$ 生成。执行

```math
(n_0,n_2,n_3,n_5,n_{25})
\mapsto(n_0-1,n_2+1,n_3,n_5+1,n_{25}-1)
```

直到 $`n_0=0`$ 或 $`n_{25}=0`$，得到唯一非负终态。于是约定 $`\binom n4=0`$ 对 $`0\le n<4`$，对所有 $`m\ge0`$，

```math
N_{\rm geom}(m)=\binom{m+4}{4}-\binom{m+2}{4}.
```

证明。逆式使 $`k`$ 是唯一自由整数。该步将 $`k`$ 减一，恰在 $`k>\max(0,U+V+W-m)`$ 时可执行；抵达下端后 $`n_0n_{25}=0`$，故终态由位置唯一决定。整数核没有更小非零步，因为最后分量就是整数参数，且原始向量的非零分量绝对值一。每个可见位置对应恰一个规范代表。非规范计数恰为 $`n_0,n_{25}\ge1`$；两项各扣一后是五项和为 $`m-2`$ 的弱组合，有 $`\binom{m+2}{4}`$ 份，$`m=0,1`$ 时无此类。相减得式。∎

**命题 12.4（事件代数之外的计数代数）。** 令 $`t_0,t_2,t_3,t_5,t_{25}`$ 为独立多项式变量，$`h,u,v,w`$ 也独立，定义

```math
\Theta:\mathbb R[t_0,t_2,t_3,t_5,t_{25}]\longrightarrow
\mathbb R[h,u,v,w],
```

```math
(t_0,t_2,t_3,t_5,t_{25})\mapsto(h,hu,hw,hv,huv).
```

则 $`\ker\Theta=(t_0t_{25}-t_2t_5)`$。每个次数 $`m`$ 的像单项式恰对应一个整数可见位置。

证明。单项式 $`\prod t_s^{n_s}`$ 的像为 $`h^mu^Uv^Vw^W`$。模给定二次关系，将每个因子 $`t_0t_{25}`$ 换成 $`t_2t_5`$，次数和像保持，最终得到命题 12.3 的唯一规范单项式。两个不同规范单项式若同像，则同 $`(m,U,V,W)`$，违反规范唯一性。因此规范单项式的像线性独立。任一核多项式先归约成规范单项式线性组合，像为零便使全部系数零，证明无其他理想关系。∎

这个平方 minor 使用 Sullivant 例 1.2 的经典二次关系背景，具体含顶点变量的核由上述证明承担。它与第二节的 Boolean 事件商代数不同：此处变量计数，不满足 $`t_s^2=t_s`$。回路使次数二以上的计数减去一次二次关系的倍数，生成函数也可写成

```math
\frac{1-t^2}{(1-t)^5}=\frac{1+t}{(1-t)^4}.
```

这里的回路及规范化不是关于随机过程 Markov 性的假设，更不执行原生树或档案的改写。

## 十三、Binet、双曲连续表示与不能补回的来源信息

## 十四、附加量子实现、四角判据与最终原子关系

### 十四的具体量子层和来源代表

**数学引文 14.1（明确已有的 Pauli 实现）。** 使用二阶关系完成定义 101.1、106.1 和 §103 的来源代表，在 $`\mathbb C^2`$ 上取

```math
\sigma_x=\begin{pmatrix}0&1\\1&0\end{pmatrix},\quad
\sigma_y=\begin{pmatrix}0&-i\\i&0\end{pmatrix},\quad
\sigma_z=\begin{pmatrix}1&0\\0&-1\end{pmatrix},
```

```math
A=-i\sigma_x,\quad B=-i\sigma_y,\quad C=BA=i\sigma_z,
\qquad A^2=B^2=C^2=-I,\quad AB=-BA.
```

来源读出 $`U_\alpha=A,U_\beta=B,U_{\langle s,t\rangle}=U_sU_t`$；右因子先作用于态。指定高位置在来源左侧的代表为

| 模式 | 来源代表或空贡献 | 表示 |
| --- | --- | --- |
| $`0`$ | 空选择单位 | $`I`$ |
| $`2`$ | $`\alpha`$ | $`A`$ |
| $`3`$ | $`\beta`$ | $`B`$ |
| $`5`$ | $`\langle\beta,\alpha\rangle`$ | $`C`$ |
| $`25`$ | $`\langle\langle\beta,\alpha\rangle,\alpha\rangle`$ | $`CA=-B`$ |

若把两端代表改为 $`\langle\alpha,\langle\beta,\alpha\rangle\rangle`$，则表示为 $`AC=B`$，故 $`25\mapsto-B`$ 依赖次序和代表。这份表示保留部分叶序相位，却因矩阵乘法结合而合并不同括号；例如 $`\langle\langle\alpha,\alpha\rangle,\beta\rangle`$ 与 $`\langle\alpha,\langle\alpha,\beta\rangle\rangle`$ 都映到 $`-B`$。它不是自由来源树的单射编码。空选择单位 $`I`$ 也不是原生 $`[null]`$ 动作。

**数学引文 14.2（经典随机选择的通道及协变条件）。** 在上述具体实现中，若模式按同一 $`p`$ 经典随机选择且不相干比较选择支，二阶卷定义 112.1、定理 112.2 给

```math
\mathcal N(\varrho)=p_0\varrho+p_2\sigma_x\varrho\sigma_x
+(p_3+p_{25})\sigma_y\varrho\sigma_y+p_5\sigma_z\varrho\sigma_z.
```

在同一固定 Bloch 基架，要求对全部酉共轭所实现的 $`SO(3)`$ 旋转协变，则恰要求

```math
p_2=p_5=p_3+p_{25}.
```

证明的具体现有计算是 Bloch 矩阵

```math
D=\mathop{\mathrm{diag}}\nolimits(2(p_0+p_2)-1,
2(p_0+p_3+p_{25})-1,2(p_0+p_5)-1).
```

标量矩阵与全部旋转交换；反向分别与两轴四分之一周旋转交换，强制三个对角元相等，即得条件。五模式均匀时 $`D=\mathop{\mathrm{diag}}\nolimits(-1,1,-1)/5`$，虽带等距收缩和已知半周旋转，却不是同一基架下的全旋转协变。经典金字塔对称不供应这个实现的各向同性。

**数学引文 14.3（普通通道、相干比较和未来环境）。** 对普通密度通道，$`\mathop{\mathrm{Ad}}\nolimits_U=\mathop{\mathrm{Ad}}\nolimits_{-U}`$。只有另外实际供应二阶卷定义 107.1 的共同控制门

```math
W_{U,V}=|0\rangle\langle0|\otimes U+|1\rangle\langle1|\otimes V
```

以及控制 $`|+\rangle`$ 制备和 $`X`$ 测量，定理 107.2 才把 $`(U,U)`$ 与 $`(U,-U)`$ 分别读成确定的正、负控制回复。普通通道名称不指定受控相位，原生窗口合同不免费授予这些仪器。

完整相干历史须使用二阶卷定义 110.1、定理 110.2 的共同环境与指定相位保持等距实现；不能把隐藏 Kraus 标签当作已取得经典档案。该卷命题 110.4 的同环境 CNOT 例中，两次使用同一环境返回原联合态，两次各用新环境却保持去相位。相同局部约化通道或经典记录分布不决定后续重新接入环境的回复。故完整五模式律也不恢复任意相干来源、完整树或全部历史；未给的附件不承担这些数学结论的来源，以上接口以具名仓内定义为准。

### 十四的四角均值判据及其闭合条件

**定义 14.4（声明的全混合线性更新）。** 固定一个作用于同一五模式律的随机矩阵 $`T=(T_{st})`$，$`T_{st}\ge0`$、$`\sum_tT_{st}=1`$，更新为 $`p'=pT`$，并对每个纯来源定义下一平均向量

```math
\Phi_s=\sum_{t\in\Sigma}T_{st}v_t.
```

这是对全部输入混合律均按同一个线性规则更新的合同。它不假设任意实际历史已经具有此自治律，也不将原生无界组成状态自动截成五个模式。

**命题 14.5（普遍平均下降的四角条件）。** 在定义 14.4 中，下一均值对所有输入律只依赖当前 $`P=(X,Y,Z)`$，当且仅当

```math
\Phi_0+\Phi_{25}=\Phi_2+\Phi_5.
```

成立时下一均值是 $`P`$ 的仿射函数，其像在 $`\mathcal P`$ 内。

证明。下一均值 $`\sum_sp_s\Phi_s`$ 逐分量使用第七节的目标展开；三个 $`J`$ 系数同时为零恰是向量四角式。必要性仍用两种对角中点律。若等式成立，联合项消失而给仿射式；$`pT`$ 为合法五模式律，所以像留在占位凸体。∎

对固定纤维，下一均值可识别的较弱条件是 $`w_\kappa(\Phi_0+\Phi_{25}-\Phi_2-\Phi_5)=0`$。对某一个当前律的乘积预测准确则还可因该律 $`\Delta=0`$ 而成立，不能拿它代替普遍四角条件。

**命题 14.6（所请求输出和记录后的继续条件）。** 若请求有限回复集 $`\mathcal R`$ 上的完整单步回复律，纯来源的回复核为 $`L_s\in\mathbb R^{\mathcal R}`$，则该律对全部混合下降的条件是

```math
L_0+L_{25}=L_2+L_5
```

逐回复成立，而不只是其数值均值满足四角式。若输出包括拒绝，拒绝必须是一项单独回复；部分动作在同一摘要纤维上的允许性也须一致，或者使用明确保留拒绝的总化接口。重复在 $`\mathcal P`$ 上执行须有该载体内的更新、每个继续动作的可执行条件，以及记录条件化后仍充分的状态。

具体地，在另行声明的有限随机过程合同内，令 $`G_a(s,b,t)`$ 是动作 $`a`$ 后回复 $`b`$ 与下一模式 $`t`$ 的共同核，非负且对 $`(b,t)`$ 求和为一；真实未来由此核继续，不另含未登记的记忆。定义

```math
\ell_{a,b}(s)=\sum_tG_a(s,b,t),\qquad
\gamma_{a,b}(s)=\sum_tG_a(s,b,t)v_t.
```

若对每个 $`a,b`$，这两项均满足四角式，则全部有限、可按已取得回复适应选择的动作任务之联合回复律可由初始均值预测。正质量回复后的条件均值也能更新。

证明。单步回复律是 $`\sum_sp_sL_s`$，逐回复使用第七节展开得其充要条件。共同核下，回复质量和未归一化下一占位矩为

```math
m_{a,b}=\sum_sp_s\ell_{a,b}(s),\qquad
u_{a,b}=\sum_sp_s\gamma_{a,b}(s).
```

四角式使二者由当前 $`P`$ 决定。若 $`m_{a,b}>0`$，记录 $`b`$ 后的条件均值为 $`u_{a,b}/m_{a,b}\in\mathcal P`$；若质量零，该支不发生，不补条件态。对每份已发生档案逐步应用同一个真实核和上述更新，归纳得到下一回复质量及全部联合记录概率。按档案选择动作仍使用这同一归纳。守卫合法性或明确拒绝输出须同时保存，载体须包含所有实际下一态；这些前提缺失时归纳不能启动或继续。∎

仅分别检查无条件的回复边缘和下一均值，不能推出该联合条件。一个明确的附加有限操作例是：在五模式上回复 $`b=x(s)`$，下一模式在 $`y(s)=1`$ 时置为 $`2`$，否则置为 $`0`$。它的回复边缘只读 $`X`$、下一均值只读 $`Y`$，两者都满足四角式；第二步读取新模式的低端却使联合回复为 $`(x,y)`$。第四节的两种对角中点律有相同三均值及相同单步边缘，联合回复分别集中于 $`(0,0),(1,1)`$ 和 $`(1,0),(0,1)`$。此例的操作是明示附加模型，不认作原生权限；原生条件任务的同源障碍由反例 11.10 直接承担。

例如第十一节未经条件化的拒绝事件 $`x`$ 的均值下降成立，但奇数档案下的继续拒绝由 $`xy`$ 决定；又如反例 11.11 的终值均值相同而完整数量律不同。四角均值条件没有抹去这两种区别。若错误态吸收，状态载体应包含该错误点及质量；不能在仍只容纳合法占位的 $`\mathcal P`$ 上把错误质量删掉。全回复未来充分性最终要求关系延拓几何定义 3.2 的输出及更新共同纤维不变性；在随机记录任务中还须对实际回复条件支保有该桥，非单个当前均值等式。这里的共同核是一个充分合同，不把有限状态自治或 Markov 性作为每种任务的必要前提。

z_A(n)=\mathbf1_{q\mid n+2},\quad z_B(n)=\mathbf1_{q\mid n+4}.
$$
模式名 $2,3,5,25$ 沿用定义 2.1 的占位标签；本定义用上述明确的除数事件实现同一事件代数，不把标签数值识别为整数偏移或原生树。记 $X=\mathbb Ex$、$Y=\mathbb Ey$、$Z=\mathbb Ez$、$\kappa=\mathbb E(xy)$。对一般非空有限 $H\subset\mathbb Z$，记 $\nu_H(q)=|H\bmod q|$。

**命题 15.2（局部存活率恰好消费遗漏的联合坐标）。** 定义 15.1 的两种来源均满足 $xz=yz=0$，因而其概率律属于本卷五模式单纯形，并且
$$
X=Y=Z=\frac1q,\qquad
\kappa=\begin{cases}1/3,&q=3,\\0,&q>3,\end{cases}
\qquad
p_0=1-X-Y-Z+\kappa=1-\frac{\nu_H(q)}q.
$$
在 $q=3$ 上，若把端点改为 $x=\mathbf1_{3\mid n}$、$y=\mathbf1_{3\mid n+4}$，中点取 $z=\mathbf1_{3\mid n+2}$，则得到 $H_C=\{0,2,4\}$ 的另一份合法五模式律。它与 $H_A$ 的三均值完全相同，但
$$
\kappa_A=\frac13,\quad p_{0,A}=\frac13,\qquad
\kappa_C=0,\quad p_{0,C}=0.
$$

**证明。** 对 $H_A$，同时整除 $n,n+2$ 或 $n+6,n+2$ 的奇素数必须整除 $2$ 或 $4$，不可能；对 $H_B$ 两个差值交换，结论相同。每个单独除数事件在 $\mathbb F_q$ 中只有一个点，所以均值为 $1/q$。端点同时发生当且仅当 $q\mid6$，故奇素数中只可能是 $3$，此时两事件相同。数学引文 2.2 的空事件恒等式 $e_0=1-x-y-z+xy$ 给出存活率，亦等于未被 $-H$ 覆盖的余数比例。对 $H_C$，模 $3$ 的三个除数事件占满三个不同余数，故两端不相交，且无存活点。两份律分别为 $(1/3,0,1/3,0,1/3)$ 和 $(0,1/3,1/3,1/3,0)$，分量次序仍是 $(0,2,3,5,25)$。∎

**命题 15.3（局部相关坐标的三向量谱消费者）。** 对任何本卷五模式律，假设 $X,Y,Z>0$。在该律的同一个 $L^2$ 空间内，将三个指示函数分别除以 $\sqrt X,\sqrt Y,\sqrt Z$，得到单位向量的非中心化 Gram
$$
U_c=\begin{pmatrix}1&c&0\\c&1&0\\0&0&1\end{pmatrix},
\qquad c=\frac{\kappa}{\sqrt{XY}}\in[0,1].
$$
定义非负凸函数与谱泛函
$$
\Psi(t)=\begin{cases}(t-1)^2,&0\le t\le2,\\2t-3,&t\ge2,\end{cases}
\qquad D_\Psi(G)=\operatorname{tr}\Psi(G).
$$
则
$$
\operatorname{Spec}(U_c)=\{1-c,1,1+c\},\qquad
\det U_c=1-c^2,\qquad
D_\Psi(U_c)=2c^2=\frac{2\kappa^2}{XY}=2(1-\det U_c).
$$
因此在命题 15.2 的模 $3$ 成对来源上，三均值相同，谱修正量分别为 $2$ 和 $0$。

**证明。** Gram 的非对角项由 $xz=yz=0$ 与 $\mathbb E(xy)=\kappa$ 给出。Cauchy–Schwarz 给 $\kappa^2\le XY$，且 $\kappa\ge0$。对左上二阶块求特征值即可，全部特征值落在 $[0,2]$，所以 $\Psi$ 的二次段给 $2c^2$。∎

这里的 $\det U_c$ 是三个单位向量的平方体积，定义 5.1 的 $\Delta=(1-Z)\kappa-XY$ 仍是底面条件关联；它们的定义与归一化不同。若某一均值为零，必须先删除相应零向量，不能沿用三阶归一化公式。$\Psi(0)=1$，所以改变矩阵维数也会改变此谱泛函。$\Psi$ 的外部零点计数来源及其真实维数条件见 [Wang 文献条目](../../../Library/Weil/wang2026proportions.md)。

**命题 15.4（奇素数限制和有限 CRT 计数）。** 在 $q=2$ 的均匀来源上，$H_A,H_B$ 的三个除数指示函数完全相同，其值为 $000$ 或 $111$。因此它不属于定义 2.1 的五模式域；其归一化 Gram 是三阶全一矩阵，谱为 $3,0,0$，$D_\Psi=5$。若 $W\ge2$ 平方自由，定义
$$
a_{H,W}(r)=\prod_{h\in H}\mathbf1_{\gcd(r+h,W)=1},\qquad r\in\mathbb Z/W\mathbb Z.
$$
则
$$
\sum_{r\bmod W}a_{H,W}(r)=\prod_{q\mid W}\bigl(q-\nu_H(q)\bigr).
$$

**证明。** 三个偏移均为偶数，所以模 $2$ 的除数事件相同；全一矩阵的特征值与 $\Psi$ 直接给出所列数值。CRT 将模 $W$ 的合法集合双射到各模 $q$ 合法集合的笛卡尔积，故其基数为各局部基数之积。∎

## 十六、轮筛三点相关、绝对原点与 Fibonacci 窗口

**定义 16.1（Fourier 约定及有序任务）。** 以下固定平方自由 $W\ge2$、非空有限 $H$，并假设每个 $q\mid W$ 都有 $1\le\nu_H(q)<q$。令 $a=a_{H,W}$，$e_W(t)=\exp(2\pi it/W)$，所有索引均按 $W$ 取模。对复信号 $f$ 取
$$
\widehat f(k)=\sum_{r\bmod W}f(r)e_W(-kr),\qquad
(T_tf)(r)=f(r-t),\qquad
\langle u,v\rangle=\sum_r\overline{u(r)}v(r).
$$
定义二点相关、三点相关及其双谱
$$
C_f(s)=\sum_r\overline{f(r)}f(r+s),\qquad
C_f^{(3)}(s,t)=\sum_r\overline{f(r)}f(r+s)f(r+t),
$$
$$
\mathcal B_f(k,\ell)=\widehat f(k)\widehat f(\ell)
\overline{\widehat f(k+\ell)}.
$$
实值轮筛中可去掉相关定义内的复共轭。对 $s,t$ 分别作 Fourier 变换，三点相关恰变为 $\mathcal B_f$；二点相关变为 $|\widehat f|^2$。有固定整数原点的任务为
$$
P_{H,W}(b)=\sum_{1\le r\le b}a_{H,W}(r)\quad(0\le b<W),
$$
$$
A_H(N;W)=\sum_{1\le n\le N}a_{H,W}(n)
=\left\lfloor\frac NW\right\rfloor\prod_{q\mid W}(q-\nu_H(q))
+P_{H,W}(N\bmod W).
\tag{16.1}
$$
最后一个恒等式按完整周期和最后前缀分解，因而不要求任何素数分布估计。

**定理 16.2（轮筛自动满足三点恢复的非消失条件）。** 对定义 16.1 的每个轮筛，
$$
\widehat a(k)\ne0\qquad(k\bmod W).
\tag{16.2}
$$
因此其完整三点相关在所有复信号中确定 $a$ 到唯一的循环平移。若再给定有固定原点的复数 $\widehat a(1)$，则唯一确定 $a$ 及式 (16.1) 的全部有序计数。

**证明。** 使用 [Keleti–Kolountzakis 的非消失与三点恢复原理](../../../Library/Fourier/keletikolountzakis2006determination.md)，先验证此轮筛的全部前提。对素数 $q$，合法集合
$$
R_{H,q}=\mathbb F_q\setminus\{-h:h\in H\}
$$
是真非空子集。零频率为正数 $|R_{H,q}|$。若非零频率消失，则其 $0/1$ 多项式
$$
P(T)=\sum_{r\in R_{H,q},\,0\le r<q}T^r
$$
在一个本原 $q$ 次单位根处为零。该根的最小多项式为 $\Phi_q(T)=1+\cdots+T^{q-1}$，故 $\Phi_q\mid P$；次数比较强制 $P$ 的全部系数相等，与真非空子集矛盾。最小多项式的不可约性亦可由 $\Phi_q(T+1)$ 的 Eisenstein 判别得到。

令 $w_q=W/q$、$c_q=w_q^{-1}\bmod q$。CRT 的表示 $r=\sum_{q\mid W}r_qw_qc_q$ 给
$$
\widehat a(k)=\prod_{q\mid W}
\widehat{\mathbf1_{R_{H,q}}}(kc_q)\ne0.
\tag{16.3}
$$
为明确复共轭与归一化，写 $F_k=\widehat a(k)$、$J_k=\widehat g(k)$，并设 $\mathcal B_a=\mathcal B_g$。由 $\mathcal B_f(0,0)=|F_0|^2F_0$ 及 $z\mapsto|z|^2z$ 的单射性，得到 $J_0=F_0\ne0$；再由 $\mathcal B_f(k,0)=F_0|F_k|^2$ 得 $|J_k|=|F_k|>0$。比值 $R_k=J_k/F_k$ 满足
$$
|R_k|=1,\qquad R_{k+\ell}=R_kR_\ell.
$$
故 $R_k=R_1^k$ 且 $R_1^W=1$，存在唯一 $t\bmod W$ 使 $R_k=e_W(-kt)$。Fourier 反演给 $g=T_ta$。反向代入双谱时平移因子相消。最后，若还要求 $\widehat g(1)=\widehat a(1)\ne0$，则 $e_W(-t)=1$，故 $t=0$。∎

**命题 16.3（生成元行、恢复成本及假设边界）。** 在定理 16.2 的同一条件下，功率谱与单行 $\mathcal B_a(k,1)$ 已能恢复至平移。给定有原点标记的 $F_1$ 后，
$$
F_0=\frac{\mathcal B_a(0,1)}{|F_1|^2},\qquad
F_{k+1}=\overline{\frac{\mathcal B_a(k,1)}{F_kF_1}}
\tag{16.4}
$$
恢复全部 Fourier 系数。该轮筛没有非平凡平移周期，其全部循环移位组成的 Gram 严格正定，但 Gram 本身未记录这些相位。

**证明。** 对具有相同功率谱与该双谱行的 $g$，比值仍满足 $|R_k|=1$，单行关系给 $R_{k+1}=R_kR_1$，$k=0$ 时给 $R_0=1$，循环闭合给 $R_1^W=1$。式 (16.4) 是双谱定义的代数反解，分母由定理 16.2 非零。平移周期必须使第一 Fourier 系数不变，所以只能为零。循环 Gram 的 Fourier 特征值为 $|F_k|^2>0$，从而严格正定。∎

上述恢复要求取得整行观测及一个原点相位；不含观测取得或高精度反演的复杂度界。非消失也不提供独立于 $W$ 的逆条件数。平方自由性不可删除：$W=4,H=\{0\}$ 的轮筛是奇数指示函数，其第一 Fourier 系数为零。空 $H$ 给恒一函数；不可容许的局部因子使整个轮筛为零；这两种情形均不满足定理前提。

**定理 16.4（两种三胞胎的二点障碍与平移分界）。** 对任意平方自由 $W\ge2$，写 $a_A=a_{H_A,W}$、$a_B=a_{H_B,W}$。有
$$
a_B(r)=a_A(-r-6),\quad
\widehat a_B(k)=e_W(6k)\overline{\widehat a_A(k)},\quad
G_{a_A}=G_{a_B},
\tag{16.5}
$$
其中 $G_a(i,j)=\langle T_ia,T_ja\rangle=C_a(i-j)$ 保留全部相同移位标签。此外
$$
\exists t:\ a_B=T_ta_A
\quad\Longleftrightarrow\quad
q\mid W\Longrightarrow q\in\{2,3,5\}.
\tag{16.6}
$$
因此若 $W$ 含素因子 $q\ge7$，两轮筛的二点相关和全部循环 Gram 谱函数仍相同，其三点相关却必不相同。

**证明。** $(-r-6)+H_A=\{-r-6,-r-4,-r\}$，变号不改变互素性，给反射等式及 Fourier 等式。实信号的自相关是偶函数，故反射保持每个二点相关，得到 Gram 逐项相等。

两种 $H$ 对每个素数均可容许，CRT 的各局部合法集合非空，所以全局平移等价当且仅当各局部合法集合在相应平移下相等。模 $2,3,5$ 的合法集合分别为
$$
\begin{array}{c|ccc}
&2&3&5\\ \hline
A&\{1\}&\{2\}&\{1,2\}\\
B&\{1\}&\{1\}&\{2,3\}
\end{array}
$$
局部平移分别为 $0,2,1$。对 $q>3$，禁点集有三个不同元素，
$$
D_A=\{0,-2,-6\},\qquad D_B=-D_A-6.
$$
若 $D_B=D_A+t$，则 $D_A$ 在反射 $u\mapsto-u-6-t$ 下不变。奇素数域中该反射只有一个不动点，三元素不变集必须包含它，其余两点交换。因此某个 $u\in D_A$ 必须是另两点的中点。三个可能的 $2u-v-w$ 分别为 $8,2,-10$，所以 $q$ 必须整除其中一个数；在 $q>3$ 中只可能是 $5$。反向在仅含 $2,3,5$ 时由 CRT 合并局部平移即可。若含 $q\ge7$，式 (16.6) 排除平移，定理 16.2 随即排除三点相关相等。∎

**命题 16.5（绝对原点与首次正跨度见证）。** 模 $30$ 时
$$
R_{A,30}=\{11,17\},\quad R_{B,30}=\{7,13\}=R_{A,30}-4.
$$
故两者所有平移不变量，包括任意阶平移不变相关，完全相同，但 $P_{A,30}(10)=0$、$P_{B,30}(10)=1$。模 $210$ 时则有
$$
C_{a_A}^{(3)}(6,30)=1,\qquad C_{a_B}^{(3)}(6,30)=0.
\tag{16.7}
$$
在 $0<s<t$ 的正位移跨度定义下，$30$ 是首次能够分离的跨度。

**证明。** 模 $30$ 的集合由上一证明的三行局部条件解得，平移 $-4$ 同时满足 $0\bmod2,2\bmod3,1\bmod5$。模 $7$ 的合法集合为
$$
R_{A,7}=\{2,3,4,6\},\qquad R_{B,7}=\{2,4,5,6\}.
$$
对位移 $(6,30)$，模 $2,3$ 位移均为零，各有一个局部起点。模 $5$ 位移为 $(1,0)$，A 的唯一起点为 $1$，B 的唯一起点为 $2$。模 $7$ 位移为 $(6,2)$，A 只有起点 $4$，其三点为 $(4,3,6)$；B 的候选起点 $2,4,5,6$ 分别缺少 $1,3,0,1$，所以无解。CRT 给 A 的唯一全局起点 $r=11\bmod210$，得到式 (16.7)。

若 $0<s<t<30$，非零相关要求 $s,t$ 均被 $6$ 整除，因为模 $2,3$ 合法集合都是单点。于是 $s,t$ 来自 $\{6,12,18,24\}$，在模 $5$ 下是两个不同非零余数。三个位置 $0,s,t$ 模 $5$ 互异，无法同时落入只有两个元素的合法集合。因此两轮筛在所有更小正跨度处的三点相关都为零。∎

**命题 16.6（模七的二阶退化及谱矩的边界）。** 模 $7$ 的两个禁点集 $\{0,1,5\}$、$\{0,1,3\}$ 各自的六个有序非零差恰好覆盖 $\mathbb F_7^\times$ 一次。其合法集合的循环 Gram 都为
$$
G=2I_7+2J_7,\qquad \operatorname{Spec}(G)=\{16,2,2,2,2,2,2\},
$$
其中 $J_7$ 是全一矩阵。对式 (16.5) 的任意 $W$，提高同一个 $G$ 的谱矩阶数仍不能恢复在其构造中丢失的算术三点相关。

**证明。** 六个差逐项相减即为 $1,\ldots,6$。若禁点集为 $D$，则对非零位移 $s$，
$$
C_{\mathbf1_{D^c}}(s)=7-|D|-|D|+C_{\mathbf1_D}(s)=7-3-3+1=2,
$$
零位移值为 $4$。这给矩阵和特征值。一般地，$G_A=G_B$ 已经强制 $\operatorname{tr}(G_A^m)=\operatorname{tr}(G_B^m)$ 对每个正整数 $m$ 成立；式 (16.7) 同时给出算术三点相关不同的实例。故 $\operatorname{tr}G^3$ 的三个矩阵指标与 $C_a^{(3)}(s,t)$ 的三个算术位置不可互换。∎

**定义与命题 16.7（有标记 Fibonacci 窗口的一致稳定恢复）。** 对任意 $W\ge1$、复信号 $f$ 和正整数 $L$，定义带固定位置标签的窗口和
$$
(S_Lf)(r)=\sum_{j=0}^{L-1}f(r+j).
$$
当 $L>W$ 时按重复绕行次数计权。两组窗口 $(S_Af,S_Bf)$ 的共同核维数为 $\gcd(W,A,B)-1$，故可恢复所有信号当且仅当 $\gcd(W,A,B)=1$。

特别地，沿本卷 $F_0=0,F_1=1$ 的 Fibonacci 数列，对每个 $k\ge2$ 与每个 $W$，
$$
\|f\|_2^2\le F_{2k-3}
\left(\|S_{F_k}f\|_2^2+\|S_{F_{k+1}}f\|_2^2\right).
\tag{16.8}
$$
它给轮筛有序信号及式 (16.1) 的一个稳定恢复接口，常数与 $W$ 无关，未断言该常数最优。

**证明。** Fourier 乘子为 $D_L(z)=1+z+\cdots+z^{L-1}$，$z=e_W(j)$。在 $z\ne1$ 时，$D_L(z)=0$ 当且仅当 $z^L=1$；零频率乘子为正数 $L$。因此共同零点是非平凡的 $\gcd(W,A,B)$ 次单位根，得到核维数。

置 $A=F_k,B=F_{k+1}$。递推给
$$
u=F_{k-1},\quad v=-F_{k-2},\quad uA+vB=(-1)^k,\quad
u^2+v^2=F_{2k-3}.
$$
第一恒等式的左侧随 $k$ 增一变号，$k=2$ 时为一；第二恒等式来自 Fibonacci 加法公式 $F_{m+n}=F_{m-1}F_n+F_mF_{n+1}$，该公式以 $n=0,1$ 为初值按 $n$ 递推，再取 $m=k-1,n=k-2$；$k=2$ 单独直接成立。对 $|z|=1,z\ne1$，整数幂的望远镜不等式给
$$
|1-z|=|1-z^{uA+vB}|
\le |u|\,|1-z^A|+|v|\,|1-z^B|.
$$
除以 $|1-z|$，再用 Cauchy–Schwarz，得到
$$
|D_A(z)|^2+|D_B(z)|^2\ge\frac1{u^2+v^2}=\frac1{F_{2k-3}}.
$$
$z=1$ 时显然也成立，Parseval 给式 (16.8)。每个频率可用
$$
\widehat f(j)=
\frac{\overline{D_A(z)}\,\widehat{S_Af}(j)+
\overline{D_B(z)}\,\widehat{S_Bf}(j)}
{|D_A(z)|^2+|D_B(z)|^2}
$$
反解。若两组观测的合并 $\ell^2$ 误差为 $\varepsilon$，同一公式与 Cauchy–Schwarz 给信号误差至多 $\sqrt{F_{2k-3}}\varepsilon$。∎

该接口使用全部位置标签和两组各 $W$ 个窗口和。它保留了原点信息，尚未给减少这些读数的算法或素数统计的误差估计。任意互素正长度对也可用 Bézout 系数给同类界；Fibonacci 递推在此供应明确的系数。仅有固定 $W$ 的可逆性不供应一致稳定性：若 $d=\gcd(A,B)>1$，则 $W_m=md+1$ 上均可逆，但对应频率 $z_m=e^{2\pi im/W_m}$ 趋向非平凡 $d$ 次单位根，两个乘子同时趋零，故不存在适用于这些 $W_m$ 的统一正下界。

## 十七、同一三维 Gram 的锐谱界与重叠块组合

**定义 17.1（全局来源与局部能量）。** 固定一个 $N$ 阶 Hermitian 半正定矩阵 $G$，$G_{ii}=1$，并保持其原始维数。对三元素索引集 $S$，置
$$
B=G[S],\qquad e(B)=\sum_{i<j,\ i,j\in S}|G_{ij}|^2\in[0,3].
$$
$D_\Psi$ 使用命题 15.3 的同一函数。以下将 Wolkowicz–Styan 的经典迹矩特征值界和 Hansen–Pedersen 的迹 Jensen 方法特化到当前有限 Gram；[Wang 文献条目](../../../Library/Weil/wang2026proportions.md) 给出这两项主源、零点计数消费者及原先的不交三点块范围。

**定理 17.2（全部能量区间的最优三点下界）。** 仅给定 $e=e(B)$ 时，
$$
D_\Psi(B)\ge F(e):=
2e-\left(2\sqrt{e/3}-1\right)_+^2
=\begin{cases}
2e,&0\le e\le3/4,\\
\frac23e+4\sqrt{e/3}-1,&3/4\le e\le3.
\end{cases}
\tag{17.1}
$$
对每个 $e\in[0,3]$ 都有实对称半正定单位对角矩阵达到此界。$F$ 严格递增；所以已证 $e(B)\ge e_*$ 时可使用 $F(e_*)$。在 $e\le3/4$ 时，所有这样的 $B$ 都有精确等式 $D_\Psi(B)=2e$。

**证明。** 设特征值 $\lambda_1\ge\lambda_2\ge\lambda_3\ge0$。迹为三，且
$$
\sum_j\lambda_j^2=3+2e.
$$
至多一个特征值大于二。用 $\Psi(t)=(t-1)^2-(t-2)_+^2$ 得
$$
D_\Psi(B)=2e-(\lambda_1-2)_+^2.
$$
另由 Cauchy–Schwarz，
$$
3+2e\ge\lambda_1^2+\frac{(3-\lambda_1)^2}{2}
=3+\frac32(\lambda_1-1)^2.
$$
$\lambda_1\ge1$，故 $\lambda_1\le1+2\sqrt{e/3}$，即得下界。取 $r=\sqrt{e/3}\in[0,1]$，
$$
B_e=(1-r)I_3+r\mathbf1\mathbf1^*
$$
的谱为 $1+2r,1-r,1-r$，恰达到该界。$F$ 的导数在下段为二，在上段为 $2/3+2/\sqrt{3e}>0$，接点两导数相同，证明单调性及全部断言。∎

**定理 17.3（保留重复使用成本的分数装填）。** 给定同一个 $G$ 的任意有限族非空主块 $B_\alpha=G[S_\alpha]$。若
$$
w_\alpha\ge0,\qquad
\sum_{\alpha:\,i\in S_\alpha}w_\alpha\le1\quad(1\le i\le N),
\tag{17.2}
$$
则
$$
D_\Psi(G)\ge\sum_\alpha w_\alpha D_\Psi(B_\alpha).
\tag{17.3}
$$
若各块均为三阶且实际能量满足 $e(B_\alpha)\ge e_\alpha^*\in[0,3]$，则
$$
D_\Psi(G)\ge
\max_{\substack{w_\alpha\ge0\\
\sum_{\alpha:i\in S_\alpha}w_\alpha\le1}}
\sum_\alpha w_\alpha F(e_\alpha^*).
\tag{17.4}
$$
此有限线性规划包含每个不交块选取作为可行点；若 $L\ge1$ 且每个索引至多属于 $L$ 个块，统一权重 $1/L$ 可行。

**证明。** 取主块 $G[S]$ 的正交单位特征向量 $v_j$，向 $S$ 外补零。标量凸函数 $\Psi$ 作用于 $G$ 的谱分解给
$$
\Psi(v_j^*Gv_j)\le v_j^*\Psi(G)v_j.
$$
求和得到 $D_\Psi(G[S])\le\operatorname{tr}(P_S\Psi(G))$。置 $Q=\sum_\alpha w_\alpha P_{S_\alpha}$，式 (17.2) 恰给 $0\le Q\le I$；又 $\Psi(G)\succeq0$，故
$$
\sum_\alpha w_\alpha D_\Psi(B_\alpha)
\le\operatorname{tr}(Q\Psi(G))
\le\operatorname{tr}\Psi(G).
$$
最后一步因为 $\operatorname{tr}(\Psi(G)^{1/2}(I-Q)\Psi(G)^{1/2})\ge0$。定理 17.2 与可行域的紧性给式 (17.4)；各非空块的权重均不超过一。∎

**推论 17.4（局部 $\kappa$ 模型的稳健实际消费者）。** 若实际三阶主块 $B$ 满足
$$
\left(\sum_{i<j}|B_{ij}-(U_c)_{ij}|^2\right)^{1/2}\le\varepsilon,
$$
则 $e(B)\ge(c-\varepsilon)_+^2$。保留指定相关对还给更强的
$$
D_\Psi(B)\ge2|B_{12}|^2\ge2(c-\varepsilon)_+^2.
\tag{17.5}
$$
对于同一个 $G$ 内多组这样的指定相关对 $E_\alpha$，只要 $w_\alpha\ge0$ 且
$\sum_{\alpha:i\in E_\alpha}w_\alpha\le1$，便有
$$
D_\Psi(G)\ge2\sum_\alpha w_\alpha(c_\alpha-\varepsilon_\alpha)_+^2.
\tag{17.6}
$$

**证明。** 非对角向量的反三角不等式给能量界，也给 $|B_{12}|\ge(c-\varepsilon)_+$。这对索引组成的二阶主块有特征值 $1\pm|B_{12}|$，谱修正量恰为 $2|B_{12}|^2$。直接在定理 17.3 中采用该二阶主块即可；第三个坐标无需占用式 (17.6) 的索引容量。∎

所有块必须来自已经指定的同一实际矩阵。分别选择不同核、不同来源或不同归一化下的最好局部值，不满足这里的量词。若仅知全 Frobenius 误差不超过 $\varepsilon_F$，则单位对角条件给上述非对角误差 $\varepsilon=\varepsilon_F/\sqrt2$。命题 15.3 的局部除数律本身还未供应这样的实际核近似。

**命题 17.5（三点循环相位及实核的精确边界）。** 对
$$
B=\begin{pmatrix}1&a&\overline c\\\overline a&1&b\\c&\overline b&1\end{pmatrix}
\succeq0,\qquad e=|a|^2+|b|^2+|c|^2,\quad h=\Re(abc),
$$
有
$$
\det B=1-e+2h,\qquad \operatorname{tr}B^3=3+6e+6h,\qquad
\lambda_{\max}(B)>2\Longleftrightarrow e+2h>1.
\tag{17.7}
$$
一般复 Hermitian 情形中，三个非对角模长不决定 $D_\Psi(B)$；实对称半正定三阶情形中，它们却决定 $D_\Psi(B)$。

**证明。** 展开特征多项式得 $(\lambda-1)^3-e(\lambda-1)-2h$，同时给行列式与三阶迹。迹三和半正定性给 $\lambda_2\le3/2$，所以 $\det(2I-B)$ 的符号由 $2-\lambda_1$ 决定，得到判据。取 $r=4/7$，$a=b=c=r$ 时谱为 $15/7,3/7,3/7$，$D_\Psi=95/49$；取 $a=b=r,c=ir$ 时谱为 $1+4\sqrt3/7,1,1-4\sqrt3/7$，仍半正定，$D_\Psi=96/49$。模长相同，证明复情形的差异。

实情形置 $p=|abc|$，仅有 $h=p$ 或 $h=-p$。若负循环号可以半正定，则 $1-e-2p\ge0$，从而即使正循环号也满足 $e+2p\le1$，所有可行符号都给 $D_\Psi=2e$。若 $e+2p>1$，半正定性排除负循环号，强制 $h=p$；此时模长已固定整个特征多项式。$p=0$ 同样无歧义。∎

这个复矩阵例子不构成实偶 Fourier 核的三点谱修正反例。命题 16.6 的算术相位障碍更强：它已固定全部 pair Gram，因而其所有谱矩无论实复都不能再分离相应轮筛。

## 十八、实际差值核的实现成本与解析量词

**定义 18.1（真实差值核）。** 取实偶、非负的 $\rho\in L^1(\mathbb R)$，$\int\rho=1$，定义
$$
K(t)=\int_{\mathbb R}\rho(u)e^{2\pi iut}\,du,\qquad
G_{ij}=K(x_i-x_j),
$$
其中 $x_1,\ldots,x_N$ 为互异实数。该 $G$ 是单位对角实对称 Gram。

**命题 18.2（模三秩二目标的精确与定量实现边界）。** 定义 18.1 的 $G$ 严格正定，故三个互异点不能精确实现命题 15.3 的 $U_1$。若进一步有
$$
\rho(u)\ge m>0\quad\text{几乎处处于 }[-a,a],\qquad
a>0,\quad |x_1-x_2|\ge d>0,
$$
置
$$
\delta=\frac{ma}{4}\min\{(2\pi ad)^2,1\},
$$
则相应三阶主块 $B$ 满足
$$
\|B-U_c\|_{\mathrm{op}}\ge(c-1+\delta)_+,\qquad
\|B-U_c\|_F\ge\sqrt2\,(c-1+\delta)_+.
\tag{18.1}
$$
特别在 $c=1$ 时，误差不能任意趋零而同时保留这些 $m,a,d$。

**证明。** 对系数向量 $v$，
$$
v^*Gv=\int\rho(u)\left|\sum_jv_je^{-2\pi ix_ju}\right|^2\,du.
$$
若为零，括号中的指数多项式在 $\{\rho>0\}$ 的一个正测度集合上为零。其解析性迫使它恒为零；在零点取前 $N$ 个导数，互异 $x_j$ 的 Vandermonde 矩阵迫使每个 $v_j=0$。故严格正定。

置 $t=x_1-x_2$。由于 $1-\cos(2\pi ut)\ge0$，
$$
1-K(t)\ge 2ma\left(1-\frac{\sin(2\pi at)}{2\pi at}\right).
$$
对实数 $s$ 有 $1-\sin s/s\ge\frac18\min(s^2,1)$，零点取连续值。为验证常数，对 $0\le s\le2$ 使用交错 Taylor 界
$1-\sin s/s\ge s^2/6-s^4/120$；$s\le1$ 时至少为 $19s^2/120$，$1\le s\le2$ 时该多项式递增且至少为 $19/120$。$s\ge2$ 时 $\sin s/s\le1/2$，负 $s$ 用偶性。因此 $1-K(t)\ge\delta$。

对单位向量 $(1,-1,0)/\sqrt2$，$B-U_c$ 的 Rayleigh 商为 $c-K(t)\ge c-1+\delta$，给算子范数界。两个对应非对角项给 Frobenius 界；右侧为负时改取正部即可。∎

**命题 18.3（无间距约束时不存在统一正距离）。** 对每个定义 18.1 的密度，存在互异三点产生的严格正定 Gram 序列趋于 $U_1$。

**证明。** $L^1$ 密度的 Fourier 变换连续，$K(t)\to1$ 当 $t\to0$；Riemann–Lebesgue 引理给 $K(t)\to0$ 当 $|t|\to\infty$。取 $x_1=0,x_2=s,x_3=T$，先使非零 $s$ 足够小，再使 $T$ 足够大，便使相关对接近一、另两对接近零。每个有限阶段仍由命题 18.2 严格正定。∎

**假设与条件推论 18.4（同一零点配置的比例消费者）。** 采用 [Wang 命题 2.1 的实际有限多重集及核](../../../Library/Weil/wang2026proportions.md)：$\eta$ 为实偶紧支撑 $L^2$ 函数、$\int\eta^2=1$，$K=\widehat{\eta^2}$。对充分大 $T$，取共轭对称多重集
$$
Z_T=\left\{\frac{i(\varrho-1/2)\log T}{2\pi}:
\varrho\text{ 为真实 }\zeta\text{ 零点},\quad0<\Im\varrho\le T\right\}.
$$
$N_T=|Z_T|>0$ 保留真实重数，$n_T$ 为简单实元素数，$D_T$ 为不同元素数。$G_T$ 仅取这同一多重集的简单实元素，保留其 $n_T$ 阶维数。令
$$
E_T=\sum_{z,s\in Z_T}K(z-s)^2
$$
为文献中的完整二次能量，取复数平方而非模平方。紧支撑保证复参数处的 $K$ 有定义。

若在每个同一 $G_T$ 上取得定理 17.3 的实际块能量与可行权重，令其下界为 $L_T$，并另外证明
$$
\limsup_{T\to\infty}\frac{E_T}{N_T}\le A,\qquad
\liminf_{T\to\infty}\frac{L_T}{N_T}\ge\delta_0,
$$
则
$$
\liminf\frac{n_T}{N_T}\ge2-A+\delta_0,\qquad
\liminf\frac{D_T}{N_T}\ge\frac32-\frac A2+\frac{\delta_0}2.
\tag{18.2}
$$

**证明。** 文献的有限不等式为 $n_T\ge2N_T-E_T+D_\Psi(G_T)$ 与 $D_T\ge3N_T/2-E_T/2+D_\Psi(G_T)/2$。定理 17.3 给 $D_\Psi(G_T)\ge L_T$，除以 $N_T$ 并按所列上下极限取界即得。$\eta^2$ 是定义 18.1 的密度，故命题 18.2 同时约束这些实际核块对 $U_1$ 的实现。∎

式 (18.2) 的新输入是实际配置上的 $L_T$ 及其渐近下界。有限轮筛的三点恢复、局部 $\kappa$ 或 Fibonacci 窗口反演尚未给出它们。Wang 的已给定能量 $e(H)=(\sqrt5-2)^2/(1+2\pi^2H^2)^2$ 总小于 $1/2$，因此仅把线性区间扩大到 $3/4$ 不改变该已用能量的数值；重叠块能否给更高比例仍要证明同一配置上的组合与解析估计。即使比例下界达到一，其极限量词也不排除有限或零密度的线外例外。

**定义与命题 18.5（有序筛信息通向实际三胞胎的估计目标）。** 对 $H_A$ 或 $H_B$ 及整数 $N\ge19$，取
$$
W_N=\prod_{q\le\sqrt{N+6}}q,\qquad
T_H(N)=\#\{1\le n\le N:\ n+h\text{ 对每个 }h\in H\text{ 都为素数}\}.
$$
则
$$
0\le T_H(N)-A_H(N;W_N)\le\lfloor\sqrt{N+6}\rfloor.
\tag{18.3}
$$
因此若能另证某个常数 $c_0>0$ 下 $A_H(N;W_N)\ge c_0N/(\log N)^3$ 对全部充分大 $N$ 成立，即得到该三胞胎无穷性。

**证明。** 因 $N\ge19$，截断包含素数 $3,5$。$n=1$ 在 $H_A$ 中被偏移 $2$ 产生的 $3$ 筛掉，在 $H_B$ 中被偏移 $4$ 产生的 $5$ 筛掉。因此每个存活的 $n+h$ 都大于一且不超过 $N+6$；若它合成，必有不超过 $\sqrt{N+6}$ 的素因子，与存活矛盾，故全部存活项为真实三胞胎。反向，真实三胞胎若被筛掉，某个素数 $n+h\le\sqrt{N+6}$，于是 $n\le\sqrt{N+6}$；这样的起点至多所列数量。所得正下界随 $N$ 无界，给无穷性。∎

这里的模长与 $N$ 共同增长。定理 16.2、16.7 证明在取得相应有限观测后可以恢复 $A_H$，未证明式 (18.3) 所消费的增长下界，也未证明固定偏移的 von Mangoldt 三重相关渐近式。

**定义 18.6（与 Robin 完整余量的接续目标）。** 使用 [Robin 二进尺度卷 §§479、486、488–489](FIBONACCI_ATOMIC_RELATION_GENERATION_ROBIN_DYADIC_RESOLVENT.md) 中同一个实际有符号积分
$$
I_\psi(x)=\int_x^\infty(\psi(t)-t)
\frac{1+\log t}{t^2\log^2t}\,dt.
$$
对每个整数 $n>5040$，其普通整数余量身份仍为
$$
\log\frac{e^\gamma\log\log n}{\sigma(n)/n}
=I_\psi(\log n)+R(\log n)+d_n,\qquad d_n\ge0.
\tag{18.4}
$$
§486 的实际储备下界 $R(x)>1/(50\sqrt x\log x)$、§489 经有限素数证书补齐的 Mathlib 路线 $R(x)>1/(120\sqrt x\log x)$，以及 §488 的奇数二幂补齐成本，均保留各自的前提与原量词。由本卷有限观测推进 RH 所需的目标，是对式 (18.4) 的同一完整余量，或对实际 Weil 测试类，给足够的有符号下界。分别的正谱量、局部存活率和无原点相关尚未提供这种识别及估计。

若另有 $\psi(t)-t=O(t^\theta(\log t)^B)$，其中固定 $\theta<1$、$B\ge0$，则直接绝对积分只给
$$
I_\psi(x)=O\!\left(x^{\theta-1}(\log x)^{B-1}\right),\qquad
\sqrt x\log x\,I_\psi(x)=O\!\left(x^{\theta-1/2}(\log x)^B\right).
\tag{18.5}
$$
证明为在 $t\ge x\ge e$ 上用 $(1+\log t)/\log^2t\le2/\log t$，再令 $t=xe^u$；剩余积分的 $e^{-(1-\theta)u}$ 乘固定对数幂可积。当 $\theta>1/2$ 时，这一绝对值估计本身不足以与固定平方根储备常数比较符号。它没有排除通过更强的有符号抵消得到所需估计。[固定无零半平面与算术三维空间的来源条目](../../../Library/Analytic/openai2026quasirh.md) 区分了外部 $\mathbb H^3$ 的实际算术作用、本卷三均值几何及尚未建立的解析映射。
