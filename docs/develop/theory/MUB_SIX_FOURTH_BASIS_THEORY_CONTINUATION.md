# 六维第四个无偏基问题：理论续卷

本卷承接 [前卷](MUB_SIX_FOURTH_BASIS_THEORY.md)，保留其编号、基约定与参数支。前卷第 51 节给出了实际循环正交三元组的严格换位正性；本卷进一步使用同一组相位与两组 flatness，排除该正性区域内的零模平衡子层。

## 52. 实参数支上实际循环三元组的零模不平衡

### 52.1 定义与结论

沿用前卷第 46、51 节的实参数支。令 `-1<a<1`，取

```math
p=\frac{a-1+i(h+a/h)}2,\qquad
q=\frac{-a-1+i(h-a/h)}2,
\qquad h>1,\qquad s=h^2,\qquad
a^2=\frac{s(3-s)}{1+s}.
```

这里 `p,q` 是前卷所选的上半平面单位相位，`p+q=-1+ih`。记 `P=p-1,Q=q-1`、`A=J+PI,B=J+QI`，并固定

```math
H_0=\frac1{\sqrt6}
\begin{pmatrix}A&B\\\overline B&-\overline A\end{pmatrix},
\qquad Sx=(x_1,x_2,x_0).
```

`A,B` 对称，故此处的共轭也等于 adjoint。这个 paired-circulant 种子来自 Szöllősi 的已知构造，见 [arXiv:0811.3930，§2](https://arxiv.org/abs/0811.3930)，DOI `10.1090/S0002-9939-09-10102-8`；以下结论是对其实际循环三元组的额外限制。

**命题 52.1。** 设 `v=(x,y)/sqrt(6)`，其中 `x,y` 的六个分量均有模一。若 `H0v` 也 flat，且同一组实际向量 `v,Sv,S²v` 两两正交，则

```math
\boxed{\left|\sum_jx_j\right|^2\ne3,
\qquad\left|\sum_jy_j\right|^2\ne3.}
```

等价地，`alpha_x=sum_j conjugate(x_j)x_(j+1)` 的实部非零。循环正交给出两个零模能量之和为六，故任一等式成立就会同时成立。本命题只限制种子中指定的零模，不把另外两个 mode 与它交换。

### 52.2 平衡相位纤维的完整分支

反设 `|sum x|²=3`。循环正交给出 `alpha_x+alpha_y=0`，而 `|sum x|²=3+2 Re(alpha_x)`，所以 `alpha_x=in`，其中 `n` 为实数。

对任意单位相位三元组 `z`，相邻比值 `e_j=conjugate(z_j)z_(j+1)` 的积为一，并且恰为下述多项式的三个根，按重数计：

```math
t^3-\alpha_z t^2+\overline{\alpha_z}t-1.
```

由于 `alpha_y=-alpha_x=conjugate(alpha_x)`，`y` 的相邻比值是 `x` 的相邻比值的共轭的一种排列。三个比值的偶排列是循环置换，积分后得到 `y=gamma S^m conjugate(x)`；奇排列则得到 `y=gamma Rx`，其中 `R` 是一个坐标换位。积分只留下同一个单位相位 `gamma`。因此全部可能性为

```math
y=\gamma Rx\quad(R\text{ 为三个换位之一}),
\qquad
y=\gamma S^m\overline x\quad(m=0,1,2),
\qquad |\gamma|=1.
\tag{52.1}
```

该推理也包括有重复比值的情形。下面逐类排除，始终保留输入和输出中的同一个 `gamma`。

### 52.3 普通反射分支的正多项式证书

`H0` 与所有同步坐标置换交换，而坐标置换将 `S` 共轭为 `S` 或 `S²`。故普通反射分支只需处理 `y=gamma R01x`。乘公共相位后可设 `x2=1`，并置

```math
u=\frac{x_0+x_1}{2},\qquad b=|u|^2,\qquad w=\operatorname{Im}u,
\qquad\gamma=G+iH,\quad G,H\in\mathbb R.
```

两个 channel 的自相关互为共轭，循环正交使它们之和为零，故 `|1+2u|²=3`。于是

```math
\operatorname{Re}u=\frac12-b,
\qquad w^2=2b-b^2-\frac14,
\qquad 0\le b\le1.
\tag{52.2}
```

同时，`<v,R01v>=(4b-1)/3`。前卷第 51 节的严格换位正性因此给出 `b>1/4`。

定义 `Y=aH/h`。固定坐标二上的两个未归一化输出分量为

```math
z_+=p+2u+\gamma(q+2u),\qquad
z_-=\overline q+2u-\gamma(\overline p+2u).
```

令 `E±=|z±|²-6`。代入种子恒等式、`G²+H²=1` 和式 (52.2)，直接展开得到

```math
E_++E_-=4\bigl(2hw(G-Y)+6b-3\bigr),
```
```math
E_+-E_-=2\bigl((12b+s-3)G-(4b+s-1)Y+4hw\bigr).
```

实际 flatness 使两式为零。还须保留整个第一输出 channel 的范数。由

```math
A^\dagger A=(3-a)I+aJ,\quad B^\dagger B=(3+a)I-aJ,
\quad A^\dagger B=\overline P QI+(3+\overline P+Q)J
```

以及 `||x||²=|sum x|²=3`，有 `||Ax||²=||BR01x||²=9`。所以 `||Ax+gamma BR01x||²=18` 等价于 `Re(gamma Z)=0`，其中

```math
Z=\overline P Q(4b-1)+3(3+\overline P+Q)
=\frac{(s+3)(4b-1)}2+
\frac{ia}{2h}\bigl((s+3)(4b-1)-6\bigr).
```

这里用了 `bar(P)Q=(s+3)/2+ia(h+3/h)/2` 和 `3+bar(P)+Q=-ia/h`。合并三个实际方程，得到

```math
\begin{pmatrix}
2hw&-2hw&6b-3\\
12b+s-3&-(4b+s-1)&4hw\\
(s+3)(4b-1)&6-(s+3)(4b-1)&0
\end{pmatrix}
\begin{pmatrix}G\\Y\\1\end{pmatrix}=0.
\tag{52.3}
```

但左侧矩阵的行列式恰为 `-24F(b,s)`，其中

```math
F(b,s)=s b(8b^2-10b+5)+3(b-1)(4b-1)(2b-1).
```

这个多项式在 `1/4<b<=1,s>1` 上严格为正。首先

```math
8b^2-10b+5=8(b-5/8)^2+15/8>0.
```

当 `b<=1/2` 时，`F` 的第一项为正、第二项非负；当 `b>=1/2` 时，使用恒等式

```math
F(b,s)=(s-1)b(8b^2-10b+5)+8b(1-b)^2+3(2b-1)^3>0.
```

因此式 (52.3) 不可能湮灭非零向量 `(G,Y,1)`。这排除了所有普通反射分支，并且没有除以 `a`，所以包括 `a=0`。

### 52.4 未位移的共轭分支

若 `y=gamma conjugate(x)`，令 `z_j=(x_j,y_j)`、`r_jk=Re<z_j,z_k>`。其 Gram 矩阵是实矩阵、对角元为二，且秩至多二，因为 `<z_j,z_k>=2 Re(conjugate(x_j)x_k)`。循环正交给出 `r01+r12+r20=0`；严格换位正性给出 `p_jk=1+r_jk>0`。展开行列式得

```math
\det(\langle z_j,z_k\rangle)
=2\bigl(p_{01}p_{12}+p_{12}p_{20}+p_{20}p_{01}
       +p_{01}p_{12}p_{20}\bigr)>0,
```

与秩约束矛盾。

### 52.5 两个共轭位移与中心化相位坐标

同步坐标换位将 `m=1` 与 `m=2` 互换，并保持实际 flatness 和循环正交。因此只需排除 `y=gamma S conjugate(x)`。

此时每个 `r_jk` 是 `x` 的两个相邻比值实部之和，亦即第三个实部的负值，因为三个实部之和为零。若 `x` 有两个相同分量，就会有一个相邻比值为一，从而产生换位内积零，与前卷第 51 节矛盾。故 `x` 的三个分量互不相同。

乘公共相位后可设 `sum x=sqrt(3)`；共轭位移关系保持，只改变单位相位 `gamma`。置

```math
\xi=x_0x_1x_2,\qquad d=1-\sqrt3\xi,\qquad
u=x-\frac1{\sqrt3}\mathbf1,\qquad\alpha_x=in.
```

单位相位的对称多项式给出

```math
u^Tu=2d,\qquad u^\dagger u=2,\qquad u^\dagger Su=-1+in.
```

`u,conjugate(u)` 线性无关；否则三个不同的单位圆点 `x_j` 会落在同一条实仿射直线上，而直线与圆最多相交两次。因此 `e=1-|d|²>0`。利用
`u^T S conjugate(u)=-1-in`、`conjugate(u)^T S conjugate(u)=-conjugate(d)`，解出

```math
S\overline u=\frac{in\overline d}{2e}u+
\left(-\frac12-\frac{in}{2e}\right)\overline u.
```

`S` 在二维零和空间的行列式为一；上述表示及其共轭组成的矩阵行列式为 `1/4+n²/(4e)`。所以 `n²=3e`，特别地 `n!=0`，并有

```math
S\overline u=\frac{3i\overline d}{2n}u+
\left(-\frac12-\frac{3i}{2n}\right)\overline u,\qquad
S^2\overline u=-\frac{3i\overline d}{2n}u+
\left(-\frac12+\frac{3i}{2n}\right)\overline u.
\tag{52.4}
```

再由 `|xi|=1`，即 `|1-d|²=3`，得到

```math
d=-\frac{n^2+3}{6}+i\nu,\qquad
36\nu^2=27-18n^2-n^4,\qquad\nu\in\mathbb R.
\tag{52.5}
```

### 52.6 两组 flatness 的联合系数方程

写 `gamma=G+iH`。两个未归一化输出 channel 的分量为

```math
P x_j+\gamma Q\overline{x_{j+1}}+\sqrt3(1+\gamma),\qquad
\overline Qx_j-\gamma\overline P\overline{x_{j+1}}+\sqrt3(1-\gamma).
```

定义

```math
A_+=\sqrt3P(1+\overline\gamma),\quad B_+=\sqrt3Q(1+\gamma),\qquad
A_-=\sqrt3\overline Q(1-\overline\gamma),\quad B_-=\sqrt3\overline P(1-\gamma),\qquad
D=P\overline Q\overline\gamma\xi.
```

使用 `x_j x_(j+1)=xi conjugate(x_(j+2))`，两个输出平方模的非恒定部分分别为 `A+u+B+S conjugate(u)+D S² conjugate(u)` 和 `A-u+B-S conjugate(u)-D S² conjugate(u)` 的两倍实部。由式 (52.4) 与线性无关性，两组 flatness 必须同时满足

```math
\mathcal E(A_+,B_+,D)=0,\qquad\mathcal E(A_-,B_-,-D)=0,
```
```math
\mathcal E(A,B,D)=A-\frac{\overline B+\overline D}{2}
+\frac{3i}{2n}\bigl(\overline d(B-D)+\overline B-\overline D\bigr).
\tag{52.6}
```

令 `L=bar(P)+Q=-3-ia/h`、`M=bar(P)-Q=a-ih`、`z=gamma M`。相加式 (52.6)，再乘 `2n/sqrt(3)`，得到

```math
n\overline L+3n\overline z+
3i\bigl(\overline d(L-z)+\overline L-\overline z\bigr)=0.
\tag{52.7}
```

这是关于同一个 `G,H` 的两个实线性方程。用式 (52.5) 和种子关系化简，其系数行列式为 `-48h²n²/(s+1)!=0`，所以

```math
G=\frac{6a(s+1)\nu-h^3n^2+9h}{6h^2n},\qquad
H=\frac{a(s+1)n^2+6h^3\nu}{6h^2n}.
\tag{52.8}
```

把式 (52.8) 代回第一组方程，记 `A0=a(5s+3)`、`B0=h(s-1)>0`，展开得到

```math
\operatorname{Re}\frac{\mathcal E(A_+,B_+,D)}{\sqrt3}
=-\frac{2A_0(\nu-n)-B_0(n^2+9)}{8h^2n},
```
```math
\operatorname{Im}\frac{\mathcal E(A_+,B_+,D)}{\sqrt3}
=\frac{A_0(n^2-3)+18B_0(n+\nu)}{24h^2n}.
\tag{52.9}
```

式 (52.7)–(52.9) 在清去已证明非零的分母后都是多项式恒等式，仅用了 `a²=s(3-s)/(1+s)` 与式 (52.5)。它们没有放松任何一组相位。

### 52.7 非零行列式矛盾与实际基方向

实际 flatness 和式 (52.9) 强制

```math
\begin{pmatrix}2(\nu-n)&-(n^2+9)\\n^2-3&18(n+\nu)\end{pmatrix}
\binom{A_0}{B_0}=0.
```

然而由式 (52.5)，该矩阵行列式恰为

```math
36(\nu^2-n^2)+(n^2+9)(n^2-3)=-48n^2\ne0.
```

所以 `A0=B0=0`，与 `B0=h(s-1)>0` 矛盾。式 (52.1) 的所有分支均已排除，命题 52.1 得证。

对相对于 `(I,H0)` 的实际共同无偏归一化列 `f`，应令 `v=H0* f`。此时 `v` 和 `H0v=f` 都 flat；因为 `H0` 与 `S` 交换，`f,Sf,S²f` 的正交等价于输入三元组的正交。因此本命题排除的是 `sqrt(6) H0* f` 两个 channel 的零模平衡，不能省略此基方向。

特别地，若 `y=gamma Pi x`，其中 `Pi` 为任意坐标置换，则两个 channel 的零模能量相等，循环正交又使其和为六。因此命题 52.1 同时排除了全部这种 projectively permuted channels。

**命题 52.2（严格正性区域中的输入反例族）。** 在普通反射分支中，任取 `1/4<b<1`，取 `u=1/2-b+iw`、`w²=2b-b²-1/4`，并令

```math
x_2=1,\quad
x_0=u\left(1+i\sqrt{\frac{1-b}{b}}\right),\quad
x_1=u\left(1-i\sqrt{\frac{1-b}{b}}\right),\quad y=\gamma R_{01}x.
```

这些输入单位相位的循环平移正交，两个 channel Fourier transforms 都满支撑；其三个换位内积为 `(4b-1)/3,2(1-b)/3,2(1-b)/3`，全部严格为正。但没有任何同一个单位相位 `gamma` 能使实际输出 flat。

**证明。** 显式公式给出 `|x0|²=|x1|²=b(1+(1-b)/b)=1` 和 `|1+2u|²=3`；`y` 是 `x` 的相位倍反射，故两个循环自相关之和为零。满支撑由前卷 §51.5 的逐模总能量六与单模退化排除推出。直接代入得到所列三个换位内积，而式 (52.3) 的正多项式证书排除实际输出 flat。证毕。

实际循环三元组本已由前卷第 46、51 节具有满支撑和非零 `Delta`，故 canonical mode-local 射线不在本节候选域中。本节进一步排除了零模平衡子层，仍未分类或排除零模能量不相等的循环三元组、来自不同置换轨道的三元组或 residual quartet。

## 53. 配对 two-circulant 的 Fourier 交点及实际 cyclic completion 的两条边

本节沿用正文 §51 和上节的实际向量方向。先对任意复参数的配对
circulant 矩阵给出精确交点判据，再将它用于同时满足两组平坦性条件的
cyclic triple。这里的 Hadamard 等价始终允许任意左右单位模对角矩阵
与行列置换；Fourier union 指 Fourier family 及其转置族的等价类之并。

### 53.1 任意复参数的平方行列对判据

下标属于 \(\mathbb Z/3\mathbb Z\)。对 \(x,y\in\mathbb T^3\)，置
\[
\alpha(z)=\sum_{t=0}^2\overline{z_t}z_{t+1},\qquad
X_{ij}=x_{i-j},\quad Y_{ij}=y_{i-j},\qquad
M(x,y)=\begin{pmatrix}X&-Y^*\\Y&X^*\end{pmatrix}.
\]
称两个不同行或不同列构成**平方比例对**，是指两向量逐项平方后成比例。
因为所有条目非零，这等价于相应两个平方向量的全部 \(2\times2\) 子式为零。
比例常数必为单位模。左右 monomial 等价保持相应类型的平方比例对是否存在。

**命题 53.1。** 假设 \(\alpha(x)+\alpha(y)=0\)。则 \(MM^*=6I\)，且：

1. \(M\) 有平方比例行对，当且仅当存在 \(d\in\mathbb Z/3\mathbb Z\)、
   \(\gamma\in\mathbb T\)，使 \(y_{t+d}=\gamma x_t\) 对所有 \(t\) 成立。
2. \(M\) 有平方比例列对，当且仅当存在 \(c\in\mathbb Z/3\mathbb Z\)、
   \(\gamma\in\mathbb T\)，使 \(y_{c-t}=\gamma\overline{x_t}\) 对所有 \(t\) 成立。
3. \(M\) 属于 Fourier union，当且仅当 \(\alpha(x)=0\)。在该零参数处，
   两种平方比例对恰有一种存在，存在的一种恰有三对；非零参数处，
   十五个行对与十五个列对各自至少有一个非零平方子式。

**证明。** circulant 矩阵彼此交换且正规。块乘法给出
\[
MM^*=\operatorname{diag}(XX^*+YY^*,XX^*+YY^*).
\]
每个对角块的对角条目为 \(6\)，非对角条目为
\(\alpha(x)+\alpha(y)\) 或其共轭，故 \(M\) 为单位条目 Hadamard 矩阵。

先排除同一 channel 内的行对。比较上半块第 \(i\)、\(i+d\) 行，\(d\ne0\)。
若平方成比例，则存在 \(c\in\mathbb T\) 使
\[
x_t^2=cx_{t+d}^2,\qquad
\overline{y_{-t}}^{\,2}=c\overline{y_{-t-d}}^{\,2}.
\]
因此 \(x,y\) 都满足 \(z_{t+d}^2=c^{-1}z_t^2\)。遍乘三式得 \(c^3=1\)。
取唯一的三次单位根 \(\eta\) 满足 \(\eta^{2d}=c^{-1}\)，则
\[
x_t=u\eta^t\varepsilon_t,\qquad y_t=v\eta^t\delta_t,
\qquad \varepsilon_t,\delta_t\in\{1,-1\},\quad |u|=|v|=1.
\]
三个符号的相邻乘积之和，在符号全同时为 \(3\)，否则为 \(-1\)。于是
\[
\alpha(x),\alpha(y)\in\{3\eta,-\eta\},\qquad
\alpha(x)+\alpha(y)\in\{6\eta,2\eta,-2\eta\},
\]
不可能为零。下半块行对交换 \(x,y\) 并作共轭、反向下标后得到相同矛盾。
第一列块内的列对直接给出 \(x_{t+d}^2=cx_t^2\)、\(y_{t+d}^2=cy_t^2\)，
仍是同一个符号与三次单位根论证；第二列块内的列对经共轭、反向下标亦然。
这排除了全部十二个同 channel 的行对或列对。

再比较上半块第 \(i\) 行与下半块第 \(k\) 行，令 \(d=k-i\)。
前三列的平方比例条件为
\[
x_t^2=c y_{t+d}^2.
\]
后三列条件正是其共轭再重标下标，故等价于
\[
y_{t+d}=\gamma\varepsilon_t x_t,\qquad
\gamma^2=c^{-1},\quad\varepsilon_t\in\{1,-1\}.
\]
写 \(e_t=\overline{x_t}x_{t+1}\)，得到
\[
0=\alpha(x)+\alpha(y)
 =\sum_t(1+\varepsilon_t\varepsilon_{t+1})e_t. \tag{53.1}
\]
若符号不全同，三个相邻乘积恰有一个为 \(+1\)，另外两个为 \(-1\)，
右侧就是某个单位相位的两倍，不能为零。因此符号全同，可吸收到 \(\gamma\) 中。
这证明行对判据，并且 \(\alpha(y)=\alpha(x)\)，所以二者都为零。
反过来，\(y_{t+d}=\gamma x_t\) 直接给出相应的跨 channel 平方比例行对。

对于第一列块第 \(j\) 列与第二列块第 \(k\) 列，令 \(c_0=k-j\)。
上半块条件为
\[
x_t^2=c\overline{y_{c_0-t}}^{\,2},
\]
下半块条件仍是其共轭与重标下标。因此存在符号使
\[
y_{c_0-t}=\gamma\varepsilon_t\overline{x_t}.
\]
反向下标与共轭同时出现，故相邻比值之和满足
\[
\alpha(y)=\sum_t\varepsilon_t\varepsilon_{t+1}e_t.
\]
式 (53.1) 的符号论证再次强制符号全同，并推出 \(\alpha(x)=0\)。
无符号变化的关系也直接给出平方比例列对。前两项已证。

若 \(\alpha(x)=0\)，则 \(\alpha(y)=0\)。任一单位相位三元组的三个
相邻比值之积为一，其二次基本对称式为相邻比值之和的共轭，故它们是
\[
T^3-\alpha(z)T^2+\overline{\alpha(z)}T-1
\]
的根。在零参数处，这三个比值恰为 \(1,\omega,\omega^2\)，各出现一次。
于是 \(y\) 的比值列表是 \(x\) 的比值列表的一个置换。
偶置换是循环移位，积分相邻比值得到第一项的相位循环关系；奇置换是反向移位，
积分得到第二项的反向共轭关系。两类互斥，因为三个比值互异。
相应的位移唯一：若两个位移均成立，\(x\) 将是一个 Fourier 单模，
其三个相邻比值相同，与上述互异性矛盾。每个位移对应三个跨 channel 对，
故零参数处恰有一种类型、恰有三对。

最后应用 order-six Fourier recognition。平方比例行对经列相位归一化和
一个行相位调整变成全一行与符号行；正交性强制符号行中恰有三个 \(-1\)。
归一化首列仍保留此模式。Matszangosz–Szöllősi 的 Proposition 4、Theorem 5
及 Corollary 23 将这种归一化模式刻画为 transposed Fourier family；
转置后得到列对与 Fourier family 的对应。
反向成立，因为标准 transposed Fourier 矩阵有平方比例行对，而这一性质
在任意 monomial 等价下不变。结合前面的全部行列对分析即得第三项。证毕。

上述 recognition 使用
[Matszangosz–Szöllősi, *A characterization of complex Hadamard matrices appearing in families of MUB triplets* (2024)](https://doi.org/10.1007/s10623-024-01503-w)。
配对形式与 Szöllősi 的标准形式之间的精确关系是
\[
M(x,y)\operatorname{diag}(I,-I)
 =\begin{pmatrix}X&Y^*\\Y&-X^*\end{pmatrix}
 =\begin{pmatrix}A&B\\B^*&-A^*\end{pmatrix},\qquad A=X,\ B=Y^*.
\]
若 \(A\) 的首行为 \((a,b,c)=(x_0,x_2,x_1)\)，则其原文参数
\(a/b+b/c+c/a\) 恰为 \(\alpha(x)\)；\(B\) 的参数恰为 \(\alpha(y)\)。
因此命题覆盖所有容许复参数及其判别式为零的边界，没有实分支或根互异的
先验限制，也没有把任意四个 circulant 块自动当成这种配对形式。
[Szöllősi, *A two-parameter family of complex Hadamard matrices of order 6 induced by hypocycloids*](https://arxiv.org/html/0811.3930v2)
在 Lemma 3.1 给出零参数的 Fourier 交点，并在 Theorem 2.2 后提出仅此交点的预期。
命题 53.1 用平方行列对给出相应零参数判据；其中的 Fourier recognition 属于上述文献。

### 53.2 实际 cyclic completion 的输入边与输出边

**命题 53.2。** 取 §§51–52 的实分支 \(-1<a<1\)，
\[
H_0=\frac1{\sqrt6}\begin{pmatrix}A&B\\B^*&-A^*\end{pmatrix},
\qquad A=J+(p-1)I,\quad B=J+(q-1)I,
\]
其中 \(p,q\) 和分支方向与正文相同。设
\[
v=\frac1{\sqrt6}\binom{x}{y},\qquad x,y\in\mathbb T^3,
\]
满足 \(H_0v\) 平坦且 \(v,Sv,S^2v\) 正交归一。令
\[
K=\frac1{\sqrt6}M(x,y),\qquad C=H_0K.
\]
则 \(K\) 与 \(C\) 均不属于 Fourier union。
当 \(a\ne0\) 时，\(H_0\) 也不属于 Fourier union。
因此若这样的实际 cyclic triple 在 \(a\ne0\) 处存在，
\((I,H_0,C)\) 是三条相对 Hadamard 边均在该 union 之外的 MUB triplet。

**证明。** §51 的实际构造已经给出 \(K\) 与 \(H_0K\) 的平坦性及酉性。
写
\[
H_0v=\frac1{\sqrt6}\binom{u}{z},\qquad
u=\frac{Ax+By}{\sqrt6},\quad z=\frac{B^*x-A^*y}{\sqrt6}.
\]
于是 \(u,z\in\mathbb T^3\)。\(H_0\) 与所有同步坐标置换交换，
故输出的 cyclic triple 也正交归一，且
\[
\alpha(u)+\alpha(z)=0.
\]
对三种同步 transposition \(R_j\)，酉性、交换性及正文 §51 的严格正性给出
\[
\langle H_0v,R_jH_0v\rangle
 =\langle v,R_jv\rangle>0. \tag{53.2}
\]
这里严格正性只对原来的实际输入 \(v\) 使用；没有将 \(H_0^*\) 擅自代入
实分支定理作为新的 seed。

若单位相位三元组 \(t\) 满足 \(\alpha(t)=0\)，命题 53.1 证明中的根分析表明
它的相邻比值恰为 \(1,\omega,\omega^2\)。所以恰有两个坐标相等，
第三个坐标是共同值的 \(\omega\) 或 \(\omega^2\) 倍。
三种 transposition 的内积 \(\langle t,R_jt\rangle\) 因而恰为
\(3,0,0\) 的一个排列：交换相等坐标给出 \(3\)，另外两种给出
\(1+\omega+\omega^2=0\)。

若 \(\alpha(u)=0\)，则 \(\alpha(z)=0\)。每个 channel 的上述内积最多只在
一个 transposition 处非零，两个 channel 合起来仍留下至少一个 \(R_j\) 满足
\[
\langle H_0v,R_jH_0v\rangle
 =\frac{\langle u,R_ju\rangle+\langle z,R_jz\rangle}{6}=0,
\]
与式 (53.2) 矛盾。因此 \(\alpha(u)\ne0\)。相同论证也可用于输入；
上节还给出了更强的 \(\operatorname{Re}\alpha(x)\ne0\)。

令 \(U,Z\) 分别是以 \(u,z\) 为首列的 circulant 矩阵。
由 circulant 块交换及实际乘法，
\[
U=\frac{AX+BY}{\sqrt6},\qquad
Z=\frac{B^*X-A^*Y}{\sqrt6},
\]
\[
H_0K=\frac1{\sqrt6}\begin{pmatrix}U&Z^*\\Z&-U^*\end{pmatrix}
 =\frac1{\sqrt6}M(u,z)\operatorname{diag}(I,-I).
\]
分别对 \((x,y)\)、\((u,z)\) 应用命题 53.1，即知 \(K,C\) 均在 Fourier union
之外。实际列方向下，completion 是 \(C\)，它的两条边分别为
\(C\) 与 \(H_0^*C=K\)；因此两个结论没有互相替代。
最后 \(A\) 的首列是 \((p,1,1)\)，且
\[
\alpha(p,1,1)=1+2\operatorname{Re}p=a.
\]
同一判据在 \(a\ne0\) 时排除 \(H_0\) 的两个 Fourier 方向。证毕。

[Matolcsi–Matszangosz–Varga–Weiner, *Triplets of mutually unbiased bases* (2026)](https://doi.org/10.1007/s10801-026-01506-x)
的 §4 Conjecture 1 预测所有六维 MUB triplet 都属于具有 Fourier 边的已知构造。
命题 53.2 表明，本节实际 cyclic triple 若在 \(a\ne0\) 处存在，将落在该预测之外。
这保留了一个精确的存在性问题：本节没有构造这样的 triple，也没有用该猜想
代替非存在性证明；对一般不同轨道的 common-flat 向量及第四个基仍未给出排除。

## 54. 中心实种子附近实际循环正交三元组的精确排除

### 54.1 参数、原始基与输出坐标置换

沿用第 46 节的实分支。令 \(C\) 为第一行 \((0,1,0)\) 的三循环矩阵，\(J\) 为三阶全一矩阵，\(\mathcal S=\operatorname{diag}(C,C)\)。对 \(-1<a<1\)，取正平方根并定义
\[
p(a)=\frac{a-1}{2}+i\sqrt{1-\frac{(a-1)^2}{4}},\qquad
q(a)=\frac{-a-1}{2}+i\sqrt{1-\frac{(a+1)^2}{4}},
\]
\[
A_a^{\rm src}=J+(p(a)-1)C,\qquad B_a^{\rm src}=J+(q(a)-1)C,\qquad
G_a=\frac1{\sqrt6}\begin{pmatrix}A_a^{\rm src}&B_a^{\rm src}\\
(B_a^{\rm src})^*&-(A_a^{\rm src})^*\end{pmatrix}.
\tag{54.1}
\]
这正是第 46 节显示的归一化种子。该 block construction 来自 Szöllősi 的 [*A two-parameter family of complex Hadamard matrices of order 6 induced by hypocycloids*，§2](https://arxiv.org/abs/0811.3930)。以下使用同一个、与参数无关的输出行置换
\[
L=\operatorname{diag}(C^2,C),\qquad H_a=LG_a
=\frac1{\sqrt6}\begin{pmatrix}A_a&B_a\\\overline{B_a}&-\overline{A_a}\end{pmatrix},
\quad A_a=J+(p(a)-1)I_3,\quad B_a=J+(q(a)-1)I_3.
\tag{54.2}
\]
恒等式由 \(C^3=I_3\)、\(CJ=JC=J\) 逐块得到。\(L\) 保持平坦性且与 \(\mathcal S\) 交换；此处没有变换输入相位。由于 \(\Re(p+q)=-1\)，有 \(A_aA_a^*+B_aB_a^*=6I_3\)；两个对称 circulant 块交换且正规，故 \(H_a\) 与 \(G_a\) 都酉。平坦向量指六个坐标模均为 \(1/\sqrt6\) 的归一化向量。

**命题 54.1。** 若 \(|a|\le2^{-423}\)，则不存在向量 \(\xi\)，使 \(\xi,H_a\xi\) 都平坦，且 \(\xi,\mathcal S\xi,\mathcal S^2\xi\) 正交归一。等价地，原始基对 \((I,G_a)\) 的实际共同无偏向量中不存在一个同步循环正交三元组。特别地，中心纤维 \(a=0\) 被完全排除于这一循环轨道类型。

**证明。** 先把中心问题化为同一组相位上的多项式等式，再给出完整有限除法证书及其误差界。最后用同一输出行置换将结论传回原始基。

### 54.2 保留全部相位的中心方程

令 \(\omega=(-1+i\sqrt3)/2\)，则 \(p(0)=q(0)=\omega\)。除去一个公共相位后，写
\[
\sqrt6\xi=(x,y),\qquad x=(1,u,v),\qquad y=(g,j,k),\qquad
|u|=|v|=|g|=|j|=|k|=1.
\]
设 \(M=uvgjk\)，在 \(E=\mathbb Q[\omega]/(\omega^2+\omega+1)\) 上取 Laurent 对合 \(\iota\)，它把 \(\omega\) 送至 \(\omega^2\)，并把五个变量各自送至倒数。于实际单位相位上，\(\iota\) 恰为复共轭。定义
\[
\Phi=u+v/u+1/v+j/g+k/j+g/k,\qquad X=1+u+v,\quad Y=g+j+k,
\]
\[
U_\ell=X+Y+(\omega-1)(x_\ell+y_\ell),\qquad
V_\ell=X-Y+(\omega^2-1)(x_\ell-y_\ell),\quad 0\le\ell\le2.
\tag{54.3}
\]
于是 \(6\langle\xi,\mathcal S\xi\rangle=\Phi\)。因 \(\mathcal S^3=I\)，循环三元组正交归一等价于 \(\Phi=0\)。又有 \(H_0\xi=(U,V)/6\)，所以输出平坦性恰给出全部六式 \(U_\ell\iota(U_\ell)=V_\ell\iota(V_\ell)=6\)。令
\[
f_0=M\Phi,\quad f_1=M\iota(\Phi),\quad
f_{2+2\ell}=M\bigl(U_\ell\iota(U_\ell)-6\bigr),\quad
f_{3+2\ell}=M\bigl(V_\ell\iota(V_\ell)-6\bigr).
\tag{54.4}
\]
乘以 \(M\) 清除所有变量分母，故这些是普通多项式。加入变量 \(t\) 及 \(f_8=tM-1\)；实际输入可取 \(t=M^{-1}\)，其模也为一。以下九个输入多项式均属于 \(E[t,k,j,g,v,u]\)：
\[
(g_0,g_1,\ldots,g_8)=(f_0,f_1,2f_2,2f_3,2f_4,2f_5,2f_6,2f_7,f_8).
\tag{54.5}
\]
所以任何实际中心循环三元组都会给出这九式的公共零点。

### 54.3 有限除法证书的数学定义

变量次序固定为 \((t,k,j,g,v,u)\)。指数 \(e=(e_0,\ldots,e_5)\) 的单项式按
\[
\bigl(\textstyle\sum e_r,-e_5,-e_4,\ldots,-e_0\bigr)
\]
的字典序排列，最大者为首项；这就是该变量次序的 graded reverse lexicographic order。对多项式 \(D\) 和有序除式表 \((P_{d_1},\ldots,P_{d_s})\)，定义余式如下：每次取当前被除式的首项，若有首单项式整除它的除式，则取表中第一个这样的除式，减去消掉该首项的唯一单项式倍数；若没有，就把此首项移到余式并从被除式删去。重复至被除式为零。每步严格降低首单项式，因而终止。

下表定义 \(P_0,\ldots,P_{176}\)。前八行直接给出输入多项式；其余每行的 \(D_i\) 是已有 \(P_r\) 的显示线性组合，\(\mathcal D_i\) 是有序除式指标表。设上述除法的余式为 \(R_i\)，则定义
\[
P_i=R_i/\operatorname{lc}(R_i).
\tag{54.6}
\]
所有非输入行的余式都非零。用 \(c_{i,h}m_{i,h}P_{d_{i,h}}\) 表示该行各次实际消项，其中 \(m_{i,h}\) 是首一单项式，则除法恒等式为
\[
\operatorname{lc}(R_i)P_i
=D_i-\sum_h c_{i,h}m_{i,h}P_{d_{i,h}}.
\tag{54.7}
\]
因此输入的公共零点归纳地消掉每一个 \(P_i\)。证书只使用这个有限恒等式链，不需要先断言任何多项式表是 Gröbner 基。

### 54.4 同一恒等式链的单位相位剩余量界

现在只假设实际单位相位、\(\Phi=0\)、\(tM=1\)，不预设中心输出平坦。设
\[
\mathcal R=\max_{0\le\ell\le2}
\left\{\bigl||U_\ell|^2-6\bigr|,\ \bigl||V_\ell|^2-6\bigr|\right\}.
\tag{54.10}
\]
输入 \(g_0,g_1,g_8\) 为零，其余六个输入的模都不超过 \(2\mathcal R\)。对系数 \(c=r+s\omega\) 令 \(\beta(c)=|r|+|s|\)，于是 \(|c|\le\beta(c)\)。每个变量（包括 \(t\)）的模都为一，因此首一单项式的模为一。

为明确表中所有指数的含义，定义 \(\ell(b)=\min\{n\in\mathbb Z:b\le2^n\}\)（\(b>0\)）。对输入行，\(g_0,g_1,g_8\) 的指数为 \(\bot\)，其余输入的指数为一。对一个非输入行，把 \(D_i\) 中每项 \(\epsilon mP_r\)（这里 \(\epsilon=\pm1\) 且 \(m\) 首一）和 (54.7) 中每次消项分别列为一个贡献；舍去指数为 \(\bot\) 的贡献。源项贡献的指数是 \(e_r\)，消项贡献的指数是
\[
e_{d_{i,h}}+\ell\bigl(\beta(c_{i,h})\bigr).
\]
若无贡献则 \(e_i=\bot\)；否则，设贡献个数为 \(N_i\)，最大贡献指数为 \(b_i\)，定义
\[
e_i=b_i+\ell(N_i)
+\ell\!\left(\beta\!\left(\operatorname{lc}(R_i)^{-1}\right)\right).
\tag{54.11}
\]
这完全确定了表中最后一栏，所有 \(\ell\) 只需比较有理数与整数次幂。三角不等式、(54.7) 与 \(P_i\) 的首一化逐行给出
\[
|P_i|\le2^{e_i}\mathcal R\quad(e_i\ne\bot),
\qquad P_i=0\quad(e_i=\bot).
\]
最后由 (54.8) 得到精确而保守的剩余量界
\[
1\le2^{419}\mathcal R.
\tag{54.12}
\]
该推导没有把不同相位向量的约束混合，也没有把总正交性加强成逐模正交性。

### 54.5 实参数闭区间与实际列基方向

固定同一单位相位输入。在 \(|a|\le1/2\) 上，\(\Im p(a),\Im q(a)\ge\sqrt7/4\)，直接求导得
\[
|p'(a)|=\frac1{2\Im p(a)}\le\frac2{\sqrt7}<1,
\qquad |q'(a)|=\frac1{2\Im q(a)}\le\frac2{\sqrt7}<1.
\]
因而 \(|p(a)-\omega|,|q(a)-\omega|\le|a|\)。由 (54.2)，六个原始输出坐标，即 \(\sqrt6H_a(x,y)^T\) 的坐标，与其中心值之差的模各不超过 \(2|a|\)。如果 \(H_a\xi\) 平坦，这些原始坐标的模均为 \(\sqrt6\)，故
\[
\mathcal R\le2|a|(2\sqrt6+2|a|)\le12|a|.
\tag{54.13}
\]
若 \(|a|\le2^{-423}\)，则 (54.12)–(54.13) 给出
\[
1\le2^{419}\cdot12\cdot2^{-423}=\frac34,
\]
矛盾。这证明闭区间结论，包括两个端点。

最后，若 \(f\) 是原始列基对 \((I,G_a)\) 的实际共同无偏向量，置 \(\xi=G_a^*f\)。则 \(\xi\) 与 \(G_a\xi=f\) 平坦，且由整个实分支上的同一恒等式 \(H_a=LG_a\)，\(H_a\xi=Lf\) 平坦。\(G_a\) 与 \(\mathcal S\) 交换并且酉，所以
\[
f,\mathcal Sf,\mathcal S^2f\text{ 正交归一}
\quad\Longleftrightarrow\quad
\xi,\mathcal S\xi,\mathcal S^2\xi\text{ 正交归一}.
\]
故以上排除确实适用于原始基的实际同步循环三元组。证毕。

Brierley–Weigert 的 [*Constructing Mutually Unbiased Bases in Dimension Six*，§2、§4.2](https://arxiv.org/html/0901.4051v2) 将中心种子关联到 Fourier-family 交点，并报告该点的共同无偏射线数量；这一数量本身不规定此处的同步循环作用。本命题依靠 (54.1)–(54.13) 的具体相位方程和除法恒等式，不以 Fourier-edge 猜想或一般 no-fourth-basis 结论为前提。结论只排除上述闭区间中的单一同步循环轨道型正交三元组，不排除由不同轨道取出的任意三元组，也不解决六维第四个无偏基问题。

## 55. 实际循环三元组的紧化证书与较大中心区间

### 55.1 结论与实际种子方向

沿用式 (54.1)–(54.2) 的原始基 \(G_a\)、固定输出行置换及同步循环 \(\mathcal S\)。以下 \(H_a\) 始终指同一个行置换后的实际矩阵，而不是另选的相位模型。令
\[
\varepsilon=2^{-14},\qquad
 a_* =\varepsilon\sqrt{\frac{3-\varepsilon^2}{1+\varepsilon^2}}.
\]

**命题 55.1。** 若 \(|a|\le a_*\)，则不存在归一化向量 \(v\)，使 \(v,H_av\) 都平坦，且 \(v,\mathcal Sv,\mathcal S^2v\) 正交归一。因此原始基对 \((I,G_a)\) 的实际共同无偏向量中也不存在这样的同步循环三元组。特别地，这把命题 54.1 的保守闭区间扩大为
\[
\boxed{|a|\le2^{-14}.}
\tag{55.1}
\]

本命题仍只排除单一同步循环轨道型，不排除从不同轨道选出的任意正交三元组，也不解决一般六维第四个无偏基问题。证明由实际矩阵的必要方程及下列完整有限 Bernstein 证书组成；不使用 Fourier-edge 猜想。

取第 52.1 节的正虚部实分支参数，写 \(b=a/h\)。其精确等价形式是
\[
(1+h^2)(1+b^2)=4,\quad h>1,\quad |b|<1,\quad a=hb,
\]
\[
p=\frac{hb-1+i(h+b)}2,\quad q=\frac{-hb-1+i(h-b)}2,
\quad P=p-1,\quad Q=q-1.
\tag{55.2}
\]
于是 \(|p|=|q|=1\)、\(|P|^2+|Q|^2=6\)。这里及以下 \(s,t\) 是新引入的重心实坐标，不再用 \(s\) 表示 \(h^2\)。由式 (54.2)，
\[
\sqrt6H_a=
\begin{pmatrix}J+PI_3&J+QI_3\\J+\bar QI_3&-J-\bar PI_3\end{pmatrix}.
\tag{55.3}
\]
只需证明在 \(|b|\le\varepsilon\) 上不存在这样的实际三元组；最后再转换参数。

### 55.2 非退化性与保留全部相位的插值

反设存在实际三元组，写 \(\sqrt6v=(x,y)\)，其中 \(x_j,y_j\in\mathbb T\)，并记
\[
\alpha_x=\sum_{j=0}^2\bar x_jx_{j+1},\quad
\alpha_y=\sum_{j=0}^2\bar y_jy_{j+1},\quad
X=\sum_jx_j,\quad Y=\sum_jy_j.
\]
下标按三取模。循环正交给出 \(\alpha_x+\alpha_y=0\)，并且对未归一化的三点 Fourier 变换有
\[
|\widehat x_k|^2+|\widehat y_k|^2=6\quad(k=0,1,2),
\qquad |X|^2+|Y|^2=6.
\tag{55.4}
\]
任一单位三元组的一个 Fourier 坐标若为零，乘相应单位模字符后其三个单位数之和为零，故它们是正三角形的三个顶点。按任意顺序排列仍是另一个 Fourier 单模，其某个 Fourier 坐标的平方模为九。这与式 (55.4) 矛盾。因此 \(X,Y\ne0\)。

两个 channel 的坐标也各自互异。事实上 \(\operatorname{Im}\alpha_x\) 是坐标三角形有向面积的两倍；三个互异单位圆点不共线，所以它为零当且仅当有重复坐标。若一个 channel 重复，则 \(\alpha_y=-\alpha_x\) 使另一个也重复。若重复位置相同，实际向量被一个同步换位固定，与前卷命题 51.1 矛盾。若位置不同，可把给定坐标描述为
\[
x=\rho(r_0,1,1),\qquad y=\sigma(1,t_0,1),
\qquad |\rho|=|\sigma|=|r_0|=|t_0|=1.
\]
这里仅分解给定坐标，没有把两 channel 的相位当作独立 gauge。循环条件给出 \(\operatorname{Re}(r_0+t_0)=-1\)，故
\[
\langle v,R_{01}v\rangle
=\frac{1+\operatorname{Re}(r_0+t_0)}3=0,
\]
与前卷命题 51.2 的严格换位正性矛盾。常数 channel 可选择固定另一 channel 重复位置的换位，已包含在前一种情形。因此
\[
\operatorname{Im}\alpha_x\ne0,
\qquad x_0,x_1,x_2\text{ 及 }y_0,y_1,y_2\text{ 分别互异}.
\tag{55.5}
\]

只乘整个六维向量的一个公共相位，使 \(X>0\)。令 \(\chi=x_0x_1x_2\)，则 \(|\chi|=1\)，且 \(x_j\) 恰为
\[
f(Z)=Z^3-XZ^2+\chi XZ-\chi
\tag{55.6}
\]
的三个互异根。于这些根上，
\[
Z^2=XZ-\chi X+\chi Z^{-1},\qquad
Z^{-2}=XZ^{-1}-\bar\chi X+\bar\chi Z.
\tag{55.7}
\]
函数 \(1,Z,Z^{-1}\) 在三个根上线性无关：将一个线性关系乘以 \(Z\)，所得二次多项式不能有三个互异根。因此存在唯一的同一组复系数 \(A_0,B,C\)，使
\[
y_j=XA_0+Bx_j+C\bar x_j,\qquad
\zeta=Y/X=3A_0+B+C=s+it,
\quad r=|\zeta|^2,\quad n=1+r,
\quad X^2n=6.
\tag{55.8}
\]
这没有删除任何相对相位。

下面记录三点模条件的完整恒等式。对任意复数 \(E,F,G\) 和实数 \(R\)，定义
\[
\begin{aligned}
\mathcal T_0(E,F,G;R)
 &=|E|^2+|F|^2+|G|^2-R-X(\chi F\bar G+\bar\chi\bar F G),\\
\mathcal T_1(E,F,G)
 &=\bar EF+E\bar G+XF\bar G+\bar\chi\bar F G.
\end{aligned}
\]
式 (55.7) 逐项给出
\[
|E+FZ+G\bar Z|^2-R
=\mathcal T_0+\mathcal T_1Z+\overline{\mathcal T_1}\bar Z.
\tag{55.9}
\]
故三个模方都为 \(R\)，当且仅当一个实系数 \(\mathcal T_0\) 和一个复系数 \(\mathcal T_1\) 同时为零。

对式 (55.8) 展开循环相关，除 \(|B|^2\alpha_x+|C|^2\bar\alpha_x\) 外的项均为实数。由式 (55.5) 及 \(\alpha_y=-\alpha_x\)，得到
\[
|C|^2-|B|^2=1.
\tag{55.10}
\]
另外 \(r>0\)。命题 52.1 已在同一实际基方向上排除 \(|X|^2=|Y|^2=3\)，所以 \(r\ne1\)。

### 55.3 两个实际输出共同给出的实参数

由式 (55.3)，两个实际未归一化输出为
\[
U_j=X+Y+Px_j+Qy_j,\qquad
V_j=X-Y+\bar Qx_j-\bar Py_j.
\tag{55.11}
\]
归一化输出是 \((U,V)/6\)，故实际平坦性要求全部六个模方等于六。定义
\[
\begin{aligned}
l&=(1+\bar\zeta)P+(1-\bar\zeta)\bar Q
  =-3+ib+h(b+i)\bar\zeta,\\
m&=(1+\bar\zeta)Q-(1-\bar\zeta)\bar P
  =h(i-b)-(3+ib)\bar\zeta,\\
\lambda&=|l|^2,\qquad \mu=|m|^2,\qquad
\Sigma=\lambda+\mu=12n>0.
\end{aligned}
\tag{55.12}
\]
对同一个实际输入直接展开两输出模方之和，得到
\[
|U_j|^2+|V_j|^2-12
=2X\operatorname{Re}(lx_j+my_j)+2X^2n.
\tag{55.13}
\]
所以 \(\operatorname{Re}(lx_j+my_j)=-Xn\)。若 \(m=0\)，因右侧非零，\(l\ne0\)，于是三个互异单位圆点 \(x_j\) 落在一条实仿射直线上，不可能。\(l=0\) 时对 \(y_j\) 同理。因此
\[
\lambda\mu>0.
\]
将式 (55.8) 代入式 (55.13)，三点线性无关性给出
\[
l+mB+\bar m\bar C=0.
\tag{55.14}
\]
结合式 (55.10)，有
\[
2\operatorname{Re}(\bar l mB)=\mu-\lambda.
\]
于是存在唯一实数 \(\tau\)，使
\[
B=\frac{\mu-\lambda+i\tau}{2\bar l m},\qquad
C=-\frac{\Sigma-i\tau}{2lm},\qquad
A_0=\frac{\zeta-B-C}{3}.
\tag{55.15}
\]
所有这里出现的变量分母均已证明非零，没有另选符号或独立相位。

也有 \(B\ne0\)：若 \(B=0\)，式 (55.10) 给出 \(|C|=1\)；\(|XA_0+C\bar x_j|=1\) 若 \(A_0\ne0\)，再次把三个互异单位圆点放在一条实仿射直线上。因此 \(A_0=0\)，进而 \(Y=CX\)、\(r=1\)，矛盾。故 \(B,C,l,m,X\) 全非零，且 \(n>0\)。

### 55.4 从同一组实际相位导出四个必要剩余式

令
\[
\eta=\bar\chi/X,\quad

\[

   +QB(1+\bar\zeta)+\bar Q\bar C(1+\zeta+P).

对输入 \((E,F,G)=(XA_0,B,C)\) 应用式 (55.9)，将复系数除以 \(X\)、实系数乘以 \(n\)，分别得到
\[
\mathcal I_1=T+\eta\bar BC=0,\qquad
\mathcal I=6|A_0|^2+2n|B|^2
             -12\operatorname{Re}(\bar\eta B\bar C)=0.
\tag{55.16}
\]
对同一个实际上输出，令
\[
e=1+\zeta+QA_0,\quad f=P+QB,\quad g=QC.
\]
其仿射系数是 \((Xe,f,g)\)。式 (55.9) 同样给出
\[
\begin{aligned}
\mathcal O_1&=\bar ef+e\bar g+f\bar g+\eta\bar f g=0,\\
\mathcal O_0&=6|e|^2+n(|f|^2+|g|^2-6)
              -12\operatorname{Re}(\bar\eta f\bar g)=0.
\end{aligned}
\tag{55.17}
\]
定义
\[
\begin{aligned}
I&=6|A_0|^2+2n|B|^2+12\operatorname{Re}T,\\
J_1&=\bar BK-dT,\\
L_1&=3|1+\zeta|^2+6\operatorname{Re}((1+\bar\zeta)QA_0)
      +n\operatorname{Re}(dB)+6\operatorname{Re}K,\\
H_1&=\operatorname{Re}(\bar mJ_1),\qquad
G_1=\operatorname{Im}(\bar mJ_1).
\end{aligned}
\tag{55.18}
\]
这里下标一是名称的一部分，不表示 \(\tau\) 的一次项系数。逐项展开有
\[
I-\mathcal I=12\operatorname{Re}\mathcal I_1,
\qquad \mathcal O_1-|Q|^2\mathcal I_1=K+d\eta C,
\]
\[
J_1=\bar B(\mathcal O_1-|Q|^2\mathcal I_1)-d\mathcal I_1,
\]
\[
\begin{aligned}
\mathcal O_0-|Q|^2\mathcal I-2L_1
 +12\operatorname{Re}(\mathcal O_1-|Q|^2\mathcal I_1)
 ={}&n(|P|^2+|Q|^2-6)\\
 &+n|Q|^2(|C|^2-|B|^2-1)=0.
\end{aligned}
\tag{55.19}
\]
因此每个实际三元组必满足
\[
I=H_1=G_1=L_1=0.
\tag{55.20}
\]
这些恒等式没有给输入、两个输出或不同剩余式分配不相干的相位。

实际点还满足 \(6|\eta|^2=n\)，且单位根判别式给出
\(4+12n-3n^2-32\operatorname{Re}\eta<0\)：事实上式 (55.6) 的判别式为
\(\chi^2[X^4+18X^2-27-8X^3\operatorname{Re}\chi]\)，方括号是三个单位根 Vandermonde 模方的负值；代入式 (55.8) 后正比例因子为 \(9/n^2\)。下面仅排除必要方程 (55.20) 的较大零集，不需要这些额外范数或严格判别式限制。

### 55.5 实际 channel 交换与紧重心区域

令 \(T_{\rm sw}\) 交换两个三坐标输入 channel，\(D_{\rm sg}=\operatorname{diag}(I_3,-I_3)\)。由于在式 (55.2) 中 \(b\mapsto-b\) 正好交换 \(P,Q\)，有实际矩阵恒等式
\[
D_{\rm sg}H_{hb}T_{\rm sw}=H_{-hb}.
\tag{55.21}
\]
两操作均保持平坦性并与 \(\mathcal S\) 交换，故保持实际循环正交及输出方程。若 \(r>1\)，交换后只乘一个公共相位 \(\bar\zeta/\sqrt r\)，得到
\[
X'=X\sqrt r>0,\quad \zeta'=1/\zeta,\quad
h'=h,\quad b'=-b,\quad r'=1/r.
\]
相应系数的精确关系是
\[
\begin{gathered}
l'=m/\bar\zeta,\quad m'=l/\bar\zeta,\quad
\lambda'=\mu/r,\quad\mu'=\lambda/r,\quad\Sigma'=\Sigma/r,\quad
\tau'=\tau/r,\\
B'=-\bar B,\quad C'=(\bar\zeta/\zeta)C,\quad
A_0'=(\bar BA_0-C\bar A_0)/\zeta.
\end{gathered}
\tag{55.22}
\]
它们由式 (55.10)、(55.15) 直接验证；特别是有限 \(\tau\) 仍有限，所有原来的非零分母仍非零。因 \(|b|\le\varepsilon\) 对符号对称，任何假想解都可选代表满足
\[
0<r<1,\qquad |s|\le1,\quad |t|\le1.
\tag{55.23}
\]
这里不是任意交换 Fourier modes，也没有使用独立 channel 相位的自由度。

### 55.6 四个实多项式的完整系数定义

以下共轭是在实变量 \(h,b,s,t,\tau\) 上逐系数作复共轭。用式 (55.12) 的 \(l,m,\lambda,\mu\)，置
\[
\begin{aligned}
D&=2\lambda m,\qquad
B_N=l(\mu-\lambda+i\tau),\qquad
C_N=-\bar l(\lambda+\mu-i\tau),\\
A_N&=(s+it)D-B_N-C_N,\\
T_N&=\bar A_NB_N+A_N\bar C_N+3B_N\bar C_N,\\
K_N&=P\{3(1+\bar\zeta)D\bar D+\bar Q\bar A_ND\}
     +3QB_N(1+\bar\zeta)\bar D
     +3\bar Q\bar C_N(1+\zeta+P)D,\\
J_N&=\bar B_NK_N-dT_N\bar D.
\end{aligned}
\tag{55.24}
\]
定义四个实多项式
\[
\begin{aligned}
P_I&=A_N\bar A_N+3nB_N\bar B_N+3(T_N+\bar T_N),\\
P_H&=(J_N+\bar J_N)/\lambda^2,\qquad
P_G=(J_N-\bar J_N)/(2i\lambda),\\
P_L&=\lambda^{-1}\{6(1+\zeta)(1+\bar\zeta)D\bar D
 +2[(1+\bar\zeta)QA_N\bar D+(1+\zeta)\bar Q\bar A_ND]\\
 &\hspace{32mm}+n[dB_N\bar D+\bar d\bar B_ND]+2(K_N+\bar K_N)\}.
\end{aligned}
\tag{55.25}
\]
在这些多项式定义中保留 \(\lambda+\mu\)，不先用种子关系把它替换为 \(12n\)。式 (55.25) 的除法在 \(\mathbb Q(i)[h,b,s,t,\tau]\) 中都是精确多项式整除；验证时不需要先施加种子关系。式 (55.24) 还给出
\[
A_0=A_N/(3D),\ B=B_N/D,\ C=C_N/D,\quad
T=T_N/(3D\bar D),\ K=K_N/(3D\bar D),\
J_1=J_N/(3D\bar D^2).
\]
因此直接清分母得到
\[
\boxed{P_I=6\lambda^2\mu I,\quad
P_H=48\lambda\mu H_1,\quad
P_G=24\lambda^2\mu G_1,\quad
P_L=8\lambda\mu L_1.}
\tag{55.26}
\]
特别注意 \(P_G\) 的乘子含 \(\lambda^2\)。这完整指定了证书的有理系数，无须另给展开系数表。四式的 \(\tau\) 次数分别至多为 \((2,1,2,1)\)；\(P_H,P_L\) 的二次项在使用种子关系之前即相消。每个实际解必为这四个多项式的公共零点。

### 55.7 两个保留端点的实图

写 \(P_R=\sum_{j=0}^{d_R}P_{R,j}\tau^j\)，其中
\[
(d_I,d_H,d_G,d_L)=(2,1,2,1),\qquad
\sigma=12(1+s^2+t^2)>0.
\]
对 \(R\in\{I,H,G,L\}\) 定义
\[
F_R(h,b,s,t,v)=\sum_jP_{R,j}\sigma^jv^j,\qquad
Q_R(h,b,s,t,v)=\sum_jP_{R,j}\sigma^jv^{d_R-j}.
\tag{55.27}
\]
若 \(|\tau|\le\sigma\)，用有限图 \(v=\tau/\sigma\)；否则用倒数图 \(v=\sigma/\tau\)。两图都满足 \(|v|\le1\)，且所用的四个多项式同时为零。对实际有限 \(\tau\)，倒数图中的 \(v\ne0\)，但证书连同 \(v=0\) 一起覆盖。

全部运算在整个闭立方体 \([-1,1]^3\) 的坐标 \((s,t,v)\) 上进行，没有删除 \(r=0,1\)、\(m=0\)、任何其他分母零点或判别式边界。两图重叠及端点恒等式为
\[
Q_R(1)=F_R(1),\quad Q_R(-1)=(-1)^{d_R}F_R(-1),
\quad F_R(0)=P_{R,0},\quad Q_R(0)=\sigma^{d_R}P_{R,d_R}.
\tag{55.28}
\]
故 \(P_H,P_L\) 在倒数图的零点保留其真正的一次最高项，未被多乘一个零因子。没有除以任何 \(\tau\) 系数；线性式恒为零的所有例外分支均被保留。

### 55.8 闭种子区间上的统一误差

由式 (55.2)，对 \(|b|\le\varepsilon\) 有
\[
1<h\le\sqrt3<2,\qquad
|h-\sqrt3|=\frac{4b^2}{(1+b^2)(h+\sqrt3)}\le2\varepsilon^2.
\tag{55.29}
\]
将任一式 (55.27) 展开为
\(\sum c_{a,k,i,j,m}h^ab^ks^it^jv^m\)，定义
\[
A_R=\sum_{k\ge1}|c_{a,k,i,j,m}|2^a,
\qquad B_R=\sum_{k=0}|c_{a,k,i,j,m}|a2^a,
\qquad E_R=A_R\varepsilon+B_R\varepsilon^2.
\]
这里 \(a\) 只在求和式中表示 \(h\) 的非负整数指数。若 \(k\ge1\)，有 \(|b|^k\le\varepsilon\)；若 \(k=0\)，由均值估计
\(|h^a-(\sqrt3)^a|\le a2^a\varepsilon^2\)。所以在闭立方体上，两个图各自满足
\[
|F_R(h,b,s,t,v)-F_R(\sqrt3,0,s,t,v)|\le E_R,
\quad
|Q_R(h,b,s,t,v)-Q_R(\sqrt3,0,s,t,v)|\le E_R.
\tag{55.30}
\]
从式 (55.24)–(55.27) 收集系数，两个图给出同一组整数：

| R | A_R | B_R | 中心 Bernstein 多重次数 N_R |
| --- | ---: | ---: | --- |

### 55.9 Bernstein 转换与有限分割规则

对中心多项式 \(F_R(\sqrt3,0,s,t,v)\) 或 \(Q_R(\sqrt3,0,s,t,v)\)，把 \([-1,1]\) 变量写成 \(2u-1\)。记 \(\beta_{i,N}(u)=\binom Ni u^i(1-u)^{N-i}\)；三维基取三个这样的基函数之积。在一维次数 \(N\) 下，从幂 \(x^j\) 到 \([0,1]\) 上 Bernstein 系数的精确转换矩阵是
\[
M_{ij}^{(N)}=\sum_{k=0}^{\min(i,j)}
 (-1)^{j-k}2^k\binom jk\frac{\binom ik}{\binom Nk},
\qquad 0\le i,j\le N.
\tag{55.31}
\]
分别作用于 \(s,t,v\) 三个系数指标，就得到多重次数 \(N_R\) 的张量 Bernstein 系数。所有系数唯一写成 \(A+B\sqrt3\)，其中 \(A,B\in\mathbb Q\)。固定
\[
\rho_- =\frac{173205080756887729352}{10^{20}},\qquad
\rho_+ =\frac{173205080756887729353}{10^{20}},\qquad
\rho_-^2<3<\rho_+^2.
\tag{55.32}
\]
若 \(B\ge0\)，系数下、上界取 \(A+B\rho_-,A+B\rho_+\)；若 \(B<0\)，交换两个端点。得到初始的有理系数下界阵列 \(\ell\) 与上界阵列 \(u\)。

二进制字 \(w\) 表示从整个闭立方体出发的一个子盒。第零次分割取 \(s\)，第一次取 \(t\)，第二次取 \(v\)，以后每三次重复；字母零表示左半盒，一表示右半盒，每次都在精确中点分割。对分割方向上的任一 Bernstein 系数线 \((c_0,\ldots,c_N)\)，定义
\[
c_j^{(0)}=c_j,\qquad
c_j^{(k+1)}=(c_j^{(k)}+c_{j+1}^{(k)})/2.
\]
左右半盒的系数分别为
\[
c^{\rm left}_k=c_0^{(k)},\qquad
c^{\rm right}_k=c_k^{(N-k)},\qquad 0\le k\le N.
\tag{55.33}
\]
对下界阵列和上界阵列分别施行同一个正权递推，并沿 \(w\) 取相应子盒，得到 \(\ell_{R,w},u_{R,w}\)。这里先按式 (55.32) 取界，再作全部分割；不在中途另换取界方式。

Bernstein 基在闭盒上非负且和为一。因此若叶子标记为 \(+R\)，定义
\[
g_w=\min\ell_{R,w}-E_R;
\]
若标记为 \(-R\)，定义
\[
g_w=-\max u_{R,w}-E_R.
\tag{55.34}
\]
只要 \(g_w>0\)，在该闭盒及整个种子闭区间上，相应式 (55.27) 就有标记规定的严格符号，不能为零。

### 55.11 矛盾、参数转换与原始列基

一个假想实际三元组经式 (55.21)–(55.23) 后，有 \((s,t)\in[-1,1]^2\) 和有限实数 \(\tau\)，且四式 (55.25) 同时为零。式 (55.27) 把它送入有限图或倒数图的闭立方体，仍使对应四式同时为零。完整叶覆盖却在该点所在闭盒上给出至少一个严格非零的式子，矛盾。因此在 \(|b|\le\varepsilon\) 上没有实际同步循环正交三元组。

全部线性式的零系数分支均包含在此矛盾中；特别是对任何写成 \(c_1\tau+c_0\) 的剩余式，没有删除 \(c_1=c_0=0\) 的分支。所有图端点和分母零点的多项式极限也都在闭盒证书内。此结论只使用实际解满足必要方程这一方向，不把较大四式零集中的点自动视为实际解。

在原来的整个实种子上令 \(u=b^2\)，则
\[
a^2=\frac{u(3-u)}{1+u},\qquad
\frac{d(a^2)}{du}=\frac{(1-u)(3+u)}{(1+u)^2}>0
\quad(0\le u<1).
\tag{55.36}
\]
故 \(|b|\le\varepsilon\) 精确等价于 \(|a|\le a_*\)，包含两个端点。又因 \(h>1\)，\(|a|\le\varepsilon\) 蕴含 \(|b|\le\varepsilon\)，给出式 (55.1) 的简洁保守区间。

最后说明实际列基方向。若 \(f\) 是原始基对 \((I,G_a)\) 的共同无偏向量，则 \(\xi=G_a^*f\) 与 \(G_a\xi=f\) 都平坦，而式 (54.2) 使 \(H_a\xi=Lf\) 平坦。\(G_a\) 酉且与 \(\mathcal S\) 交换，所以 \(f,\mathcal Sf,\mathcal S^2f\) 正交归一当且仅当 \(\xi,\mathcal S\xi,\mathcal S^2\xi\) 正交归一。刚证明的排除因而适用于原始列基对。这完成命题 55.1 的证明。结论仍限于所述闭区间和单一同步循环轨道类型。
