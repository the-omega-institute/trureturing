## 4. The exact local supplement requirement

For an old-target observation alone, augmented by $z$,

$$
\bigl(v(D_a),z(x)\bigr)=\bigl(v(D_a),z(y)\bigr)
\Longrightarrow Q(x)=Q(y)
$$

holds for all $x,y$ in the family if and only if $z$ is injective on all $N2^r$ members. This condition also gives equality of the two restricted kernels.

If the received cover number is already retained, $(v(D_a),c,z)$ is sufficient if and only if, for every fixed $j$, the map $w\mapsto z(x_{j,w})$ is injective. The same fixed-$j$ condition is necessary and sufficient for $(P_A^+,z)$ on this family.

$$
r+\lceil\log_2 N\rceil
$$

logical bits. If $c$ or $P_A^+$ is already retained, exactly $r$ further logical bits are necessary and sufficient. These are statements about finite realized observations on $\mathcal X_{P,N,r}$, not physical storage minima or initialized acquisition procedures.
