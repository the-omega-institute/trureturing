# Explicit finite quotient for the Coxeter-sector (8,9) packet

This note makes the finite-index step in the degree-(8,9) Coxeter-sector construction effective. It gives one explicit quotient with exactly

N = 3,995,136

target tetrahedra. It is an existence upper bound for this construction; it does not prove that N=24 is impossible or that the displayed quotient is minimal.

## The quotient theorem

Let Q be the doubly truncated [4,9,3] sector from CFMP_CYCLE_DEGREE9.md. Write

    W = <a,b,c,d | a²=b²=c²=d²=1,
          (ab)^4=(bc)^9=(cd)^3=1,
          [a,c]=[a,d]=[b,d]=1>,

and let W+ be its determinant/orientation-preserving index-two subgroup. The sector-symmetry subgroup is K=<c,d> ~= S3, of order six.

Over F17 specialize

    2 cos(pi/4) -> 6,   2 cos(pi/9) -> 3,   2 cos(pi/3) = 1.

Let R_a,R_b,R_c,R_d be canonical reflection matrices with R_i(e_i)=-e_i and R_i(e_j)=e_j+q_ij e_i, where

    (q_ij) = [[0,6,0,0],[6,0,3,0],[0,3,0,1],[0,0,1,0]].

The matrices preserve

    G = [[1,14,0,0],[14,1,7,0],[0,7,1,8],[0,0,8,1]],
    det G = 13 = 8² in F17.

Thus the form is of plus type. Each R_i is a reflection in a norm-one vector, so its spinor norm is square class one and its determinant is -1. Consequently rho(W) lies in the spinor-one subgroup of O⁺₄(17), and rho(W⁺) lies in Ω⁺₄(17).

For odd q, |Ω⁺₄(q)| = q²(q²-1)²/2; at q=17 this is 11,985,408.

The deterministic verifier verify_cycle9_coxeter_order.cpp enumerates the subgroup generated by the six matrices R_i R_j (i<j), using exact unsigned-128-bit base-17 matrix encoding. It visits exactly 11,985,408 matrices, so rho(W⁺)=Ω⁺₄(17). Its final line is ORDER 11985408; the verifier source SHA-256 is 6e22cce2b801d2c51015aba69bca7054d5023a864e8c27da485d8d928e4a9233.

Define Gamma = ker(rho|W⁺)=ker rho intersect W⁺. It is normal in W. The local exact audit verify_cycle9_coxeter_local.py proves that the images of maximal finite special subgroups <a,b,d> (16), <a,c,d> (12), and <b,c> (18) are faithful, while K=<c,d> has image order six. Every finite-order element of a Coxeter group is conjugate into a finite standard parabolic, so this parabolic faithfulness implies Gamma is torsion-free.

The chamber-residue quotient is indexed by double cosets Gamma\W/K. Since Gamma is torsion-free, Gamma intersect wKw^{-1} is trivial for every w, so every right K-orbit has exactly six chambers. Hence

    #(Gamma\W/K) = [W:Gamma]/|K|
                      = 2*11,985,408 / 6
                      = 3,995,136.

Coarsening each K-orbit of six sectors gives one target tetrahedron. The existing six-sector face-orbit and link checks therefore produce a connected, orientable compact hyperbolic 3-manifold with totally geodesic boundary and a topological ideal triangulation with all low edges of degree eight and all high edges of degree nine, using exactly 3,995,136 tetrahedra.

The previous center-link and low-edge counts still imply 24 divides N. The finite quotient above supplies an explicit witness but gives no obstruction to a different torsion-free subgroup or face pairing with N=24.
