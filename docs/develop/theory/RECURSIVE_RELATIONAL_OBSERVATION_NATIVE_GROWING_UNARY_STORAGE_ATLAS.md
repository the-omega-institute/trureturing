## 2. Sole incidence storage and its initialized local rules

**Definition 2.1 (unary bit, optional location and cell).** A socket root
$r$ alone represents absence. A present bit $b\in\{0,1\}$ has exactly
one additional occurrence $t$. For $b=0$, join $r.\mathsf L$ to
$t.\mathsf P$ and leave $r.\mathsf R$ empty; for $b=1$, use
$r.\mathsf R$ and leave $r.\mathsf L$ empty. The child is terminal.
All other unused slots are empty. Call the resulting two-occurrence
component $U_b$. Its terminal child path is respectively 0 or 1; the
absent component has terminal path $\varepsilon$. Absence is not zero.

Use SSA Definition 3.2's balanced ordered scaffold $F_m$, with $F_1$ one
socket and recursive consecutive floor/ceiling splits. An eight-track
cell $c$ is $F_8[U_{c_1},\ldots,U_{c_8}]$ in the actual track order.
Denote it by $C_U(c)$. It has 23 vertices and eight terminals. Its root
and all track socket roots retain their constructor occurrences.

For $w=c_1\cdots c_k$, including every actually constructed boundary or
partial boundary, its tape tree is

$$
L_U(w)=\langle C_U(c_1),\langle C_U(c_2),\ldots,
       \langle C_U(c_k),\bullet\rangle\ldots\rangle\rangle,
\qquad L_U(\varepsilon)=\bullet.
$$

The 74 tape trees, followed by the optional-location tree
$F_q[U(z_1),\ldots,U(z_q)]$, occupy $F_{75}$'s ordered sockets.
The result is $U(W)$. Add the actual origin-to-head links, one for each
ordinary port and two distinct lanes for the meter, only when that head
exists. They join the tape origin's $\mathsf O_j$ to the cell root's
$\mathsf H_j$. Their number is $\ell\le75$, equal to 75 after all heads
exist. They are determined by the native cursor tracks; there is no
descriptor-to-block shortcut. Call the linked carrier $\Gamma_U(W)$.
There is no live byte store beside these incidences. $W$ is a comparison
record for this definition, not a shadow source.

**Definition 2.2 (four local templates).** The following are ordered
suboperations inside one admitted atomic patch.

1. Inspect a component by depth-first child traversal, probing both child
   slots at every visited vertex and the parent slot on each nonroot
   return. Read a present bit from the occupied side and absence from two
   empty child slots.
2. Assign a designated existing bit $b$ by assigning $r.\mathsf L$,
   $r.\mathsf R$ and $t.\mathsf P$ to their final reciprocal values.
   All three assignments are charged even for an unchanged bit. Construct
   a bit at an absent socket by creating just $t$, initializing its seven
   slots and assigning both old root child slots: one birth and nine
   assignments. Keep the socket root's external parent attachment.
3. Append one native cell by expanding the existing trailing tape terminal
   $z$ into $\langle C_U(c),z'\rangle$. Create 23 cell vertices and one
   new terminal, initialize all seven slots of each, and assign $z$'s two
   child slots. The old terminal occurrence becomes the spine node. This
   is 24 births and $7\cdot24+2$ assignments.
4. Retarget a head link by clearing its old target slot, assigning the
   origin slot and assigning the new target slot. First activation uses
   the latter two assignments. Meter lanes use different endpoint types
   even when their targets coincide. Head-track assignments in the cell
   components are additional designated bit assignments.

Root-to-origin/head walks are SSA Definition 5.1's. From an old cell root,
next and previous cell roots use $\mathsf P\mathsf R\mathsf L$ and
$\mathsf P\mathsf P\mathsf L$ when the native move is enabled; the
trailing terminal uses $\mathsf P\mathsf R$. A boot append to an empty
word starts at its fixed origin socket. These walks do not change with
the unary shape of a track component.

$$
\operatorname{step}_{U}(\Gamma_U(W(h)),b)

The outer scaffold has finite height, all head links have length one,

radius. The primitive's actual cursor relation is preserved by each

is absent, rather than repaired into a different head configuration.

## 3. Independent support, boundary, occurrence and memory relations

**Definition 3.1 (independent geometric and chronological views).** On
$\mathcal R$ define $S(h)$ to be the set of root-relative L/R child paths
of the actual storage tree layer $U(W(h))$. Define $B(h)$ independently
as the child paths ending at an actual terminal, meaning both child
slots empty. Access links are not child edges. This boundary is a
geometric terminal antichain, not a source-tree leaf set or a halt output.

Define $T(h)$ as the chronological word of actual $\Pi_U$ primitive patch
occurrences from the charged entrance, with native operands,
read/written/supplied/emitted values, actual constructor roles and
receipts. It is an order relation on actual operations, not an installed
transcript tape. Its native erasure is exactly $h$ by Theorem 2.4.
These definitions use support, terminal incidence and actual chronology
respectively; none is defined by a replay key or an intersection of kernels.

**Theorem 3.2 (separate raw-record inverses).** For any $h,k\in\mathcal R$,

$$
S(h)=S(k)\ \Longleftrightarrow\ W(h)=W(k),\qquad
B(h)=B(k)\ \Longleftrightarrow\ W(h)=W(k).
$$

The equalities concern physical records with the fixed port/creation-chain
identity convention. They do not assert history equality on all raw runs
or recover absolute construction-event names from arbitrary graph renaming.

Proof. The fixed outer socket paths select each tape and finite-location
component. A right spine gives exactly its finite cell list, including
partial boot boundaries. At each of its eight fixed track sockets the
occupied child side gives that bit. At a finite-location socket two
empty child slots give absence, whereas exactly the left or right child
gives present 0 or 1. Thus $S$ decodes all raw bytes, controls, inactive
versions, latches, tokens and cursor tracks, without source validity,
sealing, an installed main row or a successful request. Cursor tracks
determine the access incidences. Encoded reference bytes retain their
actual grammar and origin. This proves $S$ equality implies $W$ equality.
Conversely the fixed templates construct the same support from equal $W$.

Every position in a finite rooted child tree extends to a terminal:
follow an existing child while possible; a finite strict descent must
stop. This argument permits a vertex with exactly one child. Every prefix
of a terminal is a position, so

$$
S(h)=\operatorname{Pref}(B(h)),\qquad
B(h)=\operatorname{Max}_{\preceq}(S(h)).
$$

Consequently equal $B$ gives equal $S$ and equal $W$; equal $W$ gives the
same maximal paths and hence equal $B$. In particular the absence code's
terminal $\varepsilon$ and the unary codes' terminals 0 and 1 are not
confused. Full binary branching is unnecessary. This proves both
implications for each geometric view separately. ∎

**Theorem 3.4 (two-ingress extraction at every canonical acquired cut).**
On $\mathcal C$, including partial activation and the original 00 stopping
suffix and terminal successor, $M_J(h)$ determines exactly the consumed
typed input reservoirs of ARC Definition 6.1 and $n=|h|$. It determines
$h$ and its full raw endpoint. No completed-cycle reconstruction witness
or future input is needed for this mathematical extraction.

Proof. The acquired seed, its genuine binding and $H_0$ give ARC
Definition 6.1's unique canonical padded original packet. The original
public/controller/prior inputs are this apparatus's fixed canonical
words or actual acquired bindings, not new source advice. The native
boot, normalized acquisition entry, capture $L$ and prescribed
$E/\Delta$ lineage determine their canonical supply. Hence the entire
original preparation and activation input is determined even before
the initial manifest is complete. This does not assume it was freely
available to $A$ before its actual acquisition or capture. Fixed input
is consumed at its real IN rows on replay, and its physical construction
is not omitted. There is no variable late activation-position choice.

The meter has one receipt per executed row and initially two boundary
cells. Counting actual receipt cells, without moving a live head,
gives $n$. This is a mathematical finite-chain observation, not an
installed A readout. Replay of the fixed initial portion identifies
the initial 13 prefix to skip and the first outer entry. For a cut during
activation there is no later variable input to recover. The selected
partial stores/stages are the actual ones, not a completed-manifest
substitute at an earlier cut.

After that entry, read the two retained ingress chains with the following
frontier rules. On append ingress 70, completed fields are binary payload
followed by F. Separate its initial sentinel, binary bits and delimiters.
An EX-created blank is not an input bit. The literal outer reception is
IN(6), EX(70), WR(70,6), MR(70), with no bank assignment between its bit
receptions/tests. The history tag has the same body; unary length has
the additional distinct-latch RD test; its payload body is
RD(length,5), IN(6), EX(70), WR(70,6), MR(70), MR(length).
Thus at any cut the written binary prefix plus the one occupied latch-6
bit, if its WR has not occurred, is precisely that site's consumed prefix.
Delimiters, seals, Base scratch, descriptor work and subsequent import
RDs contribute no external bits. An incomplete descriptor does not
remove the already written prefix or its native origin.

Port 13 has CAP Definition 4.6's different physical layout. Its header
is three IN/EX/WR/MR bodies, its unary length has
IN/EX/WR/RD(test)/MR bodies, and its payload is allocated and zeroed
before any payload IN. Separators and status cells are not wire bits.
During setup, including a partially zeroed reservation, that allocation
contributes no payload input. During the literal payload loop let $b$
be its actual retained base and $p$ its marked payload position. These
are positions selected from existing heads and base words, not free
stored numerals. At its substages the number of written payload bits is

$$
\begin{array}{c|c|c}
\text{substage}&\text{written extent from }b&\text{pending input}\hline
\text{before IN, including after length RD}&p-b&\varepsilon\\
\text{after IN and before WR}&p-b&\text{latch 5}\\
\text{after WR and before payload MR}&p-b+1&\varepsilon\\
\text{after payload MR, before length MR/next RD}&p-b&\varepsilon
\end{array}
$$

Before its first IN use zero; after terminal RD(0) use the full declared
length, even while At/status/seal later move the ingress head. The actual
PC/substage and live length cursor distinguish these cases. This remains
true for zero-length payloads. Before header/length completion take their
written prefixes with their single occupied latch if applicable. After
completion their literal sep/status layout and actual descriptors fix
their intervals even when later helpers move the heads. During descriptor
or length-copy construction use the actual live scratch/frontier and
raw 13/17 material; a nonexistent completed descriptor is never assumed.

These prefix identities follow by induction on the displayed reader
rows. IN adds exactly one pending bit, EX adds no consumed input,
WR transfers that bit into the written extent, and MR only updates the
frontier. The length test has a different latch. No second input can
overwrite an occupied bit before its matching WR. CAP's preallocated
zeros become counted only as their actual writes pass the frontier.
All completed fields are retained immutably. The identities therefore
hold through installation, incomplete frames, bank work and copies,
without requiring a service-boundary cut.

There is also an ordering obligation between these two streams. The
70 gate grammar is prefix-free 00, 01, 1. After 01 exactly the next
13 header/length/payload triple is the auxiliary external frame; its
complete return and CaptureCAP precede the next gate. After 1 exactly
the next self-delimiting 70 history frame is consumed; all its callbacks
are RD/import/computation, not new IN; its ACK/return precedes the next
