# FIB-ATOM 观察者与算术关系

**约定 A-0.1（论域与来源）。** 本卷讨论有限有序来源、交换环、实概率、有限剩余类、$`p`$ 进整数与另行给定的有限维复 Hilbert 实现。树、选择、编译所得组成、数量、模式律和已取得档案分别定型。普通数学证明承担下述结论；概率坐标、谱相位、矩阵维数和关系图不直接定义物理空间、运动或仪器。项目原生接口使用不可变来源 [A-R0]；单窗关联和守卫使用 [A-R1–A-R3]；秩、共同素因子和相干实现使用 [A-R4–A-R7]。经典结果在消费它们的推导中注明来源，不以更换名称主张新发现。

**约定 A-0.2（统一记号）。** 模式字母表为 $`\Sigma=(0,1,2,3,13)`$，位置选择写作 $`\mathsf{\text{𝖥}}[\varnothing],\mathsf{\text{𝖥}}[1],\mathsf{\text{𝖥}}[2],\mathsf{\text{𝖥}}[3],\mathsf{\text{𝖥}}[1,3]`$；普通 $`F_n`$ 与 $`L_n`$ 是 Fibonacci、Lucas 数。$`x,y,z`$ 分别是低端、高端、中位占用，印刷三位次序为 $`(x,z,y)`$，原生读取由高到低。组成为列向量 $`C`$，模数写 $`m`$ 或 $`\mathfrak{\text{𝔪}}`$，矩阵固定为 $`M`$。概率按 $`(p_0,p_1,p_2,p_3,p_{13})`$ 排列，$`X=\mathbb{\text{𝔼}}x,Y=\mathbb{\text{𝔼}}y,Z=\mathbb{\text{𝔼}}z,r=1-Z,\kappa=\mathbb{\text{𝔼}}(xy)`$。同一字母在不同载体的映射每次注明；不存在由同名标签自动产生的模型等价。

## 1. 有序原子、五种选择与标准窗口

**定义 A-1.1（原树及同步替换）。** 自由有序二叉树由 $`\alpha,\beta`$ 与构造子 $`\langle t,u\rangle`$ 生成。定义


```math
\rho(\alpha)=\beta,\quad \rho(\beta)=\langle\beta,\alpha\rangle,
\quad \rho\langle t,u\rangle=\langle\rho t,\rho u\rangle.
```


令 $`T_a=\rho^a\alpha`$，$`a\ge0`$。整数组成为 $`C(\alpha)=(1,0)^{\mathsf{\text{𝖳}}},C(\beta)=(0,1)^{\mathsf{\text{𝖳}}}`$、$`C\langle t,u\rangle=C(t)+C(u)`$。数量读口与替换矩阵是


```math
q=(2,3),\qquad
M=\begin{pmatrix}0&1\\1&1\end{pmatrix},\qquad
S=M^3=\begin{pmatrix}1&2\\2&3\end{pmatrix}.
```


空贡献 $`0`$ 是选择层另添的零元，原树中没有零叶树。取 $`F_0=0,F_1=1,L_0=2,L_1=1`$，两列均满足 $`u_{a+2}=u_{a+1}+u_a`$。[A-R0，定义 1.1、1.3；A-R3，§一]

证明。$`T_2=\langle\beta,\alpha\rangle`$；对此同步替换 $`a`$ 次得树递归。叶子直接满足组成等式，二叉构造按加法归纳保持它。数量初值为 $`2,3`$，所以为 $`F_{a+3}`$。合法位满足 $`xz=yz=0`$；若 $`z=1`$ 只有中位，若 $`z=0`$ 两端有四种选择，得五种。两端联合数量为 $`F_{n-1}+F_{n+1}`$；该和初值及递归与 $`L_n`$ 相同。组成公式由 $`C\rho=MC`$ 得出。每棵原树至少一叶，故其组成非零。证毕。

**定义 A-1.3（有序编译与尺度）。** 在明确供应的词编译中，代表为 $`\varepsilon,\alpha,\beta,\beta\alpha,\beta\alpha\alpha`$；合法续接可按 $`h\mapsto\rho^3(h)r_I`$ 编译，得到 $`C'=SC+d_I`$。这是 [A-R7，§188 的同源编译合同] 的一个指定接口，接缝、顺序、层数、控制和错误仍分别保留。$`j`$ 是标准位置尺度；已读取窗口数 $`\ell`$ 是事件长度。某个任意多窗口前缀的即时数量通常不是某个 $`V_j(I)`$。

**命题 A-1.4（有序来源的遗漏）。** $`C`$ 忘记叶序及括号，$`qC`$ 进一步忘记组成。$`\langle\beta,\alpha\rangle`$ 与 $`\langle\alpha,\beta\rangle`$ 同组成却不同序；$`\langle\langle\beta,\alpha\rangle,\alpha\rangle`$ 与 $`\langle\beta,\langle\alpha,\alpha\rangle\rangle`$ 同叶序却不同括号。若已在同一初始化读者上读取 $`I`$，随后实际输入 $`j`$ 个零窗口，则最后组成恰为 $`S^jd_I`$，最后回复为 $`V_j(I)`$。

证明。前两项由定义逐叶求和；数量层中 $`(3,0)`$ 与 $`(0,2)`$ 都读成六。最后一项每次实际零窗口执行 $`C\mapsto SC`$，归纳给公式，同时层数和档案增长。它不提供任意未知来源的免费初始化、重置、逆树替换或多个独立样本。证毕。

## 2. 三均值、关联纤维与目标差分

**定义 A-2.1（同一实概率律）。** 五项非负且和一的 $`p`$ 给


```math
X=p_1+p_{13},\quad Y=p_3+p_{13},\quad Z=p_2,\quad \kappa=p_{13}.
```


模式上的 $`(x,y,z)`$ 是确定指示；$`X,Y,Z`$ 是同一律的均值。两个分别取得的边缘即使给相同数字，也没有因此供应共同律。[A-R1，§§一、三、四；A-R2，§§二、三；Fréchet 界的经典背景见 A-L1]

**命题 A-2.2（单窗信息遗漏的完整逆式）。** 可实现的均值域恰为


```math
\mathcal{\text{𝒫}}=\{X,Y,Z\ge0:X+Z\le1,\ Y+Z\le1\}.
```


其全部概率提升为


<table><tbody><tr><td>

```math

(p_0,p_1,p_2,p_3,p_{13})=(r-X-Y+\kappa,X-\kappa,Z,Y-\kappa,\kappa),\qquad
\max(0,X+Y-r)\le\kappa\le\min(X,Y).

```

</td></tr></tbody></table>


宽度为


```math
w=\min(X,Y)-\max(0,X+Y-r)=\min\{X,Y,r-X,r-Y\}.
```


证明。归一化及三个均值逐项消元给逆式；非负性恰给区间。若 $`0\le X,Y\le r`$，$`X+Y-r\le X,Y`$，故区间非空，证明充分性。假设 $`X\le Y`$：若 $`X+Y\le r`$，宽度是 $`X`$，另三个松弛量均不小于它；若 $`X+Y\ge r`$，宽度是 $`r-Y`$，其余松弛量均不小于它。交换 $`X,Y`$ 得完整式。$`r=0`$ 时强制 $`X=Y=\kappa=0,Z=1`$。$`r\gt 0`$ 时宽度零恰为 $`X=0,Y=0,X=r,Y=r`$ 的四个三角侧面；底面相对内部仍可有宽度正。端点由至少一个底面概率为零决定，顶点均唯一。证毕。

**命题 A-2.3（坐标几何与确定模式）。** $`\mathcal{\text{𝒫}}`$ 是四个底角及 $`(0,0,1)`$ 的凸包；标准欧氏坐标下高度 $`t`$ 的截面面积为 $`(1-t)^2`$，体积为 $`1/3`$。三个占位区分每个确定模式，却不一般区分概率律。

证明。高度固定时 $`0\le X,Y\le1-t`$；截面及积分 $`\int_0^1(1-t)^2dt=1/3`$ 得前两项。表 A-1.2 五点互异，确定模式可逆。律 $`p=(1/2,0,0,0,1/2)`$ 与 $`p'=(0,1/2,0,1/2,0)`$ 均给 $`(X,Y,Z)=(1/2,1/2,0)`$，但 $`\kappa=1/2,0`$。体积的尺子是这组概率均值坐标，未供应物理定位。证毕。

**定义 A-2.4（目标的关联敏感度）。** 对任何 $`f:\Sigma\to\mathbb{\text{ℝ}}`$，令 $`J_f=f_{13}-f_1-f_3+f_0`$。固定均值时，目标是同一律下的 $`\mathbb{\text{𝔼}}_p f`$，不是任意选择一个实际结果。[A-R1，§四；A-R6，§39]



故

证明。逐模式检查 $`d_I`$ 得前式。律 $`p=(1/2,0,0,1/2,0)`$ 与 $`p'=(0,1/2,1/2,0,0)`$ 均有 $`(U,V)=(1/2,1/2)`$，却分别有 $`(X,Y,Z)=(0,1/2,0),(1/2,0,1/2)`$。在已初始化的同一数量读口上，其 $`\mathbb{\text{𝔼}} Q^2`$ 分别为 $`25/2`$ 和 $`13/2`$，故此二阶读口区分该对子。这不声称一项二阶矩对每个未知律都充分；完整零层回复分布因五数量互异而恢复模式律，取得该分布仍遵守第十四节的合同。[A-R3，组成均值与实际回复分布的分层] 证毕。

## 3. 同一仿射关系的整数、模与 $`p`$ 进载体

**定义 A-3.1（计数边界）。** 在有单位交换环 $`R`$ 上，令 $`a=(a_0,a_1,a_2,a_3,a_{13})`$，定义


```math
\mathcal{\text{ℬ}}(a)=(m,u,v,w_2),\quad
m=\sum_Ia_I,\quad u=a_1+a_{13},\quad v=a_3+a_{13},\quad w_2=a_2.
```


这里 $`w_2`$ 是中位计数，区别于纤维宽度 $`w`$。[A-R3，§六 的累计编码；本卷用于第十六节的同源筛任务]

**命题 A-3.2（任意交换环上的完整纤维）。** 对每个边界，全部解恰为


<table><tbody><tr><td>

```math
a=(m-u-v-w_2+t,u-t,w_2,v-t,t),\qquad t\in R,
```

</td></tr></tbody></table>


且 $`\ker\mathcal{\text{ℬ}}=R(1,-1,0,-1,1)`$。参数化是单射，映射 $`\mathcal{\text{ℬ}}`$ 满射，不需要域或除法假设。

证明。令 $`t=a_{13}`$，三个占位式依次恢复 $`a_1,a_3,a_2`$，总数式恢复 $`a_0`$。反向代入恒给边界；最后分量证明参数单射。边界零即核。其整数关系为 $`0+13\leftrightarrow1+3`$，是同一底面再分配的代数接口。证毕。

**命题 A-3.3（载体限制及排序遗漏）。** 非负整数解存在当且仅当


```math
m,u,v,w_2\in\mathbb{\text{ℕ}}_0,\quad u+w_2\le m,\quad v+w_2\le m,
```


此时 $`\max(0,u+v+w_2-m)\le t\le\min(u,v)`$ 是有限整数区间。$`m\gt 0`$ 除以 $`m`$ 得第二节实概率纤维；$`m=0`$ 只给零计数。模 $`p^k`$ 的每个边界有恰 $`p^k`$ 个代数解；$`\mathbb{\text{ℤ}}_p`$ 上为一条仿射 $`p`$ 进直线。

证明。非负性的五个不等式直接化为上述区间；条件确保端点相容。模环和 $`\mathbb{\text{ℤ}}_p`$ 使用命题 A-3.2 的单射参数。不存在将实数非负次序搬到 $`\mathbb{\text{ℚ}}_p`$ 的步骤。计数仍忘记模式次序：原生合法词 $`(1,0)`$ 与 $`(0,1)`$ 有同一模式计数，但组成分别为 $`S(1,0)^{\mathsf{\text{𝖳}}}=(1,2)^{\mathsf{\text{𝖳}}}`$ 与 $`(1,0)^{\mathsf{\text{𝖳}}}`$，数量八和二。因而 $`\mathcal{\text{ℬ}}`$ 不能一般预测有序后续数量。证毕。

## 4. 算术精度与实参数路径的边界

**定义 A-4.1（相容剩余类）。** 固定素数 $`p`$。$`k\in\mathbb{\text{ℕ}}_0`$，模 $`p^0=1`$ 为单点；$`r_k\in\mathbb{\text{ℤ}}/p^k\mathbb{\text{ℤ}}`$ 且 $`r_{k+1}\bmod p^k=r_k`$。定义


```math
\mathbb{\text{ℤ}}_p=\varprojlim_{k\ge0}\mathbb{\text{ℤ}}/p^k\mathbb{\text{ℤ}}.
```


每个相容地址唯一写为 $`\sum_{i\ge0}a_ip^i`$，$`0\le a_i\lt p`$。采用 $`v_p(0)=+\infty,|0|_p=0`$，非零差的距离为 $`d_p(a,b)=p^{-v_p(a-b)}`$。[A-L2；A-R8–A-R10]

逆极限上的加法、乘法逐剩余类进行；约化是环同态，故结果仍相容。拓扑取有限离散环乘积的子空间拓扑，其邻域基为固定模 $`p^k`$ 类的柱集，等价于上述距离拓扑。置 $`\mathbb{\text{ℚ}}_p=\mathrm{Frac}(\mathbb{\text{ℤ}}_p)`$；非零元素唯一为 $`p^eu`$，$`e\in\mathbb{\text{ℤ}}`$、$`u\in\mathbb{\text{ℤ}}_p^\times`$，赋值延拓为 $`e`$。这里单位恰是模 $`p`$ 非零的地址：各有限层的逆相容，给逆极限中的逆；非零 $`p`$ 进整数取其首个非零位得到这种分解，两个首位单位的积仍非零，故赋值相加，也说明 $`\mathbb{\text{ℤ}}_p`$ 无零因子。

**命题 A-4.2（地址精化与碰撞）。** 每个模 $`p^k`$ 类有恰 $`p`$ 个模 $`p^{k+1}`$ 延拓，即 $`r_k+dp^k`$，$`d=0,\ldots,p-1`$。两个不同整数在精度 $`k`$ 相同而 $`k+1`$ 不同，当且仅当 $`v_p(a-b)=k`$。距离满足


```math
d_p(a,c)\le\max\{d_p(a,b),d_p(b,c)\}.
```


证明。高一位的唯一商余式给第一项，也逐层给数字展开。$`p^k\mid a-b`$ 且 $`p^{k+1}\nmid a-b`$ 恰是赋值等于 $`k`$。若两个相邻差均在 $`p^k\mathbb{\text{ℤ}}_p`$，其和亦在该理想，得强三角不等式；零差由扩展约定处理。$`p^k\to0`$ 于 $`p`$ 进距离，而在实数距离中趋于无穷：这是不同拓扑的两个准确陈述。下一位属于固定未知来源；选择读取精度没有授予选择它的能力。证毕。

**命题 A-4.3（组成精度合同的路径限制）。** 对原生组成的局部地址载体，以下经典连通性步骤限制实参数更新：若 $`A`$ 连通、$`f:A\to\mathbb{\text{ℤ}}_p`$ 连续，则 $`f`$ 常量。特别地 $`[0,1]`$ 上连续路径常量；到 $`\prod_p\mathbb{\text{ℤ}}_p`$ 的连续路径亦常量。连续加法同态 $`\mathbb{\text{ℝ}}\to\prod_p\mathbb{\text{ℤ}}_p`$ 必为零。故对实际非固定组成，不能把 $`C\mapsto MC`$ 解释为这个地址拓扑中的连续实路径一步。

证明。每个有限离散投影的连续像连通，只能是单点。全部投影固定后，逆极限地址固定。乘积空间逐坐标同理；加法同态在零处取零，所以常量为零。$`n\mapsto(n)_p`$ 是非零的整数参数同态，以一在二进坐标的值证明非零；它不证明所有非平凡动作只能取整数参数。上述结论没有推断物理运动离散，也没有建立真实时间到这些地址空间的映射。[A-R10 的明确来源边界] 证毕。

**命题 A-4.4（三胞胎地址所用的完整 CRT 载体）。** 按整除约化定义 $`\widehat{\mathbb{\text{ℤ}}}=\varprojlim_{m\ge1}\mathbb{\text{ℤ}}/m\mathbb{\text{ℤ}}`$，经典 CRT 的逆极限步骤给拓扑环同构


```math
\widehat{\mathbb{\text{ℤ}}}\cong\prod_{p\text{ 素}}\mathbb{\text{ℤ}}_p.
```


普通整数的对角映射单射；该同构不把每个局部地址变成普通整数。

证明。由完整相容族取各 $`p^k`$ 分量得到右侧。反向对每个有限 $`m=\prod p^{k_p}`$ 用 CRT 唯一拼合相应分量；两个模数的约化在各素数幂上相同，由 CRT 唯一性保证整除相容。两构造互逆且保持逐分量环运算。每个有限坐标只调用有限个素数的有限精度，双方映射连续。若两个整数在全部模数相同，其差被任意正整数整除，只能为零。第十五节的全素数单位地址给不在指定正整数对角源中的实际实例，正是该载体区别的消费者。证毕。

## 5. 完整组成更新与实际数量采样

**命题 A-5.1（同源 FIB 更新的两个度量表现）。** $`M^{-1}=M-I=\left(\begin{smallmatrix}-1&1\\1&0\end{smallmatrix}\right)`$。在 $`\mathbb{\text{ℤ}}_p^2`$ 或 $`\mathbb{\text{ℚ}}_p^2`$ 的上确界范数上，完整组成更新是等距双射；在有限剩余类组成空间上是置换。在实数组成平面上，特征值为 $`\varphi=(1+\sqrt5)/2`$ 与 $`-\varphi^{-1}`$，分别给增长和带反号的收缩方向。

证明。直接相乘得整数逆矩阵。整数系数给 $`\|Mv\|_p\le\|v\|_p`$；再对整数逆矩阵应用同一不等式得反向界，故等距。模任意正整数，两矩阵仍互逆。实特征多项式为 $`t^2-t-1`$，根即所列。线性逆是在完整组成载体上的代数逆，不是任意原树上实际可执行的逆 $`\rho`$。投影 $`q`$ 可丢失信息，与完整 $`M`$ 可逆是不同问题。证毕。

**定义 A-5.2（两种采样合同）。** 若额外供应保持原接缝的单原子动作，当前和一次原子更新的回复为 $`N_0=qC,N_1=qMC`$。原生窗口合同中，只供应实际零窗口，回复为 $`N_0=qC,N_1=qSC`$。二者分别使用


```math
O_1=\begin{pmatrix}2&3\\3&5\end{pmatrix},\qquad
O_3=\begin{pmatrix}2&3\\8&13\end{pmatrix}.
```


$`O_3`$、其闭合更新及核是 [A-R0，定理 7.3] 的既有结果；$`O_1`$ 的附加动作边界为其定义 7.5、定理 7.6。下面将这些既有中间接口接到精度及第十六节同源图，不另认作新观察原理。

两回复必须来自同一来源的当前状态和已允许续接，并保留它们属于同一有序前缀的档案。实际零窗口之后状态已为 $`(0,SC)`$；$`O_3`$ 反解的是零窗口前的组成，旧接缝仍须独立取得、记录。零窗口不代表无事件，亦不能把两次不同批次准备的回复默认为这组同源读数。

**命题 A-5.3（逆式、像与二进精度）。** $`\det O_1=1`$，任意有单位交换环上


```math
C=\begin{pmatrix}5&-3\\-3&2\end{pmatrix}\binom{N_0}{N_1}.
```


$`\det O_3=2`$；在二可逆的环中


</td></tr></tbody></table>


整数像为 $`N_0\equiv N_1\pmod2`$；非负整数组成的像还要求两反解非负。在 $`\mathbb{\text{ℤ}}_2`$ 上像为同一模二条件，反解唯一，但除以二须在可除的分子上进行。模 $`2^k`$，$`k\ge1`$，核恰为 $`\{(0,0),(2^{k-1},0)\}`$，像是满足上述模二条件的 $`2^{2k-1}`$ 个对，每个像点有两原像。奇素数 $`p`$ 的模 $`p^k`$、$`\mathbb{\text{ℤ}}_p`$ 上 $`O_3`$ 可逆。

证明。$`S\equiv I\pmod2`$，所以在模 $`2^k`$ 上 $`S(2^{k-1},0)^{\mathsf{\text{𝖳}}}=(2^{k-1},0)^{\mathsf{\text{𝖳}}}`$，$`q`$ 将它读成零。任意零窗口归纳保持之。模 $`2^{k+1}`$ 得偶分子的值，除二后确定 $`C_\alpha\bmod2^k`$，而第二分量不损失精度。完整二进地址没有非零永久核，由命题 A-5.3。原生同接缝零的模式 $`2,3`$ 有组成 $`(0,1),(1,1)`$，数量三和五；在模二以及任意零续接后相同。它们是实际已初始化的同接缝例子；全载体中所有更高精度核例子不额外证明某给定长度前缀都能取得。证毕。

## 6. 素数任务的六种角色与共同窗口恒等式

**定义 A-6.1（任务分类）。** 同一素数可承担下表多个角色；分类按来源、读口及目标，而非互斥元素种类。

| 角色 | 实际数学目标 | 所需来源 |
| --- | --- | --- |
| 数值素数 | $`V_j(I)=p`$ 是否成立、$`V_j(I)`$ 是否素数 | 实际整数及其素性证据 |
| 因子标记 | $`p\mid V_j(I)`$ | 固定窗口数量或合法回复 |
| 分辨率探针 | $`p^k\mid V_j(I)-V_j(J)`$ | 同一尺度两模式的差 |
| 递归节拍 | 首次整除秩 $`r_p`$ 及命中索引 | 同一标准 Fibonacci 序列 |
| 谱选择 | $`t^2-t-1`$ 在模 $`p`$ 的分裂 | 声明的有限域 |
| 联合相容 | 一组素因子能否共存于同一 $`L_n`$ | 同一个索引，且素数集合互异 |

费马素数在这里限制索引，梅森素数可提供合数因子证书；二者属于这些角色的具体实例。

**命题 A-6.2（迹、行列式与共同双曲关系的消费）。** 同一标准窗口的量满足


```math
M^n=\begin{pmatrix}F_{n-1}&F_n\\F_n&F_{n+1}\end{pmatrix},\quad
\mathrm{tr}(M^n)=L_n,\quad\det(M^n)=(-1)^n,
```


```math
F_{2n}=F_nL_n,\qquad L_n^2-5F_n^2=4(-1)^n.
```


矩阵式适用 $`n\ge1`$，后两式及迹、行列式适用 $`n\ge0`$。令 $`A_n=L_n/2,B_n=\sqrt5F_n/2`$，则实坐标满足 $`A_n^2-B_n^2=(-1)^n`$。这些经典恒等式 [A-L3，§§1–2] 在本卷作为窗口素性、秩和碰撞的中间步骤。

证明。矩阵式的 $`n=1`$ 与初值一致，右乘 $`M`$ 给归纳。取迹及行列式得两式；$`M^{2n}=(M^n)^2`$ 的非对角元给 $`F_{2n}=F_n(F_{n-1}+F_{n+1})`$。任意二阶矩阵的迹平方减四倍行列式等于 $`(A_{11}-A_{22})^2+4A_{12}A_{21}`$；此处对角差为 $`F_n`$，非对角均 $`F_n`$，得二次式。$`n=0`$ 由初值直接核对。实坐标的归一化给交替的两条双曲线，未指定物理相位或时空。证毕。

**命题 A-6.3（共同来源迫使同层素因子分离）。** 对 $`n\ge1`$，$`\gcd(F_n,L_n)=\gcd(F_n,2)`$，故至多二；在标准窗口 $`n=3j+4`$，四个非空数量两两互素，每个素数最多整除其中一个。

证明。欧几里得递推给 $`\gcd(F_a,F_{a+1})=1`$。置 $`a=F_{n-1},b=F_n`$，则 $`c=F_{n+1}=a+b,d=L_n=2a+b`$。除 $`\gcd(b,d)`$ 外，六个 gcd 均由加减化为 $`\gcd(a,b)=1`$；剩余 $`\gcd(b,d)=\gcd(b,2)`$。模二相邻状态为 $`(0,1)\to(1,1)\to(1,0)\to(0,1)`$，故 $`F_n`$ 偶当且仅当 $`3\mid n`$。标准 $`n\equiv1\pmod3`$，所以 $`b`$ 奇，所有 gcd 一。一般 gcd 也由 $`L_n=2F_{n-1}+F_n`$ 得所列式。$`n=0`$ 单独为 $`\gcd(0,2)=2`$。这些 gcd 和奇偶事实是经典中间结果；同层分离在第十四节被实际因子读口消费。证毕。

## 7. 窗口素性掩码、例外索引与合数证书

**命题 A-7.1（标准窗口的素性限制）。** 对 $`j\ge1`$，低端 $`F_{3j+3}\gt 2`$ 为偶合数。$`j`$ 奇时素数仅可能在 $`2,13`$；$`j`$ 偶且 $`j\ge2`$ 时仅可能在 $`3,13`$，所以每窗至多两个非空素数顶点。$`j=0`$ 是唯一四个非空量均为素数的窗口。

证明。第六节的模二周期处理低端。偶指标 $`m=2a\ge6`$ 时 $`F_m=F_aL_a`$，两因子都大于一。$`j`$ 奇时 $`n+1\ge8`$ 偶，故高端合数；$`j`$ 偶且正时 $`n\ge10`$ 偶，故中位合数。零层四数为 $`2,3,5,7`$，均素。候选边为 $`2`$—$`13`$ 或 $`13`$—$`3`$，只是顶点事件的限制，不能推断物理维数减少。证毕。

</td></tr></tbody></table>


证明。使用 [A-L3，§1 的经典索引限制及 Lemma 2.7]，给出本域的完整推导。$`M^a=F_aM+F_{a-1}I`$，模 $`F_a`$ 时 $`M^a`$ 是标量，因此 $`a\mid m`$ 蕴涵 $`F_a\mid F_m`$。若合数 $`m\gt 4`$，写 $`m=ab`$、$`a,b\ge2`$；若 $`a\ge3`$ 取 $`a`$，否则取 $`b\ge3`$，得到 $`3\le d\lt m`$ 的因子，$`1\lt F_d\lt F_m`$。$`m=0,1,2`$ 非素，$`m=4`$ 给二。

## 8. 分裂谱、重根与窗口二次剩余约束

**定义 A-8.1（有限域中的黄金根）。** 奇素数 $`p\ne5`$，在 $`\mathbb{\text{𝔽}}_{p^2}`$ 中取 $`\lambda_\pm=(1\pm\sqrt5)/2`$，满足和一、积负一。置 $`\epsilon_p=(5/p)`$。由相同初值及递归得到


```math
F_a=\frac{\lambda_+^a-\lambda_-^a}{\lambda_+-\lambda_-},\qquad
L_a=\lambda_+^a+\lambda_-^a\quad\text{于该域， }a\ge0.
```


这些是 [A-L3，§2、Lemma 2.7] 的经典模数列中间表示；根的名称不供应量子相位操作。

**命题 A-8.2（谱类型对秩任务的约束）。** $`\epsilon_p=1`$ 时两根在 $`\mathbb{\text{𝔽}}_p`$，$`\epsilon_p=-1`$ 时 Frobenius 交换两根。于是


```math
p\mid F_{p-\epsilon_p},\quad F_p\equiv\epsilon_p\pmod p,\quad L_p\equiv1\pmod p,
\qquad
\epsilon_p=\begin{cases}1&p\equiv1,4\pmod5,\\-1&p\equiv2,3\pmod5.\end{cases}
```


证明。Frobenius 固定基域，并保持特征多项式的根；分裂时逐根固定，非分裂时交换。代入和差式给后两同余。比值 $`\lambda_+/\lambda_-`$ 在分裂时的 $`p-1`$ 次幂为一，在非分裂时 $`p+1`$ 次幂为一，因此相应 $`F`$ 归零。二次互反律给 $`(5/p)=(p/5)`$，模五非零平方类为一和四，得表。证毕。

**命题 A-8.3（特殊五切面的精确域）。** 模五写 $`M=3I+N`$，则 $`N^2=0`$。对 $`a\ge1`$，


```math
M^a=3^aI+a3^{a-1}N,\quad F_a\equiv a3^{a-1}\pmod5,\quad L_a\equiv2\cdot3^a\pmod5.
```


$`a=0`$ 单独有 $`M^0=I,F_0=0,L_0=2`$。故 $`5\mid F_a`$ 当且仅当 $`5\mid a`$，且五不整除任何 $`L_a`$，$`a\ge0`$。

证明。特征多项式模五为 $`(t-3)^2`$，Cayley–Hamilton 得 $`N^2=0`$。二项式展开只有前两项，非对角元给 $`F_a`$，$`\mathrm{tr}N=0`$ 给迹。三为单位，归零与指标五整除等价。没有在 $`a=0`$ 写含 $`3^{-1}`$ 的未声明表达式。证毕。

**命题 A-8.4（同一二次式对因子角色的限制）。** 对奇素数 $`p`$ 及 $`a\ge1`$，若 $`p\mid F_a`$，则 $`(-1/p)^a=1`$。若 $`p\mid L_a`$，则 $`p\ne5`$ 且


```math
\left(\frac5p\right)=\left(\frac{-1}p\right)^{a+1}.
```


所以奇 $`a`$ 的 Fibonacci 因子使负一为平方，Lucas 因子使五为平方；偶 $`a`$ 的 Lucas 因子要求五与负一有同一平方类。

证明。若 $`F_a`$ 归零，二次式给 $`L_a^2=4(-1)^a`$，且右侧非零，取 Legendre 符号。若 $`L_a`$ 归零，五切面已排除，gcd 界排除 $`F_a`$ 同时归零；取 $`-5F_a^2=4(-1)^a`$ 的符号并除去平方因子得第二式。这是第六节经典恒等式对同窗因子判据的直接消费。证毕。

## 9. 首次秩把四种非空角色接到同一指标

**定义 A-9.1（首次整除秩）。** 对素数 $`p`$，令 $`r_p=\min\{a\ge1:p\mid F_a\}`$。有限群 $`GL_2(\mathbb{\text{𝔽}}_p)`$ 中 $`M`$ 可逆，某个正幂为 $`I`$，所以集合非空。首次归零的秩不同于完整矩阵阶或 Pisano 周期。[A-R4，§163；A-R5；A-L3、A-L4]

**命题 A-9.2（同窗角色的整周期与半周期条件）。** 对所有素数 $`p`$、$`a\ge0`$，


```math
p\mid F_a\iff r_p\mid a.
```


对奇素数 $`p`$、$`a\ge0`$，


<table><tbody><tr><td>

```math
p\mid L_a\iff r_p\text{ 偶，且 }a\equiv r_p/2\pmod{r_p}.
```

## 10. 共同 Lucas 因子的二进节拍与非独立事件

**命题 A-10.1（指定奇素数集合的联合相容）。** 若奇素数 $`p\mid L_a`$、$`a\ge1`$，则 $`v_2(r_p)=v_2(a)+1`$。设 $`P`$ 为有限非空的互异奇素数集合，每个秩偶，则存在 $`a\ge1`$ 使 $`\prod_{p\in P}p\mid L_a`$ 当且仅当所有 $`v_2(r_p)`$ 相等。再要求 $`a=3j+4`$、$`j\ge0`$，充要条件还包括 $`3\nmid r_p`$ 对每个 $`p\in P`$。满足时兼容指标无界。

证明。半周期条件给 $`a=(r_p/2)(2h+1)`$，直接取二赋值。反向令 $`R=\mathrm{lcm}_{p\in P}r_p`$。二等级相同意味着 $`R/r_p`$ 奇，所以 $`R/2\equiv r_p/2\pmod{r_p}`$。任意 $`a=R/2+Rt`$ 同时命中；互异素数两两互素，故平方自由乘积整除 $`L_a`$。标准窗口要求 $`a\equiv1\pmod3`$。若任何秩含三，半秩指标含三而无法满足；若全部秩不含三，CRT 给 $`a\equiv R/2\pmod R`$、$`a\equiv1\pmod3`$ 的无界正解，取 $`a\ge4`$ 即得窗口。此论域是素数集合，不是含重复素数的列表；重复列出 $`p`$ 不会因此证明 $`p^2`$ 整除。首赋值和更高重数仍须另查。[A-R4，命题 168.1 的既有半相位、定理 169.3 证明中的三七排斥；集合的最小公倍数论证如上；经典背景 A-L3，A-L4 仅题录] 证毕。

## 18. 观察者的动作、来源与可保证结果

**定义 A-18.1（已取得节点及固定实现）。** 令 $`\Omega`$ 为供给的来源集合；状态与记录由一套固定、允许的实现逐步产生。节点 $`h=(\text{取得记录},\text{控制},\text{剩余资源})`$，动作菜单 $`\mathscr{\text{𝒜}}(h)`$，相容来源 $`\mathcal{\text{𝒞}}(h)\subseteq\Omega`$，可能回复 $`\mathcal{\text{𝒴}}(h,a)`$。更新记 $`h'=(h,a,y)`$ 并保留来源一致性：$`\mathcal{\text{𝒞}}(h')`$ 恰为在旧来源中实际可返回 $`y`$ 的非空子集。拒绝是独立回复，来源不被观察者任意换掉。终端可由资源、长度或已定义目标给出。若未知源中另有随机性，须将它纳入共同实现或实际条件核。

**命题 A-18.2（歧义、控制与随机回复不等型）。** 来源完全已知可以仍有两个允许动作；来源有隐藏位可以只有一个读取动作。因此 $`\mathcal{\text{𝒞}}(h),\mathscr{\text{𝒜}}(h),\mathcal{\text{𝒴}}(h,a)`$ 互不等同，单凭纤维多解不能证明自由意志或可控结果。

证明。取单个来源、动作左和右、各有确定回复，来源集单点但菜单两项。反向取二个隐藏位来源，唯一动作读位，菜单单点而回复集两项。两个有限模型满足定义 A-18.1，给严格分离反例。素数搜索可选择先检查哪个素数，已固定整数的整除回复由整数决定。证毕。

**命题 A-18.3（存在、稳健和条件期望的不同递推）。** 假定每个非终端节点菜单和每动作可能回复均有限非空，剩余步数 $`t`$ 有限，零步终端效用 $`g(h)\in\{0,1\}`$。停止节点保持 $`g`$。则存在某个实际一致来源分支成功的值和适应策略能保证全部可能回复成功的值分别满足


```math
\begin{aligned}
E_{t+1}(h)&=\max_{a\in\mathscr{\text{𝒜}}(h)}\max_{y\in\mathcal{\text{𝒴}}(h,a)}E_t(h,a,y),\\
V_{t+1}(h)&=\max_{a\in\mathscr{\text{𝒜}}(h)}\min_{y\in\mathcal{\text{𝒴}}(h,a)}V_t(h,a,y).
\end{aligned}
```


若另供一致归一化条件核 $`P(y\mid h,a)`$，最优期望值满足


```math
W_{t+1}(h)=\max_{a\in\mathscr{\text{𝒜}}(h)}\sum_yP(y\mid h,a)W_t(h,a,y).
```


证明。第一式是存在动作及存在回复；第二式是存在动作后对所有回复，后续策略可依实际取得的回复选择。有限非空保证最大、最小可取；按剩余步数归纳给精确值。条件核版本用全期望及有限最大。来源一致性使每个终端分支的整条记录仍有来源，不能每步自由拼一个不一致结果；缺少此条件，max-max 只会计一个虚假的形式路径。期望核不由 max-min 定义自动产生；不同未知律可能给不同 $`W`$。证毕。

## 21. 谱及 Fourier 表示与真正相干来源的边界

**命题 A-21.1（秩事件的精确 Fourier 重写）。** 对 $`r\ge1`$、整数 $`a,b`$，$`\zeta_r=e^{2\pi i/r}`$，


```math
\frac1r\sum_{k=0}^{r-1}\zeta_r^{k(a-b)}=\mathbf{\text{𝟏}}_{a\equiv b\ (r)}.
```

证明。指数为秩倍数时每项一；否则公比 $`t\ne1`$ 且 $`t^r=1`$，有限几何级数 $`(1-t)\sum_{k=0}^{r-1}t^k=1-t^r=0`$。$`r=1`$ 单项一；Lucas 半周期移位给 $`e^{-\pi ik}=(-1)^k`$。奇秩 Lucas 事件恒零，二单独按第九节。单位根向量相消是经典算术表示，不供应相干准备、量子仪器或非对易操作。证毕。

**命题 A-21.2（共同指标事件仍是经典可同时赋值）。** 有限指标集 $`J`$ 上，以 $`|j\rangle`$ 为基定义 $`P_p|j\rangle=E_p(j)|j\rangle`$，则所有 $`P_p`$ 对易；共同酉 $`U`$ 共轭后仍对易。

**命题 A-21.6（实际相位与通道的区别）。** $`AB=-BA`$，$`A^2=B^2=-I`$；固定提升的乘法为


```math
\mathcal{\text{ℒ}}(u,v)\mathcal{\text{ℒ}}(u',v')=(-1)^{uu'+vv'+uv'}\mathcal{\text{ℒ}}(u+u',v+v'),
```


其中右侧指数加法模二。$`M\bmod2`$ 保持此完整余循环，故原树同步 $`\rho`$ 保持中心符号。特别 $`t_L=\langle\langle\beta,\alpha\rangle,\alpha\rangle`$ 与 $`t_R=\langle\alpha,\langle\beta,\alpha\rangle\rangle`$ 同组成 $`(2,1)`$，$`U_{t_L}=-B,U_{t_R}=B`$，同步任意 $`\rho`$ 后仍差负号。

证明。Pauli 乘法给反交换和平方；将 $`A^u`$ 移过 $`B^{v'}`$ 产生 $`uv'`$，两个同类指数进位分别给 $`uu',vv'`$，得全部符号，不只取反对称部分。对 $`M(u,v)=(v,u+v)`$ 展开余循环，两个 $`vu'`$ 项抵消，三个 $`vv'`$ 项留一个，仍得 $`uu'+vv'+uv'`$。叶替换分别 $`A\mapsto B,B\mapsto BA`$，与此自同构相容，结构归纳给同步中心符号不变。直接 $`BAA=-B`$，$`ABA=B`$。原语重相位 $`A'=e^{i\theta_\alpha}A,B'=e^{i\theta_\beta}B`$ 后，树多一个标量 $`e^{i(C_\alpha\theta_\alpha+C_\beta\theta_\beta)}`$，同组成两来源标量相同，相对符号保留。

但 $`\mathrm{Ad}_U=\mathrm{Ad}_{-U}`$，因为对任意密度矩阵 $`\sigma`$，$`(-U)\sigma(-U)^\dagger=U\sigma U^\dagger`$。仅给两个通道名称不能取得相对负号；若实际供给共同控制位的 $`|0\rangle\langle0|\otimes U+|1\rangle\langle1|\otimes V`$、$`|+\rangle`$ 准备和 $`X_P`$ 读取，则 $`V=U`$ 或 $`-U`$ 分别给控制 $`|+\rangle`$ 或 $`|-\rangle`$，才可区分。若两支留下记录 $`e_0,e_1`$，非对角另乘 $`\langle e_1,e_0\rangle`$，不允许删除它。这是 [A-L7] 讨论的未知黑盒通道与额外物理实现的界线，不禁止已明确供应的相干比较。裸 FIB 没有自动供应这组条件。证毕。

**命题 A-21.7（全历史相干不能由经典路径权代替）。** 若实际共同边界是


```math
\Omega_n=\sum_{h,k}|h\rangle\langle k|\otimes\Xi^{(n)}_{hk}\succeq0,
\quad\mathrm{tr}\Omega_n=1,
```


并另供 $`V_n=\sum_{h,a}|h,a\rangle\langle h|\otimes K_{a|h}`$、$`\sum_aK_{a|h}^\dagger K_{a|h}=I`$，则


<table><tbody><tr><td>

```math
\Xi^{(n+1)}_{ha,kb}=K_{a|h}\Xi^{(n)}_{hk}K_{b|k}^\dagger.
```

</td></tr></tbody></table>


经典历史权为 $`\mathrm{tr}\Xi_{hh}`$，一般不确定非对角块或复用环境的未来。

证明。不同 $`|h,a\rangle`$ 正交，故 $`V_n^\dagger V_n=I`$，共轭保持正性和迹；逐块展开得到式。具体反例是两历史的 $`|+\rangle\langle+|`$ 与 $`I/2`$：对角权均为 $`(1/2,1/2)`$，额外供应的共同 $`X_P`$ 比较却给均值一与零。亦可从同一相干输入出发，使两历史留下相同记录或正交记录；约化后的非对角分别乘一或零，仍有相同历史权。块载体必须包括会再次接入的环境、控制和记忆；若实际分支含隐藏 Kraus 指标，需保留共同等距实现及其环境，不能自行挑单个 Kraus 算子拼相干。此式复用 [A-R6，§110]，用具名来源说明共同实现的条件。证毕。
