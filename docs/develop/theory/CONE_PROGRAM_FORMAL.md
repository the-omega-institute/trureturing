## 第一章 一源:GNS 与二款

**定理 1.1(GNS 矩阵形)[证]。**对任意 ρ ∈ 𝔖 与任意 x ∈ M_d(ℂ):Tr(ρ x*x) = ‖x√ρ‖²_HS。

*证明。*‖x√ρ‖²_HS = Tr[(x√ρ)*(x√ρ)] = Tr[√ρ x*x √ρ] = Tr[ρ x*x](迹循环)。∎

**系 1.2(二款即锥截)[证]。**正性 ω(x*x) ≥ 0 为定理 1.1 之"平方非负"读法;归一化 ω(1) = 1 为其 x = 1 截面(‖√ρ‖² = Tr ρ = 1)。故 𝔖 之定义二款 = "期望是长度的平方"之两个侧面。∎

**定理 1.3(祖母定理)[证]。**(经典)对分布 p ≪ q:D(p‖q) ≥ 0,且为归一化恒等式 E_p[q/p] = 1 之 Jensen 影。(量子)D(ρ‖σ) ≥ 0(Klein)。

*证明。*(经典)D(p‖q) = E_p[−ln(q/p)] ≥ −ln E_p[q/p] = −ln Σ_i q_i = 0,由 −ln 之凸性(Jensen)。等号当且仅当 q/p 常值即 p = q。(量子)Klein 不等式:对凸 f 与 Hermitian A, B,Tr[f(A) − f(B) − (A−B)f′(B)] ≥ 0;取 f(t) = t ln t、A = ρ、B = σ 得 D(ρ‖σ) ≥ Tr(ρ − σ) = 0,末步用 Tr σ = Tr ρ = 1(归一截面)。∎

**注 1.4(影之定义)。**称不等式 I 为恒等式 E 之**影**,若 I = E − R,R 为显式非负余项。余项分两族:**统计影**(散度族,凸隙/相关/位移三面一体)与**运动学影**(范数族);二族之祖分别为归一化与正性,合归定理 1.1(**一源**)。

## 第二章 恒等式层与四旗舰验亲

**定理 2.1(经典 DPI 恒等式)[证]。**设信道 W(y|x),p, q 为输入分布,后验 p̂_y(x) = p(x)W(y|x)/(Wp)(y),q̂_y 同。则

$$D(p\|q) = D(Wp\|Wq) + \mathbb{E}_{y\sim Wp}\, D(\hat p_y \| \hat q_y).$$

*证明。*对联合分布 P(x,y) = p(x)W(y|x)、Q(x,y) = q(x)W(y|x) 之散度作两种链式分解。先 X 后 Y:D(P‖Q) = D(p‖q) + E_x D(W(·|x)‖W(·|x)) = D(p‖q)(同信道,第二项零)。先 Y 后 X:D(P‖Q) = D(Wp‖Wq) + E_{y~Wp} D(p̂_y‖q̂_y)。联立即得。∎

**系 2.2(Petz 等号条件之经典形)[证]。**亏为零 ⟺ 两侧后验几乎处处相等 ⟺ 可由输出经贝叶斯逆恢复输入对。可逆信道(置换)之亏恰零。∎

**定理 2.3(Landauer 恒等式)[证]。**设系统 S 初态 ρ_S,热库 R 初态 τ = e^{−βH_R}/Z,联合酉 U 作用后约化态 ρ_S′, ρ_R′,放热 Q = Tr[H_R(ρ_R′ − τ)]。则

$$\beta Q = -\Delta S_S + I(S{:}R)' + D(\rho_R'\|\tau).$$

*证明。*(i)βH_R = −ln τ − ln Z ⟹ βQ = Tr[(ρ_R′−τ)(−ln τ)] = [S(ρ_R′) + D(ρ_R′‖τ)] − S(τ) = ΔS_R + D(ρ_R′‖τ)。(ii)酉不变性:S(ρ_{SR}′) = S(ρ_S) + S(τ)。(iii)I(S:R)′ = S_S′ + S_R′ − S_{SR}′ = ΔS_S + ΔS_R,故 ΔS_R = I′ − ΔS_S。代入 (i) 即得。∎(此恒等式见 Reeb–Wolf [典];上证为在账构件之独立重铸。)

**系 2.4(Landauer 不等式为舍正影)。**βQ ≥ −ΔS_S,弃 I′ ≥ 0 与 D ≥ 0(皆定理 1.3 之裔)。∎

**定理 2.5(完备互斥基之碰撞守恒;素数维)[证]。**设 d 为素数,{B_0,…,B_d} 为 ℂᵈ 上完备互斥基组(计算基与 Weyl 类基),P_i^b 为其秩一投影。则算子恒等式

$$\sum_{b=0}^{d}\sum_{i=1}^{d} P_i^b \otimes P_i^b \;=\; I\otimes I + \mathrm{SWAP},$$

从而对一切 ρ:Σ_b IC_b(ρ) = 1 + Tr ρ²,其中 IC_b = Σ_i (Tr ρP_i^b)²。

*证明。*Weyl 算子 W_{a,c} = X^a Z^c(a,c ∈ ℤ_d)满足 (1/d)Σ_{a,c} W_{a,c} ⊗ W_{a,c}^{-1}·(相位规范下)= SWAP(标准恒等式:双侧矩阵元直验)。d 素时,d² − 1 个非恒等 Weyl 算子恰分拆为 d+1 个循环类(每类 d−1 个),各类之公共本征基即一互斥基 B_b,且 Σ_i P_i^b ⊗ P_i^b = (1/d)Σ_{g∈类_b∪{I}} g ⊗ g^{-1}(对循环群之特征标正交性)。求和:Σ_b Σ_i P⊗P = (1/d)[Σ_{g≠I} g⊗g^{-1} + (d+1) I⊗I] = (1/d)[(d·SWAP − I⊗I) + (d+1)I⊗I] = SWAP + I⊗I。取 Tr[(ρ⊗ρ)·] 即得标量式(Tr[(ρ⊗ρ)SWAP] = Tr ρ²)。∎(标量式见 Ivanovic [典]。)

**系 2.6(测不准为 Jensen 影)[证]。**H_b(ρ) ≥ −ln IC_b(Jensen 于 −ln),求和并用定理 2.5 与 Jensen 于凸函数 −ln 之和:Σ_b H_b ≥ (d+1) ln[(d+1)/(1+Trρ²)]。∎

**定理 2.7(Landau 恒等式与三隙分解)[证]。**设 A_i, B_j Hermitian、A_i² = B_j² = I,S = A₀B₀ + A₀B₁ + A₁B₀ − A₁B₁(隐张量)。则 S² = 4·I + C,C = −[A₀,A₁]⊗[B₀,B₁];对任意态 ω:

$$8 - \langle S\rangle^2 = \mathrm{Var}(S) + \big(\|C\| - \langle C\rangle\big) + \big(4 - \|C\|\big),$$

三项皆非负,分属统计影(凸隙)、运动学影(正性)、运动学影(C*-代数,‖[A₀,A₁]‖ ≤ 2 由 ‖A_i‖ = 1)。饱和 ⟺ 三项同零。

*证明。*直接展开 S²,用 A_i² = I 消对角,余项整理即 C(逐项代数)。分解式为恒等式(移项);Var ≥ 0 为 x² 之 Jensen 影;⟨C⟩ ≤ ‖C‖ 为正性影(‖C‖I − C ⪰ 0);‖C‖ ≤ ‖[A₀,A₁]‖·‖[B₀,B₁]‖ ≤ 4 为范数亚乘性与 ‖[X,Y]‖ ≤ 2‖X‖‖Y‖。∎ **系:Tsirelson 界 |⟨S⟩| ≤ 2√2。**

**定理 2.8(Lagrange 三姊妹)[证]。**设 ⟨·,·⟩ 为任一(半)内积。恒等式 ‖u‖²‖v‖² = |⟨u,v⟩|² + G(u,v),G ≥ 0 为 Gram 楔余。三实例:
(i)**Cramér–Rao**:u = θ̂ − E[θ̂],v = score;Var·I = (∂_θ E θ̂)² + G,无偏时右首项 = 1。
(ii)**Robertson–Schrödinger**:u = (A−⟨A⟩)ψ,v = (B−⟨B⟩)ψ;σ_A²σ_B² = Cov² + |⟨[A,B]⟩/2|² + G(⟨u,v⟩ 之实虚分解)。
(iii)**量子 CR**:SLD 内积 ⟨X,Y⟩_ρ = Tr[ρ(XY+YX)/2],u = T̃,v = L(SLD);Var·F_Q = (∂_θ⟨T⟩)² + G,其中 ⟨T̃,L⟩_ρ = ∂_θ⟨T⟩(由 ∂ρ = (Lρ+ρL)/2 直验)。

*证明。*Gram 二阶行列式非负即恒等式;三实例逐一代入,(iii) 之协变量恒等式:Tr[∂ρ·T] = Tr[(Lρ+ρL)T]/2 = ⟨L, T̃⟩_ρ + ⟨T⟩·Tr[∂ρ] = ⟨L,T̃⟩_ρ。∎ **判读:不等式之强弱 = 自同一恒等式弃项之多少。**

## 第三章 路径散度理论

**引理 3.1(对数方向导数迹恒等式)[证]。**设 m ≻ 0,X Hermitian。则 Tr[m · D ln_m[X]] = Tr X,其中 D ln_m[X] = ∫₀^∞ (m+t)^{-1} X (m+t)^{-1} dt。

*证明。*Tr[m(m+t)^{-1}X(m+t)^{-1}] = Tr[X(m+t)^{-1}m(m+t)^{-1}];在 m 本征基中核为 λ_i/((λ_i+t)(λ_j+t)),仅对角项存活,∫₀^∞ λ/(λ+t)² dt = 1,故总和 = Tr X。∎

**定理 3.2(Kubo–Mori 路径恒等式)[证]。**

$$D(\rho\|\sigma) \;=\; \int_0^1 (1-s)\,\|\rho-\sigma\|^2_{\mathrm{KM},\,m_s}\, ds,\qquad \|X\|^2_{\mathrm{KM},m} := \int_0^\infty \mathrm{Tr}\big[X(m+t)^{-1}X(m+t)^{-1}\big]dt.$$

*证明。*令 F(s) = D(ρ‖m_s)。dF/ds = −Tr[ρ · D ln_{m_s}[Δ]]。写 ρ = m_s + (1−s)Δ:m_s-部分由引理 3.1 得 Tr Δ = 0;余下 −(1−s)Tr[Δ·Dln_{m_s}[Δ]] = −(1−s)‖Δ‖²_{KM,m_s}。F(1) = 0,故 D(ρ‖σ) = F(0) = ∫₀¹(1−s)‖Δ‖²_{KM} ds。∎(KM 度量为熵之 Hessian [典];此式即其 Bregman 积分形之显式证。数值核验:中位偏差 1.2×10⁻¹⁴,病态对经 300 点 Gauss–Legendre 收敛 1.7×10⁻¹²。)

**定理 3.3(量子 DPI 恒等式)[证]。**对任意信道 Φ:

$$D(\rho\|\sigma) - D(\Phi\rho\|\Phi\sigma) = \int_0^1 (1-s)\Big[\|\Delta\|^2_{\mathrm{KM},m_s} - \|\Phi\Delta\|^2_{\mathrm{KM},\Phi m_s}\Big] ds,\quad \text{被积逐点} \ge 0.$$

*证明。*Φ 保线段(Φm_s = (1−s)Φσ + sΦρ),两次应用定理 3.2 相减即恒等式;逐点非负由 KM 属 Petz 单调度量族([典]:Petz 分类)。∎(数值:六十片全非负,积分对真亏 1.1×10⁻¹⁴。)

**系 3.4(SSA)[证]。**I(A:C|B) = D(ρ_{ABC}‖ρ_A⊗ρ_{BC}) − D(ρ_{AB}‖ρ_A⊗ρ_B) 为偏迹信道之 DPI 亏(恒等身份直验,3.2×10⁻¹⁵),故 ≥ 0 由定理 3.3。∎

**系 3.5(SDPI 路径读法)[证]。**记 r_s = ‖ΦΔ‖²/‖Δ‖²(逐片比),η_path = sup_s r_s。则 D(Φρ‖Φσ) ≤ η_path·D(ρ‖σ),且真比为 r_s 之 (1−s)‖Δ‖²-加权平均。∎

**引理 3.6(反演恒等式)[证]。**对 ρ, σ ≻ 0 与 a,b > 0:aρ^{-1} + bσ^{-1} = ρ^{-1}(aσ + bρ)σ^{-1};特别地 B_u := (1−u)ρ^{-1} + uσ^{-1} 满足 **B_u^{-1} = σ\, m_u^{-1}\, ρ**。

*证明。*右乘展开:ρ^{-1}(aσ+bρ)σ^{-1} = aρ^{-1} + bσ^{-1}。取 a = 1−u, b = u 并取逆。∎

**定理 3.7(Belavkin–Staszewski 路径定理)[证]。**记 D_{BS}(ρ‖σ) = Tr[ρ ln(ρ^{1/2}σ^{-1}ρ^{1/2})],RLD 形式 ‖X‖²_{R,m} = Tr[X m^{-1} X]。则

$$D_{BS}(\rho\|\sigma) \;=\; \int_0^1 (1-u)\,\mathrm{Tr}\big[\Delta\, m_u^{-1}\, \Delta\big]\, du.$$

*证明。*四步。(1)ln A = ∫₀¹ (A−1)((1−u)+uA)^{-1} du(积分表示,谱直验);取 A = XX* = ρ^{1/2}σ^{-1}ρ^{1/2}。(2)(1−u)+uA = ρ^{1/2}B_uρ^{1/2},A − 1 = ρ^{1/2}Cρ^{1/2}(C = σ^{-1}−ρ^{-1});循环化简得 D_{BS} = ∫₀¹ Tr[ρ C B_u^{-1}] du。(3)引理 3.6:B_u^{-1} = σ m_u^{-1} ρ。(4)ρCσ = ρσ^{-1}σ − ρρ^{-1}σ·(修正次序:ρ(σ^{-1}−ρ^{-1})σ = ρ − σ = Δ),故 Tr[ρCB_u^{-1}] = Tr[Δ m_u^{-1} ρ] = Tr[Δ m_u^{-1}(m_u + (1−u)Δ)] = (1−u)Tr[Δ m_u^{-1}Δ](TrΔ = 0)。∎(端到端数值 3.9×10⁻¹²;中间恒等 10⁻¹²–10⁻¹⁴。)

**定理 3.8(均值三明治)[证]。**定义路径散度 D_g = ∫₀¹(1−s)‖Δ‖²_{g,m_s}ds,g ∈ {SLD, KM, RLD},核分别为 2/(a+b)、(ln a − ln b)/(a−b)、(a^{-1}+b^{-1})/2,即算术、对数、调和三均值之倒数。由均值链 H(a,b) ≤ L(a,b) ≤ A(a,b)(L 之上下界:L^{-1} = ∫₀¹ dt/((1−t)a+tb),被积以调和—算术夹逼)得核链,故

$$D_{\mathrm{SLD}} \;\le\; D_{\mathrm{KM}} = D(\rho\|\sigma) \;\le\; D_{\mathrm{RLD}} = D_{BS}(\rho\|\sigma).$$

∎(百对随机核验零违例;中项由定理 3.2、右项由定理 3.7。)

**定理 3.9(谱宽签名)[证]。**W(ρ,σ) := D_{RLD} − D_{SLD} ≥ 0,且 W = 0 ⟺ [ρ,σ] = 0。

*证明。*核差 (1/H − 1/A)(λ_i,λ_j) > 0 严格当 λ_i ≠ λ_j、= 0 当相等。W = 0 ⟹ 对 a.e. s,Δ 在 m_s 之非简并本征对上无交叉元;简并块内 m_s 为标量、交换自动;由 m_s 本征系之解析性(Rellich [典])延拓至一切 s,得 [Δ, m_s] ≡ 0;取两值 s 差分得 [Δ,σ] = 0 ⟺ [ρ,σ] = 0。逆向:对易时三核在公共对角上同值(k(λ,λ) = 1/λ),W = 0。∎ **注 [数/目]:**W 非 CPTP 单调(反例 6/200,最大增幅 +0.0496);D_{SLD} 张量超可加(30/30 [数]);D_M ≤ D_{SLD} 为猜想([数] 零违例);**条件定理**:若该猜想成立,则 lim_k k^{-1}D_{SLD}(ρ^{⊗k}‖σ^{⊗k}) = D(ρ‖σ)(两侧夹逼 + Hiai–Petz [典])。

## 第四章 收缩谱

**定义 4.1。**信道 Φ 之 g-收缩系数 η_g(Φ) = sup_{m,X} ‖ΦX‖²_{g,Φm}/‖X‖²_{g,m}(m 内点,X Hermitian 无迹)。族 {η_g} 称**收缩谱**。

**定理 4.2(振幅阻尼之变分统一式与端点)[证]。**AD_γ 于 Bloch 轴作用为 u ↦ u′ = (1−γ)u + γ。轴向相干方向之收缩比 = (1−γ)·φ_g(u′)/φ_g(u),径向轮廓 φ_{SLD} ≡ 1(核 2/(a+b),a+b = 1)、φ_{KM}(u) = \mathrm{artanh}(u)/u、φ_{RLD}(u) = 1/(1−u²)。由此:η_{SLD}(AD_γ) = 1−γ(逐点常值);η_{RLD}(AD_γ) = 1(u → 1 极限,p(1−p)/(p′(1−p′)) → (1−γ)^{-1} 恰消衰减)。∎(全局与轴向同值:SLD 端解析、KM 端数值四位。)

**引理 4.3(双 atanh 引理)[证]。**对 u ∈ (0,1):(i)artanh u ≤ u/(1−u²);(ii)artanh u ≥ u/(1+u²)。

*证明。*(i)artanh u = ∫₀ᵘ dt/(1−t²) ≤ u·max_{[0,u]}(1−t²)^{-1} = u/(1−u²)。(ii)artanh u ≥ u ≥ u/(1+u²)。∎

**定理 4.4(谱—序单调定理)[证]。**对一切 γ:η_{SLD} ≤ η_{KM} ≤ η_{RLD}(AD 族)。

*证明。*比值 = exp∫_u^{u′}(ln φ)′;引理 4.3 予 0 ≤ (ln φ_{KM})′ ≤ (ln φ_{RLD})′ 于 (0,1)((i) ⟺ 左不等,(ii) ⟺ 右不等,直接微分化简);u′ − u = γ(1−u) ≥ 0 且负半轴由 |u′| ≤ (1−γ)|u| + γ 与 φ 偶增归约。逐点序 ⟹ sup 序。∎

**定理 4.5(边界饱和判据)[证]。**设 Φ 有纯不动点 ψ,记 λ_pop、λ_coh 为切空间中布居与相干方向之衰减因子。则相干方向之 RLD 边界比值 = |λ_coh|²/λ_pop ≤ 1(2×2 完全正性矩阵 [[1, λ_coh],[λ̄_coh, λ_pop]] ⪰ 0),等号 ⟺ 信道居 CP 边界。**系:**"纯不动点 ⟹ η_{RLD} = 1"不真(反例 AD∘Deph:实测 η_{RLD} = 0.5988,边界比值三点趋 d² = 0.4900 [数])。∎ **形态学三判据 [数/目]:**谱分裂 ⟺ 极值方向含相干;谱平坦 ⟺ 极值经典化(诸度量经典向同值,Chentsov [典]);谱顶 = 1 ⟺ CP 边界饱和。

**定理 4.6(KM 渐近律)[证/数]。**L = ln(1/(1−γ)) → ∞ 时:η_{KM}(γ) = ((1−γ)/2)[L + ln 2 + 3/(4L) + o(1/L)],极值点 u* ~ 3/(2L)。

*证明(主二项)。*u′ = 1 − (1−γ)(1−u),artanh(1−δ) = ½ln(2/δ) + O(δ);比值分子 = ½[L + ln 2 + ln(1/(1−u))] + O(1−γ);近 u = 0 展开 φ_{KM} = 1 + u²/3 + O(u⁴),对 u 极大化:一阶条件 1 = (2u/3)(L + O(1)),代回得三项展开;首二系数由五点深扫验证(组合残差 O(1/L)),第三系数单调趋 3/4 [数]。∎

# 第三部 方法核(成典;附不可穷尽条款)

## 第九章 纪律法典

**9.1 预注册制。**判据先于数据:凡实验先立可证伪判据与预言值,后开机;违者所得不入账。

**9.2 试杀制。**立了就试杀,含杀自家所立;猜想入册即附**被推翻方式**;处决与流产如实入判负册,判负为主件非注脚。

**9.3 假阳三铁款。**数值识别(PSLQ 等)须过:重根检验、**高度预算**(系数复杂度对可用精度记账;系数贴帽即疑)、双向核(跨参数点一致性)。深尾解析常数须**三件套**:稳定形改写、收敛表、PSLQ。

**9.4 仪器优先审。**反常读数先审仪器后审定理("零税平台"两案、t-网格混叠案、采样饥饿三改案在卷);**采样域随目标域缩放**;涉 σ^{it} 平均一律闭式或自适应;**好仪器的标志不是不出错,是错得响**。

**9.5 计价与检验规范。**保真度必信道级(单输入可被完美匹配吸收作弊,判例在卷);守恒律检验必打相干扇区(守恒本征输入零敏)。

**9.6 分级标注制。**[证]/[典]/[数]/[条件]/[目] 五级,不许越级;类比**可出题不可出证**;呼应唱名即止;防命理墙对一切数值巧合执行粉碎审查。

**9.7 恒等式优先。**一物二算为恒等式工厂之唯一生产线(七案零换厂);证明策略首选:寻同一量之两种分解。

**9.8 不可穷尽条款。**本部为方法之**记录与示范**,非其兑现:何题值得攻、何路当止之判断力若可算法化完备,即成算术判定程序,为哥德尔第二所禁。法典可读,手艺须练;**本部之存在方式是被引用,不是被穷尽**。


**9.9 晶核方法论(核心方法论,院主令立宪;2026-08-04)。**
(一)**分类先行**:凡新题先判三类——**晶面**(平推件:自已知族取对象 + 跑工厂 + 验证即达)、**晶核**(生成器缺件:现册 N1 模流之源、N2 算术之源、N3 相对化重铸、N4 半群条款;经审计可增删)、**封条**(首存、取值、方法之兑现、两颗心脏——定理级封条,只测绘不填充)。
(二)**晶面处置**:不逐件研究,归入附录 C 总纲;动手仅二由——**桥**(服务晶核件或承重补梁)或**矛**(证伪检验点);动手时证书纪律分毫不减。
(三)**晶核处置**:主力所在;战役制推进;慢火件(N2 型)不押工期。

(五)**审计节律**:每逢并陆级事件重跑晶核审计。
(六)**自限条款**:三类判定本身属方法核,依 9.8 不可穷尽;存疑时从晶核处置(宁重勿漏)。
(七)**不赦条款**:本方法论不减免任何证书、判负、预注册义务。
