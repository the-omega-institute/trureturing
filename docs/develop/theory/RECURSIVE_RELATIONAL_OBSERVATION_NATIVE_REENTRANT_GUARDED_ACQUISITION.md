## 3. Persistent states and newly closed local readers

**Definition 3.1 (state payload and installation).** A state is a fixed-arity
framed tuple containing version/phase; original source/public/code/seed

ordered list of complete genuine released responses with full row/dependency
origins.
All variable objects are finite words or actual complete local block
references. None is a finite-control register indexed by a runtime integer.

Export the whole state on25 by ARC26.2's measured export: measure Base,
dry-count an immutable bank field, reposition and copy its bits, append

newest completed `RG-S2` descriptor by CAP6.1's LatestType origin scan,
checks its following seal and actual availability and reads the selected
local interval. A partial new state disables entry, so the old completed
one cannot be resumed as its substitute. A state may contain its previous
state's complete reference; it contains no reference to its own not-yet-
constructed descriptor. All retired states remain constructed.

**Definition 3.2 (close anew before reading).** At each initialized actor

This rule applies separately to initial import, every state reload, every
raw/computed return reader, and the guard reader after its new descriptor
has sealed. In a return reader, all scans use that invocation's frozen

literal compiled cons branch, perform the assignment and MR, then Reverse.
Bank assignments touch64–68 and preserve the native payload head. A sealed
state is exported only after its reader has finished.

**Lemma 3.3 (fresh closed-prefix representation).** Each such reader
terminates and returns exactly its selected available local payloads and
their genuine origins. A row delivered after a previous reader's bound
is included in the new bound and is not replaced by an old equal-valued
row. The reader makes no new original source observation.

*Proof.* CAP6.3 delivers all required blocks/descriptors/statuses and installs

by CAP6.4, but different event origins are not compared by value alone.
If a new descriptor is appended after an earlier count $D_0$, its one-based
ordinal is greater than $D_0$; the next complete-stream count includes it.
This applies even when the new payload has old bits. No search extends its
own bound while writing a destination. Subsequent state export is outside
that closed read. Finiteness follows from the frozen count and finite
payload lengths, including terminal/no-block and seal tests. ∎

## 4. A real return for an unknown raw request

$$

\tag{RG.3}
$$

where $s_-$ is the actual previous state reference and $U_-,J_-$ are the
last acquired journal origins. It has no request-tag, operand, request
reference or waiting computed-packet field. It is not a `RG-CALL2` packet.

**Theorem 4.3 (unknown-request ownership and return).** At a tight reached

There is no automatic safe-growth edge before that original test.

actually completed finite data; the service progress premise supplies its
