## 2. Typed interval registers and their boundaries

**Definition 2.1 (a checked local span).** A payload register has three
metadata fields $(R,o,l)$. Here $R$ is a complete CAP local reference on29
to an initialized immutable available actor-owned bit block on one of
25,26,27,28,69,70; $o,l$ are actual internal unary naturals with
$o+l\le L_R$, where $L_R$ is its checked block length. Its value is

$$
\operatorname{val}(R,o,l)
=\operatorname{payload}(R)[o:o+l].
$$

The displayed equation is a denotation, not an instruction. The whole
block has its actual CAP descriptor, following sep, status address,
available status1 and authentic writer history. An interval has no new
descriptor, capability or ownership token. In particular its reference
does not address a new independently allocated block.

Borrowed mutable work1–12, compiler64–68, private producer ports and
unfinished output are forbidden backing. Acquired remote references
resolve through equal complete origins to the actual local descriptor;
they are never remote payload addresses. Empty-origin local blocks are
selected by their complete local references, not by equality of empty
origin fields. Distinct locally created blocks may all have empty origin.

**Definition 2.2 (metadata and payload types).** Metadata consists of
references, offsets, lengths, ordinal/count/address words, syntactic
cursors and finite phase encodings. Payload consists of the logical word
values operated on by the RG word program, including trees, complete
states, proposals and response items. A length or reference may have the
same bit pattern as some payload; these types classify its construction
and consumer, not its bit pattern.

For each syntactic payload register allocate three fixed root fields.
Add fixed fields for the closed descriptor bound, selected ordinal,
input reference/offset/length, index, absolute address, base, output base,
output length/status/ordinal, saved head, budget, remaining length,
parsed length, leaf counts, open slots, serializer cursors and phase.
Each static helper receives fresh scalar/reference temporaries for
Copy, Add, Subtract, Compare, Equal and reference coding. These helpers
have ARC2.1/RCA12.1's finite expansions on metadata words. First-occurrence
numbering after hygienic inlining gives a finite register count $r_M$,
independent of runtime lengths and request count. No natural selects a
native register or control state.

**Definition 2.3 (callable boundary).** At a callable actor boundary the
active64/65 bank and its separate68 descriptor are completely sealed;
every live root denotes the required word by Definition2.1. Source roots
and a complete descriptor-prefix bound are frozen for each reader/emitter.
The actor has its actual local tokens and the full twelve-word loan
whenever public CAP arithmetic/descriptor helpers run. During publication
of a new root triple, partial bank construction, descriptor append or
partial TOK transfer, there is only the prescribed next primitive.
There is no reader or external acquisition entry at such an interior cut.

The final publication boundary follows completion of all three root
fields and the designated CTL. Updating one field is not itself that
boundary. An interrupted publication therefore supplies neither a usable
partial root nor a substitute old-root continuation.

## 4. Actual resolution, one-head reading and measured sealing

**Definition 4.1 (Check).** At each reader entrance count the complete29
stream anew by CAP6.1's count-only scan, storing its real $U(D)$ before
any new descriptor append. Resolve a requested local reference among
those first $D$ complete records. Obtain one requested field per complete
origin/ordinal scan and check the following seal. For a local root compare
all eight components of its local wire reference with the actual local
descriptor, and require owner $A$, one of the six allowed ports, expected
type, initialized1, mutable0 and matching status address. Execute the
actual At(status); RD test for status1.

For an acquired remote binding $\sigma$, first scan for a local record
whose complete origin equals $\sigma$. Check that record's actual local
owner/port/type/flags/base/length/status, then construct its complete local
reference $R$ from those local fields. The resulting root uses this $R$;
the original $\sigma$ remains in the acquisition/row binding. Its remote
base, port and ordinal are not compared as if they were the local ones.
All later root checks compare the local $R$. An original empty-origin
block instead uses its actual local ordinal and complete local components.
Bound every search by the closed prefix; missing, wrong-kind and unavailable
outcomes remain distinct. Load only reference/scalar fields into metadata.
Compare the actual unary $o+l$ with the checked length. Flags do not issue TOK.

In a field scan retain the requested ordinal and only the current returned
field in public work; import that field into its fixed metadata destination
and release its public temporaries before requesting the next field.
Equal-origin comparisons use the complete reference word, not payload.
CAP's one-field/count/arithmetic graphs then have their original bounded
public-role inventory; other roots, previous fields and cursors are already
on64–68. No caller retains ten public descriptor fields during Check.

**Definition 4.2 (Bit and literal emission).** With a saved span
$(R,o,l)$ and internal unary index $j$, first perform the actual $j<l$
test and Check. Compute $a=b_R+o+j$ by metadata unary additions. Position
the actual active-bank field $1^a$ by RCA's fixed Field. Execute
Home(payload); MR(payload). Per leading1 of the positioned metadata
address execute RD(address); MR(payload); MR(address); the final
RD(address sep) exits. No assignment occurs inside this address loop,
so its bank/head remains fixed. This is a seek driven by an internal
natural; it does not pretend that $1^a$ ends in a wire0.

Execute RD(payload,4) testing0, then the finite CTL test for1 on its other
branch; any other symbol takes structural failure. Select the literal
bit continuation before any helper can clobber4. Emission of that bit
to a destination is Tail(destination); EX; WR(literal bit); MR. Reposition
the next source bit from its saved address; never call a two-head copy
routine with equal source/destination ports.

**Theorem 4.3 (one-head and same-port read/write relation).** Check and
Bit, at their specified authenticated boundary, terminate and return
precisely the requested literal bit with actual local read authority.
If a sequence of such reads emits to the same port, an old source span
and a newly appended destination remain disjoint, and the emitted word
is the read sequence in order. This covers old25/new25 and old70/new70.

*Proof.* CAP's individual field scans select only completed descriptors
and their true local fields. The separate actual status test and current
tokens establish available readable backing. Unary range checking puts
$b_R+o+j$ in its initialized payload, hence at an existing bit cell.
After Home; MR, induction on the address's leading ones places the sole
payload head at that exact cell. The final symbol tests give its bit.

The literal control alternative retains only that finite bit during the
subsequent Tail and append; no old source head is needed then. An append
replaces the old R, beyond every previously sealed payload's sep/status.
It never writes a source payload cell. The next Home/address seek is real
and reestablishes the required source position even on the same port.
The source $o,l$ fence was saved before the append and cannot grow with
the destination. Induction on the fixed read length proves exact order
and noninterference. Metadata operations change only64–68 and public
scalar work, so they do not invalidate that source payload. Every scan
has a finite existing end; every unary loop consumes its finite word. ∎

**Definition 4.4 (complete result writer).** A writer takes saved input
roots, a closed29 bound and a finite bit-emitter schema. It performs:

1. Check all input roots. Measure the destination's actual Base before
   either pass, retaining it in metadata. Initialize a real unary output
   counter and the emitter's fixed cursor fields.
2. Run the emitter in count mode. Each emitted bit executes a compiled
   unary counter increment, with all bank work. Save the complete length.
   Reset the emitter cursors from the frozen roots for write mode.
3. Run exactly that emitter in write mode, each bit using Definition4.2's
   literal emission. Append physical sep and status0. Compute the actual
   status address $b+l+1$ with paid arithmetic. Only now release public
   source roles that descriptor preparation will reuse.
4. Construct the ten complete descriptor fields on ten distinct public
   roles: actual owner/port/base/length, creation field, type, initialized1,
   mutable0, actual status address, and complete origin. For a new local
   result origin is empty. The creation/count scan uses the remaining
   two roles as CAP6.1 prescribes and constructs the real one-based ordinal.
   Execute its full tag/ten-WriteField/seal graph on29. During this append
   no reader scans29 and no source field is fetched from its unfinished tail.
5. Execute At(status); WR1; CTL seal, construct the complete wire reference
   from the actual returned/measured descriptor fields, then publish the
   root and its final callable boundary. A descriptor seal alone did not
   make the earlier status0 payload available.

All bit-source reads in steps1–3 concern the saved prefix. Metadata
assignments append descriptors on68, not29. If a helper requires public
scalar words, export only its currently needed metadata fields; release
them before the ten-field preparation. Persistent roots/cursors remain
on64–68. There is no thirteenth public word role.

**Theorem 4.5 (writer relation and seal order).** For a finite deterministic
emitter whose bit decisions read only the frozen immutable inputs and its
reset cursors, the writer constructs exactly its bit word, with its true
base/length/ordinal/status/reference. It publishes no partial block or
self-reference and preserves all old payloads, including with aliased
same-port input. It has a finite paid expansion using the twelve-word
contract.

*Proof.* The reset makes both passes' logical cursor sequences identical.
The read lemma supplies the same bit at every corresponding decision;
count mode therefore records exactly the number of write emissions.
Base was measured before either emission, and the physical sep/status
follow precisely those emitted bits. Reads on a growing destination still
use the fixed old source fence by Theorem4.3. The writer never extends its
own input bound. Its body has completed before descriptor-role reuse.
The original ten-field writer then reads ten complete distinct words,
with its two count/construction roles and no simultaneous payload roles.
CAP's ordinal scan and field copies give the actual descriptor. Status1
and seal precede reference/root publication. The new result cannot be a
source root of its own earlier emission. Finiteness follows from finite
passes, finite scalar arithmetic and the closed descriptor scans. ∎

## 5. Word operations, self assignment and immutable aliases

**Definition 5.1 (payload leaves).** Snapshot every right-hand root triple
to fresh metadata before changing a destination triple. Empty selects the
installed empty view. Copy copies only that triple. Tail of an empty word
keeps an empty view; otherwise paid scalar successor/subtraction produce
$(R,o+1,l-1)$. Empty tests inspect the metadata length, and a nonempty
first-bit test invokes Bit at0. For literal cons $b x$, freeze the old
$x$, and use the70 writer to emit literal $b$ followed by Bits of that
span in increasing index order. Publish the resulting length-$l+1$ block
only after its complete writer return.

An explicitly requested Reverse first tests $l=0$ and returns the empty
view in that case. Otherwise it starts at the actual unary $l-1$ and
emits indices down to0, exiting after that0 emission without subtracting
below0, into one new70 result. An explicitly requested Cat emits its two frozen spans
in order, with empty-side cases permitted to share the other span. All
indices/decrements and loop tests are metadata compiler operations. A
requested result is distinguished from a parser/export staging cache.

**Theorem 5.2 (leaf and alias correctness).** At every callable boundary
these operations have their usual finite-word values. They are correct
for self-copy, self-tail, self-cons, empty-tail and any sharing of backing
among roots. Copy/tail/tests construct no independent payload word.

*Proof.* Copy and empty have the stated denotations. Removing the first
element of a nonempty interval increments its start and decrements its
length; its range remains within the same checked block. Empty-tail is
defined empty. A test reads either that length or the exact first bit by
Theorem4.3. For cons, Reverse and Cat, the saved right-hand triples denote
the old values throughout the emitter. Theorem4.5 constructs their stated
concatenations/reversal before publication. Thus a destination aliased to
an input changes only its own metadata after all required old reads;
other aliases retain immutable backing. No WR targets a previously sealed
payload. For copy/tail/tests the specified graph has only metadata writes
and at most one payload-bit read into finite control. ∎

## 6. Parsers that return spans rather than payload accumulators

**Definition 6.1 (bounded cursor parsing).** A payload cursor is its saved
parent root and a unary offset/remaining length in metadata. Consuming a
bit tests that remaining length, calls Bit, and updates these scalar
fields. A missing bit has a paid short-block edge. ReadUnary consumes
leading1s with an actual compiled count increment until its real0; it
returns the natural and suffix. Its natural may remain the view of those
leading1s; scalar arithmetic imports that unary value as a scalar, through
its explicit bit loop, only when needed.

ReadFrame uses this counted natural $m$, compares it with the actual
remaining parent length, validates/consumes those $m$ payload bits, and
returns their exact subinterval and the suffix. Take is the same bounded
span selection. ReadList retains RCA12.1's grammar $0$ or
$1\operatorname{Frame}(w)s'$; a1 branch returns an item span and remaining
list cursor, and its final0 is checked at the required list end. Nth
advances actual list and unary-index cursors. Fixed tuple arity, option
tags, reference components and final exhaustion have their original
explicit finite tests.

CAP's eight-component wire reference is its original sequence of eight
Frames with final exhaustion, as in ARC3.4. The word-program tuple/list
codec is RCA12.1's fixed-arity framed list. Each site retains its own
codec; these two tuple conventions are not identified. Decoding a native
29 field additionally retains its physical sep/following-seal grammar.

Equality saves each first literal bit in a finite continuation across
reading the other side; both cursor updates are paid. It scans the two
finite words through their required end tests, retaining unequal length
and mismatch outcomes. Shared-port or identical-span operands use separate
saved offsets and successive seeks. No live source head is assumed across
the second read. On structural refusal retain the bounded remaining scan
required by CAP6.1 before taking that local refusal. It is not an executed
source refusal.

**Theorem 6.2 (codec relation).** On every finite checked bit-block argument,
the cursor parsers have exactly the
original decoded values, suffixes, arity/exhaustion decisions and bounded
failure meanings. Their payload projections are
views; they require no Reverse/Take accumulator, whole-stream snapshot
or ARC26 bounded payload import.

*Proof.* After $k$ successful consumed bits, the saved offset has advanced
by $k$, remaining length has decreased by $k$, and the consumed word is
exactly that parent prefix, by induction using Theorem4.3. Hence the
first0 of ReadUnary returns precisely its preceding1 count and suffix.
The range test for ReadFrame selects exactly its $m$ following bits;
the cursor invariant gives the returned span and suffix, including $m=0$.
An overrun reaches the actual finite short-block test. Induct over list
items and each fixed tuple arity to obtain all subordinate values and
exhaustion decisions. The reference and native descriptor codecs use
their separate stated boundaries. Equality compares the exact bits of
both words and retains the first finite branch across the second read;
shared backing cannot change either bit. Its terminal tests distinguish
lengths. All loops consume a finite parent/list/index or a fixed bounded
remaining suffix. Every output payload in this specification is a root
triple into existing backing, so none of these proofs requires a payload
accumulator in another storage role. ∎

## 7. Complete serializers without whole-state staging

**Definition 7.1 (direct structured emitter).** A structured emission is a
finite nesting of literal bits, saved spans, unary scalar wire fields,
Frames, fixed tuples/options, and cursor-traversed encoded lists, using
exactly the site's original grammar. For a Frame first count the child
emitter's bits, then emit that many literal1s and its0 by actual scalar
loops, then emit the child. Each static nesting level has fresh metadata
checkpoint/cursor/count fields. Restore child cursors from those saved
roots before each pass. Variable list traversal is iterative; its input
is a saved encoded-list span, not an unbounded native recursive call.
Fixed tuple nesting is static. Already encoded items may be emitted as
their checked spans.

To append a response item, validate the old list and emit its encoding
except its final0, then $1\operatorname{Frame}(\text{full new item})0$.
The new item includes the complete genuine response and all original
row/dependency bindings, not only an accept label. Replacements traverse
the old list and emit each retained or selected complete item. No output
accumulator for Frame/Cat/AppendItem is built first.

Use Definition4.4 to write the full original RG-S2 state on25 or the full
RG-CALL2/internal proposal on27. Their fields remain RG3.1/RG6.1's entire
fixed inventory and original nesting: version/phase; source/public/code/
seed bindings; saved original configuration/packet/head data; mode/stage;
round; $t,a,b$; current $H,K$; previous/selected guards and their ingress/
proposal bindings; semantic/unified counts/ends; pending variant; and
the ordered complete response list. All prior snapshots, raw operands,
requests and genuine origins remain in the required fields. A new state
may name its previous sealed state, but never its own unfinished reference.

After state seal, parse that installed block with the span parsers before
the next phase/loan. On the next Entry use fresh complete29 scans and
LatestType/status checks for the actual installed state. New roots then
point into the actual new25 state; they are not justified by a predicted
serialization. A partial new state has no enabled Entry, just as in RG3.1.

**Theorem 7.2 (full output and reload relation).** Direct emission produces
the exact original bit grammar of every specified state/proposal/response
list, including its full required payload fields. Reparse/reload consumes
that actual sealed output and recovers those same logical fields. Neither
direction constructs a whole state or $t$ in a reader/parser/export cache.

*Proof.* For a span the bit lemma gives its exact word. For a literal or
unary field the emitter constructs every required bit. Induction on the
finite structured nesting proves the same for a Frame: its counted child
length is the number of child emissions, its wire prefix is constructed
by the actual unary loop, and the reset child emits its same word.
Tuple/option cases follow their fixed tags and arities. Induction on
the consumed encoded list proves list preservation, response append and
replacement; the final0 is emitted once. No branch drops a response field.
The top writer counts and constructs that entire word with its actual
descriptor/status relation by Theorem4.5. Its sources were earlier sealed
blocks, including old25 when destination25 is used. No state reference
could name the current unfinished block. Theorem6.2 applied to that newly
installed sealed block returns exactly its fields and their real suffixes.
The specified construction has only final output emissions and scalar
checkpoints/counts; a nested frame has no payload staging result. ∎

## 8. Ordered tree computations and the original consumer

**Definition 8.1 (tree scans and result emission).** On public prefix
syntax use branch0, alpha11, beta10. Start open slots at1; branch raises
it by1, a leaf lowers it by1; reject closure before the required end,
missing leaf-bit and nonclosure at the end. Count alpha/beta by actual
bit reads and unary increments. Produce a requested rho result by
emitting the chunks

$$
0\mapsto0,\qquad11\mapsto10,\qquad10\mapsto01011;
$$

for rho squared use

$$
0\mapsto0,\qquad11\mapsto01011,\qquad10\mapsto00101110.
$$

Each result is a counted/written/sealed70 block. An ordered graft emits
branch0 and the two operand spans in the required order. These are genuine
result words. They are distinct from the padded source-token alphabet
PAD00, alpha01, beta10, PAIR11. Where raw/seed ingress has that token
format, retain PR57.T1/LJA2's actual order/bracket-preserving conversion
and its complete finite work. Equal counts never identify two operands.

**Theorem 8.2 (task-level substitution join).** The new tree routines
have exactly the ordered tree and count values consumed by RG7.1, with
the original token/prefix interfaces. They support both branches of RG8's
