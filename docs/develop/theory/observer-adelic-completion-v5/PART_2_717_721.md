# 第七百一十七部　零点运动需要两种导数

设项目中构造一族完成程度为 `\tau` 的解析对象：

```math
F(\tau,s).
```

这里 `\tau` 可以代表：

-  素数截断高度； 
-  黄金 ζ 因子抽取深度； 
-  观察记忆深度； 
-  平滑或 completion 参数。 

设存在简单零点线程：

```math
F(\tau,\rho(\tau))=0.
```

对 `\tau` 求导：

```math
\partial_\tau F
+
\partial_sF\cdot\rho'(\tau)
=
0.
```

因此：

## 定理 717.1（Zero completion velocity）

只要：

```math
\partial_sF(\tau,\rho(\tau))\neq0,
```

就有：

```math
\boxed{
\rho'(\tau)
=
-
\frac{
\partial_\tau F(\tau,\rho(\tau))
}{
\partial_sF(\tau,\rho(\tau))
}.
}
\tag{717.1}
```

所以应区分：

```math
\boxed{
\begin{aligned}
\partial_sF
&=\text{空间导数，描述零点局部几何};\\
\partial_\tau F
&=\text{完成导数，描述新层注入了什么};\\
-\partial_\tau F/\partial_sF
&=\text{零点在完成层级中的运动速度}.
\end{aligned}
}
```

---

## 717.1 静态 Newton 导数

对固定函数 `F`，定义 Newton 向量场：

```math
\boxed{
\mathcal N_F(s)
=
-\frac{F(s)}{F'(s)}.
}
\tag{717.2}
```

它不是一个零点，而是从当前点指向附近零点的局部完成向量。

所以“还未完成但将要完成的点”可以严格表示为：

```math
\boxed{
(s,\mathcal N_F(s)).
}
```

这是一阶 jet，而不是单独的实数点。

# 第七百一十八部　临界反射自动杀死一阶法向导数

令：

```math
s=\frac12+u+it.
```

定义 completed potential：

```math
\boxed{
V(u,t)
=
\log
\left|
\xi\left(
\frac12+u+it
\right)
\right|.
}
\tag{718.1}
```

由 completed `\xi` 的函数方程与实结构：

```math
\xi(1-\overline s)=\overline{\xi(s)},
```

得到：

```math
\boxed{
V(-u,t)=V(u,t).
}
\tag{718.2}
```

因此在 `\xi(\tfrac12+it)\neq0` 的位置：

```math
\boxed{
\partial_uV(0,t)=0,
}
\tag{718.3}
```

更一般地：

```math
\boxed{
\partial_u^{2k+1}V(0,t)=0.
}
\tag{718.4}
```

所以：

```math
\boxed{
\text{临界线上的一阶法向导数永远无法检测反射成对的离线零点。}
}
```

它不是仪器不够灵敏，而是完成对称使一阶信号精确相消。

# 第七百一十九部　正确的导数观察器是二阶曲率

定义临界曲率场：

```math
\boxed{
\mathcal K_\xi(t)
=
\left.
\partial_u^2
\log
\left|
\xi\left(
\frac12+u+it
\right)
\right|
\right|_{u=0}.
}
\tag{719.1}
```

在临界线附近没有零点的区间，`V` 为调和函数，所以：

```math
\partial_u^2V+\partial_t^2V=0.
```

因此：

```math
\boxed{
\mathcal K_\xi(t)
=
-
\frac{d^2}{dt^2}
\log
\left|
\xi\left(
\frac12+it
\right)
\right|.
}
\tag{719.2}
```

令：

```math
L(s)=\frac{\xi'(s)}{\xi(s)}.
```

则：

```math
\boxed{
\mathcal K_\xi(t)
=
\Re
L'\left(
\frac12+it
\right).
}
\tag{719.3}
```

这非常接近你的判断：

```math
\boxed{
\text{隐藏在完成轴之外的结构，
可以在完成轴上的导数中留下影子。}
}
```

而且不需要先在轴外找到那个点。

# 第七百二十部　离线零点对的曲率影子

假设存在一对反射零点：

```math
\rho_\pm
=
\frac12\pm\delta+i\gamma,
\qquad
\delta>0.
```

令：

```math
y=t-\gamma.
```

它们对局部势的贡献为：

```math
\boxed{
V_{\delta,\gamma}(u,t)
=
\frac12\log\bigl((u-\delta)^2+y^2\bigr)
+
\frac12\log\bigl((u+\delta)^2+y^2\bigr).
}
\tag{720.1}
```

对 `u` 求二阶导数并置 `u=0`：

## 定理 720.1（Off-line curvature dipole）

```math
\boxed{
\mathcal K_{\delta,\gamma}(t)
=
2
\frac{
(t-\gamma)^2-\delta^2
}{
\left[
(t-\gamma)^2+\delta^2
\right]^2
}.
}
\tag{720.2}
```

它具有：

```math
\boxed{
\mathcal K_{\delta,\gamma}(\gamma)
=
-\frac2{\delta^2},
}
\tag{720.3}
```

以及零交叉点：

```math
\boxed{
t=\gamma\pm\delta.
}
\tag{720.4}
```

并且：

```math
\int_{\mathbb R}
\mathcal K_{\delta,\gamma}(t)\,dt=0.
```

因此它是一个：

```math
\boxed{
\text{中心负、两翼正、总质量为零的曲率偶极}.
}
```

---

## 720.1 与临界线零点的区别

一个简单临界线零点：

```math
\rho=\frac12+i\gamma
```

对曲率的局部贡献为：

```math
\boxed{
\frac1{(t-\gamma)^2},
}
\tag{720.5}
```

即正奇点。

而一对离线零点在其中心产生负曲率井。

所以在理想隔离情形中：

```math
\boxed{
\text{临界零点}
\leftrightarrow
\text{正曲率奇点},
}
```

```math
\boxed{
\text{离线零点对}
\leftrightarrow
\text{负中心曲率偶极}.
}
```

真实 `\xi` 中还包含全部其他零点和全局解析背景，所以不能仅凭某一点的曲率符号直接宣称发现离线零点；必须进行局部化、背景控制和严格反演。

# 第七百二十一部　离线零点的“出生点”是重根 jet

考虑保持 completed reflection 的实参数族：

```math
F_\tau(s).
```

假设：

```math
s_0=\frac12+i\gamma_0
```

是 `\tau_0` 时的临界线零点。

如果：

```math
\partial_sF_{\tau_0}(s_0)\neq0,
```

则隐函数定理给出唯一邻近零点分支。

反射对称又给出它的反射分支。

由于邻近零点唯一，这两者必须相同，所以零点仍留在临界线上。

因此：

## 定理 721.1（Simple-zero no-bifurcation）

保持完成反射的小扰动不能把一个简单临界线零点推出临界线。

离线零点对若从临界线产生，至少需要：

```math
\boxed{
F_{\tau_0}(s_0)=0,
\qquad
\partial_sF_{\tau_0}(s_0)=0.
}
\tag{721.1}
```

也就是多重零点或零点碰撞。

---

## 721.1 一般二次分岔正规形

在非退化情形，局部可写为：

```math
\boxed{
F_\tau(s)
=
A
\left[
(s-s_0)^2
-
\mu(\tau-\tau_0)
\right]
+
\text{高阶项}.
}
\tag{721.2}
```

于是：

```math
\boxed{
s_\pm(\tau)
=
s_0
\pm
\sqrt{
\mu(\tau-\tau_0)
}
+\cdots.
}
\tag{721.3}
```

所以真正的“还不是离线零点、但将要产生离线零点”的对象是：

```math
\boxed{
(\tau_0,s_0;
F,\partial_sF,\partial_s^2F,\partial_\tau F).
}
```

这是一个二阶 jet／判别式事件，而不是一个普通实轴点。

你的“导数应该能找到”在这里得到最强的严格版本：

```math
\boxed{
\text{寻找 }F=0\text{ 与 }F_s=0\text{ 的共同退化，}
}
```

比直接搜索一个尚未存在的离线零点更合理。
